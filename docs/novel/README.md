|---|---|

## 注意

- **ネタバレを含みます。** 黒幕の正体やクリア後の真相まで書いてあります。
- 元にした資料: `docs/story/` の設計書と、`src/game/world/` に実装ずみの会話。ゲームの設定と食い違ったときは、ゲーム側と設計書を正とします。
- 小説にするために補った部分（情景・心の動き・つなぎの会話、エピローグでレトの封筒の中身など）があります。ゲームには出てきません。
- ゲーム側で「仮」の部分（クリア後の報酬や一部の演出など）は、小説でも仮のままです。
- サブストーリーは「幕間」として、関係する章の中にまぜてあります（S-001〜S-033。S-014は第4章の本編と合わせて書きました）。

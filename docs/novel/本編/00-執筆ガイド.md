# 長編小説版『陽だまり紀行』執筆ガイド（全担当者が最初に読むこと）

全11部・合計およそ50万字。部ごとに別の書き手が並行して書くので、以下の決まりで整合させる。

## 目的とテーマ
- ゲームの物語（`docs/story/`、実装ずみの会話 `src/game/world/`）を、濃い長編小説にする。
- **「人というものがわかる物語」にする。** 善意も悪意も、弱さも強さも、同じ一人の中にある。正しさは人の数だけあり、簡単に白黒はつかない。各部に、人間の一面を掘るテーマを割り当てる（下表）。説教にせず、人物の行動・失敗・沈黙・小さな仕草で見せる。
- **戦闘描写をしっかり書く。** 1部につき大きな戦闘を2〜4回、通常の小競り合いも。間合い、呼吸、仲間の連携、恐怖、迷い、傷の痛み、戦いのあとの静けさを書く。ゲームの技名（見切りの一撃／水紋ノ波／風唱ノ矢・疾風ノ矢／岩砕きの一撃・地固ノ守り／光断ノ一閃 など）を使ってよい。血みどろの残酷描写は避け、子どもから年配まで読める範囲に。
- 文体: 三人称、基本はユーリの視点（節ごとに仲間や敵の視点に移ってよい）。自然でやさしい日本語。会話は生き生きと。地の文は情景（匂い・音・光・手ざわり）を豊かに。同じ言い回し・同じ展開の繰り返しを避ける。
- 既存作品の名前・設定・台詞・展開のまねは禁止（CLAUDE.md 1-1）。

## 分量
- **各部の目標字数を必ず満たすこと**（`wc -m` で確認。空白・改行を含めてよいが、水増しは不可）。足りなければ場面を追加して書き足す。
- 一度に全部書こうとせず、**1ファイル8千〜1万5千字くらいの節ごとに、複数ファイルに分けて Write する**（`docs/novel/本編/NN-部名/01-....md` の形。NNは部番号）。
- 要約で済ませない。会話・心の動き・情景・戦闘を場面として書く。

## 共通設定（動かさない）
- 舞台: 大陸アルテシア。統暦412年。太陽1つ、月2つ（大きな白い朝月／小さな赤い宵月）。通貨は灯貨。灯り石に人々が共鳴して術（共鳴術）を使う。系統: 火照・水紋・風唱・地固・光断。異形「歪み」は灯り石の力が乱れて生まれる。
- ユーリ（16歳、灯里支部の新人調査員）: 素直、人の話をまっすぐ聞く、放っておけない。敬語まじり。左手首に祖父の形見の灯り石の腕輪（ほんのり温かい）。**ユーリが生まれたのは統暦396年。祖父ソウイチが消えた「静まりの年」（392年）より後なので、ユーリは祖父と会ったことがない。** 祖父は消える前、「いつか生まれる孫に腕輪を頼む」と言い残した（ユーリの母は当時、結婚したばかり）。終章で目覚めた祖父とは初対面。祖父の「ずいぶん背が伸びたな」は、「写し絵で見るより、ずっと大きいな」に読み替えてよい。
- レト（26歳前後、先輩調査員）: 皮肉屋、軽口、要所で的確。6歳のとき、合議会の書記官だった兄が「疫病」で死んだと届けられた（静まりの年）。合議会に不信。「静まりの年 覚え書き」の封筒を持つ。技: 見切りの一撃。
- ミナ（17歳、麦香野）: 丁寧でおっとり。水紋系（水紋ノ波）。幼なじみ（水色の灯り石の子）が歪みで行方不明→鉱山の町で再会。歪みへの恐怖と憎しみを隠していた。
- ガイド（16歳、硝子湖の商人の息子）: 早口、駆け引き、損得。風唱系（疾風ノ矢／風唱ノ矢、弓）。従兄は密輸組織の元締めと噂されたが、名を使われただけ（第4章で潔白）。
- オルカ（30代半ば、鉄鏈鉱山の組合代表）: 寡黙、短い言葉。地固系（岩砕きの一撃、地固ノ守り）。若い頃の落盤で仲間を助けられず自責。
- アヤメ（17〜18歳、霜原）: 静かで丁寧、観察者。光断系（光断ノ一閃）。祖父（ハクエイ）は静まりの年の失踪者。エドレアを調べるためユーリたちに近づいた。手帳に観察を書く。
- カセン（灯里支部長、60前後の女性）: 世話焼き、温かい。ソウイチの同僚で、静まりの年に何もできなかった負い目から昔語りを濁す。
- エドレア（合議会代表、50代半ばの女性）: 落ち着いた公人。黒幕。動機は大乱期の再来への本気の恐怖。「争いの芽になる人を先に表から消す」。表向きは公正、ユーリたちに助言もする。口癖の一つ「わたしの言葉を信じるかどうかは、あなた方次第です」。
- ドルン（40歳前後）: 慇懃で摑みどころがない。14歳で灯り石の技を教わっていた孤独な少年だったところをエドレアに拾われた。「平和のために才能を」と信じ込まされた。最後は切り捨てられ、審問で証言し、終章で「いっしょに、償おう」と言う。
- 灯守り（虚灯宮の老人）、議長セイラン（灯芯都、厳格）、長老（浮嶼）、ヴィオン（渡り職人、妻イスカを27年前の浮嶼平定戦で亡くした）、澄影（静滅教団の教祖）。
- 三名の失踪要人: ソウイチ（ユーリの祖父）、ハクエイ（アヤメの祖父）、トウマ（もう一人）。
- 組織: 灯りの相談所（各地に支部）。合議会（灯芯都）。環信仰（祠、灯の環）。

## 仕上げのルール
- 各部の冒頭に、部タイトルと一行のテーマ。各節は見出し付き。
- 完成したら、`wc -m` で全ファイルの合計字数を確認し、目標未達なら書き足す。
- git のコミット・push はしない（統括者が行う）。自分の部のディレクトリ以外は変更しない。
- 報告は短く: 書いたファイル一覧、合計字数、次の部につなぐ最後の状態、設定の食い違いがあればその点。

# 台帳　第05部　砂音

## 最初と最後
- 最初: 鉱山を出て東へ、五人（ユーリ・レト・ミナ・ガイド・オルカ）。徒歩。
- 最後: 帆走車（組合から預かる）で東の街道へ。灯芯都からの招きを受けるが、まず静まりの年の手がかりへ。灰青色の指輪の男は未特定。

## 人物（新出）
ザイド（60代、組合長）／トキオ（25歳、ガイドの9歳上、3年前に失踪、風待ちの岩屋の火の番）／ゴウ（50代、門番）／ナジ（18歳）と妹リリ（5歳、砂熱病）／ケイス（20歳ほど、先導役）／トビ（印刻みの弟子）／情報屋／紫の帯の男／イルマ（東の隊商の長）／ドルン／紺の使者。

## 出来事
1. 砂音着。掟「水は分けよ。火は絶やすな。荷は嘘をつかぬ」。偽の組合印つき抜け荷の調査を頼まれる。ガイドが従兄への疑いを告白。
2. 夜の野営地の待ち伏せ。ドルンが二重底を教えて消える。偽印（縁に波模様なし）とトキオ署名の帳面。ガイドが別人の字と指摘。
3. 分け水の泉の岩に「トキオ／水は分けよ。三年前の夏」。
4. ナジの抜け道問題。宿場で荷獣を借りる条文を使い、薬草を間に合わせる。
5. ドルンが灯り石を砕き砂嵐の歪み出現、撃破。トビの証言（師匠の薬を人質に偽印を彫った、灰青色の指輪の男、ガイドの盗まれた手紙が手本）。
6. 審理でユーリが七日の猶予を願う。風待ちの岩屋でトキオと再会（白紙の保証状、脅迫、失踪）。紺の外套の男「平和のための、必要な処置」。
7. 砂鯨（歪み）を、音叉・ガイドの風・ユーリの剣で鎮める。東の隊商を救う。
8. 町で審理、トキオは火の番を正式な役目に。紫の帯の男が謝る。帆走車を預かる。エドレアの使者が「真実の一部」と伝言。

## 新設定
砂丘は日没後に鳴る。岩屋に音叉。使者の伝言は口上のみ。

## 第2回校閲で確定したこと
- 一人称: ユーリ・トビ・ケイスは「ぼく」、ガイド・レト・トキオは「俺」（ガイドの「ぼく」は全部「俺」に直した）。ザイドは「わし」、髭は短く刈った白髭。
- 指輪の色は「灰青色」に統一（青灰色は直した）。ガイドは16歳、トキオは25歳。
- 日数: 到着後、ナジの薬は出発から4日目に届く。審理で7日の猶予をもらい、岩屋往復で2日と少し、町に戻るのは猶予の途中。旅立ちの朝は到着から10日ほどあと。
- 帆走車は組合から預かる。第06部の冒頭で砂音から東へ3日走り、崖の手前で降りる。
- 使者は「代表・エドレア」の名で伝言（392年当時は書記長、就任は393年。現在は代表でよい）。ユーリの腕輪は「祖父の形見」。

## 他の部への注意
- 第06部の冒頭は、この部の終わり（帆走車で東の街道へ）と合っている。

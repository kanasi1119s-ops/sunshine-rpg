# 台帳　第09部　灯芯都（第8章）

## 人物・持ち物
- ユーリ(16): 剣。腕輪＋革の帯、書き付け、ハルオミの白い石。レト(26): 短剣、覚え書き、一人称「俺」。ミナ／ガイド／オルカ(大槌)／アヤメ。
- エドレア(50代半ば): 385年書記見習い→389年灰渡を視察官で見る→392年書記長→393年代表就任。青い石。死者19人の名を毎晩読む。
- ドルン(40歳前後): 灰色の外套、脇腹の傷。掃除人（墨色の外套）に追われ、庭師の源に救われる。
- セイラン(議長、60過ぎ)、ロクジョウ、議事官、トクヨウ(元記録係)、源、使用人キヨ、澄影(本名ハルオミ)。

## 出来事の順
1. 空の船「風待ち」(灯り石の機関と羽根)で到着。審問は翌朝。使用人たちから「怖がるエドレア」の話。夜、水路で歪みと戦う。
2. ドルンが逃げ、源と傍聴席へ。朝、トクヨウが革の帯と「約束の酒」を託す。議場の床下に脈動。
3. 審問。帳簿(毎回4999灯、代表印)と碑の書き換え(392年欄「四名退職・うち三名行方不明」→「疫病の噂」)。持ち出したのは帳簿の写しと「静まりの年」の1冊、浮嶼には複数冊。トクヨウ証言。ドルンが指示書の印で告発。
4. エドレアの動機(平定戦4208人、灰渡、地方の連合)。消したのは三人(ソウイチ・ハクエイ・トウマ)。ソウイチは「みんなで怖がりましょう」と言い、正しかったから眠らされた。
5. 床の番人(柱六本)戦。核は頭の器。ドルンが回路を乱し、十を数える間に撃破。
6. エドレアは転移、「虚灯宮」の書き付け。レトが覚え書きを読む。カセンの手紙。ハルオミが名を呼ばれ消える。前夜、セイランが依頼状とドルンの図面を渡す。翌朝、空の船「風待ち」(渡し守が操縦)で出発、桟橋にセイランが立つ。

## 最初と最後
- 最初: 浮嶼を発って二日め、6人。
- 最後: 風待ちで出発直前(帆船ではない。帆船は3日後にセイランが迎えに出す)。エドレア逃亡・停職、ドルン勾留、レトの兄は生死不明のまま。

## 新設定
- エドレア代表就任は393年。
- ソウイチの置き手紙「家族へ」（消えた）。革の帯は置き忘れ。ソウイチは今年60。
- 死者19人（麦香野は0人）。麦香野の装置は15年前設置。
- 議決は賛成41・反対3・棄権4。セイラン「二十年、目を閉じていた」(比喩)。一人称: ガイド「俺」、ユーリ「ぼく」。
- 要確認: 06の原本は「当年春」退職、04のエドレアは「秋の終わり」にソウイチ来訪(退職後も在職扱いの含み)。10-01の見送りは議長と議員のみ、09-06はトクヨウと議事官も桟橋にいる。

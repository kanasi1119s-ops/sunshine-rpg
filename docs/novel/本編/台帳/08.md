# 台帳　第08部　浮嶼（統暦412年）

## 登場人物・持ち物
- 長老（老婆、空色の肩掛け）: 挨拶「いい風を」。船「風待ち」を託す。
- サザン（90近い、右目白濁）: 日誌『灯石の記』。ドルンを386〜389年に教えた。伝言「日誌は、まだ残しておる」。
- ヴィオン（60前後）: 渡り職人。妻イスカを27年前に失う。空鳥の木彫りと太綱。
- エドレア（50代半ば、紺の衣）: 初登場。
- 渡し守（操縦）、ノイ（娘メグを失う）、澄影（消えかけ）。

## 出来事の順
1. 籠舟で浮嶼へ、雲まとい撃退。長老から平定戦と北の整備区画の話。
2. サザンの日誌でドルンの生い立ち（父は船を造り自殺、叔父に殴られ、14歳で拾われる）。ヴィオンと出会う。
3. 夜、整備区画へ。見張り灯6つ。帳簿の部屋（「ソウイチ・ハクエイ・トウマ　処置済　保全」「保全区画へ移送。所在は代表のみが知る」）。
4. 監視卓の歪みを鎮める。エドレアが現れ「続きは灯芯都で」と去る。
5. 風待ちを託される。避難民の手伝い、ノイと澄影（「次が最後」）。屋根でレトが「期待する」と決める。
6. ヴィオンが荷舟の綱を切らず、嵐の夜に船員を救う。空鳥をユーリへ。
7. 風待ちで灯芯都へ。

## 最初と最後の状態
- 最初: 霜原から帆走車で到着。「あの方」の確証はない。
- 最後: 帳簿の写し、「静まりの年」の原本、エドレアの書き付け、空鳥を持ち灯芯都へ。水平線に嵐雲の渦（伏線）。

## 新設定
- 眠りびとは「保全」で生きている含み。所在は代表のみ知る。
- 別会計『灯り石保全費・特別支出』、1件4999灯まで。
- 風待ちは平定戦の終わりに隠された船。定員7〜8人。
- 「灯合」は使わず「合議会」。大乱期は180〜210年の30年。

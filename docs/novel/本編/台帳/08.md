# 台帳　第08部　浮嶼（412年）第2回校閲済み

## 人物・持ち物
- 長老（老婆、一人称「わたし」）: 挨拶「いい風を」。船「風待ち」を託す。
- サザン（90近い）: 日誌『灯石の記』。ドルンの師（386〜389年）。伝言「日誌は、まだ残しておる」。
- ヴィオン（60前後）: 渡り職人。妻イスカを27年前に失う。空鳥の木彫り。
- エドレア（50代半ば、紺の衣、現代表）、渡し守（操縦）、ノイ（娘メグを失う）、澄影（消えかけ）。

## 出来事の順
1. 籠舟で浮嶼へ。長老から平定戦（27年前）と北の整備区画の話。
2. サザンの日誌でドルンの生い立ち。ヴィオンと出会う。北の島に合議会の旗1本。
3. 整備区画へ。見張り灯6つ。帳簿は複数冊。392年「静まりの年」に「ソウイチ・ハクエイ・トウマ　処置済　保全」。署名欄は「合議会・書記長　処置責任者」、名は擦れ、払いはエドレア似。
4. 監視卓の歪みを鎮める。エドレアが「続きは灯芯都で」。大乱期は180〜210年の30年。
5. 風待ちを託される（灯り石の機関と羽根、帆なし、定員7〜8人）。旗は島の三つの角に三本。レトが「期待する」。
6. ヴィオンが嵐の夜に綱を切らず船員を救う。空鳥をユーリへ。
7. 風待ちで灯芯都へ。

## 最初と最後
最後は帳簿の写し、「静まりの年」原本1冊、書き付け、空鳥を持ち出発。水平線に嵐雲の渦（伏線）。

## 新設定
眠りびとは「保全」で生存の含み。別会計は1件4999灯まで。風待ちは平定戦末に隠された船。

## 第2回で直した点
ガイドの一人称を「俺」に。羽根は「翼のよう、帆はない」。署名欄に「書記長」。帳簿は全部持ち出せない旨に。「舟員」→「船員」。

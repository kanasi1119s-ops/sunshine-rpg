# 台帳 第06部 霧断崖（校閲後）

## 最初の状態
砂音から帆走車で東へ三日、五人（ユーリ・レト・ミナ・ガイド・オルカ）。砂音を発つ前に、エドレアの使者（紺の外套）に会っている。レトの冗談が軽い。

## 登場人物（この部の新顔）
- ホウゲン（司祭、五十年近く仕えた老人）。二十年前、灯芯都の使いに「記録は簡潔に」と言われ、碑の欄が削られたのを知りつつ黙った。
- ツムギ（見習い巫女、14〜15歳、一人称「私」）。灯りの巡礼儀礼を手伝わせる。光断の灯り石（一度きり）をユーリに渡す。
- ユキヒサ（聖堂の書記、四十過ぎ。旧稿の名ハルマを、ミナの幼なじみ「ハル」と紛れるため改名）。気づいて黙っていた。
- オウギ（写字官、五十ほど、合議会書庫局。娘が灯芯都で「保護」の名の人質）。碑を書き換えた。上の「高い場所のお方」は名を知らない。署名は印だけ、添え書きは「記録を、正しい形に」。
- 記録係の老人（四十年勤務、名なし。トクヨウとは別人扱い）。故・先代書記の余白の一行を見つけた人。
- 老女の巡礼者（41回目の巡礼）。巡礼歌を教える。
- 運び屋三人（引き渡された）、カイ（9〜10歳）とその母、冷谷村の村人約30人、旅の商人、地方兵、司祭見習いの青年。
- 澄影（静滅教団の教祖、三十代半ば、白い衣、長い黒髪）。本名ハルオミはこの部では名乗らない。共鳴術で心の響きを聞く。「合一の秘技」。

## 出来事の順
1. 霧の道で人形の歪み7体を撃退。宿坊で司祭が予言の碑（「霧が町を呑み、人々は灯を失う」）を相談。老女の巡礼歌（四番「霧は町を抱き」）が逆と気づく。夜、レトが兄の疫病を語る。
2. ツムギの手伝いで三つの祠に灯りを置く（ミナは「ハル」を思い、自分を励ます。オルカは12年前の落盤で友カジ。ガイドは従兄。レトは兄。ユーリは祖父）。五つの光が一つになる。禁域の縄と「沈黙」。書記から写字官オウギの存在を聞く。
3. 夜、運び屋三人を捕らえ、予言の推敲案の紙（書庫局の透かし）を得る。
4. 記録の間で碑の改ざん、392年の欄「四名退職・三名行方を絶つ」、原本の綴りに「ハクエイ、トウマ、ソウイチ」を発見。ユーリは崖のふちで動揺し、ミナ・オルカ・レト・ガイドに支えられる。
5. オウギが黒い灯り石を砕き、碑が「予言の歪み」に。書いた文が、信じた者に現実になる。ユーリらが撃破。オウギは碑の修復を誓う。司祭が住民に告白。巡礼歌の合唱。カセンに手紙、返信が届く（ソウイチは腕輪を頼むと言っていた）。
6. 冷谷村の異変。カイの母を含む村人を、澄影の合一の秘技から解放（ツムギの石でユーリが光断ノ一閃）。澄影は霧に消える。
7. 碑に真実が刻まれ、レトは「名は略す」に兄を思う。ユーリは禁域の前で「いつか来る」と誓う。北の霜原へ出発。

## 最後の状態
五人、北へ。祖父の名（灯里出身、元調査員、合議会員二期目）を知った。母の返事はまだ。ユーリは司祭から灯りの芯を一本もらう。ツムギの光断石は使用済み。澄影は行方不明。オウギの娘の件は相談所が動く約束。

## 新設定・注意
- ユーリの一人称は「僕」（手紙も）。ツムギは「私」。
- 光断ノ一閃は、ツムギの石を通してユーリが一度だけ使った。
- 澄影の年齢は三十代半ば（他部と要照合）。

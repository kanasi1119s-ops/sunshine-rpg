## 注意
- 小説にするために補った人物・出来事があります（ゲームには出てきません）。ゲームと食い違ったときは、ゲームと設計書（`docs/story/`）を正とします。
- ゲームで「仮」の部分（クリア後の報酬など）は、小説でも軽く扱っています。
- 設定の決めごと: ユーリは統暦396年生まれで、祖父ソウイチとは終章が初対面。ガイドの従兄はトキオ、ミナの幼なじみはハル。

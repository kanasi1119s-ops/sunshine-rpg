# 確定事項（全部の校閲者が守る基準。00-執筆ガイド.md の共通設定に加えて）

## 人物・名前
- ガイドの従兄は**トキオ**（25歳前後、ガイドより9歳上）、ガイドの父は**ロウガ**（湖鳥商会の主）。焼き印は翼をたたんだ白い水鳥。
- ミナの幼なじみは**ハル**（ミナと同い年、4年前の初夏に失踪、水色の灯り石、目撃者は少年コタ）。鉱山の町で再会する。
- 麦香野の青年は**シン**（浚渫で発生装置を掘り当てた）。鉱山の少年坑夫は**ケン**（旧シン）、坑夫**マサ**（旧ゴンザ）、食堂の女**ヨネ**（旧トメ）。麦香野のゴンザ・タヘイは農夫。
- オルカは**男性**（一人称「俺」）。12年前の落盤で友カジを亡くす。副代表スズ、事務員ミオ、支配人トウゴ。
- レトは26歳。6歳のとき書記官だった兄が「疫病」で死んだと届けられた。兄は実は虚灯宮の静めの間に眠っていて、終章で目覚める。武器はレトが短剣、ユーリは剣。
- アヤメは統暦394年生まれ、祖父ハクエイには会ったことがない。祖母に育てられ、祖母は3年前に亡くなった。
- ドルンの生い立ち: 浮嶼の雲海衆の船大工の子。母は早世、父は平定戦で軍に船を造らされ戦後に自殺。叔父に引き取られて殴られる。14歳（統暦386年）のとき灯芯都の若い女役人（のちのエドレア）に見出され、島の老技術者サザンのもとで3年学び、389年に灯芯都へ。390〜392年に試作機を組み上げる。
- 澄影の本名はハルオミ。静滅教団の教祖。
- 老人トクヨウ（元・記録係、ソウイチの同僚）。議長セイラン。議員ロクジョウ。先代代表ガンリュウ。
- 眠りびと: ソウイチ、ハクエイ、トウマ、レトの兄ほか。終章で目覚め、灯里へ帰る（目覚めなかった人もいる）。ソウイチは灯里在住で、後日談の深部には同行しない。
- ユーリの母はハルカ、存命。ユーリは396年生まれで、祖父ソウイチとは終章が初対面。祖父は「いつか生まれる孫に腕輪を頼む」と言い残した。ソウイチの初対面の台詞は「生まれたのか。……大きくなったな」。

- 分量は減らさない（削るのは重複・矛盾・水増しの箇所だけ）。物語の筋は変えない。必要なら場面の追加・書き足しは可。

- 自分の部以外のファイルは編集しない。他の部との食い違いは報告に書く（統括者が振り分ける）。

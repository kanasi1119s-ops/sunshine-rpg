# 物語全体の構成

`bible.md`・`characters.md` を土台にした、序章〜終章のあらすじ骨子。真相の詳細（黒幕の正体・各章のトリック）は `docs/story/mystery.md` 側で管理し、この文書では「各章で表向きに何が起きるか」「何が少しだけ見え始めるか」までにとどめる（ネタバレの分散防止）。予定プレイ時間は `docs/playtime-budget.md` と合わせて管理する。

## 全体の起承転結

- **起（序章〜第2章）**: ユーリが灯りの相談所の新人調査員として旅を始め、仲間が増えていく。各地の事件は一見バラバラだが、共通して「歪み」の不審な発生と「静まりの年」というキーワードがちらつく
- **承（第3章〜第5章）**: 事件の裏にゲルドという仲介人の存在が見えてくる。灯芯都の合議会にも不穏な影があると分かり、フィアが合流する伏線が撒かれる
- **転（第6章〜第7章）**: フィアが合流し、黒幕の輪郭が見え始める。行動範囲が空の乗り物まで広がり、これまでの地方の出来事がすべて繋がっていることが判明する
- **結（第8章〜終章）**: 灯芯都で真相の全貌が明かされる。黒幕との対決、「静まりの年」の真実、ユーリの祖父の消息が明らかになり、クリア後は裏ボスへの道が開く

## 章ごとの構成

### 序章（灯里）
- **舞台**: 主人公の故郷、港町・灯里
- **事件**: 町の外れで「歪み」が頻発し、灯りの相談所に調査依頼が入る
- **起承転結**: 事件の調査→依頼人との交流→歪みの討伐→実は人為的に発生させた形跡がある、という違和感で幕引き
- **明かされる真相の断片**: 「歪みは自然発生とは限らない」という前提が提示される（黒幕の存在はまだ示唆すらしない）
- **仲間の出入り**: レトが同行を申し出て加入
- **章の引き**: カセン支部長が言葉を濁しながら「灯芯都にも報告しておく」と言う
- **予定プレイ時間**: 2.5〜3時間

### 第1章（麦香野）
- **舞台**: 農村地帯、水路と水車小屋
- **事件**: 水路の水が突然枯れ、村同士の水争いに発展しかけている。原因は水源近くの歪み
- **明かされる真相の断片**: 歪みの発生地点に、いずれも古い「灯り石の採掘跡」があるという共通点
- **仲間の出入り**: ミナが加入
- **章の引き**: ミナの幼なじみの行方が歪みに関係している疑いが浮上する
- **予定プレイ時間**: 3〜3.5時間

### 第2章（硝子湖）
- **舞台**: 湖上の交易都市
- **事件**: 密輸組織が絡む事件。密輸品の中に不自然な量の灯り石が含まれている
- **明かされる真相の断片**: 密輸組織に指示を出している仲介人「ゲルド」の存在が初めて表に出る
- **仲間の出入り**: ガイドが加入
- **章の引き**: ゲルドが正体を明かさぬまま去り際に「灯芯都からの依頼でね」と一言残す
- **予定プレイ時間**: 3〜3.5時間

### 第3章（鉄鏈鉱山）
- **舞台**: 灯り石の鉱山町
- **事件**: 労働争議に乗じて鉱山の奥で違法な採掘・実験が行われている
- **明かされる真相の断片**: 「歪みを人為的に作る実験」が実在することが確定する
- **仲間の出入り**: オルカが加入
- **章の引き**: 実験の指示書に「静まりの年」という単語が記されているのをユーリが見つける
- **予定プレイ時間**: 3.5〜4時間

### 第4章（砂音）
- **舞台**: 砂漠の隊商都市
- **事件**: 隊商route を巡る対立と、隊商に紛れ込んだ密輸ルートの摘発
- **明かされる真相の断片**: ゲルドの後ろに、さらに上位の依頼主（合議会関係者)がいる可能性が浮かぶ
- **仲間の出入り**: 加入なし（既存パーティで進行）。帆走車の入手で行動範囲拡大
- **章の引き**: 灯芯都から合議会代表・エドレアの使者が接触してくる
- **予定プレイ時間**: 3〜3.5時間

### 第5章（霧断崖）
- **舞台**: 断崖の古都、宗教都市
- **事件**: 環信仰の聖地で起きた「予言めいた事件」。実際は情報操作
- **明かされる真相の断片**: 「静まりの年」に合議会要人が複数失脚・失踪した経緯の一部が、古い記録から判明する
- **仲間の出入り**: 加入なし
- **章の引き**: ユーリの祖父の名が記録に残っていたことが判明する
- **予定プレイ時間**: 3.5〜4時間

### 第6章（氷華）
- **舞台**: 北の雪原、かつての大乱期の戦跡
- **事件**: 戦跡に隠された施設を巡る事件。ゲルドと直接対峙する
- **明かされる真相の断片**: フィアの本当の目的（黒幕・「静まりの年」関係者の血縁）が明かされる
- **仲間の出入り**: フィアが加入
- **章の引き**: ゲルドが「これ以上はあの方の領分だ」と言い残して姿を消す
- **予定プレイ時間**: 4時間

### 第7章（浮嶼）
- **舞台**: 空の乗り物で渡る浮島群
- **事件**: 浮島に隠された黒幕の拠点の一つを発見し、これまでの事件がすべて黒幕につながっていたと判明
- **明かされる真相の断片**: 黒幕の正体そのものではなく、「静まりの年」に黒幕が何を行ったかの全体像が見える
- **仲間の出入り**: 加入なし。空の乗り物の入手で行動範囲が最大に広がる
- **章の引き**: 黒幕が初めて直接姿を見せ、灯芯都で待つと告げる
- **予定プレイ時間**: 4時間

### 第8章（灯芯都）
- **舞台**: 大陸中央の王都
- **事件**: 合議会そのものを巻き込んだ最終局面。エドレアの立場が明らかになる
- **明かされる真相の断片**: 黒幕の正体と動機が確定する。ユーリの祖父の消息も明らかになる
- **仲間の出入り**: 加入なし。全員そろって終章へ
- **章の引き**: 黒幕が「虚灯宮」へ去り、決着の舞台が整う
- **予定プレイ時間**: 4〜4.5時間

### 終章（虚灯宮）
- **舞台**: 神話伝承の最果て
- **事件**: 黒幕との最終決戦。「灯の環」の真の姿と「静まりの年」の全真相が明かされる
- **明かされる真相の断片**: 物語全体の謎がすべて回収される
- **仲間の出入り**: 全員参加
- **章の引き**: エンディング。クリア後、裏ボスへの道（虚灯宮の奥）が開く
- **予定プレイ時間**: 3〜3.5時間

## 合計時間の目安

- 上記の合計: 約34.5〜38.5時間（メイン部分のみ、寄り道除く）
- サブストーリー・寄り道を含めた最終確認は `docs/playtime-budget.md` で行う（2-8）

# サブストーリー一覧（骨子）

各章で立ち寄れる寄り道クエストの一覧。ここでは「タイトル・発生条件・あらすじ・報酬・本編や裏ボスとのつながり・予定プレイ時間」までを骨子として決める。会話文の具体的なセリフ・イベントスクリプトはフェーズ5（実装時）に詰める。

**設計方針**
- 各章2〜4本、合計28本（`docs/roadmap.md` 2-6 の目標「25本以上」を満たす）
- 本編の謎（`mystery.md`）に直接関わるものは少数にとどめ、大半は「その章の土地・人・仲間の素顔を掘る」寄り道として設計する（本編のミステリーが薄まらないようにするため）
- 発生条件は「その章の間、灯里支部や各町の依頼所（掲示板）から受注できる」を基本形とし、仲間の加入後でないと受けられないものは明記する
- 予定プレイ時間の合計はこの文書の末尾で集計し、`docs/playtime-budget.md`（2-8）に引き継ぐ

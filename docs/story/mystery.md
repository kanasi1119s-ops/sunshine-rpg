# 真相の設計書（機密度の高い文書）

物語全体を貫く謎の答え、黒幕の正体、各章の事件の真相・トリック・動機をまとめる。ネタバレそのものなので、この内容をプレイヤー向けの文章（マニュアル・紹介文・デバッグ表示以外の場所）にそのまま書き写さないこと。イベント作成・伏線配置は必ずこの文書を確認してから行う。

## 1. 物語全体の謎（大枠）

### 黒幕の正体
**合議会代表・エドレア**（`characters.md` に「重要NPC」として先出しし、終盤まで味方とも敵ともつかない立場で登場させている人物）。

- 表の顔: 灯芯都の合議会代表。公正中立な立場を装い、ユーリたちに時折助言を与える「大人の理解者」ポジション
- 裏の顔: 「静まりの年」の事件を引き起こした張本人。当時、合議会内部の権力争いに敗れかけていたエドレアが、灯り石の力を使って対立していた要人たちを排除（失脚・記憶操作を伴う失踪）した
- **動機**: エドレアは、大乱期（統暦180〜210年）の再来を本気で恐れていた。灯り石の採掘権を巡る争いが再燃すれば大陸全土が戦火に包まれると確信し、「争いの芽になりうる有力者を、表に出さない形で排除すれば平和が保てる」という歪んだ正義感で行動した
- **手段**: 「歪み」を人為的に発生させる技術（灯り石の暴走を人為的に引き起こす）を、当時まだ若かったドルンを使って開発・運用させた。以後20年、合議会の代表として振る舞いながら、都合の悪い動きがあるたびに各地でドルンに指示し、歪みを使った事件を起こしてきた
- **ユーリの祖父との関係**: ユーリの祖父は当時の合議会員で、エドレアの計画にいち早く気づき、証拠を集めて告発しようとしていた。エドレアはこれを「静まりの年」の最後の標的として、祖父を人知れず幽閉した（虚灯宮の奥に、記憶を封じた状態で今も生存している。終章で再会・救出）
- **アヤメとの関係**: アヤメは、「静まりの年」で失脚したもう一人の要人の孫。エドレアを合議会内部から調べ続けており、ユーリたちに接触したのもそのため

### ドルンの立ち位置
- エドレアに拾われ、灯り石を使った技術者として育てられた人物。表の悪役として各章で暗躍するが、本人はエドレアの「平和のため」という言葉を信じ込まされている
- 終盤（第7〜8章）で、エドレアに切り捨てられる形で退場し、ユーリたちに真実の一端を託す（完全な悪役のまま終わらせない）

## 3. 推理パートの設計方針

- 各章に1つ、「集めた手がかりから、誰が・何のために事件を起こしたかを選択式で問う」推理パートを置く（序章のみ簡易版でチュートリアルを兼ねる）
- 正解しなくても物語は進む。正解数に応じて手帳の評価・報酬アイテムが変わる程度に留める
- 各章の推理パートの具体的な問い・選択肢・正解・根拠手がかりIDは、章のイベント作成時に `clue-ledger.md` と合わせて確定させる（この文書では出題方針のみ管理）
- **実装済み（序章）**: `src/game/world/chapter0-world.ts` の `reasoningQuizCommands()`。レトが「歪みはなぜ起きたと思うか」を選択式で問い、手がかりC-001（人為的な痕跡）を見つけていることが前提（未発見なら先に調査するよう促し、クイズは出さない＝フェアプレイの原則を実装レベルでも徹底）。不正解でも物語（レトの仲間加入）は進み、レトが手がかりを振り返るヒントを一言添える

## 4. レッドヘリング（意図的なミスリード）

- **カセン支部長**: 言葉を濁す描写を多用し、序盤プレイヤーに「何か隠している=怪しい」と思わせる。実際は単に「静まりの年」で親しい同僚（ユーリの祖父）を失った気まずさから言葉少なになっているだけで、事件には無関係
- **ガイドの出自**: 密輸組織の元締めと血縁という設定自体が中盤の疑惑の対象になるが、ガイド本人は無関係。第2章〜第4章で疑いが強まり、第4章で潔白が証明される流れにする
- レッドヘリードは真相が明かされた後に「そういう繋がりだったのか」と得心が行くよう、後付け感が出ないように各章のイベント作成時に伏線を薄く仕込む（`clue-ledger.md` で追跡）

## 5. フェアプレイチェックのルール

- 終章でエドレアの正体・動機を説明する際に使う手がかりは、すべて第5章までに（遅くとも第7章までに）プレイヤーが入手できていなければならない
- 各章の推理パート・章の引きで新しい手がかりを出したら、必ず `clue-ledger.md` に登録する
- 章を作るたびに、「仕込んだが回収していない伏線」「回収したが仕込んでいない設定」がないかをこの文書と `clue-ledger.md` で突き合わせる（QA・本格テストのミステリーのフェアさチェックでも確認する。roles.md 3-10）

# プレイ時間の予算表

`game-design.md` 2-3 の見積もりルールに基づき、章ごとの予定時間を集計し、メイン48時間以内に収まるかを確認する。見積もりルール:

- 会話文は1分あたり400字で読む想定
- 移動は、町1つ10〜20分、ダンジョン1つ30〜60分を基準に、地図の広さと敵との遭遇率から見積もる
- 戦闘は雑魚戦1回30〜45秒、ボス戦5〜10分
- レベル上げなどの寄り道時間を、メインの1割程度見込む

## 4. 合計と判定

- 本編合計: 約34.5〜38.5時間
- サブストーリー合計: 約8.75時間（S-029〜S-032「静滅教団」全4部追加後）
- **本編＋サブストーリー合計: 約43.25〜47.25時間**
- 目標（30〜40時間）は寄り道を含めるとやや超えるが、**48時間以内には収まる見込み**（`CLAUDE.md` の「48時間以内にクリアできる長さ」を満たす）。ただし上限までの余裕がかなり少なくなってきているため、以後サブストーリーを追加する際は本数・長さを見直す判断を優先的に検討する（新規追加より、既存の内容を削って埋め合わせる判断が必要になる可能性がある）
- クリア後の裏ボスコンテンツ（約1〜1.5時間）はメインの48時間の外枠として扱う（`game-design.md` 2-3の通り、裏ボスはクリア後コンテンツのため本編の時間予算に含めない）

## 5-補. 序章の実装状況（2026-09-28時点）

地図（町・支部内部・町外れ）とイベント（オープニング〜依頼受注〜歪みとの戦闘〜報告〜レト加入）、ボス「灯里の歪み」までを実装した（`docs/roadmap.md` 3-1〜3-3）。推理パート（3-4）・BGM（3-5）・効果音（3-6）はまだで、実測プレイ時間はそれらが揃ってから計測する。ここまでの内容だけでも会話・移動・戦闘一式が一通り遊べる状態で、見積もり（30〜40分）から大きく外れる兆候は今のところない。

## 5. 今後の調整方針

- フェーズ3（序章の実装）で実際の地図・イベントを作った時点で、見積もりと実際のプレイ時間のズレを確認し、この表を更新する
- 章の内容が増えた場合（`docs/roadmap.md` の各章の項目が完了するたび）、この表の該当章の内訳を更新する（roles.md 3-6）
- 合計が48時間を超えそうになった場合、サブストーリーの本数を減らすか、章の中身（特にダンジョンの広さ）を削る判断を優先する（本編の謎の骨格は削らない）
- 本格テスト（roles.md 3-10）で実際の通しプレイ時間を計測できるようになったら、その実測値をこの表に反映し、見積もりから実測ベースの管理に切り替える

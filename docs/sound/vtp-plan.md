# プロ仕様のボカロ曲（vtp）— 作り方の決まりと曲の表

2026-11-07 人間「プロ仕様のボカロ曲作ろうか。プロがどのように作っているか学んで来て」。調べたことを、この曲から使う決まりにする（合う曲だけに使う）。

## 調べたプロのやり方（出典は下）
- 作る順番: サビ（いちばん言いたいこと）から作る。コンセプトを一言で言える形にしてから打ちこむ。
- 構成: イントロは短く、早く歌を聞かせる（ストリーミングの時代の流れ）。0サビ（頭にサビの節）。2番のAメロは楽器を変えて変化。
  Cメロ → 落ちサビ → 最後のサビは調を上げる。パッドは「鳴っているかわからないくらい」に足すと響きが変わる。
- 調声: しゃくりは句の頭を 50〜100 セント下から 50〜100ms で。ビブラートは1拍以上の長い音の後半 1/3〜1/2 に深さ 20〜40 セント
  （Aメロ浅く・サビ深く）。強弱は歌い出し弱く・句の山で強く。句の間に息つぎ。言葉の頭を強く・前の音を短くして滑舌。
- ハモリ: サビに3度下（6度下も入れやすい）。ハモリは本線と別のビブラートにして、声が混ざらないように。
- ミックス: 声の帯域（2〜3kHz）をギター・シンセ側で 2〜3dB 下げる。歌のリバーブ 1〜2 秒・プリディレイ 20〜40ms。
  ディレイは 1/4 か付点8分を控えめに。仕上げは -11〜-14 LUFS（こちらの決まりは -13.5）。

## 01「白い息のリテイク」White Breath Retake（仮）
A長調・148（Aメロ1は半分のノリ）→ 最後のサビは +2（B長調）。4分16秒。台本 `assets-src/ai-songs/_gen/vtp_01_whitebreath.py`。

| Aメロ1 帰り道・白い息・告白の準備 | ハーフのドラム（ライド）・ピアノの分散和音（中弱） | 話すような低めの短い句 |

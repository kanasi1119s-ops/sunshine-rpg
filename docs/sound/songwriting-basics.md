# 曲づくりの基本（学びなおし・2026-11-17）

人間の指示「なんかプロっぽくならないね。曲作りの基本学んで来ようか。」を受けて、作曲・編曲・ミックスの基本を調べなおし、今の曲（16・17）を基本に照らして確かめた記録。
このあとの段階（曲を聴いて、楽器・コード・音の種類・ジャンルまでわかるようにする）は `docs/design/song-analyzer-plan.md` の 4 段階目に書く。

## 1. 基本（調べたこと。出どころは下）

### 旋律（メロディ）
| 基本 | 中身 |
|---|---|
| くり返す短い形 | 短くて覚えやすい音の形をくり返すと、耳に残る。同じ形をもとに、少しずつ変えて進める |
| なめらかな動きと跳ぶ動き | となりの音へ進む動きと、大きく跳ぶ動きを組み合わせて山と谷を作る |
| サビで音域を上げる | サビは Aメロより高い所で歌う（例に出てくる曲は 1 オクターブ以上高い）。いちばん高い音はサビのためにとっておく |
| 安定する音 | 主音・3度・5度がいちばん安定する。のばす音は和音に合う音に |
| 緊張とゆるみ | 聞き手の予想にこたえつつ、気持ちよく裏切る所を作る。なじみやすさと意外さのつり合い |
| 対比 | 音の高さの差・長調と短調・くり返しと変化・リズムの切りかえ・強弱で力を出す |
| 言葉の切れ目 | 行や段落の切れ目は、休みや長い音の近くに置く（日本語の歌の分析） |

### 編曲
| 基本 | 中身 |
|---|---|
| 役わりと音域を分ける | 楽器ごとに受け持つ音域を分け、役わりをはっきりさせる。主役のパートがうもれないように、音の間と広がりを調える |
| 場面ごとに変える | 場面ごとに楽器・強弱・手ざわりを変えて、聞き手の注意を保つ。鳴らしつづけた音を急に取りさる、などの対比で展開を作る |
| 土台 | ベース・キック・くり返す形などのはっきりした土台があると、歌が自由になる |
| 音色を替える | 音を変えなくても、楽器や音色を替えるだけで印象は大きく変わる |
| 小さく直す | 和音は大きく作り直すより、代わりの和音・積み方の入れかえなど小さな直しから |
| 戻ってくる | 遠くまで行ったあとで元の調や気分に戻ると、満足感が高まる |

### ミックス
| 基本 | 中身 |
|---|---|
| いちばん大事な音から | 音量は、いちばん大事な音（歌。歌がなければリード）を基準に、ほかを合わせる。キックから始めなくてよい |
| 先に EQ とコンプ、あとで左右 | 全部を真ん中に置いたまま、音のかぶり（マスキング）を EQ で整理してから左右にふる。モノラルでもくずれないか確かめる |
| 引く EQ から | まず削るほうの EQ だけで、大事な音の場所を空ける |
| 真ん中に芯 | キックとベースは真ん中に置いて、しっかりした芯にする。左右には同じくらいの量を置く |
| 響き | 速い曲で動きの多いパートに長い響きはかけない。前に出す楽器は短く少なく、うしろの音は広く |
| 低い所 | 低い所によけいな響きがあると全体がにごる。整理して輪郭を出す |
| お手本とくらべる | お手本の曲（仕上げ済みで大きい）は 6dB ほど下げてくらべる |

## 3. これから守ること（今日決めた分）

1. **サビのためにいちばん高い音をとっておく。** Aメロの最高音は、サビの最高音より 3 半音以上下にする。サビの高さの中央値は Aメロより 3 半音以上上にする。作ったら `tools/vt3/vocal_shape.py` などで場面ごとの高さを出して確かめる。
2. **主役の楽器は、そのパートの音量で主役にする。** 仕上げで全体を持ち上げて、あとで下げることはしない（`docs/sound/composer-preferences.md` の「必ず守る」表）。
3. **音量は歌（主役）から決める。** 主役を基準に、ほかのパートを数字で合わせる。

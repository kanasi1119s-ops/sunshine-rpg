# ドラムのジャンル別の作り方（パターン・音色・ミックス）（2026-10-11 調査）

ドラムを「どのパターンを、どんな音色・チューニング・ミックスで鳴らすか」をジャンルごとに調べ、うちの書き方（16マスのグリッド `g:`、`drumMix`、`--drums`、`swing`、`human`）に直した。

**決まり**: ここに書いた型は、ジャンルの一般的な基本形をうちの記法で組み直したもの。特定の曲のドラムを写していない（CLAUDE.md 1-1）。記事の文章は写さず、自分の言葉でまとめた。16マスの型は、出典が述べる「どの拍・どの裏にキック／スネアが来るか」を16分の位置に置き換えたもので、聴いて確かめたものではない（この環境では音源を聴けない）。

**重複を避けた先行文書**: フィルは `drum-fills.md`、基本のビート表と入り方は `drum-patterns.md`、パンクの2ビートは `punk-guide.md`、ミキシング一般は `mixing-guide.md`。この文書は「ジャンルごとの型と音づくりを一枚に束ねる」ことと、先行文書にない **音色・チューニング・drumMix の推奨値、swing の換算、ベロシティの目安、ジャンル別の変化形** を足す。

記法の復習（`ai-song.ts` の実装どおり）: `g:` のあと1文字＝16分音符。`x` ふつう（強さ1.0）／`X` 強く（1.3）／`o` 弱く＝ゴースト（0.5）／`O` オープンハイハット（1.25、hihat だけ）／`.` 休み。1小節＝16文字。タムは音名（`C4` 高い … `A2` 低い）。3連・32分は、拍つきの書き方（`x:0.333`、`x:0.125`）で書く。

---

## 1. 要点

1. **ジャンルを決めるのは「スネアの位置」「キックの置き方」「ハイハットの細かさ」の3つ**。ロックは2・4拍のスネア、レゲエは3拍目だけ、ハーフタイム系（トラップ・ダブステップ）も3拍目だけで、テンポの倍の遅さに聞こえる。ハウス・ディスコはキックが毎拍。ドラムンベースはキックが1拍目と3拍目の裏、スネアが2・4拍。
2. **同じ型でも、ハイハットの強弱とゴーストで別のジャンルになる**。8ビートの強弱は拍の頭が強く、16ビートでは裏のアクセントが効く。ファンク・R&B・ヒップホップは、スネアの合間の弱いゴースト（強さ30〜40%くらい）がノリの主役。
3. **ノリは「位置」が強さより大事**。16ビートのハイハットは、強くするより弱い拍を弱くする（速いほどその差を広げる）。キックの置き場所が、グルーヴを決定づける。
4. **スウィングは、キック・スネアを真っすぐにして、ハイハット（と打楽器）だけ揺らす**のが基本。うちの `swing` は曲全体にかかり、8分の裏を `swing/6` 拍、16分の裏を `swing/12` 拍遅らせる。MPC流のパーセントとの換算は §3.2。
5. **ジャズはテンポが速いほど、はね方が弱くなる**（研究では、速いテンポで8分の長短の比が1に近づき、遅いテンポで3.5近くまで広がる）。うちの swing は比が最大2（三連）までなので、遅いジャズは 0.8〜1.0、速いジャズは 0.3〜0.6。
6. **音色は「ジャンル × 部屋の鳴り」**: ロック・ハードロックは部屋を多めに、メタルは部屋を少なく近い音で硬く、ジャズは自然な部屋、ハウス・ドラムンベースは短く乾いて締まった音、バラードはスネアに短い残響。うちでは `--drums` の音源と `drumMix` の `reverb` で選ぶ。
7. **キックとベースは別の帯域を分け合う**: キック（60〜100Hz のドン＋3〜5kHz のカチッ）、ベース（80〜250Hz）。ベースの `duck`（0.2〜0.4）でキックの瞬間に凹ませる。808を使うときは、キックを短く、808を長くする。
8. **ハイハット・クラッシュの高域（6〜10kHz）は耳に痛い**。うちでは `drumMix.hat.level` と `crash.level` を下げて、`pan` で左右に逃がす。
9. **展開で変えるのは、まずハイハットの細かさとスネアの強さ**（Aメロ＝8分や半分の密度、サビ＝16分や開いたハイハット）。最後の1〜2拍にフィル、次の頭にクラッシュ。
10. **やりすぎ防止**: ゴーストは3つ以上続けない、速いテンポではバックビートの直前のゴーストを間引く、フィルは毎回入れない。

## 2. ジャンル別の表

### 2.1 パターン（1小節、グルーヴの基本形）

各行の「変化形」は、4小節ごとの繰り返しで1〜2小節だけ差し替えるもの。キックは小節ごとに型を回すと機械的に聞こえにくい。

### 2.2 音色・ミックス（同じ順番の表）

`drumMix` の `level` は倍率（0〜1.5）、`pan` は -1（左）〜1（右）、`reverb` は残響の送り（0〜1）、tom の `spread` は高いタム左・低いフロア右への広がり、`tune` は半音（-6〜6）。`--drums` は音源（`std` 標準／`muldjord` 生録音の素／`rock` 部屋多め・ふくよか／`metal` 近接・硬い・部屋少なめ／`jazz` ジャズ用の生ドラム／`jpop` スネアとキックが前に出る／`supra` 乾いた金属スネア・短い余韻）。数値は出発点で、聴いて動かす。

| ゲーム: フィールド | 控えめ、または無し | 空気感優先。ドラムは小さく、タムは低く柔らかく | `{"kick":{"level":0.7},"snare":{"level":0.6,"reverb":0.2},"hat":{"level":0.5}}` | std | 0 / 0.4 |
| ゲーム: 通常戦闘 | 8分／16分。前のめり | 太めでスネアが前に。残響短め | `{"kick":{"level":1.05},"snare":{"level":1.1,"reverb":0.15},"hat":{"level":0.85},"tom":{"spread":0.7,"tune":-3}}` | rock | 0 / 0.25 |
| ゲーム: ボス | 8分＋crash、サビで密に | 低いタム・太い太鼓を足す。部屋はやや大きく | `{"kick":{"level":1.2},"snare":{"level":1.1,"reverb":0.2},"tom":{"spread":0.8,"tune":-4},"crash":{"level":1.0,"reverb":0.25}}` | metal か rock | 0 / 0.2 |

### 2.3 型の細部（グリッドで書けるもの・書きにくいもの）

**メタルの細かい型**（4/4、各行1小節）
| 型 | kick | snare | 上物（hihat か crash） | 意味 |
|---|---|---|---|---|
| ギャロップ（8分＋16分2つ） | `g:X.xxX.xxX.xxX.xx` | `g:....X.......X...` | `g:x.x.x.x.x.x.x.x.` | 馬の走り。ツーバスの16分より軽く、走って聞こえる |
| ツーバス16分 | `g:XxXxXxXxXxXxXxXx` | `g:....X.......X...` | `g:x.x.x.x.x.x.x.x.` | ベースも根音を16分でそろえる |
| ブラスト（交互） | `g:x...x...x...x...` | `g:..x...x...x...x.` | `g:x.x.x.x.x.x.x.x.` | キックとスネアが交互に、シンバルはキックと一緒（伝統的）。速いほど8分単位 |
| ブラスト（ハンマー） | `g:x.x.x.x.x.x.x.x.` | `g:x.x.x.x.x.x.x.x.` | `g:x.x.x.x.x.x.x.x.` | キックとスネアが同時に8分。片手と足で足りるので速くできる |
| ブラスト（ボム） | `g:xxxxxxxxxxxxxxxx` | `g:x.x.x.x.x.x.x.x.` | （crash を拍頭に） | キックは16分、スネアは8分 |
| ブレイクダウン（ハーフ） | `g:X.......X.x...x.` | `g:........X.......` | crash を拍頭 | ハーフタイム＋重いキック |

ブラストは速い（180〜250 bpm が目安）ので、書いた型が詰まって聞こえるときは、**テンポを下げるか、キックを抜いて8分にする**。長く続けない（4〜8小節）。

**トラップのハイハットのロール**（16マスでは書けない。拍つきで書く）
- 1拍だけ三連のロール: `x:0.5 x:0.5 x:0.5 x:0.5 x:0.5 x:0.5 x:0.333 x:0.333 x:0.334`（合計4拍）
- 小節末に32分のロール: `x:0.5 x:0.5 x:0.5 x:0.5 x:0.5 x:0.5 x:0.5 x:0.125 x:0.125 x:0.125 x:0.125`（合計4拍）
- 強弱をつける: ロールの途中の音を `,`（弱く）にして（`x:0.125,`）、最後の1発を `!`（強く）にする。
- ロールは「スネアの直前」か「小節の終わり」に置く。多すぎると耳に残らない。

**ドラムンベースの要点**: 2ステップ＝キック1拍目と3拍目の裏、スネア2・4拍。ここから「2つ目のキックを動かす」「スネアを2拍目だけにして、もう1発を裏へずらす」「スネアを3拍目だけ（ハーフタイム）」と変える。ゴーストをスネアの合間に混ぜると、ブレイク（アーメン）ふうに聞こえる。

**ジャズの要点**: ライドの基本形（`g:x...x.x.x...x.x.`＝1拍目・2拍目・2拍の裏・3拍目・4拍目・4拍の裏）。スウィングでその裏が三連の最後に寄る。ペダルのハイハットは2・4拍（別パートにできないので、`hihat` の `X` で近似）。キックはごく弱く（フェザリング）、ときどき `X`。スネアは**コンピング**（合いの手）で、ゴースト `o` と、まれなアクセント `x`。速いテンポではライドを4分音符だけにして、ゴーストはバックビートの直前を避ける。

## 3. グルーヴの作り方

### 3.1 ベロシティ（強さ）の目安
うちの `o`＝0.5、`x`＝1.0、`X`＝1.3。出典の数値（MIDIの強さ）を、おおよそ同じ比にすると次のとおり。

| 役割 | 強さ（MIDI目安） | うちの記号 | 書き方 |
|---|---|---|---|
| ゴースト | 30〜40%（出典の例で 79/127=約60% のものも。音源によって違う） | `o` | スネアの16分の裏、バックビートの直前は避ける |
| 弱い拍（ハイハットの裏・16分） | 60〜75% | `o` か `x` | 表より弱く |
| ふつう | 80〜90 | `x` | |
| バックビート・アクセント | 100〜110 | `X` | 2・4拍のスネアはゴーストより必ず強く |
| 山（crash・フィル最後） | 115以上 | `X` | 次の頭に1発 |

- ハイハットは「強弱が交互」: 16分なら `XoxoXoxo`、8分なら `X.x.X.x.`。**同じ小節のコピーを避け**、2〜4小節ごとに型を変える（ずらす・1個だけ `O` にする）。
- キックとスネアの強弱はハイハットより変えない。キックは一定に、スネアのバックビートは強く。
- ハイハットの音と、スネア・クラッシュ・ライドが**同時に鳴りすぎない**（機械っぽさの手がかり）。クラッシュの拍は、ハイハットを休む。
- 4〜8小節かけて徐々に強さを上げると、サビ前のビルドになる（フィル `g:xxxxXXXX`）。

### 3.2 スウィングの換算（うちの swing と MPC風パーセント）
うちの `swing` は 0〜1 で、`swing=1` で8分の裏が三連の位置（比 2:1、MPC の約66.7%）に来る。換算の式は `swing ≒ (パーセント - 50) ÷ 16.7`。

| 感じ | MPC風パーセント | うちの swing | 比（長:短） |
|---|---|---|---|
| ほぼまっすぐ（ロック・ダンス） | 50 | 0 | 1.0 |
| わずかなグルーヴ（モダンなヒップホップ・R&B） | 54 | 0.25 | 1.17 |
| 定番のブーンバップ（古典的なMPCの感じ） | 58 | 0.5 | 1.4 |
| ハウスの「はねる」・ファンクのシャッフル寄り | 60〜62 | 0.6〜0.75 | 1.5〜1.7 |
| 三連・ブルースのシャッフル | 66.7 | 1.0 | 2.0 |

- **うちの swing は8分の裏を `swing/6`、16分の裏を `swing/12` 拍遅らせる**。MPC は16分の偶数番目だけを揺らし、8分は動かさないので、完全には同じにならない。ヒップホップ・ハウスの16分ハイハットは、近似として 0.25〜0.5 から始める。
- ジャズ: **遅いほど三連に近い**。研究（ライドの測定）では、速いテンポで比が1に近づき、遅いテンポで3.5近くまで広がる。うちは最大2なので、60〜120bpm=0.8〜1.0、140〜180bpm=0.5〜0.7、200以上=0.3〜0.5（またはライドを4分音符だけ）。
- キックとスネアは**まっすぐに**、ハイハットだけ揺らすのが理想だが、swing は曲全体にかかる。ほぼ揺らさない曲（ロック・メタル・ダンス・パンク）は 0 にして、ノリは `push` と強弱で作る。

### 3.3 ゴーストノート
- ゴーストは**バックビートの間の、16分の裏**に置く。スネアが2・4拍で `X`、その前後の裏拍に `o`。
- **3つ以上続けない**。最後の16分に1つ置くと、次のフレーズへの「跳ね」になる。
- 速いテンポでは、バックビートの直前のゴーストを削る（腕を上げる時間が要る）。
- キックと同じ瞬間のゴーストは削る（キックに埋もれる）。
- 連打ではなく、2〜3個の弱い連続（バズ）にすると、ロールのように聞こえる。
- 音色に変化がほしいときは、ゴーストにメインのスネアの別の小さな音（クロススティック）を使う。うちでは同じスネア音の弱いもの（`o`）が使える。

### 3.4 タイミング（push・human）
- スネアを遅く（`push` +0.02〜0.04 拍）＝重い・ゆったり。ヒップホップ・ネオソウルは、スネアを5〜15ms ほど遅らせるのが定番（bpm 90 で約 0.01〜0.02 拍）。
- ハイハットを少し早く（-0.01〜-0.02）＝軽く急かす。ゲームの戦闘のように「追い立てる」場面は、ドラム全体を少し前へ。やりすぎは変に聞こえる。
- キックは動かさない（土台）。
- 打ち込みらしさを消すときは、**ハイハット・打楽器を最も崩し、スネアを少し、キックを最小限に**。`human` は 0.3〜0.6 が自然。メタル・ダンス・トラップは 0〜0.2 でよい（機械の正確さも音楽の一部）。

## 4. 展開ごとの変え方

| 場面 | ハイハット | キック | スネア | その他 |
|---|---|---|---|---|
| イントロ | 4分か休み | 入れない／1拍目だけ | 入れない | 入りのおかず（`drum-patterns.md`） |
| Aメロ | 半分の密度（4分か弱い8分） | 土台だけ（1・3拍） | バックビート＋小さなゴースト | ハーフタイムにして余白を作ってもよい |
| Bメロ | 8分、だんだん強く | 少し増やす | `x`→`X`、ゴーストを足す | 4小節目にフィル（小〜中） |
| サビ | 16分や開いたハイハット、crash | シンコペを足す | `X` の強いバックビート | 頭に crash、キックを太く |
| 間奏 | ジャンルに合わせて型を変える（例: ボサノバ風、4つ打ち） | 別の型 | 別の型 | 楽器を抜いてもよい |
| ブリッジ | 弱く／休み | 休むかハーフ | ハーフタイム | 直前にブレイク（全部止める）、最後のフィルで戻す |
| 最後のサビ | 最も密、crash 多め | 最大 | 最大 | タムの足し、フィルを大きく |
| アウトロ | だんだん引く | 引く | 引く | 最後に crash 1発、または止めて余韻 |

- **ビルドアップ**: スネアを8分→16分→32分（拍つき）と密にし、強さも上げる。頂点の直前に1拍休む。
- **ドロップ（ブレイク）**: 8小節の終わりで kick と bass を同時に抜き、次の頭で全部を戻す（EDM・ヒップホップ・ロックのサビ前）。
- **ゲームのボス**: 長い戦いは遅く威圧的に始めて速くする／短い戦いは最初から速い。フェーズごとにテンポ上げ・楽器追加・調の変更で強度を上げる。ドラムを少し前のめり（-0.01〜-0.02 拍）にして「追われている」感じを出す。ただしやりすぎると崩れて聞こえる。
- **場面で型を変える例**（ボカロ風・J-POP）: Aメロ 16ビート → Bメロ 静かな4つ打ち → サビ 4つ打ち＋裏ハイハット → 間奏 ボサノバ風（`drum-patterns.md` の見本）。

## 5. ミックスの要点

### 5.1 帯域（ドラムごとの山と谷）

| 太鼓 | 切る・整える | 持ち上げる | メモ |
|---|---|---|---|
| キック | 25〜60Hz 以下を HPF（キックの基音に合わせる）。200〜500Hz の「ボックス」を狭く削る | 50〜80Hz（ドン）、1〜5kHz（カチッ）、60Hz・150Hz・350Hz の使い分け | ロックはカチッ強め、808は60Hz の低音、ヒップホップの古い感じは350Hz のふくらみを残す |
| スネア | 80〜200Hz 以下を HPF、250〜500Hz のこもり、500〜1.5kHz の鳴りすぎを狭く削る | 150〜250Hz（太さ）、2〜5kHz（パシッ）、8〜12kHz（空気、控えめに） | ジャンルで高さが違う（§2.2 の tune） |
| ハイハット | 300〜500Hz 以下を HPF | 12kHz 付近の空気（こもるとき）／開いた音の 5〜7kHz のうなりを抑える | 左右に 20〜40% 振る。音量はキック基準 -10〜-14dB |
| タム | 低域の濁りを削る、高域を少し丸める | 中域のアタック | 高→低で左→右（`spread`） |
| クラッシュ・ライド | HPF、6〜10kHz の耳に痛い帯域を抑える | 10〜15kHz の空気 | 強い一発だけ高域が暴れる。`level` を下げる／`pan` で逃がす |
| 部屋（ルーム） | | | ロック・ハードロックは多め、メタル・ドラムンベースは少なめ |

### 5.2 サイドチェイン・低音の分け合い
- ベースのパート設定 `duck`（0.2〜0.4）で、キックの瞬間にベース（と pad）を凹ませる。出典の目安は、ベースが数dB凹む程度、アタック速く・リリース速く。808を使うときは、808を `duck` で凹ませ、キックを短く。
- 808の長さ: 短い（50〜200ms）は「キックの補強」、長い（0.5〜2秒）は「ベースライン」。曲のキー（根音）に合わせる。小さなスピーカーで消えないように、倍音を足す（`bright` を上げる、歪みを少し）。
- 帯域の分担: キック＝60〜100Hz のドン／ベース＝80〜250Hz。同じ帯域に両方を重ねない。
- ダブステップのサブは、サイン波にして、キックと軽くサイドチェイン。

### 5.3 リバーブと圧縮
- **スネアの残響**: ポップ・ロックは短いプレート（0.1〜0.3）、トラップ・ヒップホップは短いプレートで薄く（0.12〜0.2）、ジャズは自然な部屋（0.1）、パンクは 0.15。キックにはかけない（輪郭が濁る）。80年代ふうの大きなスネアは、短いゲートつきリバーブ（0.2秒）で聞こえる（うちにゲートは無いので、`reverb` を 0.3 にして、ほかの音と重ならないようにするのが近似）。
- **ドラムバス**: 2:1・アタック 3ms・ゲインリダクション 1〜2dB で接着（グルー）。パンチを残すならアタック 10ms。強い攻撃にするなら 4:1。**並列圧縮**（強く潰した複製を薄く足す）は、厚みを足す手段。うちでは近似として、kick と snare の `level` を 1.1〜1.2 にして、hat・crash を下げる。
- **メタル**: スネア 6〜10dB の強い圧縮、キックとスネアにサンプルを重ねて粒をそろえる。シンバルはダイナミックEQで 8kHz 付近の耳障りな音だけ、強く叩かれたときに抑える。
- **ポップパンク**: キックは高域のカチッを持ち上げ、強めに圧縮。ルームを混ぜてシンバルを大きく。スネアのゲートは、完全に閉じず少し余韻を残す。
- ドラム全体の音量は、ベースとキックのぶつかりを避けるため、先にキックとスネア→ベース→ハイハットの順に合わせる。

## 6. チェックリスト

ドラムを書いたら確認する。
- [ ] 各行の `g:` が **16文字**か（3拍子なら12文字）
- [ ] ジャンルに合うスネアの位置か（ロック＝2・4拍／ハーフ＝3拍目／レゲエ＝3拍目／ハウス＝2・4拍クラップ／DnB＝2・4拍）
- [ ] 同じ小節のコピーが4小節以上続いていないか（キックかハイハットの型を回す）
- [ ] ハイハットに強弱があるか（全部 `x` のベタ打ちでないか）
- [ ] バックビートのスネアが、ゴースト（`o`）より必ず強いか
- [ ] ゴーストが3つ以上続いていないか、キックと同時になっていないか
- [ ] 4・8小節の終わりにフィルか休み、次の頭に crash があるか（毎回は入れない）
- [ ] サビでAメロより密か強いか（強度の地図がある）
- [ ] `swing` はジャンルに合うか（ロック・メタル・ダンス 0、ジャズ 0.5〜1.0、ヒップホップ 0.3〜0.5）
- [ ] 音源 `--drums` はジャンルに合うか（§2.2）
- [ ] `drumMix` で hat と crash が耳に痛くないか（`level`・`pan`）
- [ ] kick と bass が同じ帯域でぶつかっていないか（`duck`）
- [ ] 速い曲で snare の `reverb` を上げすぎて濁っていないか
- [ ] `human` はジャンルに合うか（メタル・EDM・トラップは低く）

## 7. 取り入れる提案（実装できる単位）

1. **ジャンル別 drumMix プリセット**: §2.2 の `drumMix` と `--drums` を、サウンドセット（`sound-sets.ts` の `SOUND_SETS`）に追加する。`punk-run`、`clear-guitar-rock` に続けて `rock-band`、`metal`、`jpop-anime`、`ballad`、`jazz-swing`、`funk-tight`、`hiphop-boombap`、`trap`、`house`、`dnb`、`reggae`、`bossa`、`game-battle`、`game-boss` を作る。各セットの `drumPatterns` に §2.1 の型を入れる。
2. **自動ドラム（newsong.ts）のジャンル追加**: 今はロック系と `danceSong` の2系統。`feel` に `hiphop`・`trap`・`dnb`・`halftime`・`reggae`・`bossa`・`disco` を足し、§2.1 の kick/snare/hihat を `kickPos`/`snarePos` に与える。特に 4小節ごとに kick の型を回す仕組み（`KICK_A`/`KICK_B` を A〜D に増やす）。
3. **ハイハットの型の自動生成**: `hihatPattern(genre, barIndex, section)` を作り、§3.1 の強弱（`XoxoXoxo` の回転、`O` を1小節に最大1つ）と、サビで密になるルールで返す。同じ小節の繰り返しを避ける。
4. **スウィング換算のヘルパ**: `swingFromPercent(pct)`（= `(pct-50)/16.7`）と、ジャズのテンポ別 `jazzSwingForBpm(bpm)`（60〜120=0.8〜1.0、140〜180=0.5〜0.7、200以上=0.3〜0.5）。AIソングの案内文（`guide`）にも、この表を載せる。
5. **ブラスト・ギャロップ・ハーフのヘルパ**: メタル用の `blastPattern(type)`（交互・ハンマー・ボム）、`gallop()`、`breakdownHalftime()`。速いテンポで16分が詰まったときに自動で8分に落とす。
6. **トラップのハイハットのロール生成**: 拍つき表記で `x:0.333 x:0.333 x:0.334`、`x:0.125 ...` を、小節末・スネア直前に自動で挿入する（`rolls: true`）。強弱は中の音を弱く、最後を強く。
7. **ゴースト自動配置**: スネアのバックビートの前後の16分の裏に、`ghostDensity`（0〜1）に応じて `o` を置く。バックビートの直前（速いテンポ）とキックと同時の位置は除く。3つ以上続けない。
8. **ジャンル別のドラム・検査**: `tools/audio-check` に「スネアがバックビート以外に出ていないか」「全部 `x` のベタ打ちでないか」「同じ小節が N 回続いていないか」「g: の文字数」をチェックする `check-drums` を追加する。
9. **ボス曲のフェーズ表**: 戦闘曲の `sections` に、フェーズごとのテンポ上げ・ドラム型・楽器追加を書ける簡易テンプレートを `game-boss` プリセットに付ける。
10. **`--drums` の選び方の自動推奨**: `genre` を指定すると、§2.2 の `--drums` を提案する（`song.mjs build --genre trap` → `--drums jpop`）。

## 8. うちの書き方で書けないこと・注意

- **3連のスウィングを含む12/8**: `swing=1.0` の8ビートで近似。`beats: 6` の6/8とは別物。
- **クロススティック・ブラシ・ライドの音そのもの**: ドラムのパートは kick・snare・hihat・tom・crash だけ。スネアを弱く高く（`drumMix.snare.level/tune`）、ハイハットをライド代わりにして近似する。`--drums jazz` はジャズ用の生ドラムなので、ここだけは近い。
- **ゲート付きリバーブ・並列圧縮**: 実装されていない。`reverb` と `level` で近似。
- **swing は曲全体**: ドラムだけを揺らしてメロディをまっすぐにはできない（ベースやギターも揺れる）。ほぼ揺らさない曲は 0。
- **ブラストの本物の速さ**: 16分グリッドで 200bpm 以上だと、1小節の中で細かすぎて濁る。8分に落とす。
- **drumMix の level の上限**: 実装は 1.5 まで（以前のメモ `punk-guide.md` §7 には 1.05 上限とあった。新しい実装に合わせて確認する）。
- この調査は文章資料が中心で、実際の録音を聴いて採譜していない。数値は出発点で、聴いて動かす。

**ブラスト・ギャロップ・トラップのロールの書き方の確認**: ブラスト3種・ギャロップ・ツーバス・ブレイクダウンの格子は、どれも16文字で、`g:` のまま AIソングのドラムのパートとして読める。トラップのロール（三連・32分）は、拍つき表記が読め、1小節4拍に収まり、最後の1発が中の音より強い（テストで確認）。1小節の型は曲の長さまでくり返される。案内文（`AI_INSTRUCTIONS`）に、この書き方の参照先を追記した。

**入れなかったことの補足**: 耳での確認はこの環境ではできない（数値の出発点のまま）。書き出して `realism.py` で測ったのは jazz（タイミングのずれ 20.9ms・強弱の幅 0.4dB）と metal（8.0ms・1.0dB）。強弱の幅が小さいのは、自動伴奏そのものの特徴（`dynamics`・`sections` で起伏をつける前）。

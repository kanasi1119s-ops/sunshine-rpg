# 主題台帳（案・人間の確認待ち）

**状態: 案です（2026-10-02）。** 伏線台帳（`docs/story/clue-ledger.md`）の音楽版です。旋律そのものはまだ作っていません（作曲家役が、企画書と構成表を受けて作ります）。**旋律は完全オリジナルで、既存作品に似せない**（`CLAUDE.md` 1-1）。主題は3系統に絞ります（`music-bible.md`）。

## 書式
| 主題ID | 系統 | 骨格（変えない音程とリズムの特徴） | 意味 | 初登場（曲ID・章） | 変奏の記録（曲ID／技法／意味） | 伏線台帳との対応 | 状態 |
|---|---|---|---|---|---|---|---|

- **骨格**: 音程の並び（Parsons code と音程列）と、リズムの特徴。3〜7音。旋律の最初の3音は変奏でも残す。
- **変奏の技法**: 旋法変更・テンポ・リズム・編成・和声・断片化・拡大・縮小・反行・逆行・移調（`roles/composition-writer.md`）。1回に1〜2要素。
- **状態**: 予定／骨格決定／初登場済／変奏済／回収済（その主題の最終形が鳴った）。

## 音による伏線の置き方（案）
- 敵や真相の主題（M-03）の**断片**を、早い章で低音・小さな音量で**1回だけ**入れる。真相の章で完全な形で鳴らす。
- 置いた場所は、曲ID・小節・音量・どの伏線に当たるかを台帳に記録し、`clue-ledger.md` にも「音の伏線」として追記する（後から矛盾が出ないように。`CLAUDE.md` 1-7）。
- **未決**: M-01〜M-03 の骨格（旋律）は、プロンプトの確認後に作曲家役が作る。

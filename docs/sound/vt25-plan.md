## 決めた理由
- 始まり方は、続く2曲で同じにならないようにした（雑音が消える／ピアノ前奏／炭酸の泡／いきなりリフ／ドラムだけ／短いサビ／アルペジオ／アコギ1回／エンジン音とベース／手拍子／前の曲のフェード／雨とピアノ／ビー玉の音／カウント／808の一撃／アコギのアルペジオ／ドラムンベースのブレイク／時計／通知音／シャッフルのリフ／指パッチン／ピチカート／ウインカー／ナイロンと鈴／アカペラ）。
- どの2曲も「形」「場面と強さ」「旋律の性格」のうち2列以上が違う。前回の25曲とも物語・曲名が重ならない。
- 人間が見せてくれた無料のエフェクト5つ（サチュレーター・OTT・ボーカルダブラー・ワイダー・テープストップ）は、Windows と Mac 用でこちらでは直接動かせないので、同じ働きのものを作曲ソフトの仕上げに作って、曲に合うものだけに使う（02・25 ダブラー／04 テープストップ／15・17 多バンドの圧縮／20 サチュレーター／01・16 ワイダー）。全曲に一律には入れない。

## 作るときに表から変えた所（19〜25）
- 19: 表のとおり（トラップポップ・G#m 72）。通知の音が1小節に8つ → 最後は0に減っていく。
- 20: 物語を「となりの席のセンパイの『まあいいか』を受けつぐ」に。3連のシャッフルは、まっすぐ書いて3連の長さに直す（`swing()`）。ストップタイムを足した。
- 21: 表のとおり（R&B・E♭ 94 → 最後のサビは E）。ポストサビ（「シュガーレス」の合いことば）と歌なしのダンスブレイクを足した。
- 22: 物語を「けんかのあとの『ごめんね』と、晴れのちハレルヤ」に（12 天気雨とは別の、天気予報の話）。転調は B → C → D♭ の2回。
- 23: 表のとおり（夜行バス）。サックスのソロを足した。最後のサビと終わりは C 長調の明るい和音。
- 24: 物語を「日曜の午後、ねこじゃらしで猫と遊ぶ」に。ロンドの形（主題が4回帰ってくる）。
- 25: テンポは 93（サビは 8ビートで倍に感じる）にした。前回の25（ボカロロック×オーケストラ・高速）と同じにならないように、アカペラで始まるアンセムに。

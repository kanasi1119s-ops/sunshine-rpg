# ギターロックバンド（邦ロック）の音の作り方（2026-10-11 調査）

「アルペジオが走り、歌うようなメロディを、バンドの音が押し上げていく」タイプのギターロックを、うちの道具（曲JSON）で作るための手引き。BUMP OF CHICKEN の音作りについての公開記事を読み、**曲そのものではなく、作り方の考え方**だけを取り出した。特定の曲のメロディ・コード進行・フレーズは写さない（CLAUDE.md 1-1）。見本曲は完全なオリジナル。

調べた先: [ぴあ音楽「“バンプらしさ”の源泉とは？」（黒田隆憲氏の分析）](https://lp.p.pia.jp/article/news/8696/index.html)、[「BUMP OF CHICKENの曲」になる条件（kyataken）](https://ameblo.jp/kyataken/entry-12327823320.html)、[ER-MUSIC コード進行と分析](https://er-music.jp/2569/)、[風サウンドの作り方＋機材（guitarkizaihikaku）](https://guitarkizaihikaku.com/bumpofchicken-fuziwara-amp-effector-setting/)、[使用ギター・エフェクター（guitareffector）](https://guitareffector.com/bumpofchicken/)、[使用機材（m-u-t-e）](https://m-u-t-e.com/archives/8165)、[増川弘明の歩み（lsecret-gardenl）](https://lsecret-gardenl.com/%E5%A2%97%E5%B7%9D%E5%BC%98%E6%98%8E+vol.2+)、[mFound インタビュー](https://mfound.jp/interview/bump-of-chicken2.html)。数値や機材の記事には「〜と言われている」という伝聞が含まれる。**耳で確かめて決める**。

## 1. 調べて分かったこと（一般化したもの）
### 和声（コード）
- **分数コード（オンコード）を多用する**。上のコードを変えずに、ベースだけ動かして響きを変える。
- **クリシェ**: ベースが半音・全音でゆっくり下がったり上がったりしながら、上のコードは同じ、または少しだけ変わる。
- **ペダルノート**: ギターのアルペジオを**同じ形で弾き続け**、ベースだけが動く。「固定した上、動く下」で、同じ手元なのに景色が変わる。
- **終止を焦らす**: 解決の直前に sus4 を挟む（Bsus4 → B のように）。パッシングディミニッシュで次のコードへ滑らかにつなぐ。
- **借用和音**: 同主短調から IVm・Vm を借りて、明るい長調に影を差す。VII♭ など調から外れるコードをブルージーに混ぜる。
- **ツーファイブ・代理コード**でクラシカルな響き。ループ型の進行（IV V iii vi のような繰り返し）を土台にすることも。
- **7th・maj7・テンション**で、三和音より柔らかく陰りのある響きに。
- **イントロで調をぼかし、ベースの音で調を確定**させる焦らし。
- 録音はほぼ**半音下げチューニング**（オープンコードの響きが太くなる）。うちの道具では、**Eb や Ab などフラット系の調**で書くと近い雰囲気になる（実際に半音下げるわけではない）。

### メロディ
- **同じ音を繰り返してから、急に動く**（抑揚の変化）。9th（コードの2度上）を使う。
- **シンコペーション**（つんのめるような、拍の裏からの入り）。
- サビは**ファルセットが映える高い音域**へ上がる。サビの後半は**下行して主和音へ終止**（緊張 → 解放）。
- Aメロは**音数を減らし、4分音符と休符を増やして**落ち着かせる。Bメロは**1小節1コード**で溜めて、サビへ。
- A・B・サビに分けず、**16小節で1つのまとまり**のメロディをくり返す作り方もある。

### アレンジ・バンド
- **同じ進行のくり返しに、リズムとメロディの変化で彩りを足す**（進行を変えずに景色を変える）。
- **曲（メロディ）が主役**。ギターは歌と重ならないよう配置する。
- **ギターの役割分担**: コード/アルペジオを弾く人と、リフ・ソロを弾く人。アコースティックをバンドの音に混ぜる。
- **ベースは1オクターブ程度の範囲で動き**、ドラムと噛み合う。控えめなリフ。ハンマリング・スライドのニュアンスを大切に。
- **シンセパッドは土台として敷く**。空間を埋めるためではなく、トップノートを派手に動かさない。
- **サビ頭の飾り**: グロッケン・チューブラーベル・マンドリン・オートハープ・ティンパニなどを足すと、「シングルらしさ」が出る。
- 低い**リバースピアノ**（C1〜C2あたりに、根音の3度下・5度下を重ねる）で、響きを濁らせ重くする使い方。
- 長い音のギター（E-Bow）を2〜3本、低・中・高に役割分担して重ねる使い方。
- ドラムは曲の場面に合わせた表現（「勇ましく、行進するように」）。テンポはミドルでも、**ダイナミクスで大きく聞かせる**。

### ギターの音色
- 近年は**クリーンが増え、歪みが減った**。**ギターとアンプで音を作り、エフェクターは少なめ**。
- アンプは中域をやや強調し、低域と高域は絞りすぎない。ピックアップは主にセンター。**テレキャスやストラトは高域が「キンキン」しやすいので、ギター側のトーンを絞る**。
- ディレイは2系統を使い分けて、**リズムに躍動感**を出す。リバーブは広がりを出す。
- EQは比較的フラットで、**高域を少し足し、中域を厚く**。ミックスでは**ギターが他の楽器と重ならないように配置**。

## 2. うちの道具での書き方
| 学んだこと | 書き方（曲JSON） |
|---|---|
| ペダルアルペジオ（上は固定、ベースだけ動く） | アルペジオ（`guitar`）は同じ4音を同じ順で数小節くり返す。ベース（`bass`）だけ、根音を半音・全音で下げる（例 Eb2 → D2 → C2 → Bb1）。`chords` には表示用に Eb → Ebmaj7 → Cm7 → Bb と書く |
| 分数コード | ベースのパートの音を、コードの根音以外（3度・5度）にする。例 Eb の上で G1 |
| sus4で焦らす | その小節のアルペジオに3度のかわりに4度（Bbsus4 なら Eb）を入れ、次の小節で3度に戻す |
| 借用和音（IVm） | Ab → Abm のように3度を半音下げる。アルペジオの3度の音を1つ下げるだけ |
| パッシングディミニッシュ | Bdim（ディミニッシュ。B D F）を1小節挟む（音は Bdim7 の気持ちで、ベースを B1 に）。ベースは B1 |
| 同じ進行にリズムで変化 | 2周目はアルペジオの型を変える／ドラムの型を変える／ベースを8分に／メロディを入れ替える |
| 半音下げチューニング | Eb・Ab・Db などのフラット系の調で書く |
| アコースティックを混ぜる | アルペジオの1本を `patch: "nylonGuitar"`（ナイロン弦）に。`chorus` 0、`reverb` 少なめ。**`steelGuitar`・`mutedGuitar` はゲーム用の音源に入っておらず、ピアノの音になる**（2026-10-11 に判明） |
| ディレイ（2系統）で躍動感 | `echoGuitar`（エコー付きギター）を高い音の飾りに使う。短い音を少なく置いて、エコーに歌わせる |
| サビ頭の飾り（グロッケン・ハープ） | `bell`（鐘）をサビの頭に1音、`harp` を頭の2拍だけ上昇アルペジオ |
| パッドは土台。トップノートを動かさない | `strings` の長い音を、小節をまたいで共通音（Eb の曲なら Bb や G）で保つ |
| ベースは1オクターブの範囲 | 根音と、その1オクターブ上、5度だけで動く。`bright` .2、`volume` .2前後、`duck` .2 |
| テレキャス対策（キンキンする） | ギターは `amp: clean`、`chorus` 0、`reverb` .1〜.2。**自動のしゃくり（autoScoop）を止める**。メロディを高くしすぎない（E4〜E5中心） |
| ギターが重ならない | アルペジオ2本は左右（-.5 / +.55）に、音域をずらす。サビでは低い刻みを減らして濁りを避ける（`guitar-arpeggio-rock` の経験） |

## 3. 見本曲
`assets-src/ai-songs/band-pedal-arpeggio.json`（「灯りのかたち」・見本・仮・完全オリジナル）。Eb長調・bpm148。次の工夫を入れた。
- イントロと前半のAメロは**ペダルアルペジオ**（ギターは同じ形、ベースが Eb → D → C → Bb と下がる）。
- Bメロは**1小節1コード**で、IVm（Abm）と Bsus4 で解決を焦らし、Bdim7 を経由してサビへ。
- サビ頭に `bell` と `harp`。サビの後半は下行して Bb（属和音）で次へ。
- アコースティック（スチール弦）とエレキ（エコー付き）の2本のアルペジオ。
- 場面の終わりのおかずは、おかず集（`drum-fills.md`）から場面ごとに別の型を選ぶ。

## 4. まだ足りないこと
- **スラッシュコードの記法**（Eb/G）を `chords` 欄で直接書けない。ベースの音で表している。
- **半音下げチューニング・カポ**の機能はない（フラット系の調で代用）。
- ギター側の**トーン操作・ピックアップ切り替え**の違いは出せない（`bright` で近似）。
- ディレイの**2系統の設定**（付点8分など）はできない。`echoGuitar` の固定のエコーのみ。
- **リバースピアノ**（逆再生）は作れない。低いピアノの重ねで代用。

## 5. 生ギターの音源（2026-10-11 追加）
作曲ソフトに「ギター音源」の選択欄を足した。Karoryfer Samples「Black And Green Guitars」（CC0）の生ギターで、ジャズギター（26）とクリーンギター（27）の音を入れかえる。
- `gretsch`（明るいクリーン）／`hofner`（丸い音）。書き出しは `node tools/composer/song.mjs build 曲.json --wav --guitar gretsch`。
- 作り直し: `node --experimental-strip-types tools/soundfont/build-guitar.mjs`（録音の置き場は環境変数 `BGG`）。
- 録音は小さめ（元の音量が控えめ）なので、標準の音源より中域が薄くなる。
- アンプシミュレーター（NAM）は、ライセンスが明確な無料のクリーン／クランチのモデルが見つからなかった（`docs/assets-credits.md` の「使わないと決めた素材」）。

- ドラム：`drumMix` の各太鼓に `tune`（半音単位 -6〜6）を足した。タムを低くしたいときは `"tom":{"tune":-3}`。クラッシュの余韻は、スープラのドラム音源で約2.0秒→約4.5秒に伸ばした（`crashSec`）。
- 生ギターのコーラスの送り（元の入れものにある25%）とフィルターの共鳴は、電子的に聞こえる原因になるため打ち消した。
- 人間の指示（2026-10-11）：エレキギターは、音の終わりに何度もビブラート（`~`）を付けて無理に鳴りを作らない。`sustain` で伸ばすのもやめ、録音そのままの自然な減り方で聴かせる。

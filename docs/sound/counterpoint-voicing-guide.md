## 1. 要点（まず読む16行）
1. **対位法＝独立した2本以上の線が、同時に鳴って和音としても成り立つこと。** 縦（和音）と横（線の流れ）を同時に見る。
2. **独立の3要素は「動く向き」「リズム」「山の位置」。** 向きが反対（反行）、リズムが違う、頂点がずれている、の3つが多いほど別々の線に聞こえる。
3. **動きの種類は4つ**: 反行（逆向き）／並行（同じ向き・同じ幅）／類似（同じ向き・幅が違う）／斜行（片方が止まる）。反行と斜行が主役、並行は3度・6度だけ長く続けてよい。
4. **協和は完全（1・5・8度）と不完全（3・6度）。** 古典の2声では4度は不協和扱い。2声の対旋律は3度・6度中心にすると外れない。
5. **平行5度・8度はぶつかるのではなく、2本が1本に溶ける。** だから禁じられた。溶かしたい時（パワーコード、オクターブ重ね、弦の厚み）は、わざと使う。
6. **ボイスリーディングの基本3つ**: 共通音は同じ声部に残す／ほかは最短距離で動かす／声部を交差させない。
7. **四声体は「低音（ベース）を先に決め、上の3声を和音の残りの音で埋める」。** 3度は省かない（長調か短調かを決める音）。根音を倍にするのが無難。
8. **上3声は近く（1オクターブ以内）、低音との間は広く。** 低い所で3度を鳴らすと濁る（補：うちの checkScore の「低音のにごり」と同じ話）。
9. **対旋律は「旋律が長い音なら短く、短いなら長く」。** 旋律が休む所に答え、頂点を重ねない。
10. **ペダル（保続音）とオスティナートは、上の和音が変わっても動かない柱。** 景色だけ変えたいとき、緊張を溜めたいときに効く。
11. **ドロップ2は「密集形の上から2番目を1オクターブ下げる」。** 4声が一気に開いて、旋律の邪魔をしない。低くなりすぎると濁る。
12. **模倣（カノン）は「同じ旋律を遅らせて重ねる」だけ。** 5度上で答えると調が揺らぎにくい。ストレッタは答えを早めに入れて重ねる。
13. **バッハ式の和声は、シンプル。** 根音が3度下・4度上・2度上へ動く流れが自然で、第2転回は終止の前くらいしか使わない。低音を歩かせるのが肝。
14. **ゲームの曲は「どのパートを外しても成り立つ」層で書く。** 対旋律・ペダル・オスティナートは、それぞれ単独で聞ける線にする。
15. **ルールは理由とセットで覚える。** 理由が分かれば、破るべき時も分かる。破るなら、1曲の中で意味のある場所に1〜2回。
16. **書いたら1声ずつ聴く。** 1本だけ鳴らして歌える線なら良い声部、跳躍が不自然ならどこか直す。

## 2. 規則の表
### 2.1 声部の動き（縦と横）
| 項目 | してよいこと | 避けること | 例外・事情 |
|---|---|---|---|
| 平行5度・8度（同じ向きで同じ幅の連続） | 3度・6度の連続、反行・斜行での移動 | 隣り合う和音で2声が同じ向きに5度・8度（1度も同様）を続ける | ギターのパワーコード、オクターブ重ね、弦や管の「1本に聞かせる」重ね、ロックの5度の平行 |
| 隠れ（直接）5度・8度 | 完全音程へ入るとき反行か斜行にする。上の声が順次進行なら可 | 外声（最高と最低）が同じ向きに跳んで完全音程に着く | 内声同士ではよく出る。ホルン5度のように上が順次なら許される |
| 不等5度（完全5度→減5度） | 減5度→完全5度は古くから許容 | 完全5度→減5度の平行を長く | 和声の都合で避けられないとき |
| 声部の交差 | 声部は低→高の順を保つ | 内声が上や下の声を一瞬追い越す | 平行を避ける目的、旋律を際立たせるときに限る（バッハも稀） |
| 声部の追い越し（オーバーラップ） | 次の音が相手の前の音を越えない | 上声が動いた先が、下声の直前の音より低い | 同じ音域の2本を意図的に絡める時 |
| 共通音 | 次の和音に同じ音があれば、同じ声部で保つ | 共通音があるのに全声が動く | 大きく雰囲気を変える転調・突然のコード |
| 動く幅 | 順次（2度）か3度まで。内声は特に小さく | 内声の大跳躍、続けての跳躍 | 低音は根音の5度・オクターブ跳躍がふつう。跳んだら反対向きに戻る |
| 向きの割合 | 反行と斜行を主に | 全声が同じ向きに何度も動く | 3度・6度の並行は数音ならよい |
| 頂点（一番高い音） | 1フレーズに1回、2本で別々の位置 | 2本が同時に頂点、最後の音が頂点 | クライマックスの一致は演出として使える |
| 不協和（2度・7度・減増音程） | 弱拍で経過音、強拍なら予備（同じ音を前の拍から保持）→解決（下へ2度） | 強拍に準備なしで置く | 現代的な曲は9th・11thを和音の一部として置く |
| 終わり（2声の終止） | 不完全協和→完全協和（6→8度）へ、一方が2度で入る | 5度で終える、同じ向きで8度へ入る | ゲームのループ曲では主和音で終わらず次へ流すこともある |

### 2.2 四声体の和音の作り方
| 項目 | してよいこと | 避けること | 例外・事情 |
|---|---|---|---|
| 音の倍にする（ダブリング） | 根音を倍にするのが基本（I・IVでは特に）。第2転回は5度（低音）を倍に | 導音（長調の7度）の倍。傾向音（上に行きたい音）の倍 | 調性の根を強めたいとき、3度を倍にする短和音・減和音の第1転回など |
| 省く音 | 5度は省いてよい（そのとき根音を倍、または3度を倍） | 根音と3度の省略。第2転回と減和音での5度の省略 | 7thコードでは5度を省くのが普通 |
| 間隔（スペーシング） | ソプラノ・アルト・テナーは互いに1オクターブ以内。低音とテナーの間は広くてよい | 上3声の間が1オクターブより離れる | 開離配置は意図的に使う（バラードのピアノ） |
| 低音との間隔 | 低い音ほど広くとる（5度以上、できれば1オクターブ） | C3より下で3度や2度を鳴らす | 弦のコントラバス＋チェロはオクターブで重ねる |
| 音域 | 各声は自然な音域の中ほどに置く（§5.1） | 端の音ばかり、全員が高すぎ・低すぎ | シンセパッドは楽器の制約が少ない。ただし帯域の衝突は起きる |
| 7thの扱い | 7度は下へ2度で解決。中声部に置く | 7度を低音に置く、7度を倍にする | 9th以降のテンション化は、ジャズ・ポップで普通 |

### 2.3 対旋律（書くときの規則）
| 項目 | してよいこと | 避けること | 例外・事情 |
|---|---|---|---|
| リズム | 旋律の長い音の間に動く、旋律が動く所では止まる | 旋律と同時に同じ音価で動き続ける | 3度・6度のハモリは同じリズムが前提 |
| 向き | 旋律が上がる所で下がる | 同じ向きで長く動く（特に5度・8度） | 3度・6度の並行 |
| 音 | 強拍は和音の構成音、弱拍は経過音・刺繍音 | 強拍にコード外音を並べる | 保続音（ペダル）は和音の外にもなり、後で解決する |
| 音域 | 旋律と別の音域・別の音色 | 旋律と同じ音域・同じ楽器 | 同じ声質なら旋律より思い切って高く書く |
| 量 | ここぞの場面だけ。2周目や間奏から | 曲の頭から最後までずっと | 戦闘曲はずっと動く対旋律が推進力になる |
| 単独で | 1本だけ鳴らして成り立つ線にする | 伴奏の音を並べただけの線 | ベースラインが対旋律を兼ねる場合 |

### 2.4 模倣・保続・反復
| 項目 | してよいこと | 避けること | 例外・事情 |
|---|---|---|---|
| カノン（模倣） | 同じ旋律を遅らせる。5度上・8度・3度上下で答える | 遅れ幅と音程を毎回変える | 反行（上下逆）・拡大（音価2倍）・縮小は変化球 |
| ストレッタ | 前の声が終わる前に次を入れる（1〜2小節遅れ） | 重なりで強拍が不協和ばかり | 偽のストレッタ：入った後は自由に続けてよい |
| ペダル | 低音を保持し、上は和音が動く。始めと終わりは協和 | 長すぎて飽きる、途中が耳に痛いだけ | 属音ペダルは緊張、主音ペダルは安定。内声・高音のペダルもある |
| オスティナート | 短い型を同じ高さで繰り返し、上を変える | 同じ型を何十回も変化なしで | 型の最後の音だけ変える、2周目に楽器を足す |

## 3. ポピュラー・ゲーム音楽での使い方
- **古典と違う点（まとめ）**: 5度の平行はロック・ダンスでは普通。コードが先にあり、旋律と伴奏が「層」になって重なる。縦の和音の都合が横の線より強いので、**声部の独立は「対旋律・ベース・内声の保続」の3か所で見せる**。
- **対旋律の置き場所**: ①旋律の休符（短い4〜5音）②2番・間奏・最後のサビ③旋律と別の音域（下のオクターブ、または思い切って上）。
- **ベース＝対旋律**: ベースが歩く（C–C/E–F–F/A–G）と、それだけで旋律と反行する。旋律が下がるとき、ベースは上がる。
- **内声の保持**: ピアノ・ギターの内側の1音を動かさず（G4 などを保持）、和音の変化に合わせて「9thの色」だけ変える。声部が少ない曲ほど効く。
- **クリシェ（半音の下降）**: 内声や低音を半音で下ろす（A→G→F♯→F）。コードが変わるのに線がつながっているので、聴き手が自然に追える。
- **ペダル**: 戦闘前の静かな導入、ダンジョン、緊張の溜め。低音を固定したまま上のコードを替え、最後に根音が動いて解決する。
- **オスティナート**: 短い型（アルペジオ、2小節のリズム）を土台にして、上に旋律を乗せる。町・フィールド・長い戦闘で、飽きにくくする。
- **コーラス・弦のパート割り**: 旋律はソプラノ（最上）。男声は低めのテナー・バスで根音と5度。弦は低音をオクターブで重ね、内側を2〜3声に分ける（§5）。
- **ゲームの層（レイヤー）**: パートを「単独で成り立つ層」として書く。対旋律の層が外れても、旋律＋伴奏が完結すること。
- **バッハ風の和声進行（一般論）**: 和音はシンプルに、低音の線が滑らかになる時にだけ替える。根音は「3度下がる」「4度上がる（5度下がる）」が自然。IV→V のように2度上がるときは、旋律を逆に動かす。第2転回形は終止の手前（I⁶₄–V–I）に限る。同じ和音が続くなら、片方を転回形にして低音を動かす。
- **やりすぎ注意**: 声部を増やすと濁る。低音域の3度は避け、同じ音域の楽器は役割を分ける。

## 4. ボイシングの型（44個）
**読み方**: 音名は中央のドが C4（うちの記法と同じ）。「低→高」は下の声から順。パート割りは、1つの和音を何パートに分けるか（`strings` を複数パートにする、`piano` の左右など）。
音を移すだけで他のコードにも使える（根音の違いは平行移動）。ベースを別に置く場合は「＋ベース」と書いた。

## 5. 音域・パート割りの目安
### 5.1 声と弦の音域（目安。合唱の下限・上限は端を避ける）
| パート | 音域の目安 | 補足 |
|---|---|---|
| ソプラノ | C4〜A5 | 旋律向き。端は避ける |
| アルト | G3〜D5 | 内声。順次が多い |
| テナー | C3〜A4 | うちの記法では書いた音がそのまま実音 |
| バス | E2〜C4 | 根音と5度。低い所の3度は避ける |
| コントラバス | E1〜 | 弦では分けず、ほぼチェロとオクターブ重ね。濁りやすいので分割しない |
| チェロ | C2〜C5 | 低音と対旋律の両方 |
| ビオラ | C3〜E5 | 内声。刻みや保持 |
| ヴァイオリン | G3〜E6 | 旋律・高い持続音 |
- 弦は2声に分ける（div a 2）が基本。3分割は上の2つのパートだけに、4分割は特別な場面に。低域は広く、高域は詰める。
- **根音を最もよく倍にし、5度を次に、3度を最も少なく。** コントラバスとチェロはオクターブで重ねず、チェロは分けて和音を埋める手もある。

### 5.2 パートの作り方（ポップス・ゲーム）
1. **ベース（最低）**: 根音。転回形で歩かせる。
2. **旋律（最高、または別の目立つ音域）**: 先に決める。対旋律・和音はそのあとに。
3. **内声**: 和音の残りの音。共通音で保つ、順次で動く。
4. **対旋律**: 旋律の隙間に。別の楽器・別の音域。
5. **ダブリング**: 同じ線を別の音色で重ねる（弦＋ホルン、ピアノ＋ギター）。声部を増やさず厚くなる。

## 6. 対旋律の作り方：手順と例
### 6.1 手順（8ステップ）
1. **旋律の「長い所」と「休む所」に印をつける。** そこが対旋律の出番。
2. **小節ごとの和音の構成音を書き出す。** 強拍で使える音の一覧。
3. **音域を決める。** 旋律の下（3度〜1オクターブ下）か、思い切って上。同じ音域なら楽器を変える。
4. **リズムを旋律の逆にする。** 旋律が長い音 → 短い音。旋律が動く → 長い音か休符。
5. **向きを決める。** 旋律が上がる所は下げる（反行）。止まる所は動く（斜行）。
6. **強拍は和音の構成音に置く。** 弱拍は経過音・刺繍音（2度で行って戻る）。最後の音は和音の音。
7. **旋律との音程を点検する。** 強拍は3度・6度・10度（協和）に。5度・8度が2回続いたらどちらかを動かす。
8. **1本だけ鳴らして歌う。** 跳躍が続く、同じ音ばかりなら直す。うちなら `node tools/composer/song.mjs build` の「注意:」も読む。

### 6.2 見本16個
**書式**: `# 番号 名前　bpm・小節数・拍子　chords:` の見出し、`名前 : notes` が1パート。`|` は小節の区切り（貼るときは取る）。各パートの拍の合計が同じになるように書いた（小節数×拍の数）。旋律は仮のもの。

```
# E1 長い音に下降する対旋律　C Am・bpm 80・2小節　chords: C Am
lead          : E5:4 | C5:4
counter(keys) : G4:1 F4:1 E4:1 D4:1 | E4:1 D4:1 C4:1 A3:1
```
- 旋律が止まる間に、対旋律が順次で下りる（斜行）。強拍は C の音（G・E）と A の音（E・C）。

```
# E2 上がる旋律と下がる対旋律（反行）　C F・bpm 92・2小節　chords: C F
lead          : C5:1 D5:1 E5:1 F5:1 | A5:2 G5:2
counter(keys) : G4:1 F4:1 E4:1 D4:1 | C4:2 A3:2
```
- 旋律が上がる所で下がる。2小節目は旋律の山の A5 に対し、対旋律は低い所へ（頂点が別々）。

```
# E3 旋律が休む所に答える　Am G・bpm 96・2小節　chords: Am G
lead          : A4:2 C5:1 B4:1 | R:4
counter(keys) : R:4 | D5:1 B4:1 G4:1 B4:1
```
- 呼びかけは旋律、答えは対旋律。答えの音はすべて G の構成音（D・B・G）。

```
# E4 3度下のハモリ（並行3度）　C Am・bpm 100・2小節　chords: C Am
lead          : E5:1 G5:1 F5:1 D5:1 | C5:4
harmony(strings) : C5:1 E5:1 D5:1 B4:1 | A4:4
```
- 各音の「音階で2つ下」。並行3度は例外としてよい。長く続けるのは2〜4音まで。

```
# E5 保続音（ペダル）の上で動く旋律　Dm Bb・bpm 72・2小節　chords: Dm Bb
lead          : D5:1 F5:1 A5:2 | Bb5:2 A5:2
pedal(strings): D4:4 D4:4
```
- 2小節目 Bb の上で D は3度。静かに2つの景色が見える。解決は次の Dm。

```

ostinato(harp) : A3:0.5 E4:0.5 A4:0.5 E4:0.5 A3:0.5 E4:0.5 A4:0.5 E4:0.5 | F3:0.5 C4:0.5 F4:0.5 C4:0.5 F3:0.5 C4:0.5 F4:0.5 C4:0.5

- 土台は2音の往復。型はそのまま、根音だけを和音に合わせて移す。

lead           : E5:1 G5:1 B5:2 | R:4
answer(guitar) : R:4 | A5:1 F#5:1 D5:2
```
- 2小節目の答えは D の音（A・D）と経過の F♯。呼びと答えで山の高さを変える。

lead           : G5:1 F5:1 E5:1 D5:1 | D5:4
counter(keys)  : C4:1 D4:1 E4:1 F4:1 | G4:2 B4:2

- 旋律は下り、対旋律は上り。2小節目は両方の終着が G の3度・6度。

## 7. 模倣・カノンの簡易版の書き方
### 7.1 考え方
- **カノン**＝同じ旋律を遅れて重ねるだけ。遅れ幅（1〜2小節）と音の高さ（同じ高さ、1オクターブ、5度上）を決める。
- **ラウンド（輪唱）**＝旋律の終わりが頭に戻れる形。ループ前提のゲーム曲向き。
- **答え（アンサー）**＝5度上（または4度下）に移した旋律。調性を揺らしたくなければ、最初と最後の音だけ主音と属音を入れ替えて調整する（補）。
- **ストレッタ**＝前の声が終わる前に次の声を入れる。1〜2小節の遅れで、2〜3声。
- **変化球**＝反行（上下逆）、拡大（音価2倍）、縮小（音価半分）。まずは「同じ旋律を遅らせるだけ」から。
- **書くコツ**: ①旋律は3度・5度・オクターブの跳びとステップで組む。②先に2声を書いて、1拍ずつ縦の音程を確認（強拍は3度・6度・オクターブ）。③強拍が不協和なら、2声目を3度か6度に移して試す。④ぶつかる所は、旋律の途中の音を1つ変える（元は両方とも同じにする必要はない）。

### 7.2 見本3つ
```
# K1 輪唱（2小節遅れ）　C Dm Em C G C・bpm 84・6小節　chords: C Dm Em C G C
voice1(lead)  : C4:1 E4:1 G4:1 E4:1 | D4:1 F4:1 A4:1 F4:1 | E4:1 G4:1 B4:1 G4:1 | C5:4 | G4:2 E4:2 | C4:4
voice2(strings) : R:8 | C4:1 E4:1 G4:1 E4:1 | D4:1 F4:1 A4:1 F4:1 | E4:1 G4:1 B4:1 G4:1 | C5:4
```
- 2声目は8拍（2小節）遅れて同じ旋律。2声目の3小節目が1声目の旋律の終わりとぶつかる箇所は、耳で確かめて音を入れ替える。

```
# K2 5度上の答え　Am G Em Em・bpm 90・4小節　chords: Am G Em Em
voice1(lead)    : A4:1 C5:1 E5:2 | D5:1 C5:1 B4:2 | E4:2 G4:2 | F#4:2 E4:2
voice2(strings) : R:8 | E5:1 G5:1 B5:2 | A5:1 G5:1 F#5:2
```
- 主題を5度上げて答える（A→E、C→G、E→B）。1声目は3〜4小節目で自由に続ける。

```
# K3 ストレッタ（1小節遅れ、1オクターブ下）　C C C・bpm 100・3小節　chords: C C C
voice1(lead)    : E5:1 D5:1 C5:2 | G4:2 C5:2 | R:4
voice2(strings) : R:4 | E4:1 D4:1 C4:2 | G3:2 C4:2
```
- 主題は2小節。2声目は1小節遅れで入り、1声目が終わる前に重なる。重なる小節は C の構成音が多いので、ぶつかりにくい。

### 7.3 うちの道具で書くとき
- 遅れ＝先頭に `R:拍数` を置く。拍の合計が同じになるよう、先に鳴る声の末尾にも `R` を足す。
- 5度上＝音名に+7半音（A4→E5、C5→G5）。2声目が高くなりすぎたら、1オクターブ下げて書く。
- 音量は2声目をやや小さく（ハモリと同じ扱い）。

## 8. チェックリスト
**書く前**
- [ ] 旋律・ベース・和音の役割が重なっていないか

## 9. 取り入れる提案（実装できる単位）
いずれも「警告・ヒントのみ」で、曲の生成を止めない。既存の `song-check.ts`（checkScore）と `score-check.mjs` の流儀に合わせる。
1. **平行5度・8度の自動検出（全ペア）**: 拍の頭の音を、ピッチのあるパート全ペアで比べ、前後2点で「両方が同じ向きに動き、音程が完全5度（7半音）またはオクターブ（0 か 12 の倍数）」なら数える。ドラム・同一音を保持するだけのパートは除く。ベース×旋律だけでなく、内声同士も。ギターのパワーコード（同じ楽器名が2パートで5度）やオクターブ重ねは「意図」として除外し、回数が多いペアだけ警告（目安：同じペアで4回以上）。
2. **声部交差の検出**: 同じ楽器名の複数パート（`strings` の3声など）を、番号順に低→高と仮定し、同じ時刻で順序が入れ替わった回数を数える。意図した交差（ハモリで上下を替える）に備えて、警告のみ。
3. **隠れ5度・8度（外声）の検出**: 最高声と最低声が、同じ向きで完全5度・8度へ着く。ただし最高声が順次なら除外。ベース×旋律の既存検出に足す。
4. **`voiceLead` の改良（コスト関数の拡張）**: ①共通音は同じ声部に残すボーナス ②平行5度・8度のペナルティ ③声部交差の禁止（順列を絞る）④外声の反行にボーナス。現在は移動量の合計だけで選ぶので、最短でも平行5度になることがある。
5. **`voiceLead` に型の指定（近い／開く／ドロップ2）**: 引数 `voicing: "close" | "open" | "drop2" | "spread"`。close はいまの動作、open は根音・5度を下、3度を上に、drop2 は4音の密集形の上から2番目を下げる（§4）。
6. **低音域の間隔チェック（にごり判定の精密化）**: すでにある「C♯3より下の近い音程」に加え、C3より下の3度、E3より下の2度を数え、パート名を挙げる。§2.2 の「低い所は広く」に対応。
7. **対旋律の自動生成（`generateCounter`）**: 旋律のノーツ列と和音列を入れて、候補の音（和音の構成音＋経過音）から、①旋律と逆向き ②リズムは旋律の補い（長い所は短く）③強拍は構成音 ④旋律との音程が協和 ⑤平行5度・8度なし、を評価する経路探索（DP）で1本作る。結果は notes の記法で返す。拍の合計が旋律と一致すること。
8. **カノン／模倣の生成（`canonOf`）**: notes 列に、遅れ幅（拍）・移調（半音）・反行・拡大/縮小を与えて、もう1パートを返す純粋関数。先頭の `R:拍数` と末尾の `R` で拍の合計をそろえる。§7 の見本をテストに使える。
9. **保持音（ペダル）の補助（`pedalLine`）**: 和音列と度数（根音／5度）を与えて、長い音の列を返す。上の和音が替わるとき、保持音が和音外になる拍だけ警告する（解決の確認）。
10. **対旋律の「入り」の自動セクション**: `parts[].sections` と組み合わせて、1周目は休み・2周目から入る対旋律をテンプレートで生成（`arrangement-deep.md` §11 の提案とつなぐ）。

### 9-1. 実装状況（2026-10-11、ブランチ feat/r2-melody）

提案 1〜10 をすべて実装した。テストは `src/audio/counterpoint-craft.test.ts`。いずれも警告・ヒントのみで、曲の生成は止めない。

| 番号 | 状況 | 置き場所・使い方 |
|---|---|---|
| 1 平行5度・8度（全ペア） | 実装 | `tools/audio-check/voice-lint.mjs` の `findParallels`。拍の頭で全ペアを比べ、前後2点とも両方が動いて同じ向きで完全5度／オクターブなら数える。ペアの6割以上がその音程（パワーコード・オクターブ重ね）、role に「重ね」「下で」「ハモ」「パワー」を含むパートは除外。同じペアで4回以上なら警告。旋律×ベースは既存の点検があるので、`score-check.mjs` では重複を避けて外した |
| 2 声部交差 | 実装 | `findVoiceCrossings`。同じ楽器名の複数パートを**平均音高の低い順**（「番号順に低→高」ではなく、書き順に依存しない形にした）に並べ、拍の頭に順序が入れ替わった回数を数える。2回以上で警告 |
| 3 隠れ5度・8度（外声） | 実装 | `findHiddenPerfects`。旋律とベースが同じ向きに動き、最高声が3半音以上跳んで完全5度・8度に着く所を数える（最高声が順次なら除く、すでに完全音程だった所は平行側で数えるので除く）。4回以上で警告 |
| 4 voiceLead のコスト関数 | 実装 | `src/audio/newsong.ts` の `voiceLead`。①共通音は同じ声部に残す ②平行5度・8度に罰 ③声部の交差・追い越しは選ばない ④外声の反行にボーナス。省略可の引数 `opts.smart: true` で有効（**既定は false**＝旧い動作。`genre-feels.test.ts` が `buildNewSong` の出力をハッシュで固定しているので、既存の出力を変えないために opt-in にした。自動伴奏の和音に使うかは別途決める） |
| 5 voiceLead の型 | 実装 | `voiceLead(bars, voices, lo, hi, { voicing: "close" \| "open" \| "drop2" \| "spread" })`。close＝いまの動作。open＝根音が最低・5度は根音の上・3度（と7度）が上。drop2＝上から2番目を1オクターブ下げる。spread＝open の最高声をさらに1オクターブ上げる。open 系・drop2 は lo より最大1オクターブ下に出ることがある（なめらかさの計算は密集形で行う） |
| 6 低音域の間隔 | 実装 | `findLowMuddy`。C3 より下の3度、E3 より下の2度を、パート名つきで数える |
| 7 対旋律の自動生成 | 実装 | `tools/composer/counterpoint.mjs` の `generateCounter(melody, chords, { beats, place, lo, hi })`。動的計画法（状態＝候補の高さ＋同じ音の続いた長さ）。評価は逆向き・リズムの補い・強拍は構成音・協和・平行5度8度（大減点）・順次。拍の合計は旋律と同じ。`node tools/composer/song.mjs counter 曲.json [--part N] [--above] [--enter 小節] [--instrument strings]` で `parts` に足せる JSON を出す |
| 8 カノン／模倣 | 実装 | `canonOf(notes, { delay, transpose, invert, factor, total })`。先頭に `R:遅れ幅`、末尾は休符で合計をそろえる（長すぎれば切る）。`song.mjs canon "<notes>" --delay 4 --transpose 7` |
| 9 保持音（ペダル） | 実装 | `voice-lint.mjs` の `pedalLine(chords, { degree: "root" \| "fifth", beats, octave })`。長い1音の列と、和音の外になる小節の警告を返す。`song.mjs pedal "C Am F G"` |
| 10 対旋律の「入り」 | 実装 | `counterEntering(melody, chords, { enterBar })`（入りの前は `R`）と `enterBarFromSections(sections, totalBars)`（同じ種類の2回目の頭。なければ後ろ半分）。`parts[].sections` の音量倍率ではなく**音符に休符を入れる**形にした（`sections` は種類ごとに1つの倍率で、同じ種類の1周目と2周目を分けられないため） |

`score-check.mjs` は声部の点検（1・2・3・6）を `voiceLint` で呼び、出力に行として足す。

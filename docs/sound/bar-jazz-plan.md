2026-10-27 作成。依頼：BARに合うジャズ50曲／楽器は自由／4〜5分／同じ曲・似た曲なし／8点以上（最低7.5）。

## 守ること
- 本物の楽器の録音音源だけ（電子音なし）。ピアノ＝salamander、ベース＝upright/rubner、ドラム＝jazz、管・弦＝vsco 系の実音。
- 長さ 4:00〜5:00。形は「頭（テーマ）→ソロ→頭→終わり」を基本に、曲ごとに骨組みを変える。
- 2曲を並べて、「形」「場面と強さ」「旋律の性格」のうち **2つ以上** がちがう。前後の曲で始まり方を重ねない。
- 前作カフェジャズ25曲（朝のエスプレッソ／雨の窓辺のボサノバ／午後のワルツ／真夜中のバラード／本棚の五拍子／ランプのモード／ネオソウル／港のサンバ／ブルーな月曜日／月夜のボレロ／雪の窓／6/8木もれ日／石畳スウィング／チャチャ／ハードバップ／北の湖／ギタートリオ／古い喫茶店ピアノ／室内楽／霧の夜の探偵／カリプソ／メロウファンク／チェロのデュオ／ゴスペル／バイヨン）と、名前・テンポ・調・編成の組み合わせが重ならないようにする。
- 各曲に「その曲だけの音や展開」を1つ以上。ゲームの要素は入れない。

## 重なりのチェック（案）
- テンポ：50〜212 に散らす。同じ曲調で近いテンポは並べない。
- 調：12調をまんべんなく。マイナーは約4割。
- 編成：1曲ごとに主役の楽器を替える。ソロピアノ、デュオ、弦楽、管のみなど。
- 細かい被り（#13 と #27 の トロンボーン、#33 と #2 のテナーなど）は、曲想・拍・形をはっきり変える。

## 次の手順
1. 承認をもらう（直したい曲・入れ替えたい曲があれば反映）。
2. `bar_jazz.py` を作る（cafe_jazz.py をもとに、曲の定義と楽器表を拡張）。
3. 5曲ずつ作って、点数（Audiobox）・ノイズ・音量の段差・単調さを確かめ、直してから次へ。
4. mp3 を1曲ずつチャットに送る。

# ギターの和音の弾き方（プロのギタリストの伴奏で確かめた）（2026-11-15）

人間（2026-11-15）:「あとギターの音毎回思うけどどうにかならないかな。」「ギターは和音の弾き方を学んだ方がいい。」

## 使ったデータ

- GuitarSet（https://zenodo.org/records/3371780 ・CC BY 4.0。Q. Xi, R. Bittner, J. Pauwels, X. Ye, J. P. Bello, ISMIR 2018）。プロのギタリスト6人が、5つのジャンル（ロック・ファンク・ジャズ・ボサノバ・弾き語り）で伴奏を弾いたものを、**弦1本ずつ**記録したデータ。伴奏の演奏180本（各ジャンル36本）を使った。
- 使ったのは注釈（どの弦で・いつ・どの高さを・どれだけの長さ弾いたか）だけ。音は取っていない。測ったあと消した。出したのはジャンルごとの統計だけ（`docs/sound/data/guitarset-chords.json`）。
- 道具: `tools/audio-check/guitarset-chords.py`。型にしたものは `vocalo_lib.py` の `gtr_shape()`・`gtr_strum()`・`gtr_velocity()`。
- 注意: アコースティックギターの演奏。歪ませたエレキの「刻み」は入っていない。強さ（どれだけ強く弾いたか）は記録されていない。

## 今までの自分の弾き方と、ちがっていた所

| | プロ（ロック） | 今までの自分（16 など） |
|---|---|---|
| 和音の形 | 根音・5度・オクターブ・その上に3度（広い） | 根音のすぐ上に和音の音を2つ（せまい。プロでは 2.5%） |
| 鳴らす弦の数 | 毎回ちがう（1〜6本） | いつも3本 |
| 弦のずれ | 1本あたり8ミリ秒 | 0（ぴったり同時） |
| 向き | 8分はぜんぶダウン、16分ウラだけアップ | 区別なし |
| 強さ | （記録なし。ふつうは頭が強い） | ぜんぶ同じ |
| 音の長さ | 次のストロークまで鳴らす | 同じ |

**いちばん大きなちがいは、和音の形だった。** 歪ませたギターで根音のすぐ上に3度を置くと、音がにごる。プロは3度を1オクターブ上に置く。

## 型にしたもの

- `gtr_shape(和音)`: ギターの押さえ方に近い形を返す。根音が6弦なら6本（根音・5度・オクターブ・3度・5度・根音）、5弦なら5本。sus4・7th・m7・maj7 にも対応。
- `gtr_strum(6本のパート, S, 小節, 型, 和音, 乱数)`: 拍の頭はダウンで低い弦から4〜6本（たまに3本）・強く。8分ウラはダウンで、いちばん低い弦を飛ばして3〜4本。16分ウラはアップで、高い弦から2〜3本・弱く。弦のずれは1本8ミリ秒。
- `gtr_velocity(js, 役の名前)`: 1音ずつの強さを付ける（頭 94〜106・8分ウラ 76〜88・16分のアップ 56〜68）。この3段階の数字は、データにないので自分で決めたもの。

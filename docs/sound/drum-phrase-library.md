## 1. 材料と出典

- **Groove MIDI Dataset（GMD）v1.0.0**（Google Magenta。CC BY 4.0）: 10人のドラマー（8割以上がプロ）が、メトロノームに合わせて Roland TD-11（電子ドラム）でたたいた演奏の MIDI。1,150ファイル・約13.6時間・22,214小節・18ジャンル。
  MIDI だけの zip（3.3MB）を使った。ライセンスの写し: `assets-src/soundfont/extra/src/licenses/README-GrooveMIDI-CCBY4.md`（本文は同じ所の `CC-BY-4.0-legalcode.txt`）。
  引用: Jon Gillick, Adam Roberts, Jesse Engel, Douglas Eck, David Bamman. "Learning to Groove with Inverse Sequence Transformations." ICML 2019。
- **E-GMD（Expanded GMD）は使わなかった**: GMD と同じ演奏を、43種類のキット（TD-17）で録り直したもの（MIDI だけの zip も 103MB）。**演奏そのもの（リズム）は GMD と同じ**で、新しいフレーズは増えないため。
- **自作の189個**: GMD にほとんど無いツーバス・ハーフタイムのブレイクダウン・ブラスト寄り・チャイナのアクセント・ギャロップ・Dビート寄り・スカンク、と**静かな場面（繊細）**の型を、ドラムの教本・レッスンで一般に教えられている型から組み立てた（特定の曲の写しではない）。
  出典: Modern Drummer「Double Bass Drumming」（16分のツーバスは「1 e & a」をくずして作る・2・4のスネア）、metalcore wiki「Breakdowns」（ライド4分＋3拍目のスネア／クラッシュかチャイナの4分／遅いときは2分音符／キックはギターの刻みに沿う）、freedrumlessons「Heavy Metal Drumming」（ブラストの手順・スネア→ハイ→ミッド→フロアの16分のフィル）、Wikipedia「Heavy metal gallop」、うちの `drum-genre-guide.md` 2.3・`modern-loud-rock/arrangement-detail.md` 5章。
  id が `loud:` で始まり、source は「自作（一般的な型）」。GMD のものは `gmd:` で、source は「GMD」。

**クレジット**: 作曲ソフト専用。ゲームに入れる曲でこのフレーズを使うときは「Drum patterns: Groove MIDI Dataset (Google Magenta, Gillick et al. 2019), CC BY 4.0。16分の格子への変換・切り出しの加工あり」と書く（`docs/assets-credits.md`）。

## 2. 取り出し方

- 4/4 の「beat」の演奏（491ファイル）から、**頭から8小節ずつ重ならないように**切った（2,442個）。同じ中身の重複と、空の小節が3つ以上あるものを外して 2,439個。
  「fill」の演奏（1〜2小節が9割）は 647個を `fills.json.gz` に。
- 楽器の対応（GMD のページの表どおり）: キック 36／スネア 38・40（縁＝リムショット）・37（クロススティック）／ハイ 48・50 → `1`（C4）／ミッド 45・47 → `2`（A3）／フロア 43・58 → `4`（D3）／
  閉じたハット 42・22、ペダル 44（`o`）／開いたハット 46・26（`O`）／クラッシュ1 49・55 → `c`（C2）／クラッシュ2 57・52 → `g`（G2）／ライド 51・59 → `r`（D2）／ベル 53 → `u`（F2）。
  TD-11 はタムが3つなので、GMD のフレーズには `3`（F3）は出てこない（自作には出る）。
- **強さの3段**（GMD の分布から。スネアの中央値 45・キック 53・閉じたハット 43〜85）:

| 楽器 | o（ゴースト） | x（ふつう） | X（強） |
|---|---|---|---|
| キック | 30 未満 | 30〜99 | 100 以上 |
| スネア | 50 未満 | 50〜109 | 110 以上、または縁（リムショット）で 100 以上 |
| 閉じたハット | 40 未満（ペダルはいつも o） | 40〜99 | 100 以上 |
| 開いたハット | 50 未満は閉じた音にする | — | `O` |
| タム・シンバル | — | 110 未満 | 110 以上（タムは A〜D、シンバルは大文字） |

  クラッシュの 30 未満は、手で止めた音・触れただけの音として捨てた。
- **16分への寄せ**: 各音を、16分の格子と8分3連の格子のうち近い方に寄せる。3連の音は 16分の近いマスへ（1/3 → 2マス目、2/3 → 4マス目）。
  **跳ねた演奏（シャッフル）は、3連の3つ目を8分の裏に寄せ、`swing`（裏の平均の位置。0.667＝3連）を記録**した（作曲ソフトの曲の `swing` で戻す）。
  寄せた量（全 397,635打）: 16分の1/4（=64分）より大きく動かした打 **28.4%**、平均のずれ 0.20 マス、3連の格子に近かった打 **9.5%**、同じマスに2打が重なってまとめた打 **9.1%**（32分の連打・フラム）。フレーズごとに `quant` に記録。
- **たたくタイミング**（メトロノームとのずれ。シャッフルを除く）: 2・4拍のスネアはキックの1拍目より平均 **+2.5ms（ロック）〜+5.6ms（ファンク）〜+6.7ms（ヒップホップ）遅い**（あと乗り）。ラテン −7.7ms・ニューオーリンズ −10.6ms は前のめり。
  `snare_lag_ms`・`kick_lag_ms` に記録（作曲ソフトの push の目安: ロック +0.01 拍・ファンク／ヒップホップ +0.02 拍）。

## 3. 仕分けの基準（1フレーズの項目）

`{id, source, style, sub, bpm, drummer, energy, feel, fills:[{bar, beats, kind, kinds}], ghost, cymbals, uses_ride, uses_toms, toms, density, swing, quant, bars:[{k,s,h,t,c} ×8]}`

- **energy（0〜1）**: 打の強さの段の平均（o 0.32・x 0.72・X／O 1.0）45%＋1小節の音数（36打で満点）40%＋テンポ 15%＋クラッシュの数、を GMD 全体で 0〜1 に伸ばした。
  分布: 0〜0.2 が 32・0.2〜0.4 が 352・0.4〜0.6 が 880・0.6〜0.8 が 992・0.8〜1 が 372。自作のメタルは 0.9〜1、静かな型は 0.1〜0.4。
- **feel**: shuffle（裏が 0.6 拍より後ろに寄る）／half（スネアが3拍目で、2・4拍に少ない）／double（裏拍ごとのスネア＝2ビート・スカンク、または毎拍のスネア）／normal。全体で normal 1,759・shuffle 582・half 157・double 130。
- **fills**: 拍ごとに「ふだん（8小節の中央値）より、時を刻む手（ハイハット・ライド）が止まり、タム・スネア・キックが増えた」所をフィルとし、小節の終わりから続く拍の数（beats）と種類を付けた。
  グルーヴの一部としていつも鳴るタム（ラテンのタムなど）はフィルに数えない。
  種類: タム下り（高→低）・タム上り・タム回し・タム一打・スネア連打・キック連打・3連・一撃（シンバル＋キック・スネアの少ない打）・間（3マス以上の無音）・ゴースト・変化（そのほかの崩し）。
- **ghost**: 1小節あたりのスネアのゴーストの数。**cymbals**: hihat・open・ride・bell・crash・china・splash のうち使うもの。**uses_ride**（ライドかベルが4打以上）・**uses_toms**（タム2打以上）。

## 4. 学んだこと（数字）

### 4-1. フィルの頻度と位置
- フィルの入る小節（GMD 2,439個の8小節）: 1小節目 340・2小節目 231・3小節目 156・**4小節目 536**・5小節目 280・6小節目 240・7小節目 200・**8小節目 658**。
  → **4小節目と8小節目が山**（2〜3倍）。プロも「4小節ごとに小さく、8小節ごとに大きく」区切っている。ただし**1〜3・5〜7小節目にも合わせて半分くらいの量の崩しがある**（ずっと同じではない）。
- 8小節目にフィルがあるのは 27%、4小節目は 22%。**フィルの無い8小節も 40%**（975個）＝毎回フィルを入れるわけではない。
- 8小節目のフィルの長さ: 1拍 248・2拍 128・3拍 90・1小節 192。**いちばん多いのは最後の1拍だけの短いフィル**。
- 4・8小節目のフィルの種類: タム下り 410・タム一打 284・スネア連打 218・変化 142・間 53・タム回し 38・一撃 22・3連 21。
  タムの打の数は 4小節目（3,856）・8小節目（4,138）がほかの小節（2,559〜2,897）の 1.4倍。タムの内訳は**ハイ 11,230・フロア 9,065・ミッド 4,165**＝**ハイとフロアの往復が主役**で、ミッドは通り道。

### 4-2. 8小節の中で何が変わるか
- **となりの小節と同じ小節は 8.9% だけ**。となりとのちがい（キック・スネア・ハットのマスの差）は平均 6〜8マス。
- 8小節の中で、キックの形は平均 **5.0種類**、スネア 5.9種類、ハイハット 5.5種類。→ **同じ1小節のコピーを8回並べると、プロの演奏とはまるで違う**（いちばん大きな「単調」の原因）。
- 1小節目と5小節目のちがいも 6.4マス（同じ「頭」でも変える）。
- 強さの流れ: 1小節の音数は 17.7（1小節目）→ 18.4〜18.8（2〜8小節目）。強打（X・O・強いシンバル）は 3.9〜4.2 で、**4小節目 4.63・8小節目 4.82 に山**（フィルで強くなる）。
- クラッシュの入る小節: 1小節目 758・**5小節目 726**・ほかは 456〜578。位置は小節の頭が 38%、残りは 2・4拍・裏拍（クラッシュで刻む・アクセント）。

### 4-3. ゴースト・ハイハットの開け閉め
- ゴーストのあるフレーズは **79%**、平均 2.0個／小節。位置は16分の **2・6・10マス目（1〜3拍の「e」）が各 9〜10%**、**8・14・16マス目（2・4拍の「a」など）が各 7%**＝バックビートのすぐ前後。バックビートの真上（5・13マス目）は 4〜5% と少ない。
- 開いたハット（`O`）は GMD の 1,199フレーズ（49%）で使う。位置は**裏拍（3・7・11・15マス目）が 45%**、拍の頭が 38%。小節による差はほとんど無い（564〜654）＝「区間の最後だけ」ではなく、ずっと所々で開ける。
- 1拍目のクラッシュの下では、閉じたハットは鳴らさない（手は2本）。

### 4-4. ライド・タムの使いどころ
- ライドを使うフレーズの割合: アフロキューバン 84%・ジャズ 60%・ラテン 53%・ロック 42%・アフロビート 40%・ポップ 35%・パンク 30%・ファンク 23%・ヒップホップ 18%・レゲエ 0%。
  **ロックでも4割はライド**（サビや2回目のAメロ・ブリッジ）。ベル（カップ）は 449フレーズ（18%）で、本体と交互（`u.r.u.r.`）か、4分の頭。
- タムはフィルだけでなく、グルーヴの中の1打（タム一打）にも多い。

### 4-5. 強さ（ベロシティ）
- スネアは中央値 45（ゴーストが多い）、縁（リムショット）は中央値 127。キック 53、閉じたハット 43〜85、ライド 66、ベル 93、クラッシュ 89〜103。
  → **全部を強く打っているわけではなく、強打は全体の2割ほど**（「激しすぎ・音が強すぎ」への答え: X は2・4拍と区切りだけ、あとは x と o）。

## 5. 使い方（`loud25_drums.py`）

```python
from loud25_drums import Library, section_strings, apply_section, describe
lib = Library(seed=3)                         # 曲ごとに seed を変える
bars = lib.fit(10, kind="verse", bpm=150)     # 10小節（8の倍数でなくてよい）。最後の小節にフィルが来る
bars = lib.fit(8, kind="chorus", bpm=150, styles=["rock", "metalcore", "loudrock", "metal"])
bars = lib.fit(8, kind="break", bpm=150, sources=["自作"])            # ブレイクダウン（half・チャイナ）
bars = lib.fit(4, kind="quiet", bpm=150, need_ride=True, dynamics="soft")  # 繊細な場面
apply_section(parts, start_beat, bars)        # kick/snare/hihat/tom/crash のパートを loud25_hand.put() で書きかえる
S = section_strings(bars)                     # 文字列だけほしいとき: {"k":"g:...","s":"g:...","h":"g:...","t":"C4:0.25! ...","c":"C2:4 ..."}
print(describe(bars))                         # 使ったフレーズの id
```

- **区間の種類（kind）**と energy の既定: intro 0.15〜0.6／verse 0.3〜0.65／pre 0.45〜0.8／chorus 0.65〜1（クラッシュ・開きハット・ライドを好む）／bridge 0.3〜0.75（ライドを好む）／break 0.55〜1・half（チャイナ）／solo 0.55〜0.95／inter 0.4〜0.8／outro 0.2〜0.7／quiet 0〜0.4。
- 条件: `energy=(下,上)`・`feel="normal"/"half"/"double"/"shuffle"/"any"`（書かなければ shuffle 以外）・`bpm`（フレーズの元の速さの 0.75〜1.3 倍）・`styles`・`sources`・`need_ride`・`need_toms`・`fill_at`・`fill_kinds=["タム下り", ...]`・`max_ghost`・`avoid`。
  合うものが無ければ、fill_kinds → styles → energy・ride・tom の順に条件をゆるめる。
- 決まりごと: **直前と同じフレーズは使わない**／曲の中で使った回数が多いもの・同じ演奏の別の8小節は下げる／**直前と同じ種類のフィルで終わるものは下げる**／区間の最後のまとまりは**8小節目にフィルがあるもの**から選び、n が8で割り切れないときは、そのフレーズの**後ろの小節**を使う（→ 区間の最後の小節にフィル）／区間の途中は、できれば**同じ演奏の続きの8小節**（`continuity=True`）でつなぐ／区間の頭にクラッシュを足す（`crash_start`）。
- `dynamics="soft"`: X→x、刻みのハット x→o、強いタム・シンバルをふつうに（Aメロ・静かな所）。`"hard"`: 2・4拍のスネアと頭のシンバルを強く。
- `lib.gmd_fill_bar(kinds=["タム下り"], bpm=150)`: GMD の短いフィル集から、最後の小節だけを入れかえる1小節を取り出す。
- シャッフルのフレーズ（`feel="shuffle"`）を使うときは、曲の `swing` を 0.5〜0.7 に（フレーズの `swing` 値が目安）。
- GMD のフレーズはハイ・ミッド・フロアのタム3つ（C4・A3・D3）。自作には F3 も出る。シンバルは CrocellKit（`--drums crocell`）でいちばんよく鳴る（チャイナ B2・スプラッシュ A2 もある）。

## 7. 注意・限界

- GMD は電子ドラムの演奏なので、シンバルの「止め打ち」や「半開き」は区別できない。ハイハットの半開きは 46（開き）の弱い打として閉じた音に寄せた。
- 3連・32分は16分に寄せたので、細かいロールは少し粗くなる（9.1% の打をまとめた）。3連のフィルは `fills.kinds` に「3連」と残している。
- 8小節の切り方は演奏の頭からの機械的な区切りなので、演奏者の4・8小節の区切りとずれているものがある（1小節目のフィル 340 はその分）。
- ジャンルはロック 737・ラテン 429・ファンク 297・ジャズ 267 が多く、メタル系は GMD に無い（自作で補った）。

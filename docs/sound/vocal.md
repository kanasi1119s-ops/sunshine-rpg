# 歌声をつける（作曲ソフト＋VOICEVOX）

2026-10-03 追加。作曲ソフトが作った曲に、**女声の歌**をのせる。作曲ソフトは「歌のメロディに歌詞をのせた楽譜」までを作り、声にするのは PC 側の `vocal_tool.py`（VOICEVOX の歌唱）が受け持つ。

## しくみ

```
songs.json（lyrics_kana つき）
  → make.mjs  … 楽器の曲（WAV/MIDI）＋ 歌声用の楽譜 song-NN.vocal.json
  → vocal_tool.py … VOICEVOX エンジンで声にして、伴奏とミックス（song-NN.wav を歌入りに置きかえ）
  → song_tool.py … 音量調整・MP3化
```

- 歌のメロディは、楽器の旋律とは**別に**作る（`SongSpec.vocal: true`。`composeSong(spec, extra)` の `extra.vocal` に入る）。歌わせない曲（`vocal` なし）の楽器の曲は、これまでと1音も変わらない（テストで確認）。
- メロディの高さは、Aメロ D4〜D5、Bメロ D4〜F5、サビ F4〜G5（女声が歌いやすい高さ）。男声などにするときは `transpose` で半音単位にずらす。
- 歌うのは Aメロ・Bメロ・サビだけ。イントロ・間奏・アウトロは楽器だけ。
- 歌詞の1行を、区間（8小節）を等分した区切りにあてる（4行なら2小節に1行）。行の終わりに息つぎ（短い休符）が入る。
- 音（モーラ）が足りないときは、いちばん長い音を半分に割ってふやす。多いときは、母音をのばして埋める（メリスマ）。「っ」は直前の音の末尾に短く入る。「ー」は直前の母音にする。

## songs.json の書き方

```json
{
  "title": "空を裂く声",
  "prompt": "ラウドロック、女性ボーカル、132 BPM",
  "lyrics_kana": "[verse]\nまどのそとは あめのまち\n…\n\n[chorus]\nそらをさいて とどけ\n…",
  "voice": "波音リツ",
  "transpose": 0,
  "vocal_gain_db": 0
}
```

- **`lyrics_kana`**: **ひらがな・カタカナだけ**で書く（漢字・英字は読めないので、警告が出てその部分は歌われない）。見出し `[verse]` `[bridge]` `[chorus]`（`[Aメロ]` `[Bメロ]` `[サビ]` も可）で区切る。`[intro]` `[outro]` `[solo]` の見出しのまとまりは歌わない。見出しがなければ、空行ごとに Aメロ→Bメロ→サビの順にあてる。
- Aメロ・Bメロは**書いた数だけ**歌い、足りない回は楽器だけで進む（くり返さない）。サビは、毎回歌う（`[chorus 2]` と番号をつければ、2回目だけ別の歌詞にできる）。
- 目安: 1行 8〜14音（モーラ）、1区間 4行。テンポが速い曲は少なめに。多すぎると「音が足りず」の警告が出る。
- 歌詞を書かない（`lyrics_kana` がない）曲は、これまでどおり楽器だけ。`"vocal": false` でも歌なしにできる。
- 表示用の漢字まじりの歌詞は `lyrics` に書けば `.lyrics.txt` に保存される（歌声には使われない）。

## 声について

- VOICEVOX で**歌声のライブラリ（ソング）があるのは「波音リツ」（女声）だけ**。既定はこの声。
- ほかの声（四国めたん・春日部つむぎ・雨晴はう・冥鳴ひまり・九州そら など）は「ハミング」方式（話し声に近い声で歌う）。`"voice": "春日部つむぎ"` のように選べる。`python vocal_tool.py voices` で、使える声の一覧が出る。
- **グロウル・シャウト・ガンのような歌い方はできない**（デスメタル・ハードコアなど）。そういう曲は歌なしにするか、きれいな歌声で割りきる。

## 利用条件（必ず守る）

- VOICEVOX は商用・非商用とも無料。ただし**クレジット表記が必要**で、波音リツの場合は「**VOICEVOX:波音リツ**」。`vocal_tool.py batch` は、歌入りにした曲を `credits.txt` に書く。**公開するときは概要欄などに必ず載せる**。
- 声ごとの規約は声の作者側にある。波音リツの規約: <http://canon-voice.com/kiyaku.html>（公式の一覧では「クレジットを書けば商用・非商用で利用可」）。**配信・販売を始める前に、旭さん自身で最新の規約を読んで確かめる**（CLAUDE.md 1-2: 有料・販売・公開は人間の承認が必要）。
- 規約の要点は第三者の紹介記事・公式一覧から読んだもので、全文を確認したものではない。

## 確かめたこと・まだのこと

- 確かめた: 歌詞の分割・メロディへのあてはめ・フレーム計算（ずれがたまらない）・規則（先頭と末尾は音、音は VOICEVOX の一覧にある、など）の自動テスト。VOICEVOX エンジン本体の**模擬モード**を起動して、`vocal_tool.py` の通信（`/singers` → `/sing_frame_audio_query` → `/frame_synthesis`）・区間の配置（声の終わりの位置が楽譜と 0.001 秒まで一致）・ミックス・`inst\` への移動を通した。
- **まだ**: 本物の声での確認（模擬モードは本物の声を出さない）。声の聞こえ方・歌詞の乗り方・伴奏との音量バランス・タイミングの合い方は、**耳で聴いて**確かめる。ずれたときは `--offset-ms`、声の大きさは `--gain-db`（または songs.json の `vocal_gain_db`）で直す。Windows での実行も未確認。

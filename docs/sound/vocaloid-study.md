## 1. 調べて分かった「ボカロっぽさ」の中身

出どころ: Real Sound の連載「ボカロ曲の流行の変遷と『ボカロっぽさ』についての考察」(1)〜(5)、情報処理学会の研究報告
「Are Vocaloid Songs Getting Denser?」（初音ミクの 1,900 曲・2007〜2025 年）。

### 速さ・リズム
- 「ボカロっぽい」の土台は wowaka とハチの**高速ロック**。例に出る速さは BPM 159（16ビートの4つ打ちロック・16分音符の早口の歌）と BPM 205。
- **16分音符を要所にはさむ**。小節の最後の 1.5 拍を「16分音符＋16分休符＋4分音符」にする決めのリズム。
- **1〜2小節で完結するリフ**、**1つの和音だけの Aメロ**、打楽器のような音を散りばめる、1拍ごとに左右で交互に鳴るギター。
- 1,900 曲の分析では、19 年間でテンポ +2.3%、音の立ち上がりの数（密度）+6.4%、リズムの複雑さ +9.1%、和音の変わる速さ +8.0%、**曲の長さ −6.8%（2020 年から急に短く）**。

### 旋律
- **5度の行き来**（ラ→ミ・ミ→ラ）のくり返し、**短6度で上がる**（ミ→ド）など、**跳ぶ旋律**。
- 弱起で短3度上がり、小節の頭でさらに長2度上に着く形（「千本桜」などにもある、5音音階の形）。
- メロディックマイナー（ファ♯・ソ♯）、ブルーノート（ミ♭）で色をつける。

### 和音・転調
- **Just the Two of Us 進行（丸サ進行）**: IV△7 → III7 → VIm7 →（Vm7 → I7）。2016 年以降とくに多い。後半で半音ずつ下がる形もある。
- **サビで転調**する曲が多い（調べた 60 曲中、邦楽 8 曲に対してボカロ曲 20 曲）。例: C♯m → Em（短3度上）。

### 音色・編曲
- **リリースカットピアノ**: 音を短く切り、少しすき間を空けて刻むピアノ（2016 年以降の定番）。
- エレクトロスウィング、比較的おそいテンポのダンスロックとエレクトロ（2016 年〜）。
- コーラスをかけた、わざと少しにごったリードの音。
- 2016 年以降に共通する感覚は「**エディット（切り貼り）・性急さ・技巧**」。

### 歌（調声）
- 子音の速さ（ベロシティ）で歯切れを変える。音の途中の変化はなめらかに（とびとびにしない）。
- フレーズの頭にエッジボイス、ピッチの線を細かくゆらす「がなり」、地声の中に一瞬だけ裏声、など。

## 2. 今の作り方（vt3 02〜14）に足りないもの

| ボカロ曲にあるもの | 今の作り方 | 足りないこと |
|---|---|---|
| BPM 150〜205 の速い曲、16分の早口 | 92〜176。歌はほぼ 8分と4分 | 16分で歌う行・決めのリズムが無い |
| 跳ぶ旋律（5度の行き来・6度上がる） | となりの音へ動く旋律が多い | 跳躍をわざと入れていない |
| 丸サ進行・半音下降・サビで転調 | I・IV・V・vi が中心。転調は最後のサビだけ | 和音の色と転調の場所が少ない |
| リリースカットピアノ・切り貼り（グリッチ）・ボーカルチョップ | のばす和音・分散和音・刻み | 「切る」音作りの部品が無い |
| 1〜2小節のリフが曲を引っぱる | 伴奏の型（パターン）を小節ごとにくり返す | 型のくり返しが「単調」の原因 |
| 曲が短く、場面がどんどん変わる | 4分〜4分半・8〜16小節ごとの場面 | 展開の速さが足りない |
| 細かい調声（しゃくり・裏声・がなり） | しゃくり・ビブラート・ハモリ | 声の表情の種類が少ない |

人間が「良い」と言った 12（図書館ではお静かに）は、くり返しなしで場面ごとに節が新しく、8小節ごとに音が増える形。→ 「同じ型をくり返さない」ことが効いている。

## 3. 作曲ソフトに入れる部品（案。順に作る）

1. **ボカロの旋律の部品**: 16分の早口の行、「16分＋16分休符＋4分」の決め、5度の行き来、6度の跳躍、弱起で上がる形を、歌詞の音数に合わせて組む道具。
2. **和音の部品**: 丸サ進行・半音下降・サビでの転調（短3度上・半音上）を1行で書けるように。
3. **切る音の部品**: リリースカットピアノ（短く切ってすき間）、スタッター（同じ音を細かくくり返す切り貼り）、テープストップ、ビットクラッシュ、サイドチェイン（今の duck を強く）。
4. **リフの部品**: 1〜2小節のリフを決めて、場面ごとに音色・高さ・リズムを変えて育てる（型のくり返しをやめる）。
5. **ドラムの部品**: 16ビートの4つ打ち（裏のオープンハイハットは点数が落ちるので、閉じたハイハットの16分とライド）、キメ（全員で同じリズム）、1拍だけの止め。
6. **歌の部品**: 子音の速さ、フレーズ頭のエッジ、一瞬の裏声、ダブリング（同じ歌を重ねる）、かけ合いのチョップ。
7. **曲の長さと展開**: 3分〜3分半・前奏は短く・4〜8小節ごとに何かが変わる、を曲の表で確かめる。

## 4. 他社のボカロソフトを使えるようにする（調べたこと）

- VOCALOID6 が読める形式: VPR・VSQX・MIDI。書ける形式: VPR・MIDI。
- OpenUtau（無料）は VSQX/VSQ・UST を読める（MIDI は歌詞なし）。
- UtaFormatix は VSQ/VSQX/VPR・UST・USTX・CCS（CeVIO）・SVP/S5P（Synthesizer V）・DV の間で変換できる。
- ヤマハの VX-β は、Cubase などの DAW の中で動くプラグイン（VST/AU）。

やり方は3つ考えられる（どれにするかは人間に聞く）:
- A. **ファイルでつなぐ**: 作曲ソフトの歌のパートを、ほかの歌声ソフトが読める形式（UST/USTX・VSQX・SVP・MusicXML・MIDI）で書き出し、歌声ソフトで作った WAV を作曲ソフトに読みこんで伴奏と合わせる。どのソフトでも使える。
- B. **パソコン用のアプリにして、プラグインを中で動かす**（Cubase と同じ形。VST3 の歌声プラグインを読みこむ）。大きな開発になる。
- C. **無料の歌声エンジンを自動で動かす**（VOICEVOX の歌・NEUTRINO・OpenUtau など。パソコンに入っていれば、作曲ソフトから直接歌わせる）。

## 作曲ソフトに入れた部品（2026-11-15・`assets-src/ai-songs/_gen/vocalo_lib.py`）

今のボカロ曲でよく使われる作り方を、曲の台本（`vt3_NN_*.py`）から呼べる部品にした。1曲目は 15「おばあちゃんのスタンプ」（`vt3_15_stamps.py`）。

| 部品 | 何をするか |
|---|---|
| `steps(型, 音)` | 16分のマス目（`x`＝音の頭、`-`＝のばす、`.`＝休み）でフレーズを書く。`short=` で音を短く切る（リリースカット） |
| `mel16(型, 度数)` | 歌の1小節を16分のマス目で書く（早口・「16分＋休み＋4分」の形が書きやすい） |
| `marusa(移調, last=)` | 丸サ進行（IV△7 → III7 → VIm7 → I7）を好きな調で出す。サビで転調するときに使う |
| `relcut(トラック, 和音, 型)` | リリースカットピアノ（和音を短く切って、すき間を空けて刻む） |
| `stutter_chop(音, かな, 回数)` | 歌の切り貼り（「ぴ・ぴ・ぴ・ぴ」）。`chops()` に渡す |
| `BEAT16` `BEAT16B` `HALF` `KIME8` `KIME_END` | 16ビートの4つ打ち・半分の速さ・全員そろうキメ・しめのキメ のドラムの型 |

決まり: これは「使える素材」で、全曲に入れる決まりではない（曲ごとに選ぶ）。まだ入っていないもの: 声のピッチを機械的に動かす調声（ケロケロ声）、グリッチ（音を細かく刻んで巻き戻す効果）、サイドチェインの深いうねりの自動化。

## プロの音作り（2026-11-15 に調べて、部品にしたもの）

人間（2026-11-15）:「今の作り方に足りていないもの全て足して。あと、音の作り方も学んでプロ仕様にしてきて。」

### 調べて分かったこと

| 項目 | プロのやり方 | 作曲ソフトでの形 |
|---|---|---|
| スーパーソウの和音 | 少しずつ高さをずらしたノコギリ波を 7〜12 本重ねる。和音は 7th・9th・add9 などを使い、根音を低く、上の音を高く、2〜4 オクターブに広げる | `wide9()`（根音・5度・3度・7度・9度の5声）。5本のパートに分けて、高い音ほど左右に広げる |
| 和音の EQ | 150〜200Hz より下を切る。150Hz 付近のにごりと、2〜3kHz のきつさを少し抑える | `rack_supersaw()` |
| サイドチェイン | キック（または鳴らさないキック）に合わせて和音を凹ませる。比 3:1〜4:1、速い立ち上がり、戻りは拍の長さ | パートの `duck`（0.6）＋ 2拍で1往復する `syncfilter` |
| サブベース | 真ん中（モノラル）で根音だけ。和音の音をサブに入れると低音がにごる | `kfbSub` は根音だけ・pan 0 |
| 広がり | 低音は真ん中、和音とリードは広げる。高い音ほど広く | `widen`・`doubler`・パートごとの pan |
| うねり | 和音をどんどん変えるのでなく、音量とフィルターの動きで変化を作る。すき間を空ける（全部を埋めない） | `syncfilter`・リリースカット・止め |
| 場面の変わり目 | 上がる音（ライザー）・逆再生のシンバル・インパクト・サブドロップ | `fx_bar()`（kawaiiFx の鍵盤） |
| 歌の調声 | 子音の速さ（ベロシティ）・強弱・しゃくり。ハモリを重ねて厚くする（機械の声は同じ音を重ねても厚くならないので、ハモリやオクターブ下を使う） | `harmony()`（3度下・1オクターブ下）、`kero()`（ケロケロ声） |
| 歌のミックスの順番 | いらない音を取る（引くEQ・ディエッサー）→ コンプ → 音色のEQ → 空間（残響・ディレイ）→ 音量の自動化 | sing.py の eq・deess・dynamics・reverb（今の順番と同じ） |

### 足した部品（`vocalo_lib.py`）

`wide9`（広い和音）・`arp16`（16分のアルペジオ）・`glitch`（16分→32分→64分と細かくなるくり返し）・`tape_stop`（テープが止まるように音が落ちる）・`fx_bar`（上がる音・下がる音・インパクト・サブドロップ・レーザー）・`rack_supersaw`／`rack_bass`／`rack_pluck`／`rack_piano`／`rack_lead`（音作りのまとまり）・`kero`（ケロケロ声）

### まだできていないこと（正直に）

- シンセの音そのもの（kfb の音源）は作り直していない。今回はエフェクターの並び・和音の積み方・重ね方で詰めた
- ドラムにパラレルコンプをかける道がまだない（ドラムのパートには fx が効かない）
- 歌の「ダブリング」（同じ旋律を少しずらして重ねる）は、合成の声では同じ音になってしまうので未対応
- 数字は、解説記事の目安（記事自身が「目安であり、参考曲で確かめること」と書いている）。最後は耳で確かめてもらう必要がある

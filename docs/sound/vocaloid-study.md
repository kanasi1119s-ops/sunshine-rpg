# ボカロ曲の作り方の学習（DECO*27・Orangestar ほか）

2026-10-25 記録。人間「ボカロ曲で DECO*27 さんや Orangestar さんなどの作曲の仕方、音源などを学んで来て」。
4つの調査（DECO*27／Orangestar／ほかのボカロP 8人／音の作り方）をまとめた。
**メロディ・リフ・歌詞・音そのものは写さない（CLAUDE.md 1-1）。ここに残すのは、作り方の型と数値だけ。**
数値の多くは ChordWiki（有志の耳コピ）・KeyTube（自動解析）・音楽ゲームの公式BPM。細部は「傾向」として使う。
「推」は資料に数値がなく、こちらで決めた値（耳で詰める前提）。

## 1. 人ごとの作り方

### DECO*27
- 制作: 初期はドラムを先に打ち込み、ギターで弾き語って録り、あとから編曲。2017年以降は「詞メロ」のデモを作って Rockwell に編曲を任せ、ミックスは本人が全曲で行う。Rockwell はドラムに「わざと細かいズレ」を入れる（[Real Sound 2022](https://realsound.jp/2022/03/post-995598_2.html)・[iLOUD](https://futuregroove.jp/iloud/interview/deco27/)・[CINRA](https://www.cinra.net/article/interview-201906-deco27)）。
- 機材（まとめサイト。不確か）: Logic Pro・Pro Tools・Addictive Drums 2・Waves CLA・Effectrix（スタッター）・Axe-Fx（[機材図鑑](https://kizai-zukan.com/deco27/)）。モニターは Genelec（[Genelec](https://www.genelec.jp/references/deco27/)）。
- テンポ: 3つの帯。ハーフ／倍テン 95〜110（倍で 190〜220）・中速 125〜145・高速 160〜200（ヒバナ 200、ラビットホール 173、ヴァンパイア 164、モザイクロール 145、乙女解剖 134）。
- コード: Aメロは短調の2〜4個の循環（♭VI–V–i、i–♭III–♭VII–♭VI、i–♯iv°–V、i–♭VII–♭VI–♭II）。サビは平行調の長調で vi–IV–V–I–V/3（ベースが3度の分数コード）。短調でも長調の V を V/3 で入れる。静かな場面は 7th・add9。
- 転調: サビで +1・+2・短3度上に変える。最後のサビでさらに +1。半音ずつ2回上げる曲もある（ゴーストルール）。近年は転調なしで同じ循環を押し切る曲もある。
- 構成と強弱（ゴーストルールの形）: リフ → ギターとドラムだけ(p) → 全員(f) → サビ直前の1小節は「ベースとシンセだけ」 → サビ → 終わりはギターとピアノ(mp)。全員休み（N.C.）の止めを多く使う。
- 旋律: 曲全体で A3〜A5（約2オクターブ）。Aメロは低め（C4〜D5）。サビは同じリズムの短い句を2〜4回くり返し、最後を上がりか下がりで締める。同じ音の連打をフックにする（[cdhvn](http://cdhvn.com/archives/3971)）。
- 演出: Half feel の区間でパワーコードを半音ずつ下げる（ラビットホール）。最後のサビの前に全体にフィルターを掛けて開く（モニタリング）。耳を引く音を毎回変える（カウベル、オーケストラヒット、一瞬のワブルベース、生の弦を突然入れる）。終わりはテンションつきの短い和音で切る。
- 年代: ギターロック・ポップパンク（2008〜）→ ミクスチャー（GHOST 2016）→ Rockwell のギターのフック（2017〜）→ ダンスポップ（ヴァンパイア 2021）→ ラウド×エレクトロ（2024〜）。

### Orangestar
- 制作: Cubase。作詞から編曲・ミックスまで本人。ピアノとシンセが中心で、ギターはときどき（[Wikipedia](https://en.wikipedia.org/wiki/Orangestar)・[Real Sound 2015](https://realsound.jp/2015/05/post-3132_2.html)）。プラグイン名は一次情報なし。
- テンポ: 疾走 172〜185（アスノヨゾラ哨戒班 185、快晴 172）・中速 136〜158（Henceforth 158）・しっとり 120〜128。
- コード: 4つのコードの循環を1曲ずっと回す（IV–I–V–vi、vi–IV–V–I、vi–IV–I–V）。王道進行・丸サ進行は目立たない。ベースが下がる分数コード（vi–vi/5–I/3）。区切りの手前に、vi へ入る減三和音を1拍（vii°/vi）。
- 転調: 最後のサビで全音（+2）上げが最多。快晴は4回転調する。
- 旋律: 本人「メロディはいちばん聴かれる部分なので、わかりやすく、頭の中でイメージしやすいものに」。サビは高い音域で同じ句をくり返す。
- 音: ピアノで始まる・ピアノが主旋律を弾く曲が多い。夏の音（蝉など）を入れる。音を左右に動かす（イヤホンと蝉時雨）。「現実的な非現実世界」の静けさ。

### ほかのボカロP（[Real Sound の分析連載](https://realsound.jp/2020/09/post-613823_2.html) ほか）
- **wowaka**: 160〜222 の16分の4つ打ちロック。「16分＋16分休符＋16分＋付点8分休符」型のリフ。短調の i–♭VI–♭VII–v を使い回す。旋律は全曲 C4 以上・最高音 C6 以上で、高い音域に張りつく。本人「変拍子だから面白い、という発想は苦手」。
- **ハチ**: 短調で ♭VI–V–i（和声的短音階）。パンダヒーローはドラムだけで始まる。マトリョシカは Bメロで短3度上へ一時転調。
- **kemu**: 六兆年と一夜物語は、ゆっくりのピアノの前奏（約 80）から本編 186 へ約2.4倍に跳ぶ。リフは主和音の音でなくレやシ（2度・7度）から始める。マイナーペンタトニック。ギターを切り貼りしてぶつ切り（スタッター）に。
- **ピノキオピー**: 短い単純な循環に電子音。神っぽいなは間奏だけ 142→103 に落とし、属7の和音を半音ずつ上げる。曲ごとに情報量を「削る」こともする。
- **Ayase**: Logic Pro。生楽器を使わずソフトで再現（[GRAMMY.com](https://grammy.com/news/yoasobi-music-laptop-logic-pro-vocaloid-interview-video-it-goes-to-11)）。ピアノが主導、セブンス・m6 を多用、丸サ進行の変形。転調は2段（半音下げ→短3度上げ）。
- **n-buna**: ギター中心、長調・中速寄り。カノン系の進行、後半で半音上げ。
- **柊キライ**: 和音はそのままで、サビごとにリズムのジャンルを入れかえる（1サビは EDM のドロップ、2サビはジャージークラブ）。ワブルベースにギターを重ねる。オーケストラヒット。
- **いよわ**: 9/8・7/8 を一瞬だけ入れる。1拍の完全な無音。音域は3オクターブ（G#3〜G#6）。グリッドに合わせないリズム。意図的な不協和でもキャッチー。
- **cosMo@暴走P**: 初音ミクの消失は 150→240 で早口を詰め込む極端な例。

### ボカロ曲全体の傾向（研究）
- 2007〜2025年の人気曲1,900曲の分析: テンポは +2.3% とわずかだが、音の数 +6.4%・リズムの複雑さ +9.1%・コードの変わる速さ +8.0%。曲の長さは −6.8%。「速くなった」印象の正体は、音の詰め込みと複雑さ（[Lau 2026 情報処理学会](https://ipsj.ixsq.nii.ac.jp/records/2009796)）。
- 再生数との関係: テンポ 142〜179 がいちばん伸びやすく、179以上が次。最高音は F6 以上・C6〜F6 が伸びやすい（[南山大 卒業論文](https://www.st.nanzan-u.ac.jp/info/gr-thesis/2022/matsuda/19ss005.pdf)）。
- 「人間には歌いにくい旋律」: 歌い手が歌って確かめないので、急な跳躍・半音の細かい動き・早口・高い音が生まれやすい。声の表情が平らなぶん、編曲と音色に情報が集まる（Real Sound）。

## 2. 音の作り方
- よく使われる音源: Serum・Massive（Kai さんはほぼ全パートに Massive）・NI Komplete・EZdrummer 3・Neural DSP（[機材まとめ](https://scrapbox.io/musicstudyroom/%E3%83%9C%E3%82%AB%E3%83%ADP%E3%83%BB%E3%83%9F%E3%83%A5%E3%83%BC%E3%82%B8%E3%82%B7%E3%83%A3%E3%83%B3%E5%88%B6%E4%BD%9C%E7%92%B0%E5%A2%83%2F%E4%BD%BF%E7%94%A8%E6%A9%9F%E6%9D%90%E3%81%AE%E3%81%BE%E3%81%A8%E3%82%81)）。無料の代わりは Vital・Surge XT・Dexed。ピアノは今の Salamander（CC-BY）でよい。
- くじらさん（[サンレコ](https://www.snrec.jp/entry/special/softsynth_kujira)）: 派手なリードの1オクターブ下に、少しこもった同じ旋律を重ねる。リードが浮くときは下にピアノを重ねて芯を作る。サステインが長すぎて濁るときは絞る。
- 初音ミクの声（公式）: 得意な音域 A3〜E5、得意なテンポ 70〜150（[AV Watch](https://av.watch.impress.co.jp/docs/20070831/crypton.htm)）。150Hz より下はほとんど鳴っていない（非公式の目安）。
- 日本語の母音の響きの山（F1/F2 Hz）: い 400/2700・え 500/2200・あ 900/1800・お 500/1200・う 400/1200（[関西学院大 講義資料](https://ist.ksc.kwansei.ac.jp/~kawabata/lectures.d/spch/Spch-04.pdf)）。
- 歌声の音程の動き（[Saitou 2009](https://www.isca-archive.org/interspeech_2009/saitou09_interspeech.pdf)）: ビブラートはプロで 6.3Hz・幅 65cent。上がる音は目標を 11% 越えて約 126ms で戻る（オーバーシュート）。音を変える直前に逆へ約 10%・約 120ms 動く（プレパレーション）。VOCALOID の調声ではビブラートは小さめ（Slight）を、音の後半から掛けることが多い（[gihyo](https://gihyo.jp/lifestyle/serial/01/vocaloid/0002)）。
- プラック: 鳴り始めに約 20ms のピッチエンベロープ、オシレーターのずらしは 30cent 以内（[Cymatics](https://cymatics.fm/blogs/production/creating-plucks-xfer-serum)）。
- サイドチェイン: キックでベースとパッドを下げる。4:1・アタック 2〜5ms・リリース約 100ms（[Unison](https://unison.audio/side-chain-compression/)）。
- 音量の基準: ニコニコ −15 LUFS、YouTube 約 −14 LUFS。旭さんの標準 −13.5 LUFS のままでよい。

## 3. 作曲ソフトで使う決まり（ボカロ曲のインスト）

### テンポと拍子
1. テンポは4つの型から選ぶ。高速ロック 175〜210（wowaka・ハチ・ヒバナ）／疾走ピアノ 165〜185（Orangestar）／中速ダンス 125〜150（DECO*27・Ayase）／ハーフ 95〜110（スネアは倍の 190〜220 で取る）。
2. アルバム全体で、142以上の曲を7割以上にする。
3. 曲の中でテンポを変えるのは1〜2回まで（前奏だけゆっくりのピアノ→本編で倍以上、間奏だけ ×0.7 に落とす、など）。
4. 3/4・6/8 の Bメロは3割の曲まで。7/8・9/8 はサビの前後の1〜2小節だけ（変拍子そのものを目的にしない）。

### コード
5. Aメロは短調の2〜4個の循環から選ぶ: ♭VI–V–i／i–♭III–♭VII–♭VI／i–♯iv°–V／i–♭VII–♭VI–♭II／i–♭VI–♭VII–v。
6. サビは平行調の長調に開く: vi–IV–V–I–V/3、IV–I–V–vi、vi–IV–I–V、IVM7–III7–vi–v（丸サの変形）。
7. 定番だけにしない: 曲ごとに最低1か所、副属和音・増三和音・♭II・属7の半音の連鎖・vi へ入る1拍の減三和音のどれかを入れる。
8. ベースは分数コードで順に動かす（V/3、vi–vi/5–I/3）。
9. ピアノ主導の曲は和音の4割以上を M7・7・9・m6 に。ロック型は三和音・sus4・パワーコード。
10. 転調は、サビで変える（+1・+2・短3度上）／最後のサビで +1 か +2／半音ずつ2回上げる／2段（半音下げ→短3度上げ）のどれか。直前に1拍のブレイクを置く。転調しない曲もアルバムに2割入れる。

### 歌の役（シンセのリード）の旋律
11. 音域: 曲全体で2〜2.5オクターブ（シンセなので A3〜C6 を中心に、いちばん高い音は D6 まで）。Aメロは低め（C4〜D5）、サビはそれより5〜7度高くする。
12. 密度: 高速曲の Aメロは16分を6〜8割。サビは8分を中心に、付点と休符で開放感を出す（密度の差で強弱をつける）。
13. 食い: 拍の頭の16分前から入る音を、1小節に1〜2か所。
14. サビのフック: 1〜2拍の同じリズムの短い句を2〜4回くり返し、最後の2小節を上がりか下がりで締める。同じ音を2〜3回連打する形を1か所以上。
15. 跳躍: サビの音程の動きの15〜25%を5度以上に。オクターブの跳躍は1つの句に1回まで。半音の経過音は1小節に1〜2回まで。
16. ボカロらしい「歌いにくさ」: 早口の16分、急な跳躍、高い音のつなぎを、1曲に少なくとも1か所はっきり入れる。
17. 既存の曲の旋律に似せない（音程の並び4つが同じになったら書き直す）。

### 歌の役のシンセの音（声のように聞こえるリード）
18. 元の音: 矩形波（デューティ 25〜50%）とパルス波の重ね。のこぎり波だけの音は避ける（この曲集で PQ が約 0.4 下がった）。
19. 声の響き: ピーキング EQ で「あ」の F1（約 900Hz）を +6dB・F2（約 1800Hz）を +4dB、Q は 4〜6。2.8〜3.2kHz を +3dB（歌い手の明るさ）。ハイパス 150Hz。
20. 音程の動き: 3度以上の跳躍のときだけポルタメント 40〜80ms。上がる音は目標を少し越えて約 120ms で戻す。ビブラートは長い音の後半（音の長さの 40% より後）だけ、5.5〜6Hz・±20〜30cent。いきなり深く掛けない（「ゴム」に聞こえる）。
21. 重ね: 1オクターブ下に、ローパス 2kHz に絞った同じ旋律を −8〜−10dB で重ねる。浮くときはピアノを下に重ねる。
22. 刺さり対策: 耳に痛い山は狭い Q で −6dB。5〜8kHz は必要に応じて −2〜−4dB。

### 伴奏・構成
23. 主旋律の受け渡し: サビはリード、2番の Aメロはピアノ、間奏はギターかシンセのソロ、のように最低3種類を回す。
24. 合いの手: 歌がないぶん、各場面に最低1つ、ピアノ・ギター・オーケストラヒットなどの合いの手を入れる。ただし「削る」場面も作る。
25. 強弱の地図（DECO*27 の形を見本に、物語で崩す）: 2パートだけ → 全員 → Aメロで減らす → サビ直前の1小節は「ベースとシンセだけ」 → サビ → 間奏で下げる → 最後のサビ → 終わり。
26. 止め: サビの前や場面の終わりに、全員休みを半小節〜1小節。1曲に2〜4回。1曲に1回は1拍の完全な無音。
27. サビごとにリズムの型を変えてよい（1サビは4つ打ち→2サビはジャージークラブやハーフ）。和声はそのまま（柊キライ型）。
28. Half feel の区間を、間奏か2番のあとに8〜16小節。パワーコードを半音ずつ下げる形も使える。
29. 最後のサビの前の4〜8小節で、全体のローパスを約 800Hz から閉じ、サビの頭で一気に開く。
30. 耳を引く音を1曲に2〜3個、曲ごとに変える（カウベル、オーケストラヒット、一瞬のワブルベース、生の弦を突然入れる、スタッター、逆再生、夏の環境音など）。
31. 始まり方は、ドラムだけ／ピアノだけ（ゆっくり）／いきなりリフ／短いサビ、などから選び、前の曲と重ねない。終わり方も、テンションつきの短い和音で切る／ピアノだけ残す／フェードアウト、などから変える。
32. ピアノ: 疾走系は右手16分の分散和音・左手8分のオクターブ。ギター: 歌の役とぶつからない D3〜D5 に、覚えやすいリフを1つ。
33. ドラム: タイミング ±5〜12ms・強さ ±8 の揺れ、ゴースト、シンバルは伸ばす。サイドチェインはキック→ベースとパッド（4:1・3ms・100ms）。

### 曲の長さ
34. ボカロ曲の近年は3分前後と短いが、この依頼は 4:00〜5:00。1番・2番・Cメロ・最後のサビに、間奏と Half feel・転調を足して長さを作る（同じ場面をただくり返さない）。

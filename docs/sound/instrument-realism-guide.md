# 楽器ごとのリアルな打ち込み（奏法・表情・音域）（2026-10-11 調査）

作曲ソフトで書く曲を「本物の人が弾いたように」聞こえさせるための手引き。楽器ごとに、(1) 本当に出る音域と出ない音、(2) その楽器らしい奏法、(3) うちの記法での書き方、(4) 打ち込みで起きがちな失敗、をまとめた。

- ネットの解説・音楽事典・奏者の掲示板（文末の35件）を調べ、**文章は写さず、数字と考え方だけを借りて**うちの記法に書き直した。
- 数字の読み方: **「出」**＝記事に数字や事実がある。**「補」**＝記事に無く、一般的な楽器の知識や複数の記事の傾向から置いた目安。どれも出発点で、最後は耳で決める。
- 既存曲の再現手順は書かない（CLAUDE.md 1-1）。例の音名・リズムは、練習用に作った短い型である。
- 既存文書との分担: 奏法の記号の一覧は `craft-guides.md` §13、ギターの音作りは `guitar-tone-basics.md`、ベースの型は `bassline-guide.md`、ドラムの型は `drum-genre-guide.md`、帯域は `sound-design-basics.md`。ここは**「奏者が実際にできること・できないこと」と「それをうちの記法に置き換える方法」**を足す。

---

## 1. 要点（先に読む）

1. **1つのパートは1度に1音しか鳴らせない**（`notes` に同時発音の書き方が無い。実装は `parseNotes`）。和音は**パートを分けて**書く。1曲16パートまでなので、ギターの6本の弦を6パートで書くことはできない。**「根音・5度・上の3度」の3〜4パート**に絞るのが現実的。
2. **音域は検査されない**。実装が見ているのは MIDI 12〜108（C0〜C8）だけ（`parseNotes`）。`AI_INSTRUMENTS` の「E2〜E5」などは**案内であって制限ではない**。楽器の「出ない音」を書いても警告が出ないので、書く側が §5 の表で確かめる。
3. **人の演奏との一番の違いは「息」と「手の数」**。管楽器は息継ぎ、弦楽器は弓の返し、ギターは指と弦の本数、ピアノは手の幅、ドラムは手足4本、ハープは片手4本。**物理的にありえない重なりを書かない**だけで、リアルさが一段上がる。
4. **「強さ」は拍の位置で変える**。拍頭を強く（`!`）、裏を弱く（`,`）、フレーズの頭と終わりを引く（`phrase`）。全部同じ強さが、打ち込みっぽさの最大の原因。
5. **音のつなぎ方を使い分ける**。つなぐ（`_`、レガート）・切る（`'`、スタッカート）・伸ばす（`sustain`）の3つを楽器ごとに決める。弦とブラスは長く、ピッツィカート・ハープの跳ね・カリンバは短く／自然減衰に任せる。
6. **揺れ（ビブラート・ベンド・しゃくり）は「長い音の山場」だけ**。毎音に付けると歌えていない演奏になる。
7. **ピアノはペダルがソフト側で固定**（4拍ごとに踏み替え。`midi-export.ts` 237行以降）。コードの変わり目と合わないとにごる／スタッカートがペダルで伸びる、の2つに気をつける（§3・§6）。
8. **タイミングは `push`**（−0.1〜+0.1拍、パート単位）。ストロークの弦ずらしは 0.015〜0.03 拍ずつ。キックとベースは 0。

## 2. うちの記法の早見（この文書で使う道具）

| 道具 | 内容 | 実装での値・制限 |
|---|---|---|
| `notes` | `音名:拍` を空白でつなぐ。`R` は休み。短いと**曲の長さまでくり返して埋める** | 音名は MIDI 12〜108 のみ検査 |
| `!` / `,` | 強く（×1.3）／弱く（×0.7） | `parseNotes` |
| `'` | スタッカート。音の長さ（gate）を 0.4 倍 | |
| `_` | レガート。gate 1.15 倍（次の音に少し重なる） | 音ごとの gate は `sustain` より優先される |
| `~` / `~~` | ビブラート（深さ 0.7／1.0）。0.4拍以上の音で効く | 音の頭から少し（最大0.4拍）遅れて揺れ始める |
| `^` `^^`… | ベンドアップ（1つ＝半音、最大4）。0.125拍未満の音には付かない | 音の頭から最大0.5拍かけて到達 |
| `/` `//`… | しゃくり（下から入る。最大4半音）。入りは最大0.3拍 | `autoScoop`: リード/ギターの1拍以上の音には自動でも付く（止めるなら `autoScoop:false`） |
| `\` `\\`… | フォール（終わり30%で落とす） | |
| `sustain` | パート全体の音の伸び 0.2〜3 | ドラムには使わない |
| `phrase` | フレーズの山の強弱（2〜32拍） | |
| `push` | パートのタイミング −0.1〜+0.1拍 | **ミリ秒＝ 60000÷bpm × push**。bpm120で 0.02拍＝10ms |
| `human` | 0〜1。タイミング・強さ・長さ・音程（±8セント）のずれ | 0.3〜0.6 が自然 |
| `volume` / `pan` | 0.1〜0.35 / −1〜1 | 合計は 0.7 前後まで（歪みギター2本＋ドラム＋ベースの場合） |
| ドラム | `x` 普通、`X` 強（×1.3）、`o` 弱（×0.5）、`O` オープンハット、`g:x...` 16分グリッド | タムだけ音名（A2〜C4）で高さを選べる |
| 音源の割り当て | `lead`＝フルート（GM73）、`pad`＝合唱（GM52）、`keys`＝エレピにピアノを薄く重ね、`harp`＝GM46、`koto`＝GM107 など（`gm-map.ts`）。`synth:true` で lead/pad はシンセ | 名前と音色が違うものに注意 |
| 自動で付くもの | 歪みギター／クランチに**1オクターブ下を薄く重ねる**（音が E1 以上になる場合）。ベースは rock 以外の tone で B1 以上に1オクターブ下を薄く重ねる。lead・leadGuitar・bell・keys・cowbell は**0.4拍以上の音に付点8分・付点4分のエコー**が付く | `midi-export.ts` 395行付近。エコーは和音の掛け合わせで音が増えて聞こえるので、速い動きには不向き |
| ピアノ・エレピのペダル | **4拍ごとに自動で踏み替える**（拍子に関係なく。コード進行とは無関係） | 237行付近 |

## 3. 楽器別の表

凡例: 音域は**実音**（音名は C4＝中央のド）。「うちの案内」は `AI_INSTRUMENTS` の書き方。範囲を出たときの音は保証されない。

### 3.1 ギター系（guitar・crunch・distGuitar・leadGuitar・echoGuitar）

標準チューニングの弦: E2・A2・D3・G3・B3・E4（6弦→1弦）。**E2 より低い音は出ない**（ドロップDなら D2）。フレット22〜24で、1弦の最高は D6〜E6（補。出）。

| 項目 | 内容 |
|---|---|
| 実用音域 | 出る: E2〜E6（24フレット）。安全: E2〜E5（歪み刻みは E2〜E4。高いフレットはピックアップの音が細くなる補） |
| うちの案内 | guitar／crunch E2〜E5、distGuitar E2〜E4、leadGuitar／echoGuitar E3〜E6 |
| 同時に鳴らせる数 | **最大6音（1弦に1音）**。押さえる指は4本まで。ふつうは**4フレット以内**に収まる形（バレーで6音が1フレットに揃う） |
| 奏法 | ストローク（ダウン／アップ）、アルペジオ、ブラッシング（ミュートした刷り）、パームミュート、ハンマリング・プルオフ、スライド、チョーキング、ビブラート、ハーモニクス、タッピング |
| 書き方 | §4 に詳しく。ストローク＝複数パート＋`push`、パームミュート＝`'`、ハンマリング／プルオフ＝短い音を`_`、チョーク＝`^`、ビブラート＝`~` |
| リアルにするコツ | 低音弦はジャーンと**下から上へ**ずらして鳴らす。ダウンは強く弦を多く、アップは弱く高い弦だけ（出）。ハンマリング／プルオフの2音目は**弱く**（ピックの打撃が無い）。ベンドは**1〜3弦**で全音が基本（低音弦でのチョーキングは難しい補）。同じ音の連打は強さを変える。刻みは低い開放弦 |
| 失敗例 | E2 より下を書く／6音以上を同時に鳴らす／12フレットも離れた2音を同じ弦で連続で速く（指が間に合わない）／毎音にビブラート／ストロークで全弦が同時に鳴る（ずれが0） |

### 3.2 ベース系（bass・slap・sub808）

4弦ベースは E1・A1・D2・G2（ギターの1オクターブ下。出）。5弦は低い B0 を足す（出）。

| 項目 | bass（指・ピック） | slap | sub808 |
|---|---|---|---|
| 実用音域 | E1〜G3（高いフレットは細い補） | E1〜G3。親指（低）と、はじく（1オクターブ上）を行き来 | C1〜C3。**低すぎる音は再生機器で出ない**（小さなスピーカーは約40〜60Hz以下が出ない。出） |
| 奏法 | 指弾き（丸い）、ピック（硬い）、ゴースト、スライド、ハンマリング、ミュート | サム、プル（ポップ）、ゴースト（出） | 長く伸ばす／ピッチを滑らせる |
| 書き方 | 指＝普通／`_`、ピック＝`'`と`!`、ゴースト＝`,'`、スライド＝`/`か`\`、ハンマリング＝短い音を`_` | サム＝`!`（低）、プル＝`'`（オクターブ上）、ゴースト＝`,'` | 長い音＋`sustain` 1.5〜3 |
| リアルにするコツ | **キックの位置に合わせ、少し遅れるくらい**（キックより先走らない。出）。キックと同時の拍に強い音、フィルは軽く（出）。長さをそろえず隙間を作る（出） | ゴーストは「ドラムの第2パート」のように休符の位置に（出）。シンコペを大事に（出） | キックの位置に合わせ、長い音の頭に `!` |
| 失敗例 | 全音を同じ長さ・同じ強さで8分連打／和音を弾く（1パートで）／B0 より下／キックとずれる／スライドの代わりに音が飛ぶ | ゴーストなしで高低だけ交互 | C1 より低い（聞こえない） |

### 3.3 ピアノ系（piano・keys・harpsichord）

| 項目 | piano | keys（エレピ。ピアノを薄く重ねる） | harpsichord |
|---|---|---|---|
| 実用音域 | A0〜C8（88鍵）。旋律は C4〜C6、左手は C2〜C4（補） | C2〜C6 | 出る範囲はおよそ F1〜F6（補）。うちの案内 C2〜C6 |
| 同時に鳴らせる数 | 両手で最大10音。**1つの手は約1オクターブ（10度まで）**（補） | 同 | 同（チェンバロは1段だと音が薄い） |
| 奏法 | ペダル、アルペジオ、両手の役割分担、トップノート（一番上の音）の旋律、グレースノート | 同。柔らかく丸い | 強弱が付かない（出）。アクセントは音の長さと装飾音で |
| 書き方 | 左手パート（根音＋5度）と右手パート（和音を2〜3パートに分ける）。旋律に`!`、伴奏に`,` | 同 | `!`と`,`は**あまり効かせない**（実際の楽器は強弱がほぼ無い）。装飾音（0.125拍）と音の長さで表情 |
| リアルにするコツ | **和音は同時に鳴らさず、低い音から高い音へ少しずらす**（出。真ん中の音を拍にそろえる）。ペダルは**コードの変わり目で一瞬離す**（出）。強さを全体に下げる（出）。**左手の根音、右手の親指（真ん中）が強すぎないようにする**（出） | 同 | 同じ強さの8分で、音と音の間に空白を作る（補） |
| 失敗例 | 全音が同じ強さ／全部量子化して和音が同時／ペダル無しで音が途切れる／ペダルのコード切り替わりが遅くにごる／右手の和音が12度以上の開き | | 強弱を付けたピアノのような演奏 |

**うち固有の注意**: ペダルが4拍ごとに自動のため、(a) 1コードが1小節なら理想どおり。(b) 1コード2小節だと途中で一度離れて音が切れる／1小節に2コードだと前のコードの音が後ろへ残る。(c) `'` スタッカートの音も、ペダルで鳴り続ける（音が短くならない）。スタッカートのピアノは**ペダルのせいで短くならない**と覚え、短い刻みには `sustain` を 0.3〜0.5 にして、さらに `R` を入れて区切る。

### 3.4 弦楽器（strings）

| 項目 | 内容 |
|---|---|
| 実用音域 | ヴァイオリン G3〜E7（独奏）。**セクションの実用は G3〜E6**（出・補）。ヴィオラ C3〜C6（出）／実用は E5 まで（補）。チェロ C2〜E5（出）。コントラバス E1〜B3（出）／実用は G3 まで（補）。うちの案内は C2〜C7 を1パートで |
| 高い音の扱い | 上の音域は「**無理がある、細い**」音になる。下の半分に寄せる（出） |
| 奏法 | レガート（旋律）、サスティン（和音の土台）、スタッカート／スピッカート（推進力）、ピッツィカート、トレモロ、マルカート、ディヴィジ（パートを分ける）、グリッサンド |
| 書き方 | 旋律＝`_`でレガート、土台＝長い音＋`sustain` 1.5、スタッカート＝`'`、ピッツィカート＝`'`＋`sustain` 0.3＋弱く、トレモロ＝同じ音を 0.125〜0.25拍でくり返し、マルカート＝`!`＋短め |
| パートの分け方 | **上から ヴァイオリン1・ヴァイオリン2・ヴィオラ・チェロ**（出）。コントラバスはチェロの1オクターブ下（出）。うちは `pan` でも分ける（左：ヴァイオリン、右：チェロなど） |
| リアルにするコツ | **レガートの音と音を少し重ねる**（出。数tick〜10〜20tick）。重要な旋律だけレガートにし、内声は長い音でよい（出）。**同じ旋律をコピーして移調しない**（別パートとして書き分ける。出）。内声に8分の脈動を持たせて、低弦だけ長く伸ばすと豊かになる（出）。強さは拍頭を強く（約95）、アウフタクトを弱く（約55）（出）。立ち上がりが遅いので、他の楽器と合わせるために**20〜40ms 前へ**ずらす（出。`push` は −0.05 前後） |
| 失敗例 | 音と音の間に隙間があって「弦のパッド」のよう（出）／全部レガート（出）／ピッツィカートを長い音で／全員が高音域／ヴァイオリン〜コントラバスの全音域を1パートで書く（人の手に収まらない音の並び）／1小節中ずっと同じ強さ |

### 3.7 和楽器・民族楽器

### 4.1 コードフォーム（開放弦。1つのパートが1音だけなので、パートに分けて使う）

| G | 320003 | G2 B2 D3 G3 B3 G4 | G2 / D3 / B3 / G4 |
| Am | x02210 | A2 E3 A3 C4 E4 | A2 / E3 / A3 / C4 |
| Em | 022000 | E2 B2 E3 G3 B3 E4 | E2 / B2 / G3 / E4 |
| D | xx0232 | D3 A3 D4 F#4 | D3 / A3 / D4 / F#4 |
| Dm | xx0231 | D3 A3 D4 F4 | D3 / A3 / D4 / F4 |
| E | 022100 | E2 B2 E3 G#3 B3 E4 | E2 / B2 / G#3 / E4 |
| A | x02220 | A2 E3 A3 C#4 E4 | A2 / E3 / A3 / C#4 |
| F（バレー） | 133211 | F2 C3 F3 A3 C4 F4 | F2 / C3 / A3 / F4 |
| G7 | 320001 | G2 B2 D3 G3 B3 F4 | G2 / D3 / B3 / F4 |
| パワーコード（歪み） | 根音＋5度（＋オクターブ） | 例 E2 B2 E3 | 2パートで十分（`amp`で歪み） |

押さえられる形かの目安（補）: 指は4本、1つの弦に1音、**4フレット以内**。開放弦を使うと簡単。ジャンプの大きいコード進行（例: G から F# への移動）は、**バレーコードで平行移動**する。

### 4.2 ストローク（ダウン・アップ。ずらし方）

1. **パートを低い弦から高い弦の順に分け、`push` を段階的に増やす**（下向きに弾いた感じ）。1弦あたり 0.015〜0.03拍（bpm120で 7〜15ms。補）。
2. **ダウンは弦を多く強く、アップは高い方の弦だけ弱く**（出：弦の数を変えて強弱を出す方法）。低いパートは**アップのときは休符**。
3. 同じ強さの連打にしない。拍頭`!`、裏は`,`。
4. ダウンとアップの音は少し重ねる（出）。`sustain` 1.3〜1.8。
5. ミュート気味の刻み（チャカチャカ）は、短い音（`'`、`sustain` を下げる）で（出：短いストロークで代用できる）。

**例（C、4/4、「ダウン ダウン アップ（休み）アップ ダウン アップ」。8分グリッド）**

```
部品1（低・push 0）     C3:0.5! R:0.5 C3:0.5 R:1.5 C3:0.5 R:0.5
部品2（中・push 0.02）  G3:0.5! R:0.5 G3:0.5 R:1.5 G3:0.5 R:0.5
部品3（高・push 0.04）  C4:0.5! R:0.5 C4:0.5 C4:0.5, R:0.5 C4:0.5, C4:0.5 C4:0.5,
部品4（最高・push 0.06）E4:0.5! R:0.5 E4:0.5 E4:0.5, R:0.5 E4:0.5, E4:0.5 E4:0.5,
共通: instrument guitar、sustain 1.5、volume 0.07〜0.1、pan は同じ（左右に振るなら −0.4 / +0.4 の2本）
```
（合計は4拍。曲の長さまでくり返す。コードが変わる所は音名を書き換えた新しい型を並べる。）

### 4.6 弦と指板の制約（まとめ）

- 最低音 E2。**それより下は書かない**（ドロップチューニングの曲だけ D2 まで）。
- **1つの弦に同時に1音**。同じ弦で2音を同時に書かない（例: 同時に G3 と B3 は別の弦。同じ弦で A3 と C4 は不可）。
- 左手の幅は 4フレットが目安。**6フレット以上離れた2音の素早い連続は、弦を変える**か、ゆっくりにする（補）。
- 開放弦の音（E2 A2 D3 G3 B3 E4）は、鳴りがよく刻みの基本。
- チョーキングは1〜3弦（高い弦）。低い弦では軽く半音まで（補）。
- ハーモニクスは5・7・12フレット付近（出）。5フレットより低い位置は弱い（出）。
- 歪みギターの低いパワーコードは、強調のため1オクターブ下が自動で薄く重なる（うちの実装。E2 なら E1 が重なる）。重ねすぎに注意。

## 6. ピアノ・弦の書き方の型（22個）

どれも**短い型**で、曲の長さまでくり返す（`notes` が短いと自動でくり返される）。コードが変わる所は、音名を書き換えて並べる。ハ長調（C）、4/4拍子、1小節=4拍で書いてある。**パート名**は `role` の例、記法の末尾に、おすすめの `sustain` と `volume` を付けた。

### ピアノ（P1〜P11）

## 7. よくある失敗と直し方

| # | 失敗（聞こえ方） | 原因 | 直し方 |
|---|---|---|---|
| 1 | 全部がデジタルっぽい | 全音が同じ強さ・同じ長さ | 拍頭`!`、裏`,`、`'`と`_`を混ぜる。`phrase`、`human` 0.3〜0.5 |
| 2 | ギターの和音が一発で「ボン」 | すべての弦が同じ瞬間 | パートを分けて`push`を 0.015〜0.03 ずつ |
| 3 | ギターの刻みが「ピピピ」 | 単音を短く切りすぎ | 開放弦の低音＋`sustain`、休符で区切る（`guitar-tone-basics.md`） |
| 4 | ギターが高音で細い | 24フレット近く | E5 以下に |
| 5 | ベースがキックとずれて濁る | 先走り／離れた音 | キックの位置に合わせ、`push` 0 以上 |
| 6 | ピアノが「ガチャ」 | 和音が量子化されて同時 | 低い音から順に`push`を 0.01〜0.02 |
| 7 | ピアノが途中で切れる／にごる | ペダルが4拍固定 | コードを1小節に1つ（または4拍の整数倍）にそろえる。変わり目に`R`を置く |
| 8 | ピアノのスタッカートが短くならない | ペダルで伸びる | 短い刻みは休符を足して区切る |
| 9 | 弦が「パッド」に聞こえる | 隙間のない長い音・全部レガート | 音を少し重ね、内声に動きを。ピッツィカートやスタッカートを混ぜる |
| 10 | 弦のコピーが機械的 | 旋律を移調コピーした | 別パートとして書き直し、数tick／`push`を変える |
| 11 | ブラスが吹きっぱなし | 息継ぎが無い | 4〜8小節ごとに休符。長い音は頭`!`で終わりを弱く |

| 13 | 笛が速すぎて不自然 | 16分の連打 | オカリナ・尺八は8分以下、休符を入れる |

| 15 | 琴が全音階で明るくなる | 平調子の弦に無い音 | 弦の音を中心に、押し手の音は少なく |

| 17 | バグパイプにダイナミクスがある | 実物は強弱が付かない | `!`と`,`を使わず、装飾音で区切る |
| 18 | ドラムが同時に5音以上 | 手足4本を超える | キック・スネア・ハイハット＋1つに |

| 20 | 毎音にビブラート／ベンド | 乱用 | 山場の1〜2音だけ |
| 21 | 歪みギターが割れる | volume が大きい／音域が高い | 0.05〜0.12、音域を E4 以下 |
| 22 | エコー付き楽器（lead・bell・keys）が速い旋律で濁る | 自動エコー（付点8分・付点4分） | 速い動きは別の楽器か`patch`で |

## 8. チェックリスト

書き終えたら、次を見る。

1. **音域**: 各パートの最低音・最高音が、§5 の「出る」範囲に入っているか（特に shakuhachi D4、guitar E2、bass E1、brass の下限）。
2. **同時発音**: 同じ楽器の同時の音の数が、ギター6・ハープ8・ピアノ10・ドラム4を超えないか。
3. **1パート1音**: 和音をパートに分けたか。16パートに収まるか。
4. **息**: 管楽器・尺八・合唱に4〜8小節ごとの休符があるか。
5. **強さ**: 拍頭と裏で強さが違うか。全部`X`／全部無印になっていないか。
6. **つなぎ**: レガート（`_`）・スタッカート（`'`）・伸ばし（`sustain`）が楽器の性格に合っているか。
7. **揺れ**: ビブラート・ベンド・しゃくりは、山場だけか。
8. **ストローク**: 和音の弦がずれているか（`push` 0.015〜0.03 刻み）。アップは弱く高い弦だけか。
9. **ベース**: キックと合っているか。ゴーストは休符の位置か。
10. **ピアノ**: コードの変わり目が4拍の区切りにそろっているか。左手と右手の役割が分かれているか。
11. **弦**: 旋律は別パートで書いたか（移調コピーでないか）。内声に動きがあるか。低弦が土台を担っているか。
12. **ドラム**: 1小節のループをそのまま繰り返していないか。フィルは弱い方の手が弱いか。クラッシュの拍にハイハットを休んだか。
13. **和楽器**: 琴・三味線は弦の音（調弦）に沿っているか。尺八は五音中心か。バグパイプに強弱を付けていないか。
14. **エコー**: lead・leadGuitar・bell・keys の速い旋律にエコーが重なって濁っていないか。
15. **ペダルとスタッカート**: ピアノ／エレピのスタッカートは休符で区切ったか。
16. **音量**: 全パートの合計が 0.7 前後までか。

## 9. 取り入れる提案（実装可能な単位）

どれも、実装前に短い実験で確かめる。優先度は上ほど高い。

1. **音域チェック（`instrument-range.ts` ＋ `song.mjs gate`）**: 楽器ごとに `{ hard: [最低, 最高], safe: [最低, 最高] }` の表を作り（§5）、`parseNotes` のあとで各パートの最低音・最高音を調べる。`hard` を出たら**警告（小節番号つき）**、`safe` を出たら**注意**。出力例: 「shakuhachi: C4 は出ません（最低 D4）」。テストを `ai-song.test.ts` に足す。
2. **和楽器・民族楽器の音階チェック**: koto は平調子（D・G・A・B♭・D・E♭…）、shakuhachi は五音（D F G A C）を基準に、外れる音の割合（例: 20% 以上）を警告する。外れる音は「押し手／メリで作る音」として `^` `/` が付いているものは許す。
3. **同時発音チェック（`voices`）**: 同じ楽器グループ（例: 役割名が「ギター」で始まるパート）で、同時に鳴る音の数が、ギター6・ハープ8・ピアノ10を超えたら警告。さらに、ギターは同じ弦（音の高さの近さ）に2音あたらないか簡易に見る。ドラムは5音以上の同時発音を警告（クラッシュ＋閉じたハイハットは個別に警告）。
4. **息継ぎチェックと自動ブレス（`breath`）**: lead・brass・choir・shakuhachi・ocarina・panflute の連続して鳴る長さを**秒**で測り、10秒（目安）を超えたら警告。`breath:true` で、フレーズ終わりの音を 0.25拍短くして息継ぎの隙間を自動で作る。
5. **奏法の自動付与（`autoArticulation`）**: 楽器ごとの小さなルールを、`seed` つきで自動に付ける（決定的）。
   - guitar／leadGuitar／strings／brass／lead: 1.5拍以上の音の**フレーズの最後の音だけ**に`~`。
   - strings の旋律: 順次進行（2度）で続く音に`_`を自動で付ける。内声は付けない。
   - guitar: ハンマリング／プルオフ（上行・下行の短い2音）の2音目を弱く`,`＋`_`。
   - slap: 拍頭に`!`、オクターブ上の音に`'`。
   - ピアノ・ハープ: 和音の中の最高音に`!`（旋律扱い）。
6. **ストローク生成（`strum`）**: `parts[].strum = { chords: "C G Am F", pattern: "D.DU.UDU", spreadMs: 12, strings: 5 }` のように書くと、**コードフォーム表（§4.1）**から音を決め、内部で3〜5パートに分けて`push`を付ける。アップは高い3弦＋弱く。**この変換は `prepareSong` の中で行うため、8パートの上限に数えない**ようにする（隠しパート）。
7. **ピアノのペダルをコード追従に（`pedal: "chord" | "bar" | "none"`）**: 今は4拍固定。コード進行の変わり目（`song-plan` の情報）でペダルを離して踏み直す。`pedal:"none"` にするとスタッカートが短くなる。
8. **弦・管楽器の立ち上がり補正（`attack`）**: 弦・パッド・合唱は前へ 20〜40ms、ブラス・木管は 0〜30ms（出）。まず、音源（soundfont）の立ち上がりを `analyze.py` で測って、ずらす値を決める実験。
9. **ドラムの手足制約チェックと利き手（`drum-limbs`）**: 同時に4つまで、速い16分・32分のフィルの**弱い方の手**（交互に）を 5〜25 弱める（`X`→`x`、`x`→`o`）、フラム（装飾音0.125拍）を自動で付ける選択肢。
10. **楽器の追加と奏法プリセット**: オルガン（GM16〜20。強弱が付かない楽器として、`!`を無効化）、トランペット／フルート／オーボエ／クラリネットの個別楽器、ピッツィカート専用（短い・弱いが標準）、ミュートギターを `AI_INSTRUMENTS` に足し、`sound-sets.ts` に「指ベース」「ピックベース」「ピッツィカート」「ストロークギター」の`PartMix`セット（`sustain`・`push`・`phrase`・`bright`・`reverb`）を作る。今 `steelGuitar`・`mutedGuitar` は録音音源に無くてピアノになるので、先に音源を確認する。

| 5 | 奏法の自動付与 | **入れた** | `src/audio/articulation.ts`。フレーズ終わりの長い音に `~`、strings の旋律に `_`、guitar のハンマー／プル（seed で 50%）、slap の拍頭 `!`・オクターブ上 `'`、ピアノ・ハープの最高音 `!`（`accentTopNotes`）。パートの `autoArticulation`、または曲全体の `autoArticulation: true`。決定的（seed） |
| 6 | ストローク生成 | **入れた** | パートの `strum: { chords, pattern, spreadMs, strings }`。`part-expand.ts`（オープンコードのフォーム表、重複する音名を先に間引く、960 ticks/拍、弦ごとのずれ、音量は 1/√本数）。パターンは `D d U u x . -` |
| 7 | ペダルをコード追従に | **入れた** | パートの `pedal: "chord" \| "bar" \| "none"`。MIDI の CC64 を書く（`midi-export.ts` の `track.pedal`）。指定なしは従来の 4 拍ごとのまま |
| 8 | 立ち上がり補正（attack） | 一部 | パートの `attack`・`release`（CC73／CC72）と、`detune`（RPN 1）を MIDI に書く。**音源に効くかは耳と `analyze.py` で未確認**。数値の決め方（楽器ごとの前倒しの ms）は実験が要る |
| 9 | ドラムの手足制約（drum-limbs） | **入れなかった** | ドラムの記法とヒューマナイズの内部に踏み込む。リズム担当の作業と重なるので任せた |
| 10 | 楽器の追加 | 一部 | `drawbarOrgan`（GM16）を追加（`synth-voices.ts`、`synth-sfx-guide.md` §11 参照）。トランペット／フルートなどの個別楽器とピッツィカート専用は**未**（サウンドフォントの切り出し直しが要る） |

あわせて、第1ラウンドの積み残しを入れた: **doubleDetune**（`doubleDetune: { cents, pan }` で 2 パートに分け、左右に振って RPN 1 でずらす）、**echo**（`echo: { beats, decay, repeats }` で音符を複製。`shift` を使う）、**ADSR 近似**（上の `attack`・`release`）、**コード表記** `5`・`m7-5`・`mmaj7`（`newsong.ts` の `QUALITY`）。**アンプの箱（cab）を既存の役割に当て直す**ことは**やらなかった**: 既存の曲の音が変わるうえ、`amp-sim-guide.md` に「耳と 1/3 オクターブ分析で別に決める」とあるため。

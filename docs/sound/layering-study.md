# 音の重ね方の勉強ノート（山下達郎さんの作り方から学ぶ）

2026-10-28、旭さんの提案で調べた。目的は「笛が主役のまま、音数が多く繊細で、深みのある重ね方」を、ケルト・フルート100曲「銀の笛と百の夜」に取り入れること。
**まねるのは考え方だけ。** 特定の曲のメロディ・コード進行・アレンジをそのまま使うことはしない（CLAUDE.md 1-1）。

## 調べて分かったこと

### 和音（ハーモニー）
- 3和音のままにせず、**テンション（9th・11th など）を足して響きを複雑にする**。ジャズやソウルの響きをポップスに持ち込んだ。
- **sus4（7sus4(9)）** で、明るくも暗くもない浮遊感を出す。
- **低い位置に9thを置く**と、部分的に半音でぶつかる所ができるが、全体では調和し、切なさと奥行きになる。
- **maj7 と 6 を行き来させ、いちばん上の音（トップ・ノート）だけを全音で動かす**。6th は経過音として使い、maj7 と交互にして「緊張と緩和」を作る。
- マイナーに **11th や 9th** を足すと、暗さがやわらぐ（マイナー感をぼかす）。
- **クリシェ**：和音の中の1音だけが、一音ずつ動いていく。
- いちばん大事な点：**ハーモニーは複雑でも、メロディは歌いやすく**保つ。

### 重ね方（多重録音）
- 楽器もコーラスも**一人で何度も重ねる**。重ねるほど「均整のとれた」厚みとまとまりが出る。
- **ハモらずに全員が同じ音（ユニゾン）** で歌う所を作り、場面の力を出す。
- コール＆レスポンス（掛け合い）。
- ハンドベルなどの色づけの音。

### 音域と、ミックスを見越したアレンジ
- **和音の楽器が中音域を埋めすぎない**ようにする（主役の通り道をあける）。
- ミックスやマスタリングを**最初から見越して**アレンジする。
- 音圧を不自然に上げない。極端なEQをしない。**高い音は丸く、中音域は厚く**。

### リズム・タイミング
- 打ち込みは基本的に**ジャスト（グリッドどおり）**。
- 揺らすなら**一律にずらさない**（それは「ただズレている」だけ）。ずらすなら幅とランダムさを持たせる。
- ギターのカッティング：弾いて止めるを正確にくり返し、止めたときに雑音を出さない。
- バラードでも、低音（キック）がどこに入るかを細かく詰める。

## 「銀の笛と百の夜」への取り入れ方
| 学んだこと | この曲集での形 |
|---|---|
| テンションで響きを複雑に、メロディは素直に | 伴奏の和音（弦・パッド・竪琴・ギター）だけを m9・maj9・add9・6 などにする。笛の旋律は今までどおり素直に |
| maj7↔6 でトップ・ノートを動かす／クリシェ | 「内声の動き」パート：弦の1本が、和音の中で一音ずつ下がる・上がる |
| 一人で何度も重ねる | 主旋律の笛を2本重ねる（一律にずらさず、1音ずつ少しランダムにずらす）。山場は和声の笛2本を重ねて3声に |
| ユニゾン | 山場の一部は、和声をやめて笛を同じ音で重ねる |
| 中音域を埋めすぎない | 和声の笛が鳴る所では、弦の持続を小さくする。ギター・ピチカートは小さく左右に |
| ジャスト＋ランダム | ギター・ピチカート・竪琴はグリッドどおり。重ねの笛だけ、1音ごとにランダムな小さなずれ |
| 高い音は丸く、中音域は厚く | 笛の高い音はやわらかく（既にある）。チェロ・低い弦で中低域を支える |

## 0. 先に読む：10行まとめと、既存文書へのつっこみ

### 0-1. 全ジャンル共通の「合わせ方」の法則

| # | 法則 | 理由 |
|---|---|---|
| 1 | **キックとベースは「一つの楽器」として設計する。** 先にキックの位置を決め、ベースはその位置に合わせるか、わざと空ける。 | 低音の帯域（キック約60〜100Hz、ベース約40〜200Hz）は重なる。バラバラに動くと低音が濁る |
| 2 | **ジャンルの「決め手」は1つだけ。** ファンクは16分の隙間、ディスコは4つ打ち＋裏のオープンハイハット、モータウンはスネアの4拍打ち、レゲエは3拍目、ブルースは三連のシャッフル。他の楽器はその決め手を邪魔しない。 | 全部を主役にすると、どのジャンルにも聞こえない |
| 3 | **ギターは「音域の高い・短い・左右どちらか」で居場所を作る。** 低音は100〜120Hz以下を切り、ベースに譲る。 | 重なる帯域を減らすのが、ミックスの基本 |
| 4 | **「かっちり」と「ゆるい」は、ジャンルで決める。** ディスコ・J-POPは機械のようにそろえる（human 低め）。ソウル・ブルース・カントリーは人間らしくずらす（human 高め＋swing）。 | 時間のずれは5〜10msが効く。20msを超えると「ずれた」と感じる |
| 5 | **コード楽器は、歌が入るところで引く。** 歌のない小節で厚くし、歌のある小節で薄くする。 | 全ジャンルの定番 |
| 6 | **「ジャンルの音色」より先に「リズムの位置」。** アンプ名より、どの拍にどの楽器が鳴るかで決まる。 | この調査で最も一貫していた点 |
| 7 | **パーカッション不在は、ハイハットとギターのミュートで補う。** このソフトにタンバリン・シェイカー・クラップはない。 | 該当ジャンル：ソウル、ディスコ、フォーク、レゲエ |
| 8 | **ミュートは「ひとかたまり」で掛ける。** 通常奏のすぐ後に急にミュートを混ぜると、旭さんの禁止事項に触れる。ミュートのカッティングは、曲の区間（セクション）全体で通す。 | memory の好み |
| 9 | **クリーンギターに chorus は掛けない（chorus: 0）。** シティポップ・AOR のコーラス感は、2本のギターを左右に置く・リバーブで作る。 | memory の好み |
| 10 | **音量バランスはミキサーの仕事。** 曲側で volume を足し合わせて0.9を超えないようにし、細かい調整は後に回す。 | lint の警告が出る |

### 0-2. 既存文書への「つっこみ」（ギャップ・矛盾・まちがい候補）

| # | 場所 | 指摘 | 対策案 |
|---|---|---|---|
| A | skank（スカンク）のプリセット | `ring` が既定で「次の打ち込みまで鳴り続ける」ため、スカ／レゲエの**短い裏打ち**が長く伸びる。見本では `ring:false` が必要 | `STRUM_PRESETS.skank` に `ring:false` を既定で持たせる。または guide に「レゲエは ring:false」と明記 |
| B | ハイハットの自動オープン化 | 16分の「ア」の閉じハイハットのうち約14%が自動でオープンになる。**ファンク・ディスコの閉じ16分で意図しない開きが出る** | 指定したジャンルでは `human` を0.95以上にして止めるか、自動オープンを切る指定を用意する |
| C | クラッシュとライドの同じパート | シンバルの長さは「同じパートの次の音まで」。クラッシュとライドを同じパートに混ぜると、ライドが途中で切れる（またはその逆） | 必ず別パートにする。guide に太字で書く |
| D | `t:`（三連）グリッド | 4/4の1小節は**12文字**。11や13文字だと組み立てが止まる。見本を書く人がよく間違える | guide の例に「12文字」を数字つきで再掲 |
| E | パーカッション楽器 | タンバリン・シェイカー・クラップ・カウベルがない。ソウル／ディスコ／ラテン系で**穴**になる | 追加を提案（小さな音源でよい）。当面は、スネアのゴースト・ハイハットの強弱で代用 |
| F | ブラス | 音域が G2〜Bb4 に制限される。ファンク／ディスコ／スカのホーンで「高い合いの手」を書くと lint 警告 | ホーンは1オクターブ下げて書く。または `patch: brassSection` と音域の解説を guide に追加 |
| G | ベースの音域 | E1〜G3。ファンクの低いD（D1）は書けない（見本で修正した）。ドロップDの曲にはD1が欲しい | 5弦ベース（B0〜）を入れるか、音域を D1 まで広げる |
| H | レゲエ／ダブ | ドラムの `drum-genre-guide` に「ワンドロップ」はあるが、**ルーツ（ベースが主役）、ロッカーズ、ステッパーズの区別**がない。資料の間でも定義がずれる（0-3） | 区別を決めて書いておく（レゲエ節に表を置いた） |
| I | 「ミュートを混ぜない」との整合 | ファンクの funk-cut は4弦パートに展開され、**ミュートが16分ごとに混ざる**。旭さんの禁止（通常奏のあとの急なミュート）に当たるか、ファンクでは別扱いか、不明 | ファンクは「ジャンル特性として許可」と decisions.md に残すのがよい。人間に確認 |

### 0-3. 資料間で割れていた点（どちらを採るか）

| 論点 | 資料A | 資料B | この文書での採用 |
|---|---|---|---|
| ステッパーズ／ロッカーズ | キック4つ打ち＝ステッパーズ、キック全拍＋3拍目スネア＝ロッカーズ | ロッカーズ＝キックを全拍に入れる（資料により定義がやや違う） | **「キックの数」で区別する。** ワンドロップ（3拍目だけ）／ロッカーズ（全拍キック＋3拍目スネア）／ステッパーズ（4つ打ち、速め）。確度：中 |
| ベースとキックの関係（ソウル） | 揃える | あえてずらして「ため」を作る | モータウン＝ベースが動いてキックと逆を埋める。スタックス＝ほとんど揃える。**ジャンルで決める** |
| ローカット位置 | ギター100Hz | ギター120Hz | **100〜120Hz** のどちらでも可。ベースが目立たない曲は120Hz。これは書き出しの後のミキサーの話 |

## 2. ポップス／ポップロック

### 2-1. ドラム
- 基本は 8ビート：キック1・（2の裏）・3、スネア2・4、ハイハット8分。ここは `drum-patterns.md` と同じ。
- **ポップスの「決め手」は、セクションごとの密度の違い。** Aメロはハイハットを閉じて小さく（またはサイドスティック風のスネア）、Bメロでハイハットを8分に、サビでクラッシュと16分のキックを足す。
- フィルは、セクションの最後の1拍〜1小節だけ。毎回入れない。
- サビ頭にクラッシュ（C2）を1回。ライド（D2）はAメロやブリッジで使うと音の質感が変わる。**クラッシュとライドは別パートに分ける**（0-2 C）。

| 場面 | ハイハット | スネア | キック |
|---|---|---|---|
| Aメロ | 8分、小さく／または閉じ4分 | 2・4（弱め）またはサイドスティック | 1・3、たまに「3の裏」 |
| Bメロ | 8分、頭を強く | 2・4 | 1・2の裏・3 |
| サビ | 8分または16分、開きを混ぜる | 2・4（強く） | 1・2の裏・3・4の裏 |
| 間奏 | 8分 | 2・4 | 少なめ |

### 2-2. ベース
- 根音の8分刻み（サビ）と、根音の長い音（Aメロ）を使い分ける。
- **キックの位置に合わせる。**見本の lint では「キック20回のうちベースも鳴る 60%」前後が自然。100%にすると堅く、30%以下だと散らかる。
- コードが変わる直前の1拍に、次の根音へ向かう経過音（半音下か上）を置くと、進行がなめらかになる。

### 2-3. ギター
- **アコギのストローク（2本目）＋エレキのコード**で壁を作るのがポップロックの王道。アコギは左、エレキは右。
- エレキは Aメロで 4分のパワーコード、サビで 8分刻み（または開放弦を混ぜた響き）。
- 歪みは「crunch 止まり」（禁止事項：歪ませすぎない、リードに crunch を使わない）。リードは `lead` 系の別アンプを選ぶ。

### 2-4. 合わせ方
| 項目 | 目安 |
|---|---|
| ドラム | キックとスネアが中心、ハイハットは左へ少し |
| ベース | 0。キックの位置に合わせる |
| 左右 | アコギ左（-0.5）／エレキ右（+0.5）／キーボードは小さく反対側 |
| 密度 | サビで2〜3パートを足し、AメロでPadを外す |
| human | 0.3前後（少しだけ人間らしく） |

### 2-5. 失敗と対策
| 失敗 | 原因 | 対策 |
|---|---|---|
| サビなのに薄い | 全セクション同じ編成 | `sections` で2本目のギターとストリングスをサビだけ入れる |
| Aメロからうるさい | ハイハット16分＋歪み | Aメロを4分ハイハット、ギターはクリーンのアルペジオに |
| ベースが聞こえない | ギターが低音まで鳴っている | ギターを100〜120Hz以下で切る／コードの最低音をE2より上に |
| 単調 | コード4種のくり返し | 最後の繰り返しで転調、またはブリッジに別進行 |

### 2-6. 作曲ソフトでの書き方
- `autoAccompaniment:false` にして、ドラムは `g:` で書く。
- `sections` を作って、`parts[].sections` で出し入れする（`{"intro":0,"verse":0.6,"chorus":1}`）。
- 検証済みの形は、5節のモータウンの見本を8ビートに直して使える（スネアを2・4だけにする）。

## 3. J-POP／J-ROCK（バンドサウンド、アニソン系、シティポップ）

> 既存の `jpop-clean-guitar-guide.md`（クリーンギター）と `jpop-structure-guide.md`（構成）に深く書いてあるため、ここは**バンド全体の合わせ方**に絞る。

### 3-1. ドラム
- **J-ROCK／アニソン：** 8ビートの中で、サビ頭の前に必ず1小節のフィルまたは1拍の空白（ブレイク）がある。サビはハイハットをオープンにして「開く」感じを出す。
- 16分のハイハット＋キックの細かい刻み（BPM 150〜190）が多い。速い曲ではハイハットは8分に落として、キックを16分で刻む。
- **シティポップ：** 16分のハイハット＋ゴーストノート入りのスネア＋動くスラップ寄りのベース。ファンクの「引き算」版で、ドラムはきれいにそろえる。swing は 0.1〜0.2。
- 曲の終わりは、Cメロのあとの「大サビ」で一度ドラムを抜き、最後のサビで全部戻す、が定番（確度：中、構成は `jpop-structure-guide.md` にもある）。

### 3-2. ベース
- J-ROCK：ピック弾きの8分刻み。ピックのアタックが明るい。ギターのリフと**同じ音**を弾くところと、離れるところを作る。
- アニソン：サビでベースが歌のメロディの下を**対旋律**で動く。
- シティポップ：スラップ（`slap`、amp `funk`）。オクターブ跳び＋ゴースト（短い休み）。見本では F1:0.75! R:0.25 F1:0.5, F2:0.5' のように、**アクセントと休符**で書いた。
- 音域：E1〜G3。4弦で収まる。

### 3-3. ギター
- **ギター2本が基本。**左：コードの刻み（歪みは crunch まで）、右：アルペジオまたはリード。
- シティポップ：クリーンのカッティング（funk-cut）。**chorus は掛けない。**空間は reverb と、キーボード側のコーラスで作る（キーボードにはコーラスを掛けてよい）。
- アニソン：サビ前にギターソロの短い断片（1〜2小節）。

### 3-4. 合わせ方
| 項目 | J-ROCK／アニソン | シティポップ |
|---|---|---|
| BPM | 140〜190 | 100〜120 |
| ドラム | 8ビート＋サビでオープン | 16分ハット＋ゴースト |
| ベース | ピック8分 | スラップ＋休符 |
| ギター | 歪み2本＋ソロ | クリーンのカッティング |
| 鍵盤 | ピアノ（サビの壁） | エレピ＋シンセ |
| human | 0.2〜0.3 | 0.3 |
| swing | 0 | 0.1〜0.2 |

### 3-5. 失敗と対策
| 失敗 | 原因 | 対策 |
|---|---|---|
| 歌が埋もれる | ギター2本とキーボードが同じ帯域 | キーボードを高めの音域に、ギターは中域をカット |
| ずっと同じ強さ | サビだけが強くない | AメロBメロでドラムとギターをS字に弱める |
| シティポップなのに野暮ったい | ベースが根音の8分のみ | オクターブ＋ゴースト（休符）を入れる |
| ブラスが高すぎる | G2〜Bb4の制限を超える | 1オクターブ下げて書く |

### 3-6. 作曲ソフトでの書き方（検証済み：シティポップ）
- `bpm:108`、`swing:0.15`、キック `g:X.....x...x.....` など。
- スラップ：`{"instrument":"slap","amp":"funk","sustain":0.9,"notes":"F1:0.75! R:0.25 F1:0.5, F2:0.5' R:0.25 C2:0.25 F1:0.5 R:0.5 ..."}`
- ギター：`{"instrument":"guitar","amp":"crystal","chorus":0,"strum":{"pattern":"funk-cut"}}`
- ブラス：`"patch":"brassSection"` を指定し、**音域は G2〜Bb4 以内**に。
- 警告が3つ出た（ブラスが高い／volume合計0.97／pan の偏り）。合計は0.9以下に、右側のパートは減らす。

## 4. ファンク

### 4-1. ドラム
- **決め手：1拍目（"the one"）の強さと、16分の中の隙間。**キックは1拍目を必ず打ち、残りは「ジグソーパズルのように」ベースと噛み合わせる。
- ハイハット：16分連打。**頭を強く、間の音を小さく**（見本は `XoxoxoxoXoxoxoxO`）。開いた音は1小節に1回程度。
- スネア：2・4に強い音、その前後に弱いゴースト（`o`）。ゴーストは音量を大きく下げる（本体の約3割）。
- ゴーストが強いと、ただの「うるさい16分」になる。**2・4が「ガッ」と立ち、間が「さわさわ」と聞こえる**差が命。
- テンポ：95〜110（重い）、115〜125（軽いファンク）。swing 0.1〜0.2（見本は 0.2）。

### 4-2. ベース
- **1拍目を伸ばしすぎない。**1拍目を強く短く弾き、そのあと**休符**を作る。「音を弾くこと」より「休むこと」で乗せる。
- 16分の休符（R:0.25）と、短い音（スタッカート `'`）が主役。
- ドラムのキックと**同じ位置**と**違う位置**を半々にする。見本の lint はキックとベースの重なりが約6割で、ほどよい。
- 低いEのオクターブ上（E2）にポンと跳ぶ「ポップ」が定番。

### 4-3. ギター
- **短く切るカッティング（funk-cut）。**1小節中に16分で細かく刻み、ミュートした音（ザッ）を混ぜる。
- 高い弦（上の3〜4本）だけ。低音弦はベースに譲る。
- 歪みなし（`crystal` などのクリーン）。**chorus は掛けない。**ワウは作曲ソフトにない。
- ギターは右、キーボード（クラビ風の音）は左。

### 4-4. 合わせ方
| 要素 | 動き |
|---|---|
| 1拍目 | 全員が「そろう」。ここだけは必ず合わせる |
| 2・4拍 | スネアだけが強い。ギターは弱める |
| 16分の裏 | ギターとハイハットが細かく、ベースは休む |
| ブレイク | 1小節ごとに全員が止まって、ドラムだけ（または無音）→1拍目に全員で戻る |

> **ジグソーの原則**：キック・ベース・ギターの3つが「同時に鳴る場所」と「だれかだけが鳴る場所」を決める。全員が16分で動くと、ただのノイズになる。

### 4-5. 失敗と対策
| 失敗 | 原因 | 対策 |
|---|---|---|
| ずっと忙しい | 全パートが16分で動く | ギターを2拍に1回の短い刻みに、キーボードは合いの手だけ |
| 重く聞こえない | swing=0 で human も低い | swing 0.15〜0.2、human 0.35〜0.4 |
| ハイハットが勝手に開く | 自動オープン化（0-2 B） | 見本のとおり `O` を自分で置き、human の設定を確認 |
| 低音のD1が書けない | ベースの音域 E1 まで | D2 に上げるか、曲のキーをEに |
| ギターのミュートが「急に消える」と感じる | funk-cut は常にミュートが混ざる | ファンクは例外として扱う（0-2 I） |

### 4-6. 作曲ソフトでの書き方（検証済み）
```
bpm 102 / chords "Em7 Em7 A7 Em7" / feel rock / swing 0.2 / human 0.4
kick   g:X.x.......x..... g:X.x.....x.x..... g:X.x.......x..x.. g:X...x.....x.....
snare  g:o..oX..o.o.X..o  g:o..oX..o...X.o.  g:o..oX..o.o.X..o  g:o..oX..o.o.X.oX
hihat  g:XoxoxoxoXoxoxoxO ...（push:-0.01）
bass   E1:0.5! R:0.25 E1:0.25, E2:0.5' E1:0.5 R:0.25 G1:0.25, A1:0.5 B1:0.5 R:0.5 ...
guitar strum {"pattern":"funk-cut"}  amp crystal  chorus 0  pan 0.45
keys   合いの手だけ（R:4 R:2 G4:0.5 B4:0.25, R:1.25 ...）
```
- スネアの `push:0.02` は「少し後ろにため」る指定。ファンクは前のめりにしない。
- 実際の曲の構造メモ（確度：中、メロディは書かない）：
  - 「Superstition」型：ドラムの16分ハイハット＋クラビ風のリフ。ベースは**リフと同じ形**で重ねる。サビでホーンが入る。
  - 「Le Freak」型（シックの系統）：4つ打ちに近いが、ギターの16分カッティングが主役で、ベースはオクターブで跳ねる。ファンクとディスコの境目。

## 5. R&B／ソウル／モータウン

### 5-1. ドラム
| 流派 | 特徴 | 決め手 |
|---|---|---|
| **モータウン** | スネアが**4拍とも**鳴る（フォー・オン・ザ・スネア）、またはタンバリン風に2・4を強調。ハイハット8分。キックは動く。 | 全員がきれいにそろう。「かっちり」だが軽く弾む（swing 0.1） |
| **スタックス（メンフィス）** | 後ろにため、音数が少ない。スネアは2・4、キックはまばら。 | 「間」が長い。ブラスの短い合いの手 |
| **ディープ・ソウル／バラード調** | 12/8（三連×4）。スネアは各拍の3つ目。 | `t:` グリッド（12文字） |
| **現代R&B** | 16分ハイハット、キックが少ない、スネアは2・4。 | テンポ70〜90、隙間が多い |

### 5-2. ベース
- モータウン：**常に動く。**根音→3度→5度→6度のような、メロディのようなライン。キックとは違う位置を埋める。
- スタックス：少ない音を長く（スタッカートより長め）。1拍目と3拍目の根音。
- 現代R&B：サブベース（低い）寄り。このソフトではベースの `sustain` を長くして、音域を E1〜A1 に。

### 5-3. ギター
- **モータウン：**2・4の短い「チャッ」とした和音（3本弦、アップ弦）。見本は `strum:{"pattern":"-D-D","step":1,"strings":3,"ring":false,"spreadMs":5}`。`ring:false` が肝（長く伸ばすと、ただのコードになる）。
- **スタックス：**細く尖ったクリーン（crystal）。ブルース的な短いフレーズ。
- **R&B：**クリーンの8分アルペジオまたは逆アルペジオ。
- ギターは歪ませない。

### 5-4. 合わせ方
| 要素 | モータウン | スタックス | 現代R&B |
|---|---|---|---|
| BPM | 100〜130 | 80〜100 | 70〜90 |
| swing | 0.1 | 0.15〜0.2 | 0〜0.15 |
| human | 0.35 | 0.4 | 0.2 |
| ベース | 常に動く | 少なく長く | 低く伸ばす |
| ギター | 2・4の短い刻み | 短い合いの手 | アルペジオ |
| 鍵盤 | エレピの8分 | オルガンの長い音 | エレピ・パッド |
| 管 | ホーンの合いの手 | 短いホーン | なし |
| パーカッション | タンバリン（**ない**） | なし | クラップ（**ない**） |

### 5-5. 失敗と対策
| 失敗 | 原因 | 対策 |
|---|---|---|
| ギターがボヤける | ring ありで伸びる | `ring:false`、sustain 0.5 |
| ベースがメロディを邪魔する | 動きすぎ | 歌の合間（歌のない拍）に動かす |
| スタックスなのに忙しい | 音が多い | 4小節に1回しか動かないくらいに |
| タンバリンがない | 楽器がない | スネアのゴースト（`o`）とハイハット8分の強弱で代用 |

### 5-6. 作曲ソフトでの書き方（検証済み：モータウン）
```
bpm 112 / chords "C Am F G" / swing 0.1 / human 0.35
kick   g:X.........x...x.  g:X.......x.x...x.  ...
snare  g:x...X...x...X...  （push 0.015）
hihat  g:X.x.X.x.X.x.X.x.
bass   C2:1! E2:0.5 G2:0.5 A2:0.5 G2:0.5 E2:0.5 D2:0.5 ...  （sustain 1.1）
guitar strum {"pattern":"-D-D","step":1,"strings":3,"ring":false,"spreadMs":5} amp crystal chorus 0 pan 0.45
keys   エレピの8分の和音 pan -0.35
```
- スネアの `x...X...`（頭は弱い、裏拍は強い）で、4拍とも鳴りながら2・4が強くなる。
- 12/8 のバラードは `t:` グリッドで書く。1小節＝12文字（3文字で1拍）。例：キック `t:X.....X.....`（1・3拍目の頭）はちょうど12文字。11や13文字だと組み立てが止まる。
- 構造メモ（確度：中）：モータウンの曲は、**イントロにベースとドラムだけが入り、2小節後にギターと鍵盤、ブラス・弦が段々と重なる**型が多い。

## 6. ディスコ

### 6-1. ドラム
- **決め手：4つ打ち（キック全拍）＋ハイハットの「裏拍のオープン」。**キック1・2・3・4、スネア2・4、ハイハットは裏の8分でオープン。
- 見本：`g:x.O.x.O.x.O.x.O.`（ハイハット）。
- テンポ：115〜125（120が標準）。human 低め（0.2）、swing 0。**機械のようにそろえる。**
- 16分のハイハットを足すと、ファンク寄りのディスコ（Le Freak 型）になる。
- クラップ（手拍子）が2・4に重なるのが定番だが、このソフトにはない。スネアで代用する（reverb 少し足す）。

### 6-2. ベース
- **オクターブ奏法：**G1-G2-G1-G2 のように、低い音と1オクターブ上を8分で交互に。
- ドラムのキックが毎拍あるため、ベースは**裏拍で動く**（キックを避けて動くのが肝）。
- 音は少し長め（sustain 0.9）。スタッカートにしない。
- 音域：E1〜G3。ディスコは G が多く、音域に収まる。

### 6-3. ギター
- **funk-cut のカッティング。**クリーン、chorus 0、右側（0.4）。
- 16分の「チャカチャカ」でハイハットと一緒に動く。コード音は上の3本だけ。
- 歪み系はない。

### 6-4. 合わせ方
| 要素 | 動き |
|---|---|
| キック | 毎拍（強く） |
| スネア（＋クラップ代用） | 2・4 |
| ハイハット | 裏拍オープン |
| ベース | オクターブの8分（裏拍に重い） |
| ギター | 16分のカッティング（右） |
| ストリングス | 長い音とグリッサンド風の上昇（左） |
| ブラス | 短い合いの手（G2〜Bb4の範囲） |

### 6-5. 失敗と対策
| 失敗 | 原因 | 対策 |
|---|---|---|
| ベースとキックがぶつかって濁る | 同じ位置で低音が重なる | ベースのオクターブ下の音を弱める（`,`）／ベースを裏拍の強調に |
| ずっと同じで飽きる | 4つ打ち一定 | 8小節ごとにキックを抜く（ブレイク）、または4小節目にフィルを |
| ホーンが高すぎる | 音域制限 | 1オクターブ下げる |
| ハイハットが眠い | 開閉の差が小さい | `O`を使う、`x` を小さく |

### 6-6. 作曲ソフトでの書き方（検証済み）
```
bpm 118 / chords "Gm7 Cm7 F7 Bbmaj7" / swing 0 / human 0.2
kick  g:X...X...X...X...
snare g:....X.......X...
hihat g:x.O.x.O.x.O.x.O.
bass  G1:0.5! G2:0.5 G1:0.5 G2:0.5 G1:0.5! G2:0.5 G1:0.5 F2:0.5 ...（sustain 0.9）
guitar funk-cut / crystal / chorus 0 / pan 0.4
strings D4:4 G4:4 A4:4 D5:4 ... （pan -0.3, reverb 0.3, sustain 1.6）
```
- 構造メモ（確度：中）：ディスコの定番は、イントロでドラムとベースが先に入り、**ブレイク後に全員が戻る**。ストリングスは上昇する音形で盛り上げる。
- 失敗しやすい点：ライドを 8分の裏に置くと「ハイハットのオープン」と役割が重なる。どちらかだけに。

## 7. AOR／ソフトロック

### 7-1. ドラム
- **決め手：ハーフタイム・シャッフル。**スネアは**3拍目だけ**に落とし（遅く、広く聞こえる）、ハイハットは三連のシャッフル（16分三連の1つ目と3つ目）。
- 真ん中の三連音に**ゴースト**（`o`）を入れる。これがシャッフルの「ふくらみ」を作る。
- キックは1拍目＋3拍目の少し後ろ。三連の中の位置で動かす。
- テンポ：80〜100。`t:` グリッドで書く（1小節12文字）。
- 資料の例（Rosanna 型の説明。確度：中）：ゴーストが真ん中の三連に並ぶのが特徴。曲の細部は耳で確かめていない。

### 7-2. ベース
- キックに**寄り添う**：キックの位置と同じ音を弾き、次の音は三連の最後に跳ねて次の拍へつなぐ。
- 長い音（2.667拍）と短い音（0.333拍）の対（ダッタ、ダッ）が三連の乗り方。
- ベースの音はまろやかに（amp auto）。スラップは使わない（それはシティポップ）。

### 7-3. ギター
- クリーンのアルペジオ（sparkleClean）。**chorus 0**。コーラスは掛けない代わりに reverb（0.3）で奥行きを作る。
- もう1本が使えるなら、右側に細いオブリガート（短い返し）を足す。
- ソロは歪みなしのサスティーン長めの音（lead 系 amp）。**crunch は使わない。**

### 7-4. 合わせ方
| 要素 | 動き |
|---|---|
| ドラム | 3拍目スネア＋三連ハット（ゴースト付き） |
| ベース | 長い音＋三連の短い音 |
| エレピ | 長い和音（pan 0.35） |
| ギター | アルペジオ（pan -0.4） |
| パッド | ストリングス風の長音（pan 0） |
| 歌 | 中央。AORは歌の下にコーラス（ハモリ）を厚く |

### 7-5. 失敗と対策
| 失敗 | 原因 | 対策 |
|---|---|---|
| `t:` が通らない | 11・13文字になっている | 数え直して12文字に |
| シャッフルが走る | swing と `t:` を二重に掛けた | `t:` を使うなら swing 0 |
| 重くならない | スネアが2・4のまま | 3拍目だけにして、BPMを落とす |
| 眠くなる | 全パートが長い音 | ドラムのゴーストとギターの分散を細かく |

### 7-6. 作曲ソフトでの書き方（検証済み）
```
bpm 86 / chords "Am7 Dm7 G7 Cmaj7" / swing 0（t:を使うので） / human 0.3
kick  t:X.....X..X.. t:X.....X..... （どちらも12文字）
snare t:.o..o.Xo.o.. （12文字。3拍目に本打ち、三連の真ん中に o）
hihat t:XxxXxxXxxXxx
bass  A1:2.667! E2:0.333 A1:0.667 C2:0.333 D2:3 F2:1 ...
guitar amp sparkleClean / chorus 0 / reverb 0.3 / sustain 1.8
keys  C4:4 A3:4 ... / pad E4:8 D4:8 ...
```
- 最初は11文字で書いてしまい組み立てが止まった。末尾に `.` を足して12文字にして通った。
- 構造メモ（確度：中）：AORは**イントロが長め**、Aメロ・Bメロで編成を小さくして、サビでコーラスの厚みを増やす。ソロの前に1小節の無音に近い間を置くことがある。

## 8. バラード（ロックバラード・パワーバラード）

### 8-1. ドラム
- **決め手：ダイナミクスの階段。**Aメロ＝ドラムなし、またはハイハット・サイドスティックだけ。Bメロ＝キック1・3とハイハット4分。サビ＝スネア2・4＋クラッシュ。最後のサビ＝フィルとシンバルが増える。
- テンポ：60〜80。6/8 や12/8 のとき、`t:` グリッド（12文字）。
- フィルは、サビの前の**1拍〜1小節**。タムを下に降りる動き（ミ→ド→ラ のようなタム）が定番。具体の音名は `drum-fills.md` を参照。
- 余韻を作るため、サビ頭にクラッシュ（C2）、終わりにもう1枚（G2：クラッシュ2）。

### 8-2. ベース
- Aメロ：根音の全音符、または2分音符。
- サビ：8分刻みに変わり、**サビに入る直前に半拍の休み**を置くと盛り上がる。
- ギターのアルペジオの最低音と**同じ音**を弾かない（かさなるため）。ギターは根音を避け、ベースが根音を担当。

### 8-3. ギター
- Aメロ：クリーンのアルペジオ（chorus 0）。
- サビ：歪みのパワーコード（crunch まで）＋アコギのストローク。
- ソロ：サスティーンの長い音、ビブラート（`~`）、ベンド（`^`）。**短い「ピ、ピ」は使わない**（禁止）。

### 8-4. 合わせ方
| 区間 | ドラム | ベース | ギター | 鍵盤・弦 |
|---|---|---|---|---|
| イントロ | なし | なし | アルペジオ | ピアノ |
| Aメロ | ハイハットのみ | 全音符 | アルペジオ | 薄いパッド |
| Bメロ | キック＋ハット4分 | 2分音符 | アルペジオ＋細い和音 | ストリングス |
| サビ | 2・4＋クラッシュ | 8分 | 歪み＋アコギ | ストリングス全開 |
| 間奏／ソロ | 同サビ | 8分 | ソロ | ピアノ |
| 最後のサビ | フィル追加 | 8分＋高い音 | 歪み＋もう1本 | 全開 |

### 8-5. 失敗と対策
| 失敗 | 原因 | 対策 |
|---|---|---|
| 最初から盛り上がる | Aメロから同じ編成 | `sections` で段階を分ける（intro:0, verse:0.5, chorus:1） |
| 感動が来ない | 最後のサビが一つ前と同じ | 転調（半音〜全音上げ）またはドラムの手数を増やす |
| ベースがギターと衝突 | 同じ音域 | ギターを3弦以上のアルペジオ（高い弦）に |
| 歪みが粗い | 歪みすぎ | `crunch` まで。それ以上は禁止 |

### 8-6. 作曲ソフトでの書き方（案：未検証。構造は検証済みの `sections` の書き方による）
```
"sections":[{"name":"intro","bars":4},{"name":"verse","bars":8},{"name":"chorus","bars":8}, ...]
drums:  parts[].sections {"intro":0,"verse":0.4,"chorus":1}
guitar2（歪み）: sections {"intro":0,"verse":0,"chorus":1}
strings: sections {"verse":0.6,"chorus":1}
```
- 書き方の詳細は `song.mjs guide` の sections の項を見る（`scene` でも可）。
- 転調はコード列で書く。最後の繰り返しだけ半音上のコードに。

## 9. フォーク／カントリー／アメリカーナ

> この節は検索の上限に達する前に集めた資料が少なめです。**確度：中。**

### 9-1. ドラム
- フォーク：ほとんど鳴らさない。ブラシ（ほうき）風の柔らかさ。このソフトにブラシはないので、**サイドスティック風の小さなスネア**＋ハイハット4分で代用。
- カントリー：**トレイン・ビート**（スネアが16分で連続、キックが各拍）と、**ブーン・チャッ**（キック1・3、スネア2・4）。BPM 100〜160。
- アメリカーナ：行進曲のような2拍子（キック1、スネア2）や、静かなフロアタムだけ。

### 9-2. ベース
- カントリー：1拍目と3拍目に**根音と5度**（C-G）。2ビート。
- フォーク：ウッドベース風の太く短い音（`'` スタッカート）。
- アップライトの音は amp で近いものを選ぶ（ベースの種類は `bassline-guide.md` 参照）。

### 9-3. ギター
- **アコースティックが主役。**ストローク（folk6／pop）と、ブーン・チャッ（ベース音→和音）。
- フィンガーピッキング：`fingerpick` の指定（親指がベースを、指が高音弦）。
- カントリーのエレキ：**スラップバックのエコー**（echo を短く 80〜120ms）、テレキャス風の明るいクリーン、スライド（`/`）。
- ジャングル（12弦）風：高い開放弦を重ねてきらびやかに（2本のギターで1オクターブ違いのアルペジオ）。

### 9-4. 合わせ方
| 要素 | フォーク | カントリー |
|---|---|---|
| BPM | 70〜110 | 100〜160 |
| ドラム | ほぼなし | 2ビート＋トレイン |
| ベース | 根音と5度 | 根音と5度、1・3拍 |
| ギター | アコギ2本（左右） | アコギ＋エレキ（スラップ） |
| 他 | ハーモニカ（なし）、ストリングス少し | フィドル（`violin`）、ペダルスチール（なし） |
| human | 0.4 | 0.3 |

### 9-5. 失敗と対策
| 失敗 | 原因 | 対策 |
|---|---|---|
| 打ち込み感が強い | ストロークが一定 | `human 0.4`、ストロークに `spreadMs` を 10〜20 |
| ベースが重い | フォークで太い低音 | ベースの音域を E2〜G2、sustain 短く |
| カントリーなのにロック風 | 歪みを使った | クリーン＋エコーに |
| 低音が濁る | ギターが低弦まで鳴る | 2本のうち1本をカポ風の高いポジションに |

### 9-6. 作曲ソフトでの書き方（案：未検証）
```
bpm 120 / chords "G C D G" / swing 0.1（カントリーは0〜0.1）
kick  g:X.......X....... （2ビート）
snare g:....X.......X...
hihat g:x...x...x...x...
bass  G1:1' D2:1' G1:1' D2:1'
guitar（アコギ）strum {"pattern":"D-DU-UDU","preset":"pop"} / pan -0.4
guitar（エレキ）amp crystal / echo 0.1 / pan 0.4
violin 合いの手
```
- ブーン・チャッの書き方：`strum` の型で `"D.xD.x"` のように、ベース音のダウンの後にミュート気味のダウンを置く（`x` で ring を止める）。
- 型の文字の意味は `song.mjs guide`：D ダウン・U アップ・x ミュート・. のばす・- 休み。

## 10. ブルース／ブルースロック

> この節も資料が少なめです。**確度：中。**

### 10-1. ドラム
- **決め手：シャッフル。**三連（`t:`）で、ハイハットは1つ目と3つ目、スネアは2・4。キックは1・3、または全拍。
- テキサス（軽い・速い）／シカゴ（重い・遅い）の違い：シカゴは BPM 70〜100、テキサスは 110〜140。
- 12小節の構造：I-I-I-I / IV-IV-I-I / V-IV-I-V（ターンアラウンド）。**ドラムはターンアラウンドで一度ブレイク**。
- ブルースロック：8ビートに崩れて、スネアが強くなる。

### 10-2. ベース
- **ウォーキング：**根音→3度→5度→6度→5度→3度の4分音符。シャッフルのときは「ブーン・ブ・ブーン」のように三連で跳ねる。
- ドラムのキックと同じ位置に4分音符を揃える（シャッフルは揃えるのが基本）。

### 10-3. ギター
- **リズム：**シャッフルのパワーコード（5度と6度の行き来）。パームミュートは**1つの区間に通して**使う（急に切り替えない）。
- **リード：**ペンタトニック＋ブルーノート、ベンド（`^`）、ビブラート（`~`）。歪みは `crunch` に近いが、リードには crunch を使わない決まりのため、リード用の別アンプを選ぶ（`lead` 系）。
- 歪みすぎは禁止（ジリジリが出る）。

### 10-4. 合わせ方
| 要素 | 動き |
|---|---|
| ドラム | 三連シャッフル（`t:`） |
| ベース | ウォーキング（4分、三連の跳ね） |
| リズムギター | 5度・6度のシャッフル（左） |
| リードギター | コール＆レスポンス（歌のあとに返す） |
| ピアノ・オルガン | 音の隙間に合いの手 |

### 10-5. 失敗と対策
| 失敗 | 原因 | 対策 |
|---|---|---|
| シャッフルが揺れない | swing 0 のまま8分で書いた | `t:` グリッドで書く、または swing 1.0 |
| 二重に揺れる | `t:` と swing を重ねた | `t:` を使うなら swing 0 |
| 聞きづらい | ギターが歪みすぎ | `crunch` 以下、ゲインを下げる |
| ベースが走る | ウォーキングが速い | BPM を落とす、4分を `'` で短く |

### 10-6. 作曲ソフトでの書き方（案：未検証）
```
bpm 100 / chords 12小節（chordsに 12個のコードを書き barsPerChord 1）
swing 0
kick  t:X.....X.....
snare t:......X..... ではなく、2・4拍: t:...X.....X. などで12文字
hihat t:X.xX.xX.xX.x
bass  E1:1 G#1:1 B1:1 C#2:1 ...（ウォーキング）
guitar（リズム）amp crunch 手前 / strum 型 "D-D-D-D-" をパワーコードで
guitar（リード）lead 系 amp / ベンド ^ とビブラート ~
```
- 構造メモ（確度：中）：「Pride and Joy」型（スティーヴィー・レイ・ヴォーン）：シャッフルのリフに**ベースが同じリフ**を重ねる。ターンアラウンドで全員がそろって止まる。

## 11. レゲエ／スカ／パンクスカ

### 11-1. ドラム
| 型 | キック | スネア（リム） | ハイハット | 速さ |
|---|---|---|---|---|
| ワンドロップ | **3拍目だけ** | 3拍目（キックと同時） | 8分（または裏） | 60〜90 |
| ロッカーズ | 全拍 | 3拍目 | 8分 | 70〜100 |
| ステッパーズ | 4つ打ち（全拍） | 3拍目（または2・4） | 8分の裏 | 速め |
| スカ | 1・3（拍の頭） | **裏拍**（「アンド」） | 8分 | 120〜180 |
| パンクスカ | 全拍 | 2・4 + 裏 | 8分 | 160〜220 |

- **決め手：レゲエは「1拍目を空ける」。**ワンドロップは1拍目に音がない。スカは「アンド」にスネアが入る。
- 見本（レゲエ）：キック `g:........X.......`（3拍目）、スネア `g:........o.......`（弱く）、ハイハット `g:x.x.x.x.x.x.x.x.`。

### 11-2. ベース
- **レゲエでは主役。**音数は少ない。**長い音と休符**（R）でグルーヴを作る。1拍目をわざと休むことが多い。
- 低めの音域（E1〜A1）、音を太く（sustain 長め）。
- スカ：ウォーキング（4分）。パンクスカ：8分の根音。

### 11-3. ギター
- **スカンク：**裏拍の短い「チャッ」。`strum` で `"xUxUxUxU"`、`step:0.5`、`strings:3`、**`ring:false`**。
- ミュート指定（`x`）は、「ひとかたまり」で通す（途中で通常奏に切り替えない）。
- クリーン、chorus 0、reverb 0.2。
- キーボード：オルガン風のバブル（8分で「ポコポコ」と小さく）。

### 11-4. 合わせ方
| 要素 | レゲエ | スカ |
|---|---|---|
| ドラム | 3拍目のみ | キック頭、スネア裏 |
| ベース | 長く、休みが多い | ウォーキング |
| ギター | 裏拍（右） | 裏拍（右） |
| キーボード | バブル（左） | 同左 |
| ホーン | 短い合いの手 | 主役（メロディ、ハモリ） |
| ボーカル | 空間を空ける | 速い |

### 11-5. 失敗と対策
| 失敗 | 原因 | 対策 |
|---|---|---|
| スカンクが長く伸びる | skank プリセットが ring | `ring:false`（0-2 A） |
| ノリが出ない | 1拍目に音がある | キックとスネアを3拍目だけに |
| ベースが薄い | 8分で動かした | 全音符＋休みに |
| 3パートが同じ側に集まる | pan の偏り | ギター右、鍵盤左、ホーン中央寄りに |

### 11-6. 作曲ソフトでの書き方（検証済み：レゲエ）
```
bpm 76 / chords "Am Dm Am E7" / swing 0 / human 0.3
kick   g:........X.......
snare  g:........o.......
hihat  g:x.x.x.x.x.x.x.x. （pan -0.3, 小さく）
bass   A1:1.5 R:0.5 A1:1 E2:1 R:1 ...（sustain 1.4）
guitar strum {"pattern":"xUxUxUxU","step":0.5,"strings":3,"ring":false} amp crystal chorus 0 pan 0.5
keys   A3:0.5 R:0.5 を繰り返し（pan -0.4）
```
- 警告：同じ音の繰り返し（単調）と、右側の3パートの偏り。**レゲエでは単調が音楽の一部**なので、単調の警告は無視してよい。pan だけ直す。
- スカは、キック `g:X...X...X...X...` ではなく `g:X.......X.......`（頭だけ）で、スネアを `g:..x...x...x...x.`（裏）に。ホーンは1オクターブ下げて G2〜Bb4 に収める（未検証）。

## 12. ジャンル横断の「失敗と対策」まとめ

| 症状 | 起きやすいジャンル | 原因 | まず試すこと |
|---|---|---|---|
| 低音が濁る | ディスコ、ファンク | キックとベースが同時 | ベースの音を裏拍に、キックの間に |
| ノリが固い | ソウル、ブルース、レゲエ | human・swing が低い | human 0.35〜0.4、swing 0.1〜0.2 |
| ノリがゆるすぎる | ディスコ、J-ROCK | human が高い | human 0.2以下 |
| 全部がずっと同じ | ポップ、AOR | sections 未使用 | 区間ごとに出し入れ |
| ギターが単調 | ファンク以外 | 同じ型の繰り返し | 型を2つ用意し、4小節ごとに切り替え |
| ミュートが急に出る | 全般 | 通常奏とミュートの混在 | ひとかたまりで通す |
| ハイハットが勝手に開く | ファンク、ディスコ | 自動オープン | 0-2 B |
| シンバルが途中で切れる | 全般 | 同じパートにクラッシュとライド | 別パートに |
| ホーンが lint 警告 | ファンク、ディスコ、スカ | 音域 G2〜Bb4 | 1オクターブ下げる |
| 合計音量が0.9超 | 全般 | volume 足しすぎ | 各パートを下げる |

## 13. 実装・文書への提案（優先順）

1. **skank プリセットの `ring:false` を既定にする。**（0-2 A）

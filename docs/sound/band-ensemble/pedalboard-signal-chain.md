# ペダルボードと信号の流れ（プロのギタリストの機材のつなぎ方と、作曲ソフトでの再現）（2026-10-14 調査）

このメモは、旭さんの指示「プロのギタリストが実際に行っているエフェクターの接続の仕方（ペダルボードの順番、アンプ前・センド/リターン、ステレオ構成、レコーディングでの作り方）を学び、その音の作り方を覚えて、音作りに生かせ」に答えるための調査と実装の記録です。

- 対象のコード: `src/audio/amp-rack.ts`・`src/audio/fx-chain.ts`・`src/audio/ai-song.ts`・`src/audio/amp-cab.ts`・`src/audio/amp-gate.ts`、先行文書 `amp-sim-guide.md`・`effects.md`・`guitar-tone-basics.md`
- 新しく作ったコード: `src/audio/fx-extra.ts`（新しいエフェクター9種）、`amp-rack.ts` の「アンプの前に fx をつなぐ」`pre: true`、テスト `src/audio/fx-extra.test.ts`・`src/audio/pedalboard-recipes.test.ts`
- 耳での確認はできません（作者は音を聴けない）。音の性格の数字は、波形とスペクトルを**実ブラウザ（ヘッドレス Chromium）で測った値**と、記事に書いてある値だけを根拠にしています。聴いて確かめた事柄はひとつもありません。

## 0. 重要な発見（先に読む10個）

1. **うちの fx はぜんぶ「アンプのあと」につながっていた**（`amp-rack.ts` の `configure`）。本物のペダルボードは、歪み・ブースター・コンプ・ワウ・ファズを**アンプの前**に置く。アンプのあとに置いた歪みは、キャビネットの高域カットを通らないので「ジャリ」「ピー」が出やすい。そこで fx に **`pre: true`** を足し、アンプの前に置けるようにした【実測】。
2. 実測すると、同じファズでも **アンプの前（PRE）はアンプの後（POST）より、波形の山と谷の差（クレスト）が 7.1 dB 対 2.9 dB**で、アンプの前のほうが自然に粒が残る（`clean` アンプの場合）。後ろに置くと、ほとんど四角い波になる【実測】。
3. **ブースターは、アンプの前に置くと「歪みが増える」、後ろに置くと「ただ大きくなる」**。`overdrive` アンプで +12 dB のブースター：前だと 2kHz〜8kHz の割合が −34.7 → −20.1 dB（歪みが増えた）、後ろだと −34.7 のまま音量だけ +12 dB【実測】。
4. **ペダルの順番の王道は「ダイナミクスに反応するもの→歪み→揺れもの→時間系」**。その理由は、後ろの効果に「きれいな信号を渡す」ことと、「ノイズを後ろの歪みに増幅させない」こと【出典:S1】。
5. **ディレイとリバーブは、本当はアンプのFXループ（センド/リターン）に置く**。アンプの歪みの前に置くと、くり返しの音まで歪んで濁る【出典:S1】。うちの fx は「アンプのあと」なので、ちょうど FXループの位置にあたる＝**時間系は今のままの位置でよい**。
6. **うちの fx の chorus・flanger・phaser・tremolo・delay・歪み系は、すべてモノラルの出力**（左右の相関が 1.00）。ステレオになるのは reverb 系・pingpong・widen だけだった【実測】。ステレオの広がりは、パートの `pan` と、新しい `doubler`（相関 0.48、モノラルに足しても ±1.7 dB 以内）で作る。
7. **プロの「太い歪みの壁」は、1本の音を厚くするのではなく、同じパートを別々に弾いた2本（クアッド＝4本）を左右に振り分けて作る**。コピーして左右に振ると、同じ信号が真ん中に集まってモノラルになるだけ【出典:S9, S11】。うちのエンジンでは、別々のパートとして2〜4本書く（音程やタイミングを少し変える）。
8. **ディレイのくり返しは、1回ごとに暗く・平らにするのが「いい音」の条件**（テープ・アナログ）。うちの `delay` は高域を丸める（tone 3500Hz）だけで飽和がなかったので、**テープディレイ `tape`**（くり返しの道に 140Hz のハイパス＋2.8kHz のローパス＋やわらかい飽和＋ゆれ）を足した。くり返しは 1 回あたり −5〜6 dB で減っていく【実測】。
9. **Web Audio の `DynamicsCompressorNode` は自動でメイクアップ（音量の持ち上げ）をし、約6ミリ秒の先読みの遅れを持つ**。そのため既存の `compressor` fx は、出力を更に持ち上げていて（独自のメイクアップが既定で +6 dB、最大 +12 dB）、パラレル（元の音と混ぜる）にするときは元の音も 6 ms 遅らせないと打ち消し合う【実測】。`pcomp`（パラレルコンプ）は、この両方を直してある。
10. **作曲ソフトに足りなかったのは「弾き方の強さで開くフィルター（エンベロープ・フィルター）」「テープ」「回るスピーカー（ロータリー）」「ハーモニックトレモロ」「オクターブ上」「ステレオの二重化」「パラレルコンプ」「ばねの「ビヨン」」**。そこでこの9種を作った。足りないまま残るのは「オクターブ下」「ピッチシフター」「シマー」「ステレオコーラス」「fx 内のノイズゲート」「本物のIR（音声ファイル）」（§13に作り方を書いた）。

## 2. 王道の接続順（ペダルボードの順番）

### 2.1 基本の並び
```
ギター → チューナー → ワウ／エンベロープ系 → コンプレッサー → ブースター／ファズ／オーバードライブ／ディストーション
      → ［アンプの入力］ ……歪みアンプ ……［FXループ：センド］ → 揺れもの（コーラス／フランジャー／フェイザー／トレモロ）
      → ディレイ → リバーブ → ［リターン］ → パワーアンプ → キャビネット
```
- 大きな考え方は「**広く効く効果（性格を決めるもの）を前に、細かく整える効果を後ろに**」【出典:S1】。
- 前のほうに置く：弾き方の強さに反応するもの（エンベロープ・フィルター、オートワウ）、ワウ、ファズ（古いファズは入力の相性が大事）、コンプ。後ろに置く：揺れもの、ディレイ、リバーブ【出典:S1, S7】。
- Wikipedia の「エフェクトユニット」も同じ並び：先頭にコンプ・ワウ・オーバードライブ、真ん中にコーラス・フランジャー・フェイザー、最後にディレイ・リバーブ。ノイズゲートは歪みやヴィンテージ機材のハムを抑えるため、最後のほうに置く、とある【出典:S7】。

### 2.2 順番の理由と例外の表
| ペダル | 基本の位置 | 理由 | 例外・注意 |
|---|---|---|---|
| チューナー | いちばん最初（ギターの直後）。ループ切り替え機の専用出力につなぐ方法も | 余計な効果を通る前の素の音で正確に測れる。チューニング中は音を消せる【出典:S1】 | なし |
| ワウ | 前のほう（歪みの前） | 歪みの前だと、ギターの倍音が豊かなところを動かせる。歪みの**後**に置く人もいて、そちらは音の変わり方が違う【出典:S1】 | ワウの前後にファズを置く人もいる（音色が別物になる）。ピッチシフターはワウより**前**【出典:S1】 |
| エンベロープ・フィルター／オートワウ | ほぼ先頭 | 弾き方の強さを読むので、前にコンプなどがあると反応が鈍る【出典:S1】 | ピッチシフターはこれらの前に置くと追跡しやすい【出典:S1】 |
| ファズ（古いタイプ） | 先頭（バッファーの前） | ギターのピックアップと直接つないだときに、入力の重さ（インピーダンス）で音が決まる設計【出典:S2】、前に圧縮するものがあると反応が鈍る【出典:S1】 | ディストーションの後ろにファズを置く人もいる（ざらざらの足し算） |
| コンプレッサー | ワウ・エンベロープ系の後、歪みの前 | 歪みの**後**に置くと、歪みが作ったノイズまで持ち上げてしまう【出典:S1】 | 歪みの後ろでも、音を平らにしたい意図ならありえる【推測】 |
| ブースター | ・歪みの前＝歪みを深くする／・歪みの後＝ソロ用の音量アップ | 前に置くとアンプや後ろの歪みを押す。うちの実測でも同じ結果【実測】 | 2台並べる人も多い |
| オーバードライブ／ディストーション | コンプの後、揺れものの前 | 揺れものを歪みの**後**に置くと、音がにじむ（特にコーラス）【出典:S1】 | フランジャーやフェイザーを、歪んだアンプの**前**に置くと迫力が出る（エディ・ヴァン・ヘイレンの例。歪みはアンプで作っていた）【出典:S1】 |
| 歪みの順番 | 軽い歪み→深い歪み | 軽い歪みを前に置くほうが、ノイズを抑えやすい（著者の好み。逆でもよい）【出典:S1】 | 後ろに置くほどノイズが増える【出典:S1】 |
| ノイズゲート | 揺れものの直後、または歪みの直後。ループ切り替えを使う人はアンプのループ内も | フランジャー／フェイザーのシューという音を、ギターが止まったときに消せる【出典:S1】。高ゲインでは音の切れ目を静かにする【出典:S26】 | 歪みの**前**に置くと、反応が鈍くなって刻みの頭が欠けることがある【既知】 |
| コーラス／フランジャー／フェイザー | 歪みの後（クリーンなら先でも） | 同じ理由。通常は1台しか使わないので、順番はあまり問題にならない【出典:S1】 | フェイザー＋コーラスは「軽いコーラス＋ゆっくりのフェイザー」で重ねる提案がある【出典:S20】 |
| トレモロ | 揺れものの後ろ | 音量の上下が最もはっきり効く【出典:S1】 | アンプの入力側に置く人もいる（ループを空けるため）【出典:S1】 |
| ボリュームペダル | ・先頭＝フェードインでペダルに効果を渡す／・ディレイの前＝残響を切らずに音量調整 | 位置で意味が変わる【出典:S1, S4】 | ディレイの前に置くと、スウェル（音がふくらむ）をディレイに食わせられる【出典:S4】 |
| EQ | ・歪みの前＝歪みに渡す帯域を決める／・歪みの後＝仕上げの調整 | 前に置くと「歪みの性格」を変える。メタルでは、前に低音を削るEQで「締まった」音にする【出典:S26】 | |
| ディレイ | リバーブの前 | 「ディレイ→リバーブ」の順なら、くり返しが滑らかにつながる【出典:S1, S4】 | 歪みの前に置くとくり返しも歪む（実験的な効果）。U2のエッジはアンプの入力に直接つなぐ例【出典:S1】 |
| リバーブ | 最後（ループがあるならループ内） | 歪んだリバーブは明瞭さを失う【出典:S1】 | シューゲイザーでは、**ファズをリバーブの後**に置いて、残響の尾を潰してうねらせる【出典:S21, S23】 |
| ピッチシフター／オクターバー | ワウ・エンベロープ系の前（音程の追跡をしやすく） | 【出典:S1】 | オクターブ上を歪みの**前**に置くと、整流の倍音がアンプに押されて鋭くなる【既知】 |

### 2.3 位置を変えると音がどう変わるか（実測）
うちのエンジンで、同じブースター・オーバードライブ・ファズを「アンプの前（`pre: true`）」「アンプの後（従来）」で測った【実測】。入力は、110Hz を基音にした和音風の合成波（0.05 の音量、減衰する）。

| アンプ | 位置 | 音量(RMS) | 2〜8kHzの割合(dB、小さいほど高域が少ない) | クレスト(dB) |
|---|---|---|---|---|
| overdrive | なし | −14.2 | −34.7 | 8.5 |
| overdrive | ブースト+12dB・前 | −8.1 | **−20.1**（歪み増） | 7.3 |
| overdrive | ブースト+12dB・後 | **−2.2** | −34.7（変わらず） | 8.5 |
| overdrive | tubescreamer・前 | −7.3 | −10.0 | 6.9 |
| overdrive | tubescreamer・後 | −7.9 | −12.1 | 4.6 |
| overdrive | fuzz・前 | −7.6 | −17.3 | 6.1 |
| overdrive | fuzz・後 | −13.8 | −14.2 | **3.6**（つぶれ） |
| clean | fuzz・前 | −11.1 | −31.4 | 7.1 |
| clean | fuzz・後 | −13.8 | −22.2 | **2.9**（つぶれ） |

読み取り（【実測】＋【推測】）：
- 前に置くと、歪みをアンプの形（コンプ・EQ・キャビネット近似）で整えてくれる。**後ろに置いたファズは高域が多く、波が四角く潰れやすい**。
- ブースターを後ろに置いた場合は、歪みの量は変わらず音量だけが上がる。「歪みを増やしたい」ときは必ず `pre: true`。
- 耳で聞いてどちらが気持ちよいかは確かめていない。

## 3. アンプ前・アンプのFXループ・4ケーブルメソッド・ステレオ構成

### 3.1 アンプの前に置く／FXループに置く
アンプは大きく「プリアンプ（歪みと音色を作る）」と「パワーアンプ（スピーカーを鳴らす）」に分かれる【出典:S34】。FXループは、その**間**にある入口（センド＝プリアンプの出口、リターン＝パワーアンプの入口）。

| 置き場所 | 向くもの | 理由 |
|---|---|---|
| アンプの前（ギター→ペダル→アンプ入力） | ワウ、コンプ、ブースター、ファズ、オーバードライブ、ディストーション、エンベロープ系 | アンプの歪みに「入力として」渡して、アンプと一緒に音を作る |
| FXループ（センド／リターン） | リバーブ、きれいなディレイ、（好みで）コーラス・フェイザー・フランジャー | アンプの歪みのあとなので、**効果が歪まない**。歪んだリバーブは明瞭さを失う【出典:S1】 |
| どちらでもよい | トレモロ、モジュレーション | ループを空けたいなら入口側、きれいにしたいならループ側【出典:S1】 |
| アンプの出口（キャビネットの後） | （ミキサー側）EQ、コンプ、サチュレーション | ミックスの段で処理する |

**効果的な指針（記事の言葉の言いかえ）**：リバーブは「ほぼ必ずループ」（アンプが非常にクリーンなら例外）、きれいなディレイはループ、モジュレーションは好み、トレモロはアンプの入口側【出典:S1】。

→ **うちの対応**：`AmpRack` は「入口 → アンプ → fx」の順。アンプのあと＝ほぼFXループの位置。なので、リバーブ・ディレイ・コーラス・フェイザー・フランジャー・トレモロ・スプリング・テープ・ロータリー・ダブラーは**今のまま（アンプのあと）**。歪み・ブースター・コンプ・ワウ・ファズ・エンベロープ・オクターブアップは **`pre: true`**（アンプの前）にする。

### 3.2 4ケーブルメソッド（Four Cable Method）【既知】
アンプのFXループを使いながら、前に置きたいペダルを「アンプの前」にも置く接続のしかた。
1. ギター → ペダルボードの**入力**（チューナー、ワウ、コンプ、ドライブ）→ ペダルボードの**出力** → アンプの**入力**（ケーブル1と2）
2. アンプの**センド** → ペダルボードの**ループ入力**（モジュレーション、ディレイ、リバーブ）→ ペダルボードの**ループ出力** → アンプの**リターン**（ケーブル3と4）
- 合計4本のケーブルで「歪みはアンプの前、時間系はアンプの後」を一つのボードで切り替える。この調査では4ケーブルメソッド専用の記事を取得できなかった（【既知】）。ただし「ループ切り替え機（ルーパー）」で同じことをする例は S1 にある【出典:S1】。
- → **うちの `pre: true` は、この4ケーブルメソッドのソフト版**。「`pre: true` の列＝ボードの前半、それ以外の列＝ループの後半」。

### 3.3 ウェット／ドライ／ウェット（Wet-Dry-Wet）【既知】
- 3台のアンプ（または2台のアンプ＋1台のドライ）を使い、真ん中のアンプにはドライ（効果なし）、左右のアンプにウェット（ディレイ・リバーブ・コーラスの効果音だけ）を送る。
- ステレオのディレイ・リバーブを、アンプごとに別々のスピーカーから鳴らす。ドライの音は真ん中で太く、効果は左右に広がる。
- この調査では記事の本文を取得できなかった（【既知】）。
- 録音のミックスでは次のように置きかえる：ギターは中央か左右にパン、**ディレイ／リバーブは「別のトラック（Aux）」に送り（センド）、返りを左右に広げる**。実例として Primal Tap（ギターを右 100%、左のディレイは左 100%・右の遅れ方が違うもう片方は 2 時の位置）と、ゴーストディレイ（モノの短いディレイをギターの反対側にパン）がある【出典:S13】。

### 3.4 ステレオの作りかた（実際の例）
| 方法 | しくみ | 長所 | 注意 |
|---|---|---|---|
| 2回弾いて左右に振る（ダブルトラック） | 別々の演奏を 100% 左と 100% 右 | 最も自然。音が太くなる | コピーして振ってもモノラルになるだけ【出典:S11, S9】 |
| クアッド（4本） | 外側 2 本＝100%、内側 2 本＝70〜80%（またはさらに 50%/25%）【出典:S9, S10】 | 厚い壁。内側が真ん中とつなぐ | 内側の 2 本は音色を少し変える（ピックアップ、ゲイン、ブースト、IR）【出典:S9】 |
| 別のアンプ・別のギターで重ねる | 同じパートを違う機材で | コーム（くし形）フィルターの干渉が減る【出典:S12, S10】 | |
| ステレオ・ディレイ | 左右の時間を変える（例：付点8分と16分、330ms と 660ms）【出典:S13, S14】 | 1本のギターが広がる | モノラルで聴くと相殺が出ることがある |
| ステレオ・リバーブ | 左右が相関しないインパルス | 空間の広さ | 低音を入れすぎると濁る（返りを 200Hz 以上に）【出典:S14, S22】 |
| ステレオ・コーラス | 左右で遅れの時間・LFOの速さを変える（例：10ms と 20ms、1Hz と 0.8Hz）【出典:S18】 | 広がる | 位相の問題が出たら幅を狭める【出典:S18】 |
| Haas（ハース）広げ | 片側を 10〜30ms 遅らせる | 1本のモノを広げる | モノラルでくし形になる。ゴーストディレイは 45〜70ms、フィードバック約25%（Haasより長い）【出典:S13】 |
| ロータリー・スピーカー | 回るホーン／ドラムが左右と音量を揺らす | 立体的な動き | §4.4 |

- 左右に振るときは、**完全な 100% より少し内側（90〜95）にすると自然**という意見もある【出典:S10】。
- 左右の音量を同じにしないと、中心が傾く【出典:S11】。
- 注意：**うちのエンジンは、ギターのパートをコピーして左右に置いても、同じ信号が重なるだけ**。パートを別々に書き、音程（`doubleDetune` など）やタイミングを少し変える。

## 4. ペダルの種類ごとの「つまみの標準値」と、掛け方

つまみの位置は「時計の位置」で書くのが慣習（9時＝小さめ、12時＝真ん中、3時＝大きめ）。ここでは、機種を限定しない**一般的な目安**を書く。**この調査では機種ごとの取扱説明書を取得できていない**ので、ほとんどが【既知】。記事で確認できたものだけ【出典】を付けた。

### 4.1 歪み系（3種類の違い）
| 種類 | 波形の潰れ方 | 性格 | 代表（【出典:S2, S3】） |
|---|---|---|---|
| オーバードライブ | やわらかく潰す（ソフトクリップ） | 低中域を温め、高域は増えにくい。ギターの音量の強弱が残る【出典:S2, S3】 | Tube Screamer、BOSS OD-1 |
| ディストーション | 硬く潰す（ハードクリップ）。トランジスタやダイオード | 伸びる・飽和する。ピックのアタックの輪郭は少し犠牲になる【出典:S2】 | BOSS DS-1、ProCo RAT（RAT は【既知】） |
| ファズ | 正弦波をほぼ四角い波にするまで潰す | 高域の倍音が増え、低音は薄くなる。壁のような背景に向く【出典:S2, S3】 | Fuzz Face、Tone Bender、Big Muff |

- ドライブのつまみは、**ギター側のボリュームを絞るとクリーンに寄る**。ソロで歪みの量をギター側で変える【出典:S31】。

### 4.3 フィルター系（ワウ）
- ワウは、**バンドパスフィルター**の中心周波数を足で動かす。かかとを下げる＝低く暗い、つま先を下げる＝高く明るい。Q（鋭さ）が高いほど尖る【出典:S35, S34 ワウ】。
- 標準値【既知】：中心の動く範囲は約 350Hz〜2.2kHz、Q は 5〜8。**ペダルを止めたまま使う（ココッド・ワウ）**と、一つの場所で帯域を強調・カットする音になる【出典:S34 ワウ】。
- 自動のワウは2種類：**エンベロープ・フィルター**（弾く強さに応じて開く）と、**LFOオートワウ**（一定の速さで往復）【出典:S7】。うちの旧 `autowah` は LFO 式。強さで開くものは新しい **`envwah`**。
- → うちの fx：`wah`（固定位置 `freq` 250〜2800 Hz、`q` 0.5〜12）、`autowah`（LFO）、`envwah`（強さで開く）。

### 4.5 時間系（ディレイ）
**時間の計算**：4分音符 = 60000 ÷ BPM ミリ秒。付点8分 = 4分音符 × 0.75。例：BPM 120 で 375ms、BPM 95 で約 474ms（記事の例ではテンポ 95、473.69ms、フィードバック 38%）【出典:S16, S4】。8分は 4分の 0.5 倍、16分は 0.25 倍。

- ディレイの種類（アナログ BBD／テープ／デジタル）【既知】：

  - **テープ**：くり返しが暗く、回転むら（ワウ・フラッター）でゆれ、ヘッドが飽和する。**うちの新しい `tape`**。

## 6. 録音・ミックスでの処理

### 6.1 アンプ＋キャビ＋マイク
- **マイクの種類と位置**は音色の大部分を決める。この調査では、マイク位置の専門記事（Recording Magazine の「Capturing the Cab」）の本文を取得できなかったので、以下は【既知】（私の記憶）。間違っている可能性がある。

| 位置・組み合わせ【既知】 | 音の性格 |
|---|---|
| ダイナミックマイク（SM57）をスピーカーの**中心（キャップ）**に近づけて正面 | 明るく攻撃的で前に出る。「プレゼンスのピーク」が切り込む【出典:S39 の SM57 の記述】 |
| 同じマイクを**コーン中間〜縁**へ動かす | 暗く丸く、低音の割合が増える（明るさが減る） |
| 角度をつける（斜め） | 高域が少し丸まる |
| 近づける（1〜数cm） | 近接効果で低音が増え、タイト。遠ざけると部屋が混ざる【出典:S39】 |
| リボンマイク（R-121 など） | 高域がなだらかに落ち、耳にやさしい。「高域のジャリ」を減らす【出典:S39】 |
| e906（スーパーカーディオイド。グリル正面に置く） | 低域が締まる。ライブ向きの設計【既知】 |
| 57 + 121 を同じスピーカーに2本 | 57 の明るさ＋121 の太さ。**位相を確認して**重ねる（ずれると痩せる）【既知】 |
| 部屋のマイク（ルームマイク） | 空気感とサステインを足す |
- プリアンプのゲインとマスターの関係：**プリのゲイン低め＋マスター高め＝パワー管の飽和**が強い。**プリのゲイン高め＋マスター低め＝プリの歪み**が強い【出典:S39】。
- 軽い圧縮は音量をそろえるが、強い圧縮はクランチの強弱を消す【出典:S39】。

> 注：S39 は、クランチ録音に関するある記事（soundsheavy.com）。数字は一つもなく、性格の説明だけだった。

### 6.2 DI＋リアンプ
- 方法：①アンプ（マイク）の音と、**ギターの生のDI信号**を同時に録る。②あとでDI を「リアンプボックス」でアンプに戻して、別のアンプ・別のペダル・別のマイクで録り直す。1回目のテイクを DI で残しておけば、あとでアンプを選び直せる【出典:S11, S12】。
- **ダブル録りのやり方**：1本目はアンプ＋DI の両方を録り、2本目は新しく弾く【出典:S11】。
- 注意【既知】：リアンプボックスは、DI の信号のレベルとインピーダンスを「ギターのピックアップ」に近づけるための道具。これがないと音量が大きすぎ・高域が痩せる。
- **NAM（Neural Amp Modeler）は、DI に「アンプだけ」の録音で作ったモデルを掛ける**のが得意で、キャビネットは後から IR で足す。キャビを含んだままモデルを作らない。モデルを作るときは、ディレイ・リバーブ・コンプ・ゲートを切る（コンプとゲートが入ったままだと誤差が増える）。ESR が約 0.1 なら「まあまあ」、約 0.04 なら「かなり良い」。歪みペダルやオーバードライブも撮れるが、時間系のエフェクトは撮れない【出典:S19】。
- うちの NAM は `amp-rack.ts` の `buildNam`（モデル → 高音の調整 → キャビネット近似 → パン）。**NAM に fx の `pre: true` は効く**（アンプの前に歪みペダルを置ける）。

### 6.3 ダブルトラック（二重録り）
- 2回弾いて、100%左／100%右に振る【出典:S11, S9, S10】。
- **コピーしてずらして振る**のは良くない：同じ信号は中央に集まって「ただ大きいだけのモノラル」になり、ずらすと**コムフィルター**（くし形の凹み）の「フェイズ」した音になる【出典:S11】。数ミリ秒の遅れが原因【出典:S11】。
- 左右で**別のアンプ／別のキャビIR**にすると、ステレオの奥行きが出る。ただしゲインは控えめに：高ゲインを重ねると濁る【出典:S11, S12】。
- タイミングは**大きなアクセント（コードの頭、パームミュート）を合わせ、完全にそろえない**。人間のゆらぎが幅を作る【出典:S11】。
- 静かな部分では、2本が**交互に**弾き（小節の前半・後半）、サビで**同じパート**を一緒に弾くと強くなる【出典:S12】。
- 2本の音色の違いで、くし形の干渉が減る：片方は低中域を多く、片方は中高域を明るく【出典:S10】。
- 左右のバスで一緒に処理（EQ・コンプ）すると、まとまる【出典:S11, S9】。

### 6.4 クアッド（4本）
- 外側 2 本は 100%、内側 2 本は 70〜80%（または 50%と 25%）【出典:S9, S10】。
- 外側＝主な高ゲイン、内側＝ピックアップ違い／ゲインを下げる／別のブースト／別のIR【出典:S9】。
- バス：100〜150Hz 以下を切る、300〜500Hz をスネア・ボーカルのために空ける、圧縮は**遅いアタック（ピックを通す）・速いリリース（胴鳴りを持ち上げる）**、軽いテープ／チューブのサチュレーション【出典:S9】。
- 同じ音色を 4 本に使うと、高域がジャリついて輪郭が悪くなる【出典:S9】。

### 6.5 EQ（ローカット／ミッド／プレゼンス）
複数の記事の数字を並べる（どの数字がどの記事かは一部対応が曖昧。S10 は記事群）【出典:S10, S37】。

| 帯域 | 処理 | 内容 |
|---|---|---|

| 100〜150Hz（バンドミックス） | ハイパス | 基音は 82Hz（標準チューニングの6弦）まで届く。150Hz 付近まで上げてベースと調整する人もいる【出典:S10】 |
| 160〜300Hz | 体 | 多すぎると「樽のよう」で明瞭さが減る【出典:S10】 |
| 250〜500Hz | 濁りのカット | ベースと他のギターとぶつかる。リードで少しえぐる【出典:S37, S10】 |

| 2〜4kHz | 刺さり／プレゼンス | 歪んだギターは 2〜4kHz を少し凹ませる【出典:S10】。バンドの中で前に出したいときは 3〜5kHz を持ち上げる【出典:S10】。ピックのアタックは 2.2kHz 付近【出典:S10】 |

### 6.6 コンプ・サチュレーション
- 歪んだギターは歪み自体がすでに圧縮なので、**軽く**（歌わせる程度）【出典:S10】。
- バスにコンプ：2 本のギターを 1 本のように聞こえさせる【出典:S10】。
- サチュレーションは、サイズを EQ ではなく**飽和で**出す：テープ・トランス・アンプ型の歪みが密度を足す【出典:S22】。

### 6.7 リバーブ／ディレイのセンド量とプリディレイ
- センド量は「**耳で最適を探す**」。数値の記事は少ない【出典:S14】。
- ミックスで「ちょうどよく聞こえる位置から 10〜25% 減らす」【出典:S15】。
- ディレイは「短い」ほど目立たない。深さ（奥行き）には**とても小さな音量**の遅れを使い、倍音の「太らせ」には**とても短い**遅れを使う【出典:S15】。
- 低域を切る（200Hz以上）とリバーブは濁らない。400Hz 付近まで上げて「抜け」を作る人もいる（Abbey Road は 600Hz）【出典:S14】。
- プリディレイ：リード 15〜35ms、アンビエント 40〜80ms【出典:S8】。ソロの 8.5 秒ホールで 148ms の例【出典:S14】。
- リバーブとディレイは、**共有の空間を 1〜2 種類**にする：長いモジュレーション付きホール＋ドラム用の短いルーム【出典:S22】。リバーブ返りを**ダッキング**（ドライの音に反応して凹ませる）と、フレーズの合間に尾が膨らむ【出典:S22】。

### 6.8 ステレオ幅
- 低音はモノ、高域は広く【出典:S22 の「フルレンジのレイヤーを避ける」】：各ギターが 100Hz〜12kHz を全部埋めないように、**役割ごとに帯域を分ける**（土台＝ドライでミッド多め、質感＝モジュレーション濃い、輝き＝1オクターブ上を高域だけ広く）【出典:S22】。
- 左右を 100% にしない（90 くらい）【出典:S10】。
- ギター1本ならディレイ（数ミリ秒）や小さなピッチ差でステレオ感が出るが、2 本の演奏のほうが良い【出典:S10】。

## 7. 音作りのレシピ集（ペダル順・つまみ値つき。作曲ソフトの書き方つき）

読み方：
- **「実機のボード」**：実機でのペダル順とつまみ（時計）。ほとんど【既知】または【推測】（聴いて確かめていない）。
- **「うちの書き方」**：パートに書く JSON の一部。`amp`／`ampDrive`／`ampLevel`／`ampTone` と `fx`（`pre: true` がアンプの前、なければアンプの後）。`mix` などは 0〜1。すべて、書いただけで耳では確かめていない「仮」の値。
- **うちで使えない・好まれない音**（`banned-sounds.md`）：クリーンギターへの chorus（きゅいんきゅいん）、リードの標準 crunch アンプ（ピロピロ）、短い単音の刻み。このレシピ集でも、ギターに `chorus` を付けない。

> JSON は `src/audio/fx-extra.test.ts`／`src/audio/pedalboard-recipes.test.ts` で、`fx` の種類とつまみの名前が実在することを自動検査している。

### 7.1 SUNO のようにきれいで厚い、現代的なギターの音（10種類）
SUNO の音を耳で聴いて確かめたわけではない。既存の調査（`suno-like-plan.md`、`quality-recipes.md`）で言われていることを前提に、**「低域を切る・帯域を役割で分ける・左右に広げる・ドライとウェットを分ける・やりすぎない」**を信号の流れにしたもの【推測】。

**S-1 きらきらクリーン（ポップのバッキング）**
- 実機のボード：ギター → コンプ（3:1、5ms/50ms、約3dB）→ クリーンなアンプ（JC-120系）→（ループ）ステレオ・ディレイ（付点8分、混ぜ 12%）→ プレート（混ぜ 10%、プリディレイ 25ms）【出典:S10 のコンプ値、S8】。

{"amp":"sparkleClean","ampLevel":1,"fx":[{"type":"pcomp","mix":0.3,"threshold":-28,"ratio":8},{"type":"delay","beats":0.75,"mix":0.12,"feedback":0.3,"tone":3200},{"type":"plate","mix":0.12}]}

## 8. 作曲ソフトの現状（コードを読んで確認したこと）【コード】

### 8.1 信号の流れ
```
MIDIチャンネル(ch)の音 → ［pre: true の fx（今回追加）］ → アンプ（ロール）→ ［キャビネット近似・ゲート・tight（ロールの追加の段）］ → ［pre でない fx（最大8個、書いた順）］ → ミキサーの出口（パン・音量）
```
- 実装：`AmpRack.configure`（`src/audio/amp-rack.ts`）。**これまで fx はアンプの後ろだけだった**。
- アンプの種類（`AmpSetting.type`）：`auto`／`clean`／`overdrive`／`distortion`／`metal`／`prs`／ジャンル別（`jazz` `blues` `funk` `crunch` `hardrock` `punk` `fuzz` `shoegaze` `lofi` `retro8bit` `radio` `loudmetal` `loudrock` `delicate` `crystal` `lead` `modernHigh` `sparkleClean` `jpopClean`）／NAM（学習式の実アンプ。`namA` `namB` `namKay3〜10`）／`plugin`／鍵盤用。
- ロールごとの追加の段（`AmpSetting` の `cab`／`mic`／`tight`／`gate`／`preLowpass`／`curve`）：`lead`（open・前段ローパス 7000・softsqrt）、`modernHigh`（closed・6500・ゲート 60）、`sparkleClean`（bright）に既定がある。
- **注意（AI ソング形式）**：パートの JSON から指定できるのは `amp`／`ampDrive`／`ampLevel`／`ampTone`（と、NAM だけ `ampCab`）。`cab`／`mic`／`tight`／`gate`／`preLowpass`／`curve` は JSON に出ていない（コードの `AmpSetting` にはある）。→ 提案（§15）。

### 8.2 fx の種類（22＋今回の9＝31種類）
| 分類 | 種類 | 実装の様子 |
|---|---|---|
| 時間 | `delay` | 遅れ＋ローパス（`tone` 既定 3500Hz）。くり返しの道にローパス。**モノラル**【実測】 |
| 時間 | `pingpong` | 左右（−0.8／+0.8）に跳ねる。ステレオ（相関 0.54）【実測】 |
| 空間 | `reverb` `plate` `spring` `room` | 畳み込み。インパルスは「指数で減るノイズ」。ステレオ（相関 0.64〜0.89）【実測】【コード】 |
| 揺れ | `chorus` `flanger` `phaser` `tremolo` `vibrato` | 遅れや位相をLFOで揺らす。**すべてモノラル**（相関 1.00）【実測】 |
| フィルター | `wah`（固定位置）`autowah`（LFO式）`filter` `eq`（3バンド） | `autowah` は**弾く強さには反応しない**（LFOで往復）【コード】 |
| ダイナミクス | `compressor` `boost` | `compressor` は固定のアタック 12ms／リリース 200ms だった（今回 `attack`／`release` を足した）。Chrome の自動メイクアップに加えて独自のメイクアップを足す【コード】【実測】 |
| 歪み | `tubescreamer` `fuzz` `bitcrusher` `ringmod` | WaveShaper。**アンプのあとに置くのでキャビを通らず「ジャリ」が出やすかった**【実測】 |
| 広がり | `widen` | 片方を 17ms 遅らせて 0.7 パン。相関 0.79【実測】 |

### 9.3 `pre: true` の使い方
- `fx` の要素に `"pre": true` を書くと、**アンプの前**につながる。書かなければ従来どおり**アンプの後**。
- 前につなぐ順は、`fx` の中の `pre` の要素の順（コンプ → ブースター → ファズ のように、王道の順に書く）。
- 後ろのチェーンは従来どおり「書いた順」。上限は 8 個（従来どおり）。
- **ドラム・ベースにも効く**が、通常は使わない。ベースの前に歪みを置くなら `pre: true`。
- NAM にも効く。

## 10. 作曲ソフトで、先に何をするとよいか（実践の手順）
1. **歪み・ブースター・コンプ・ワウ・ファズ・エンベロープは `pre: true`** にする。
2. **リバーブ・ディレイ・テープ・ロータリー・ダブラーは `pre` なし**（FXループの位置）。
3. 左右に広げたいギターは、**別々の2パート**にして `pan` を −0.9／+0.9、片方の `ampDrive` を 0.85 に。1パートだけ広げるなら `doubler`。
4. クリーンのギターに `chorus` は付けない。ゆれは `rotary`／`harmtrem`、広がりは `doubler`／`pan`。
5. ディレイは **付点8分（`beats: 0.75`）**が出発点。リードは `mix` 0.12〜0.2、フィードバック 0.28〜0.4、`tone` 3000Hz 前後。
6. リバーブは `mix` 0.08〜0.2。速い曲は `size` を 0.6〜0.8 に。
7. 迷ったら、最後に **全体の効果の量を 10〜25% 引く**【出典:S15】。
8. 耳で確かめる：メモに「聴いていない」と書いてあるものは、人間が聴いて決める。

## 13. 足りない効果の実装方針（アルゴリズム）

「作れそうなもの」は fx-extra.ts に入れた。以下は、**まだ作っていないもの**を、Web Audio の部品や AudioWorklet でどう作るかの方針。どれも耳では確かめていない設計案。

### 13.1 オクターブ下（フリップフロップ分周）
- 原理【既知】：入力の**ゼロ交差のたびに**内部の出力（+1／−1）を反転すると、周波数が半分の方形波になる。これを入力の**包絡**（整流 → ローパス 15〜30Hz）で振幅変調し、ローパス（800Hz〜1.5kHz）でやわらげる。
- 手順（AudioWorklet、サンプルごと）：
  1. `x` の符号が負 → 正に変わったら `flip = !flip`（立ち上がりのゼロ交差だけ数える）。
  2. `sq = flip ? +1 : −1`。
  3. `env += (|x| − env) * (|x| > env ? 0.05 : 0.002)`。
  4. `y = sq * env * g`。
  5. `y` をローパス（1次、1kHz）。
- 注意：**単音専用**（和音はゼロ交差が乱れ、ざらつく）。入力前に 1kHz ローパスを入れると安定する。
- 既存の `amp-gate.ts` の `GATE_PROCESSOR_CODE` と同じ方式（文字列のコードを Blob で読み込む）で、`OfflineAudioContext` でも動く。

### 13.2 ピッチシフター（ハーモナイザー）
- 方式A（ディレイ線のクロスフェード。軽い）：長さ `D`（例 50ms）の遅れ `d(t)` を鋸歯状に変化させる。ピッチ比 `r` のとき、`d` は 1 周期の間に `(1 − r) * (周期)` だけ動く。2 本の遅れを半周期ずらし、**ハン窓で交互にフェード**する。Web Audio では、`DelayNode` ×2 と `ConstantSourceNode`＋鋸歯の `PeriodicWave` で、`delayTime` を変調して作れる。
- 方式B（グラニュラー）：小さな粒（20〜50ms）を再生速度 `r` で切り出し、一定間隔で重ねて足す（OLA）。
- 方式C（位相ボコーダー）：オフライン（書き出し）専用。FFTのサイズ 2048、ホップ 512、位相を累積。品質は一番良いが重い。
- 音程の「上のオクターブ」（+12）なら、方式Aで r = 2。ギターの和音でも使える（`octup` の整流式は単音専用）。

### 13.3 シマー（リバーブ内のピッチシフト）
- リバーブの**くり返しの道**に +12 半音のピッチシフターを入れ、ゲイン 0.4〜0.5 で戻す。尾が伸びるたびに 1 オクターブ上がる。
- 手順：入力 → プレート（`ConvolverNode`）→ 方式Aで +12 → ローパス 6kHz → 0.45 倍 → 入力へ戻す（`DelayNode` を 1 つ入れてループを成立させる）。
- 注意：低域はフィードバックに入れない（ハイパス 400Hz）。そうしないと濁る。

### 13.4 ステレオコーラス
- 2 声：左は遅れ 12ms ± 3ms、右は 18ms ± 3ms。LFO は同じ速さ（1〜1.5Hz）で、**位相を 90°ずらす**（または逆位相）。`ChannelMergerNode` で左右に。元の音は真ん中に残す。
- 記事の数値：遅れ 20〜30ms（ギター）、速さ 1.5Hz、深さ 25〜35%、混ぜ 40%、左右で遅れ 10ms／20ms・速さ 1Hz／0.8Hz【出典:S18】。
- **うちでは、ギターに付けない**（`banned-sounds.md` 6）。鍵盤・弦・パッド用。

### 13.5 fx としてのノイズゲート
- すでにある AudioWorklet のゲート（`amp-gate.ts` の `createGate`）を fx から呼ぶ。`AmpRack.attachGate` と同じく「用意ができるまで素通し」でつなぎ替える。
- 先読み（ルックアヘッド）：音を 3〜5ms 遅らせ、検出は遅らせない側で行う。立ち上がりの頭が欠けない。
- 置く位置：歪みの**後**（歪みが作る雑音を消す）。刻みの頭を欠けさせたくないときは、歪みの**前**でなく、歪みの後でホールドを 15〜20ms にする。
- 標準：しきい値 −52dB（深いゲートは −48）、ヒステリシス 4dB、ホールド 20ms、リリース 120ms、深さ 24〜60dB（うちのゲートの標準）。

### 13.6 ユニヴァイブ
- 4 つのオールパスをそれぞれ**中心周波数をずらして**（例 150／450／1200／3500Hz 付近を基準）、1つのLFO（0.5〜7Hz）で動かす。出力は元の音と混ぜる。LFO の形は「光る電球の遅れ」を真似て、**少し歪んだ正弦**（立ち上がりが速く、下りが遅い）にする。
- うちの `phaser` との違い：段ごとの中心がずれていて、LFO の形が非対称。

### 13.7 オートパン／ステレオトレモロ
- `StereoPannerNode.pan` に LFO（振幅 depth）をつなぐだけ。ハーモニックでない普通のトレモロは `tremolo`。

### 13.8 ダッキング・ディレイ／リバーブ
- ドライの音の大きさ（整流 → ローパス 20Hz）を求め、その反転をウェットの `GainNode.gain` に加える。ドライが鳴っている間はウェットが引っ込み、止まった瞬間にくり返しが戻る。
- 記事：「リバーブ返りをドライでダッキングすると、フレーズの合間に尾が膨らむ」【出典:S22】。

### 13.9 本物のIR（音声ファイル）
- `ConvolverNode` に WAV の IR を読み込むだけで、キャビネットを再現できる。ただし**外部の IR 素材は、ライセンス（商用利用・再配布・組み込み）を確認してから**（`CLAUDE.md` 1-1 の例外条件と同じ）。この調査では、使える無料IRの規約を確認していないので、**使っていない**。
- 既存方針：フィルター近似＋`cabir` のマイクの癖。

### 13.10 リバース・リバーブ
- インパルス応答に「だんだん大きくなる」ノイズを使うと、入力の後にふくらむ音になる（本物のリバースは入力を逆再生してから畳み込み、さらに逆再生する）。
- オフライン書き出しなら、本物の方式（音を切り出して逆再生 → リバーブ → 逆再生）ができる。

### 13.11 AI ソング JSON から指定できる項目の追加（提案）
- `ampGate`（0〜60）、`ampTight`（0〜1）、`ampMic`（center/edge/off/far）、`ampCab`（非NAMも）、`ampPre`（前段ローパス）、`ampCurve`。`AmpSetting` に既にある項目なので、`ai-song.ts` の amp の組み立て（`p.amp && p.amp !== "auto"` の行）に足すだけ。この調査では他の作業者の変更と衝突するため、実装していない。

- 左右の相関 0.48。左の音量 −14.9dB、元の音 −15.2dB。
- モノラルに足したときの、元の音との差（オクターブ別）：100Hz +1.7、200Hz −0.2、400Hz +0.8、800Hz −0.2、1.6kHz −0.1、3.2kHz −0.1、6.4kHz −0.5（dB）。**モノラルで聴いても大きく痩せない**。

### 14.5 パラレルコンプ（440Hz のサイン、−40dBFS と −10dBFS）【実測】
| 設定 | 小さい部分(dB) | 大きい部分(dB) | 差(dB) |
|---|---|---|---|
| 元の音（mix 0） | −43.0 | −13.5 | 29.5 |
| `pcomp` mix 0.5（修正前、独自メイクアップあり） | −23.4 | −4.6 | 18.7 |
| `pcomp` mix 0.5（6ms遅れなし。位相が打ち消し合う） | −39.4 | −15.7 | 23.7 |
| `pcomp` mix 0.5（修正後） | −33.6 | −9.2 | 24.4 |
| `pcomp` mix 1 | −29.2 | −6.4 | 22.8 |
| `compressor` 比 4:1・しきい値 −24 | — | — | 24.0 |
- 発見：①`DynamicsCompressorNode` は自動でメイクアップをかけるので、独自のメイクアップを足すと +9dB うるさくなる。②約 6ms の先読みで遅れるため、元の音も 6ms 遅らせないと、足したときに打ち消し合う。
- 標準の `mix` は 0.35（それでも大きい部分が約 +3dB 上がる）。足したあとの音量は、`level`（dB）か、パートの `volume` で戻す。

### 14.6 ハーモニックトレモロ、オクターブアップ【実測】
- ハーモニックトレモロ（rate 4.5、depth 0.8）：200Hz の変調度 0.78、3kHz の変調度 0.74、**包絡の相関 −1.00**（完全に逆）。
- オクターブアップ（220Hz のサイン）：`mix` 1 で 220Hz −12.2dB、440Hz −8.5dB、660Hz −126dB（なし）、880Hz −16.9dB。奇数倍が出ない＝きれいな上のオクターブ。

### 14.7 キャビネットIR（ノイズ 3秒、1kHz を 0dB にしたときの 1/3 オクターブ別のおおよその値）【実測】
| 周波数 | closed／center | dark(tone3000) | bright(tone6000) | off(size0.5) | far(size2) |
|---|---|---|---|---|---|
| 100Hz | +2.0 | +1.3 | +0.5 | +6.6 | −1.5 |
| 250Hz | −0.4 | −0.2 | −0.3 | +2.6 | −1.6 |
| 1kHz | 0 | 0 | 0 | 0 | −0.4 |
| 2.5kHz | +1.4 | −1.0 | +2.1 | −6.7 | −6.1 |
| 4kHz | −4.3 | −11.4 | −1.8 | −15.3 | −16.3 |
| 6.3kHz | −22.7 | −37.7 | −14.6 | −48.4 | −35.5 |
| 8kHz | −37.4 | −56.0 | −23.9 | −61.7 | −48.3 |
| 10kHz | −50.6 | −70.8 | −32.1 | −79.1 | −57.1 |
- 読み取り：斜めのマイク（off）は、**100Hz が +6.6dB、2.5kHz が −6.7dB**と、低域寄りで暗い。遠いマイク（far）は 2.5kHz 以上が下がる。【推測】実物のマイクの位置の違いの性格には合うが、反射の数字（0.25ms で 0.35、2.1／3.7／6.2ms）は仮。

### 14.9 エンベロープ・フィルター（110Hz の鋸歯風。小さい音 0.04、大きい音 0.4）【実測】

## 15. 確かめられていない点・限界・次にやること

### 15.1 確かめられていない点（正直に）
1. **音を耳で聴いていない**。数字（相関、重心、音量）しか見ていない。聴いたときの「気持ちよさ」は、旭さんが決める。特に `tape`・`rotary`・`springx`・`doubler` の標準の量は仮。
2. 検索予算が尽きたため、**S1〜S39 以外の資料は読めていない**。Sound On Sound・Premier Guitar・Reverb.com の rig rundown、Fractal・Kemper・Helix のプリセット解説、日本語の機材記事（BUMP、ELLEGARDEN、YOASOBI など）は、本文を取得できなかった。→ §5 の日本のギタリストの欄は空。
3. §4 の「標準のつまみの位置（時計）」は、ほとんど【既知】（記憶）。機種の取扱説明書で裏を取っていない。
4. §6.1 のマイク位置は【既知】。Recording Magazine の専門記事を取得できなかった。
5. 4ケーブルメソッド、ウェット／ドライ／ウェットの説明は【既知】。専門記事を取得できなかった。
6. `springx` のチャープの数字（4200Hz → 320Hz、34ms／41ms、減衰 0.7）は仮【推測】。本物のばね（Accutronics の測定）と比べていない。
7. `cabir` の反射の数字（斜めのマイク 0.25ms で 0.35 など）は仮【推測】。
8. `rotary` の揺れの速さが設定どおりか、測定の限界で確かめきれていない（変調度は測れた）。
9. `pre: true` の実測は、アンプ `clean`／`overdrive` と、合成の和音風の入力だけ。NAM・他のアンプ・実際のギターの音では確かめていない。
10. ブラウザが違う（Safari・Firefox）と、`DynamicsCompressorNode` のメイクアップや先読みの量が違う可能性がある【推測】。測定は Chromium のみ。

### 15.2 他の作業者との衝突を避けるために、あえてやらなかったこと
- `ai-song.ts` の amp の項目の追加（§13.11）、`tools/composer/entry.ts` の fx 画面のつまみ（`FX_MAIN`）への新種類の追加。
- 自動ミックスの実装の領域（`auto-mix` 関連、`offline-render.ts`、`midi-export.ts`、`score.ts`）。

### 15.3 提案（次にやるとよい順）
1. 旭さんが `tape`・`rotary`・`doubler`・`pcomp`・`envwah`・`springx` を聴いて、標準の量を決める。
2. `entry.ts` の `FX_MAIN` に新しい 9 種類の主要つまみ（`tape`：`ms`、`rotary`：`rate`、`doubler`：`ms`、`pcomp`：`threshold`、`harmtrem`：`rate`、`octup`：`gain`、`cabir`：`tone`、`springx`：`size`、`envwah`：`freq`）を足す（今は混ぜ具合のつまみだけ出る）。
3. AI ソング JSON に `ampGate`／`ampTight`／`ampMic`／`ampCab` を足す（§13.11）。
4. 既存の曲（`src/audio/songs/`）のギターの歪みペダル（`fuzz`／`tubescreamer`）を `pre: true` にするとどう変わるかを、書き出しの合否表で比べる。
5. オクターブ下、ピッチシフター、fx のゲート（§13）を作る。
6. ステレオのコーラスは、鍵盤・弦・パッド用に作る（ギターには付けない）。

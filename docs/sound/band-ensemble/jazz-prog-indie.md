# バンド編成の作り方 ジャズ／フュージョン／プログレ／ポストロック／インディー／エレクトロニック

調査日: 2026-10-14。対象は、ギター・エレキギター・ベース・ドラムを「どう合わせるか」を、ジャンルごとに調べたものです。
既存の `drum-genre-guide.md` `drum-patterns.md` `genre-guides.md` `bassline-guide.md` などとは重ならないように、ここでは「足りなかったこと」「間違っていたこと」「実際に書けるようになる書き方」を中心にまとめます。

この文書の使い方:

- 先に「0. 既存の資料との食い違い」を読む。ここは、いま書かれている説明書が間違っている、または古い場所の一覧です。
- 次に、作りたいジャンルの章だけ読めば足ります（1から6）。各章は同じ並び方です。ドラム／ベース／ギター／合わせ方／失敗と対策／作曲ソフトでの書き方。
- 7は共通の周波数表と音量の目安、8は有名曲の構造分析、9は設計の提案、10は出典です。
- 歌詞とメロディは引用していません。曲の分析は「構造」と「役割分担」だけです。
- 「確認済み」と書いたJSONは、実際に `node tools/composer/song.mjs build` で通ったものです（検証用の置き場は作業用フォルダ）。そのまま貼って使えますが、音色の好みは耳で直してください。

## 0. 既存の資料との食い違い（先に直してほしい所）

コードと実際に動かした結果から、次の食い違いが見つかりました。上にあるものほど、曲作りへの影響が大きいです。

| # | 既存資料の書き方 | 実際（コード・ビルドで確認） | 影響 |
|---|---|---|---|
| 1 | `drum-genre-guide.md` §8: ライド、ブラシ、ペダルハイハットは書けない | ライドは crash パートの `D2`（GM51）、ライドベルは `F2`（GM53）で書ける。足のハイハットは別の hihat パートで書ける。ブラシだけは本物の音が無いので、音量を下げた snare の連打（`g:` の o）で似せる | ジャズが「ライド抜き」で作られてしまう |
| 2 | 同: スウィングは曲全体だけ | パートごとの `swing` `swing16` が曲の値を上書きする（ai-song.ts） | ライドだけ跳ねさせ、ハットは真っすぐ、が書ける |
| 3 | `genre-guides.md` プログ: beats は 3/6/7 だけ、曲中は同じ拍子 | `beats` は 2 から 12。`grouping`（例 `[3,2]`）で区切りを指定できる。auto は 5=3+2、7=2+2+3、9=3+3+3、11=3+3+3+2。ただし曲の途中で拍子を変える機能は無い | 5/4 や 11/8 が書けるのに知られていない |

| 5 | 7/8 を書く方法が無い | 「拍子の欄」が無いので、beats 7（4分音符7つ＝14/8）で書く。8分音符14個、グリッド28文字が1小節 | 7/8 を2回つなげた形になる |
| 6 | コード語彙は一般的な7th系まで | 13、11、alt、7#9、7b9、6/9、7#11 は読めず、ビルドが止まる（例: `G13` で「読めないコードがあります」）。使えるのは maj7 m7 dim aug sus4 sus2 m 7 m7b5 dim7 7sus4 maj9 m9 9 add9 m6 6 madd9 m(maj7) 5 mmaj7 mM7 M7 とスラッシュコード | ジャズの緊張音は、`9` `maj9` `m9` で代用するか、音を直接書く |
| 7 | `guitar-techniques-rock-guide.md` §2.7 のシューゲイザーの例が chorus 0.4。`gtrStyle: "shoegaze"` は chorus 0.6 | きれいな音のギターにコーラスは掛けない、という決まりと矛盾する | 例を写すと「きゅいんきゅいん」になる |
| 8 | チェッカー（score-check）は「クラッシュとハイハットが同時」と警告する | ライド（crash パート）と足ハイハットは、ジャズの正しい形。警告は誤検出 | 警告を消そうとして、ライドを消してしまう事故 |
| 9 | ストラムの accent は4拍周期 | 5拍や7拍の曲では、5拍目が「1拍目の強さ」になる。3+2 の区切りに合わない | 奇数拍子のギターが妙に強くなる |

補足: 「バンドの各パートの音量バランスは、ミキサー（人が後で直す）の仕事」という方針があるので、この文書の音量は「出発点」です。直すべき正解ではありません。

## 1. ジャズ（スウィング／ビバップ／モード／ジャズロック）

### 1-1 ドラム

ジャズのドラムは「リズムを刻む」より「空気を動かし続ける」役です。ロックのように、キックとスネアが土台になる形ではありません。

基本の役割（出典: Drumeo、BYUの打楽器ジャズ解説、Jazz Academy、日本のジャズドラム解説サイト）:

| 道具 | 役割 | 強さの目安 |
|---|---|---|
| ライド | 4分音符を切れ目なく。2拍目と4拍目の少し前に「跳ねる」8分をつける（タッ・ターン・タタ・ターン、の形） | 中くらい。常に一定 |
| 足のハイハット | 2拍目と4拍目で閉じる「チッ」。ドラム全体の時計 | ごく小さい |
| キック | 「フェザリング」。4つ打ちを、聞こえるか聞こえないかの音量で。音というより、ベースの足元を支える振動 | とても小さい |
| スネア | コンピング（会話）。決まった形は無く、ソロの人の動きに反応する。弱いゴーストを散らし、ときどき強い一打 | 小さい。時々だけ強く |
| クラッシュ | 曲の大きな区切りだけ。あまり使わない | 中 |
| タム | フィルの彩り。メロディのように叩く（音程の上下を使う） | 中 |

ライドパターンの考え方:

- 4分音符の連打（ライドの「スパング」）が土台。ここに「スパン・スパン・ガ・スパン」のように、拍の裏に付く音を入れる。
- 8分音符が3連符の2つ目と3つ目をまとめる形（長・短）に聞こえるのが、スウィング。スウィング比は一定ではなく、テンポが速いほど1:1（まっすぐ）に近づく。遅いと2:1より深く、3:1に近づくこともある。研究（Friberg & Sundström の分析など）では、速い曲ほど比が小さくなる、とされる。
- 曲全体の `swing` は、テンポに合わせて変える。いまのコードでは 0.6 がやや軽いスウィング、0.7 が標準、1.0 が完全な3連符。速い曲（BPM 220前後）は 0.4〜0.5 くらいにして、跳ねすぎを避ける。

ブラシ（バラードや静かな曲）:

- ブラシは、スネアの上でこすって円を描く。円を描くたびに、2拍目と4拍目で「パシッ」と軽く叩く。
- 本物のブラシの音は作曲ソフトに無い。代わりに、snare パートの音量を 0.04〜0.06 まで下げ、`g:` の o（ゴースト）を8分で並べると近い雰囲気になる。完全には再現しない。

フィル:

- ジャズは「フィル」ではなく「会話の相づち」。小節の頭ではなく、フレーズの切れ目に入れる。
- 4小節または8小節の終わりに、スネアとタムで短く。長く派手なフィルは使わない。
- クラッシュは、ソロの切り替わりの頭に1発。長く鳴らして、余韻を響かせる（crash パートは次の打撃まで最大8拍鳴る）。

奇数拍子のジャズ（5/4、7/4）:

- 5/4 は 3+2 のことが多い。ライドは4分音符で5つ、足のハイハットは 2・4 でなく、グループの終わり（3拍目の裏と5拍目）に合わせる曲もある。
- テンポが遅めの5/4（BPM 160 前後の4分音符）だと、ライドは軽いスウィングのまま続けられる。

ジャズロック（70年代の、ロックのビートにジャズの和音を乗せる形）:

- ライドの代わりに、ハットまたはライドで8分音符の直線。キックとスネアは強く、2・4拍にスネアを入れる。
- 詳しくは次の章（フュージョン）に近い。

### 1-2 ベース

- ウォーキングベース: 4分音符の連続で、1小節に4音。1拍目はコードのルートが基本。2拍目と3拍目はコードの構成音（3度・5度・7度）かスケールの音。4拍目は、次の小節の頭のルートへ半音上か半音下から入る（アプローチノート）。
- 小節をまたぐ「順次進行」（階段のように動く）を中心にし、同じ音を連続させない。大きく跳ぶのは、小節の頭だけ。
- 4分音符を均等に、少し後ろ（遅め）に置くと、ジャズらしい「ゆったりした推進力」になる。
- 音域は、E1 から G3 の範囲（作曲ソフトの制限）。ギターが下に来ないように、ベースを低く（D2〜D3 が中心）。
- 音の伸ばし方: ウッドベースらしい、短めの余韻。`sustain` は 0.8〜1.2、音の長さを1拍ちょうどにせず少し短くして、次の音の前に切る。
- アンプは `jazz`（低音 +3dB、高音 −6dB、4500Hz から上をカット）が合う。
- ウッドベースの特徴の「弦のこすれ（ノイズ）」と「アタックの丸さ」は、`bright` を下げて近づける。

ベースが引き立つ理由（ミックスの研究）: SoundOnSound の「ジャズ・カルテットを録る」「ミックス救出（ジャズトリオ）」の記事では、ウッドベースの重要な帯域は 80〜250Hz（太さ）、指板の音（アタック）は 700〜1kHz。キックが小さいので、ベースが低域の主役になる。

### 1-3 ギター

ジャズのギターは「コンピング」。メロディの合間に和音を置く、会話の相づちです。

フレディ・グリーン奏法（4つ刻み）:

- 小さく4音を、すべて4分音符で。ドラムのライドに溶け込む。音量はとても小さく、ベースとドラムの下に隠れていてよい。
- 4弦だけ（低い2本を除く）、3音または4音のシンプルな和音（ルートを弾かないことも多い、ベースが持つから）。
- 余韻を残さず、短く切る。`strum.ring` を false、パート `sustain` を 0.5 にする。

通常のコンピング:

- 拍のうらの「アンティシペーション」（次の小節の頭を8分前に弾く）や、2拍目の裏と4拍目の裏に和音を置く。
- 4拍目の裏に入れる小さな音は、ドラムの会話と重なって気持ちいい。
- 休符が半分以上。「弾かない時間」を残す。

ボイシング:

- ルートを省き、3度と7度を中心にする（ガイドトーン）。これでベースとぶつからず、コードの明るさ・暗さが決まる。
- 9度、13度などの「テンション」は、トップ（一番高い音）に置く。
- 作曲ソフトでは、13 などが書けないので、`9` `maj9` `m9` を使うか、ストラムではなく音を直接書く（`G3:0.5 B3:0.5` など）。

エフェクト:

- ジャズのギターは基本、ほぼドライ（空間系を足さない）。リバーブは、ほんの少し（部屋の自然な響き）。
- コーラス、ディレイは使わない。トーンは丸く、高音を削る（amp `jazz`）。

単音のメロディが電子的に聞こえないために:

- 音の頭を少し「なぞる」（スクープ、`/`）と生っぽい。ただし連続では使わない。
- 音の長さをそろえすぎない。強弱もつける（`!` と `,` を混ぜる）。
- `human` を 0.3 前後にして、拍の位置にわずかなゆれを持たせる。

### 1-4 合わせ方

周波数の住み分け:

| 楽器 | 中心になる帯域 | 避ける帯域 |
|---|---|---|
| ベース（ウッド） | 60〜250Hz、アタックは700Hz前後 | 250〜400Hz のこもりは削る |
| ギター（コンピング） | 200Hz〜3kHz | 100Hz 以下はカット |
| ライド | 5〜12kHz（チン）、300Hz（ガン） | 低域は削る |
| スネア（ブラシ） | 200Hz、5kHz | — |
| キック（フェザリング） | 60〜80Hz。ほとんど聞こえない | 強調しない |

- 音量のバランスは、ベース > ライド > ギター > スネア > キック（フェザリング）の順が出発点。
- パンニングは、ジャズでは「実際のステージ」に近づける。ドラムの中央からライドを右寄り（0.25）、ギターを左寄り（−0.2）。ベースは中央。

テンポの感じ（タイミング）:

- 研究（Nature の Physics 系論文、Friberg ほか）では、ジャズのバンドは「ベースが少し前」「ソロ奏者の拍の頭が少し後ろ」になる。BPM 150前後でソロ奏者の頭が約 30ms 遅れ、テンポが遅くなると差が縮む。
- 作曲ソフトで再現するには、スネア（コンピング）に `push: 0.03` のような小さい値、またはメロディパートの `pushMs` を負でなく正（後ろ）にする。ベースには `grooveFeel: "pushed"`（ほんの少し前）が使える。

決め手:

- ライド（ドラム）、ベースの4分音符、ギターの小さな和音の3つが、同じ「時計」を共有していること。
- 3つがぴたりと揃うより、ほんの少し前後する「呼吸」があること。

### 1-5 失敗と対策

| 失敗 | 原因 | 対策 |
|---|---|---|
| ロックっぽく聞こえる | スネアが2・4拍で強い。キックが大きい | スネアのバックビートをやめて、ゴーストだけにする。キックは 0.07 以下 |
| スウィングが機械的 | `swing` だけで、強弱が均一 | ライドの8分に `!` と `,` を交互に。`human` を 0.3 |
| ギターが邪魔 | 休みが少ない。余韻が長い | 休符を半分以上にする。`ring` を false |
| ベースが濁る | ギターもベースも 150Hz 付近 | ギターの下のほうの音（E3 以下）を使わない |
| ライドが途切れて聞こえる | 同じ crash パートにクラッシュも書いた | ライドとクラッシュは別パートにする（ring が次の打撃で切れるため） |
| 警告「クラッシュとハイハットが同時」 | チェッカーの誤検出 | 無視してよい（ライド＋足ハイハットは正しい） |

### 1-6 作曲ソフトでの書き方

確認済み（ビルドが通った）ジャズ・トリオの型。BPM 150、ii-V-I。

```json
{
 "bpm": 150, "beats": 4, "chords": "Dm7 G7 Cmaj7 Cmaj7", "barsPerChord": 1, "repeats": 2,
 "autoAccompaniment": false, "feel": "pop", "tone": "rock", "swing": 0.7, "human": 0.3, "dynamics": "natural",
 "parts": [
  {"instrument":"crash","role":"ライド","volume":0.12,"pan":0.25,"notes":"D2:1 D2:0.5! D2:0.5, D2:1 D2:0.5! D2:0.5,"},
  {"instrument":"hihat","role":"足のハイハット(2・4拍)","volume":0.10,"pan":-0.3,"notes":"g:....x.......x..."},
  {"instrument":"kick","role":"フェザリング","volume":0.07,"notes":"g:o...o...o...o..."},
  {"instrument":"snare","role":"コンピング","volume":0.10,"push":0.03,
   "notes":"g:................ g:..........o..... g:............o... g:........o......."},
  {"instrument":"bass","role":"ウォーキング","volume":0.2,"amp":"jazz","sustain":1.1,
   "notes":"D2:1 F2:1 A2:1 Ab2:1 G2:1 F2:1 D2:1 Db2:1 C2:1 E2:1 G2:1 A2:1 B2:1 A2:1 G2:1 Gb2:1"},
  {"instrument":"guitar","role":"フレディ・グリーン風","volume":0.14,"pan":-0.2,"amp":"jazz","sustain":0.5,
   "strum":{"pattern":"DDDD","step":1,"strings":4,"ring":false,"spreadMs":6}}
 ]
}
```

書き方のポイント:

- ライドの書き方: `D2:1 D2:0.5! D2:0.5,` で「タ・タタ」。4分1つ、8分2つ（強、弱）を2回で、1小節。
- ライドベル（`F2`）は、サビやソロの高まりで、ライドの代わりに数小節だけ。
- 足ハイハットの `g:....x.......x...` は、2拍目と4拍目だけ（16文字で1小節）。
- 速いウォーキングはコードごとに4音を書く。Dm7 は D F A Ab（ルート・3度・5度・半音下）で次の G7 へ、という考え方（G の半音上 Ab から G へ）。
- ジャズロックにしたいときは、ライドをハットの8分に変え、スネアを 2・4 拍に置き、`swing` を 0.0〜0.2 にする。

## 2. フュージョン／ジャズファンク（日本のフュージョン含む）

### 2-1 ドラム

フュージョンは、ジャズの和音とロックの強さ、ファンクの16ビートを混ぜた音楽です。

- 16ビートが基本。ハットまたはライドで16分音符を並べ、強弱をつける（1つおきに小さいゴースト）。
- スネアは2・4拍の強い音に、前後の16分に小さいゴーストを付ける。ゴーストの強さは、本打ちの20〜30%。スネアのゴーストは、グルーヴの「うねり」を作る（Drum! Magazine のゴーストノート解説、Sound Quest の16ビート解説）。
- キックは、ベースとの「かみ合い」で決める。1拍目と、ベースが弾かない所に置く。16ビートのキックは、1拍目、2拍目の裏のウラ、3拍目の頭などがよく使われる。
- ハットを開ける（O）のは、拍の裏の終わりに。1小節に1〜2回まで。
- 小節の終わりのフィルは、16分のタム回し。次の小節の頭のクラッシュで締める。
- 日本のフュージョン（カシオペア、T-SQUARE）は、8ビートまたは16ビートで、ドラムは「歌う」ようにメロディの区切りに合わせる。曲の頭は、ドラムとベースのユニゾンのキメを使うことも多い。

### 2-2 ベース

- 16分音符のシンコペーション。キックの隙間に音を入れる（キックと同時に鳴らさなければならない所だけ同時）。
- ジャコ・パストリアスに代表されるフレットレス: 音の頭がなめらか、スライドで音程を移動、ハーモニクスを使う。作曲ソフトでは `glide`（スライド）と `~`（ビブラート）を使えばニュアンスが近づく。
- スラップは、既存資料の方針で「スラップの曲の伴奏ギター」が禁止対象。ベースのスラップそのものは禁止ではないが、ギターとの両立に注意（ギターが短い単音を並べないこと）。
- ベースとギターの音域分け: ベースは E1〜G3、ギターのカッティングは E3 より上。

### 2-3 ギター

- カッティング: 16分音符の「ツクツクツク」。2〜4弦だけを使い、短く切る。`strum.pattern` の `x`（ミュートの刻み）を混ぜる。
- 和音はテンションが多い。9th、maj9、m9 が中心。
- 通常の演奏の直後に急にミュートへ切り替わると不自然、という決まりがあるので、`x` は拍の流れの中で自然に混ぜる（`gxDgxDgxD...` のように、ゴーストと下げを交互）。
- エフェクト: クリーンでコーラスなし（決まり）。薄いリバーブだけ。アンプは `crystal` または `funk`。
- メロディ（リード）: ロックのクランチ系ではなく、`crystal` またはクリーンに薄いディレイ。日本のフュージョンでは、EWI（電子管楽器）やシンセがメロディを担当することも多い。
- 2本のギター: 1本は和音のカッティング、もう1本はオブリガート（メロディの合間のフレーズ）。パンで左右に分ける（±0.3）。

### 2-4 合わせ方

- キック、スネア、ハット、ベース、ギターのカッティングは、すべて16分音符の同じ格子の上にある。どれか1つが16分の位置を外すと、全体がだらしなく聞こえる。
- ベースとキックは「同じ位置」と「違う位置」を意識する。同じ位置は強調、違う位置は会話。
- ギターのカッティングは、ハットと同じ位置に置くと溶け込む。ズラしたいときは、休符を入れて。
- カシオペアは「アンサンブル重視」（バンド全員で緊密に）、T-SQUARE は「メロディ重視」（曲の旋律を前に出し、和声は比較的わかりやすく）、という違いが、日本語のウィキペディアや解説から読み取れる。

周波数の目安:

| 楽器 | 中心 |
|---|---|
| キック | 60〜100Hz（アタック 3〜5kHz） |
| ベース | 80〜250Hz（アタック 800Hz〜1.5kHz） |
| スネア | 200Hz（ボディ）、4〜6kHz（鳴り） |
| ギターのカッティング | 400Hz〜4kHz |
| ハット | 8kHz 以上 |

### 2-5 失敗と対策

| 失敗 | 原因 | 対策 |
|---|---|---|
| 16ビートが固い | ゴーストが全部同じ強さ | `o` と `x` と `X` を混ぜ、`swing16` を 0.15〜0.3 |
| ベースがうるさい | キックと全部重ねている | ベースをキックの隙間に。同時は1小節に2回まで |
| ギターが機械的 | 同じ強さの連打 | `strum.pattern` に `D d U u x g` を混ぜ、アクセントを変える |
| 全体がぎこちない | `human` が 0 | 0.2〜0.35 にする |

## 3. プログレッシブロック（シンフォニック／変拍子／テクニカル）

### 3-1 ドラム

- 変拍子の基本は「小さな塊の足し算」。7/8 は 2+2+3 または 3+2+2、5/4 は 3+2、11/8 は 3+3+3+2（音楽理論の解説、Open Music Theory、Kevin Hartnell の11/8採譜解説）。
- 塊の頭にキック、または強いアクセントをつけると、聴く人が拍子を迷わない。スネアは、長い塊（3）の頭か、塊の終わりに。
- ハットまたはライドは8分音符を刻み、塊の頭を少し強く（`X` と `x`）。
- セクションが変わるとき、拍子が変わる曲では、ドラムが新しい拍子の「見本」を最初の小節で示す。聴く人は、ドラムで拍子を覚える。
- プログの名ドラマーの傾向: 数多くのタムとシンバルを使う（ニール・パートは大きなセット）。作曲ソフトで再現するときは、タムの音程（C4 から A2）を、メロディのように上下させる。
- 余韻を残すシンバル: 次のセクションの頭のクラッシュを、前の小節の最後のフィルに被せるとドラマチック。
- フィルは、拍子の塊に合わせて切る。7/8 なら、最後の塊（3）をフィルに使う。

### 3-2 ベース

- クリス・スクワイア（Yes）のように、ベースが「リードに近い」役を担う。リッケンバッカーの鋭い音で、メロディのように動く。ギターの低い音を担うので、ギターは高い音域に。
- ピック弾きかフィンガーの選択: ピックは音の頭がはっきり、フィンガーは丸い。プログでは両方使われる。作曲ソフトでは、アンプ `rock` または `hardrock` と `sustain` で調整（ピックっぽさは `bright` を上げる）。
- ベースとキックは、変拍子では「塊の頭」で同時に。塊の中間はベースだけ動く、という書き方が混乱しにくい。
- 低域の整理: ベースが速いと、キックと混ざる。キックのアタックを強く、ベースは少し短めに。

### 3-3 ギター

- スティーヴ・ハウ（Yes）のように、クリーン（アコースティック）とエレキが交互に。ハーモニクスの使い方が特徴。
- アレックス・ライフソン（Rush）のボイシングは、開放弦を混ぜ、コード（和音）の一部をシンプルにしたまま「広がり」を作る（Guitar Player の解説）。三和音の中の3度を省いて、ドローン（持続する音）を足す。
- ギターが2本の場合: 1本はアルペジオ（分散和音）で音を並べ、もう1本は長い音（ロングトーン）で和声を作る。
- シンフォニック: キーボードと、オーケストラ的な層。ギターはあまり前に出ず、キーボードの合間にソロ。
- 歪み: ソロはクランチではなく、サステインのある `rock` または `hardrock`（決まり: リードにクランチは使わない）。

### 3-4 合わせ方

- 構造: 「組曲」型（複数の短い曲をつなげる）、「循環」型（最初の主題が最後に戻る）。Quetzal バンドの「プログレッシブな曲の構造」や Wikipedia の解説にまとめられている。
- 拍子が変わる所で、全員が同じ塊を意識する。ドラム、ベース、ギターのリフが、同じ塊の区切りで一斉にアクセントをつける。
- 音量: セクションごとに大きく変える。静かな部分は、ほとんどソロや2人だけ。盛り上がりで全員。
- 周波数: ベース 40〜250Hz、ギター 100Hz〜5kHz（低域は切る）、ドラム全体は倍音が広く、トップのシンバルは 8kHz 以上。キーボードを足す場合、中域（500Hz〜2kHz）がギターと重なるので、パンで分ける。

### 3-5 失敗と対策

| 失敗 | 原因 | 対策 |
|---|---|---|
| 拍子が聞き取れない | 塊の頭に何もない | キックまたはクラッシュで塊の頭を示す |
| 技巧が目立つだけ | 休みがない | 曲の半分は静かな場面にする |
| 拍子が崩れる | グリッドの数え間違い | 「文字数 ÷ 4 = beats」を毎回確認 |
| 曲が長いだけ | 展開に意味がない | 主題を最後に戻す（循環）。途中で楽器を1つずつ抜く |

## 4. ポストロック／アンビエントロック

### 4-1 ドラム

- 静かに始まり、少しずつ盛り上がる（クレッシェンド）。ドラムは最初は何もないか、リムクリック（スネアの縁）や小さなハットだけ。
- 盛り上がりでは、タムのロール（転がし）、クラッシュを長く鳴らす。次の拍に被せない。
- 基本は8ビートに近いが、パターンを単純にして、音量と音色の変化で盛り上げる（Explosions in the Sky、Mogwai の手法として MusicRadar などの記事で紹介）。
- 曲の山のあとに、突然の静けさ（ブレイク）。ここでシンバルの余韻だけを聞かせる。

### 4-2 ベース

- 長い音（ロングトーン）。ルートを2小節〜4小節伸ばし、ギターの層を下から支える。
- 盛り上がりで、1オクターブ下を足す、または8分音符の連打に変わる。
- ポストロックでは、ベースがメロディを歌うこともある（Mogwai など）。そのときはギターを静かにして音域を空ける。

### 4-3 ギター

- ボリュームスウェル: 音の頭を消して、ゆっくり音量を上げる。バイオリンのように聞こえる。`swell: true` や `<` `>` の記号で近づけられる（Guitar World のスウェル解説）。
- ディレイの設定: 付点8分（dotted 8th）のディレイが定番。時間は 45000 ÷ BPM(ms) の式（既存資料と同じ）。作曲ソフトの fx では `beats: 0.75`（付点8分＝4分音符の0.75倍）。
- アルペジオ: 同じ音型を何度も繰り返し、少しずつ層を足す。ここでコードが変わっても、アルペジオは同じ音型のまま。
- ロングトーン: 高い音域（B4〜B5）で、薄いリバーブと一緒に。
- 歪み: 盛り上がりで、ファズまたはシューゲイザー・アンプに切り替える。静かな場面はクリーン。ここでコーラスは使わない（決まり）。
- 2本のギターの役割: 1本は「刻む／アルペジオ」、もう1本は「伸ばす／スウェル」。パンを左右に振る。

### 4-4 合わせ方

- 曲の進め方: 「楽器を足していく」。ギター1本、次にベース、次にギター2、次にドラム、最後に全員。
- 周波数: 低域はベースだけに任せる。ギターの層を重ねるほど、中域（300〜800Hz）が濁るので、各ギターの音域を分ける（低い層は E3〜B3、中は E4 あたり、高いは B5 以上）。
- 空間: リバーブは長め（2〜4秒）。ただし全部に掛けると滲むので、ドラムは少なめ。
- 山の作り方: 音量を上げるだけでなく、「音数」「音域」「歪み」「ドラムの密度」を順に足す。

### 4-5 失敗と対策

| 失敗 | 原因 | 対策 |
|---|---|---|
| 退屈 | 変化がない | 4小節か8小節ごとに、楽器1つだけ足す、抜く |
| 濁る | 層が重なりすぎ | 音域を分ける。ディレイのフィードバックを下げる |
| 山が小さい | 音量だけで盛り上げた | ドラムの手数、歪みも変える |
| 終わり方が弱い | 最後が急に終わる | 余韻（リバーブ、ディレイ）を残す。クラッシュの長い余韻で終わる |

### 4-6 作曲ソフトでの書き方

層を重ねる方法（`parts` の最大は32）:

```json
{"instrument":"guitar","role":"アルペジオ(序盤から)","volume":0.08,"pan":-0.6,"amp":"clean","reverb":0.5,"chorus":0,"fingerpick":true},
{"instrument":"guitar","role":"スウェル(中盤から)","volume":0.06,"pan":0.6,"amp":"clean","swell":true,"sustain":4,"reverb":0.6,"chorus":0,"fx":[{"type":"delay","beats":0.75,"mix":0.3}]},
{"instrument":"leadGuitar","role":"高い単音(終盤)","volume":0.05,"amp":"crystal","sustain":3,"reverb":0.6}
```

- 「途中から入る」を書くには、最初の数小節を休符 `R:8` で埋めておく。例: `R:16 E3:8 ...`。
- クレッシェンドは、音符に `<`（だんだん大きく）をつける。パート全体の音量を急に変えるより、自然。
- ディレイは `fx[]` の `delay` に `beats: 0.75`。ビートに同期するので、BPMを変えてもずれない。

## 5. インディー／シューゲイザー／ドリームポップ

### 5-1 ドラム

- インディー: シンプルな8ビート、または4つ打ち寄り。キックとスネアは堂々としすぎず、少し「ゆるい」（`grooveFeel: "laidback"`）。
- シューゲイザー: ドラムは控えめ。スネアは音量が小さく、リバーブ多めの「奥」に置く。キックは低めでぼんやり。マイ・ブラッディ・ヴァレンタイン『Loveless』は、ギターの層を引き立てるために、リズムが一定でシンプル。
- ドリームポップ: ハットの8分はごく小さく。スネアに薄いリバーブ。
- フィルは少なく、あっても短い。大きなフィルでは音の壁が割れる。

### 5-2 ベース

- 太く丸い。ルート中心の長い音（`sustain` 1.5 以上）。ギターが上に層を作るので、ベースは下の1本の線として動かない。
- ポストパンク寄りのインディー: ベースがメロディを担当（ピーター・フック風）。高い位置の繰り返し音型で、ギターは壁やコードに。出典: Louder の「Joy Division / New Order のベース」。
- ギターと音域が重ならないように、ベースの高い音（G3 以上）はギターの中域と衝突する。

### 5-3 ギター

シューゲイザーの音の作り方（出典: Riffhard、Mixdown、Tape Town Studio、Music Gear Specialist など）:

- 歪みは「ファズ」や「ビッグマフ」に近い、厚く丸い音。作曲ソフトではアンプ `shoegaze`（drive 18、非対称クリップ、4kHz カット）を使う。
- 音の壁は、歪みを足すのではなく、「層を重ねる」「リバーブを深く」「音域を分ける」ことで作る。
- グライド（音程のなめらかな変化。トレモロアームで揺らす）が特徴。作曲ソフトでは `glide` を使う。
- 逆再生のリバーブ、長いディレイ、ピッチシフトもよく使われるが、作曲ソフトでは、長いリバーブと `fx` のディレイで近づける。
- コーラスは使わない（決まり）。`gtrStyle: "shoegaze"` は内部で chorus 0.6 が掛かるので、使うなら `chorus: 0` で明示的に打ち消す。
- `humanPitch: 0` と `autoScoop: false` にして、音程が勝手に揺れないようにする。

インディーロック（きらびやか系）:

- クリーンまたは軽いクランチで、開放弦を使ったアルペジオ。2本のギターが違うリズムで、絡み合う。
- ディレイは付点8分。U2 のエッジ（The Edge）の手法として、MusicRadar の解説にある。

ドリームポップ:

- クリーンな音にリバーブを深く。高音域のコード（9th、maj7）の持続。出典: Reverb の「ドリームポップを自宅で録る」。

### 5-4 合わせ方

- シューゲイザーの周波数: ベース 40〜200Hz、ギター層は 200Hz〜6kHz。低域をベースとキックだけに空け、ギターは 150Hz 以下を切る。
- 層の分け方: 左に低い層、右に中の層、中央少し上に高い層。パンは ±0.85。
- ボーカル（このゲームでは歌なし）がない場合は、リード楽器（高い単音）が「光」を担当。
- 奥行き: ドラムは奥（リバーブ多め）、ギターの層は中、リード単音は前（ドライ寄り）。

### 5-5 失敗と対策

| 失敗 | 原因 | 対策 |
|---|---|---|
| 音の壁が割れる | 歪みをすべて強くした | 層を分け、歪みは1〜2本だけ。他はクリーンまたは弱め |
| きゅいんきゅいんする | クリーンにコーラス | `chorus: 0` |
| ぼやけて音程が分からない | 全部が同じ音域 | 層の音域を B3、E4、B5 のように離す |
| 低域がこもる | ギターの低い音が残っている | ギターは E3 以上。ベースだけが E2 以下 |
| ドラムが消える | リバーブが多すぎ | スネアのアタックを残し、リバーブの返りを抑える |

## 6. エレクトロニック＋バンド（ダンスロック／シンセポップのバンド編成）

### 6-1 ドラム

- ダンスロック（ダンスパンク）の基本: キックの4つ打ち（フォー・オン・ザ・フロア）。スネア（またはクラップ）は2・4拍。ハットは裏拍（8分の裏）にオープン（O）を置く。出典: Attack Magazine「Raw Dance Punk」、Soundbrenner の4つ打ち解説。
- シンセポップのバンド編成: 8ビート。スネアに強めのゲートリバーブ風の長めの余韻（80年代風）。タムの転がしはシンセに近い音程の動きで。
- ハットを16分で刻み、1小節に1〜2回だけ開ける。
- ブレイク: 1小節だけキックを抜く（ドロップ）と、次の頭で強く聞こえる。

### 6-2 ベース

- オクターブ奏法（低い音と1オクターブ上を交互）: ディスコ、ダンスロックの定番。8分音符で、ルート → オクターブ → ルート → オクターブ。
- ベースシンセを使うなら、音の頭がはっきり（アタック短め）、キックと同時に鳴らさず「キックの間」に。
- ピーター・フック風: 高い位置の単音で、メロディのように動く。ギターは和音を伸ばすだけ。
- キックとのかみ合わせ: サイドチェイン（キックが鳴る瞬間にベースの音量を下げる）が一般的。作曲ソフトでは `duck` が近い効果を出す。サイドチェインの目安は、ベースを2〜6dB下げ、アタック 5〜10ms、リリース 80〜150ms（MusicRadar、Sonarworks の解説）。

### 6-3 ギター

- ダンスロック: 短い、シャープなカッティング（8分または16分）。ハットの裏拍と溶け合う。
- シンセポップのバンド: ギターは主役ではない。クリーンの小さな刻み、またはアルペジオで、シンセの層を飾る。
- エッジ風の「ディレイを使ったリズムギター」: 付点8分のディレイで、実際に弾いていない音が聞こえる。
- ディストーションは控えめ。ダンスロックのリフは `punk` または `rock` で、短い8分のミュート刻み（パームミュート）。
- パームミュートを使う場所: 8分音符の連打、リフ。使わない所: ロングトーン、コードの頭を伸ばす場面。

### 6-4 合わせ方

- キックとベース: 同じ位置に鳴らして一体化させるか、サイドチェインで分ける。どちらかに決めておく。
- ギターは、ハットの裏拍と同じ位置に置く。キックの位置を空ける。
- シンセ（ここではパッド、リードなど）: ギターと同じ中域を使うので、パンで分けるか、音域で分ける。

| 帯域 | 担当 |
|---|---|
| 40〜100Hz | キック |
| 80〜200Hz | ベース（キックのない瞬間） |
| 200〜500Hz | ギターの太さ、スネアのボディ |
| 1〜4kHz | ギターの存在感、リードシンセ |
| 5〜12kHz | ハット、シンバル、ギターの空気感 |

### 6-5 失敗と対策

| 失敗 | 原因 | 対策 |
|---|---|---|
| 低域が飽和 | キックとベースの低音が重なる | `duck` を使う、またはキックとベースをずらす |
| ダンスの勢いが出ない | キックが弱い、ハットの裏拍がない | 4つ打ちを強く。オープンハットを裏に |
| のっぺりする | 全部が一定の音量 | セクションごとに、ハットの数や、ギターの有無を変える |
| ギターが埋もれる | シンセと同じ帯域 | ギターを 1〜4kHz に集中させ、パンを分ける |

### 6-6 作曲ソフトでの書き方

ダンスロックの型（検証していない部分は耳で確認してください）:

```json
{"instrument":"kick","role":"4つ打ち","volume":0.18,"notes":"g:X...X...X...X..."},
{"instrument":"snare","role":"2・4拍","volume":0.12,"notes":"g:....X.......X..."},
{"instrument":"hihat","role":"裏拍のオープン","volume":0.09,"pan":0.3,"notes":"g:..O...O...O...O."},
{"instrument":"bass","role":"オクターブ","volume":0.2,"duck":0.3,"notes":"A1:0.5 A2:0.5 A1:0.5 A2:0.5 A1:0.5 A2:0.5 A1:0.5 A2:0.5"},
{"instrument":"guitar","role":"短いカッティング","volume":0.1,"pan":-0.3,"amp":"punk","strum":{"pattern":"x.D.x.D.","step":0.5,"strings":3}}
```

- `O` は hihat だけで使える。
- `duck` の効き具合は、ほかのパートの記述を参考に 0.2〜0.4 から試す。
- 付点8分のディレイは `fx` で `{"type":"delay","beats":0.75,"mix":0.3}`。
- ダンスロックの、ギターの `amp` は `punk`（短い歯切れ）または `rock`。ここでも、リードを `crunch` にしない決まりがある。

## 8. 有名曲の構造分析（歌詞・メロディは書きません）

どれも「どういう順番で、誰が何を担当するか」の見方です。細かい小節数は、聴いて確かめてください。

### 8-1 "Take Five"（Dave Brubeck Quartet、5/4、ジャズ）

- 拍子: 5/4（3+2）。ピアノが2つの和音を行き来する短い反復（ヴァンプ）で、5拍の周期を刻む。
- ドラム: 最初にドラムが5/4のパターンで入り、その後のソロでもこの周期を保つ。曲の中ほどにドラムソロがある。
- ベース: ピアノと同じ反復の低音。
- 構造: 反復 → サックスの主題 → サックスのソロ → ドラムソロ → 主題 → 終わり。
- 学べること: 変拍子でも、グループ（3+2）を一定に保てば、ソロで自由に動ける。ヴァンプの繰り返しが「ホーム」になる。

### 8-2 "Money"（Pink Floyd、7/4 と 4/4、プログレ）

- 拍子: 序盤のベースの反復は7拍子。ギターソロの部分は4拍子に切り替わる。
- 構造: ベースの反復リフ → 全員が入る → 拍子が4に切り替わる → ギターソロ → 7拍に戻る。
- 学べること: 変拍子のリフ（記憶に残る）と、普通の拍子のソロ（解放感）を交互に置く。ソロの部分で拍子を戻すと、聴く人が安心する。
- 作曲ソフトでの注意: 途中の拍子切り替えができないので、リフとソロを別のファイルにするか、長い小節に詰める。

### 8-3 "Roundabout"（Yes、プログレ）

- 構造: アコースティックギターの静かな導入 → ベースが主役の本編（リッケンバッカー）→ 複数の展開 → 静かな中間部 → 戻る。
- ベース: Chris Squire のベースは、メロディに近い動きで、ギターは高い音域とコードの刻みに回る。
- 学べること: 「静かな導入」と「ベースが前に出る本編」の対比。ギターとベースの音域分担。
- 参考: Guitar World の "Chris Squire: Roundabout ベース解説" 記事。

### 8-4 "Chameleon"（Herbie Hancock、ジャズファンク）

- 構造: シンセベースの反復リフが長く続く、2つのコード中心のヴァンプ。そこに、サックス、キーボードのソロが乗る。
- 学べること: ハーモニーの変化が少ないぶん、リズムのかみ合いで聴かせる。同じパターンを何分も続けても飽きないのは、上の楽器が少しずつ入れ替わるから。
- ドラムは16分のハットとゴースト、キックはベースの隙間に。
- 参考: Produce Like A Pro の "Songs That Changed Music: Chameleon"。

### 8-5 "Tom Sawyer"（Rush、プログレ／ハードロック）

- 構造: シンセのリフ → ギターとベースとドラムの全員 → 変拍子を含む展開 → ギターソロ → 戻る。
- 学べること: 3人（ギター・ベース・ドラム）でも、シンセ（鍵盤）の層で厚みを作れる。ギターのコードは、開放弦を混ぜ、広がりを作る（ライフソンのボイシング）。
- 参考: Synthtopia の "Synth Secrets of Rush's Tom Sawyer"、Guitar Player の Alex Lifeson 解説。

### 8-6 『Loveless』の曲群（My Bloody Valentine、シューゲイザー）

- ギター: 音程を揺らす（グライド）、複数の層、ぼかしたリバーブ。
- ドラム・ベース: 一定で単純。
- 学べること: 音の壁は、リズム隊の安定の上でこそ成立する。
- 参考: Wikipedia の Loveless 項目と、シューゲイザーのギター解説（Riffhard など）。

### 8-7 ポストロックの典型的な展開（Explosions in the Sky、Mogwai などの傾向）

- 構造: アルペジオの導入 → 層が増える → 小さな山 → 静かになる → 大きな山（歪み、ドラムのロール） → 余韻。
- 学べること: 山を2回作る。1回目は小さく、2回目に最大。

### 8-8 日本のフュージョン（カシオペア、T-SQUARE）

- カシオペア: バンド全体のアンサンブルを重視。16ビートで、テンションの多いコード。
- T-SQUARE: メロディを前面に、和音は比較的わかりやすい。8ビートも多い。
- 学べること: 同じフュージョンでも「アンサンブル型」と「メロディ型」で、書き方が変わる。作曲ソフトでは、前者は伴奏を細かく、後者はリードの音量を上げる。

## 9. 作曲ソフトへの提案（設計・資料）

優先度が高い順です。

1. **資料の修正（すぐできる）**: 0章の表の1〜10。特に、ライド（`D2`）とパート別 `swing`、`beats` の範囲、コード語彙の一覧を、`drum-genre-guide.md` `genre-guides.md` `song_guide` に書き直す。
2. **グリッド長のチェック**: `g:` の文字数が `beats × 4` の倍数かを、ビルドとチェッカーで警告する。奇数拍子の数え間違いが多いため。
3. **ライド＋足ハイハットの誤警告**: チェッカーで、crash パートの `D2/F2/E2` はクラッシュとして数えない。
4. **コード語彙の追加**: 13、11、alt、7#9、7b9、6/9、7#11（ジャズ、フュージョンで必須）。
5. **ストラムのアクセントを拍子に合わせる**: `grouping` から accent を導く。
6. **gtrStyle "shoegaze" のコーラス**: 既定を 0 にする（決まりと矛盾）。資料側の例も chorus 0 に。
7. **拍子の切り替え**: 曲の途中で拍子を変える機能（プログレに必須）。難しければ、セクションごとに別の `beats` を持てる仕組み。
8. **ブラシの音色**: snare の音色に「ブラシ」を足す（ジャズのバラード用）。
9. **ジャンル別の `grooveFeel` プリセット**: ジャズは「ソロ後ろ・ベース前」、インディーは「laidback」、ダンスは「少し前のめり」。
10. **サンプル曲**: この文書の確認済みJSONを `assets-src/ai-songs/` に追加する（ジャズ・フュージョン・7/8・5/4・11/8・シューゲイザー）。

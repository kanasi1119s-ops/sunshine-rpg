# コード進行を、似たものにしない手引き（2026-10-11 調査）

「今までの曲のコード進行が似ている」への対策。曲を作る前に、ここから**進行の型を1つ選び**、直前の曲と違うものにする。

[Secrets of Songwriting「定番進行をおもしろくする5つの案」](https://www.secretsofsongwriting.com/2021/06/11/making-standard-chord-progressions-more-interesting-try-these-five-ideas/) /
[Learn Jazz Standards「借用和音（モーダルインターチェンジ）」](https://www.learnjazzstandards.com/blog/modal-interchange/) /
[Yamaha「ギタリストのコード代理ガイド2」](https://hub.yamaha.com/guitars/g-how-to/a-guitaristss-guide-to-chord-substitutions-part-2-beyond-diatonic/) /

注意: 実在曲のコード進行をそのまま使わない（CLAUDE.md 1-1）。下の型は一般的な手法で、曲ごとに主音・順番・リズム・旋律を変えて使う。

## 1. 同じに聞こえる原因
- 4コードを1小節ずつ回す（I–V–vi–IV、vi–IV–I–V など）。度数が全部、基本の7和音（ダイアトニック）の中にある。
- 1コード＝1小節、同じ長さ。ベースが毎回ルートだけ。
- どの曲も長調か自然短調だけ。借用・転調・ペダルがない。

## 2. 変化をつける手法（効果つき）
| 手法 | やり方（C長調の例） | 効果 |
|---|---|---|
| 転回（スラッシュコード） | C C/E F F/A G7 G7/B C | ベースが歩いて流れる。コードは同じでも別物に聞こえる |
| サスペンド | G7sus4 → G7、Csus2、Dsus4 | 解決を引き延ばす。ぼんやり浮く |
| 借用和音（同主調から） | C F Fm C（IV→iv）、♭VI＝Ab、♭VII＝Bb、♭III＝Eb | 切なさ（iv）、力強さ（♭VII）、陰り（♭VI） |
| ペダルポイント | C F/C G7/C C（低音を C に固定） | 緊張が溜まる。ドローンのような安定 |
| 偽終止 | G7 → Am（または F、Ab） | 期待を外す。続きを聴かせる |
| 副ドミナント | A7→Dm、E7→Am、D7→G | 次のコードに引っぱる。ひとつの進行に1〜2回まで |
| 裏コード（トライトーン代理） | Dm7 Db7 Cmaj7（G7 の代わりに Db7） | ジャズ的になめらかな半音進行 |
| 半音進行・クリシェ | Am Am(maj7) Am7 Am6 | 内声が1音ずつ動く。陰りと流れ |
| 三度のとなり（クロマティック・メディアント） | C → E → Ab → C | 映画的な飛躍。調性がゆらぐ |
| 旋法のバンプ | ドリアン Dm–G、ミクソリディアン G–F、リディアン C–D | 2コードの往復。浮遊感・民族色 |
| 転調 | 最後のサビで半音上／全音上（直接）、共通和音を経由 | 後半で気持ちを持ち上げる |
| 非機能の平行移動 | C–D–E♭–F（同じ形を平行に動かす） | 目的地のない浮遊 |
| 小節の長さを変える | 1コード2小節／半小節ずつ／5小節で1周 | 拍の周期が変わる（変拍子もあり） |

## 3. 進行の型（レシピ）。ローマ数字は主音から。どれも曲ごとに主音とリズムを変える
| 型 | 進行（度数） | 向く場面 | 一言 |
|---|---|---|---|
| A 王道（使いすぎ注意） | I–V–vi–IV／vi–IV–I–V | ポップ | すでに多用。次は別の型にする |
| B 下降ベース | I–V/7–vi–I/5（C G/B Am C/G F） | 感動・別れ | ベースが階段状に下りる |
| C 借用の陰り | I–IV–iv–I | 郷愁 | iv で一瞬暗くなる |
| D ♭VII の力強さ | I–♭VII–IV–I | ロック・疾走 | 長調のまま荒々しい |
| E 短調の三連 | i–♭VII–♭VI–V | 戦闘・追跡 | 下りてから V で締める |
| F 短調の浮遊 | i–♭III–♭VII–IV | 冒険 | 短調なのに明るい色（ドリアン寄り） |
| G 偽終止 | I–vi–IV–V→vi（解決しない） | 物語・つづき | 終わらせず次へ |
| H ペダル | I–IV/1–V/1–I（低音固定） | 緊張・ダンジョン | 動かない低音の上でコードが揺れる |
| I 半音クリシェ | i–i(maj7)–i7–i6 | 不穏・謎 | 内声だけが動く |
| J 三度の飛び | I–♯III（=E）–♭VI–I | 映画・壮大 | 遠い調へ飛ぶ |
| K ドリアン往復 | i–IV（Dm–G） | 民族・フィールド | 2コードで世界を作る |
| L ミクソリディアン | I–♭VII–IV（G–F–C） | ブルージー・ロック | 長調と短調のあいだ |
| M リディアン | I–II（C–D）／Imaj7–II | 空・浮遊 | 4度が半音上がる明るさ |
| N 副ドミナント連鎖 | III7–vi–II7–V–I（E7 Am D7 G C） | 古風・歌謡 | 5度でどんどん引っぱる |
| O 裏コード | ii7–♭II7–Imaj7 | ジャズ・夜 | 半音で滑り込む |
| P 平行移動 | I–II–♭III–IV（C D Eb F） | 不思議・幻想 | 調性がぼやける |
| Q 後半転調 | A 型を3回→最後だけ半音上 | 盛り上げ | 最後のサビで持ち上げる |
| R 5小節周期 | I–IV–V–♭VI–V（5小節で1周） | プログレ | 拍の周期をずらす |

## 4. 使い方（作曲前の手順）
1. 場面から候補を2〜3個選ぶ。直前の曲の型（`song.mjs` が過去曲との一致を警告する）と違うものにする。
2. 主音を変える（C 以外。ギターなら E・A・D・G のほかに F#・B♭・C#）。
3. 1コードの長さを変える（1小節固定にしない。2小節・半小節・不規則）。
4. ベースを根音だけにしない（転回・ペダル・クリシェ）。
5. 途中で1回は、型の外の和音（借用・副ドミナント・偽終止）を入れる。
6. build の警告「コード進行が〇〇の曲と同じ形です」「基本の和音だけです」を直す。

# 銀の笛と百の夜 — 作り直しの割り当て表（案・2026-10-29）

学んだこと（A 曲の種類と地域・B 楽器と編成・C 世界観と音作り・D O'Neill's 1850曲の分析）から、100曲それぞれに
「調べ（悲しみ／喜び／眠り／あいだ）・種類と形・拍子と速さ・旋法・笛の吹き方・伴奏の主役・始まりと終わり・山の形・この曲だけの仕掛け」を割り当てた。
**旋律そのものは毎回その曲のために新しく書く**（伝承曲は写さない）。

## これまでとの大きな違い
1. **曲の性格の配分**: これまでは 静 82曲・動 18曲で、ほとんどがゆっくりの曲だった。三つの調べで配り直して、**喜び 35・あいだ 31・悲しみ 18・眠り 16** にする（喜びの曲の多くは速い踊りの曲）（点数の目安は、ゆっくりの曲 7.0・速い曲 7.5）。
2. **伴奏の主役を曲ごとに変える**: これまで全曲に入っていた「竪琴・弦の持続・チェロ」は、その曲に要るときだけ。主役の伴奏は となりの曲と同じにしない。同じ楽器が主役になるのは多くて5曲で、そのときは弾き方（指弾き・断片・歩く低音・子守歌の揺れなど）を変える。
3. **打楽器**: 使うのは 100 曲中 26 曲。足拍子・手拍子・打音だけの曲もある。
4. **山の位置**: 伝統のエアは前半に一番高い所がある（O'Neill's の分析）。「後半3/4で一番大きく、そこから下がる」形は全体の 2 割まで。
5. **始まり方・終わり方**: 同じ始まり方が続かないようにし、前奏に「うすい弦の和音」を敷く始まりはやめる。
6. **曲の形**: AABB の踊りの形とスロー・エアだけでなく、主題と変奏（ピーブロック）、呼びかけと応答でだんだん速くなる（布打ち歌）、句の終わりが重なる受け渡し（ブルターニュ）、伴奏の旋律に別の旋律を重ねる（ウェールズ）、3部の哀歌、同じ節を何十回もくり返して少しずつ足す（アン・ドロ）、悲しみ→喜び→眠りの3つの調べを1曲で通る、などを使う。

記号: 笛＝木のフルート（低く息の多い〜高く柔らかい）／ホイッスル＝ティンホイッスル（高く明るい。少しだけ）／2本＝フルート2本。
伴奏の名前は「主役の伴奏（脇）」。打＝打楽器。

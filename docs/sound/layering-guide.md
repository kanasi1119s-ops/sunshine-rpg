# 音の重ね方の手引き（2026-10-08 調査）

「楽器をいくつも鳴らしても、濁らず、全部が聞こえて、まとまる」ための考え方と、うちの道具（曲JSON）での書き方。ミキサーで直すより前に、**編曲（どの楽器を、どの音域で、いつ鳴らすか）で場所を空ける**のが本筋。EQやコンプで直すのは最後。

調べた先: [Production Expert「周波数マスキングを防ぐ8つの方法」](https://www.production-expert.com/production-expert-1/8-ways-to-prevent-frequency-masking-in-your-mixes)、[Vintage King「ミックスに空間を作る」](https://vintageking.com/blog/create-space-in-mixes/)、[Wisseloord「濁らずに音を重ねる」](https://wisseloord.org/?p=48228)、[mastering.com「キックとベースの関係」](https://mastering.com/?p=30890)、[バンドサウンドのミックス（Trivision）](https://trivisionstudio.com/band-mixing-tips/)。数値は一般的な目安で、**最後は耳（とA/B）で決める**。関連: `mixing-guide.md`（ミキシング）、`music-knowledge.md`（楽器ごとの書き方）、`drum-fills.md`（おかず）。

## 1. 原則
1. **「それぞれの層に、息をする場所が要る」**。同じ帯域・同じ左右の位置・同じタイミングに、主役を2つ置かない。
2. **足す前に、引く**。曲が濁ったら、新しい音を足すより、今ある音を減らす（音域をずらす・休符を入れる・音量を下げる）。
3. **役割を1つずつ**。リズム／低音／和音／旋律／きらめき／空間。1つの役割に2パート以上要るなら、片方を別の帯域か別のタイミングにする。
4. **音量は遠近**。「大きいほど近く聞こえる」。主役は手前（大きい・明るい・残響少なめ）、脇役は奥（小さい・丸い・残響多め）。
5. **測って確かめる**。`analyze.py --bands` で、帯域のバランスと左右の広がりを見る。

## 2. 帯域の地図（Hz）と、うちの楽器
| 帯域 | 範囲 | 主な担当 | 注意 |
|---|---|---|---|
| 超低音 | 〜60 | キックの芯、sub808 | 低域は**モノ**（中央）に。多すぎると他が引っこむ |
| 低音 | 60〜250 | キック（60〜100）、ベース（80〜250）、ピアノ・ギターの低い弦 | **キックとベースが奪い合う帯域**。キック＝60〜70、ベース＝80〜120以上＋倍音、で分ける |
| 中低域 | 250〜1k | ギターの胴、ピアノ、ベースの倍音、スネアの胴 | **濁りの帯域**（200〜500）。持続音（弦・パッド・ピアノ・歪みギター）が重なると団子になる |
| 中域 | 1k〜4k | 旋律、アルペジオの輪郭、ギターの存在感 | 旋律の居場所。歪みギターや弦が占めると旋律が埋もれる |
| 張り | 4k〜8k | スネアの抜け、ハイハットの刻み、ピックの音 | 多いと耳に刺さる |
| 空気 | 8k〜 | シンバル、きらめき、残響の高域 | 少しで十分 |

## 3. 役割分担（編成の組み方）
| 役割 | 向く楽器（`instrument`） | 帯域・音域の目安 | 数の目安 |
|---|---|---|---|
| リズム（ビート） | kick・snare・hihat・tom・crash | 全域（キック低、ハット高） | 1セット |
| 低音 | bass、sub808 | E1〜E3 | 1（ギターが同じリフを1オクターブ上で重ねるとパンチ） |
| 和音（背骨） | guitar（コード）、piano、keys、pad | C3〜C5（開離配置は低音域、密集は上） | 1〜2 |
| 流れ（アルペジオ） | guitar（クリーン）、harpsichord、keys | D3〜D5 | 1〜2（別の速さで） |
| 旋律 | lead、leadGuitar、flute 系 | C4〜C6 | 1 |
| きらめき（飾り） | bell、高いアルペジオ、strings の高音 | C5〜 | 0〜1 |
| 空間（包む） | strings、pad、choir | 低域をあけて C3〜 | 0〜1 |
- 目安: 同時に主役級が鳴るのは**3〜4種類まで**。それ以上はどれかを背景（小さく・丸く）にする。
- ギター3点編成（ギター・ベース・ドラム）でも、アルペジオを2〜3本（遅い8分／速い16分／高いきらめき）重ねれば厚みが出る。音域とリズムの細かさを**別々**にするのがコツ。

## 4. 重ね方の技
- **オクターブをずらす**: 同じ旋律・リフを1オクターブ上（または下）で重ねると、音域がぶつからずに太くなる。ぶつかる2つのパートの片方を転置するだけでも分離できる。
- **リズムを噛み合わせる**: 片方が16分で動くなら、もう片方は白玉か8分。両方が細かいと団子。ギターが動く間、ピアノは休む（「ギターがリフの間、シンセはパッドかアルペジオ」）。
- **強拍と弱拍を分ける**: アルペジオは頭を強く（`!`）、2つ目の層は裏を強く。ベースとキックは頭をそろえて短め（スタッカート）に。
- **頭（アタック）と胴（ボディ）を分ける**: 短い音（pluck）の層と、伸びる音（pad・弦）の層を重ねる。アタック役は高域まで、ボディ役は低域を空けて丸く。
- **同じ音を左右に**: ダブル（同じパートを2本）は左右に振る。内側の層を少し小さく。
- **休符をパートの一部に**: 全員が休む1拍（ブレイク）や、旋律の切れ目で伴奏が一瞬引くと、次が立つ。サビ前に1拍の無音。
- **音数を管理する**: 起伏は、楽器数・音域・リズム密度のうち2つ以上を同時に上げる。

## 5. 密度の設計（場面ごとの重ね）
`sections` の自動伴奏の配分を、手書きの曲でも真似する（`arrangement.ts` の `LAYERS`）。
| 場面 | 重ねるもの | 目安 |
|---|---|---|
| イントロ | アルペジオ1本＋（後半にキック・ハット） | 1〜2種類 |
| Aメロ | アルペジオ＋ベース＋ドラム（ハーフタイムなど軽い型） | 3〜4種類 |
| Bメロ | 上に加えて和音の層（ピアノ・ギターのコード）、ドラムは基本のバックビート | 4〜5種類 |
| サビ | 別の流れのアルペジオ（16分）＋高いきらめき＋ベースは8分で動く＋ドラム全開（crash） | 5〜7種類 |
| 間奏・ブリッジ | 1〜2種類に絞る（ドラム休み）→ 最後におかず（ブレイク） | 1〜3種類 |
| アウトロ | 少しずつ引いて、アルペジオ1本に戻る | 1〜2種類 |

## 6. 左右の重ね（ステレオ）
- **中央**: キック・スネア・ベース・旋律（低域と主役）。
- **ドラムの `pan` は効かない**（ドラムは1チャンネルに集まるため）。ドラムの左右は曲の `drumMix`（太鼓ごとの pan）で決める。
- **左右**: 同じ役割の2本は反対側へ。アルペジオ・パッド・弦は ±0.4〜0.7。ハイハットは片側に寄せ（-0.35）、タムは高→低で左→右に（`drumMix.tom.spread`）。
- **広さの目安**: 左右の相関は 0.4〜0.88（参考37曲の平均は0.66）。0.9を超えたら狭い（真ん中だけ）。**広げるのは上の帯域**（中域より上）。低域は狭いまま。
- **広げる道具**: `pan`（左右）、`chorus`（揺らぎで広がる）、`reverb`（奥行き）。ハース効果（片側を遅らせる）はモノでへこむので、重要でない音だけ。

## 7. うちの道具との対応
| やりたいこと | 書き方（曲JSON） |
|---|---|
| 主役を前へ／脇役を奥へ | パートの `volume` を変える。奥に置くパートは `reverb` を上げ `bright` を下げる |
| 低音の整理（キックとベースを分ける） | ベースを短く（`sustain` を小さく）、`volume` をキックの -2〜-4dB に。**`duck` 0.2〜0.4**（キックの瞬間だけベースが引く＝サイドチェイン風） |
| 持続音の居場所を作る | 重なる2つの片方を `duck`、または音域をずらす |
| 左右に広げる | アルペジオの `pan` を ±0.4〜0.7。`chorus` 0.3前後を足す |
| 奥行き（ふんわり） | 脇役の `reverb` 0.4〜0.6、主役は 0.1〜0.3 |
| 高域の刺さりを抑える | `drumMix` の `hat`・`crash` の `level` を 0.6〜0.85 に。パートの `bright` を -0.2〜-0.4 に |
| ドラムの太鼓どうしのバランス | `drumMix`（kick・snare・hat・tom・crash の level・pan・reverb） |
| 場面ごとに層を増減 | `sections`（自動伴奏）。手書きなら、パートごとに場面の小節を `R:` で休む |

## 8. よくある失敗と直し方
| 症状 | 原因 | 直し方 |
|---|---|---|
| 団子（もこもこ） | 200〜500Hz に持続音が重なる | 片方の音域をずらす／`duck`／休符を入れる |
| 旋律が埋もれる | 1〜4kHz を歪みギター・弦が占める | 伴奏の `volume` を下げる、`bright` を下げる、旋律の音域を上げる |
| 低音が膨らむ | ベースとキックが同じ時に長く鳴る | ベースを短く、`duck`、`volume` を下げる |
| 平べったい（広がらない） | 全部が中央、全部同じ音域 | `pan` を振る、`chorus`、音域を分ける |
| うるさい（疲れる） | 全パートが全小節で鳴る | 場面で層を減らす。休符を入れる |
| 刺さる | 4〜8kHz が多い（ハット・スネア・シンバル） | `drumMix` で hat・crash の level を下げる |
測定: `node tools/composer/song.mjs build 曲.json --wav` → `python3 tools/audio-check/analyze.py 曲.wav > r.json` → `python3 tools/audio-check/analyze.py --bands r.json`（目安から外れた帯域と、直し方が出る）。

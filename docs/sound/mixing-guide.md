# ミキシングの手引き（2026-10-02 調査）

世間一般のミキシング知識を調べて、うちの曲（JSONで書く → WAVで測る）に使える形にまとめたもの。`music-knowledge.md` の 3・4・20 を、ミキシングに絞って深掘りした。

**注意**: 本文を読めたページはほとんどなく、数値は検索要約が中心。「補」「一般値」「慣例値」は出典で確かめていない一般的な目安。**どの数値も出発点で、最後は耳（とA/B）で決める**。ゲームBGMは効果音と一緒に聞くので、曲単体で完璧にするより、ゲーム画面で聞いて調整する。

## 0. うちのエンジンでできること・できないこと（実験で確認済み）
- **できる**: パートごとの `volume`・`pan`・`amp`（アンプ）・`sustain`・`push`（曲JSON）。曲全体の出口（バスのコンプ・リミッター・左右の広がり、`createBgmBus`）。書き出して測る（`song.mjs build --wav`、`analyze.py`、`score-check.mjs`）。
- **できない／効きにくい**: パートごとのEQ・コンプ・サイドチェイン・残響の送り量（エンジンに無い）。Web Audio の `DynamicsCompressorNode` はサイドチェイン非対応。出口の残響の返しにEQを足しても変化なし（量が小さい）。出口のリミッターを変えても PLR はほぼ変わらない（`tracks.md` の実験記録）。
- したがって、**ミックスの調整は「編曲（どの楽器を・どの音域で・どの音量で鳴らすか）」が主役**。EQ・コンプの定石は、編曲で再現する形（音域をずらす・音量を下げる・休符で抜く・音色を選ぶ）に読み替える。

## 1. ミックスの手順（5段階）
| 段階 | やること | 目安 |
|---|---|---|
| 0. 準備 | 各トラックのレベルをそろえる。フェーダーは0dB（ユニティ）から | 各トラック平均 約-18dBFS、ピーク-12〜-6dBFS |
| 1. ラフバランス | プラグインなし、フェーダーだけ。リズム（ドラム・ベース）→リード（主旋律）→飾り（弦・シンセ）の順に上げる | マスターのピーク -6〜-3dB |
| 2. 低域 | キックとベースを先に整理。低域に要らない音はハイパス。120Hz以下はキックとベースが主役 | キックとベースが同等〜ベースがやや下 |
| 3. 中域 | リードが埋もれないよう、ぶつかる帯域を少し削る。かけすぎない | リードを主役に |
| 4. 空間 | リバーブ・ディレイをセンドで足す。パンで左右に配置 | 濁るなら減らす |
| 5. 仕上げ | オートメーション、バス処理、参照曲との比較、ヘッドルーム確認 | ピーク-6〜-3dBで書き出し |
- **優先順位**はキック→ベース→リード。リードは大きくしすぎると曲から浮く。
- **音量バランスの目安**: ベースはキックの -2〜-4dB。リードは絶対値で -11〜-13dB（資料により差が大きい。ジャンルで変わる）。
- **グループバス**は ドラム・ベース・ギター・シンセ・ストリングス・FX の6つ。キックとベースは別バス。リバーブ・ディレイはFXバスにセンドで集める。
- **バス処理の順**（出発点）: EQ → コンプ（軽いグルー）→ サチュレーション（軽く）→ リミッター（最後）。ゲーム用BGMで最終の音量調整が別にあるなら、バスはごく軽く。
- **よくある失敗**: ①ゲインステージングをしない ②キックとベースの音量比が不適切 ③リードを大きくしすぎる ④プラグインのかけすぎ ⑤低域に要らない楽器をハイパスしない ⑥キック・ベース・シンセが同じ帯域でぶつかる ⑦ミックスバスにコンプ・リミッターをかけすぎる ⑧オートメーションをしない（平坦）⑨リバーブのかけすぎ ⑩参照曲と比べない・1種類のスピーカーだけで判断する。
- **完成の判断**: ノリがある／全楽器が聞き分けられ主旋律が全部聞こえる／ベースとドラムの関係が適切でパンチがある／聴き手として楽しめる／小さい音（スマホ・イヤホン）でも崩れない。

## 2. EQ
- **方針**: まず削る（減算）、そのあと足す（加算）。減算は合計3dB程度までにとどめる（中が空洞になる）。3dBは訓練した耳でやっと分かる差、6dBは誰でも分かる差。
- **Q**: 共鳴を削るときは狭く（Q5〜10、補）、音色づくり・ブーストは広く（Q0.5〜1、補）。狭いブーストはキンキンしてリンギングが出る。
- **掃引の探し方**: 狭いQで10dB以上ブーストして掃引し、嫌な点を見つけて逆に削る（削ったあとQを少し広げる）。複数の楽器が同じ点で飛び出したら競合。片方を削り、もう片方を足す（相補EQ）。よくぶつかる帯域: 60〜80Hz（キックとベース）、200〜400Hz（濁り）、1〜3kHz（ボーカルとギター）、2〜5kHz（presence の混み合い）。
- **ロック**
| 楽器 | 処理 | 周波数 | dB（補を含む） |
|---|---|---|---|
| キック | ハイパス | 30〜40Hz | - |
| キック | ブースト（重み） | 60〜90Hz | +2〜4 |
| キック | カット（もこもこ） | 200〜500Hz（250Hz前後） | -3〜-5 |
| キック | ブースト（アタック） | 1〜5kHz | +2〜3 |
| スネア | ブースト（太さ／抜け） | 120〜240Hz／2〜3.5kHz・5kHz | +2〜3 |
| ハイハット | ハイパス | 300〜500Hz | - |
| ハイハット | カット（耳に痛い） | 3〜7kHz（狭く） | -2〜-4 |
| ベース | ハイパス | 30〜40Hz | - |
| ベース | カット／ブースト（輪郭） | 200〜400Hz／700Hz〜1kHz | -2〜-4／+2〜3 |
| 歪みギター | ハイパス | 80〜150Hz（300〜400Hzまで上げることも） | - |
| 歪みギター | カット（箱鳴り）／ブースト（存在感） | 200〜500Hz／1〜3kHz | -2〜-4／+1〜3 |
- **ダンス**
| 楽器 | 処理 | 周波数 | 備考 |
|---|---|---|---|
| キック | 基音を守る | 60〜70Hz | アタックは約4kHzを +2〜3dB |
| ベース | キックとぶつかる帯域 | 50〜80Hz | サイドチェイン／ダイナミックEQでキックが鳴る間だけ -2〜-4dB。500Hz付近でローパス＋2〜3kHzシェルフでキャラ付け |
| シンセ・リード | ハイパス | 300〜600Hz | 約1kHzを +1〜2dB で前に出す |
| パッド | ハイパス | 200〜300Hz | リードの居場所に 4〜7kHz を約 -5dB。サイド信号の150〜200Hz以下をカット（M/S） |
- **シンバル・ハイハットの耳に痛い帯域（3〜8kHz）**: 狭いQで3〜6kHzを掃引して最も痛い点を見つけ、2〜4dB削る。削った上の柔らかい帯域を軽く持ち上げて明るさを保つ。叩く強さで痛さが変わるならダイナミックEQやディエッサー（5〜8kHz）。
- **スペクトラムの傾き**: 現代のミックスは -4〜-4.5dB/oct の傾きに収まることが多い（ツールの初期値は3〜4.5）。ただしソロピアノやチップチューンは直線にならない。見た目だけで直すとバランスを崩す。
- **リニアフェーズ／最小位相**: リニアは位相がずれず、狭いカット・急なフィルター・並列処理向き。遅延が増え、プリリンギングでアタックが弱まる。最小位相は色づけ・温かみ向き。
- **ゲームBGMで効果音・会話と帯域を分ける**: 戦闘曲などの特定帯域をダイナミックEQで下げ、台詞・効果音の居場所を作る（2.5kHz付近が出発点）。数値は補で、**BGMの 1〜4kHz を約2〜3dB**（効果音が鳴る間だけが理想、固定なら Q0.7〜1 で -2〜-3dB）。パッドは200〜300Hz以下をハイパス。うちでは、1〜4kHz を担う楽器（リード・歪みギター）の音量を下げる／音域をずらす、で近づける。

## 3. コンプレッサー
- **耳での合わせ方**: レシオを決める → アタックを最も遅く・リリースを最も速くしておく → スレッショルドを下げてGRを出す → アタックを速めて、パンチが減る手前で止める → リリースを曲の呼吸に合わせる → メイクアップで音量をそろえてオン／オフを比べる（大きいだけで良く聞こえるため）。
- **アタック**: 10〜30ms以上＝パンチが残る／1〜5ms＝頭が潰れて平らで落ち着く。
- **リリースのBPM計算**: 1拍(ms) = 60000 ÷ BPM。16分 = その1/4。120BPMで1拍500ms・8分250ms・16分125ms、140BPMで429・214・107ms。リリース ≒ 1拍の50〜90%（次の拍の頭までにGRが戻りきる）。
- **回路方式**: VCA＝速く透明（ドラム・バス）／FET(1176系)＝速く攻撃的で倍音が乗る（スネア）／Opto(LA-2A系)＝滑らか（ベース）／Variable-mu＝遅く自然（マスター・バスの接着）。
- **楽器別（出発点）**
| 楽器 | アタック(ms) | リリース(ms) | レシオ | GR(dB) |
|---|---|---|---|---|
| キック | 5〜20 | 80〜200 | 4:1 | 3〜5 |
| スネア | 3〜10 | 60〜150 | 4:1 | 3〜5 |
| ベース | 15〜50 | 100〜300 | 3:1 | 2〜5 |
| ドラムバス | 3〜10 | オートか100〜200 | 2:1〜4:1 | 1〜2 |
| ギター（一般値） | 10〜30 | 80〜200 | 3:1 | 2〜4 |
| シンセ（一般値） | 10〜30 | 100〜300 | 2:1〜3:1 | 1〜3 |
| ミックスバス／マスター | 20〜60 | オートか100〜400 | 2:1 | 1〜2（最大3） |
- **パラレル（NYコンプ）**: レシオ8:1〜20:1・GR10dB以上の圧縮側を、ドライの知覚音量の15〜30%で足す。ドライのアタックを残したまま厚みを足せる。
- **サイドチェイン（キック→ベース／パッド）**: アタック1〜10ms（5〜20msでキックの頭が抜けて音楽的）、リリース50〜150ms（タイトは30〜80ms、ポンピングは200〜500ms）、レシオ4:1以上、GR 6〜10dB（ポンピング系のベース）。**うちのエンジンには無いので、編曲で代用**（ベースの音を短く切る・キックの位置に休符を入れる）か、将来のMIDI CC11の音量カーブで実装する案。
- **その他**: アップワードコンプは小さい音を持ち上げる（余韻・空気感）。マルチバンドは100Hz／1k／6kHz付近で分割して低域の暴れを整える。トランジェントシェイパーは圧縮せず直接ゲインを変える（±3〜6dBから）。デエッサーは男声5〜6kHz・女声7〜8kHz付近で GR3〜6dB。リミッターは天井-1dBTP前後・GR1〜3dB、クリッパーは速い短い山だけ0.5〜2dB削り、リミッターの前に置く。

## 4. リバーブ・ディレイ・奥行き
- **種類**: ルーム（1秒未満、ドラム・アコギ）／ホール（2〜5秒、弦・パッド。**速いテンポでは濁りやすい**）／プレート（1〜2.5秒、スネア・リード）／スプリング（エレキギター）。
- **BPMから計算**: 1/4 = 60000÷BPM、1/8 は半分、付点1/8 は ×0.75（=45000÷BPM）、1/16 は1/4。120BPMで 500・250・375・125ms。プリディレイは 1/32（63ms）や 1/64（31ms）の音価で決める方法もある。ディケイは「狙う音価の長さ − プリディレイ」。
- **プリディレイ**: 前に出して奥に空間を作る＝20〜60ms／くっつけて奥に置く＝0〜10ms。
- **リターンのEQ**: ハイパス約200Hz（濁るときは250〜400Hz）、ローパス約8kHz。ディレイのリターンは ハイパス200〜300Hz・ローパス4〜6kHz（繰り返しごとに暗くなって自然）。
- **ディレイ**: フィードバックは 1/4 で15〜25%、付点1/8 で25〜35%、長い反響は40%以上。左右でタイムをずらす（左 1/8・右 付点1/8）と広がる。
- **ダッキング**: 原音が鳴っている間はリバーブ／ディレイのリターンを下げ（GR3〜8dB、アタック1〜10ms、リリース100〜400ms）、間で戻して広げる。
- **奥行き**: 手前＝音量が大きい・高域が多い・プリディレイ長め・ウェット少なめ・ディケイ短い／奥＝音量が小さい・高域が少ない・プリディレイ短い・ウェット多め・ディケイ長い。全パートに同じ空間のリバーブを少しずつ送ると、まとまりが出る。
- **楽器別の送り量（一般値）**: キック0〜5%／スネア10〜25%（プレート）／ハイハット5〜10%／ベース0〜3%／リズムギター10〜20%／リード15〜30%（ディレイは付点1/8を15〜25%）／アルペジオ10〜20%（短いルーム、1/8ディレイ10〜20%）／パッド20〜40%（ホール2〜4秒）／弦20〜35%（ホール1.5〜3秒）。
- **かけすぎて濁るとき**: ①送り量を下げる（「聞こえたら多すぎ」）②リターンのハイパスを250〜400Hzに ③ディケイを短く ④ローパスで8kHz以上を丸める ⑤プリディレイ ⑥ダッキング ⑦速い曲ではホールをやめてプレートかルームに。
- **ゲームBGMのループと残響**: 終わりの残響を先頭に足し合わせる（テールラップ）と継ぎ目が自然。ディケイ3秒・120BPMなら約1.5小節を先頭に足す。尾がソースに入っていなければ後から作れない。ホールの3秒超えは場面が変わる曲では避ける。
- **うちの現状**: 出口バスの残響は wet 0.1（2.2秒）、録音音源の内蔵リバーブ（CC91）とホール（0.15）が別にあり、**楽器ごとの送り量は変えられない**（S-4）。パートごとの残響差は、曲の楽器選び（残響の少ない音色／多い音色）で作る。

## 5. ダンス・シンセ主体のミックス
- **キックとベース**: キックが超低域を担当、ベースはキックの基音あたりを少し削る。**サブ（〜100〜150Hz）は必ずモノ**（ステレオに広げるとクラブのモノ合成で位相が打ち消される）。キックのキーとベースのキーをずらす。位相が合えばサブは太くなり、逆相なら打ち消される（痩せたらベースの極性反転かわずかな遅らせ）。サイドチェイン帯域は〜100〜200Hz、ダッキング量3〜8dB。
- **スーパーソー／リード**: 広い層は100〜150Hzでハイパス。メロディの芯は別に狭い層を用意し、1〜3kHzで聞こえるように。リード全体は250〜300Hzまで上げ、300〜500Hzの「こもり」を削る。広がりは300〜500Hz以上に置く。Side の高域シェルフ（8kHz以上）+2〜3dB、Mid 同帯域 -1〜-2dB、Side の200〜400Hz -1〜-3dB。
- **パッドとアルペジオ**: パッドは低域をHPF（150〜250Hz）で空け、1〜3kHzを少し削る。アルペジオは左右に振るかステレオディレイ、パッドはコーラス・ユニゾンで広げる。長いリバーブはパッド、短いものはアルペジオ。
- **ドラム（慣例値、キック=0dB）**: クラップ -3〜-6dB／ハイハット -10〜-14dB（左右20〜40%）／シェーカー -14〜-18dB（反対側30〜50%）／オープンハット・ライド -12〜-16dB。ハイハット類は250〜500Hz以下をHPF。
- **ブレイク・ビルド・ドロップの変化**: ブレイク＝キック・ベースなし、パッド主体、リバーブ多め／ビルド＝HPF上昇、ライザーの音量上昇（-20dB→0dB付近）、スネアロール、幅は狭く／**直前の1拍＝無音か極端なHPF**／ドロップ＝低域復帰、幅を最大に、ドライ寄り。ブレイクとビルドの音量を下げておくと、ドロップが大きく聞こえる。
- **幅の作り方**: ユニゾンのデチューン／コーラス／ハース効果（片側を10〜30ms遅らせる。モノで櫛形にへこむのでモノチェック必須）／M/S EQ。幅は上の帯域に置き、低域は狭いまま。
- **ラウドネス**: EDMは -9〜-8LUFS が基準（-6は無理をした値）、True Peak -1dBTP以下。順序は サブのモノ化 → サチュレーション → クリッパー → リミッター（GR 2〜4dB）。**ゲームのBGMは -8〜-6LUFS までは詰めず、-14〜-10LUFS の範囲で曲どうしの音量をそろえる**（私見）。
- **ロックのギターと混ぜる**: 各シンセに周波数とステレオの居場所を割り当てる。ギターは300〜500Hzを削り2〜4kHzで抜け。ギターが2〜4kHzを使うなら、シンセのリードは別の帯域に置くか、そこを少し削る。シンセは全帯域に音が出るので、直接出力は前に出やすい。ダンス寄りならキックに合わせてベースを動かしギターは短く刻む、ロック寄りならギターを中域に置きシンセは広がりに回す。

## 6. 測定器と診断
- **相関メーター**: +1＝モノ／+1〜0＝おおむねモノ互換あり／0＝無相関（広い）／0〜-1＝モノで消える部分が増える／-1＝逆位相。0前後でも広がりのあるミックスなら普通。**長く負に沈むのが問題**。
- **LUFS**: Momentary＝直近400ms／Short-term＝直近3秒／Integrated＝曲全体（ゲートあり）。LRA＝曲の中の音量の幅（目標値でなく記述的な指標）。True Peak＝DA変換後の山の推定値。
- **PLR／PSR／クレスト**: PLR＝ピーク−Integrated（-1dBFSで-15LUFSならPLR14、-10LUFSなら9）。PSR＝True Peak−Short-term。最も大きい部分のPSRは8以上。PLR 16・最小PSR 8 なら音量をそろえて再生される環境でも通用する。**ゲームのBGMは再生音量が決まっていないので、「つぶしすぎの警告」として使う**。
- **リファレンス比較**: 音量をLUFS（Integrated と Short-term）で±0.5dB以内にそろえてから比べる。1回に1要素。EQの動かしすぎは禁物（±1.5dB程度を目安）。アナライザは耳で聞こえた違いの裏づけ。
- **モノ互換の確認**: モノにして、サビなど音数の多い所で音量や音色が変わるものを探す（小さくなる・薄くなる・遠くなるものが怪しい）。低音が抜けるのが最も多く影響も大きい。直し方: 重ねた音の極性・位相を確認／100〜150Hzより下をモノに／広げる処理を Haas 式から M/S 方式に替える（Haas は重要でない音だけ）。
- **症状別の診断表**
| 症状 | 帯域 | 主な原因 | 直し方 |
|---|---|---|---|
| 濁り（団子） | 200〜500Hz（特に200〜350Hz） | ベース・キック・ギター・ボーカルの低域が重なる | 重なる音の片方を狭めに2〜4dB削る。音ごとに居場所を決める。リバーブの低域を削る |
| こもり・箱鳴り | 200〜500Hz、300Hz付近 | 箱の共鳴 | 300Hz付近を2〜3dB削る（ギターは400〜500Hz）。削ったあとQを少し広げる |
| 耳に痛い・刺さる | 2〜5kHz（広くは2.5〜8kHz） | 上中域の出すぎ・歪み・重なり | 痛い点を細く探して削る。presence の持ち上げすぎをやめる。リバーブ返しに5〜8kHzのディエッサー |
| 歯擦音・キンキン | 5〜8kHz | サ行・高域の強調 | ディエッサー（リバーブ返しにも） |
| 薄い・貧弱 | 80〜250Hz（補）、モノで低音が抜ける場合も | 低域の不足、または位相の打ち消し | 低域の足りない音を補う。モノ確認で位相を直す。100〜150Hz以下をモノに |
| 広がらない | 500Hz〜3kHz（中域の本体） | 空気感の帯域だけが広く、本体に広がりがない | 本体の帯域にだけ幅を足す（Haasは避ける） |
| リバーブで濁る | 200〜500Hz | 低域の残響の尾 | リバーブの低域を削る |
| 小さく聞こえる・ペラペラ | 全体（PSR・PLR） | 圧縮のしすぎ（PSRが8を下回る） | リミッターを浅く。クレストを取り戻す |
- **診断の順**: ①モノ確認と相関（位相の問題を先に潰す）②アナライザで帯域の偏り ③症状別の表で原因を絞る ④耳で最終確認。ヘッドホン・スピーカー・スマホの3種類で聴く。
- **耳と測定器**: 測定器は助手。数値がすべて良くても違和感があれば耳を優先する。ヘッドホン補正（Sonarworks 等）は逆EQで平らに近づけるが、個体差・測定位置の影響があり万能でない。

## 7. うちの曲に当てはめるチェックリスト（編曲で再現する）
1. **低域の分担**: キックは60〜70Hz、ベースは80〜120Hz以上＋倍音。ベースの音は短め（スタッカート）にしてキックの隙間に入れる。ベースの `volume` はキックの -2〜-4dB（実際の `volume` の比で見る）。
2. **200〜500Hz の整理**: 同時に鳴る持続音（弦・パッド・合唱・歪みギター・ピアノ）の音域を重ねない。「体を残す楽器」を1つに決め、残りは音域を上げる。
3. **リードを主役に**: リードの帯域（1〜3kHz）を歪みギターや弦が占めないよう、歪みギターは `volume` 0.05〜0.1、音域を E2〜E4 の低めに。
4. **左右**: 低域とリードは中央。歪みギター2本は ±0.9。パッド・弦・アルペジオは反対側に。相関は 0.4〜0.8。
5. **起伏**: 8小節ごとに鳴るパート数を変える（ヴァース3〜4、ビルド4〜5、サビ5〜7、ブレイク1〜2）。ドロップ前に1拍の無音。
6. **測る**: `score-check.mjs`（楽理）→ `song.mjs build --wav` → `analyze.py --compare`（PLR 9以上、相関 0.4〜0.88、LRA 2.3〜9、頭が最大より小さい）→ 耳。
7. **ゲーム内**: 曲どうしの音量を近づける（`bgm-loudness.json`）。効果音の邪魔をする 1〜4kHz を担うパートの音量に注意。

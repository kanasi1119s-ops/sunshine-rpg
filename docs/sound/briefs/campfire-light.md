# 曲の企画書: campfire-light（焚き火の灯り）

状態: **自己確認済（仮）**。人間試聴済までは「仮」。
作成日: 2026-10-02 ／ 作成者: プロデューサー役（Claude Code）。※曲づくりチームのプロンプト案（`song-team-prompts.md`、人間の確認待ち）を試しにそのままなぞって作る、最初の1曲。

## 1. 場面と役割
- 使う場面: 旅の途中、野営の夜。焚き火のそばで、ユーリと仲間が静かに語らう（フィールドの野営・宿屋のない道中・休憩の会話など）。
- 場面の言葉: 「焚き火がはぜる夜。星がきれいで、誰かが小さく笑っている」
- プレイヤーに感じさせたいこと: 安らぎと、ほんの少しの郷愁（覚醒は低く、快は高い）。明日も旅を続けようと思える、あたたかさ。
- **避けたいこと**: 悲しすぎる／眠くなるほど平坦／ホラーや不穏／派手な戦闘感／効果音（会話の決定音など）を覆う高域のきらびやかさ。
- ループ: する。最初と最後のコードを同じ（Dm）にして、つなぎ目の違和感を減らす。

## 2. 音楽の仕様
- テンポ 84BPM／4拍子／Dドリア（短調だが長6度＝Bが明るく、希望を含む）／48小節（約137秒）
- ジャンル: アコースティックなフォーク（`style: folk`）。編成: ガット/アコースティックギター（分散和音）・ハープ・フルート（主旋律）・フィドルとオカリナ（対旋律）・弦（薄いロングトーン）・カリンバ（きらめき）・アコースティックベース・ドラムは入れない（小さなハンドパーカッション風に hihat だけ弱く）。
- 参考にする**性質**: 小さな編成で、息づかいのある木管と弦の対話。拍は穏やかで、音数は少なめ。曲名は参考にしない。
- 前後の曲とのつながり: フィールドの昼の曲からクロスフェード（ゲーム側の調整）。
- 効果音・会話と重なる場面: 会話中に重なる。リードの帯域（1〜4kHz）を空け、音量は控えめ。

## 3. 主題
- 使う主題: M-01 灯りの主題（`motif-ledger.md`）の**初案**。4〜5音・順次中心・跳躍は1回まで・長調でも短調でも成り立つ形。この曲で骨格を初めて作る（動機: D5:1 F5:0.5 E5:0.5 D5:1 A4:1 = 5音＋応答）。
- 音の伏線: なし。

## 4. 構成表（構成作家役）

|---|---|---|---|

| 17〜24 | A'（応答） | 1→2 | 主題を繰り返し、フィドルの対旋律が主旋律の休みに入る。カリンバがきらめく（楽器6） |
| 25〜32 | B（広がり） | 2 | 音域を上げた新しい旋律（オカリナ）。弦が少し厚く。山場は28小節目の最高音1回（楽器6〜7） |

# 曲の企画書: plaza-minigame-chip（広場のたからさがし（仮））

状態: 下書き（人間試聴前）
作成日: 2026-10-02 ／ 作成者: 作曲担当（Claude Code）

## 1. 場面と役割
- 使う場面: 町の広場のミニゲーム、古き良き味を出したい場面（レトロは選択肢の一つ）
- 場面の言葉: 「お祭りの広場で、屋台の景品をかけた小さなゲームに挑む」
- 感じさせたいこと: 軽く弾む、明るく元気な気持ち
- **避けたいこと**: 既存ゲーム曲の旋律・効果音の再現、残響感、音数の増やしすぎ
- ループ／終止: 最初と最後のコードは同じ C。最終小節 C から前奏の頭へ

## 2. 音楽の仕様
- テンポ 156 ／ 4/4 ／ ハ長調 ／ 48小節・約74秒
- 編成: lead（主旋律）・keys（速いアルペジオ＝和音の代わり）・bass（amp: retro8bit）・kick・snare・hihat（`synth: true`、ドライ）
- 参考にする性質: 同時発音を少なくし、和音は速いアルペジオで表す、明るい長調

## 3. 主題
- 4音前後の動機（ド・レ・ミ・レ・ド）を順次進行で。A（8小節）、Bは音域を上げる

## 4. 構成表
| 小節 | 区間 | 内容 |
|---|---|---|
| 1-8 | 前奏 | アルペジオ＋ベース、5小節目からキック・ハイハット（4） |
| 9-16 | A | 主旋律＋全部（6）。16小節目はスネア連打のフィル |
| 17-24 | A' | 主旋律の最後を変え、アルペジオの型を変える |
| 25-32 | B | 高い音域の主旋律（最高音C6は1回） |
| 33-40 | 間奏 | 主旋律を抜く。スネアなし。40小節目の3拍目に連打、4拍目は無音 |
| 41-48 | 最後のB | 主旋律が戻る。最後は C でループへ |

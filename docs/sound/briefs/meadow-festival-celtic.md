# 曲の企画書: meadow-festival-celtic（草原の祭り）

状態: **自己確認済（仮）**。人間試聴済までは「仮」。
作成日: 2026-10-02 ／ 作成者: 作曲担当（Claude Code）。「各ジャンルで1曲ずつ」のケルト風の1曲。

## 1. 場面と役割
- 使う場面: 草原の祭り、旅の始まり、明るいフィールド・村の催し。
- 感じさせたいこと: 軽快、わくわく、仲間と踊る楽しさ。
- 避けたいこと: 重さ・悲しさ／実在曲の旋律／うるさすぎる打楽器。
- ループ: する。最初と最後が同じコード（Dm）・同じ編成（ドローン・ギター・太鼓）。

## 2. 音楽の仕様
- テンポ 120BPM／4拍子（リール風の8分音符の流れ）／Dドリア／48小節（約96秒）
- 編成: バグパイプ（ドローンA）、ギター（分散和音）、フィドル（主旋律）、オカリナ（ティンホイッスル役）、ハープ、ウッドベース、tom（ボドラン風、小さく）。`style: folk`。
- コード: Dm Dm C C Dm G C Dm（1小節ずつ、6周）。

## 3. 構成表（8小節ずつ）
| 小節 | 区間 | 内容 |
|---|---|---|
| 1〜8 | イントロ | バグパイプ・ギター・太鼓 |
| 9〜16 | A | フィドルが主題、ベース |
| 17〜24 | A' | フィドルの主題をくり返し、ハープが加わる |
| 25〜32 | B | オカリナが高い新しい旋律、フィドルは長い音で支える |
| 33〜40 | A'' | フィドルの主題＋オカリナがオクターブ上で重ねる（最も厚い） |
| 41〜48 | アウトロ | イントロと同じ形に戻る |

## 4. 由来の記録
- 制約: Dドリア・8分音符中心・動機は「4分音符を含む短い8分の動き」・跳躍は1回まで。
- 参考にした性質: リールの一般的な拍感、ドローン、ドリア旋法。実在曲は参照していない。
- 外部素材: なし。

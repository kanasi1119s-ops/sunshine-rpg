# 曲の企画書: mist-shrine-wafu（霧の社）

状態: **自己確認済（仮）**。人間試聴済までは「仮」。
作成日: 2026-10-02 ／ 作成者: 作曲担当（Claude Code）。「各ジャンルで1曲ずつ」の和風の1曲。

## 1. 場面と役割
- 使う場面: 霧の立つ山の社（やしろ）。静かで少し神秘的な場所の探索・会話。
- 感じさせたいこと: 静けさ、神聖さ、ほんの少しの畏れ（覚醒は低め）。
- 避けたいこと: 不気味すぎる／ホラー調／実在の民謡・曲の旋律／会話の効果音を覆う高域。
- ループ: する。最初と最後が同じ形（ドローン D3 と琴の同じ音型）。

## 2. 音楽の仕様
- テンポ 66BPM／4拍子／日本の陰旋法（都節 D・E♭・G・A・B♭）／28小節（約102秒）
- 編成: ドローン（pad・低いD）、琴（まばらな分散）、尺八（主旋律）、三味線（まばらな合いの手）、太鼓（tom、小さく）。`style: nature`。
- 和音は Dm・Gm のラベルだけ。実際はドローンの上に旋律を置く。休符多め（間）。

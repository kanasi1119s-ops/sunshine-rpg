# 曲の企画書: ruins-stillness（雲の上の遺跡（仮））

状態: 自己確認済（人間試聴前のため「仮」）
作成日: 2026-10-02 ／ 作成者: 作曲担当（Claude Code）

## 1. 場面と役割
- 使う場面: 古い遺跡・神殿・雲の上など、静かで神秘的な場所
- 場面の言葉: 「風も止まった石の広間に、遠くで鐘が鳴る」
- 感じさせたいこと: 静かで少し畏れ多い（覚醒度 低 × 快さ 中）
- **避けたいこと**: 拍や旋律がはっきりして場面を急かすこと／不安をあおる不協和／ドラム
- ループ／終止: ループ。最初も最後も Dsus2。

## 2. 音楽の仕様
- 60BPM・4拍子・Dを中心にした旋法（sus2・sus4・m7、Gは Gsus2）・14コード×2小節＝28小節（約112秒）
- ジャンル: アンビエント、style space（合唱lead）。編成: パッド・弦・合唱・ハープ・鐘。ドラム・ベースなし。
- 参考にする性質: 長い音、少ない音、ゆっくり変わる和音。sustain 2〜3 で立ち上がりと余韻を遅く作る。
- 注: 当初 add9 のコード（Gadd9）を使う予定だったが、ソフトが読めず Gsus2 に変更。9度（A）はハープ・合唱の旋律で補っている。

## 3. 主題
- 決まった主題はなし（合唱の長い音の旋律で、2音ずつ動く）。

## 結果
- True Peak -1dBTP付近 ○／PLR 11.8 ○／左右相関 0.422 ○（下限すれすれ）／LRA 7.8 ○／重心 751Hz ○／I -12.8 LUFS／頭は最大より -12.4dB ○／長さ 114.5秒
- 楽理の△: 順次進行52%・4度以上の跳躍26%（長い音の旋律で、2音ずつの跳躍が多いため。アンビエントなので許容）／動機の再利用なし（主題を決めていないため）／冒頭のパート数（パッド・鐘のみだが同時に小さな音が鳴る判定）。
- 耳で確認: 拍が見えない感じか／パッドの立ち上がり／ハープと合唱が濁らないか／ループの継ぎ目（末尾にわずかな無音あり）。

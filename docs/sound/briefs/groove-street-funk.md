# 曲の企画書: groove-street-funk（夜の街のグルーヴ（仮））

状態: 下書き（自己確認済み。人間試聴前＝仮）
作成日: 2026-10-02 ／ 作成者: 作曲担当（Claude Code）

## 1. 場面と役割
- 使う場面: 夜の街・酒場・都会の探索
- 場面の言葉: ネオンの路地、人の話し声、少し危ない匂いのする酒場
- 感じさせたいこと: 落ち着いた中の高揚（ノリ・遊び心）
- 避けたいこと: 既存のファンク曲のリフやフレーズ、効果音・会話を邪魔する高音の厚み
- ループ／終止: 最初も最後も Am7

## 2. 音楽の仕様
- 102 BPM／4拍子／A短調（Am7 D7 Am7 D7 Fmaj7 E7 Dm7 Am7 を5回＝40小節＝約94秒）／swing 0.55
- 編成: ドラム（ゴーストノート入り）・スラップベース（amp funk）・16分カッティング（amp funk、sustain 0.35）・エレピ3声（7度・3度・9度／13度）・ブラスのスタブ2声・サックス風リード（style rnb）
- 参考にした性質: ファンク／R&B の一般的な様式のみ（16分刻み、間のあるキック、2・4拍のスネア）

## 3. 主題
- 動機の制約: 音は A・C・D・E・G（ペンタトニック）＋G#、リズムは8分の休符から入る、跳躍は1回まで

## 4. 構成表
| 小節 | 区間 | 内容（同時に鳴るパート数） |
|---|---|---|
| 1-8 | 前奏 | キック・ハイハット・ギター（後半ベース）（2〜4） |
| 9-16 | A | 全リズム＋エレピ＋サックス（6） |
| 17-24 | A' | ブラスのスタブ追加（8） |
| 25-32 | 間奏 | ドラムを抜く。ベース・エレピの伸ばし・ソロ（後半ギター） |
| 33-40 | 最後 | 全部が戻る（8）。Am7 で終わりループ |

## 5. 完成の基準
- PLR 9以上、True Peak -1dBTP以下、相関 0.4〜0.88、LRA 2.3〜9（LRA 3.6）

## 6. 由来の記録
- 出自: AI支援（Claude Code）。旋律の照合: 2026-10-02 に assets-src/ai-songs/*.json と比較。最初は他曲と7音程の一致が出たため、冒頭の動機を2回作り直して警告なしにした

## 結果（2026-10-02）
- 測定: True Peak ○／PLR 10.8 ○／相関 0.787 ○／LRA 3.6 ○／頭は最大より -4.4dB ○／I = -11.8 LUFS
- △: 音の重心 1144Hz（目安 300〜700Hz。カッティング・ブラス・サックスで高め。ハイハット・ギター・ブラスの音量を下げて 1271→1144Hz）／旋律の順次進行 36%（ペンタトニックで3度の動きが多い。ファンクのリフらしさを優先）
- 耳で確認してほしいこと: 16分カッティングとスラップのノリ（swing 0.55）、エレピの9th・13thの響き、サックス風リードの聞こえ方、ゴーストノートの強さ、ループの継ぎ目（末尾に約0.2秒の余韻あり）
- 由来: 制約＝A短調ペンタトニック、冒頭は休符から入る、リフは同じ型を繰り返す

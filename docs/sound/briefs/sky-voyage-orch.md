# 曲の企画書: sky-voyage-orch（空へ漕ぎ出す朝（仮））

状態: 自己確認済（人間試聴前のため「仮」）
作成日: 2026-10-02 ／ 作成者: 作曲担当（Claude Code）

## 1. 場面と役割
- 使う場面: 空を行く船で初めて旅立つ場面
- 場面の言葉: 「朝の雲海の上へ、船がゆっくり浮かび上がる」
- 感じさせたいこと: 高揚して快い（覚醒度 中〜高 × 快さ 高）。広がりと希望。
- **避けたいこと**: 既存作の旋律・コード進行に似ること／最初から全楽器で鳴ること／うるさい金管
- ループ／終止: ループ。最初も最後もコードは D（48小節目のDから1小節目のDへ）。ただし最後の和音は余韻なしで切れるので、つなぎ目は耳で確認。

## 2. 音楽の仕様
- 100BPM・4拍子・Dメジャー・48小節（約115秒）
- ジャンル: オーケストラ（劇伴）、style epic（lead＝トランペット）。編成: 弦・ハープ・合唱・ブラス・トランペット・ベース・タム（ティンパニ代用）・鐘。`synth` 不要。
- 参考にする性質: 弦の8分刻み（オスティナート）で推進力、薄く始めて層を足す、サビで音域を上げる、という一般的な劇伴の様式のみ。
- 木管系は epic の割り当てに無いため、省略（トランペットの旋律で代用）。

## 3. 主題
- 動機: 4度上がって（A→D）3度上がる、跳躍1回の「船出の動機」。サビでは1オクターブ上で再現。

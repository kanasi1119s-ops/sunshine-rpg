# 曲の一覧

## 音楽の方向性

- 土台: ファミコン〜スーパーファミコン風（16bit風）のチップチューン
- 重ねる要素: テンションを含む和音、転調や意外性のある進行、ドローン・パッドの響き、テンポ・拍子の変化、ダイナミクス — といった「現代的な音づくり」の工夫
- 場面ごとの好み: 悲しい・切ない曲は現代音楽的な不協和音を強めに／戦闘曲は疾走感を強めに
- 既存曲・既存のゲーム音楽のメロディ・コード進行はなぞらない。特定の実在の作曲家の作風を狙って似せることもしない（`CLAUDE.md` 1-1、`roles.md` 3-7）
- 曲を作ったら、この一覧に「一言メモ（方針をどう反映したか）」を添えて記録する

# 曲の一覧

## 音楽の方向性

- 土台: ファミコン〜スーパーファミコン風（16bit風）のチップチューン
- 重ねる要素: テンションを含む和音、転調や意外性のある進行、ドローン・パッドの響き、テンポ・拍子の変化、ダイナミクス — といった「現代的な音づくり」の工夫
- 場面ごとの好み: 悲しい・切ない曲は現代音楽的な不協和音を強めに／戦闘曲は疾走感を強めに
- 既存曲・既存のゲーム音楽のメロディ・コード進行はなぞらない。特定の実在の作曲家の作風を狙って似せることもしない（`CLAUDE.md` 1-1、`roles.md` 3-7）
- 曲を作ったら、この一覧に「一言メモ（方針をどう反映したか）」を添えて記録する

## メモ

- 効果音（決定・カーソル・扉・勝利・全滅・攻撃）は章をまたいで共通で使う設計のため、第1章・第2章専用の効果音は追加していない（`src/audio/chapter0-se.ts`をそのまま使う）
- 全パートの合計拍数を揃える（ループのつなぎ目で音が途切れたり不揃いになったりしないようにするため）ことを自動テスト（`chapter0-tracks.test.ts`）で確認している。今後の章の曲も同じ形式・チェックを踏襲する
- 効果音（決定・キャンセル・カーソル・攻撃・呪文・回復・宝箱・扉・階段・ダメージ・会心など）はroadmap 3-6でまとめて作る予定
- エンジンの制約で、1曲の中でテンポそのものを変える（テンポチェンジ）ことはまだできない（`Score`は曲ごとに単一のtempoBpmを持つ）。「テンポ・拍子の変化」（`CLAUDE.md`のサウンド方針）は、当面はリズムの刻み方の変化（音符の細かさ・休符の使い方）で表現する
- 新曲7曲は `src/audio/style-tracks.ts`。伴奏は `src/audio/compose.ts`（コード進行×リズムの型から組み立てる道具）で作り、旋律は手で書いた。楽器の音色は `src/audio/voices.ts`（ギター・ベース・ドラム・キーボード・弦・パッド・鈴など。すべて発振器とノイズの合成で、音声ファイルは使わない）。
- 効果音は `src/audio/se-library.ts` に約50種（メニュー・フィールド・戦闘。走り去る、斬撃、会心、逃げられない、宝箱、レベルアップ、勝利、全滅など）。まだゲーム本体の各場面には接続していない（接続は次回以降。`docs/progress.md`）。
- 聴き比べは BGMプレイヤー（`node tools/bgm-player/build.mjs`）でできる。
- **2026-09-30 大幅な入れ替え**: 序章〜第6章の仮曲23曲を、新しい作曲エンジン（`src/audio/songwriter.ts`）と新しい楽器の音色（`src/audio/voices.ts`）の曲に置き換え、全体で52曲にした（`docs/decisions.md`）。曲調は、ロック・メタル・クラシック・空間系・キーボード・不協和音・不思議・オーケストラ風・フォーク・自然音楽・フォンク・サンバ・ジャズ・R&B・エレクトリック・ハードコア・デスメタル・プログレッシブメタル（7拍子）・J-POP。
- 作曲エンジンの曲は、設計図（調・速さ・曲調・乱数の種）から毎回同じ曲ができる。気に入らない曲は、`catalog.ts` の `seed` や調・テンポを変えて作り直す。
- 「ネット上のゲームBGMを参考に」という指示は、曲調・楽器編成・構成の一般的な傾向（ボス戦は速く、町は穏やかに、など）の参考にとどめた。既存曲のメロディ・進行の再現はしていない（`CLAUDE.md` 1-1）。
- 効果音は `src/audio/se-library.ts`（53種）。ゲーム本体には、決定・カーソル・扉・戦闘開始・遭遇・勝利・全滅・レベルアップを接続済み。残りは各場面に順次接続する。
- 未接続の曲: タイトル・第7章以降・終章・裏ボス・イベント用の曲（該当する場面がまだ無い）。フィールド・宿屋・城などの共通曲も、場面ができたら割り当てる。

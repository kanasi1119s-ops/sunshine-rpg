## 1000曲で分かったこと（37曲の結論を確かめ直した）

1. **音量は、ジャンルや速さに関係なく -12〜-15 LUFS にそろえてある**（全体の中央値 -13.4、下位10%〜上位10% が -14.8〜-12.0）。
   - 戦闘・ボスでも -12.7。速い曲ほど大きい、ということはない（テンポ別の表）。
   - ピークと平均の差も、全体で 12.6〜16.3dB。
   - 「音量が大きい曲ほど差が小さい（つぶれている）」の相関は -0.69 と強い。**大きくするとつぶれる、だから大きくしない**が、はっきり出た。
   - → うちの戦闘 -4 LUFS・差 7dB は、1000曲のどれよりも大きく、つぶれている。**S-1 がいちばん大事**なのは変わらない。
2. **レトロ（チップチューン・8bit・16bit）の曲は、狭くて明るいのがふつう**。
   - 説明タグに chiptune・8-bit・retro がある曲（それぞれ21〜36曲）: 左右の相関 0.86、音の重心 720〜780Hz、4〜8kHz が -15dB、ざらつき 0.37。
   - オーケストラ・ピアノ系（相関 0.45〜0.65、重心 300〜590Hz）とは作りが違う。
   - **（2026-09-30 追記）人間の指示で、このゲームの音はレトロ風にこだわらず、きれいで現代的な音を基本にすることになった。** なので、ふだんの曲はオーケストラ・生楽器・ピアノの目安に合わせる。レトロの目安は、あえてレトロな曲にするときだけ使う。
   - ただし音量（-13.5 LUFS）とピークと平均の差（13.9dB）は、レトロでもほかと同じ。S-2・S-3 は、曲の系統（レトロ／オーケストラ・生楽器／ピアノ）で目安を分ける。
3. **ピアノ・オルゴール・フェルトピアノは、高音をばっさり落として、左右に広く、音量の差を大きく**。
   - 4〜8kHz が -45dB 前後。相関 0.38〜0.46。ピークと平均の差 16〜17dB。LRA 8。
   - 「きれい」「やさしい」と感じる音は、この作り。
4. **遅い曲ほど広く、起伏が大きく、余韻が長い**。
   - 80未満: 相関 0.56、LRA 5.9、引く所 6、余韻 1.9秒
   - 160以上: 相関 0.74、LRA 2.9、引く所 0、余韻 0.9秒
   - 速い曲ほど、音の重心が上がり（相関 0.41）、ざらつき（シンバル・刻み）が増える（相関 0.52）。
5. **ホラー・アンビエントは「低い音と空気」**。
   - 重心 140〜260Hz、超低音 -4.5〜-7.5dB（いちばん多い）、1kHz より上はとても少ない。
   - 曲の中で引く所が5〜6か所ある。
6. **説明タグの言葉と音の対応**。AIへの指示の言葉が、そのまま音の数値に出ている。うちで音色を決めるときの言葉の目安になる。
   - 「warm」「soft」「gentle」: 4〜8kHz が -31〜-43dB で、高音が少ない
   - 「epic」「orchestral」「choir」: 音量がやや大きく（-12.5〜-12.8）、差は 13dB 台
   - 「reverb」「ambient pad」: 余韻 2.4秒、相関 0.47〜0.57
7. **曲の長さ**: 中央値 2分20秒（ゲーム用BGMは1分40秒、戦闘BGMは2分40秒）。

## 目安の見直し

37曲で決めた目安（`reference-nihonichi-bgm.md` 第5節）を、1000曲の分布（下位10%〜上位10%）に合わせて少し広げた（`analyze.py --compare` も同じ値に更新）。
- 左右の相関の上限: 0.8 → 0.88（レトロの曲のため）
- 音量の幅（LRA）の下限: 3.0 → 2.3
- 曲の頭: -13〜-2dB

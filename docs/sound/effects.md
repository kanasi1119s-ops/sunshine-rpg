# エフェクター（fx）

トラックごとに、アンプのあとへ「足し算の音づくり」をつなぐ（実装: `src/audio/fx-chain.ts`）。Web Audio の部品だけで作るので、作曲ソフト・ゲーム・書き出し（オフライン）で同じ音になる。外部素材は使っていない。

## 書き方（AIソング形式）

```json
"fx": [{"type":"delay","beats":0.75,"mix":0.25},{"type":"plate","mix":0.2}]
```

- 書いた順につながる（最大8個）。`mix`＝元の音との混ぜ具合（0〜1）。省略は種類ごとの標準。
- `delay`／`pingpong` は `ms` のほかに `beats`（テンポから自動で ms に直す）。
- そのほかのつまみ: `feedback`・`rate`・`depth`・`freq`・`q`・`gain`・`level`・`low`・`mid`・`midHz`・`high`・`threshold`・`ratio`・`bits`・`size`・`tone`。
- 作曲ソフトの「MIX」パネルにも、同じ22種類のボタンとつまみがある。

## 種類

| 名前 | 呼び名 | 使いどころ |
|---|---|---|
| `delay` | ディレイ | やまびこ。メロディに奥行き |
| `pingpong` | ピンポンディレイ | 左右に跳ねるやまびこ |
| `reverb` | ホール | 広い空間の残響 |
| `plate` | プレート | 明るく密な残響（ボーカル・スネア向け） |
| `spring` | スプリング | ビヨンと鳴るギターアンプの残響 |
| `room` | ルーム | 小さな部屋の自然な響き（ドラム向け） |
| `chorus` | コーラス | 音を厚く広げる（クリーンのギターには不向き） |
| `flanger` | フランジャー | ジェット機のような うねり |
| `phaser` | フェイザー | ゆるやかに回る うねり |
| `tremolo` | トレモロ | 音量が震える |
| `vibrato` | ビブラート | 音程が震える |
| `wah` | ワウ | 「ワウワウ」と口を開け閉めする音（固定位置） |
| `autowah` | オートワウ | 自動で動くワウ（ファンク） |
| `compressor` | コンプレッサー | 音量をそろえて粘らせる |
| `eq` | イコライザー | 低音・中音・高音の調整 |
| `boost` | ブースター | きれいに音量を上げる |
| `tubescreamer` | オーバードライブ（ペダル） | 中域が前に出る定番の浅い歪み |
| `fuzz` | ファズ | もこもこ荒い歪み |
| `bitcrusher` | ビットクラッシャー | ざらざらした粗い音 |
| `ringmod` | リングモジュレーター | 金属的な変な音（効果音向け） |
| `filter` | フィルター | 高音や低音を削る |
| `widen` | ステレオ広げ | 左右に少しずらして広げる |

## 注意
- 耳での確認は利用者が行う（作者は音を聴けない）。標準の量は「仮」。
- クリーン・ギターにコーラスは付けない（既存の決まり）。

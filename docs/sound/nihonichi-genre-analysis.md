## 0. 読むときの注意
- 曲は**生成AI（Suno）のインスト曲が993/1000**。人間の録音ではないので、「AIが作るとこうなる」目安であって、プロの録音の目安ではない。

- 分け方は、サイトのジャンル名ではなく**説明タグのキーワード**（例: orchestral・punk・jazz）。1曲が複数に入る。
- 数値は中央値。p10〜p90の幅は JSON を見る。

## 4. 数値どうしの関係（相関係数。1000曲）
- **ざらつき(flat) と 傾き(tilt): 0.74**。2〜8kHzにノイズ成分（シンバル・空気・歪み）が多い曲ほど、高域が寝ない（傾きが平ら）。
- **PLR と 音量(I): -0.7**。大きくした曲ほどピークと平均の差が減る（つぶれる）。同じ大きさなら起伏の大きい曲は少ない。
- **左右の相関(corr) と flat: 0.7**。ざらつきの多い曲ほどモノ寄り（中央に集まる）。広い曲は、ざらつきの少ない静かな曲。
- **LRA と flat: -0.65**、LRA と tilt: -0.61。起伏の大きい曲は、高域が静かで、傾きが急。
- **BPM と LRA: -0.41**、BPM と flat: 0.52、BPM と PLR: -0.38。速い曲ほど、起伏が小さく、ざらつきが多く、つぶれやすい。

## 5. 分かったこと（要点）
1. **ジャンルで一番違うのは「起伏(LRA)と高域(張り・空気)」**。ピアノ・バラード・アンビエントは LRA 6〜8、張り(4〜8k)が −37〜−57dB まで下がる。ロック・電子・チップ・戦闘は LRA 2.5〜3.5、張りが −15〜−17dB。音量(I)は全部 −13〜−14 LUFS でほぼ同じ。
2. **「ジャンルを変える」＝ LRA・張り・空気・テンポ・左右の広がりの組み合わせを変える**こと。音量は変えない（−13〜−14で共通）。
3. **速い曲(140〜160 BPM 以上)は PLR が 11 前後に下がり、LRA 3 以下**。遅い曲(〜80)は PLR 12.8、LRA 5.9。テンポに合わせて起伏の目標を変えるべき。
4. **曲の頭**: 全体で −6.3dB（最大より小さく始まる）。ジャズ・チップ・ロックは −3〜−4dB（すぐ全開）、オーケストラ・ホラー・バラードは −7〜−8dB（小さく始まる）。
5. **余韻**: ピアノ・バラード 2.3〜2.5秒、アンビエント 1.8秒、ロック・チップ 0.7〜0.9秒。残響の長さはジャンルで決まる。
6. **和風**: 超低が −12.7（少なめ）、低中(250〜1k)が −3.7（多い）、広がりが −7.1（モノ寄り）、余韻 1.3秒。重心 460Hz。

## 7. 作曲ソフトに取り入れる提案
1. **ジャンル別の目標を `mix-targets.json` に足す**: 起伏(LRA)・PLR・頭の大きさ・余韻・corr の目標を、このJSONの p10〜p90 から（例: ピアノ/バラード LRA 6〜8、PLR 13、corr 0.45。戦闘/電子 LRA 3、PLR 11、corr 0.75）。`gate` の合否の基準にする。【実装しやすい】
2. **テンポで起伏の目標を変える**: BPM が 100 上がるごとに LRA −1.5 程度（3章）。`natural` の強弱幅や `gate` の LRA 判定を BPM で変える。【実装しやすい】
3. **空気(8k+)とざらつき(flat)の診断**: うちは flat が 0.04（1000曲の中央値の1/4）。シンバル・ハイハットの高域、残響の空気、プレート系の `space` を足す目安にする。`report` に flat と空気を出す。【中】
4. **曲の頭の大きさ**: ジャンルに応じて、小さく始める（−7dB）か全開（−3dB）かを `introGain`／sections の目標にする。【中】
5. **余韻の目標**: `--loop-tail`／`space-wet` のジャンル別の既定（バラード 2.3秒、ロック 0.8秒）。【中】
6. **足りない学習素材**: ロック・ジャズ・ポップス・ヒップホップは少ない（20〜30曲）。ジャンルごとに200曲は、サイトの規約と、取得の許可が要る（人間が許可済みだが、自動の安全確認で止まることがある）。

## 8. 限界
- AI生成曲の数値で、人間の録音の目安ではない。『Suno が作る音』に寄せることになる点に注意（人間の判断で、−13LUFS前後の「ほどよい大きさ」を目標にするのはよいが、ロックの −10 のような大きさは別に決める）。
- スタイル別の曲数に偏りがあり、ロック(92・タグ判定)、ジャズ系(44)は、分布の幅が広い。
- 旋律・和音・リズム型は測っていない。**テンポ(BPM)はサイトの表示値**。

# 銀の笛と百の夜 — 曲調の台帳（似せないための表）

2026-10-28 旭さん「曲調は全部なるべく変えてね」。1曲ずつ、作る前にこの表で、近い曲と「曲の形・拍子・伴奏の主役・始まり方・終わり方」が重ならないかを確かめる。
- 型：静＝点数 7.2 以上、動＝7.8 以上を目指す（celtic-flute-100-plan.md）。動の曲は ♩=96〜120 相当に上げる
- 曲の形は docs/sound/celtic-study/README.md の15種＋ダンスの型。隣の曲と同じ形・伴奏・始まり・終わりにしない。（形・拍子・伴奏）の組は100曲で重ならない
- 作るときに物語に合わないと分かったら、近い曲と重ならない範囲で替えてよい。替えたらこの表も直す
- **いちばん大事なのは、その曲のイメージ（場面・物語・「ただひとつ」）**（2026-10-28 旭さん「その曲のイメージを大事にして作成をお願いします」）。形・拍子・伴奏は、そのイメージを伝えるために選ぶ。001〜030 はイメージから選び直した。031 以降は自動で並べた仮の値なので、作る前に必ずイメージから見直す
- 001〜011 は第1版で作ったもの。第2版で作り直すときに、この表の値で作る

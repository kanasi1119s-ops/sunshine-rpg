# 鼻歌から曲を作る（スマホの録音 → 旋律 → 曲）

2026-11-25 人間「スマホでも鼻歌で曲が作れるようにして」。選ばれた形: **スマホで鼻歌を録って、Claude のチャットに送る**（作曲ソフトは音源込みで約 750MB あり、スマホでは開けないため）。

## 人（旭さん）がやること

1. スマホのボイスメモ（iPhone）やレコーダー（Android）で、鼻歌を録る。
   - 静かな場所で、口を閉じた「んー」より「ラララ」「ナナナ」のほうが読み取りやすい（音の頭がはっきりする）。
   - 同じ高さを続ける所は、1音ずつ切って歌う。10秒〜2分くらい。
   - 分かれば、いっしょに書く: どんな曲にしたいか（ジャンル・速さ・歌詞のイメージ）、鼻歌はサビか Aメロか。
2. 録音（m4a・mp3・wav）を、Claude のチャットに付けて送る。

## Claude がやること

1. 読み取る: `python3 tools/hum/hum_to_melody.py <録音> --out <フォルダ> [--bpm 120]`
   - 出るもの: テンポ・調・小節ごとの旋律（音名と度数）・和音の案（`.melody.json`）、すぐ鳴らせる下書き（`.preview.json`）。
   - 画面に「あやしい所」の目安が出る（テンポのずれ 0.15 より大きい／調の確からしさ 0.6 より小さい）。あやしい時は `--bpm` を変えて読み直す。
2. 下書きを鳴らして送る: `node tools/composer/song.mjs build <.preview.json> --wav` → mp3 にして「こう読み取りました」と聞いてもらう。**読み取りは下書き**。まちがっていたら、どの小節かを聞いて直す。
3. 旋律が合ったら、それを歌（`Key.mel` の度数の書き方にそのまま使える）やリードにして、いつもの作り方で曲にする（曲を決める表・物語・似ている曲の確かめ・形のくじ）。
   鼻歌の旋律は人間が作ったもの。勝手に変えない（音域がテトに合わない時は、調を移す。変える時は言う）。和音の案は I・IV・V・vi だけの単純なものなので、曲にする時に付け直す。

## しくみと、できないこと

- 声の高さを pYIN（librosa）で読む → 全体の音程のずれを直す → 半音に丸めて音に分ける（しゃくり・ビブラートはまとめる。同じ高さの連続は、声の大きさの谷で切る）→ テンポを探す → 8分のマス目にそろえる → 調を決める。
- 試したのは、合成した「鼻歌らしい音」（音程 +35 セント・ビブラート・しゃくり・テンポのゆれ・雑音つき）だけ。24音ぜんぶ合った。**本物の鼻歌ではまだ試していない**。
- 苦手: 16分より細かい動き（`--grid 0.25` で読み直す）、3拍子（`--beats 3`）、テンポが大きくゆれる録音、伴奏や話し声が入った録音、和音（1度に1つの音しか読めない）。

## 1曲め: HUM01「はんぶんこサイダー」（仮・2026-11-25）

- 人間の鼻歌（78秒・低い声 G#2〜C#4）→ 読み取り（ホ長調・合い具合 0.63・テンポ 139 はあやしい）。人間「これをただ大元にするだけで、あとはアレンジして変えて、曲として成り立つように。2オクターブあげて。4分ぐらいで kawaiiFutureベースのアニソン。コンセプトは高校生の甘酸っぱい記憶」。
- 読み取りは半音に丸めるだけでは音階の外の音だらけになった → **全体のずれと調をいっしょに探して、音階に寄せる**形に直した（`fit_scale`・`snap`）。
- 使い方: 読み取りの全部は使わず、**くり返し出てくる動き**を種にした（上がって主音でのばす「6, 7, 1」／「4 3 2 1」／「2 2 2 3 | 3 2 7, 5,」／順に上がる「3 4 5 6」／下りて落ち着く「6 4 2 5, 7, 1」）。リズム・和音・並べ方・歌詞は新しく書いた。
- 高さ: 2オクターブ上はテトの音域を超える → 歌は 1オクターブ＋半音上（ヘ長調）。2オクターブ上の高さは、フックのシンセが弾く。
- 形: `form_dice.py --skeleton 51430 240 150 --min-chorus 3 --not-start 手びょうし`（種 51433）。くじに「サビが N 回より少ない形は引き直す」「この始まり方は引き直す」を足した。サビの旋律は1つにして毎回同じ出だし。
- `assets-src/ai-songs/_gen/kfb_hum01_soda.py`。158小節・4分12秒。歌 7.77・BGM 7.78。耳では未確認。和音に合わない音の自動直しが 28か所入っていて、種の音が少し変わっている所がある。

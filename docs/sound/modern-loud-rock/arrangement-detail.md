# 「プロの曲が素人の曲と違って聞こえる理由」— 区間・小節レベルの深掘り（2026-10-22）

対象: 現代（2015〜2026）のラウドロック／メタルコア／ポストハードコアと、歌のないプログレ・インスト（Intervals・Polyphia・CHON・Covet・Plini・Animals As Leaders・Periphery）。

前回の調査（`docs/sound/modern-loud-rock/structure.md`・`vocabulary.md`・`production.md`、`docs/sound/loud-rock-patterns.md` の型B）で、**構成の骨組み・区間の長さ・エネルギー曲線・つなぎの部品の名前・ブレイクダウンの型・音作りの数値**はすでに決まっている。この文書は、そこに書いていない次のことだけを書く。

- 骨組みの「中身」: 1〜2拍の小さな飾りを、何小節に何個、どこに置くか
- サビで主旋律の下に鳴っている層の、音域と役割の割り振り
- 看板リフを曲の中でどう「育てる」か（出てくるたびに何を1つ変えるか）
- リードを「歌」に聞かせるための、フレーズ単位の決まり
- ドラムの 4小節・8小節単位の変え方と、強さ・タイミングの数値
- 区間の最後の1小節で、楽器ごとに何が起きているか
- 打ち込みが機械っぽく聞こえる原因と、その直し方の数値
- 作曲プログラムで機械的に確かめられるチェックリスト

書き方の約束:
- 【出典】= 読んだ記事・論文に書いてあったこと。【分析】= 出典をもとに、この作曲プログラム向けに数値へ落とした目安（出典に数値がないところは、そう明記する）。
- 既存曲の旋律の音名・タブ・コード進行は書かない。曲名は例としてだけ挙げる。
- 人間（旭さん）の好みは、すべての指示で優先する: 曲の頭を刻みにしない／すぐミュートしない（シンバル・和音は鳴らし切る）／クリーンにコーラスを掛けない／ゴムのようなビブラートにしない（チョーキングはよい）／リードに標準の crunch アンプを使わない／シンセのライザーやキーボードで電子音っぽくしない（型A「入れないもの」）。
- 140BPM の換算: 1拍 = 428.6ms、8分 = 214ms、16分 = 107ms、1小節 = 1.714秒。

## 0. いちばん大事な結論（先に）

1. **プロの曲は「同じ区間の中」でも止まっていない。** 骨組み（区間の並び）が正しくても、各区間の 4小節目・8小節目に何も起きないと、聞き手には「同じものがずっと鳴っている」と聞こえる。Joey Sturgis は、ドラムの打ち込みの段階で**1曲の中に約200か所の変化**を書き込むことがあると話している【出典: Sound On Sound / Joey Sturgis】。100〜125小節の曲なら、**ドラムだけで1小節に1.5〜2か所の変化**がある計算になる。
2. **同時に鳴る「役割」は4つまで。** 「土台（ドラム＋ベース＋同じリズムのギター）」「伸ばす層（パッド）」「動きの層（リズム）」「主役（リード）」「合いの手（フィル）」の5つの役割のうち、同時に鳴らすのはふつう3〜4つ。5つ以上はほとんどうまくいかない【出典: Bobby Owsinski】。素人の打ち込みは「全部の楽器が全部の小節で鳴っている」ことが多い。
3. **合いの手（耳のごちそう）は「主役が休んでいる所」に置く。** 合いの手は「主役への返事」で、主役の旋律のすき間に入る【出典: Owsinski】。主役と同時に鳴る飾りは、飾りではなく「にごり」になる。
4. **くり返しは「同じ型＋最後だけひねる」。** リフのくり返しは冗談と同じで「前ふりは同じ、オチでひねる」【出典: Riffhard】。2回目以降のサビは、1回目の上に「層を足す」か「音域を上げる」だけで、別の曲にはしない【出典: Eyal Levi】。
5. **機械っぽさの正体は「全部同じ」こと。** 同じ強さ（ベロシティ）、同じタイミング、同じ長さ、同じ音のサンプル、左右のギターが同じ演奏のコピー。直し方は「ランダム」ではなく、**人間の体の都合（利き手・拍の重み・フレーズの流れ）に沿ったゆらぎ**を入れること。

## 1. 耳のごちそう（ear candy）— 種類・置き場所・頻度

### 1-1. 出典から分かること
- 合いの手は「主役への返事」。主役の旋律のすき間か、看板のフレーズとして置く【出典: Owsinski】。
- 短い高音の飾り（短い一撃、アルペジオ、逆再生シンバル、左右に飛ぶ効果音、声の切れはし）を、**くり返しの多い区間に「ちりばめて」**、勢いを保つ。数値の決まりは書かれていない【出典: Audient】。
- 低音の一点もの（ドーンという音、サブドロップ）は、ブレイクダウンやドロップの頭に置く。50〜60Hz から下はハイパスで抑え、音量に気をつける【出典: Audient】。
- **1〜2拍の別のフィル**: ふだんのドラムとは別の音（加工したタム回しなど）で1〜2拍のフィルを作ると、本体のドラムへ「転がり込む」ように盛り上がる【出典: Audient】。
- 曲がなくても成り立つが、あるともっとよくなるものが「耳のごちそう」。使いすぎると、少なすぎるのと同じくらい素人っぽく聞こえる。くり返し聞いたときに新しい発見があるように置く【出典: Soundtrap】。
- 「投げ」: 主役のフレーズのあとの空いた1小節に、短い音を1つ置き、拍に合わせたディレイで空間を埋める。ディレイの戻りはローパスで遠くに聞こえさせる【出典: Music Guy Mixing】。
- 1つの飾りの中に、**高い音と低い音の両方**を入れる。音量・フィルター・リズムの動きで形をつける【出典: SoundGirls】。
- Silverstein のミックスでは、ブリッジの雰囲気の層を「ディレイ → 左から右へゆっくり動くオートパン → リバーブ」にしている【出典: Nail The Mix / Sam Guaiana】。
- Lakeview のミックスでは、デモから切り取ったソロの終わりが急に切れていたので、フレーズの最後でリバーブの量を自動で上げて「余韻で消える」ようにした【出典: Nail The Mix / Lakeview】。
- Polyphia はハーモニクスと開放弦で独特の色を足す。「簡単に聞こえるものを、わざと複雑に弾く」【出典: Premier Guitar / Polyphia】。
- 「Playing God」では、目立つしかけ（ハモりのスライドのリフ）を、あとの曲では使う量を減らしている。**目立つしかけは「配給制」**にしている【出典: Shipwrecked Sailor の分析】。

### 1-2. 頻度の目安【分析】
出典には「何小節に何個」という数値はない。上の考え方（すき間に置く・ちりばめる・使いすぎない・配給制）と、型Bの区間の長さから、次の目安を作った。

| 大きさ | 長さ | 頻度の目安 | 置く場所 |
|---|---|---|---|
| 小（1音〜1拍） | 1/8〜1拍 | **4小節に1つ**（8小節の区間で2つ） | 4小節目の3〜4拍目。主役が休んでいる拍 |
| 中（1〜2拍のフレーズ） | 1〜2拍 | **8小節に1つ** | 8小節目の後半。区間の中の区切り |
| 大（区間の境目） | 1拍〜1小節 | **区間の境目ごとに1つ**（型Bの「つなぎ部品」がこれ） | 区間の最後の小節 |
| 一点もの | 1拍＋余韻 | **1曲に1〜2回** | ブレイクダウンの頭、ラストサビの頭 |

- 100〜125小節の曲で、小 20〜30・中 10〜15・大 11〜12（区間の境目の数）・一点もの 1〜2 くらい。
- **同じ飾りを、同じ形のまま3回以上使わない。** 2回目は高さ・長さ・左右の位置のどれかを変える。
- **主役（リード）が鳴っている拍には、中以上の飾りを置かない。** 小の飾りも、リードの音と同じ音域（±5半音以内）なら置かない。
- 静かな区間（Aメロ前半・ブリッジ）は飾りを**半分**に、サビ2・ラストサビは**1.5倍**にする（エネルギーに合わせる）。

### 1-3. この作曲プログラムで使える飾りの部品（電子音を使わない版）【分析】
型Aで「シンセのライザー・キーボードは入れない」と決まっているので、ギター・ベース・ドラム・空間処理だけで作れるものに絞る。

| 部品 | 長さ | 作り方の目安 |
|---|---|---|
| ナチュラル・ハーモニクス | 1音、余韻 1〜2秒 | 12・7・5フレット相当（基音の 2倍・3倍・4倍）。正弦波に近い音＋短いアタック。リバーブ多め。左右どちらかに ±0.4〜0.6 |
| ピッキング・ハーモニクス（「キュイッ」） | 1音、1/4〜1/2拍 | リズムギターの1音を、基音の 3〜5倍の倍音だけ強調した音に替える。4小節目の最後の1音などに |
| スライド・ダウン（区間の終わり） | 1/2〜1拍 | 伸ばした音の音程を 12〜24半音、指数カーブで下げながら音量を下げる。区間の最後の拍に |
| スライド・イン | 60〜150ms | 2〜5半音下から滑り上がって入る。リードのフレーズの頭（3回に1回くらい） |
| ピック・スクレイプ（弦をこする音） | 1/2〜1拍 | 帯域を絞った雑音（2〜6kHz）を高い方から低い方へ動かす。サビやブレイクダウンの直前に1回 |
| フィードバック | 1〜2小節 | `production.md` 6章の作り方。静→動の境目 |
| 開放弦の鳴りっぱなし | 1〜2拍 | 和音を弾いたあと、開放弦の1本だけ 1〜2拍長く残す |
| 1〜2拍の「別の」タム回し | 1〜2拍 | ふだんのタムとは別の加工（ハイパス 200Hz＋短いディレイ）。本体のフィルの代わりに8小節に1回まで |
| スネアの「投げ」 | 1打＋余韻 | 区切りの最後のスネア1打だけ、リバーブの送りを +6〜+10dB（`production.md` 4-2 の値） |
| リードの最後の音の「投げ」 | 1音＋余韻 | フレーズの最後の音だけディレイの送りを上げ、戻りをローパス 3〜4kHz で遠くへ。次の頭で 50ms かけて戻す |
| 逆再生シンバル | 1〜2拍 | `production.md` 6章の値。サビ頭とブレイクダウン頭だけ（1曲に3回まで） |
| 雰囲気の層を左右へ動かす | 2〜8小節 | ディレイの戻りを、0.1〜0.25Hz で左右 ±0.6 にゆっくり動かす。ブリッジの静かな部分だけ。コーラス（音程の揺れ）は使わない |
| ベースのスライド | 1/2拍 | 区間の頭の根音へ、上から 5〜7半音滑り下りる（型Bのつなぎ部品と同じ。数を数える対象に入れる） |
| 全員が抜けて1つだけ残る | 1/2〜1拍 | リードだけ・ベースだけ・ハイハットだけを残す（6章を参照） |

## 2. 対旋律と層の重ね方（サビで主旋律の下に何が鳴っているか）

### 2-1. 出典から分かること
- **役割は5つ**: 土台（ドラム・ベース、同じリズムのギターも含む）／伸ばす層（パッド。歪んだギターの伸ばした和音でもよい）／動きの層（土台に逆らって動きを足す）／主役（歌・リード）／合いの手（主役への返事）。同じリズムで弾くものは、楽器が何本でも1つの役割と数える。2本のリードギターが違うことを弾けば2つと数える【出典: Owsinski】。
- **それぞれの役割に別の音域を持たせる。** 同じ音を同じオクターブで弾く2つの楽器はぶつかる。直し方は、音色を変える・オクターブを変える・弾くタイミングをずらす、の3つ【出典: Owsinski】。
- Periphery のレッスンでは、**4本の役割分け**: リズムギター1本・クリーン2本・リード1本。クリーンの1本は特徴あるリズムで和音を弾き、もう1本は別のリズムと開放弦で音色を足す。リードは和音の変化をなぞる【出典: Premier Guitar / Periphery】。
- Polyphia「Playing God」では、ベースはおもにオクターブを弾き、ギターの音色の邪魔をしない。2本のギターは Aメロで同じ旋律を弾き（ユニゾン）、その分、音階の速い動きが目立つ【出典: Shipwrecked Sailor】。Polyphia の2人は、ユニゾンとハモりを「スライド・チョーキング・タイミングまで」そろえる【出典: Premier Guitar / Polyphia】。
- Silverstein のミックスでは、**オクターブのリード**は「背景だが自分の場所を持つ」層として、ハイパスとローパスで帯域を細くし、8kHz を上げて音量を上げずに前に出している。サビのリードは1本のギターを、左は少し低く・右は少し高く音程をずらして左右に置き、「歌のようなシンセの質感」にしている【出典: Nail The Mix / Sam Guaiana】。
- Lakeview のミックスでは、リードのリフに**1オクターブ上の層**を下に混ぜ、「ガラスのような、シンセのような」音にしている。ソロには**1オクターブ下の層**を混ぜている【出典: Nail The Mix / Lakeview】。
- Joey Sturgis は、似たフレーズを弾くギターを3本重ねると厚すぎて「前に押し出せない」ので、**大きな1本**のほうを好む【出典: Sound On Sound / Joey Sturgis】。重ねるほどよい、ではない。
- 対旋律の決まり【出典: Orphiq】:
  - 主役と**違う音域か違う音色**に置く
  - **主役が休んでいるときに動き、主役が歌っているときは落ち着く**（「交代で忙しくなる」）
  - 反対の向き（主役が上がると下がる）か、片方だけ動く形を基本にする。同じ向きの平行はハモり用にとっておく
  - 3度・6度が気持ちよい。完全5度・オクターブは空っぽに聞こえやすい
  - 強拍には和音の音、弱拍に経過音
  - 主役がいちばん高い所に行くときは、対旋律は逆へ動く
  - **2回目のAメロかラストサビから入れる**（最初からは入れない）
  - 主役より小さく。消しても曲が成り立つか確かめる
- Eyal Levi のサビの積み方【出典: CreativeLive】:
  - サビ1は少なく: 主題をベース・ドラム・主役の旋律だけで
  - サビ2で層を足す（リズムギター、ハモり）
  - ラストサビは「小さな変化」: 高いハモり、ベースを少し前に、**和音の積み方を1段高い転回形に上げる**（和音は同じ）
  - 小さな層（ギターの音をなぞるシンセなど）は、消してみると大きく効いていたと分かる
  - 「育てる」のであって「作り直す」のではない

### 2-2. サビの層の割り振り（Dマイナー・140BPM の例）【分析】
| 層（役割） | 楽器 | 音域（MIDI） | 中身 | サビ1 | サビ2 | ラストサビ |
|---|---|---|---|---|---|---|
| 土台 | キック＋ベース | ベース D1〜D3（26〜50） | 根音を8分、2小節に1回だけ経過音・オクターブ上 | ○ | ○ | ○（ベース +1dB） |
| 土台 | リズムギター L/R | D2〜A3（38〜57） | 伸ばした和音（2分〜全音符）、ルート・5度・オクターブ＋9度か3度 | ○ | ○ | ○（転回形を1段上へ） |
| 伸ばす層 | 高い持続音のギター（E-Bow 風・トレモロ） | D5〜A5（74〜81） | 和音の3度か9度を2小節ずつ伸ばす。ゆっくり動く | なし | ○（−10dB） | ○ |
| 動きの層 | クリーンのアルペジオ（2本目） | A3〜D5（57〜74） | 8分か16分で和音をなぞる。**リードが伸ばしている間だけ動く** | なし | ○ | ○ |
| 主役 | リード | D4〜F5（62〜77） | フック（3章・4章） | ○ | ○＋3度上のハモり（後半4小節から） | ○＋オクターブ上の層（−8dB）＋ハモり |
| 合いの手 | リードの返事・ハーモニクス・スライド | 主役と5半音以上はなす | 主役の休みの拍だけ | 4小節に1つ | 4小節に1つ | 2小節に1つ |

- **同時に鳴る役割の数**: サビ1 = 3（土台・主役・合いの手）、サビ2 = 4（＋伸ばす層か動きの層のどちらか）、ラストサビ = 4（伸ばす層と動きの層は交代で）。**5つを同時に鳴らすのは、ラストサビの最後の2小節だけ。**
- **「すき間」の割り振り**: リードの長い音（2拍以上）の間に、動きの層と合いの手を動かす。リードが細かく動く小節では、動きの層は和音を伸ばすだけにする。
- **音域の重なりを確かめる**: 同じ拍で、2つの層の音が ±2半音以内に入る（ユニゾン・オクターブ以外）のは、1小節に1回まで。
- **リードの真下（1オクターブ以内）には和音の構成音を置かない**ようにリズムギターの積み方を選ぶ（和音の最上音は、リードの音より5半音以上下）。
- オクターブ上の層は、ハイパス 1.5kHz・ローパス 9kHz で細くし、音量は主役の −8〜−10dB。ピッチを揺らすエフェクト（コーラス）は使わない（人間の好み）。左右に広げたいときは、左を −7セント・右を +7セント の固定のずれにする（揺らさない）。

## 3. リフの「育て方」

### 3-1. 出典から分かること
- 動機の育て方の7つの道具【出典: Soundfly Flypaper】:
  1. そのままくり返す（3回くらい。やりすぎない）
  2. 問いと答え（前半は不安定な音で終わり、後半は安定した音で終わる）
  3. 移す（形を保ったまま高さを変える。曲の後半で全音上へ、さらに全音上へ、など）
  4. 付け足す（最後に音を足して締めを強くする）
  5. 切り詰める（短くした切れはしを組み合わせて新しい区間を作る）
  6. 細かく分ける（1つの音のかたまりをさらに分ける）
  7. 拍をずらす（同じ動機を、違う拍から始める。3拍の動機を4拍の小節でくり返すと、毎回ずれる）
- リフは「前ふりは同じ、オチでひねる」。リズム・音・強弱のどれかを変える。**和音の積み方の小さな変化**だけでも、くり返したリフが新しく聞こえる【出典: Riffhard】。
- Periphery のレッスン【出典: Premier Guitar】:
  - 小さな単位（セル）→ それを半音・全音下へ移す → 別の単位と組み合わせる → 全体の編成、の順に育てる
  - 動機を**16分音符1つ分ずらす**（2拍目で）
  - 伸ばしたパワーコードを2小節鳴らしたあとで、短3度を足す（同じ和音が2小節後に色を変える）
  - リフを2回くり返したあと、スライドと弦をまたぐ動きの音階のフレーズへ
  - 3/4 と 4/4 の切りかえ。複雑な割り方は数小節かけて元に戻る
- Intervals の Aaron Marshall の講座の章立て【出典: JamPlay】: リフから旋律を見つける／フックでサビを作る／長いリフに「いくつもの変化」と「いくつもの動く部分」を持たせる／**リフを1オクターブ上に移す**（リードの区間で）／弦1本だけで動機を作り直す。
- Polyphia の LePage: リフはアコギ1本でも成り立ち、聞く人がテンポに合わせて首を振れるものにする【出典: Premier Guitar】。
- Eyal Levi: 同じ区間をそのままコピーすると、最後には聞き手が疲れる。1曲に関係のないアイデアを詰め込みすぎるのも、弱いメタルの曲によくある欠点【出典: CreativeLive】。
- 型Bの既存資料: 「モチーフを3回以上、違う楽器・音域・ノリで出す」（`structure.md` 7-3）。この章は、その「どう変えるか」を具体的にする。

### 3-2. 看板リフの出番ごとの変え方（型Bの並びに合わせた設計図）【分析】
**決まり: 出番ごとに変えるのは1〜2か所だけ。** 3か所以上変えると別のリフに聞こえ、「育った」と感じなくなる。

| 出番 | 小節 | 変えるところ | 変えないところ |
|---|---|---|---|
| ① イントロ（顔見せ） | 2〜4 | **音色**: クリーンかボリューム奏法で、前半2小節だけ（`loud-rock-patterns.md` 型Bのイントロ）。または全体をローパス 800Hz から開く | 音の並び・リズム |
| ② イントロ（全員） | 4〜8 | なし（**原形**をここで聞かせる）。4小節目だけオチ（最後の2拍を一撃＋休みに） | — |
| ③ サビ1のあと（ポストコーラス） | 4〜8 | **オチ**: 4小節目・8小節目の最後の1拍を、リードのフックの最後の音で終える（サビとリフをつなぐ） | 前半3小節 |
| ④ Aメロ2の頭（またはサビ2のあと） | 4 | **高さ**: 1オクターブ上（Intervals の「オクターブ上に移す」）か、**拍のずらし**: 16分1つ遅らせて始める（Periphery） | リズムの形 |
| ⑤ ブリッジ | 4〜8 | **切り詰め＋引きのばし**: 頭の3〜4音だけを取り出し、音の長さを2倍（ハーフタイムのノリ）にしてクリーンで弾く | 音の並び（頭の部分） |
| ⑥ ブレイクダウン | 8 | **リズムだけ**: リフのリズムの形を、最低音の根音1つで弾く（音程を捨て、リズムを残す）。後半4小節で原形の高い音を1つ足す | リズムの形 |
| ⑦ アウトロ | 4〜8 | **付け足し**: 原形を2回 → 3回目の最後に1〜2拍付け足して、主和音か、型Bの「解決しない明るい和音」で終える | 前半 |

- 出番は **最低5回、最大7回**。出番と出番の間は**16小節以上**あける（イントロの①②は続けてよい）。
- 「和音の積み方の小さな変化」（Riffhard）: ②と⑦で、同じ根音の上の音を 3度 → 9度、5度 → 4度 などに1つだけ替える。
- 「伸ばしてから色を足す」（Periphery）: リフの中の伸ばした和音を、2回目のくり返しで2小節目から短3度（または9度）を足す。
- 「3拍の動機を4拍の小節でくり返す」ずれ（Flypaper・型Aの7つのかたまり）を使う場合も、**ずれは2小節か4小節で必ず元に戻す**（`vocabulary.md` 7-2）。
- **リフとリードのフックを1つの音でつなぐ**: リフの最後の音か最初の音を、サビのフックの最初の音と同じにする（③で効く）。曲が「1つの素材から育った」ように聞こえる。

## 4. インストのリードを「歌」に聞かせる書き方

### 4-1. 出典から分かること
- Intervals: リードは「ソロ」ではなく「歌」として扱われた（プロデューサー Sam Guaiana）。音の選び方とフレーズは、速弾きの人ではなく「表現する作曲家」のもの。何も考えない速弾きではなく、長く残る旋律で曲に仕える【出典: Produce Like A Pro】。
- Aaron Marshall の具体的なこつ【出典: MusicRadar】:
  - **弦1本だけで旋律を書く**（箱の形の音階では見つからない音と弾き方が見つかる。完成形は1本でなくてよい）
  - 「予想できない・音の幅が広い」旋律を目標に、**弦を飛ばして大きな跳躍**を作る
  - 音階のかけらをオクターブで移すのは便利だが、**使いすぎると硬く聞こえる**
  - 1本の弦で2音、次の弦で1音（ふつうの速いフレーズやスウィープより心地よい）
  - **音階の中で、弾く音より抜く音を多くする**（「真ん中の色」を好む）
  - 根音が1音ずつ下りていく低音の線
- Plini の技【出典: Guitar World】:
  - **フレーズの中で和音の音をはっきりたどる**、くり返せて歌える形
  - スライドで音をつなぐ（レガート）。**フレーズの最後でチョーキング**して歌い手の抑揚をまねる
  - 半音の経過音で緊張を作り、音階の音に解決する（歌い手が音程へ滑り込むのに近い）
  - 速い部分は、バンド全体と**ユニゾン**で弾くとリードが前に出る
  - 指で叩く音（タッピング）は、弾かない弦をミュートして1音ずつ「言葉のように」はっきりさせる
- Plini: 自分がまだやったことのないことをやる。好きなもの同士で、まだ組み合わされていないものを組み合わせる。自分は簡単なことを弾き、バンドの他の人が細かく動く場面もある【出典: Metal Injection】。音の積み方とフレーズの弾き方（アーティキュレーション）に時間をかけた【出典: Mixdown】。
- Polyphia の Tim Henson: ギターを「ラッパー」のように聞かせたい（＝**リズムで語る**）。ピアノで作曲して、ギターの手グセから離れる【出典: Premier Guitar】。
- Covet の Yvette Young: 先に**歌ってから**フレットで探す。聞いた人が「あとで口ずさめる」ものを目指す。最近の曲は「速弾きのタッピング」より「旋律が主導する」【出典: Performer Mag・Guitar World】。
- Animals As Leaders の Tosin Abasi: 聞き手をつかむ「歌うような演奏」。ソロは**音を少なく、1音1音を選ぶ**方向へ変わってきた。曲は層が多いが「詰め込み」ではなく、くり返しに頼る【出典: Premier Guitar】。
- フレーズの決まり【出典: Killer Rig】:
  - 短い動機は音階から**3〜4音**、問いと答えのフレーズは**4〜6音で十分**
  - **フレーズのあとに最低2拍休む**
  - 同じ3音で、リズムだけを変える（均等／最初を長く／2音目のあとで休む）
  - チョーキングは半音か全音で、目標の音程に合わせる。ビブラートは「少し音をまっすぐ保ってから」ゆっくり均等に
  - 強弱: 5音のフレーズを「弱→だんだん強く→最後の音がいちばん強い」にする
- 問いと答え: **最初のフレーズは和音にない音で終え（問い）、2つ目のフレーズは和音の音で終える（答え）**。2つ目で動機をもう一度言い直す【出典: Guitar World / Rut-Busters】。
- 旋律を**1〜2拍早く**（小節の頭より前から）始め、その拍だけ他の楽器を抜くと、入りが目立つ【出典: Loopcloud】。

### 4-2. 作曲プログラムへの指示（リード）【分析】
**フレーズの形**
- 1フレーズ = **2小節（音を出す部分は 5〜7拍）＋休み 1〜3拍**。8小節 = 4フレーズ。4フレーズの形は **A・A'・B・A''**（A' はオチだけ変える、B は高さを変える、A'' は付け足しで締める）。型Bの「A・A'・B・終止」と同じ考え方を、フレーズ単位で守る。
- 1フレーズの音の数: **4〜9音**。10音を超える速いパッセージは **8小節に1回まで**（ラストサビとソロ区間は16小節に3回まで）。
- フレーズの**始まりの位置**を散らす: 8小節の中で、小節の頭から始まるのは半分以下。残りは「前の小節の4拍目の裏から（1/2拍早い）」「1拍目の裏から」「2拍目から」。
- 奇数番目のフレーズは**和音にない音（9度・4度・6度）か長い音**で終え、偶数番目は**和音の音（根音・3度・5度）**で終える。ただしサビの最後のフレーズは型Bどおり「解決しきらない音」で止めてよい。
- **同じ音の連打でリズムを語る**（Polyphia の「ラッパー」の考え方）: 1つのフックの中に、同じ音を3〜4回、16分のシンコペーションでくり返す部分を1か所入れてよい。旋律のための跳躍と組み合わせる。
- **抜く音を多く**: 音階の7音のうち、1フレーズで使うのは4〜5音（Marshall「真ん中の色」）。
- **弦1本・弦飛ばしの考え方**: 1フレーズに1回、6〜9半音の跳躍を入れる（跳んだら順次で戻る＝型Bの決まりと同じ）。

**奏法（音の出し方）を音の数に対して割り当てる**
| 奏法 | 1フレーズあたり | 実装の目安 |
|---|---|---|
| スライド・イン | 0〜1回（3フレーズに1回くらい） | 2〜5半音下から 60〜150ms で滑り上がる。アタックは弱め（−6dB） |
| 音と音のスライド | 0〜1回 | 2つの音の間を 80〜200ms で滑らかに。2音目は弾き直さない（新しいアタックを付けない） |
| レガート（ハンマリング・プリング） | 3音以上の順次の速い動きに | 2音目以降はアタックを −8〜−15dB 弱く、ピックの雑音なし |
| チョーキング | 1回（フレーズの頂点か語尾） | 半音か全音を 60〜150ms で上げきって止める（`production.md` 2章の値）。上げきったら音程はまっすぐ |
| ビブラート | 語尾の長い音（2拍以上）だけ | 最初の 30〜40% はまっすぐ保ち、そのあと浅く（±10〜15セント、4.5〜5Hz）。**ゴムのような深い揺れにしない** |
| 経過音（半音） | 0〜2音 | 弱拍だけ。次の拍で音階の音に解決 |
| 装飾音（グレース・ノート） | 0〜1回 | 主音の 30〜60ms 前に、1〜2半音下の短い音 |

- **強弱の形**: フレーズの中で、最後に向かって +3〜+6dB（ベロシティで +10〜+20）上げる形を基本にする。ただし 4フレーズのうち1つは逆（最初が強く、だんだん弱く）にする。
- **音の長さ**: 次の音の直前まで伸ばす（レガート）を基本に。フレーズの最後の音は余韻（リバーブ・ディレイ）まで含めて鳴らし切る。次のフレーズまで休みがあるので、そこで「息つぎ」になる。

**ハモり・重ね・音色の切りかえ**
- ハモりは**区間の後半から**入れる（最初の2〜4小節は単音 → 後半からハモり。`vocabulary.md` 5-2 と同じ）。ハモりの音は3度上（音階の中）を基本に、和音の音にぶつかる所だけ4度か6度に替える。
- **ハモりはスライド・チョーキング・タイミングまで主旋律とそろえる**（Polyphia）。ハモりのパートだけ奏法が抜けていると、すぐに打ち込みと分かる。ただし発音のタイミングは +5〜+10ms ずらす（`production.md` 2章）。
- **速い部分はユニゾン**（Plini）: リードの速いパッセージ（10音以上）が来る小節では、リズムギターかベースもそのリズムを一緒に弾く（同じリズムで、高さは和音の音でよい）。
- **音色を区間で替える**: Aメロ = ネック側の柔らかい音（または小さめのリード）、サビ = いつものリード、ラストサビ = リード＋オクターブ上の層（Lakeview）、ブリッジ = クリーンかボリューム奏法。1曲で使うリードの音色は **3種類まで**。
- **リードの合計の割合**は型Bどおり曲全体の 50〜70% の小節。そのうち「速いパッセージ」の小節は 10% 以下。

## 5. ドラムの作り込み（4小節・8小節単位の変化）

### 5-1. 出典から分かること
- Joey Sturgis は、ドラムを録る前に、音の基準つきの MIDI で全部を書き出す。**1曲で約200か所の変化**があることもある【出典: Sound On Sound】。
- **同時にたたけるのは手で2つまで**（キックとハイハットのペダルは別）。クラッシュと重なる閉じたハイハットは消す。両手がふさがるフィルの間は、ハイハットをペダルで踏む。**スネアのフィルの近くで、ときどきハイハットを開ける。** フィルにはリムショットや縁の音を混ぜ、同じ音の連続を避ける【出典: Splice】。
- **ハイハットの強さの順番**: 小節の1拍目がいちばん強い → 3拍目 → 2・4拍目 → 裏拍はもっと弱い。ハイハットがいちばん強さの差が大きく、キックとスネアは少しだけ（同じサンプルに聞こえない程度）。フィルのスネアは左右の手の差を出すため差を大きく。**1小節分の強さの手直しを、全部の小節にコピーしない**【出典: Splice】。
- 強さ（ベロシティ）の数値【出典: Nail The Mix / GetGood Drums 3記事】:
  - ふつうのバックビート（2・4拍のスネア）: 115〜120、または 120〜127 の間で変える
  - **127 はブレイクダウンなどの大きな山のためにとっておく**
  - ブラストビートのスネアは低め（105〜115）。速い所ほど下げる
  - ゴーストノート: 20〜40（20〜50）
  - ハイハット・ライドは 5〜10 の幅で揺らす
  - 強さが変わると、音の大きさだけでなく**録音そのもの（サンプルの層）**が変わる
  - クオンタイズ（拍に寄せる強さ）は 85〜95%、**100% にはしない**。フィルは 85% にゆるめて「生の慌ただしさ」を出す
  - フィルを急がせるときはスネアを数ms前へ、ゆったりさせるときはキックを少し後ろへ
- URM の5つのこつ【出典: URM Academy】:
  - フラム（2打をほぼ同時に）でゆっくりしたフィルのスネア・タムを強調。シンバルのチョーク（つかんで止める）は区間の終わり
  - 110〜120 が「現実的に強い」一打。最大の層を使いすぎない
  - **3つ以上を同時にたたかない**
  - 速い16分・32分のフィルでは、**左手の音を右手より 5〜25 弱く**（「マシンガン」に聞こえるのを防ぐいちばんの方法）
  - タイミングのゆらぎは 2〜5% くらい
- Loopmasters: 強さのゆらぎは ±4%（0〜127 で ±5）。タイミングは最大 8ティック、速い曲では最大 12ティック。ゴーストは 40 くらい、左手がたたく位置だけに残す（16分の右手の位置のゴーストは消す）。フィルは高いタムから低いタムへ、キックは4分で鳴らし続ける。**同じサンプルの加工したコピーを半分の打に使う**（同じ音の連続を避ける）【出典: Loopmasters】。
- Sound On Sound（Cubase）: 1拍目は動かさず、それ以外を ±5ティックでゆらす。強さは −5〜−10 のランダム。**パターンは8小節以上の長さで作り**、コピーしたら少しずつ手を入れる【出典: Sound On Sound】。
- 実際のドラマーのゆれ（論文）:
  - ロック・ポップで、クリックに合わせた演奏の1拍ごとの間隔のばらつき（標準偏差）は **約 9.2ms**、クリックなしで 11.9ms【出典: Sogaard ほか arXiv 1710.05608】
  - そのゆれは**ばらばらのランダムではなく、前後の拍とつながっている**（長い時間でゆっくり波打つ）。約8拍より短い時間では「手足のゆれ」、長い時間では「テンポのゆっくりした流れ」が主になる【出典: 同上】
  - 有名なロックドラマー5人の調査では、2・4拍目のスネアは平均で拍の長さの ±1% 前後ずれる（120BPM なら ±5ms 前後）。人によって「いつも少し遅い」「いつも少し早い」という**くせ（指紋）**がある。テンポのばらつきは、クリックを使った録音で 0.2〜0.5%、生の演奏で 0.8〜1.8%【出典: Carter & von Appen 2025】
- Sound On Sound の「ノリの型」: 120BPM で、キックの1・3拍目を約 18ms 早く（押す）、スネアの2・4拍目を約 15ms 遅く（ゆったり）。区間のくり返しごとに、拍に寄せる強さを少しずつ変える【出典: Sound On Sound】。

### 5-2. 4小節・8小節単位の「変化の予定表」【分析】
`vocabulary.md` 6-2 の「4小節ごとに小さいフィル、8小節ごとに大きいフィル」を、小節ごとの予定に細かくした。1区間 8小節を基本とする（16小節の区間は 8小節×2 として、後半の8小節は前半と違う選択肢を使う）。

| 小節 | 起きること（どれか1つ以上） |
|---|---|
| 1 | 区間の頭: クラッシュ（またはチャイナ）＋キック。シンバルは鳴らし切る。前の区間と**シンバルの種類を変える** |
| 2 | ほぼ基本形。ゴーストの位置を1か所だけ1小節目と変える |
| 3 | 基本形。ハイハットの開き（4拍目の裏）を1回、またはキックを1つ足す／抜く |
| 4 | **小さい変化**: 最後の1拍で小さいフィル（タム2〜3打）か、スネアの装飾（フラム・3連）か、**何も鳴らさない半拍**。小節の頭のクラッシュは次の5小節目に |
| 5 | 1小節目と同じ扱い。ただし**クラッシュは左右の別の1枚**に |
| 6 | 2小節目と違うゴーストの位置。キックの形を1つ変える（ギターのリフに合わせて） |
| 7 | 盛り上げの準備: ハイハットを半開き・開き気味に、またはライドのカップを混ぜる |
| 8 | **大きい変化**: 最後の2拍のフィル（種類は下の表から、前回と違うもの）。区間の最後なら 6章の「最後の1小節」に従う |

**フィルの種類（同じ種類を続けて使わない。1曲で最低5種類）**
| 種類 | 長さ | 中身 |
|---|---|---|
| A. タム下り | 1〜2拍 | 16分でハイタム→ミッド→フロア。最後の1打はフロア＋キック |
| B. 3連（6連）回し | 1〜2拍 | 3連でスネア→タム→フロア。テンポが遅く感じる効果 |
| C. スネアだけの上昇 | 1〜2小節 | 8分→3連→16分（強さを 70→120 へ） |
| D. キックとシンバルの一撃そろえ | 1〜2拍 | ギターのリズムと同じ位置で、クラッシュ（またはチャイナ）＋キック＋スネア |
| E. 間（何もしない） | 1/2〜1拍 | フィルの代わりに無音。シンバルの余韻だけ残る |
| F. フラムの4分 | 1〜2拍 | ゆっくり、フラムでスネア→タム→フロア |
| G. ツーバスの連打 | 1拍 | 16分か6連のキック＋スネアの頭だけ |
| H. 別の音のタム（ear candy） | 1〜2拍 | 1-3 の「別のタム回し」。8小節目のフィルとして1曲に1〜2回 |
| I. 32分の短い連打 | 1/2拍 | スネアの32分を4打、強さは 50→110 へ |

**区間ごとのシンバルとハイハットの選び方（同じ区間名の2回目では、どれか1つ変える）**
| 区間 | 1回目 | 2回目 |
|---|---|---|
| Aメロ | 閉じたハイハット8分（または16分） | ライドの本体8分＋カップを1・3拍目 |
| Bメロ | ハイハットを半開きへ／ライドのカップ4分 | クラッシュ4分（スネアの連打で上げる） |
| サビ | ライドかオープンハイハット8分、小節頭にクラッシュ | クラッシュ8分（明るい方）、4小節ごとにチャイナを足す |
| ポストコーラス（看板リフ） | チャイナ4分 | スタック（短い重ねシンバル）8分 |
| ブリッジ | タムとフロアのグルーヴ＋ライド | — |
| ブレイクダウン | チャイナ4分 | 後半4小節でチャイナ2分＋クラッシュ |

**キックの形の変え方**
- Aメロ: ギターのリフのアクセントに合わせる（全部は合わせない。7〜8割）
- サビ前半: 1・3拍目中心のシンプルな形 → **サビ後半の4小節で8分か16分に詰める**（型Bの「ツーバスはサビの後半だけ」）
- 同じキックの形が **8小節を超えて続かない**ようにする

### 5-3. 強さ（ベロシティ）とタイミングの数値【分析・出典の数値を140BPMにそろえた】
| 打 | ベロシティ | 1打ごとの揺れ | タイミング |
|---|---|---|---|
| スネア 2・4拍（ふつう） | 112〜120 | ±4 | 0〜+6ms（少しだけ遅め）。曲ごとに1つの「くせ」を決めて固定 |
| スネア（区間の頭・サビの山） | 122〜127 | ±2 | 0〜+4ms |
| スネア（ブラスト・速い連打） | 100〜112 | ±5 | ±3ms |
| ゴースト | 22〜40 | ±6 | +5〜+15ms（遅めでよい） |
| キック（ふつう） | 100〜115 | ±5（トリガー層は ±1.5dB まで。`production.md` 4-1） | 0〜−3ms（ほんの少し前） |
| キック（ツーバス） | 90〜110 | ±8、右足を +4 強く | ±3ms |
| ハイハット 1拍目 | 95〜105 | ±5 | ±4ms |
| ハイハット 3拍目 | 88〜98 | ±5 | ±4ms |
| ハイハット 2・4拍目 | 80〜90 | ±5 | ±4ms |
| ハイハット 裏拍 | 60〜78 | ±7 | ±5ms |
| ライド本体 | 75〜95（カップは 100〜115） | ±7 | ±4ms |
| クラッシュ・チャイナ | 100〜120 | ±6 | キックと同時（±1ms）。**キックとそろえる打はゆらさない** |
| フィル（右手） | 95〜120 | ±5 | ±5ms |
| フィル（左手） | 右手より 8〜20 弱く | ±6 | ±6ms |

- **ゆらぎの作り方**: 1打ごとに独立したランダムではなく、**なめらかにつながったゆらぎ**（前の打のずれを 70〜85% 引きつぐ「ランダムウォーク」に、毎打 ±2〜3ms の小さなランダムを足す）にする。全体のばらつきは標準偏差 **4〜7ms**（クリックに合わせたプロのメタル。生のロックの 9ms より小さく。メタルは編集でそろえる文化のため）。
- 1拍目のクラッシュ＋キックと、ギターと一撃を合わせる打は、ゆらさない（±1ms）。
- **フィルの中だけ**、拍に寄せる強さをゆるめる（ゆらぎを 1.5倍、最大 ±10ms）。
- **強さの流れ**: 8小節のなかで、ハイハット・ライドの平均の強さを、区間の後半に向かって +5〜+10 上げる（盛り上げ）。Bメロは +10〜+20。
- **同じサンプルの連続を避ける**: 同じ強さが2打続いたら、2打目の強さを ±3 動かすか、別の録音（ラウンドロビン）を使う。

## 6. 展開のつなぎの細部（区間の最後の1小節で起きていること）

### 6-1. 出典から分かること
- サビの前に、ドラムを**半小節〜1小節**まるごと抜くと、戻ったときに強く当たる。ハイハットだけ残す形もある【出典: Loopcloud】。
- 「引き算」のつなぎ: フレーズの最後の小節で1つの楽器を抜く（例: ブレイクダウンの1小節前にハイハットを抜く）。「積み重ね」のつなぎ: 最後の1〜2小節に、逆再生シンバル・フィルター・フィルかスネアの連打・短い音量の下げを重ねる【出典: Beat Kitchen】。
- 区切りの小節で、楽器とリバーブの戻りの音量を、小節の頭でぱっと下げる（余韻が休みを埋めないように）【出典: MusicRadar】。※ 人間の好み「すぐミュートしない」があるので、**シンバルと投げたリバーブの余韻は残す**。下げるのはギターとベースの「鳴っている音」だけにし、それも 30〜80ms かけて下げる。
- 4/4 の途中に 3/4 の小節を入れて1拍減らす、5/4 で1拍増やす【出典: MusicRadar】。
- ディレイのフィードバックを上げて、こだまを「消えずに積み上がる」ようにし、ちょうどの所で下げる【出典: MusicRadar】。
- 旋律を**1〜2拍早く**始め、その拍は他の楽器を抜く【出典: Loopcloud】。
- リバーブの量をフレーズの最後で最大にして、次の小節へ余韻で流す（次の小節の1拍目のクラッシュの代わりになる）【出典: Loopcloud】。
- ブリッジの雰囲気のギター（ディレイ＋ゆっくりした左右の動き＋リバーブ）【出典: Nail The Mix / Silverstein】。
- 日本のラウドは前ぶれを大事にする（既存 `structure.md` 4-1）。

### 6-3. つなぎの決まり（全体）【分析】
- 区間の境目のうち、**「音が増えて入る」つなぎと「音が減って入る」つなぎを両方使う**（素人の曲は全部「増えて入る」になりがち）。12の境目のうち、減って入るのを3つ以上（Aメロ1・ブリッジ・ラストサビの頭など）。
- **最後の1小節で何も起きない境目を作らない**（ドラム・ギター・ベース・飾りのうち、最低2つが「最後の1小節だけの動き」をする）。
- 境目の1拍目にクラッシュを鳴らすのは、全体の7割まで。残りはチャイナ・クラッシュなし・ライドのカップなどにする（毎回クラッシュだと単調）。
- 3/4 の小節を入れて1拍減らすつなぎは、1曲に1回まで（Bメロ → サビなど）。

## 7. 打ち込みが「機械っぽく」聞こえる原因と直し方

### 7-1. 原因の一覧と、出典の数値
| 原因 | 出典の内容 |
|---|---|
| 強さが全部同じ（とくに全部 127） | 127 ばかりだと、ソフトな層・ゴーストなどの細かい表情を捨てる。強さで録音の層そのものが変わる【Nail The Mix】。最大の層を使いすぎない。110〜120 が「現実的に強い」【URM】 |
| タイミングがぴったり | クオンタイズ 85〜95%、100% にしない【Nail The Mix】。±8〜12ティック【Loopmasters】／±10ティック以上は「間違い」に聞こえる【Splice】。2〜5%【URM】。ロックのドラマーの1拍ごとのばらつきは約9ms【arXiv】 |
| ゆらぎがばらばら | 人間のずれは前後とつながっている（長い時間で波打つ）。独立したランダムとは統計的に違う【arXiv】 |
| 同じサンプルの連続（マシンガン） | 加工したコピーを半分の打に使う【Loopmasters】。左手を 5〜25 弱く【URM】 |
| ありえない同時打ち | 3つ以上を同時にたたかない【URM】。手は2つまで、クラッシュと重なる閉じたハイハットを消す【Splice】 |
| 1小節の手直しのコピー | 1小節分の強さの手直しを全部にコピーしない【Splice】。パターンは8小節以上で作る【Sound On Sound】 |
| 左右のギターが同じ演奏 | 二重録音は「別々の2つの演奏」でないと効かない。コピーして 20ms 遅らせて左右に振るのは「ひどい音」。コーラスで広げるのも本物よりずっと悪い。2本目は1本目にぴったり近く（離れすぎると左右の往復に聞こえる）【ProSoundWeb】。少しの違いが個性になる【Riffhard】。人工の二重録音は少なくとも ±20ms、ときに ±30ms のゆっくりした揺れ（0.03Hz と 0.07Hz の2つの揺れ）が必要【Sweetwater】 |
| 繰り返す音の音量・低音がばらばら | リフの中でくり返す音は、ひずみの量と低音がそろっているべき（ただし音声のコピーではなく）【Sound On Sound / Sturgis】 |
| ハモりの奏法が主旋律と違う | スライド・チョーキング・ずらしまでそろえる【Premier Guitar / Polyphia】 |

### 7-2. 直し方（作曲プログラムの設定値）【分析】
**ドラム**: 5-3 の表のとおり。要点だけ:
- ベロシティは打の種類ごとの範囲から選び、127 は 1曲で **8打以下**（区間の頭の山・ブレイクダウンの一撃だけ）。
- タイミングは、つながったゆらぎ（ランダムウォーク、引きつぎ 0.7〜0.85）で標準偏差 4〜7ms。一撃をそろえる打は ±1ms。
- 同じベロシティが3打続かない。左手は右手より 8〜20 弱い。

**ギター（左右の2本・4本）**
- 左右は**別々の演奏として作る**（片方のコピーをずらすのは禁止）。
  - 発音のタイミング: 各音で、それぞれ独立につながったゆらぎ（標準偏差 3〜6ms）。左右の差の平均は 0 に近く、**左右のずれが 15ms を超える音は 5% 以下**（それ以上は往復して聞こえる）
  - 強さ: 左右それぞれ ±6〜8%
  - 音の長さ: ±5%（伸ばす和音は ±10%）
  - 音程: 左右で固定の ±2〜4セント（揺らさない＝コーラスにしない）
  - ピックの当たり: 2〜3種類の当たりの音を交互に（ラウンドロビン）。左右で別の順番
  - 内側の2本（`loud-rock-patterns.md` 型Bの4本重ね）はさらに別の演奏として作る
- **音の終わり**: 和音が変わる直前の 10〜30ms は音を下げる（左手を動かす時間＝現実の弦の移り）。ただし**伸ばす和音はすぐ止めない**（`production.md` の 300ms〜1.5秒の自然な減衰）。止めるのは速い刻みの区切りだけ。
- **ダウンとアップの差**: 8分・16分の刻み（使う場合）は、裏の音（アップ）を −1.5〜−3dB、高い音域を少し多く（明るめ）にする。和音のかき鳴らしは、ダウンは低い弦から、アップは高い弦から、弦ごとに 3〜8ms ずつずらして鳴らす（全部の弦が同時に鳴らない）。
- **リフの中のくり返す音**: 同じ高さの音は、ひずみの量と低音をそろえる（音量の差は ±1dB 以内）。そのうえでタイミング・当たりの音だけ変える。

**ベース**
- 指弾きのゆらぎ: タイミングは標準偏差 4〜6ms、キックと合わせる音は ±2ms。強さは ±6%。
- 人差し指と中指の差: 交互に −1dB（左手の差と同じ考え方）。
- 音の長さ: 次の音の直前まで伸ばすのを基本に、休みの前の音だけ 70〜85% の長さ。

**リード**
- 4-2 の奏法の割り当て（スライド・レガート・チョーキング・装飾音）を必ず入れる。**奏法なしで、全部の音がまっすぐ同じアタックで鳴るリードは「機械」に聞こえる。**
- タイミング: ゆったりした場面は +5〜+15ms 遅め、速いパッセージは ±3ms。フレーズの最初の音は 0〜−10ms（少し前に出る）。
- 強さ: フレーズの中の流れ（4-2）＋各音 ±5%。

**テンポ**
- メタルコア・インストはクリックに合わせて作るのがふつうなので、テンポは一定でよい（クリックを使った録音のテンポのばらつきは 0.2〜0.5%【Carter & von Appen】）。テンポの揺れは入れない。人間らしさは「拍の中のずれ」で出す。

## 8. チェックリスト（作曲プログラムで機械的に確かめる・22項目）

数値の目安は上の各章。「○○以下」「○○以上」は、作曲プログラムの出力（ノートの一覧）から数えられる。

### 構成・層
1. [ ] **同時に鳴る役割の数**（土台・伸ばす層・動きの層・主役・合いの手。同じリズムのものは1つと数える）が、どの小節でも 4 以下。5 はラストサビの最後の2小節だけ。
2. [ ] **音域のぶつかり**: 同じ拍で、別の役割の2音が ±2半音以内（ユニゾン・オクターブを除く）に入るのは、1小節に1回まで。リードの音の下1オクターブ以内に、リズムギターの和音の最上音がない（5半音以上はなれる）。
3. [ ] **サビの層の積み上げ**: サビ1 < サビ2 ≦ ラストサビ（役割の数かパートの数）。サビ2・ラストサビにはサビ1にない層（ハモり・オクターブ上・伸ばす層・動きの層）が最低1つ。
4. [ ] **対旋律**（動きの層・合いの手）は、リードが鳴っている拍の 70% 以上で「伸ばしているか休んでいる」。リードの休みの拍の 50% 以上で何かが動いている。対旋律はAメロ2かサビ2から始まる。

### 耳のごちそう
5. [ ] **小さい飾り**（1拍以下）が 4小節に1つ以上（静かな区間は 8小節に1つ以上）。
6. [ ] **中くらいの飾り**（1〜2拍）が 8小節に1つ以上。
7. [ ] 飾りの 80% 以上が、リードの休みの拍か、リードと5半音以上はなれた音域にある。
8. [ ] 同じ飾り（種類・高さ・左右の位置が同じもの）を3回以上使っていない。逆再生シンバルは1曲に3回まで、一点もの（サブドロップなど）は1〜2回。

### リフ
9. [ ] 看板リフの出番が5〜7回。出番の間が16小節以上（イントロを除く）。
10. [ ] 看板リフの出番ごとの変更点が1〜2か所（音色・高さ・ずらし・切り詰め・付け足し・リズムだけ・和音の積み方のうち）。原形のまま出るのは2回まで。

### リード
11. [ ] フレーズの長さが 4〜9音、フレーズのあとに 1拍以上（基本は 2拍以上）の休みがある。10音以上の速いパッセージは 8小節に1回まで。
12. [ ] フレーズの始まりのうち、小節の1拍目の頭から始まるのが 50% 以下。
13. [ ] 1フレーズに、スライド・レガート・チョーキング・装飾音のどれかが最低1つ。チョーキングは1フレーズに2回まで。深いビブラート（±20セント超）が0。
14. [ ] ハモりのパートが、主旋律と同じ位置に同じ奏法（スライド・チョーキング）を持っている。ハモりは区間の頭からではなく後半から入る。

### ドラム
15. [ ] 同じドラムの小節（キック・スネア・シンバルの形が同じ）が 4小節を超えて続かない。全く同じ8小節のかたまりが曲の中にない。
16. [ ] フィルが 4小節目（小）・8小節目（大）にある。フィルの種類が1曲で5種類以上、同じ種類が続けて出ない。
17. [ ] ハイハットの強さが「1拍目 > 3拍目 > 2・4拍目 > 裏拍」の順。ハイハット・ライドの強さのばらつきが 5〜10。ゴーストは 20〜40。127 の打が 8打以下。
18. [ ] 手でたたく音が同時に3つ以上ない。クラッシュと同時の閉じたハイハットがない。速いフィルで左手が右手より弱い。

### タイミング・人間らしさ
19. [ ] ドラムの打のタイミングのばらつき（標準偏差）が 4〜7ms で、隣の打とのずれに相関がある（引きつぎ 0.7 以上）。一撃をそろえる打（区間の頭のクラッシュ＋キック、ギターとの一撃）は ±1ms。
20. [ ] 左右のリズムギターが別々の演奏（タイミングの差の平均が 0±2ms、15ms を超える差が 5% 以下、強さ・長さ・当たりの音が独立）。片方のコピーをずらしたものではない。

### つなぎ
21. [ ] すべての区間の境目で、最後の1小節に「その小節だけの動き」が2つ以上の楽器にある。同じつなぎのレシピが3回続かない。「音が減って入る」境目が3つ以上。
22. [ ] 区間の頭のクラッシュが境目の 70% 以下（残りはチャイナ・ライドのカップ・シンバルなし）。シンバルと和音の余韻を途中で切っていない（人間の好み）。

### 調べたが使えなかったもの・限界
- Hooktheory には、対象のバンド（Intervals・Polyphia・Plini・Periphery など）の分析ページが見つからなかった（同じ名前の別の曲がヒットしただけ）。
- Riffhard「How to Create a Guitar Riff」（URL 制限で読めず）、hackmusictheory「Backing Melody Rule」（転送先が読めず）、オスロ大学の Câmara の論文（転送先が読めず）。
- Sheet Happens（Intervals の譜面の案内）は、技法の名前（ハイブリッド・ピッキング）以外の中身が文章になかった。
- **「耳のごちそうを何小節に何個」という数値は、どの出典にも書かれていなかった。** 1-2 の頻度の表は、出典の考え方（すき間に置く・ちりばめる・使いすぎない・配給制）と型Bの区間の長さから作った目安。実際の曲で耳で確かめて直すこと。
- ドラムの数値は、メタルの打ち込みの解説（Nail The Mix・URM）と、ロック全般の論文（arXiv・Carter & von Appen）を組み合わせた。メタルコアのドラマー本人の演奏を測った論文は見つからなかった。

# 現代ラウドロック／メタルコア／ポストハードコア／ジェントの語彙（2015〜2026年ごろ）

調査日: 2026-10-22。作曲解説記事・レッスン記事・音楽理論の論文など 30 前後の情報源を読み、作曲プログラムで実装できる形にまとめた。
**特定の曲の旋律・コード進行は書かない**（一般的なパターンとしてだけ書く）。

- 表記: 4/4 拍子、1小節＝16分音符16個（0〜15）。「1拍目の裏」＝16分の位置2、「2拍目」＝位置4、など。
- 和音はローマ数字（短調の主和音＝i）。半音＝st。
- 【出典】は情報源から直接言えること、【整理】は情報源の内容とジャンルの通例をまとめ直した実装ルール。

## 0. 全体の設計思想（いちばん大事なこと）

【出典】
- メタルコアの基本の形は「重い（叫ぶ）ヴァース → メロディアスなサビ」の対比。サビでは、ヴァースのまばらで打楽器的な刻みから「伸ばす和音やリードの旋律」に開ける（gravitee のまとめ、Riffhard の Chorus 記事）。
- サビらしさを決めるのは、和声や音の高さよりも「音色（明るさ・ざらつき）と音色の変化の多さ」がやや強い。サビは音が高く、音程がはっきりし、**音量の幅（ダイナミクスの幅）が小さい＝ずっと詰まって鳴っている**（Van Balen ほか 2013 の実証研究）。
- ブレイクダウンが重く感じられるのは、その前の部分で速さや密度を作ってあるから（gravitee）。重さは「その前との差」で生まれる。
- ダウンビートの前の短い無音が、そのあとの全員の入りを重くする（gravitee、Riffhard の Breakdown 記事）。

【整理】実装ルール
- 1曲の中で「密度」を数値で設計する。各セクションに `density`（0〜1）を持たせ、隣のセクションと **0.3 以上差** をつける場所を最低3か所つくる（イントロ→ヴァース、プレサビ→サビ、サビ→ブレイクダウン or ブリッジ）。
- 刻み（パームミュート）だけのセクションは連続2つまで。3つ目は必ず「伸ばす和音」「旋律」「アンビエント」のどれかにする。
- **曲の最初を刻みで始めない**。イントロは、(a) クリーンのアルペジオ＋空間系、(b) 伸ばす和音（歪み）＋シンバル、(c) リードの旋律＋ドラムのタム中心、のどれかから始める。

## 1. サビの旋律

### 1-1. 情報源から言えること
【出典】
- サビはヴァースより音域が高いのが普通。いちばん多いやり方は「サビで音を上げる」。上げない場合でも、目立つ上向きの跳躍があればエネルギーが上がって聞こえる（Secrets of Songwriting）。
- ヴァースの歌のリズムは短く細かく複雑になりやすく、**サビのリズムは単純で拍にそろう**（同上）。
- プレサビは上へ向かって登り、サビ頭の和音へしっかりつながる形で終わる。サビの入りは速い曲で 0:45〜1:00 ごろ（Secrets of Songwriting）。
- 単純で歌える短い動機から始め、繰り返しで覚えやすくし、少しずつ変えて単調を避ける（Riffhard Chorus 記事）。
- 短調の曲のサビで長三和音（平行長調側の和音）を使うと「持ち上がる・開ける」感じが出る（Riffhard Chorus 記事）。
- 旋律は3度・5度でハモらせる（Riffhard 各記事）。

### 1-2. 実装ルール【整理】
- **音域**: ヴァースの歌の中心音より、サビの中心音を **長3度〜完全5度（4〜7st）高く**。サビ全体の音域は **オクターブ＋長2度〜短3度（14〜15st）以内**、ヴァースは 7〜9st 以内に抑える（サビとの差を作るため）。
- **最高音の位置**: サビの最高音は **3小節目か7小節目（8小節サビの場合）** に置く。1小節目でいきなり最高音を出さず、1小節目は最高音より2〜4st下から入る。最終サビだけ、最高音を **1度（全音）上に1回だけ** 伸ばす（「最後に一段上がる」）。
- **長い音**: サビの各2小節の終わりに **2拍〜1小節の伸ばし** を置く（8小節中に最低3つ）。伸ばす音は和音の構成音のうち **3度か9度（add9 の音）** にすると現代的に「開けた」響きになる。根音での伸ばしは最後の終止だけ。
- **跳躍**: サビ1小節目か2小節目に、**完全4度〜短6度（5〜8st）の上行跳躍を1回** 入れ、跳躍のあとは順次進行で下る（跳躍→下降の補填）。オクターブ跳躍は1サビにつき最大1回。
- **リズム**: サビは8分音符と4分音符中心、16分は装飾として1小節に2個まで。ヴァースは16分・3連を多めにして差をつける。
- **入りの位置（弱起）**: サビ頭は2通りを使い分ける。
  - (A) **弱起**: 前の小節の4拍目裏（位置14）か4拍目（位置12）から 1〜3音のピックアップで入り、サビ1小節目の1拍目で伸ばす。勢いが出る。メタルコアのサビで多い。
  - (B) **頭抜き**: 1拍目は伴奏（全員のアタック＋クラッシュ）だけにして、歌は **1拍目の裏（位置2）か2拍目（位置4）から** 入る。伴奏の衝撃と歌がぶつからず、歌が浮いて聞こえる。
  - 1曲の中でサビの入り方を固定し、ブリッジ後の最終サビだけ、もう一方に変える（変化を付ける）。
- **フックの長さ**: 中核のフックは **2小節（長くて4小節）**。8小節サビは「フック(2) → 応答(2) → フック変形(2) → 終止(2)」。フック変形は「同じリズムで最後の2音だけ高くする」か「同じ音で最後の音を伸ばす」。
- **繰り返し**: 同じ2小節を4回そのまま繰り返さない。最低でも3回目は語尾（最後の1〜2音）を変える。
- **メジャーに開ける**: 短調の曲なら、サビの頭の和音を **VI（平行長調の IV）か III（平行長調の I）** にし、主和音 i はサビの終わり（7〜8小節目）まで取っておく。
- **ハモり**: 2回目以降のサビで、旋律の上に **3度上のハモり** を、長い音の部分だけ足す（全部にかけない）。最終サビは、旋律の **オクターブ下** を重ねて厚くする。
- **プレサビ**: 4小節。旋律は1小節ごとに中心音を 1〜2st ずつ上げる。最後の1拍は無音（歌も伴奏も止める）か、スネアの連打で埋めてサビへ。

## 2. 和音の進行と「現代的な色」

### 2-1. 情報源から言えること
【出典】
- 短調で多い和音は i（14%）、VI（9%）、VII（9%）、III（6%）、iv（5%）、v（3%）。拡張のない三和音が基本。**VI→VII→i** は平行長調の偽終止に似た流れ。iv は始まりよりもブリッジやプレサビで使われがち。借用の V（長三和音のドミナント）は短調で最も多い借用和音（Hooktheory のブログ）。
- クリーンで光るように鳴る和音: **add9（音の重なりで倍音が増えて豊かに）、maj7・maj9（物悲しく憧れのある色）、sus2・sus4（長短どちらとも決まらない、静的で開けた響き）、6度の付加（甘い）**。開放弦は伸びがよい（MusicRadar）。
- 開放弦を「ペダル」として鳴らしたまま、押さえる形を動かす。開放弦が、本来つながりにくい和音どうしを結びつける。同じ形を平行移動すると 11th・13th・maj7 などの拡張和音に自然になる（Premier Guitar: Open String Chords）。
- 調の中の「きれいな不協和音」: 短2度・長2度・増4度（三全音）を重ねる。暗い部分では **sus♭6（根音・5度・短6度）** 型。三和音に 2度・4度・6度を足す（Am(add9)、C(add#4) など）。低音を変えると同じ和音がぐっと暗くなる（Premier Guitar: Finding Dissonance in Tonality）。
- ジェント／プログレでは、パワーコードに高い5度をもう1つ重ねた4音の形、パワーコードに3度を足して和声を示す形、長三和音とマイナー(maj7)を交互にする、メロディックマイナーへの切り替え（Premier Guitar: Periphery 回）。
- 短調・自然的短音階・フリジア（♭2）の色・半音進行・sus 和音で緊張を作る（gravitee）。

### 2-2. 実装ルール【整理】
**基本の骨組み（短調）**
- ヴァース: i 中心。i ↔ ♭VI、または i → ♭II（フリジアの色）を1小節おき。**ベースは根音に沿う**（ユーザー方針）。
- プレサビ: **iv → ♭VI → ♭VII** と上向き、最後の ♭VII を伸ばして（またはサス4にして）サビへ。
- サビ: **♭VI → ♭III → ♭VII → i**、**♭VI → ♭VII → ♭III → ♭III/5（同じ和音で低音だけ5度へ）**、**♭III → ♭VII → ♭VI → iv** などから選ぶ。サビ頭は ♭VI か ♭III（長三和音で開ける）。

**定番から少し外すやり方（毎曲1〜2個だけ使う）**
1. **ペダル低音**: 和音を ♭VI → ♭VII → i と動かしながら、低音は主音（i の根音）のまま。→ ♭VI/1、♭VII/1 の浮いた響き。プレサビかブリッジで使う。
2. **低音だけ動かす**: 上の和音（ギターの高い開放弦を含む形）は固定し、ベースだけ 1 → ♭7 → ♭6 → 5 と下がる（線的な下降ベース）。サビ後半やアウトロで使う。
3. **サビ頭を ♭VI(add9) ではなく iv(add9) にする**（暗いまま開ける。定番より少し苦い）。
4. **借用 IV（ドリアの長三和音の IV）** をサビの3小節目に1回だけ入れる。急に光が差す。
5. **♭II（フリジア）** をヴァースやブレイクダウンの低音に。サビでは使わない。
6. **ピカルディ寄り**: 最後のサビの最後の和音だけ、i ではなく **I(add9) か ♭VI(maj7)** で終える（解決したようでしない）。
7. **v ではなく ♭VII sus4 → ♭VII**: 終止前の緊張をサスペンドで作る。
8. **転調**: 最終サビの前で全音上（+2st）に上げるのは「よく聞く」ので、使う場合は **短3度上（+3st）** や、ブリッジだけ **平行長調** に移る、などにする。1曲に1回まで。

**色づけ（ボイシング）の規則**
- 歪みギター: 3音以内（根音・5度・オクターブ）が基本。色づけするときは **sus2（根音・2度・5度）** か **根音・5度・9度（オクターブ上の2度）**。3度は歪むと濁るので、歪みでは原則入れない（入れるならオクターブ上に）。
- クリーン／アンビエントのギター・鍵盤: **add9、maj7、maj9、m9、m11、sus2、6/9** を使う。1つの和音に、隣り合う2度（クラスタ）を1か所だけ入れると「現代的なきらめき」になる。
- **共通音（ペダル）**: クリーンのアルペジオで、上の1音（例: 主音の9度＝2度の音）を全部の和音で鳴らし続ける。和音が変わると、その音が 9th → maj7 → 6th → 11th と役割を変えて色が移る。
- 割合の目安: 1曲の和音のうち、色付き和音（add9/sus/maj7 など）は **30〜50%**。全部を色付きにすると、かえって平板になる。

## 3. リフの作り方（「刻みばかりでない」リフを特に）

### 3-1. 情報源から言えること
【出典】
- シンコペーション（アクセントを裏拍へずらす）、パームミュートの部分と普通に弾く部分の交互、ハーモニクス・スライド・ピッキングハーモニクスで噛みつきを（Riffhard Metalcore Song／Riffs）。
- 刻みの上に旋律を乗せると、リズムと旋律の対比で深みが出る。2本のギターで役割を分ける（片方は刻み、片方は旋律・和声）（Riffhard Riffs）。
- 低い弦はパワーコード、高い弦では旋律フレーズ（Riffhard Post-Hardcore）。
- **クロスリズム**: 3つの16分（付点8分）の繰り返しは、3拍で拍にもどり、3小節で小節頭にもどる。5つの16分の塊は、最後の繰り返しを変えて2小節に収める。21個の16分の長い塊を5回繰り返し、6回目を変えて4小節に収める。ドラムのスネア（とチャイナ）は基本の拍を示し続け、ギターだけが拍とずれていく（Fundamental Changes）。
- 1小節16個の16分を 5-5-5-1、6-6-4、3-7-6、5-5-2-2-2 などに分ける。2小節で 7-7-7-7-4。**ドラムは4/4のまま**、ギターだけ周期がずれて、2小節後にぴたりと戻るのが「解決」（Premier Guitar: Polymeters）。
- 5つの塊を4回 → 4つの塊で締める、のように「しっぽ」で小節頭にもどす。5+5+6=16、7+4+5=16（Premier Guitar: Odd Groupings）。
- 3連のフレーズ、3/4と4/4の切り替え、16分1つ分の動機のずらし、数小節かけて解決するリズムの重ね。プリベンド、弦飛び、指でのタッピング、ハンマリング・オン・フロム・ノーウェア、短2度の音程を指板上で動かす（Premier Guitar: Periphery）。
- ゲートを強くかけ、和音の打撃の間を完全な無音にする（Premier Guitar: Periphery）。
- 予想外の場所に休符を置く。数小節ごとに1音・1アクセントだけ変える。小さな旋律の動機を何度も戻す（Riffhard Djent Riffs）。
- オクターブ: 低いオクターブ形（6弦と4弦、5弦と3弦）で、間の弦はミュート。スライドで入る、短く切る（スタッカート）でリズムを出す。サビを目立たせる、ブリッジでつなぐ、ハーモニクスのオクターブで静かな部分（Riffhard Octaves）。
- リズムの書き方は「ドラマーのように考える」（Riffhard Djent Riffs）。
- 不協和音程: 短2度、三全音、ピッキングハーモニクスはブレイクダウンにも（Breakdowns fandom）。
- メタル的な語彙: 刻み・トレモロ・オクターブ・不協和音程。ヴァースはまばらな打撃、サビは伸ばす和音か旋律（gravitee）。

### 3-2. 実装ルール【整理】
**リフの「素材の種類」を必ず混ぜる**。リフの1単位（2小節 or 4小節）の中に、次の6種類のうち **3種類以上** を入れる。
1. **開放弦のペダル（チャグ）**: 一番低い開放弦。16分か8分。ミュート強。
2. **伸ばす和音（サステイン）**: パワーコード or sus2 を 1拍以上ミュートなしで伸ばす。
3. **オクターブの旋律**: 中〜高音域で、オクターブ形の単音旋律。
4. **高音弦の旋律（ペダルトーン奏法）**: 低い開放弦と、高い弦の旋律を交互に（「低・高・低・高」）。
5. **スライド／グリス**: 和音・オクターブの入りに 2〜5st 下からスライド（16分1つ分の長さ）。
6. **休符（ゲートで完全無音）**: 8分〜4分の無音。

**「刻みばかりでない」リフの型（そのまま実装できる形）**
- **型A（チャグ→サステイン）**: 1小節目は位置0・2・3・6・8・11 にチャグ（開放弦）、位置12 から sus2 の和音を2小節目の頭まで伸ばす（タイ）。2小節目の後半で、オクターブ旋律が3音下りてくる。
- **型B（ペダルトーン旋律）**: 16分で「開放弦（ミュート）→ 高い弦の旋律音（ミュートなし）」を交互に。旋律音は音階の 1→♭3→4→5→♭6→5 と動く。低い開放弦の音量は旋律音より −4dB 程度（下支え）。
- **型C（付点8分の塊）**: 付点8分（16分3つ）単位で和音の打撃を置き、間を開放弦の16分でつなぐ。3小節で小節頭に戻るので、4小節目を「しっぽ」（4分音符2つの伸ばし）にして4小節で一周させる。
- **型D（2拍3連）**: 2拍の中に4分3連の和音を3つ（ミュートなしで伸ばす）。1小節目は普通の8分、2小節目の後半2拍だけ2拍3連にして、ノリを一瞬ゆるめる。
- **型E（5の塊）**: 16分5つ（「打撃・開放・開放・打撃・休」など）を3回 → 1つの16分で締めて16個（5-5-5-1）。2小節目は 6-6-4。ドラムは普通の4/4で、キックはギターの打撃に合わせる。
- **型F（オクターブ主体）**: 8分のオクターブ旋律を、各音の頭に短いスライド付きで。下で開放弦の低音を 4分音符で鳴らし続ける（ペダル）。サビ前・ブリッジ向き。
- **型G（不協和の和音を伸ばす）**: 根音＋5度＋短2度上（クラスタ）や、根音＋三全音を1小節伸ばし、トレモロピッキング（16分か32分）で揺らす。ポストハードコアの開放的な部分向き。

**シンコペーションの置き方**
- 1小節の中で、打撃の **3〜4割を裏拍（16分の奇数位置や8分の裏）** に置く。表拍だけにしない。
- 打撃は「キックと同時（一致）」を基本に、**1小節に1〜2個だけ** キックとずらしてギターだけの打撃にする（ずれが引っかかりになる）。
- 4小節単位で、**4小節目の最後の2拍は変える**（休符・フィル・スライド・ハーモニクス）。

**チャグとサステインの比率**
- ヴァース: チャグ 60〜70%、サステイン 30〜40%。
- プレサビ: チャグ 30%、サステインと旋律 70%。
- サビ: チャグ 0〜15%（ほぼ伸ばす和音）。
- ブレイクダウン: チャグ 70〜85%、ただし休符を必ず入れる。
- **曲の最初の4小節にチャグを入れない**（ユーザー方針）。

**ミュートの切り替え**（ユーザー方針への対応）
- 伸ばしている途中の和音を、いきなりミュートに切り替えない。ミュートに入るときは **前の音を自然に減衰させるか、8分以上の休符をはさむ**。
- 1つの音の中で「ミュートなし→ミュート」に変えるのは禁止。切り替えは音と音の境目だけ。

**飾り**
- ピッキングハーモニクス: 1リフ（4小節）に **最大1〜2回**。チャグの連続の最後の音か、伸ばす音の頭。多用しない。
- ゴーストノート（ギター）: チャグの間の 16分に、ごく小さい（ベロシティ 20〜35）ミュート音を入れて、つぶつぶ感を出す。1拍に1個まで。
- 自然ハーモニクス（12・7・5フレット）: 静かなイントロ、ブレイクダウン前の「ため」で、長く伸ばす。

## 4. ブレイクダウンのリズム

### 4-1. 情報源から言えること
【出典】
- 前のセクションより 10〜20BPM 遅くするか、ハーフタイムの感じで重さを出す。シンプルな形から始め、少しずつ層と複雑さを加え、頂点で解決。長さは 8〜16小節（Riffhard Breakdown）。
- キックをギターのチャグに合わせる。シンバルで大事な瞬間を強調、シンバルとタムで装飾とフィル（同上）。
- 戦略的な休止が衝撃を強める。急な停止で、無音にも音と同じ重さを持たせる（Riffhard Breakdown／Play Breakdowns）。
- 遅い・ストップ＆スタートの刻み。ピックスクレイプ・不協和の和音（Wikipedia: Metalcore）。
- ドラムは4分音符のライド（またはチャイナ）＋スネアは3拍目。キックはギターのチャグに沿う（ツーバス）。ギターは主に開放弦。とても遅いブレイクダウンではドラムを2分音符に。不協和（短2度・三全音・ピッキングハーモニクス）。声は繰り返しの一言（Breakdowns fandom）。
- ハーフタイム: 1小節を2小節分に引き伸ばした感じ。スネアは3拍目、ハイハットは4分（Wikipedia: Half-time）。
- メロディックなサビや激しいリフのあとに置くのが「ピボット」。前にリバーブやフィルターのかかったディレイで移行。最小から始めて不協和の頂点へ。最近は格子からずれた落とし方・非対称のパターン（Soundverse）。

### 4-2. 実装ルール【整理】
- **位置**: 2回目のサビのあと（ブリッジの前か後）に1つ、曲の最後に任意で1つ。1曲に最大2つ。2つ目は1つ目と型を変える。
- **テンポ**: BPM は変えずにハーフタイム（スネア3拍目）にするのを基本に。さらに重くしたい最後の4小節だけ、スネアを2小節に1回（＝4分の1タイム）にする。
- **キックとギターの一致**: ギターのチャグとキックを **100%同じ位置** にする（これがブレイクダウンの核）。シンバル（チャイナ or ライド）は 4分音符か2分音符で別に刻む。
- **間（無音）**: 2小節ごとに、**最低8分音符2つ分の完全な無音** を入れる。無音の間もシンバルの余韻は止めない（ユーザー方針: シンバルは伸ばす）。ギターはゲートで切るが、シンバルとルームの響きは残す。
- **リズムの型**（16分の位置で書く。● ＝チャグ＋キック）
  - 型1（3連の重さ）: 1拍を3等分した位置で ●●● ＿ ●●● ＿（3連の塊＋休み）。重く引きずる感じ。
  - 型2（付点）: 位置 0・3・6・10・12 に ●。付点8分の連続で前のめりにならない重さ。
  - 型3（間を大きく）: 位置 0 と 6 だけ ●、位置 12〜15 は無音 → 次の小節頭に和音の打撃（伸ばす）。
  - 型4（非対称）: 1小節を 3-3-3-3-4 の塊で区切り、各塊の頭に ●。4小節で1周。
- **最後のチャグの前の「ため」**:
  - ブレイクダウンの最終小節（4小節 or 8小節の終わり）で、**3拍目〜4拍目を無音** にし、4拍目の裏（位置14）か次の小節頭に、いちばん低い音の和音（＋チャイナ＋クラッシュ＋全員）を1発。
  - 「ため」の無音の間に、スネアの1発・声の一言・リバースシンバルなどを1つだけ入れてもよい（全部入れない）。
  - 最後の1発のあとは **2拍以上伸ばして響かせる**（すぐ止めない）。
- **進め方**: 1〜2小節目は打撃だけ（キック＋ギター＋4分のシンバル）→ 3〜4小節目でギターの2本目が不協和の高い音（短2度上・三全音）を足す → 5〜6小節目でスネアの裏打ちやタムを足す → 7〜8小節目で「ため」と最後の1発。
- **不協和**: ブレイクダウンの中の和音は、パワーコードに **短2度（♭2）** か **三全音（♭5）** を1つ足したものを1〜2個だけ使う。

## 5. リードギター／ギターの旋律

### 5-1. 情報源から言えること
【出典】
- 多くのメタルコアの曲はギターソロがない。メロディックメタルコアではハモりのリードやソロがある（Wikipedia: Metalcore、gravitee）。
- ハモりは音階の中の3度が基本、4度・5度も。旋律の上にも下にも作れる。半音進行とハモりの組み合わせで不穏な響き（Premier Guitar: Twin Guitar Harmonies）。
- 音量を上げてゆく奏法（ボリューム奏法）: ノブ／ペダルで音量 0 から上げる、逆に下げて終える、ハーモニクスとの組み合わせ。中くらいのディレイで余韻を引き、長いリバーブで大きな空間に。アンビエントなイントロ、感情的なブリッジ、ブレイクダウン前の高まり（Riffhard Volume Swell）。
- タッピング、ハイブリッドピッキング、弦飛び、プリベンド、プリベンドを全員でいっせいに戻す（Premier Guitar: Periphery、Soundverse）。
- 重い低いリフと、明るく鳴る旋律の対比。何本かのギターが、それぞれ違う形で和音の変化をなぞる（Premier Guitar: Periphery）。
- 開放弦を使ったクリーンパート、空間系（ディレイ・リバーブ）は控えめに、明瞭さを保つ（Riffhard Djent Riffs、Guitar Masterclass: TesseracT）。

### 5-2. 実装ルール【整理】曲の中での配置
| 技法 | 置く場所 | 量・長さ |
|---|---|---|
| アンビエントなクリーンのアルペジオ（add9/maj7、開放弦、ディレイ付点8分＋長いリバーブ） | イントロ、1回目のヴァースの後ろで小さく、ブリッジの静かな部分 | 4〜8小節。音は伸ばして重ねる（すぐ止めない） |
| ボリューム奏法（音量 0→最大まで 1〜2拍かけて上げる） | ブレイクダウン前の「ため」、ブリッジの頭、アウトロ | 和音1つ or 単音を2〜4小節 |
| オクターブ奏法の旋律 | サビの後ろ（歌の合間の応答）、プレサビ | サビ旋律と同じ動機を、オクターブで応答させる |
| ハモりのリード（3度中心、ところどころ4度・5度） | サビ後のインスト、2回目のサビ前の4小節、ソロの最後 | 4〜8小節。最初の2小節は単音、後半からハモり |
| トレモロピッキング（16分〜32分で1音を連打する旋律） | ポストハードコアの開放的な部分、サビの裏で高い持続音として | 1音を1〜2小節。旋律はゆっくり動かす |
| タッピング（3〜4音のアルペジオを16分 or 6連で繰り返す） | ソロの頂点、ブリッジの盛り上がり、イントロの高音の飾り | 1〜2小節で区切る。和音が変わるたびに形を変える |
| スウィープ | 使うなら、ソロの最後の頂点に1回だけ | 1小節以内 |
| チョーキング（ベンド） | ソロ・リードのフレーズの頂点・語尾 | 1フレーズに1〜2回。全音か半音、ゆっくり上げきって止める |

- **ビブラートは浅く・遅く・少なめ**（ユーザー方針: ゴムが伸びる音は嫌）。深さ ±15セント以下、速さ 4〜5Hz、伸ばす音の後半だけ。チョーキングは使ってよい。
- ギターソロは **1曲に最大1回、8〜16小節**。前半は歌のように少ない音（4分・8分中心）、後半で速い音（16分・6連・タッピング）へ上げ、最後はチョーキングか伸ばしで終える。
- リードの音色は crunch アンプ系（ピロピロ）は使わない（ユーザー方針）。

## 6. ドラムの語彙

### 6-1. 情報源から言えること
【出典】
- 重い部分はツーバス、メロディアスな部分は控えめなパターン。区切り目でフィルとクラッシュ（Riffhard Metalcore Song）。
- 速いツーバス、きっちりそろったシンバルのアクセント、パンク由来の速いビート。ハーフタイムのグルーヴとタムのフィルでセクションをつなぐ。キックとミュートしたギターが同時に当たる（gravitee）。
- ブラストビートはメタルコア全体というより、デスコア寄り（Wikipedia: Metalcore）。
- ツーバスの型: 16分の連続、3連、ギャロップ（Drumeo, Ash Pearson）。
- チャイナ、スプラッシュはアクセント用。シンバルチョーク（たたいてすぐ手でつかむ）。メインのグルーヴは 8分・16分の 2〜3音の短い型（Wikipedia: Heavy metal drumming）。
- ジェントでは、スネア（とたいていチャイナ）が基本の拍を示し、ギターのクロスリズムはその上で動く（Fundamental Changes）。
- ゴーストノート: 主な音の間の16分に、とても小さくスネアを入れる。強いバックビートの周りに細かいノリを作る（Wikipedia: Ghost note）。
- ハーフタイム: スネア3拍目、ハイハット4分。ダブルタイム: スネアは8分の裏、ハイハット16分（Wikipedia: Half-time）。

### 6-2. 実装ルール【整理】
**セクション別のビートの型**（同じ型を8小節以上続けない。4小節ごとに何かを変える）
- **イントロ**: タム（フロア＋ラック）中心のグルーヴ。キックは1拍目と3拍目の裏、フロアタムで8分、ラックタムで裏のアクセント。シンバルはライド（伸ばす）。
- **ヴァース（重い）**: キックはギターの打撃と一致、スネアは2・4拍。ハットは閉じた8分 → 4小節目でチャイナの4分に変える。スネアの間にゴーストノート（ベロシティ 25〜40）を 1拍に1個まで。
- **ヴァース（静かめ）**: ライドの 8分（ライドベルを 1拍目と3拍目にだけ）、キックはまばら、スネアはクロススティック（リムショット）も可。
- **プレサビ**: ハーフタイム → 最後の2小節でスネアを8分→16分に詰める（ロール）。最後の1拍は無音（シンバルの余韻だけ）。
- **サビ**: 基本のビート（スネア2・4）でクラッシュかライドを 8分で開放的に。1小節目の頭はクラッシュ＋チャイナ。**ツーバスはサビの後半4小節だけ** 16分で（ずっと踏まない）。もう1つの選択肢として、**ダブルタイム（スネアを8分の裏）** をサビの後半に。
- **ブレイクダウン**: ハーフタイム。チャイナかライドベルを4分、スネア3拍目、キックはギターと一致。
- **ブリッジ**: 1小節ずつタムのグルーヴ → ハーフタイム → 盛り上げのツーバス、のように動きを付ける。
- **ブラスト**: 使うなら1曲に1回、2〜4小節だけ（ハンマー型: キック・スネア・シンバル同時 16分 or 8分）。爆発の瞬間として。
- **D ビート／スカンク**: 速い部分（ヴァースの後半など）に 2〜4小節。

**シンバルの語彙**
- **チャイナ**: アクセント（各フレーズの1拍目、ブレイクダウンの4分）。鳴らしたら **伸ばす**（チョークしない）。チョークは曲全体で最大1〜2回、「ため」の直前だけ。
- **ライド**: 静かな部分・ヴァースの変化・ブリッジで。ベルはアクセントとして。余韻は長く。
- **クラッシュ**: セクションの頭とアクセント。左右に2枚を置き分ける。
- **スタック**: 速い8分・16分のアクセントで、ハットの代わりに短く乾いた音として（ブリッジの変化用）。
- **スプラッシュ**: フィルの終わりやギターのアクセントに合わせて少しだけ。

**フィル**
- 4小節ごとに小さいフィル（最後の1拍、タム2〜3発）、8小節ごとに大きいフィル（最後の2拍、タムを高→低へ、フロアで終わる）。
- フィルの終わりは次の小節頭のクラッシュ＋キック。
- **3連のフィル**（6連のタム回し）と **16分のフィル** を交互に使い、毎回同じにしない。
- フィルを「入れない」（ドラムが止まる）こともフィルの一種。1曲に2〜3回、セクション前に「全員止まる1拍」を作る。

**ゴーストノート・強弱**
- スネアのアクセント（2・4拍）は ベロシティ 110〜127、ゴーストは 25〜40、ハットの表 85〜100・裏 60〜75。キックはツーバス時 90〜110 で揺らす（±8）。
- 同じベロシティを連続させない（人間らしさ）。

## 7. 「よく聞く感じ」を避けつつ、曲として成り立たせるバランス

### 7-1. 情報源から言えること
【出典】
- リズムの「ずれ（拍子の不協和）」が出る場所は、イントロ・ヴァース・ブリッジ・セクションの終わり。**ヴァースはゆるく（不規則に）、サビはきっちり（4/4）**＝「LVTC（ゆるいヴァース／きっちりしたサビ）」の形。セクションの終わりのヘミオラ（2〜4小節だけ3拍子の感じ）や、半端な小節（2/4 の1小節）で次へつなぐ。イントロで「本当の小節頭」を後から明かす（フェイク）（Biamonte, Music Theory Online）。
- 早めに覚えやすい動機を出し、テンポ・和声・声の変化で変形していく（gravitee）。
- 小さな旋律の動機（ライトモチーフ）を何度も戻して軸にする（Riffhard Djent Riffs）。
- 定番進行から外す・意外な和音や転調を入れる（Riffhard Chorus）。
- 複雑さより、ノリと正確さが大事（Soundverse）。

### 7-2. 実装ルール【整理】「守る場所」と「外す場所」
**定番を守る場所（聞き手の足場）**
- サビの拍子は 4/4 で、ドラムはスネア2・4（またはハーフタイム）。サビの和音進行の **最初の2つ** は分かりやすい（♭VI、♭III、♭VII などの長三和音）。
- サビの中核フック（2小節）は曲中で同じリズムのまま3回以上出す。
- セクションの長さは基本 4・8小節。
- 最終サビは1回目のサビより厚く（ハモり・オクターブ・ツーバス）。

**意外性を出す場所（1曲に3〜5か所。全部の場所で外さない）**
1. **イントロの頭**: 小節頭がどこか分からない入り方（ギターだけで付点8分のフレーズ → ドラムが入って本当の1拍目が分かる）。
2. **ヴァース**: 5の塊・7の塊・3の塊（3-3-3-3-4）でギターだけ周期をずらす。ドラムは 4/4 のまま。2小節か4小節で必ず戻す。
3. **プレサビ最後の小節**: 2/4 の半端な小節を1つ入れて、サビを半小節早く始める。または1拍だけ全員無音。
4. **サビの3小節目**: 借用和音（長三和音の IV、iv(add9)、♭II など）を1つ。
5. **ブリッジ**: 拍子を 7/8 や 6/8 にする、平行長調に移る、楽器を減らしてクリーンとボリューム奏法だけにする、のどれか1つ。
6. **最後のブレイクダウンの最後**: 予想より1拍遅い（または早い）最後の1発。
7. **終わり方**: サビの最後の和音を i で解決させず、♭VI(maj7) や I(add9) で終わる、またはアンビエントなギターだけ残して余韻で終わる。

**よく聞く感じになりやすいもの（避ける・量を制限する）**
- i → ♭VI → ♭III → ♭VII（または同じ順番の回転）を **サビでそのまま4回繰り返す** こと。使うなら、3回目で和音を1つ変えるか、低音をペダルにする。
- サビの旋律が、和音の根音に毎回着地すること（3度・9度・5度に着地させる）。
- 歌が小節頭の1拍目で毎回始まること（1-2 の A/B を使い分ける）。
- 曲全体で 16分のチャグを鳴らし続けること。
- ブレイクダウンを「同じ型を8小節そのまま」にすること。
- 最終サビの前の全音転調（使うなら別の幅で）。
- 2拍ごとに同じタムフィル。

**チェックリスト（曲が書けたあとに機械で確かめる）**
- [ ] 曲の最初の4小節にチャグ（16分の開放弦ミュート）がない
- [ ] サビの中心音がヴァースより4〜7st 高い
- [ ] サビの長い音（2拍以上）が8小節中3つ以上
- [ ] サビの上行跳躍（5〜8st）が1回以上
- [ ] 色付き和音が全体の30〜50%
- [ ] 「外す場所」が3〜5か所（6か所以上は散らかる）
- [ ] 同じドラムの型が8小節以上続いていない
- [ ] ライド・タム・フロアタムがそれぞれ1回以上使われている
- [ ] シンバルの余韻を途中で切っていない（チョークは最大2回）
- [ ] ブレイクダウンのキックとギターのチャグの位置が一致している
- [ ] リフの単位に、6種類の素材のうち3種類以上が入っている
- [ ] 伸ばしている音を途中でミュートに切り替えていない

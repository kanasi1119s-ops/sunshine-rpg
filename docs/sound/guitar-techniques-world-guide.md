# ギター奏法の世界地図（ロック以外）：ジャンル別の奏法・音色・作曲ソフトでの書き方（2026-10-11 調査）

目的: 「ギターのいろんな演奏方法を、各ジャンルに合ったものとして学び、作曲ソフトの docs に記載する」。この文書は **ロック以外**（ジャズ、ブルース、カントリー、フォーク、クラシック・フラメンコ、ボサノバ、レゲエ、ファンク、ディスコ、ハワイアン、アンビエント、ゲーム・映画、和風、ケルト・中東）を扱う。ロック側は `guitar-rock-band-guide.md`、音づくりの基本は `guitar-tone-basics.md`、J-POPのクリーンは `jpop-clean-guitar-guide.md`、音階は `scales-world-guide.md` を見る。

**この文書は調査と提案だけで、コードは変えていない。** 例のノート列と `strum` の JSON は、書き終えたあとに `song.mjs build` で読み込みを確かめ、パートごとの拍の合計も数えた（エラーなし。音域・ぶつかりの注意が出た例は直した）。**音（聴いた感じ）は確かめていない**。耳での確認は、書き出し（`--wav`）とギター単体の測定（4章）で行うこと。

## 0. 読む前に（確度ラベルと、調べの限界）

- **【確認】** 出典の中身を読んで確かめた事実（出典番号 S○ を付ける）。
- **【一般】** 音楽教育・録音の一般論で、複数の出典か常識として使えるもの。この文書では出典を1つ付けられないもの。
- **【推測】** 筆者（Claude）の整理・経験則・作曲ソフトの音源についての見立て。**出典なし。耳で確かめてから使う。**

正直に書いておく限界:

1. 記事の中身は WebFetch（要約つき取得）で読んだ。要約は小さなモデルが作るため、**細かい数字や言い回しは原文と食い違うことがある**。【確認】と付けた所も、使う前に出典を開いて確かめるのがよい。
2. 取得できなかった・薄かった出典がある（例: S3 は Wikipedia の保管ページの要約で機材の記述が無かった）。そういう項目は【一般】か【推測】にした。

5. 例のノート列はすべて**この文書のための新作**で、既存曲の旋律は写していない（CLAUDE.md 1-1）。

## 1. 作曲ソフトで「表せる／近似できる／表せない」奏法の早見

作曲ソフトの前提（`song.mjs guide` より）: **1パートは同時に1音**。和音は複数パートに分ける（または `strum` が自動で6本以内に展開する）。音のあとに付ける記号は `!`（強く）`,`（弱く）`'`（スタッカート）`_`（レガート）`~`（ビブラート。`~~` 深く）`^`（ベンドアップ。1つ＝半音、`^^`＝全音、`^.`＝1/4音）`/`（下から入る）`\`（落とす）。パート項目は `sustain` `amp` `patch` `attack` `release` `echo` `doubleDetune` `drone` `strum` `pushMs` `autoArticulation` `pedal`（ピアノ・エレピ）。

| 奏法 | 判定 | 書き方（要点） | 確度 |
|---|---|---|---|
| 和音のかき鳴らし（ストローク）、アップ・ダウン | **表せる** | `strum`（pattern の D d U u x . -）。弦のずれは `spreadMs` | 【確認】`song.mjs guide` |
| アルペジオ（分散和音）、トラヴィス風の親指と指の分担 | **表せる** | 低音パート（親指）と高音パート（指）に分け、`sustain` 2〜3 で重ねる | 【一般】 |
| ベンド（半音・全音・1/4音）、ビブラート | **表せる** | `^` `^^` `^.` `~` | 【確認】guide |
| スライド（短いグリッサンド） | **近似** | `/`（下から入る）`\`（落とす）。または手前の短い音を `_` でつなぐ。**連続的なバーのすべりは出ない** | 【確認】guide、craft-guides §13 |
| ハンマリング・プルオフ・トリル | **近似** | 0.125〜0.25拍の音を `_` でつなぐ | 【確認】craft-guides §13 |
| パームミュート、ミュートした刻み | **近似** | `'`（短く）、拍頭だけ `!` | 【確認】guide |
| ゴーストノート（音程のない「カッ」） | **近似（弱い）** | `,'`（弱く短い）。**音程のない雑音ではなく、低い音の短い音になる**。ギターのドラム的な音は未対応 | 【推測】 |
| ハーモニクス（ベルのような倍音） | **近似** | 高い音（E5付近）の短い音に `!`。または `bell`/`fmBell` を小さく重ねる | 【確認】craft-guides §13 |
| ボリューム奏法（スウェル） | **近似** | `attack`（0〜1。CC73）を大きく＋`sustain` 2〜3。**音源しだいで効きが弱い**。効かなければ `pad` を重ねる | 【確認】guide / 【推測】効き方 |
| E-Bow（弦を鳴らし続ける） | **近似** | `sustain` 3＋`attack` 0.6〜0.9＋`~` | 【推測】 |
| ディレイ奏法（付点8分のエコー） | **表せる** | `echo`（`time:"dotted8"`, `repeats`, `decay`） | 【確認】guide |
| ドローン（開放弦の持続音） | **表せる** | `drone:"root"` / `"root5"` | 【確認】guide |
| 12弦・ダブリング | **近似** | `doubleDetune:true`、または1オクターブ上の同じパートを小さく重ねる | 【確認】guide / 【推測】 |
| 微分音（アラブのクォーターフラットなど） | **近似** | 1/4音ベンド `^.` `\.`。または近い半音に寄せる | 【確認】guide |
| 親指奏法（ウェス風の丸い音） | **近似** | `amp:"jazz"`、`bright` を -0.3 前後、`patch:"jazzGuitar"`。**奏法そのものは出ない、音色の方向だけ** | 【推測】 |
| オクターブ奏法（ウェス風） | **表せる** | 同じ旋律を1オクターブ離した2パートに書く。間の弦のミュートは出ない | 【一般】 |
| アポヤンド（太い音）とティランド | **近似** | アポヤンド＝`!` と `sustain` 少し長め＋低めの `bright`。ティランド＝ふつう | 【推測】 |
| トレモロ（p-a-m-i） | **近似** | 低音1つ＋同じ高い音3つ（各0.25拍）を1パートで連ねる（5章の例） | 【確認】S17, S21（形）/【推測】音 |
| ラスゲアード（4本指のフリック） | **近似** | `strum` の `DDDD` を `step:0.125〜0.25` で。**実装されている型ではないので、書き出して耳で確かめる** | 【推測】 |
| ゴルペ（表板を叩く） | **近似** | `tom` の小さな音を拍の裏に置く | 【推測】 |
| アルザプーア（親指の往復） | **近似** | 親指の下・上は 0.125〜0.25拍の連続音。同じ低音の連打になるので `human` を足す | 【推測】 |
| ペダルスティール風ベンド（片方の音を保ち、もう片方を曲げる） | **表せる** | 2パートに分け、動く音だけに `^^` | 【確認】S11 |
| スライドバー特有の音色（金属の摩擦、ボトルネックの響き） | **表せない** | 近い音色は `patch:"cleanGuitar"`＋`amp:"blues"` まで。`steelGuitar` は**ピアノの音になるので使えない** | 【確認】guide |
| オープンチューニングの響き（開放弦が共鳴する厚み） | **表せない** | 近似: 開放弦に当たる音を `sustain` 2〜3 で長く重ねる | 【推測】 |
| カポの音色の違い（高いポジションの開放弦の響き） | **表せない** | 調を上げて書くだけ。`strum` のフォームは開放弦の形になる | 【確認】guide（strum のフォーム）/【推測】 |
| ワウ・フェイザー・エンベロープフィルター（ファンクの定番ペダル） | **表せない** | 近似: `funk` アンプ、`chorus` | 【推測】 |
| 弦の選択・ポジションによる音色の違い | **表せない** | 同じ音高でも弦で音が違うが、作曲ソフトでは区別されない | 【一般】 |
| ピック位置・指の腹と爪の違い | **表せない** | `bright`・`amp` で方向だけ | 【一般】 |

## 2. ジャンル別の表（奏法・使う場面・音色・ソフトでの書き方）

表の読み方: 4列 =（1）奏法、（2）使う場面、（3）音色（クリーン／クランチ、エフェクト、作曲ソフトの amp・patch）、（4）ソフトでの書き方。サンプルは「例」で示し、ノート列は3章にまとめた。

### 2-1 ジャズ

| 奏法 | 使う場面 | 音色 | ソフトでの書き方 |
|---|---|---|---|
| **フレディ・グリーン式コンピング**（1小節に4回、全拍を刻む。1・3拍は長め、2・4拍は短くやや強く。3〜4音の少ない音。7thを超える音は足さない）【確認】S1 | スウィングのリズム隊の一部（ベース・ドラムと一緒に脈を作る）。バラードには向かない【一般】 | 細くて澄んだクリーン。フルアコ。バンドより「ほんの少し小さく」【確認】S1。amp `jazz`、`patch:"jazzGuitar"` | **3度と7度（ガイドトーン）だけ**を2〜3パートに分け、4分音符を `X:1 X:1'!` のくり返し（例J1）。音量は 0.08〜0.12。コードが変わるたびに半音で動くようにつなぐ【一般】 |
| **シェル／ルートレス・ボイシング**（根音・3度・7度、または根音を省いた3度・7度＋色の音）【確認】S7（議論はあるが定義の一つ）| ベースがいるとき（根音はベースに任せる）【確認】S5 | 同上 | 3度・7度の2〜3パート。ルートは `bass` に任せる |
| **ウォーキング・ライン**（1拍1音。1・3拍に和音の構成音、2・4拍に経過音、最後の拍は次の根音への半音や5度の接近音）【確認】S5 | ベースがいないトリオ、ソロギター、バラードの伴奏 | 丸い音。ネックのピックアップ側、トーンを少し絞る、フラットワウンド弦【確認】S6。amp `jazz`、`bright` -0.2 | 単音を4分音符で並べる（例J2）。ダウンで弾いて2・4拍を少し強く、という弾き方の指示は `!` を2・4拍に【確認】S5 |
| **コード・メロディ**（旋律を一番上に置いて和音を下に付ける。持続する和音の上に動く旋律／ジョー・パス式に和音を「区切り」として使い、歩くベースの印象を作る／ブロックコード）【確認】S4 | ソロギター、バラード、メロディをそのまま聴かせるとき | 同上。残響は控えめ【確認】S6 | メロディ1パート＋内声1〜2パート＋低音1パート。内声は拍頭だけ鳴らして `R` で休む（例J4） |
| **オクターブ奏法（ウェス・モンゴメリー風）**: 親指で弾き、間の弦をミュートして同じ旋律を1オクターブ離して重ねる。ソロの中で「単音→オクターブ→ブロックコード」と盛り上げる【確認】S2, S3 | ジャズのメロディ、ソロの山場 | 暖かく丸い音。ネック側、トーン絞り【一般】。amp `jazz`、`bright` -0.3 | 同じ旋律を1オクターブ離した2パート（例J3）。ソロの後半でブロックコードに移るなら、旋律を3〜4パートの同時打ちにする |
| **ブロックコード**（ピアノ的な連続和音）【確認】S4 | 山場、ビッグバンドのような厚み | 同上 | 4パート同時打ち。強弱は `!` と `,` |
| **フラットワウンド的な「短い減衰の音」** | ジャズ全般 | amp `jazz`、`reverb` 0.2〜0.3 | `sustain` 0.8〜1.0 |
| **アルペジオ**（ジャズバラード） | バラードのイントロ、間奏 | クリーン、ほんのりコーラス | 例は 3-4 章のアルペジオと同じ（`jazzGuitar`） |

**ジャズで避けること**【推測】: 歪み・派手なエフェクト。ジャズの標準は「効果をほとんど使わない」【確認】S6。

| 奏法 | 使う場面 | 音色 | ソフトでの書き方 |

| **リズム型（ワハダ・ウ・ノス、ファッラーヒ）**【確認】S37 | 打楽器の型 | — | `tom` と `hihat` を小さな音で不規則に（guide） |
| **増2度（ヒジャーズのD♭-E）を旋律の飾りに** | 異国情緒 | — | 小節頭の外れ・増2度の多用は `scale-check` が注意を出す（guide） |

## 4. 禁止の音との照合（`banned-sounds.md` を先に読む）

| 避ける作り方 | この文書で影響する奏法 | 対処 |
|---|---|---|
| **1. 短い単音の刻み（「ピ、ピ」と切れる・伸びない・高い）**（`guitar`＋gretsch＋`funk`/`clean`、D3〜A4）| ファンクの16分カッティング、レゲエのスカンク、ディスコのチョップ、チキン・ピッキング、トレモロ | ①**単音ではなく3声の和音にする**（FK1, R1）。②音域は低め（E3〜D4）、高域は volume を下げる。③`sustain` は 0.4 以下にしない。④**書き出しの前に `third-octave.py` でギター単体を測る**（`banned-sounds.md` 共通の注意）。⑤合否が出なければ、その奏法は和音（`strum`）か別の楽器で代える【推測】 |
| **3. ナイロン弦＋amp auto**（6〜10kHz が +8〜+15dB）| クラシック、ボサ、フラメンコ、ハープ風、和風、ケルト | **ナイロンは必ず `amp:"crystal"` か `"delicate"`**。この文書の例はすべてそうした |
| **共通: 高域（6kHz以上）をギターで出さない** | ハーモニクス、トレモロの高音、カポの高音 | ハーモニクスは `bell` を小さく、またはE5以下で |
| **共通: 短い音（`'`、0.25拍以下）を同じ高さで連打しない** | トレモロ、ピカード、ゴースト | 音程を動かす。トレモロは同じ高さが必須なので `human` と低 volume で、耳で判断 |
| 歪みギター（`hardrock`/`punk`/`crunch` の同音連打） | ロック側の話 | この文書のジャンルでは歪みを使わない（ブルースのクランチは `blues` アンプ） |

## 5. ソフトに取り入れる提案（実装しやすさ付き）

実装しやすさ: ★★★＝既存の仕組みの組み合わせか小さな拡張／★★＝新しい処理が要る／★＝音源やエンジンの追加が要る。

| # | 提案 | 内容 | 実装しやすさ | 理由 |
|---|---|---|---|---|
| 1 | **ジャンル別のガイド（この文書）を `song.mjs guide` から参照** | guide の「勉強した内容のガイド」の列に本書を足す | ★★★ | 文字の追加だけ |
| 2 | **`strum.pattern` に型の名前（`skank` `rasgueado` `bossa` `folk6` など）** | 名前で `-U-U-U-U` などに展開 | ★★★ | 既存の `strum` に辞書を足すだけ。`step` と `spreadMs` も一緒に既定値を持たせる |
| 3 | **`fingerpick`（p-i-m-a／トラヴィスの型を和音名から自動で展開）** | `{"chords":"C Am","pattern":"travis"}` で低音と高音の2パートに展開 | ★★ | `strum` のフォーム表を再利用できる。パート数は strum と同じ扱い |
| 4 | **`tremolo:true`（長い音を 0.25拍の低音＋高音×3 に展開）** | 長い音の1音を、低音＋同音3つ（p-a-m-i）に | ★★★ | notes の書き換えだけ（`pattern` と同じ展開層） |
| 5 | **`swell:true`（長い音の頭を自動で立ち上げる）** | 既存の `attack` を音ごとに（1拍以上の音だけ）、リリースも | ★★★ | `attack` の送り先が既にある。効きが弱い音源では `pad` を自動で薄く足す手もある |
| 6 | **`ghost`（音程のない短い雑音）** | `x` 記号をギターのノートに許し、低域を切った短いノイズ（またはミュートしたピアノ音）で鳴らす | ★★ | ドラム側の `x` の処理は既存。ギターでは音源側に雑音を足す必要がある |
| 7 | **`capo:N`** | 曲の `tonic` と `strum` のフォームを N 半音ずらし、「開放弦のフォームのまま高い調」を表現 | ★★★ | `strum` が開放弦フォームを持つので、実音の高さを足すだけ |
| 8 | **`harmonic` 記号（`*`）** | 音の2倍の高さの正弦波＋短いベルを重ねる | ★★ | 音源側の処理が要る |
| 9 | **すべり（グリス）の長さ指定** | `//` で「前の音から次の音まで連続的にすべる」（ピッチベンドの連続）| ★★ | ベンドの仕組みに「次の音まで」を足す |
| 10 | **ベンドの形の指定**（ブルースのカール、ゆっくり曲げる、遅れて戻す）| `^~` の長さと形の記号 | ★★ | ピッチカーブの定義が要る |
| 11 | **`batida:"bossa"`（親指と和音の2層を自動で）** | `feel:"bossa"` のベースに合わせた親指の低音と、拍1・拍2の16分の和音 | ★★★ | 例BS1の型を辞書化するだけ |
| 12 | **`golpe` 楽器（木の乾いた打音）** | 小さな木質の打撃音を合成 | ★★★ | `tom`/`kick` の合成の変形 |
| 13 | **ワウ／フェイザー系の `amp`（`funkWah`）** | 固定のワウ位置、または LFO の掃引 | ★ | フィルタの追加と評価が要る |
| 14 | **ペダルスティール・ドブロ・ウクレレ・ウードの音源** | GM の steel(25)・mutedGuitar(28) は既存の録音音源に入っていない（guide の注意）| ★ | 新しい録音音源（CC0など）の調査と導入が要る |

優先の順（効果 ÷ 手間）: 2 → 4 → 5 → 7 → 11 → 12 → 3 → 6。

## 6. 作る前のチェックリスト（ジャンル別に何を決めるか）

1. その場面のジャンルを決める。ジャンルと音色を先に決め、**同じ音色を続けて使わない**（`banned-sounds.md`）。
2. **ジャンルの奏法を表から2つ選ぶ**（例: ボサ＝バチーダ＋アルペジオ。ファンク＝16分カッティング＋単音のブレイク）。多すぎると散らかる。
3. 和音パートは1パート1音。3声に分け、`pan` を左右に振る。
4. 短い音の連打になっていないか確かめる（4章）。
5. ナイロンは `crystal`/`delicate`。ジャズは `jazz`。ブルースは `blues`。ファンクは `funk`（ただし高音域の単音連打は避ける）。
6. 書き出したら、合否表（PLR など）と `third-octave.py`（ギター単体）で確かめ、**聴いてから採用する**。

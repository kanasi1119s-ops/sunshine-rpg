# コード進行 100通り（2026-10-14、旭さんの依頼）

すべて **主音 C** で書いてある。使うときは半音ずらして好きな調にする（C→D は +2）。1コード＝1小節が基本で、`barsPerChord` を 2 にすると遅くなる。機械で読む版は `docs/sound/data/chord-patterns-100.json`。

**使い方**: 曲の JSON の `chords` にそのまま貼る。例 `"chords": "Cm Ab Eb Bb", "barsPerChord": 1`。同じ型を連続で使わず、Aメロ・サビ・ブリッジで別の番号を選ぶ（例: Aメロ=下降ベース F系、サビ=王道 A系、ブリッジ=借用 G系）。「型」の記号（B・K など）は chord-variety-guide.md の表と対応。

**耳では確かめていない。** コードの名前は作曲ソフトが読めることを自動テストで確認しただけ。響きの好みは聴いて決める。

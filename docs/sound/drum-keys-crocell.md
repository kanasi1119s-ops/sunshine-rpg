# CrocellKit（`--drums crocell`）の鍵盤と書き方

2026-10-22 追加。DrumGizmo の CrocellKit（デンマークのメタルバンドのアルバム録音の現場で取ったキット。CC BY 4.0・**クレジット必要**）を、作曲ソフトのドラム音源にしたもの。
作曲ソフト専用（ゲーム本体 `dist/` には入れていない）。ゲームに入れるときは `docs/assets-credits.md` のクレジットを書く。

- 選び方: `node tools/composer/song.mjs build <曲.json> --wav --drums crocell`（補助打楽器＝タンバリン・カウベルなどの録音つきは `--drums crocell-aux`）。作曲ソフトの画面では「ドラム音源」の「生ドラム CrocellKit」。
- 音源: `assets-src/soundfont/extra/drums-crocell.sf3`（約6.6MB）・`drums-crocell-aux.sf3`（約8.1MB）。GM のドラムセット 0・8・16・32 の鳴らすキーだけを入れかえ。
- 作り方: `tools/soundfont/dg-extract.py`（zip を Range で読み、必要な打音の頭だけ取り出す前処理）→ `CROCELL_SAMPLES=<取り出した録音> node tools/soundfont/build-drums.mjs --kit crocell`。
  取り出した録音（約100MB）は git に入れない。強さの層の選び方（Data/）は `assets-src/soundfont/extra/src/crocell/Data/`。
- まぜ方: 近接マイク＋OH 左右＋OH 真ん中（半分）＋部屋（0.4）。キックは中のマイク（アタック）0.75 と外のマイク（胴の重み）1.0 を混ぜ、55Hz を +3dB・400Hz を −3dB・4kHz を +2.5dB。
  シンバルは録音の余韻のまま 4.5〜5.5 秒（ライドは 3.5 秒）を残し、鍵盤を離したあとも 2〜4 秒かけて消える（すぐ止めない）。

## パートでの書き方の例

`loud25_arrange.py` の CYM（c=C2, g=G2, r=D2, u=F2, n=B2, s=A2）に、次の文字を足すと新しいシンバルが使える（例）:
`"N": "B3"`（チャイナ2）、`"S": "A3"`（スプラッシュ2）、`"C": "C3"`（クラッシュ3）、`"k": "C#2"`（クラッシュ1の止め打ち）、`"K": "G#2"`（クラッシュ2の止め打ち）。

- シンバルは「次に同じシンバルをたたくまで（最長8拍）」鳴る。チャイナ1とチャイナ2、クラッシュ1・2・3はそれぞれ別のシンバルとして数えるので、交互にたたくと両方の余韻が重なる。
- 止め打ちは、ブレイクの「ジャッ」と止める所（キメの最後）に。止め打ちのあとは、同じクラッシュの余韻も止まる。

## 確かめたこと（2026-10-22。数値だけ。耳での確認はまだ）
- 試験曲（120bpm）で、新しい鍵盤 90・91・92・93・94 がすべて鳴る（最初の 0.3 秒の大きさ −13〜−21dBFS）。止め打ちは 1 秒後に −40dB 以下まで止まる。ピークは −1.8dBFS（クリップなし）。

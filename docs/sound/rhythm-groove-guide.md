# リズムとグルーヴの手引き（2026-10-11 調査）

拍子・変拍子・シンコペーション・ポリリズム・クラーベ・スウィング・グルーヴの数字・ヒューマナイズ・テンポの揺らぎを調べ、うちの機能（`swing`・`human`・`push`・`beats`・`g:` グリッド・`timeSig`）に対応づけた。

**決まり**
- ここの型は、ジャンルや民族音楽で広く共有されている基本形を16分の位置に置き直したもの。特定の曲のリズムを再現する手順は書かない（CLAUDE.md 1-1）。記事の文章は写さず、自分の言葉でまとめた。
- この環境では音を聴けない。型と数字は「出発点」。聴いて動かす。
- 数字には根拠の強さを付けた。**A**＝研究・実測、**B**＝制作者の記事や目安、**C**＝この文書の推定・実装の計算。出典は末尾の S番号。

**先行文書との分担**: ドラムのジャンル別の型・drumMix・ベロシティ表は `drum-genre-guide.md`、ベースの型は `bassline-guide.md`、奏法と「打ち込みっぽさ」の6原因は `craft-guides.md` §13・§15、本物らしさの測定は `realism-roadmap.md`。この文書は、それらに無い **拍子・変拍子、ミリ秒の数字、パート別のずれ方、swing/human の実装の読み解き、テンポ変化、型の追加** を足す。

## 1. 要点

1. **グルーヴは「位置」「強さ」「長さ」「ごく小さなずれ」「パートどうしの関係」「くり返しの変化」の合わせ技**。いちばん効くのは位置（どこに打つか）と強さ（どれを強く・弱くするか）。小さなずれは仕上げ。
   - 研究でも、ずれを消した版のほうが「スウィングして聞こえる」と評価された例がある（S6）。ベースだけを ±24ms ずらしても、聴き手の評価はほとんど変わらなかった（S2）。ずれに時間をかけすぎない。
2. **シンコペーションは「中くらい」がいちばん体が動く**。ファンクのドラムで、少なすぎても多すぎても「動きたくなる度」と「気持ちよさ」が下がった（逆U字。S24）。全部を裏拍にしない。表拍を残す。
3. **ずれの向きが性格を決める**。スネアを少し遅らせると重く大きく聞こえ、ハイハットやライドを少し早めると急かす（S14・S15・S16）。ベースは「押す」「引く」で曲の気分が変わるが、テンポが変わったわけではない（S16）。
4. **耳に届く下限は数ミリ秒〜10ms 前後**。音の間隔が 240ms 未満なら 6ms 前後、それより長ければ間隔の 2.5% 前後が目安（S2が引く先行研究）。10ms 以内のずれは演奏の意図と言い切れないとの見方があり、30ms 未満は聞き分けも意図も疑わしいとする論者もいる（S1）。制作側の目安では **35ms を超えると「外れた」と感じ始める**（S23。B〜C）。
5. **スウィングの比は、遅いほど大きく（三連より強く）、速いほど1:1に近づく**（S4）。ただし2:1に決まるわけではなく、ドラマーごとに違う（S5）。うちの `swing` は最大でちょうど2:1（三連）。
6. **変拍子は2と3の足し算で数える**。5＝3+2か2+3、7＝2+2+3（または3+2+2・2+3+2）、9＝2+2+2+3か3+3+3。グループの頭にアクセントを置く（S25）。バルカンの非対称拍子も、速い最小単位ではなく、2・3・4つ分のまとまりが脈になる（S27）。
7. **うちの `beats` は「4分音符の数」で、3・4・6・7 の4種類**。`beats: 6` と `beats: 7` は、1拍を8分音符とみなして書けば 6/8・7/8 になる（§4）。1曲の中で拍子は変えられない。
8. **うちの `human` は、位置のずれが「±」だけで偏りがない**。後ノリ・前ノリは `push` で付ける。ドラムの `push` の単位は拍なので、ミリ秒に直すには bpm が要る（§3・§7）。
9. **テンポの変化（ritのような）は、今は曲全体で1つの bpm のみ**。音の長さを少しずつ伸ばして近似できる（§8）。本格的にはテンポマップが要る（§10 提案5）。

## 2. うちの機能への対応（実装の読み解き）

`src/audio/midi-export.ts` と `src/audio/score.ts` を読んだ結果。数字は**ティック**で、`PPQ=480`、**1ティック＝125÷bpm ミリ秒**（120bpm で約1.04ms、90bpm で1.39ms、170bpm で0.74ms）。

### 2.1 `swing`（曲全体）
- `grooveOffsetBeats(swing, push, 開始拍)`：拍の小数部がちょうど **0.5** の音を `swing/6` 拍、**0.25・0.75** の音を `swing/12` 拍だけ遅らせる。`push` はそのうえに足される。
- 三連（0.333…）や、0.1 刻みの音は対象外（そのまま）。`swing: 1` で 8分の裏が三連の位置（2:1）。
- **曲全体・全パートにかかる**。ドラムだけ揺らしてメロディをまっすぐにはできない（`drum-genre-guide.md` §8）。キックの位置（サイドチェイン `duck` 用）にも同じ `swing` と `push` が反映される。
- **6/8 や 12/8 の「複合拍子」では使わない**。`beats: 6`（1拍＝8分）の 0.5 拍の音は3つ1組の途中なので、`swing` を掛けると組が崩れる。複合の3連の感じは、音の長さで書く（§4）。
- リアルタイム再生（`flattenScore`）にも `swing` と `push` は効く。ただし `human` のタイミングのずれは効かない（強さのゆらぎだけ）。

### 2.2 `human`（0〜1、録音音源の書き出し＝MIDI経由だけ）
| 何を | どうなる | 数式（H＝human） |
|---|---|---|
| タイミングのずれ（各音、曲の1拍目は除く） | 一様乱数で「±」。偏りなし。**パートごと（正しくはチャンネルごと）に別の種** | 鍵盤・ギター・ベース・弦・リード・ブラス：最大 ±4.9×(1+4H) ティック。ドラム（kick・snare・hihat・tom・crash）：最大 ±3.15×(1+2.5H) ティック。`edition: "real"` は ×1.6。**H=0 でも約 ±5ms（楽器）・±3ms（ドラム）は出る** |
| 全体のゆるやかな走り・溜め | 全パート同じだけずれる（そろったまま）。周期 17.3 拍と 41 拍の2つの波 | ±20×H ティック（H=0.5 で ±10 ティック＝約10ms）。ループの長さとは無関係の周期 |
| 音の強さ | 音ごとに掛け算 | ±7%×(1+3H)。スネアはさらに ±約10%。H=0.5 で ±17.5% |
| 音の長さ | 1拍以下の短い音（ドラムを除く）が最大 14%×H 短くなる | |
| 音程のずれ | リード・ギター・弦・パッド・ブラスが ±8セント×H | |
| 長い音の山 | リード・パッド・弦・合唱・ブラスの1拍以上の音に音量の山（`pump` が無いとき） | |
- **ずれの対象にならない楽器**：`slap`・`sub808`・`pad`・`choir`・`bell`・民族楽器など。ベースのうち `bass` は対象だが、`slap` と `sub808` は対象外。
- **ずれ幅は bpm に反比例**（ティックで決まるため）。170bpm では 120bpm の約7割、80bpm では約1.5倍のミリ秒になる。
- **キックとベースは別のチャンネルなので、別々にずれる**。同じ拍に重なる音でも、H を上げるほど「ロックイン」がゆるむ（§6）。同じチャンネルに重ねたパート（ギターのストロークの各弦など）は同じようにずれてそろう。
- `human` が省略されると 0。AIソングで `drumGenre` を書くと、ジャンルの標準値が入る。

### 2.3 `push`（パートごと、−0.1〜+0.1 拍）
- プラス＝あと乗り（遅く）、マイナス＝前のめり。**単位は拍なのでミリ秒は bpm 次第**：`ms = push × 60000 ÷ bpm`。逆に `push = ms × bpm ÷ 60000`。
- 上限 ±0.1 拍は、120bpm で ±50ms、80bpm で ±75ms。実用は ±0.05 拍（±30ms 前後）まで。

### 2.4 `velocity` まわり
- ドラムの `x`＝1.0、`X`＝1.3、`o`＝0.5（`ai-song.ts`）。ハイハットは自動でさらに、拍の頭×1.15、8分の裏×0.85、16分の細かい音×0.62。
- MIDIの強さは「トラックの volume」で頭打ちが変わる（§3.3）。**ドラムの volume が大きいと `X` が 127 に張りついて、`x` との差が消える**。

## 3. グルーヴの数値表

**符号**：＋は遅い（後ノリ）、−は早い（前ノリ）。**基準はキック（0ms）**。bpm 90〜130 を想定。bpm が違えば `push = ms × bpm ÷ 60000`（§3.2）。

### 3.0 グルーヴの正体（何を動かせばいいか）
| 要素 | 中身 | うちで動かすところ | 効き目 |
|---|---|---|---|
| 位置 | どこに打つか。シンコペ・クラーベ・スネアの位置 | `g:` の型、notes の拍 | 大（ジャンルが決まる） |
| 強さの山 | 拍の頭を強く、裏を弱く。バックビート、ゴースト | `x`・`X`・`o`、`!`・`,`、volume | 大 |
| 長さ | 短く切るか、つなぐか。ハットの開閉 | `'`・`_`、`gate`、`O` | 中 |
| 系統的なずれ | スネアは遅く、ハットは早くなど「向きのある」ずれ | `push`（拍）、将来の `pushMs`（提案2） | 中（数〜20ms） |
| 偶然のゆれ | 毎回ちがう±のずれ | `human` | 小〜中（仕上げ） |
| パートどうしの関係 | キックとベースがそろう、誰が前で誰が後ろか | 同じ位置に打つ、`push`、`duck` | 大（ロックイン。§3.4） |
| くり返しの変化 | 4小節に1か所変える | 手書き（`craft-guides.md` §15） | 大 |
| テンポの揺れ | 走る・溜める・rit | §8 | 場面による |

- 研究が言うのは「ずれ」だけがグルーヴではないこと：ずれを消した版のほうがスウィングして聞こえた例（S6）、ベースを ±24ms ずらしても評価がほぼ変わらなかった例（S2）がある。**位置と強さを先に、ずれは最後に**。
- 手・足の動かし方の差は、聴き手には「音の出だしの強さ・長さ・音色」の違いとしても伝わる。うちでは音源の選択（`--drums`、`--bass`）と `drumMix` がこれにあたる。

**根拠**
- キックを基準 0 にして、スネアを遅らせ、ハイハットを早めるのは広く使われる型（S14・S15・S23）。ロックのスネアが少し遅いと大きな空間に聞こえる、という説明もある（S15）。**B**
- 実測の例：ある有名なフュージョン曲の分析で、2拍目のスネアは 20〜40ms 遅く、4拍目は 3〜5ms 程度（10ms 以内）だった（S1）。2拍目と4拍目で遅れ方が違う。**A**
- ビートメーカーの逸話：ヒップホップの先駆者は、キックを約30ms早く、スネアを約20ms遅く置いた場面があるという（S14）。うちのヒップホップのキック欄（−10まで）は、そこまで極端にせず控えめにした。**B**
- 制作ブログの目安（キック 0〜+5、スネア +5〜+12、ハット −8〜0 早め、ベース +5〜+15 遅め、鍵盤 ±5）は、数字に整合しない箇所があると自分で注意書きがある低信頼の資料（S23）。方向の傾向だけ採用し、幅は控えめに。**C**
- ファンクとスウィングの実演の「タイミングのばらつき」（標準偏差）は、音と音の間隔の約 10%、実測で 15.7ms（ファンク）・27.2ms（スウィング）（S2）。ばらつきを一様乱数の最大幅 a に直すと、標準偏差 ≒ a÷1.7。ファンクの 15.7ms は、120bpm の real 版 human 0.6（楽器の最大 約28ms、標準偏差 約16ms）に近い。スウィングの 27.2ms は、スウィング特有の偏りを含む数字なので、`human` だけで再現しようとしない（`swing` や `push` で作る）。**A**
- 初期ファンク14曲の調査（要旨）：16分のスウィングはほぼ全曲にあり、2・4拍の遅れは意外に小さかった（S19）。**A**
- 「30〜40ms 早いと『せかされる』、20〜30ms 遅いと『もたつく』」という古い早見表の紹介もあるが、科学的な根拠は疑問視されている（S18）。「15〜30ms は聞いてわかる、35ms を超えると外れる」くらいの大まかな線として使う。**B**

### 3.3 ベロシティ（強さ）の実際：volume でアクセントが潰れる
`velocityOf`（標準）で計算した、ドラム（BOOST=1）の MIDI 強さ。`o`＝0.5、`x`＝1.0、`X`＝1.3 の比。かっこ内は `dynamics: "natural"`（`dynamicRange: wide`）のとき。

| トラックの volume | `o`（0.5） | `x`（1.0） | `X`（1.3） | ハット表（×1.15） |
|---|---|---|---|---|
| 0.08 | 51（33） | 68（68） | 79（92） | 74（80） |
| 0.10 | 56（37） | 77（77） | 90（104） | 83（90） |
| 0.12 | 60（41） | 86（86） | 101（116） | 93（100） |
| 0.15 | 66（46） | 98（98） | 118（127） | 108（116） |
| 0.18 | 73（51） | 111（111） | 127（127） | 123（127） |
| 0.20 | 77（55） | 120（120） | 127（127） | 127（127） |
| 0.25 | 80（58） | 127（127） | 127（127） | 127（127） |

（表はキック・スネアの補正値 1.0 で計算。ハイハットは補正 0.9 なので、同じ volume で少し低くなる。）

- **ドラムの各パートの volume は 0.10〜0.15 を目安にする**。0.18 を超えると `X` が 127 に張りつき、0.2 では `x` がすでに約 120 で、`X`・`x` の差がほとんど無くなる（C。実装の計算）。
- 研究でなく制作者の助言だが、最大の 127 を避けて 115 前後を山にすると、ドラムの音が荒れにくい（S11）。ゴーストは 30 前後（S11）、20〜50 の範囲とする資料もある（S23）。
- ハイハットは、表を強く・裏を弱くし、交互に 3/4 の高さにする（S8）。ハイハットの強弱の幅をいちばん大きく、キック・スネアはあまり変えない（S8・S10）。同じ小節の強弱を使い回さない（S10）。

### 3.4 リズムセクションの役割分担とロックイン

| パート | 受け持つ「時間」 | 向き（ずれ） | うちでの書き方 |
|---|---|---|---|
| ドラム：キック | 脈の土台。基準（0ms） | ずらさない | `push` 0。ジャンルの型（§6 C）。重ねるベースは同じ位置に |
| ドラム：スネア | バックビート。大きさと重さ | 少し遅く（ロック・ファンク・ヒップホップ）、機械的なジャンルは 0 | `push` +0.01〜+0.04 |
| ドラム：ハット／ライド | 細かい時計。急かすか、ゆったりか | 少し早く（ジャズのライド、ハウス）、バラードは 0 | `push` −0.01〜−0.02、強弱の型（R27・R28） |
| ベース | 和声の根と、キックと組むリズム | キックと同時、またはごく少し遅く。「押す」ジャンルもある（S16） | キックと同じ位置に根音。`push` 0〜+0.01。`duck` 0.2〜0.4 |
| ギター（刻み・カッティング） | スネアに寄り添う裏拍・隙間 | スネアと同じか、わずかに遅く | 隙間を空ける型（R15・R34）、ストロークは各パート `push` を 0.01〜0.03 ずつ |
| 鍵盤・パッド | 和声のクッション。ずれが目立たない | 気持ち遅く（バラード） | 長めの音、`sustain`、`human` で音量の山 |
| ボーカル／リード | 全体の前後に自由に乗る | ジャンルによる | ループの継ぎ目に注意 |

- **ロックインの意味**：低音の2つ（キックとベース）が、同じ位置・同じ長さの感覚でそろうこと。ベースの音の出だしは遅いので、キックより数ms遅くてもそろって聞こえる。これを超えて大きくずれると、芯がにじむ（S16）。
- **うちの実装の特徴**：キックとベースは別チャンネルなので、`human` を上げるとそれぞれ別の量でずれる（H=0.5 の modern・120bpm で、ベース ±15ms、キック ±7ms）。ロックインを保ちたいときは、**同じ拍に重なる音のずれを同じにする**（提案8 `lockToKick`）。それまでは、キックとベースが同時に鳴る曲（メタル、ロック）は `human` を 0.3 以下にする。
- **誰が前か後ろかは1つに決める**：ドラムが前なら、ベースは0か少し後ろ（S16）。全部が前、全部が後ろだと、ただテンポが違って聞こえる。
- **かたよりは「ずらす」で、「速くする」ではない**（S16）。ずらしは数ms〜20ms程度。それ以上はテンポの変化になる。

### 3.5 ジャンルのグルーヴの核（ひとこと）
- **ロック・ポップ**：バックビートの強さと、キックの置き方。8分が基本で、サビで密に。
- **パンク・メタル**：正確さ。ずれを小さくして、強さを一定に。ガロップやツーバスは速いほど 8 分に落とす。
- **ファンク**：16分の裏を弱く、スネアのゴーストと、「ワン」の強調。シンコペは中くらい（S24）。
- **R&B・ヒップホップ・ローファイ**：後ろに引くスネア、揺らしたハット、間（休符）。ずれは大きくしすぎない。
- **ジャズ**：三連寄りの揺れ（テンポで変える）、歩くベース、軽いライド。
- **レゲエ**：3拍目のワンドロップ、裏拍のスカンク、引いたベース。
- **ハウス・ディスコ**：キックは動かさず、裏のオープンハットと、16分の隙間。
- **トラップ**：ずれより強さと長さ。三連のロール、808。
- **ボサノバ・サンバ**：クラーベの骨組みと、軽い8分。音量の幅は小さく。
- **ワルツ**：1拍目が土台、2・3拍目は軽く。
- **変拍子（プログレ）**：グループの頭を鳴らし、2小節単位でまとまりを作る。

## 4. 拍子と変拍子の書き方

**うちの `beats` は 3・4・6・7（4分音符の数）**。`timeSig`（Score）は 1〜32／分母 1・2・4・8・16・32 で書ける。`timeSig` は MIDI の拍子記号と表示用で、音の長さは常に「4分音符＝1拍」で数える。AIソングの `bpm` は 40〜260（案内文は 50〜220）。

### 4.1 拍子ごとの聞こえ方と書き方

| 拍子 | 聞こえ方（自分の言葉で） | うちでの書き方 | アクセントの置き方 |
|---|---|---|---|
| 3/4（ワルツ） | 「ずん・ちゃ・ちゃ」。1拍目が土台で、2・3拍目は軽い（S28）。丸く回る | `beats: 3` | 1拍目：ベース・キック。2・3拍目：和音を弱く。メロディは小節をまたいで始めたり伸ばしたりしてもよい（S28）。ウィンナワルツでは2拍目を少し長く取る伝統もある（S29） |
| 6/8（二つの三つ組） | 大きな2拍が、それぞれ3つに割れる。舟をこぐような揺れ | **`beats: 6`、1拍＝8分音符**。bpm は8分音符の速さ（付点4分＝60 なら bpm 180） | 1拍目（強）と4拍目（中）。2・3・5・6拍目は弱い |
| 6/8 → 3/4 のすり替え（ヘミオラ） | 3つ組が2つ組に変わる。ぐっと前に進む（S34・S35） | `beats: 6` のまま、アクセントを 1・3・5 拍目へ | 同じ 6 つの脈を「2+2+2」で区切る（§4.3） |
| 12/8（シャッフル寄り） | 4つの三つ組。遅いブルース・バラード | **`beats: 4`＋`swing: 1.0`**、8分で書く（`drum-genre-guide.md` §8） | 各拍の頭。3連の真ん中は弱く |
| 5/4 | 3+2 か 2+3 のどちらで数えるかを先に決める。前へつんのめるような、かたよった揺れ（S25・S26） | **AIソングの `beats` には書けない**（3・4・6・7）。作曲ソフトの `timeSig: {5, 4}` か、手書きの notes で。または §4.5 | 3拍目寄りに中アクセント（S25）。グループの頭を強く |
| 7/8（2+2+3） | 2・2・3 の3つ。最後の3つ組が「つんのめって次の小節へ」。ころころ転がる | **`beats: 7`、1拍＝8分音符**。bpm は8分の速さ（4分＝70 なら bpm 140）。※`beats: 7` を4分音符 7 つの 7/4 として使えば 4+3 や 2+2+3 の7拍子 | 各グループの頭。3つ組の最後は急がず、息をつく（S25） |
| 7/4 | 4+3。ゆったりした7つの脈 | `beats: 7`、1拍＝4分音符 | 1拍目（強）と5拍目（中） |
| 9/8 | 2+2+2+3（非対称）または 3+3+3（三つ組が3つ）（S25） | AIソングは非対応（提案6）。手書きで | 脈を先に決める |

- **非対称拍子は、最小単位がいちばん速くて脈にならない**。実際の脈は、2・3・4 つ分のまとまりで感じられる（S27）。ドラムとベースのどちらかがグループの頭を必ず打つと、バンドがそろう（S25）。
- **変拍子でも2小節のまとまりに**：小節ごとに同じ形でも、2小節目に小さな目印（ピックアップ、クラッシュ、フィル）を足すと、小節線で「リセット」された感じにならない（S25）。変拍子に入る直前・出た直後の拍が、いちばんバラバラになりやすいので、そこを念入りに（S25）。

### 4.2 8分音符を1拍にして書く方法（6/8・7/8）
`beats: 7` や `beats: 6` の曲は、**1拍＝4分音符のままの感覚で書くと 7/4・6/4 になる**。7/8・6/8 にしたいなら：
1. `beats` はそのまま（7 または 6）。
2. bpm は**8分音符の速さ**にする。7/8 で「4分＝70」に感じたいなら bpm 140、6/8 で「付点4分＝60」なら bpm 180。
3. 音の長さは「1＝8分音符」で書く。細かい音は 0.5（16分）。
4. `g:` は使わない（1文字＝0.25拍なので、8分音符の 1/4 になる）。拍つきの書き方（`x:1`、`x:0.5`）で書く。
5. `swing` は 0 にする。1拍を8分音符として書くと、`swing` が 0.5 拍目（＝16分の位置）の音だけを遅らせて、2+2+3 の組が崩れる。

### 4.3 書き方の例（`parts` の `notes`。拍つき）
すべて拍数の合計が `beats` に一致する。`x` は打つ、`!` は強く、`,` は弱く、`R` は休み。

**3/4 のワルツ（beats 3、bpm 100〜130）**
- kick：`x:1! R:2`
- snare（ブラシ代わりに弱く）：`R:1 x:1, x:1,`
- hihat：`x:0.5! x:0.5, x:0.5 x:0.5, x:0.5 x:0.5,`
- bass：`A1:1! R:1 R:1`（2・3拍目は和音の楽器に任せる）

**3/4 のヘミオラ（2小節＝6拍を3つ組に：beats 3、2小節ぶんを1まとまりで書く）**
- snare：`x:1! R:1 x:1! R:1 x:1! R:1`（1・3・5拍目。小節の頭と合うのは1拍目だけ）
- 次の2小節では元の `R:1 x:1, x:1,` に戻して、ヘミオラを「通り過ぎる」ものにする（S34）。

**6/8（beats 6、1拍＝8分、bpm 150〜190）**
- kick：`x:1! R:2 x:1 R:2`
- snare：`R:3 x:1! R:2`
- hihat：`x:1! x:1, x:1, x:1 x:1, x:1,`
- bass：`A1:1! R:1 A1:1, A1:1! R:1 E2:1,`
- 6/8 のヘミオラ（2+2+2）：hihat を `x:1! x:1, x:1! x:1, x:1! x:1,` にする（S35）。

**7/8（beats 7、1拍＝8分、2+2+3、bpm 130〜170）**
- kick（グループの頭 0・4 拍目）：`x:1! R:3 x:1 R:2`
- snare（位置2＝2つ目のまとまりの頭と、位置5＝3つ目のまとまりの最後。位置は0から数える）：`R:2 x:1! R:2 x:1! R:1`
- hihat（頭を強く）：`x:1! x:1, x:1 x:1, x:1! x:1, x:1,`
- 3+2+2 にするなら：kick の頭を 0・3・5 拍目、2+3+2 なら 0・2・5 拍目に置き換える（S25）。

**7/4（beats 7、4+3、bpm 90〜130）**
- kick：`x:1! R:3 x:1 R:2`（1拍目と5拍目）
- snare：`R:1 x:1! R:2 R:1 x:1! R:1`（2拍目と6拍目）。

### 4.4 シンコペーション
- 拍の頭の音を、その前の裏拍へ食い込ませる（先取り）。ベースとキックを同じ位置に置くとノリがそろう（`craft-guides.md` §3）。
- **度合いは中くらいに**。ファンクのドラムの調査で、シンコペが「中」の型がいちばん体が動き、気持ちよいとされた（S24）。表拍を全部消さない。
- 型の例は §6 の R1〜R8（先取り）と R9〜R13（クラーベ）。

### 4.5 曲中の拍子変更（今できること・できないこと）
- **できない**：`beats` は曲に1つ。MIDIの拍子記号も曲の頭に1つだけ書き出す（`midi-export.ts`）。`sections`・`applyArc`・自動伴奏は「1小節＝`beats` 拍」で計算するため、途中で小節の長さを変えると位置がずれる。
- **手書きの notes だけで曲を組むなら（`autoAccompaniment: false`、`sections` なし）**できる：全パートで同じ長さの小節を書く（例：4,4,4,3 の拍数をくり返す）。音は正しく鳴るが、拍子の表示（MIDIの記号）は最初の拍子のまま。ループは最長パートの合計で決まる。
- ゲーム向けの現実的な方法：**別々の曲に分けて**、場面の切れ目（小節の頭）で切り替える。曲の切り替えは次の拍・小節の区切りまで待たせる設計が一般的（S38）。
- 5拍子は、4/4 の小節に「5拍の型」をくり返すと、20拍（5小節）ごとにそろう**ポリメーター**として使える（試していない。リフが小節頭と1拍ずつずれていく）。

## 5. スウィング換算表

**うちの `swing` ＝ s（0〜1）**
- 8分の裏の遅れ：`s ÷ 6` 拍 ＝ `s × 10000 ÷ bpm` ミリ秒。
- 16分の裏（0.25・0.75 拍目）の遅れ：その半分（`s ÷ 12` 拍）。
- 8分の長短比：`(3 + s) ÷ (3 − s)`。
- MPC 風パーセント：`50 + 16.7 × s`（S3・S21 の説明と整合。S3 は 50%＝まっすぐ、66%＝完全な三連）。

| swing | MPC風% | 8分の長短比 | 遅れ（8分の裏）80bpm | 100bpm | 120bpm | 140bpm | 170bpm | 感じ・ジャンル |
|---|---|---|---|---|---|---|---|---|
| 0 | 50 | 1.00 | 0 | 0 | 0 | 0 | 0 | ロック・メタル・ダンス・トラップ |
| 0.15 | 52.5 | 1.11 | 19 | 15 | 12.5 | 11 | 9 | わずかな揺れ（ハウス） |
| 0.25 | 54.2 | 1.18 | 31 | 25 | 21 | 18 | 15 | モダンなR&B・ヒップホップ（S3：直線の16分を「ゆるめる」54%） |
| 0.4 | 56.7 | 1.31 | 50 | 40 | 33 | 29 | 24 | ブーンバップ・ローファイ |
| 0.5 | 58.4 | 1.40 | 62 | 50 | 42 | 36 | 29 | 定番のはね（S3：90bpm で 62% はややゆるい三連寄り） |
| 0.6 | 60.0 | 1.50 | 75 | 60 | 50 | 43 | 35 | ファンクのシャッフル寄り・速めのジャズ |
| 0.75 | 62.5 | 1.67 | 94 | 75 | 62.5 | 54 | 44 | シャッフル |
| 0.9 | 65.0 | 1.86 | 112 | 90 | 75 | 64 | 53 | 遅いジャズ・ブルース |
| 1.0 | 66.7 | 2.00 | 125 | 100 | 83 | 71 | 59 | 完全な三連（12/8の感じ） |

- **16分の裏は、s=1 で 0.25 → 0.333 拍**に動く。16分の細かい型（ハイハットの `x` 全部）は、8分より遅れが半分なので「半分の強さのスウィング」になる。
- **他の目安**：ツールによっては 52%（わずか）・64%（はっきり）・73%（強い）で試し、50% 未満（負のスウィング）で裏を早める（S21）。Dorico の再生では、軽いスウィング＝遅いテンポで1.5:1、速いテンポで1:1。重いスウィング＝遅いテンポで3:1、速いテンポで1.5:1（S7）。
- **ジャズはテンポで変える**：遅いほど比が大きい（速いテンポで1に近く、遅いテンポで3.5近くまで広がる実測。S4）。ただし「速いと必ずこう」と単純には言えず、ドラマーごとに差があり、約 100ms という短い音の長さが一定という説は、ある分析では否定された（S5）。うちの目安は `jazzSwingForBpm`（60〜120bpm で 0.8〜1.0、140〜180bpm で 0.5〜0.7、200 以上で 0.3〜0.5）。典型の平均比が 1.7:1 より低いとの指摘もあり（S1）、迷ったら少し控えめ（0.5〜0.6）から。
- **揺れの大きさをひと続きに保つ**：1曲の中で比が極端に変わらないほうが、スウィング感が強まったという結果もある（S6）。曲の途中で `swing` を変える機能は無いが、変えないこと自体は自然。
- **swing を使わないとき**：ロック・メタル・ダンス・トラップは 0 で、ノリは `push` と強さで作る。6/8・12/8 の複合拍子（§4）は `swing` を 0 にする。
- **要素ごとに揺らし方を変えるのが定石**：ハットだけ揺らす型も、キックを強く揺らしてハットを軽くする型もある（S13・S14）。うちの `swing` は全パートにかかる（§2.1）。近似として `swing` は控えめにし、ベースの `push` を 0 に近づける。提案3で分離できる。

## 6. リズムの型集（16ステップ `g:` と拍つき）

**書き方の復習**：`g:` の1文字＝16分音符、`x` ふつう（1.0）、`X` 強く（1.3）、`o` 弱く（0.5）、`O` オープンハイハット（ハイハットのみ）、`.` 休み。**`g:` は4/4の1小節＝16文字**。位置番号は 0〜15（0＝1拍目の頭、4＝2拍目、8＝3拍目、12＝4拍目、2・6・10・14＝8分の裏）。

型はジャンルを問わず混ぜてよい。**2〜4小節で1つ型を変える**（キックをずらす、ハイハットの強弱を回す）と、機械的に聞こえにくい（`craft-guides.md` §15）。

| R4 | 3-3-3-3-2-2 | `g:x..x..x..x..x.x.` | 0・3・6・9・12・14 | 4拍子の中で3つ組を重ねて、最後に2つ組で戻る（S34）。ブリッジ・サビ前に |

### B. クラーベ（ラテンの骨組み。5つの打点を2小節で）
クラーベは「3つ打つ側」と「2つ打つ側」を並べた周期の型。伝統の譜面では2小節（前半の小節に3つ、後半の小節に2つ。S32：3-2 の前半は 3+3+2 の骨組み）。16マスのステップ表示では、**1小節（16文字）の前半2拍に3つ、後半2拍に2つ**として1行で書く。ほかのパートはクラーベと同じ「側」に合わせる。

| 番号 | 名前 | `g:`（16文字） | 位置 | 使い方 |
|---|---|---|---|---|
| R9 | 3-2 ソン・クラーベ（3の側） | `g:x..x..x...x.x...` | 0・3・6・10・12 | 1小節の前半に3つ・後半に2つ。ラテン調・民族調のクラベス／カウベルのつもりで |
| R10 | 2-3 ソン・クラーベ | `g:..x.x...x..x..x.` | 2・4・8・11・14 | 3-2 を半分（8ステップ）ずらした形。同じ曲で1番は 3-2、2番は 2-3 にもできる |
| R11 | ルンバ・クラーベ（3-2） | `g:x..x...x..x.x...` | 0・3・7・10・12 | 3つ目の打点が1つ後ろ。やや重く、切ない |
| R12 | ボサ・クラーベ | `g:x..x..x...x..x..` | 0・3・6・10・13 | ボサノバの軽い骨組み。ハイハットを弱くして重ねる |
| R13 | ボサのベース（付点4分＋8分） | `g:x.....x.x.....x.` | 0・6・8・14 | 根音と5度を交互に（`bassline-guide.md` §3）。クラーベと同じ「側」に合わせる |

- 音符が混んで聞こえたら、ほかのパートは**クラーベの空き**に置く。クラーベのパートは弱く（`o` か `x` を volume 小さめ）。

### E. ポリリズム（2つのまとまりを同時に）
**考え方**：共通の細かい単位に割ると、2つの層が最初と最後でそろい、途中ですれ違う（S30・S31）。3:2 は6マス（片方は 1・3・5、もう片方は 1・4）、4:3 は12マス（片方は 1・4・7・10、もう片方は 1・5・9）。

### F. ハーフタイム／ダブルタイム／シャッフルの違い

| 呼び方 | 何が変わるか | うちの書き方 |

| ハーフタイム | 曲の速さ（bpm）とコードの動きは同じ。ドラムが半分の速さに感じる（S17） | snare を3拍目だけ（R17）。キックを1拍目と、その後の裏拍に |

## 7. ヒューマナイズの推奨値（`human` の値とジャンル）

### 7.1 `human` の値が実際にどれだけずれるか（ミリ秒。ティック×125÷bpm）
下の表は「最大のずれ（±）」。実際は一様乱数なので、標準偏差はこの約 0.58 倍。

| human | 楽器・modern 120bpm | 楽器・real 120bpm | ドラム・modern 120bpm | ドラム・real 120bpm | 楽器・modern 170bpm | 全体の走り溜め（±） | 強さ（±） | 音程（±セント） |
|---|---|---|---|---|---|---|---|---|
| 0 | 5ms | 8ms | 3ms | 5ms | 4ms | 0 | 7% | 0 |
| 0.15 | 8 | 13 | 4.5 | 7 | 6 | 3ms | 10% | 1.2 |
| 0.3 | 11 | 18 | 6 | 9 | 8 | 6ms | 13% | 2.4 |
| 0.5 | 15 | 24 | 7.5 | 12 | 11 | 10ms | 17.5% | 4 |
| 0.7 | 19 | 31 | 9 | 14.5 | 14 | 14ms | 22% | 5.6 |
| 1.0 | 25.5 | 41 | 11.5 | 18 | 18 | 20ms | 28% | 8 |

- **上限の目安**：楽器の「最大のずれ」が約 30ms を超えると、目安（S1・S23）で「外れて聞こえる」領域に入る。**120bpm では real 版は human 0.6 まで（約28ms）、modern 版は 1.0 まで（約25ms）**。ミリ秒はティック数×125÷bpm なので、**80bpm の曲は約1.5倍**になる（modern 1.0 で約38ms、real 0.4 で約32ms）。遅い曲ほど human を下げる。
- 参考：DAW の例では、位置のランダムは ±5 ティック（S9）〜±10 ティック（S10）程度の小さな値から（ティックの解像度は製品による）。うちの modern・human 0.3 は ±11 ティック（PPQ 480）。
- **ドラムは楽器の約半分**になるよう実装されている。聴き手が気づく下限（約6〜10ms。S1・S2）を考えると、ドラムの human 0.5 以上は「もたつき」として聞こえ始める。
- `human: 0` でも約 ±5ms／±3ms のずれは出る（§2.2）。**完全に機械的にしたいジャンル（トラップ・ハウス・DnB）は、`human: 0.1` 以下でも十分に整って聞こえる**。完全な 0 にする機能は無い。

### 7.2 ジャンル別の推奨（`DRUM_GENRES.human` と合わせた）
| ジャンル | human | 理由 |
|---|---|---|
| メタル、ボス | 0.15〜0.2 | 正確さが音楽の一部。ずれるとツーバスが濁る |
| トラップ、DnB、ダブステップ | 0.1〜0.15 | 機械の正確さ。ノリは強さと音の長さで |
| ハウス、ディスコ、ダンス | 0.1〜0.2 | キックは動かさず、ハットだけ `push` で少し早く |
| ボカロ・高速ポップ | 0.2 | 速いので ms は小さくなる（170bpm で約7割） |
| 通常戦闘 | 0.25 | 少しだけ人間味、前のめりは `push` で |
| ポップ、J-POP、ロック、ヒップホップ | 0.3〜0.35 | 標準 |
| ファンク、R&B、ボサノバ、フィールド | 0.4〜0.45 | 緩いノリ。ただし位置と強さが先 |
| バラード、レゲエ、ジャズ | 0.5〜0.55 | 余裕のあるノリ。ただし遅い曲（80bpm 前後）の real 版は ms が大きくなるので 0.35〜0.4 に |
| ローファイ | 0.5〜0.6 | よれた感じ。swing 0.3〜0.4 と合わせる |
- **くり返しの多い曲ほど `human` が効く**が、手で書くときに4小節に1か所変えるほうが本筋（`craft-guides.md` §15）。
- **`push` は human と別に**：スネア＋、ハット−、キックとベース 0 は、`human` に頼らず `push` で設定する（§3.1）。

### 7.3 `human` では足りない部分（手で書く）
- **ドラムの強弱**：一定の型を回す（R27・R28）。ハットの強弱と音の長さ（開閉）。
- **ゴースト**：スネアの `o`。やりすぎない（3つ続けない）。
- **フィルの前後**：直前の拍を空ける、直後にクラッシュ（`drum-fills.md`）。
- **和音のずれ（ストローク）**：和音を別パートに分け、各パートの `push` を 0.01〜0.03 拍ずつずらす（`craft-guides.md` §13）。
- **ベロシティの山**：セクションで volume の山と谷（`dynamics: "natural"`、`sections: "auto"`）。

## 8. テンポ変化の実現方法

### 8.1 今できること
| 目的 | 方法 | 注意 |
|---|---|---|
| 曲全体の速さ | `bpm`（AIソング 40〜260、Score は `tempoBpm`）。曲に1つ | 途中で変えられない |
| 曲の最後を伸ばす（rit） | **音の長さ（拍）を少しずつ伸ばして書く**。例：最後の1小節（4拍）を、全パートで 1.00・1.05・1.12・1.22（合計 4.39 拍）のように。**全パートで同じ比率で伸ばすこと** | `g:` は使えない（0.25 刻みに固定）→拍つきで書く。`sections`／`applyArc` など小節で数える機能は、拍数が合わなくなるので、手書きの末尾だけに使う。`swing` は 0.5・0.25・0.75 拍目だけを動かすので、伸ばした音には効かない。MIDI の拍子・ループ位置は音の合計で決まるので、ループ曲では継ぎ目がずれない |
| テンポの速まり（accel） | 同じく、拍を縮める（例：1.00・0.95・0.88・0.80） | |
| 減速の形 | 最初はゆるやかに、終わりに向けて急に落とす曲線が自然（S37：終わりの減速は、位置だけで決まる形のモデルがある）。長さの倍率を `1 → 1.05 → 1.12 → 1.25 → 1.45` のように増やす | 聴いて決める |
| ハーフ／ダブルタイムの切り替え | `g:` の snare/kick の密度で（§6.5）。bpm は変えない | |
| テンポの「感じ」の切り替え（3:2 の関係） | 区間の音価をすべて ×2/3（または ×3/2）で書く。4分音符の三連を新しい拍に | 小節の拍数が整数にならない箇所は、フェルマータ（長い音）でまとめる |
| フェルマータ・間 | 長い音＋休符（`gate` を大きく）。全パートを同じ長さにする | |
| 場面でテンポが変わる | **別の曲にして切り替える**（水平方向の再構成。切り替えは次の小節の頭まで待つ。S38） | ゲーム側の切り替えと、曲の頭・終わりの音のそろえ方が必要 |
| ルバート（自由なテンポ） | 長い音と `gate`、`push` のゆれ、`human` の走り溜めで近似。ソロだけ自由にして伴奏を固定することはできない | 全パートが同じ時間軸 |
| ループ曲の rit／accel | **フレーズの終わりに置き、継ぎ目で元に戻る**（`music-knowledge.md`）。曲の最後を rit にすると、ループで頭に飛ぶとき不自然になる | 合計の拍数が変わるとループ位置がずれる |

### 8.2 今できないこと
- **テンポマップ**（拍位置ごとの bpm、直線／曲線の速まり・遅まり）。MIDIは先頭に1つだけテンポを書き出す。`flattenScore`（再生エンジン）も1つの bpm で時刻を計算する。
- **セクションごとの bpm**（ボス曲のフェーズでテンポ上げ、など）。`drum-genre-guide.md` §10 の「ボス曲のフェーズ表」を入れなかった理由。
- **途中のテンポ変更に合わせたエコー**（`echoGuitar` などの遅れは拍数で書くので、テンポ変更が入ったら追従させる必要がある）。
- **パートごとに別のテンポ**（ポリテンポ）。
- **途中の拍子変更**（§4.5）。
- **人間らしい自由な揺れ（ルバート）の自動生成**。

### 8.3 テンポの揺れの実際（参考）
- 終わりの減速（final ritard）の形は、物理の「ブレーキ」になぞらえた式で近似される研究がある（S37）。ここから、設計の考えかたとして「最初は緩く、最後は急に」を採る。
- 拍の揺れはフレーズの構造に従う（フレーズの終わりで伸びる）。速さ全体のゆらぎは ±1〜3% 程度から。（これは演奏研究の一般論で、ここで直接の出典は無い。**C**）

## 10. 取り入れる提案（実装できる単位）

優先は、小さく安全で効果が大きい順。どれも既存の曲は変えない（省略時は今までどおり）。

1. **パート別の human（`Track.human`／AIソング `parts[].human`、倍率 0〜2）**
   - `midi-export.ts` の `H` をトラックごとに `H × (track.human ?? 役割の既定)` にする。タイミングのずれ・強さ・長さ・音程にかかる。走り溜め（drift）は全体のまま。
   - 役割の既定の例：キック 0.5、ベース 0.8、スネア 0.8、ハット 1.2、ギター・鍵盤 1.0、リード 1.2、パッド 1.0。
   - テスト：`human` 未指定の曲の書き出しが、変更前と完全一致すること。
   - DAW の groove 機能は、タイミング・ランダム・ベロシティの量を別々に持ち、全体を 0〜130% で強めたり弱めたりできる（S20・S22）。`Track.human` に加えて、`humanTiming`／`humanVelocity` を分けるのも同じ考え。
2. **ミリ秒で書く `pushMs` と、ジャンル別の「ノリ」の既定（`grooveFeel`）**
   - `Track.pushMs`（−50〜+50）を、bpm で `push = ms × bpm ÷ 60000` に換算して `push` に足す。
   - `grooveFeel: "tight" | "laidback" | "pushed"` で、§3.1 の表（スネア＋、ハット−、ベース＋）をパート別 `pushMs` として自動で入れる（`push` が書いてあればそちらが優先）。`drumGenre` と連動。
   - 新ファイル `groove-feel.ts` に表を置く。テスト：同じ ms が bpm 80／170 で違う拍数になること。
3. **swing の分離（`Track.swing` で上書き、`swing8`／`swing16` の分離）**
   - `grooveOffsetBeats(score.swing, track.push, 拍)` を `track.swing ?? score.swing` にし、8分の裏と16分の裏を別々の量にできるようにする。ヒップホップ・ハウスで「キックをまっすぐ、ハットだけ揺らす」を実現する（§5）。
   - 影響：`duck` 用のキック位置の計算にも同じ値を使うこと。
4. **三連グリッド `t:`（1文字＝三連の1つ、1拍＝3文字、4/4の1小節＝12文字）**
   - `parseNotes` に `t:` を足し、各文字を `0.3333…`（3つ目で合計が1になるよう 0.3333・0.3333・0.3334）で作る。シャッフル、12/8、トラップの三連ロール、ポリリズム 3:2 がグリッドで書ける。
   - `check-drums.mjs` を `t:` の長さ（12の倍数）に対応させる。
   - `swing` は 0.5・0.25・0.75 の位置だけなので、三連には影響しない。
5. **テンポマップ（`Score.tempoMap: { beat, bpm, ramp? }[]`）**
   - `midi-export.ts` で複数のテンポイベント（0x51）を書き出し、`ramp` は 1/8 拍ごとの階段で近似。拍→秒の変換を `beatToSec(score, beat)` にまとめ、`flattenScore`・`getScoreDurationSec`・`midi-export` の `secStart`（`humanize` の種）・エコー（拍数ベース）を差し替える。
   - AIソングの書き方：`tempo: [{ "bar": 17, "bpm": 96, "ramp": 2 }]`、略記 `rit: { "bar": 32, "bars": 2, "to": 0.7 }`。終わりの減速は `v(x) = (1 + (w^q − 1)·x)^(1/q)`（w＝最終の速さ÷最初、q＝2、x＝0〜1）を既定にする（S37の考え方を自分で整えた形）。
   - ループ曲：最終 bpm と先頭 bpm が違うと継ぎ目で警告（`song-check`）。
   - これで `drum-genre-guide.md` §10 の「ボス曲のフェーズ表」も入れられる。
6. **拍子の拡張（`beats` に 5・9・12 などを許可、`grouping` 指定）**
   - AIソングの `beats` を整数 1〜12 にし、`grouping: [2,2,3]` を新設。自動伴奏のドラムは、グループの頭にキック・スネア、ハットはグループの頭を強くする。`check-drums` の 16 文字の基準を `beats × 4` に。
   - 影響：`sections`／`applyArc`／`checkArrangement` が `beats` を使うので、テストを足す。
7. **ルバート（`rubato: 0〜1`）**（提案5が前提）
   - ゆるやかなテンポのゆれ（±1〜3%、周期 2〜4 小節）と、フレーズの終わりでの小さな伸びを、テンポマップとして自動生成。ループ長で一周して元に戻る周期にする（今の `drift` は 17.3 拍・41 拍の周期で、ループの長さと合わない）。バラード・フィールド曲向け。
8. **キックにロックインする `lockToKick`（ベース・ギター）**
   - ベースの音がキックと同じ拍（16分以内）に重なるときは、キックと同じ種でずらす（`trackSeed` をキックのものにする）。`human` を上げてもキックとベースがそろったままになる。パンチと低音のまとまりに効く（S16）。
   - テスト：重なる音のずれの差が 0 になること。
9. **ずれの分布と対象楽器の見直し**
   - 一様乱数を「三角分布」にして、中心に寄りやすく（極端なずれを減らす）。`slap`・`sub808` などを `human` の対象に任意で加える（`Track.human` で 0 のまま既定）。
   - 曲の1拍目を除く規則（`startBeat > 0`）は残す。
10. **`tools/audio-check/check-groove.mjs`**
    - 曲JSONを読み、次を警告：`push` が ±0.05 拍を超える、キック・ベースの `push` が 0 でない、`human` がジャンル上限を超える、ドラム volume が 0.18 を超える（`X` が潰れる）、6/8 系で `swing` が掛かっている、`g:` の長さが `beats × 4` でない、全部同じ強さのハット、同じ小節の完全コピーが8回以上、シンコペ率（裏拍の打点÷全打点）が極端（0% や 90% 超。S24の逆U字）。

# オーケストラ・ピアノ音源の自動点検（2026-10-13）

`node tools/soundfont/audit-orchestra.mjs [プログラム番号 ...]`（先に `node tools/composer/build.mjs`）。各楽器を半音ずつ鳴らして、①測った音の高さのずれ ②隣の音との音量差（7dB超） ③長い音のループのつなぎ目（段差）を調べる。

## 直したこと
- 録音の音量がばらばらで、隣の音と±10〜15dBちがった → 音ごとに大きさをそろえた（ループの中、またはアタック後の1.4秒を測る）。
- 弱い層と強い層の切りかえ（ベロシティ88）で14dBの段差 → 2層を重ねて（弱 1〜104、強 66〜127）、なめらかに入れかわるようにした。
- 録音のファイル名の音名が半音ずれているもの、チューニングのずれ → 測った高さに合わせて音程を補正（伸ばす音の楽器のみ）。
- 高い音（D7・F7・ピッコロの最高音など）の音の高さを1オクターブ低く測っていた → 測る範囲を広げて直した。
- 元の楽器（FluidR3）の「減衰して消える設定」などが残り、ほぼ無音になっていた → 共通設定を捨てた。

## 点検の結果（問題＝7dB超の音量差、または50セント超の音程ずれ）
- 問題なし: バイオリン、ビオラ、チェロ、コントラバス、弦の合奏、トランペット、トロンボーン、チューバ、ホルン、金管の合奏、オーボエ、ファゴット、ピッコロ、オルガン、マリンバ
- 少し残る: クラリネット1件、フルート5件（ループ区間の中身による音量差。7〜15dB）、ハープ4件（最低音域）、ピアノ7件（最高音域C8付近は録音の範囲外）
- 測りにくい（打楽器は倍音が複雑なため、音程の測定が当てにならない）: ティンパニ、グロッケン。耳で確かめる

## 限界
- 強弱は2層。音の間（最大2半音）は高さをずらして補う。
- 打楽器の音程と、フルートの一部の音量は耳で確かめて、気になる音を教えてもらえれば個別に直せる。

# Naked Drums（`--drums naked` など）の鍵盤と書き方

> **調整は途中で止めた（2026-10-22、人間の判断。シンバルが不自然）**。人間「これはシンバルの音じゃないな」（`naked-punch-fs` の8ビート）「一個前の音源に戻そうか」。
> 使う音源は CrocellKit（`crocell`・`crocell-punch`）に戻した。ここの sf3・取り出しの道具・クレジットは残してあるが、音は仕上がっていない（仮）。
> 考えられる原因（未確認）: `naked-punch` 系のシンバルに、潰した部屋のマイク（ambFx の 10:1 の圧縮）を混ぜている・3.5kHz を削り高域の棚を動かしている。直すなら、シンバルは OH だけ・highpass だけにして測り直す。

2026-10-22 追加（人間「取り込んで」）。Wilkinson Audio の **Naked Drums**（Yamaha Recording Custom・22" キック・タム5つ・Sabian／Zildjian のシンバル。SFZ 化 kinwie。CC BY 4.0・**クレジット必要**）と、
Karoryfer の **Frankensnare**（いろいろなスネアの録音集。CC0）のスネアを、作曲ソフトのドラム音源にしたもの。
作曲ソフト専用（ゲーム本体 `dist/` には入れていない）。ゲームに入れるときは `docs/assets-credits.md` のクレジットを書く。

## 音源（`--drums` の値）

| `--drums` | ファイル | 中身 |
|---|---|---|
| `naked` | `drums-naked.sf3` | 素直な混ぜ方（近接マイク＋OH＋部屋 Close Room を少し）。元の SFZ の音量の補正どおり |
| `naked-punch` | `drums-naked-punch.sf3` | 乾いてパンチのある版（目標は `drum-sound-target.md`）。スネアは Naked のスネア |
| `naked-punch-fs` | `drums-naked-punch-fs.sf3` | `naked-punch` のスネアを Frankensnare の 14x8 アルミに差しかえ（強さ 118 以上はリムショット） |
| `naked-punch-stack` | `drums-naked-punch-stack.sf3` | `naked-punch` のスネアに Frankensnare の 14x8 アルミの近接マイクを重ねる |

- 作り方: `tools/soundfont/naked-extract.py`（git の中の flac から、使う打音だけを取り寄せて切り出す前処理）→ `NAKED_SAMPLES=<取り出した録音> node tools/soundfont/build-drums.mjs --kit naked`。
  取り出した録音（約100MB）は git に入れない。強さの層の選び方などの設定は `assets-src/soundfont/extra/src/naked/`（`Data/`・`extract-list.txt`・`sfz/` に元の SFZ の該当部分の写し）。
- 強さの層: Naked は元の層を全部（キック・スネア 5層、タム・ハイハット・ライド・クラッシュ・チャイナ 3層、スプラッシュ 2層、止め打ち・ペダル・ベル 1層）× 録音2つ（元はラウンドロビン10個）。
  Frankensnare の 14x8 アルミは 11層のうち6層×2、リムショットは 3層×2。

## ハイハット（2026-10-22 人間「オープンなのかクローズなのかわからない」「半開きでももう少し音伸びていい」）

- **42 はしっかり閉じた音だけ**。Naked の録音には「tight（しっかり閉じ）」と「closed（ふつうの閉じ）」があり、closed は強く叩くほど余韻が長くなる（−20dB まで 80→130ms。ゆるく閉じた音に聞こえる）。
  42 には tight（3層×2。−20dB まで 50〜65ms で、どの強さでも同じ音色）だけを入れ、強く叩いても（`X`）音色はそのまま大きくなるだけにした。closed の録音は取り出してあるが、鳴らしていない。
- 開き（46）は `O` で書いたときだけ。半開き（95）は `h` で書いたときだけ。どちらも鍵盤を離したあとも録音の「シャー」が自然に消えるまで鳴り（鍵盤を離したあと、開きは −20dB まで約 1.2 秒・半開きは約 0.8 秒かけて消える）、
  **次にクローズ（42）かペダル（44）が鳴ったときだけ止まる**（同じ exclusiveClass 1。止まり方は再生エンジン spessasynth の決まりで、約 260ms で −96dB＝約 55ms で −20dB の速さで閉じる）。
- 書き方の例: `g:X.x.h...X.x.O...`（1拍目の裏の `h` が半開きで伸び、3拍目の `X` で閉じる。`O` は次の打音まで開いて鳴る）。
- **`h` の互換**: `h` は新しく足した文字（今までのグリッドでは書けなかった）。鍵盤 95 に半開きの録音がある音源（`crocell` 系・`naked` 系）では 95 を鳴らし、
  ほかの音源（標準・muldjord・rock など）ではオープン（46）で鳴る（作曲ソフトがドラム音源を選ぶときに決める。`midi-export.ts` の `setHihatHalfKey`）。

## 強さとリムショット

- **`naked`・`naked-punch`・`naked-punch-stack` のスネアにはリムショットの録音が無い**（Naked Drums の録音はセンター打ちとクロススティックだけ）。強さ 1〜127 はすべてふつうの打ちで、5層（1〜27・28〜52・53〜77・78〜102・103〜127）×2 の録音が強さで切りかわる。
- **`naked-punch-fs` は CrocellKit と同じく、強さ 118〜127 がリムショットの録音**（Frankensnare の 14x8 アルミのリム）。1〜117 はセンター打ち（6層×2）。volume 0.18 前後の `X` はリムショットになる。ふつうの打ちにしたいときは volume 0.13 前後。

## 音作り（`naked-punch` 系。`build-drums.mjs` の `PUNCH_NAKED`）

作曲ソフトのドラムは1本の通り道を共有するので、太鼓ごとの音作りは音源に焼き込む。

- キック: Kick In 1.0 と Kick Sub 0.45。55Hz の3段のハイパスで超低音を切り、120Hz を持ち上げ 320Hz を −8dB。帯域の補正（`bandEq`）と 6:1 の圧縮、アタックの強調（最大 +6dB）、
  **録音に無い「カチッ」は合成のクリック**（3〜12kHz に絞った 15ms のノイズ。打音の山に比例。乱数は楽器と番号で決まる種でそろえる。音程は持たない）、軽いクリップ（2.5dB）。
- スネア: 550Hz を深く削り、180Hz の胴と 5k・10kHz を立たせる。帯域の補正・6:1 の圧縮・アタックの強調（+4dB）・クリップ（2dB）。
- 部屋（Close Room）: 500Hz より下と 5kHz より上を切って 10:1 で潰し、太鼓に 0.25・ハイハット 0.05・シンバル 0.1 だけ。
- 数値の合わせ方と結果は `drum-sound-target.md`。

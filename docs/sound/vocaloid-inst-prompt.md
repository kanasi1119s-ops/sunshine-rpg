# ボカロ曲インスト 制作依頼（プロ仕様）

## 0. 今回の条件（ここだけ書きかえる）
- 曲数: 【25】曲 ／ 1曲の長さ: 【4:00〜5:00】
- アルバムの合言葉: 【楽しく、明るく、自然に】
- ジャンルの配分: 【テクノポップ・ダンス・ロック・エレクトロニカ・ヒップホップ・J-POP・K-POP】
- 楽器: 決まりなし。曲に必要な楽器は、ジャンルや場面に合わせて、どんどん入れる
- 音源: 必要な音源は、確認なしで追加してよい（無料で商用利用できるものに限る。規約を確かめて記録する）
- 使わない音・NG: 【なし】
- 保存先: 【旭洋平の Google ドライブ／作曲ソフト ボカロ曲インスト25曲】

## 1. いちばん大事なこと：「ボカロ曲のインスト」に聞こえること
ふつうのインスト曲ではない。歌を抜いたボカロ曲（オフボーカル）に、歌の代わりのシンセが乗った曲。
次の6つがそろっていなければ、点数が高くてもやり直す。
1. 歌の役のシンセ（3-1）が、Aメロからサビまで歌の旋律を最初から最後まで鳴らし、いちばん前に聞こえる。
2. 速さ・密度: アルバムの7割以上がテンポ142以上。遅い曲も、16分の細かい音で速く感じさせる。
3. 音が多い: Aメロの旋律は16分が6〜8割。早口のように詰め込む。
4. 高い: サビでいちばん高い音を出す。Aメロより5〜7度高く、最高音は C6 前後。
5. ボカロらしい「歌いにくさ」: 早口の16分・急な跳躍・高い音のつなぎを、1曲に少なくとも1か所はっきり入れる。
6. 派手な展開: 全員の止め・1拍の完全な無音・転調・Half feel・サビごとのリズムの入れかえ・最後のサビ前のフィルターのうち、3つ以上を入れる。

## 2. 作曲の型（見本にして、物語ごとに崩す）
### 2-1 テンポの型（曲ごとに1つ選ぶ）
- 高速ロック 175〜210: 16分の4つ打ちロック。短調。リフが主役の場面が多い。
- 疾走ピアノ 165〜185: ピアノの16分の分散和音が走る。長調の4つのコードの循環を1曲ずっと回してよい。
- 中速ダンス 125〜150: 4つ打ちのダンスポップ。ピアノとシンセが中心で、色の多い和音。
- ハーフ 95〜110: スネアとハットは倍の 190〜220 で感じるノリ。ヒップホップ・トラップ寄り。
- テンポの変化は1曲に1〜2回まで（前奏だけゆっくりのピアノ→本編で倍以上／間奏だけ ×0.7 に落とす、など）。
- Bメロの 3/4・6/8 はアルバムの3割まで。7/8・9/8 はサビの前後の1〜2小節だけ。変拍子そのものを目的にしない。

### 2-2 コード
- Aメロ: 短調の2〜4個の循環（♭VI–V–i／i–♭III–♭VII–♭VI／i–♯iv°–V／i–♭VII–♭VI–♭II／i–♭VI–♭VII–v）。
- サビ: 平行調の長調に開く（vi–IV–V–I–V/3／IV–I–V–vi／vi–IV–I–V／IVM7–III7–vi–v）。
- 長調の曲: 4つのコードの循環（IV–I–V–vi、vi–IV–V–I など）を回し、変化は旋律・音数・強弱でつける。
- 定番だけにしない: 曲ごとに最低1か所、副属和音・増三和音・♭II・属7の半音の連鎖・vi へ入る1拍の減三和音のどれかを入れる。
- ベースは分数コードで順に動かす（V/3、vi–vi/5–I/3）。短調でも区切りの4小節に1回は長調の V を入れる。
- ピアノ主導の曲は和音の4割以上を M7・7・9・m6 に。ロック型は三和音・sus4・パワーコード。
- 転調: サビで変える（+1・+2・短3度上）／最後のサビで +1 か +2／半音ずつ2回上げる／2段（半音下げ→短3度上げ）から選ぶ。
  直前に1拍のブレイク。転調しない曲もアルバムに2割入れる。

### 2-3 歌の旋律（歌の役のシンセが弾く）
- 音域: 曲全体で2〜2.5オクターブ（A3〜C6 が中心。いちばん高い音は D6 まで）。
- Aメロ: 低め（C4〜D5）で16分を6〜8割。同じ音の連打と小さな動きで「語る」ように。拍の頭の16分前から入る音を1小節に1〜2か所。
- Bメロ: 少しずつ上げて溜める。最後の1小節は休みか、のばす音。
- サビ: 8分を中心に、付点と休符で開放感。1〜2拍の同じリズムの短い句を2〜4回くり返し、最後の2小節を上がりか下がりで締める。
  同じ音を2〜3回連打するフックを1か所以上。音程の動きの15〜25%を5度以上の跳躍に（オクターブは1つの句に1回まで）。
- 半音の経過音は1小節に1〜2回まで。
- 既存の曲の旋律に似せない（音程の並び4つが同じになったら書き直す）。メロディは「わかりやすく、頭の中で絵が浮かぶもの」にする。

### 2-4 構成と強弱
- 型の例: イントロ → Aメロ → Bメロ → サビ → 間奏 → 2番 → サビ → Cメロ（落ちサビ・Half feel）→ 最後のサビ（転調）→ アウトロ。
  4:00〜5:00 にするときは、間奏・Half feel・転調・主旋律の受け渡しで長さを作る（同じ場面をただくり返さない）。
- 強弱の地図（見本）: 2パートだけ → 全員 → Aメロで減らす → サビ直前の1小節は「ベースとシンセだけ」 → サビ → 間奏で下げる → 最後のサビ → 終わり。
  ただし強さは「区間の種類」ではなく「物語の場面」で決める。
- 止め: サビの前や場面の終わりに、全員休みを半小節〜1小節。1曲に2〜4回。1曲に1回は1拍の完全な無音。
- サビごとにリズムの型を変えてよい（1サビは4つ打ち→2サビはジャージークラブやハーフ）。和声はそのまま。
- 最後のサビの前の4〜8小節は、全体にローパスを掛けて約 800Hz から閉じ、サビの頭で一気に開く。
- 始まり方は、ドラムだけ／ピアノだけ（ゆっくり）／いきなりリフ／短いサビ、などから選び、前の曲と重ねない。
- 終わり方も、テンションつきの短い和音で切る／ピアノだけ残す／急に止める／フェードアウト、などから曲ごとに変える。

## 3. 音の作り方
### 3-1 歌の役のシンセ（声のように聞こえるリード）
- 元の音: 矩形波（デューティ 25〜50%）とパルス波の重ね。のこぎり波だけの音は避ける。
- 声の響き: 母音「あ」の響きの山を EQ で作る（約 900Hz を +6dB・約 1800Hz を +4dB、Q 4〜6）。2.8〜3.2kHz を +3dB で歌の明るさ。ハイパス 150Hz。
- 音の入り: 立ち上がりは 5〜15ms で少しやわらかく。3度以上の跳躍のときだけポルタメント 40〜80ms。
- 音程の動き: 上がる音は、目標を少し越えてから約 120ms で戻す。ビブラートは長い音の後半（音の長さの 40% より後）だけ、5.5〜6Hz・±20〜30cent。
  いきなり深く掛けない（「ゴムが伸びる」揺れは禁止）。
- 重ね: 1オクターブ下に、ローパス 2kHz に絞った同じ旋律を −8〜−10dB で重ねる。浮いて聞こえるときは、下にピアノを重ねて芯を作る。
- 刺さり対策: 高い音でもピーと耳に刺さらない。耳に痛い山は狭い Q で −6dB、5〜8kHz は必要に応じて −2〜−4dB。
- 響き: 8分か付点8分のディレイ（12〜18%）と、短いプレート系の残響。真ん中に置き、ひとつの音だけで鳴らす（モノ）。

### 3-2 伴奏
- 主旋律の受け渡し: サビは歌の役、2番の Aメロはピアノ、間奏はギターかシンセのソロ、のように最低3種類を回す（歌の役はいちばん長く鳴らす）。
- 合いの手: 各場面に最低1つ、ピアノ・ギター・オーケストラヒットなどの合いの手を、歌の旋律のすき間に入れる。ただし「削る」場面も作る。
- ピアノ: 疾走系は右手16分の分散和音・左手8分のオクターブ。中速は和音の刻み。左手と右手で弾いているように。
- ギター: 明るく歪んだパワーコードと、歌の役とぶつからない D3〜D5 の覚えやすいリフ。割れたりピーと鳴ったりしない「ラウドな透明感」。
  ブリッジミュートの刻みを曲の頭に置かない。クリーンのギターにはコーラスを掛けない。スタッター（16分か32分の2〜4回くり返し）は1曲2〜3か所まで。
- シンセ: 厚い和音（スーパーソウ）はサビだけ。プラック（鳴り始めに 20ms のピッチの動き）とアルペジオで電子の色。
- ベース: 少し大きめ。ゴリッとした響き（600Hz〜1.5kHz）と指で弾く粒（1.5〜3kHz）。根音に沿わせ、分数コードで順に動く。サビは8分のオクターブで走る。
- ドラム: 強弱・アクセント・ゴースト、タイミング ±5〜12ms の揺れ。ライド・タム・フロアタムも使う。シンバルは鳴りを伸ばす。
  バスドラムは、トリガーの音と重みのある生の音を重ねる。Half feel の区間を、間奏か2番のあとに8〜16小節。
- バンドの音: 標準は TRiDENT の音（参考の音 `--ref-tone glossy-jrock`、ドラム `--drums crocell-punch`）。
  曲やジャンルに合わなければ使わなくてよい（テクノポップ・エレクトロは電子のドラム、ローファイは素直な生ドラムなど）。
- 耳を引く音: 1曲に2〜3個、曲ごとに変える（カウベル、オーケストラヒット、一瞬のワブルベース、生の弦を突然入れる、逆再生、夏の環境音など）。
- 楽器の足し方: 場面ごとに必要な楽器を足していく。入れた楽器は雰囲気を作るので埋もれさせない。ただし、歌の役のシンセより前には出さない。
- サイドチェイン: キックでベースとパッドを下げる（4:1・アタック 3ms・リリース 100ms）。

## 4. 作る前に必ずやること
1. ジャンルの決まりごとを確かめる（ボカロの型は `docs/sound/vocaloid-study.md`。ほかのジャンルは調べて出典つきの表にする）。
2. 曲を決める表を作って見せ、承認をもらってから作る。
   列: 番号／曲名／ジャンル／テンポの型とテンポ／形（物語の言葉での骨組み）／場面と、そこで必要な強さ／旋律の性格／派手な展開／場面ごとに重ねる楽器／始まり方と終わり方
3. どの2曲を比べても、「形」「場面と強さ」「旋律の性格」の3列のうち、2列以上が違うこと。始まり方は、続く2曲で同じにしない。

## 5. ミックスと仕上げ
- 音量 −13.5 LUFS、左右の広げなし（widen 1.0）、トゥルーピーク −1dBTP 以下。
- 前奏が小さすぎないかを、3秒ごとに確かめる。
- 20Hz より下の音と直流を取りのぞく。
- パートごとに数値で整えてから、最後に全体を整える。歌の役がどの場面でも埋もれていないかを、10秒ごとに確かめる。

## 6. 確認
- 音質の点数（PQ）は 8.0 以上。10秒ごとの点数も見て、弱い場面を直す。ただし、最後は耳で判断する。
- 「ボカロ曲のインストに聞こえるか」を、1 の6項目で1曲ずつ確かめる。足りない項目があれば、点数が高くても直す。
- 似た曲がないかを、比べる道具で確かめる（旋律・リズム・構成）。

## 7. 渡し方
- mp3 を1曲ずつ、チャットで再生できる形で送る（zip にはまとめない）。
- 1曲ごとに、点数と、主な直しを1〜2行そえる。
- Google ドライブに保存する。
- 未完成の曲は「仮」と書く。

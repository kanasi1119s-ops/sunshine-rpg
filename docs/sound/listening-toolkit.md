# 音を「見る・言葉にする」道具（2026-10-14）

Claude Code は音を耳で聞けない。そこで、数字では分かりにくい音の違いを、絵と言葉にして確かめる道具を作った。**耳の代わりではなく、人間の感想と突き合わせる材料**。

| 道具 | 使い方 | 分かること |
|---|---|---|
| `tools/audio-check/see-audio.py` | `python3 tools/audio-check/see-audio.py <WAV> --start 秒 --dur 秒 --fmin 100 --fmax 1000` | スペクトログラム・ピッチ軌跡（セント）・音量の動き。ビブラートの形、ベンドの戻り、余韻が切れていないかが見える |
| `tools/audio-check/tag-audio.py` | `HF_HOME=/tmp/hf python3 tools/audio-check/tag-audio.py <WAV> --start 60 --dur 10` | CLAP（音と言葉のAI）で、「歪みギターか」「生ドラムか」などの言葉にどれだけ近いかの順位。初回だけモデル約600MB |

## 分かったこと（2026-10-14）
- 録音のギター（Gretsch）の音程はほとんど揺れない（±2セント）。「ゴム伸び」の原因は録音そのものではない。
- `~`（モジュレーションホイールのビブラート）は、音の頭の直後から、±20セント・約6.5Hz の完全に規則的な正弦波になる。人の指のビブラートは、遅れて入り、深さと速さにむらがある。この機械的な揺れが「ゴム」に聞こえる有力な原因。
- ピッチベンド（`^`）の戻しは、音の切れた直後に 0 へ戻していたため、余韻の音程が急に落ちる恐れがあった。余韻のあとまで戻しを遅らせた（`midi-export.ts` の `pendingBendReset`）。※ 絵の上では、直す前後とも切れ目に一瞬の落ち込みが出る。追跡の誤差の可能性もあり、効果は耳で確認が必要。
- ビブラート（自前のピッチベンド方式 `vibratoSpec`）は、速さ±8%・深さ±15%の、ゆっくりしたむらを足した。
- CLAP は大づかみ（歪みギター・生ドラム・ジャンル）は当てるが、リードギターの「ゴム」や、録音ドラムの違いは区別できなかった。細かい音色の良し悪しは、人間の耳が必要。

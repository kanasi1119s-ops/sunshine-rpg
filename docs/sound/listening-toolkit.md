# 音を「見る・言葉にする」道具（2026-10-14）

Claude Code は音を耳で聞けない。そこで、数字では分かりにくい音の違いを、絵と言葉にして確かめる道具を作った。**耳の代わりではなく、人間の感想と突き合わせる材料**。

| 道具 | 使い方 | 分かること |
|---|---|---|
| `tools/audio-check/see-audio.py` | `python3 tools/audio-check/see-audio.py <WAV> --start 秒 --dur 秒 --fmin 100 --fmax 1000` | スペクトログラム・ピッチ軌跡（セント）・音量の動き。ビブラートの形、ベンドの戻り、余韻が切れていないかが見える |
| `tools/audio-check/tag-audio.py` | `HF_HOME=/tmp/hf python3 tools/audio-check/tag-audio.py <WAV> --start 60 --dur 10` | CLAP（音と言葉のAI）で、「歪みギターか」「生ドラムか」などの言葉にどれだけ近いかの順位。初回だけモデル約600MB |

## 分かったこと（2026-10-14）
- 録音のギター（Gretsch）の音程はほとんど揺れない（±2セント）。「ゴム伸び」の原因は録音そのものではない。
- `~`（モジュレーションホイールのビブラート）は、音の頭の直後から、±20セント・約6.5Hz の完全に規則的な正弦波になる。人の指のビブラートは、遅れて入り、深さと速さにむらがある。この機械的な揺れが「ゴム」に聞こえる有力な原因。
- ピッチベンド（`^`）の戻しは、音の切れた直後に 0 へ戻していたため、余韻の音程が急に落ちる恐れがあった。余韻のあとまで戻しを遅らせた（`midi-export.ts` の `pendingBendReset`）。※ 絵の上では、直す前後とも切れ目に一瞬の落ち込みが出る。追跡の誤差の可能性もあり、効果は耳で確認が必要。
- ビブラート（自前のピッチベンド方式 `vibratoSpec`）は、速さ±8%・深さ±15%の、ゆっくりしたむらを足した。
- CLAP は大づかみ（歪みギター・生ドラム・ジャンル）は当てるが、リードギターの「ゴム」や、録音ドラムの違いは区別できなかった。細かい音色の良し悪しは、人間の耳が必要。

## 使い方の実例: 「ぽーん」の原因を見つけた（2026-10-14）
1. 人間が「Aメロの少しあとに『ぽーん』が鳴る」と言う → パートごとに分けて書き出し（トランペット＋弦のグループ）。
2. `see-audio.py` で、弦のパートの音に、出だしで高い音程から急に下がる曲線があると分かった。
3. 鍵ごとに出だしの音程を測る（`orchestra.sf3` を spessasynth で鳴らして測定）と、13個の楽器が同じ曲線を持っていた。
4. 楽器の中身を調べると、13個が1つの楽器データを共有していて、その中身がインパクト音だった。作り方のバグ（`banned-sounds.md` 15）。

## 音質の点数（Audiobox Aesthetics）でのトライ&エラー（2026-10-15、パンク『稲妻ダッシュ』）

`tools/audio-check/aes-score.py`（Meta の公開モデル。PQ=制作品質 1〜10）。**耳の確認ではなく目安。** 同じ曲の版どうしの比較に使う。
24通り試して PQ 6.0 → 8.05。効いた順:
1. ギターを録音ギター（`--guitar fsbs-direct`、distGuitar）に: +1.0 前後（いちばん大きい）
2. 歪みを控えめに（ampDrive 1.2 → 0.5）: +0.3
3. ドラムを下げる（-3〜-5dB）: +0.3。**ドラムを上げると下がる**（+3dB で -0.8）。人間の「ドラムが小さい」という感覚とは逆なので、最後は耳で決める
4. 中央のギター層をなくす・ギターを少し下げる: +0.2〜0.4
効かなかった: マスタリングの種類（rock-clean / rock-open）、左右の広げ、残響、ベースの種類。ドラムは muldjord がいちばん高い（rock / metal / supra は -0.1〜-0.3）。
作り方: `node tools/composer/song.mjs build assets-src/ai-songs/punk-bolt.json --wav --drums muldjord --bass pick --guitar fsbs-direct --master-preset rock-clean`

### 9点への挑戦（2026-10-15、歪みを足しながら）— 約8点で頭打ち
- ギターの歪みを 0.5→0.9 に上げても、ampTone -3（高音を少し丸める）なら 8.05→7.92 と、ほとんど下がらない。
- **点数はギターの音色にあまり反応しない。** ギターがほぼ消えた版でも 7.79、ドラムだけでも 7.65、ドラムなしでも 7.90。どの組み合わせも 7.6〜8.0 に収まる。
- 仕上げ（rock / pop）、空間の響き（--space room）、人間らしさ（human 0.5）、ハイハットやシンバルを抜く、スネアの残響（drumMix。生ドラムでは効かない様子）は、どれも +0.1 未満か下がる。
- 見立て: 今の上限（約8）を決めているのは、音量の配分ではなく **音源そのもの（ドラム・ベース・ギターの録音素材）と書き出しの音の質**。9点には、より良い録音音源やドラムの鳴らし方（ルームマイクなど）の作り込みが要る。音量の調整だけでは届かない。

### 点数の「ものさし」の確認（2026-10-15）
- 公開されているインディーロック・パンク14曲（Free Music Archive。採点だけに使い、保存していない）の PQ は **4.1〜7.4（平均約5.8）**。実際の人間のバンドの録音でも8点に届かなかった。
- Muldjord Kit の元の録音（16本のマイク）を、作曲ソフトを通さずに直接混ぜたドラムだけの演奏でも PQ 7.88。作曲ソフトを通したドラムだけの版は 7.65。
- 見立て: このモデルで **ロックの9点はかなり難しい**（実在の曲でもほぼ出ない）。今の『稲妻ダッシュ』（約8点）は、採点した実在の曲より高い。
- ドラム音源に「ラウンドロビンの代わり」（強さの層ごとに4つの別録音。`DRUM_RR=4 DRUM_Q=6 node --experimental-strip-types tools/soundfont/build-drums.mjs std`）を入れた: 7.92→7.96（わずか。点数より、同じ音の機械的なくり返しを減らす目的）。

### ポップ『夏色シグナル』でも約8点（2026-10-15）— 9点はこのモデルではほぼ出ない
- 作り方: `node tools/composer/song.mjs build assets-src/ai-songs/summer-signal.json --wav --drums jpop --bass jpop --piano salamander --orchestra vsco --guitar gretsch --master-preset jpop-band`（ドラムは生成スクリプトより -3dB。JSON に反映済み）。PQ 8.00。
- パートを絞っても（ピアノだけ 7.65、ドラムなし 7.64、ピアノ＋弦 7.71）、仕上げを外しても（7.92）、約8点で止まる。ジャンル・楽器・仕上げに関係ない共通の上限。
- 公開音楽データの人気上位60曲（全ジャンル）: 最高 8.29、平均 6.87、8.5以上 0曲、9以上 0曲。**このモデルの9点は、実在の音楽でもほぼ出ない。** 8点を超えれば上位1割。

### ギター音源の比べ（2026-10-15）
- パンク『稲妻ダッシュ』: `--guitar emily`（ハムバッカーの直接録音）8.10 ＞ fsbs-direct 7.96 ≒ shiny 7.97。**歪みギターの元の音は emily がいちばん高い。**
- ポップ『夏色シグナル』: gretsch・shiny・emily とも 8.00 前後（ギターが小さめの編曲なので差が出ない）。
- 注意: aes-tune の2並列で、作曲ソフトの作り直し（src を変えた直後）が重なると書き出しに失敗する。src や音源を変えたら、先に1回だけふつうに build してから回す。

### 録音のキャビネットIR（2026-10-15）
- 内蔵アンプ（hardrock など）にはキャビネットの段がなく、cabir もフィルターの近似だった。録音IR（David Fau Casquel、CC BY 3.0）を6つ入れ、`{"type":"cabir","ir":"dfc-…"}` で使えるようにした（名前: dfc-ampmix・dfc-ampmix2・dfc-axhom・dfc-bestplugins・dfc-bestplugins2・dfc-mixxx）。
- パンク（Emily）で: 点数はどれも 8.07〜8.10（IRなし 8.10）。点数はギターの音色にほぼ反応しない。
- 全体の音の変化（IRなしとの差、1.5〜3kHz）: bestplugins +4.1dB（いちばん「張り」が出る）・axhom +1.7（500Hz〜3kが前に出る）・bestplugins2 +2.0・mixxx +1.4・ampmix +1.0。どれが良いかは耳で決める。

# ジャズの演奏・ミックスの調べもの（2026-10-27）

BARジャズ50曲を作る前に、人間（旭さん）の依頼で調べた内容です。【出】は出典のページで確認できたこと、【目安】は一般的な補足で未確認です。数値は目安で、最後は耳で決めます。

## 1. 演奏の心がけ（楽器ごと）

### ウッドベース
- 4拍に1音ずつ弾く。各コードの1拍目は根音、2・3拍目はコードトーンかスケールの音、4拍目は次の根音への半音のアプローチ【出】
- 同じ音形をつづけない。上がるだけ・下がるだけにしない【出】。音域は1オクターブ半ほど、4〜8小節ごとに山と谷【目安】
- 音の長さは8〜9割。ゴーストノートは弱い短い音で、1小節に0〜1回【目安】。ブリッジ寄りは締まった音、ネック寄りは温かい音【出】
- テーマは2フィール（2分音符）、ソロは4に切りかえる【出】

### ドラム
- ライドは4分音符＋2・4拍の3連のスキップ。4分は同じ強さ、スキップは強調しない（4分の7割ほど）【出・目安】
- ハイハットのペダルは2・4拍。フェザリングのキックは、ほとんど聞こえない小ささの4分音符【出】
- コンピング（スネアとバスドラの合いの手）は、ライドの下で、簡単なシンコペーションから。ゴーストはスネアの強い音の25〜40%【出・目安】
- ドミナントでは密に、トニックでは空ける。ソロの後ろでは短いフレーズで答える。ピアノのリズムと重ねない【出】
- ブラシは横にこするスイープで、のびた音【出】

### ピアノ
- ルートレス。左手で 3-5-7-9（A形）と 7-9-3-5（B形）を交互に使い、大きく跳ばない【出】。シェル（根音・3度・7度）も使う【出】
- コンピングは「全拍→8分前の先取り→チャールストン（付点4分＋8分）→2・4拍の裏の短い先取り」の順に自由に。休符も音のうち【出】
- 1小節の打鍵は2〜4回【目安】。ホーンや歌の後ろでは弱く【出】
- バラードは1音ずつ味わい、内声を少しだけ動かす【出】

### ギター
- フレディ・グリーン式: 4拍すべてに和音。1・3拍は長め、2・4拍は左手の力を抜いて短く、少し強く。ダウンストロークだけ。6・4・3弦の3音が基本【出】
- 音量は「聞こえるのでなく感じる」くらい。アーチトップのネックピックアップ、トーンは暗め【出】
- ウェス式: 親指で弾く。単音→オクターブ→和音の順に盛り上げる【出】

### サックス・管
- 8分は3連寄りの長短。遅いほど差が大きく（約3.5:1）、速いほど均等に近づく【出】。裏拍は軽く舌で突く【出】
- ゴーストは音の長さを保ったまま、ほとんど無音で吹く。スクープは短く浅く【出】
- ジャズのビブラートはクラシックより遅い【出】。ビブラートは長い音の後半から入れ、速く細かい揺れはしない（人間の「ゴムが伸びる音」の苦手に合わせた【目安】）
- トランペット（ハーマンミュート）は強く吹いても小さく鋭い音で、ほぼストレート。マイルスはビブラートをほとんど使わなかった【出】
- バラードは息を音色の一部にして、フレーズごとに1〜2拍の休符【出・目安】
- ビブラフォンはペダルで鳴りつづけ、和音の変わり目で止める。次の音を鳴らす瞬間に前の音を止める【出】

### メロディ
- 短い動機から広げる（A → A+B → A+C）。短い・短い・長いの順。休符は思うより長く【出】
- 外した音は数小節だけ。外したら和音の中の音に戻して休む【出】
- フレーズごとに高音の頂点は1か所。曲全体で同じ形を続けない【目安】

## 2. アンサンブルと空気
- 一番小さい楽器に合わせて全体を決める。大きく鳴らして、すっと引く幅を持つ【出】
- 休符を音と同じ重さで置く（マイルス: 「そこにあるものを弾くな。そこにないものを弾け」）【出】
- 互いを聴いて、ソロのあいだはピアノのコンピングとドラムのフィルを引っ込める【出】
- 形は「テーマ→ソロ→テーマ」。2度目のテーマは音量・装飾・厚みを変える。イントロはヴァンプやターンアラウンド、エンディングはタグなどから曲ごとに選ぶ【出】
- ルバートはバラードとイントロ・アウトロで。内側の拍は保つ【出】。ネオソウルは格子から少し外す【出】
- ECM系は空間と透明感、クールは控えめ、ハードバップは推進力【出】
- 一音ごとに意味を持たせる（マイルス: 「どんなに小さく弱い音でも、むだにしない」）【出】

## 3. ミックスと音作り
- ウッドベース: 50Hz以下を切る。220〜300Hzで厚み、5kHz付近を+2dBで指の立ち上がり。ブーミーな150Hz以下は抑える【出】。パラレルコンプ 2:1【出】
- ドラム: ブラシのときはオーバーヘッドを下げ、近接マイクを少し足す【出】。オーバーヘッドの5kHz以上を軽く圧縮してスティックの硬さを抑える【出】
- ピアノ: 3:1・アタック5ms・リリース50ms・約5dB圧縮、300〜600Hzを少し削る【出】
- ギター: ネックピックアップ、トーンを絞り、リバーブは少なめ。200Hzと400Hzが肝【出】。ハイカット6〜8kHz【目安】
- サックス: 100Hz以下カット、300Hz −3dB、700Hz +1dB、1.5kHz −2dB、2kHz +4dB【出】
- 空間: 残響約1.5〜3秒、プリディレイ10〜30ms、200Hz以下はリバーブに送らない【出】
- パン: オーバーヘッド±50%、ベースは中央やや右20%、ピアノは音域で左右に広げる【出】
- ラウドネス: ジャズ・アコースティックは約 −16 LUFS 以下、ピークは −1dBTP 以下【出】

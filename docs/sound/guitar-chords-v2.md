# ギターの和音の弾き方（作り直し・2026-11-19）

人間の言葉（21 v5 を聞いて）: 「ギター和音で弾いてないよね？弾くとしたら今までの和音の弾き方を忘れて、一から作り直して欲しい」

部品は `assets-src/ai-songs/_gen/gtr2_lib.py`。今までの部品（`vocalo_lib.gtr_strum`・`gtr_shape`）は、新しい曲では使わない。

## 今までの部品の、どこが悪かったか（測って確かめた）

- 21 では 左のギターが `strings=3`＝根音・5度・オクターブ の3本だけ。和音が長調か短調かを決める **3度の音が入っていなかった**。
- 試しに8つの和音（Bm・G・D・A・Em7・F#m・Asus4・D）をギターだけで書き出し、音から「どの和音に聞こえるか」を測った（`tools/vt3/chord_heard.py`）:

| 弾き方 | 和音どおりに聞こえた数 | 3度の強さ（根音・5度の強い方を 1 として） |
|---|---|---|
| 今まで（左3本・右4本） | 3／8（Bm・D・A は「B5・D5・A5」＝3度のない音に聞こえた） | 0.39 |
| 新しい弾き方（左＝根音・5度・オクターブ、右＝三和音） | 6／8 | 0.49 |
| **新しい弾き方（左＝10度の3度まで入れる4本、右＝三和音）← 採用** | **8／8** | **0.71** |
| 上と同じで、右の歪みを 0.6 倍 | 7／8 | 0.66 |

## 調べた事（出どころ）

- 歪みが強いと、3度が入った大きな和音はにごる。だから根音と5度だけの形がよく使われるが、それは和音の性格（長調・短調）を持たない。<https://violetrecording.com/what-are-power-chords/>
- 歪んだ音では、6本全部の形ではなく、2〜4本に切りつめた形を使う。<https://www.fretjam.com/metal-guitar-chords.html>
- まん中の弦の小さな三和音に置きかえる弾き方。<https://happybluesman.com/jimi-hendrix-rhythm-guitar-3-steps-mix-rhythm-and-lead/>
- 左右に重ねるギターは、同じ和音を別の形（転回形）で弾くと、ひろがって聞こえる。<https://www.musicradar.com/tuition/guitars/how-to-record-huge-guitars-27-secrets-revealed-618727>
- 低い側を重ねたあと、低い音のない転回形を重ねる。<https://www.uaudio.com/blogs/ua/studio-basics-layering-guitars>
- 16分のかき鳴らしは、手を下・上に振りつづけ、拍の頭と「と」がダウン、そのあいだがアップ。<https://www.guitarworld.com/lessons/improve-your-rhythm-guitar-strumming>
- ピックが弦をわたるので、和音の音は同時には鳴らない（少しずつずらす）。<https://splice.com/blog/make-guitar-patterns>

## 新しい部品のしくみ

1. **押さえ方は指板の上でさがす。** 6本の弦（E2 A2 D3 G3 B3 E4）とフレットで、その和音の音だけを使い、指のとどく幅（3フレット）に入る形をぜんぶ出して、いちばんよい物をえらぶ。
   - `low_shape`: いちばん下が根音。根音・5度・オクターブ・1オクターブ上の3度（10度。根音からはなれているので、歪んでもにごりにくい）
   - `triad`: まん中の弦（5〜3弦か 4〜2弦）の三和音。**前の和音の形にいちばん近い転回形へ動く**（指が少ししか動かない）。いちばん上の音は B3〜F#4
   - `open_shape`: 生のギター用。開放弦も使う 4〜6本の形。同じ高さの音が2本ならぶ形はさける
2. **左右は別の形。** 左＝`low_shape`、右＝`triad`。
3. **かき鳴らしの型は手の向きで書く。** `D d`＝ダウン、`U u`＝アップ、`-`＝鳴らしたまま、`.`＝止める。16分のマスの 0・2 番めはダウン、1・3 番めはアップ。向きが合わない型は、まちがいとして止まる。
4. **ダウンは低い弦から、アップは高い弦から。** アップは高い側の 2〜3本だけ。1回のストロークが弦をわたる時間は、強い時 12〜18 ミリ秒、弱い時 18〜28 ミリ秒。最初に当たる弦がいちばん強い。
5. **弦ごとに鳴りつづける。** その弦が次に弾かれるか、和音が変わるか、止める（`.`）まで鳴る（今までは、全部の弦を次のストロークで切っていた）。

## 使い方

```python
import gtr2_lib as G2
SL, SR = G2.Strummer(GL, S, 11), G2.Strummer(GR, S, 12)      # GL・GR は同じ設定のパートを6本ずつ（弦1本ずつ）
tri = None
for b in ...:
    tri = G2.triad(chord, tri)
    SL.bar(b, "D-----d-D---d---", G2.low_shape(chord))
    SR.bar(b, "D-dU-UD-D-dU-Ud-", tri)
SL.end(S.nb); SR.end(S.nb)
# JSON を書いたあと:  SL.velocity(js); SR.velocity(js)
```

確かめ方: `tools/vt3/gtr_chord_test.py`（ギターだけの試しの曲を書く）→ `node tools/composer/song.mjs build … --wav` → `python3 tools/vt3/chord_heard.py <wav>`。

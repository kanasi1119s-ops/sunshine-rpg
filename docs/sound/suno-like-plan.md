## 方針
- 今の「設計図（音符）を録音音源で鳴らす」方式は、音の上限が決まっている（歌なし・楽器の生々しさに限界）。
- 音そのものを生成するオープンソースのAIモデルを、作曲ソフトに「AI生成モード」として並べて足す。既存の曲・既存のモードは壊さない（CLAUDE.md 1-7）。

## 候補: ACE-Step 1.5（確認済みの事実。公式の README と LICENSE、Hugging Face のモデルカードを2026-10-13に確認）
- ライセンス: **MIT**（リポジトリの LICENSE も MIT）。モデルカードに「生成した音楽を商用に使える」と明記。
- 学習データ: 公式の説明では、許諾済みの曲・パブリックドメイン/著作権フリー・MIDIから作った合成音のみ。

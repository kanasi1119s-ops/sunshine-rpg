# 構成作家役の学習メモ（2026-10-02）
**注意**: 検索結果の要約が中心（本文を読めたページはほぼない）。「一般」「提案」「補」は出典で確かめていない一般的な目安。数値は出発点で、最後は耳（と人間の確認）で決める。既存曲の旋律・曲名は例に使わない（`CLAUDE.md` 1-1）。

## 原則
1. 物語の**感情曲線を先に決め**、曲はその部品にする。場面ごとに「緊張度」を0〜5で置き、曲順の山と谷を設計（谷を作ると山が効く。一般）。
2. 主題は少なく、**3系統**（主役の主題・土地の主題・敵や謎の主題）程度に（一般）。
3. **主題の変奏は物語の変化と対応させる**（意味のない変奏は飾り。一般）。
4. ループ前提: イントロ4〜8小節、メインループ8〜16小節が目安。終わりに残響が消える余白を4小節ほど取る／残響の尾を先頭に重ねる。
5. 緊張は積み上げて解放: 音域を上げる・楽器を足す・リズムを細かく・和声の解決を先送り・解放の直前に1〜2拍の休符（静寂）。
6. 場面転換は短い音（スティンガー）とクロスフェードで橋渡し。

## 変奏技法（作り方と物語上の意味）
| 技法 | 作り方 | 意味の例 |
|---|---|---|
| 旋法変更 | 長調↔平行短調 | 喜びが悲しみに／希望の回復 |
| テンポ | 速く／遅く | 焦り／回想 |
| リズム | 拍子や音価を変える | 性格の変化／敵側にされた主題 |
| 編成 | 楽器を替える | 場所・時代・規模の変化 |
| 和声 | 同じ旋律に別の和音 | 意味の反転／謎めいた雰囲気 |
| 断片化 | 核の2〜3音だけ残す | 記憶の欠落／予感 |
| 拡大 | 音価を2倍など | 荘厳／決意 |
| 縮小 | 音符を短く | 切迫／戦い |
| 反行 | 上がる音を下がる音に（鏡像） | 裏の顔／鏡写しの敵 |
| 逆行 | 旋律を後ろから | 時間が戻る／真相の逆転 |
| 移調 | 高さをずらす | 盛り上がりの段階づけ |
- **手順（一般）**: ①主題の「骨格」（音程の特徴とリズムの特徴のうち変えない部分）を決める ②変える要素は1回に1〜2個 ③骨格の音は拍の頭など目立つ位置に残す ④伴奏・楽器は大きく変えてよいが旋律の最初の3音は残す ⑤元の主題と続けて聴き比べ、同じ主題と分かるか確認。

## 構成表（キューシート／フォームチャート）テンプレ（架空の例）
- **曲ヘッダ**: 曲ID／仮題｜使う場面｜緊張度｜テンポ／拍子／調｜使う主題｜形式（例: イントロ＋ABAC ループ）｜編成｜ループ（総小節・ループ位置）｜状態（仮／完成）
- **フォームチャート**: 小節 | 区間 | 緊張度 | 内容。例: 1〜4 イントロ 0→1 笛が単音で入る／5〜12 A 1 主題の提示 4+4／13〜20 B 2 別の旋律・楽器を1つ追加／21〜28 A' 1 主題の再現・伴奏だけ変える／29〜32 C（つなぎ）ループ戻りの導入・残響の余白
- **遷移・仕掛け欄**: 入り（町の曲からクロスフェード2秒）／出し（戦闘へはスティンガー1小節）／伏線（20小節目に敵の主題の断片を低音で1回だけ）
- **確認**: ループの継ぎ目で音が途切れないか／最後の和音の残響は処理したか／拍が合うか

## 場面タイプ別の構成の型
- 形式: 二部形式 AB／三部形式 ABA／ロンド ABACA／変奏曲形式。
- **フィールド／町**: イントロ＋ABAC ループ、緊張度1〜2、A に主題。
- **ダンジョン**: 短い動機（2〜4小節）の反復、断片化と低音の持続音。
- **通常戦闘**: イントロなしですぐ始め、AB の2部形式16小節ほどをループ。
- **ボス**: イントロ→複数のループ区間（フェーズごと）→遷移音→アウトロ。段階が進むたびに楽器を足す・調を上げる・テンポを上げる・合唱を入れる、のうち1〜2つ。最終段階で主人公の主題を戦闘用に変奏して重ねる。
- **悲しい場面**: 主題を遅く短調に、拡大。
- **謎解き・真相**: 主題を反行や逆行で、断片から少しずつ全体が見える形に。
- **エンディング**: 変奏曲形式かロンドで旅の主題を順に回収し、最後は原形に戻す。
- **適応型**: 縦割り（層を足し引き）は曲数が少なくて済む（提案）。横割りは小節の区切りで切り替える。スティンガーは短い合図で環境音楽の上に重ねる。

## 本プロジェクトへの当てはめ案
1. 「章×場面×緊張度」の**音楽設計表**を1枚作り、tracks.md の曲一覧と対応づける。
2. **主題台帳**（伏線台帳の音楽版）: 各主題の骨格・意味・登場する曲・変奏の種類を記録。主題は3系統程度。前の章の主題は後の章で変奏して再登場させ、位置を台帳に書く。
3. **音による伏線**: 敵や真相の主題の断片を早い章で低音・小さな音量で1回だけ入れ、真相の章で完全な形で鳴らす。伏線台帳に「音の伏線」として記録。
4. 曲ごとに構成表（上）を、曲を書く前の下書きにする。
5. ボス戦は最低2段構成（前半・後半でループ区間を分け、遷移に1小節のスティンガー）。
6. エンディングは各章の主題を順に変奏して回収。裏ボスは主題を反行などで歪めた形で。
7. 実施するなら docs/decisions.md に記録。

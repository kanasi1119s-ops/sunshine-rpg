# アレンジャー役の学習メモ（2026-10-02）
**注意**: 検索結果の要約が中心（本文を読めたページはほぼない）。「一般」「提案」「補」は出典で確かめていない一般的な目安。数値は出発点で、最後は耳（と人間の確認）で決める。既存曲の旋律・曲名は例に使わない（`CLAUDE.md` 1-1）。

## 工程と原則
工程: ①曲の分析（旋律・和声・リズム・構成）→ ②リズムセクション（ドラム・ベース・リズム楽器）→ ③ハーモニー（コード楽器・パッド・弦）→ ④メロディと対旋律（主役を決め、隙間に副旋律）→ ⑤装飾（フィル・きらめき・効果）→ ⑥引き算と密度の調整。
- **引き算の編曲**: 全部入りの4・8・16小節ループ（最大密度、多くは最後のサビ）を先に作り、各セクションで要素を抜いて起伏を作る。足し続けると濃くなりすぎる。
- Aメロは薄く、サビは厚く。ダブルトラックやパッドでセクションごとに質感を変える。
- 主役は1つ。低域＝ベース、中域＝コード、高域＝メロディと分け、同じ帯域を重ねない。
- ブラスは最上声が旋律になる（上に旋律、下に和声）。

## 楽器別パターン集（汎用の型。4/4、16分グリッドは「x...」）
- **ドラム（ロック）**: kick x...|..x.|x...|..x.、snare 2・4拍、hihat 8分で表拍を強く裏拍を弱く。4・8小節ごとにタムかスネアの16分連打でフィル、直後にクラッシュ。
- **ドラム（ダンス）**: kick 毎拍、hihat 裏拍 R:0.5 x:0.5、clap 2・4拍。8小節ごとにキックを抜くブレイクを作り、スネアの16分連打で戻す。
- **ベース**: 根音＋5度＋オクターブ（C2:1 G2:1 C3:1 G2:1）／8分刻み（ロック・ダンス）／小節末に次の根音へ向かう経過音／キックに合わせて重要な音を置き拍間で動かす。
- **ギター**: カッティングは短く（sustain 0.3〜0.6）16分で裏を強調／アルペジオ 根-5-上の根-5／リフは根音中心の2小節を反復／歪みの刻みは8分の根音ミュートで左右に振る。
- **ピアノ・キーボード**: 左手にオクターブ低音・右手にシンコペーションのコード／バラードは分散和音／ジャズのコンピングは予測しにくい間隔で和音を叩く／4分刻みや裏打ちのスタッカート。
- **ストリングス**: ロングトーン（和音の3度・5度を各パートで）／8分・16分の刻み（オスティナート）／サビ前の上昇ライン／空いた隙間に旋律と逆向きの対旋律。
- **ブラス**: スタブ（短く強い音）で句の切れ目や拍頭を突く／ファンファーレ（5音程度の簡素な旋律）／2度を含む和声は厚い／弱い音から強い音へのクレッシェンド。
- **ユニゾン・オクターブ重ね・ハモリ**: 同じ旋律を1オクターブ上下に重ねると太くなる／3度・6度のハモリは旋律の下に／音域が離れすぎないように。
- **リハーモナイズ**: 2周目は借用和音・7th・代理コードに替えて変化を出す（旋律の強拍の音が不協和にならないか確認）。
- **イントロ・間奏・アウトロ**: イントロは少ない楽器で小さく始めサビの素材の一部を先に見せる／間奏は旋律楽器を替える（ギター→ブラス→ピアノなど）／アウトロは楽器を順に抜くかリフを反復して終わる。

## ジャンル別の編成表
| ジャンル | リズム | 和声 | 旋律・装飾 |
|---|---|---|---|
| ロック | drums、bass、distGuitar 2本（左右） | crunch、keys | leadGuitar、必要なら strings |
| ダンス | 4つ打ち drums、sub808かシンセベース | pad、keys、アルペジオ | lead、bell、ブレイクとビルド |
| ポップス | drums、bass | piano、guitar、strings | 歌メロ（lead か piano）、対旋律に strings |
| オーケストラ | tom（ティンパニ代用）、低弦 | strings、choir、harp | brass、木管系 |
| ジャズ | ウォーキングベース、ライド風 hihat | piano（7thコンピング）、guitar | brass、リード |
| フォーク | guitar ストローク、軽い percussion | banjo、guitar | fiddle、ocarina など |
- ロック×ダンスの融合: 4つ打ち（かそれに近いビート）に、歪みギターのリフ・シンセ・ドラムマシンを併用。オフビートのコードを乗せ、ベースはキックに揃える。

## セクション別の密度設計表
| セクション | 密度 | 構成の目安 |
|---|---|---|
| イントロ | 低 | 1〜3パート（リフ・パッド・鐘など） |
| Aメロ | 低〜中 | drums（軽め）・bass・コード1〜2・旋律 |
| Bメロ | 中、上昇 | ストリングスの刻みを追加、ハイハットを細かく |
| サビ | 高 | 全パート。旋律の音域を上げ、対旋律と重ねを足す |
| 間奏 | 中 | 別の旋律楽器に交代。ドラムを一部抜く |
| ブレイク | 最低 | ドラムと歪みを止め、パッドと旋律だけ |
| ラストサビ | 最大 | 全パート＋オクターブ重ね、ブラスのスタブ |
| アウトロ | 高→低 | 楽器を順に抜いて終える |

## ありがちな失敗と直し方
- 全パートが鳴り続けて平坦 → 全部入りから引き算し、サビ前に一度止める。
- 音域がぶつかって濁る → 低域の重なりを避け、和音楽器は1オクターブ上げるか音数を減らす。
- 歪みギターで音割れ → volume を小さくし、厚みは弦・合唱・ブラスで足す。
- ベタ打ちで機械的 → 強弱（velocity 65〜95、アクセント100以上、ゴースト35〜50）、5〜15msのずれ。本プロジェクトでは volume・push・swing・o（弱）・X（強）で代替。
- 弦・ブラスが作り物っぽい → 音の始まりと終わりに強弱、同じ音量の連続を避け、弦は表拍を強め裏拍を弱く。
- 旋律と対旋律が同時に動く → 旋律が休むところに対旋律を置く。
- 終わり方が唐突 → アウトロで要素を順に抜く。

## 本プロジェクトへの当てはめ案
- AIソング形式は1パート同時1音、`song_guide` の記載は1〜8パート（実際には16パートでも動いた）。自動伴奏（autoAccompaniment と feel）でドラム・ベース・ギター・ピアノ・弦が別に付く。足りない役だけ自分で書く。
- 和音は複数パートに分ける（strings 3本で根・3度・5度のロングトーン、または pad＋choir）。
- 8パートの例: kick／snare＋hihat／bass／和声2（guitar と keys、pan ±0.9）／strings（対旋律）／主旋律（lead か piano）／装飾（bell など）。
- 密度は全パートの notes に R を入れてセクションごとに出入りさせる。サビ前に全体を止める。
- 音量: メロディ0.22〜0.3、伴奏0.1〜0.2、歪みギター0.05〜0.1、合計0.7前後まで。
- ステレオ: kick・bass・旋律は中央、和声楽器と弦・パッドは左右に大きく。
- 生っぽさ: swing（ロック・ダンス0、ジャズ0.5〜0.7）、push（スネア少し遅く、ハイハット少し前）、X/x/o の書き分け。
- GMの重ね方: ピアノ＋弦、ベル＋ハープのように「立ち上がりの鋭い音」と「伸びる音」を組み合わせる。同じ音域に複数を置かない。

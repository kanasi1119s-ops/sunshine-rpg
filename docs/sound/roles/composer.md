# 作曲家役の学習メモ（2026-10-02）
**注意**: 検索結果の要約が中心（本文を読めたページはほぼない）。「一般」「提案」「補」は出典で確かめていない一般的な目安。数値は出発点で、最後は耳（と人間の確認）で決める。既存曲の旋律・曲名は例に使わない（`CLAUDE.md` 1-1）。

## 原則
1. 短い動機（2〜5音）を核にし、変形しながら長くする。変形は 移高・反行・逆行・拡大・縮小・断片化。**シークエンス**は動機を移高して繰り返す技法。
2. 8小節は「問いと答え」で組む。**ピリオド**＝先行句4小節（半終止などの弱い終わり）＋後続句4小節（完全正格終止などの強い終わり）。**センテンス**＝提示（動機を出してそのまま繰り返す）4小節＋展開4小節（断片化・シークエンス・リズムの細分化・和声の動きの加速で勢いをつける）。
3. 覚えやすい旋律は、短い断片の反復に少しの変化を足したもの。サビは動きが少なくて歌いやすく、全体の音域は1オクターブ半以内。
4. 二声の対位法では、完全5度・完全8度の平行を避ける（二声が一体に聞こえて独立性を損なう）。反進行を優先し、動きの種類を混ぜる。
5. カウンターメロディは、主旋律が動くところで休み、休むところで動く。主旋律が上がれば下げる。音域を離す。単独でも旋律として成り立たせる。
6. 制約はスランプ対策になる（使う音階・拍子・楽器・音数を絞る）。

## 技法ごとの手順と小さな例（音は「音名:拍」、R は休符。例は作例で既存曲ではない）
- **動機の発展（Aマイナー）**: 動機M = A4:1 C5:0.5 B4:0.5 A4:2。移高（2度下）= G4:1 B4:0.5 A4:0.5 G4:2／反行 = A4:1 F4:0.5 G4:0.5 A4:2／縮小 = A4:0.5 C5:0.25 B4:0.25 A4:1／断片化 = 「A4:1 C5:0.5」を2度ずつ上げて3回続け、最後にE5で止める。**変形は1回に1要素だけ**（音高とリズムを同時に変えると別の曲になる）。
- **問いと答え（8小節、Cメジャー）**: 先行句 = C5:1 E5:1 D5:1 R:1 / E5:1 G5:1 F5:2 / E5:1 D5:1 C5:1 D5:1 / D5:4（Vの上で止める＝半終止）。後続句 = 先行句の1〜2小節をそのまま使い、3〜4小節で変える: E5:1 D5:1 C5:1 B4:1 / C5:4（Iで終わる＝正格終止）。先頭の2小節を共通にし、終わりだけ変える。
- **非和声音（コードC）**: 経過音 E5→D5→C5（Dは弱拍）／刺繍音 C5→D5→C5／倚音 A4:1 → G4:1（強拍に置き、逆向きにステップで解決）／掛留 C5:2（次の和音へタイで持ち越し）→B4:2／先取音 G4:0.5 をGコードの前に。**原則: 強拍には和声音、非和声音は弱拍、解決は必ずステップ**。
- **二声の対位法（Cメジャー）**: 低声 C3:1 D3:1 E3:1 F3:1／高声（反進行）G4:1 F4:1 E4:1 D4:1。3度と6度を中心に。5度・8度に着くときは反進行か斜進行で入る（低声C→Dのとき高声がG→Aだと平行になるので避ける）。
- **カウンターメロディ（Aマイナー）**: 主旋律 A4:4 | G4:4／対旋律 C4:0.5 D4:0.5 E4:0.5 F4:0.5 E4:1 R:1 | D4:0.5 E4:0.5 D4:0.5 C4:0.5 B3:2。両方が同時に動いたら、次の拍でどちらかを止める。
- **機能和声と終止**: T→SD→D→T。正格終止 V→I／変格 IV→I／偽終止 V→vi／半終止 Vで終わる。Aマイナー: Am–F–Dm–E7–Am（正格）、Am–Dm–E–E（半終止）、E–F（偽終止）。マイナーの終止のVは導音G#を使った長三和音。Cメジャー: C–F–G–C（正格）、C–F–C（変格）、G–Am（偽終止）。ドミナントの装飾: Gの前にD7（ドミナントのドミナント）、G7の前にDm7、Gの前にC/G。
- **転調**: ピボット（共通和音）が基本。例: Cの C–Am–Dm–G7 を、Gメジャーで Am（ii）–D7（V）–G（I）と読み替える（Amが橋）。直接転調は最後のサビで半音か全音上げるときに。行き先は長調なら属調・平行調、短調なら平行長調。
- **リズム**: シンコペーション（例 R:0.5 E5:1 E5:1 E5:1.5）／ヘミオラ（3拍子の2小節を「2拍×3」に組み替える）／付点（1.5+0.5 は行進曲や勇ましい曲）／3連（1/3拍は避け、2/3+1/3 などに近似）。**1曲で使うリズムの型は2〜3種類**、動機に1つ固定。
- **スケッチから拡大（4→8→16小節）**: ①4小節の動機（M＋その移高）②8小節＝4小節を繰り返し後半を変える（ピリオド）③16小節＝8小節を繰り返し後半8小節に山場（最高音と音価の細分化）を置き最後に正格終止。または ABA' で中間部8小節は別の調（平行調など）。

## チェックリスト
- 動機は2〜5音で、一度に1要素だけ変形したか／4小節ごとに終止（半終止か正格終止）を置いたか／最高音は1〜2回、音域は1オクターブ半以内か／強拍は和声音か、非和声音は弱拍でステップ解決か／主旋律と対旋律・ベースの間に完全5度・8度の平行がないか／主旋律が動くところで対旋律が休んでいるか／終止でベースが根音位置か（偽終止は途中だけ）／転調の橋になる和音を置いたか／リズムの型は3種類以内か／既存曲に似ていないか。

## ありがちな失敗と直し方
- 同じ動機の機械的なコピー → 3回目で必ず1要素を変える。
- 旋律が上下だけで平坦 → 3度か4度の跳躍を1か所、跳躍の後は逆方向のステップで戻す。
- 音が詰まって聞こえる → 休符を入れ、フレーズの終わりに長い音を置く。
- 終止がどこにもない → 4小節ごとに半終止、8小節で正格終止。
- 対旋律が主旋律と同じリズム → 主旋律の長い音のところで動かし、音域を3度以上離す。
- 5度の平行 → 片方の声を逆に動かすか保持音（斜進行）にする。
- 転調が唐突 → 橋の和音を一つ入れる、または意図的な直接転調としてサビ頭に置く。
- 同じ終止ばかり → 偽終止や変格終止を混ぜる。

## 本プロジェクトへの当てはめ案（AIソング形式: 1パート同時1音）
1. 和音はアルペジオで書く（C:0.5 E:0.5 G:0.5 E:0.5）か、パートを分ける。ベース・リズム・主旋律・対旋律で最低4パート。
2. 5度・8度の平行は、旋律パートとベースパートの音名を拍ごとに並べて確認（`score-check.mjs` が拍の頭で判定する）。
3. 手順: スケッチ4小節 → 8小節（問いと答え）→ 16小節（山場と終止）→ パート追加（ベース→対旋律→リズム）。
4. 最初に制約を3つ決める（調・拍子・リズム型）。スランプのときは制約を足すか、動機を反行にしてから進める。
5. **類似を避ける手順**: 特定の既存曲を思い浮かべながら書かない（出発点は場面の説明と、動機の「音の数とリズム」だけ）／動機は先にランダムな制約で作る（例: 音は3つ、最初の跳躍は4度、リズムは付点を1回）／コード進行は機能和声の型（T-SD-D-T）だけを使い、よくある進行を丸ごとコピーしない（1か所は偽終止か転調で変化）／完成後に、有名曲と冒頭の6音の音程の並びが一致しないか確かめ、似ていたら音程を1つ変えるかリズムを変える／曲の由来（動機の作り方・制約）を tracks.md に記録して独自性の根拠を残す。
6. ジャンル別の目安（経験則）: ロック＝パワーコードと刻むリズム／ダンス＝4つ打ちと短い反復フレーズ／RPGのフィールド＝長いフレーズと広い音域／オーケストラ＝複数の旋律を重ねて音域を離す／戦闘曲＝リズムの推進力と覚えやすい旋律。

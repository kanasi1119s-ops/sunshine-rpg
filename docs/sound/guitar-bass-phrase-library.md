# ギターとベースのフレーズのライブラリ（2026-10-22）

人間の依頼「ギターとベースも1000通りぐらいおねがいしたい」（ドラムのフレーズ1000通りと同じ日）。
曲づくりで「リフ・バッキング・分散和音・リードの短い句・ベースライン」を、条件で選んでそのまま使えるようにした型の集まりです。

**大前提（CLAUDE.md 1-1）**: 既存の曲のリフ・旋律・ベースラインは写していない。市販曲を元にしたデータ（Lakh MIDI・Slakh・DadaGP など）は使っていない。
自作の型は、一般的な技法（`docs/sound/modern-loud-rock/vocabulary.md` 3〜5章、`arrangement-detail.md` 3〜4章、`bassline-guide.md`、`bass-melody-guide.md`）を組み合わせて機械で作ったもの。

## 1. 型の書き方（度数で書く＝キーを変えて使える）

```json
{"id":"gr0497","inst":"guitar","role":"リフ","kind":"リフ（付点）","sections":["前奏","Aメロ","Bメロ","看板リフ"],"energy":0.546,"feel":"ふつう",
 "chug":0.0,"bars":4,"fits":["m","m7","5"],"scale":"aeolian","range":[0,24],"ref":"low","rel":"bar","tech":["オクターブ","付点","休み","伸ばす"],
 "pc":true,"family":"gr123","src":"gen","ev":[[0,9,[0,7,12],"!"],[9,9,[8,15,20],"!"], ...]}
```

- **時間**: 1拍＝12刻み、1小節（4/4）＝48刻み（16分＝3、8分の3連＝4、4分の3連＝8）。`ev` の1つ＝`[始まり, 長さ, 音, 印]`。書いていない所は休み。
- **音**: 根音からの半音の数。和音は複数（`[0,7,12]`＝パワーコード、`[x, x+12]`＝オクターブ）。
  - 根音の高さ＝その小節の和音の根音を `ref` 以上でいちばん低い所に置いた音。`ref` は ギターのリフ・バッキング＝`low`（いちばん低い弦。ドロップDなら D2）、分散和音＝E3、自作のリード＝C4、実演＝E2、ベース＝E1。
  - `rel: "bar"`＝小節ごとにその小節の根音から数える／`rel: "first"`＝1小節目の根音から数えたまま（ベースのペダル、リードの線）。
  - ベースだけ: `"N"`＝次の小節の根音、`"N-1"`・`"N+1"`・`"N-2"`・`"N+2"`＝半音・全音で近づく、`"N-5"`＝次の根音の5度下から、`"N+11"`・`"N+13"`・`"N+10"`＝1オクターブ上の根音へ近づく。`"x"`＝デッドノート（ゴースト）。
- **印**（作曲ソフトの記号のまま）: `!` 強く・`,` 弱く・`,,` もっと弱く・`'` 短く（刻み）・`_` つなぐ（分散和音の響きを残す）・`^^` 全音のチョーキング・`^` 半音のチョーキング・`//@0.1` 下から2半音すべって入る（リフのスライド）・`>+2` 音の中で2半音すべる（リードのスライド。鳴らすときに `>E5` の形になる）。
  - **使わない印**: `~`（ビブラート。人間「ゴムが伸びるような音」）。リードに `/`（しゃくり）も使わない（「ピロピロ」の原因）。
- **鳴らすとき**（`render`）: キーと旋法を渡すと、音階にも和音にもない音をとなりの音階の音へ寄せる。和音（パワーコード・オクターブ）は形をくずさない（いちばん低い音だけ寄せて、ほかは同じだけずらす）。リード（`snapct`）は強拍の1拍以上の音を、その小節の和音の音へ寄せる（チョーキングは着いた音で見る）。

## 2. 作り方

### 2-1. 実演の記録（GuitarSet、CC BY 4.0）
- GuitarSet（Xi ほか、ISMIR 2018。アコースティックギターを6人が5つの流儀〔ロック・ファンク・ジャズ・ボサノバ・弾き語り〕で弾いた360の演奏の注釈）の `annotation.zip`（39MB）だけを使った。録音は使わない。
- 使ったのは **進行1（12小節のブルース形式）と進行3（I-V-vi-iii-IV-I-IV-V）** の伴奏（comp）と即興（solo）。**進行2（ii-V-I-IV-viiø-III-vi）は既存のスタンダード曲の進行に基づくので外した。**
- 手順: 6本の弦の音（note_midi）を、60ミリ秒以内のかき鳴らしはひとまとめにし、拍の注釈（beat_position）で刻みに直す（演奏ごとに 16分と3連のどちらの格子に近いかを測って選ぶ）→ 小節頭の和音（長三和音・短三和音だけ）の根音からの半音に直す → 1小節の型と、同じ和音が2小節続く所の2小節の型を取り出す。伴奏の和音は低い1音＋高い3音まで、即興は単音（重なったら上の音）。
- 伴奏で、いちばん低い音が根音と5度だけのもの（ボサノバの親指のベースなど）は、1オクターブ下げてベースの「グルーヴ（実演の低音）」にした。
- 取り出した 1960 個 → ふるい落とし（3章）と重複の除去で **ギター 1194・ベース 114**。

## 3. ふるい落としの規則（機械で確かめる）

`loud25_phrases.check()` と `make_library.keep_musical()`。1つでも当てはまれば捨てる（数は `summary.json`）。
| 規則 | 中身 |
|---|---|
| 拍の合計 | 音が重ならず、小節数×4拍をこえない。鳴らした音の並びは、いろいろなキー・和音・チューニングで、拍の合計が小節数×4ちょうど（`verify_library.py`） |
| 音域 | 12通りの根音のどれでも、ギター F1〜E6（low は E2〜F1）、ベース B0〜G3 に入る |
| 音程のぶつかり | 1つの和音の中で半音（短2度・短9度）がぶつからない（「不協和」の型だけ例外）。リードは強拍の1拍以上の音が和音の音か 9度・11度（チョーキングは着いた音で見る）。実演の型は、音の長さの75%以上が和音と音階の音 |
| 同じ音だけ | 音の高さが1種類だけ（リフは和音の形が変われば可）。高さも長さも1種類だけの連打はどの役割でも捨てる |
| 跳躍だらけ | 旋律（リード・ベースの旋律）は7半音以上の跳躍が3割まで、1オクターブをこえる跳躍なし、同じ向きに続けて2回跳ばない。分散和音は弦をまたぐので 55%・10度まで |
| ピロピロ | 2半音以内の2つの音を8分以下で a-b-a-b とくり返す（トリル）型は捨てる。1小節に13音以上も捨てる |
| 息つぎ | リードは2小節の中に8分以上の休みがある |
| リフの素材 | 開放弦のペダル・伸ばす和音・オクターブ・ペダルトーン・スライド・休み・付点・2拍3連・5／7のかたまり・不協和などのうち3種類以上 |
| ミュートの切りかえ | 1拍以上伸ばした音のすぐ後にミュートの刻みを置かない（生成のときに伸ばす音を8分短くして間を空ける） |
| 単調 | 4小節で同じ1小節を4回そのまま、は捨てる |
| ベースの根音 | 根音・ブレイクダウン・ファンクは小節の頭が根音（またはオクターブ上）。旋律は小節の頭の半分以上が根音 |
| 刻み中心の割合 | 刻みの割合（刻みが2つ以上ある拍÷全部の拍）が 0.5 以上の型は、ギター全体の15%まで（いまは 204/2855＝7.1%） |
| 重複 | 長さ・基準・音・印がすべて同じものは1つだけ |

## 5. 使い方（曲のファイルから）

```python
from loud25_phrases import pick, render, render_voices, pick_pair, describe
from loud25_hand import put

# 1つ選ぶ（条件に合うもののうち、強さが近い8つからくじ）
g = pick("guitar", role="リフ", section="看板リフ", energy=0.7, chords=["Dm", "Dm"], seed=3, avoid=used_ids)
print(describe(g))
# 音の並びにする（和音の名前は "Dm"・"Bb"・"F#5"・"Csus2"、度数の "1m"・"b6" も可。low＝いちばん低い弦）
put(riff, a, a + 16, render(g, ["Dm", "Dm", "Bb", "C"], key="D", mode="aeolian", low="D2"))
# 和音の型（パワーコード・オクターブ）を声部ごとに: パートを分ける（powerChord: false）か、voice 0 だけを powerChord: true のパートへ
vs = render_voices(g, ["Dm", "Dm", "Bb", "C"], key="D", mode="aeolian", low="D2")

# ギターとベースを合わせて選ぶ
p = pick_pair("サビ", ["Bb", "C", "Dm", "Dm"], key="D", mode="aeolian", energy=0.85, low="D2", how="split", seed=1)
p["guitar"]["voices"]; p["bass"]["notes"]; p["how"]
```

- `pick(inst, role, section, energy, feel, fits|chords, bars, avoid, max_chug, min_chug, tech, kind, src, seed)`:
  - `avoid` に前に使った id を入れると、その型と同じ `family`（兄弟）をさける＝「前回と違う」。
  - `chords` を渡すと和音の種類で合う型だけにしぼる（短調の型は長三和音に使わない）。1小節目基準の型・パワーコードの型は1つ目の和音で見る（ほかの小節は音階に合わせて鳴らす）。
  - `src="gen"`＝自作だけ、`src="GuitarSet"`＝実演だけ。`max_chug=0.15` で刻みの少ないものだけ。
- `pick_pair(section, chords, key, mode, energy, low, bass_low, how, avoid, seed)`:
  - `how="unison"`: ギターのリフと、そのユニゾンのベース（ライブラリの `unison_of`、無ければその場で作る）。
  - `how="split"`（すみ分け）: ギターが忙しい（1小節7音以上）ならベースはペダル・根音で少なめ、ギターが伸ばす（バッキング）ならベースが根音の8分や旋律で動く。
  - `"auto"`: リフで看板リフ・前奏・Aメロ・ブレイクダウンなら7割ユニゾン。
  - **ブレイクダウン**はベースの型（キックの位置つき）を先に選び、ギターを同じリズムのパワーコードにする（`guitar_from_bass`）。返り値の `kick` をキックのグリッドに使えば3つがそろう。
- 前奏には刻みの型が入らないように仕分けてある。曲の頭は分散和音・伸ばすバッキング・リードから。

## 6. 確かめた数値（2026-10-22）

## 8. 限界・これから

- 自作の型は機械で作ったもので、**耳での確認はテスト曲の1曲だけ**。「曲として成り立つ」かは、使う曲ごとに耳で決める（人間の好み「数字は基準、最後は耳」）。
- リードは2小節の短い句まで。サビの主旋律（歌の代わり）は、これまでどおり曲ごとに手で書く（`loud-rock-patterns.md` 型B）。
- GuitarSet はアコースティックギターの演奏なので、実演の型はクリーン・クランチ向き（ラウドの歪みにはそのまま合わないものもある）。
- 4/4 だけ。6/8・7/8 などはまだない。

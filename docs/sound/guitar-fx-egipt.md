# ギターの飾り（guitarFx など）と 4x12 の IR（eg-412-v30-*）

2026-10-22 追加。元は EG-IPT Dataset（M. Fiorini, N. Brochec, J. Borg, R. Pasini、2025。doi:10.5281/zenodo.15205644。**CC BY 4.0・クレジット必要**）。
Gibson SG（ハムバッカー・ブリッジ側）を 19 の奏法で録った 23.8GB のうち、必要な分（約 0.4GB）だけを `tools/soundfont/egipt-fetch.py` で Range で取り出して使った。
作曲ソフト専用（ゲーム本体 `dist/` には入れていない）。元の録音はリポジトリに入れない。

## (a) ギターの飾り（`assets-src/soundfont/extra/guitar-fx-egipt.sf3`、1.7MB）
DI（アンプを通す前）の録音なので、パートの `amp`（クリーン・歪み・NAM と `ampCabIr`）に通して使う。**コーラスは掛けない**（元の楽器の全体設定のコーラスの送りは消してある）。
使う曲だけ自動で読み込まれる（作曲ソフトの EXTRA_FONTS）。作り方は `tools/soundfont/build-guitar-fx.mjs`。

| パートの patch | GM | 中身 |
|---|---|---|
| `guitarFx` | 15 | 鍵盤で種類を選ぶ（音程は変わらない）: **C2**＝ピックスクレイプ（長い・強い、約3秒）、**C#2**＝ピックスクレイプ（長い）、**D2**・**D#2**＝ピックスクレイプ（短い、0.4〜0.5秒）、**E2**＝指で弦をこする（長い）、**F2**＝同じく短い、**F#2**・**G2**＝弦を手のひらでたたく（ジャッ）、**G#2**＝ボディを手でたたく。**E3〜E6**＝本物のナチュラルハーモニクス（鳴る高さの音名で書く。録音のある高さ E3 A3 B3 D4 E4 G4 A4 B4 D5 E5 F#5 G5 B5 E6、間は近い録音の音程をずらす） |
| `guitarSlideUp` | 22 | 書いた音を弾き、約0.4秒後に全音（2半音）上へすべる（A#3〜G5 は録音そのまま、外は音程をずらす） |
| `guitarSlideDown` | 64 | 書いた音を弾き、約0.4秒後に全音下へすべる（A#3〜A5） |

例: `{"instrument":"guitar","patch":"guitarFx","role":"ピックスクレイプ","volume":0.15,"amp":"namDD","ampCabIr":"eg-412-v30-mix","notes":"R:28 C2:4"}`（サビの直前の4拍にスクレイプ）
- ふつうのギターのパートとは別のパートにする（飾りだけを書く）。歪みのパートと同じアンプにすると、同じギターの音に聞こえる。
- 試験（数値だけ）: 倍音の音程は基音の判定がすべて一致（±10 セント）。スライドは 試験の4音で、弾きはじめ→0.6秒後が 64.0→65.6、69.0→70.9、67.1→65.2、72.1→70.9（期待どおり全音動く）。

## (b) 4x12（V30）のキャビネット IR（`ampCabIr`）
同じ演奏の DI 録音と、アンプ（EVH 5150 III、つまみはすべて中央）→ 4x12（Celestion V30）をマイクで録った音の組（32組：通常の音・ピックスクレイプ・弦をたたく音）から、`tools/soundfont/egipt-cab-ir.py` で計算した（ウィーナーの推定 → 大きさをならす → 端の処理 → 最小位相 → 48kHz・100ms）。元のフォルダ `assets-src/ir/egipt/`、作曲ソフトへは `build-cab-irs.py` で `cab-irs.ts` に入れた。

| 名前 | マイク |
|---|---|
| `eg-412-v30-dyn` | ダイナミックマイク（SM57 系） |
| `eg-412-v30-cond` | コンデンサーマイク（C414 系） |
| `eg-412-v30-rib` | リボンマイク（低音が厚い） |
| `eg-412-v30-mix` | dyn と rib を半分ずつ |

- **アンプの音色（トーン回路）も含む**ので、500Hz〜1.5kHz が大きくへこみ、2〜5kHz が強く出る「中域を削った」性格（既存の `dd-v30-2x12-mix-balanced` よりずっと中域が少ない）。ラウドの刻みで、中域を削った音にしたいときに。中域が足りないときは既存の IR と `+` で混ぜる（例 `"eg-412-v30-dyn+dd-v30-2x12-mix-balanced"`）。
- 確かめ: DI にこの IR を畳み込んだ音と、本物のマイク録音の大きさの差は、100Hz〜4kHz の 1/3 オクターブごとに dyn・cond が ±1dB 以内、rib が ±2.3dB 以内。6.3kHz より上はマイク側がほぼ雑音（DI とのコヒーレンス 0.1 以下）なので、−24dB/オクターブで下げている。
- 耳での確認はまだ。

# 毎日10曲のマスタープロンプト（作曲ソフト・歌声つき版）

Claude（チャットでもClaude Codeでも）に、そのまま貼って使う。出力された JSON を `songs.json` に貼り、PCの `daily.bat` をダブルクリックすると、10曲が作られる。
更新: 2026-10-03（自作の作曲ソフト `make.mjs`・女声の歌（VOICEVOX）・パート別ミックスに対応）

---

## ▼ここから貼る▼

あなたは、プロのレベルの曲を毎日10曲作る音楽プロデューサー兼作詞家です。今日の10曲ぶんの「設計図」を作ってください。

### 目的
- 4〜5分の曲を、毎日10曲。公開できる品質を目指す。
- 曲は、次の3つの道具のどれかで作られます。**あなたが書く設計図は、1つ目（自作の作曲ソフト）にそのまま使える形**にしてください。
  1. **サンシャイン作曲ソフト**（`make.mjs`）: 文章から4〜5分の曲を自動で組み立てる。無料。ボーカルは、歌詞（ひらがな・カタカナ）を渡すと女声（VOICEVOX 波音リツ）で歌う。
  2. **ACE-Step**（PC内で動くAI作曲）: 同じ `songs.json` で作れる。歌詞つきの歌も作れる。
  3. **Suno など**: 同じ内容（prompt・lyrics）を貼って使える。

### 作曲ソフトの得意・不得意（これに合わせて設計する）
- 読み取れる曲調: メタル、デスメタル、ハードコア、プログレメタル（7拍子）、ロック、ダンスロック、クリーンダンス、エレクトロ、J-POP、ジャズ、R&B、フォーク、クラシック、バロック、エピック、宇宙・自然・カフェ・ミステリー系、フォンク、サンバ。
- 味つけ（prompt に書く）: `loud`（ラウドロック／ラウドメタル。リズムギターを左右に倍にする）、`orchestra`（弦・ブラス・合唱・ティンパニ）、`wagakki`（琴・三味線・尺八・太鼓）。orchestra と wagakki は4拍子の曲だけ。
- 長い曲の工夫（自動）: 旋律はモチーフで組み立てる、2回目のAメロは別の旋律になる、ポップ・ロック・エレクトロ・壮大系は**ラスサビで全音上がる（転調）**、サビ頭にクラッシュ、ブリッジ後にストップタイム。
- 歌声: 女声。きれいな歌声で成り立つ曲（メロディアス、プログレ、ラウドロック、ダンス×ロック、ロック×オーケストラ、ロック×和楽器、J-POP など）に歌をつける。
- **歌をつけない曲**: デスメタル・ハードコアなど、グロウルやシャウトが主役の曲。歌が合わない曲は、インストにする（`lyrics_kana` を書かない）。10曲のうち歌入りは4〜6曲を目安にする。
- 正直な限界: 旋律は規則から作るので、似た雰囲気になりやすい。歌声は話し声に近い方式の声もある。耳で聴いて選ぶ前提。

### 10曲の作り方
1. **ジャンルをばらけさせる**。同じ曲調を3曲以上並べない。例: メロディアスメタル／プログレ／ロック×和楽器／ラウドロック／ダンスロック／ロック×オーケストラ／J-POP／ハードコア／テクニカルデスメタル／エピック。毎日、前日と少し違う組み合わせにする。
2. **BPM・キー・拍子を曲ごとに決める**（`bpm`、`key_scale` 例 "E minor"、`time_signature` 例 "4/4"）。長さ `audio_duration` は 240〜300 秒。
3. **prompt は英語のキーワード中心で、具体的に**。ジャンル、味つけ（loud / orchestra / wagakki）、雰囲気、楽器、テンポ、キー、歌の有無（female vocal / instrumental）。**既存の曲名・アーティスト名・バンド名は書かない**（そっくりの曲を避ける）。
4. **歌入りの曲は歌詞を2種類書く**:
   - `lyrics`: 漢字まじりの表示用（Suno・ACE-Step や公開用）。
   - `lyrics_kana`: **ひらがな・カタカナだけ**の歌い用。次のルールを守る。
     - `[verse]` `[bridge]` `[chorus]` の見出しで区切る。1つのまとまりは4行。
     - 1行は8〜14音（150 BPM 以上は8〜11音）。「きゃ」は1音、「っ」は数えない。
     - 助詞は発音どおり（は→わ、へ→え、を→お）。「ー」「っ」「ゃゅょ」は使ってよい。漢字・英字・数字は使わない。
     - Aメロ2〜3つ、Bメロ1〜2つ、サビ1つ（サビは毎回歌う）。
     - 歌詞は完全にオリジナル。実在の歌詞・フレーズは使わない。サビは短く覚えやすい言葉に。
5. 歌入りの曲には `"voice": "波音リツ"` を入れる（ほかの女声に変えてもよい）。

### 出力の形
最初に、10曲の一覧表（番号・曲名・ジャンル・BPM・キー・歌あり/なし・ひとこと）を出す。
続けて、**JSONだけのコードブロック**を1つ出す。形式:

```json
[
  {
    "title": "曲名",
    "prompt": "melodic metal, twin guitar harmonies, galloping riffs, female vocal, 160 BPM, E minor",
    "lyrics": "[Verse 1]\n漢字まじりの歌詞…",
    "lyrics_kana": "[verse]\nひらがなのかし…\n\n[bridge]\n…\n\n[chorus]\n…",
    "voice": "波音リツ",
    "bpm": 160,
    "key_scale": "E minor",
    "time_signature": "4/4",
    "audio_duration": 270
  }
]
```
- インスト曲は `lyrics` / `lyrics_kana` / `voice` を省く。
- 10曲ぶん、すべて入れる。JSON は文法を守る（最後の項目の後ろにカンマを付けない）。
- 最後に、公開するときの注意を2行で書く: 歌入りの曲は「VOICEVOX:波音リツ」のクレジットが必要。公開前に必ず耳で聴いて選ぶ。

## 使い方（PC）
1. 上のプロンプトをClaudeに貼る → 出てきたJSONを `C:\Users\fujik\Music\music-tools\songs.json` に貼る。
2. `daily.bat` をダブルクリック（曲の生成 → WAV → 歌声 → 音量調整・MP3化）。初回だけ、`setup_composer.ps1`・`setup_voicevox.ps1` を済ませておく。
3. `inbox\<日付>\index.md` と `out\<日付>` を見て、耳で聴いて選ぶ。
4. Suno で作りたい曲は、`prompt` と `lyrics` を貼って使える。

## 注意
- 作曲ソフトの曲の出来は、**耳での確認がまだ**。気に入らない曲は `--variations 3` で種違いを作って選べる。
- 詳しくは `docs/sound/suno-style.md`、`docs/sound/vocal.md`。

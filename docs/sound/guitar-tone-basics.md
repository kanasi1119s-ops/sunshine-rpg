## 1. 音を決める4つ（機材側）
1. **歪み（ゲイン）**: 「欲しい歪みが出る最小限」にする。足しすぎると濁り、音の輪郭が消える。クリーンは歪みなし、クランチは浅く、ディストーションは深く。
2. **中域（ミドル）**: 中域を持ち上げると、バンドの中でギターが前に出る。削る（スクープ）と荒く攻撃的になる（メタル向き）。ふつうのロック・ポップは削らない。
3. **高域（トレブル）**: 上げるときらびやかで輪郭が出る（クリーン・カッティング・リード向き）。下げると温かく丸い（ジャズ・ブルース向き）。上げすぎは耳に刺さり、足りないと埋もれる。
4. **ピックの当たり（アタック）**: 強く弾くと明るく硬く、弱く弾くと丸い。強弱をつけて弾くのが表情の元。

## 2. 帯域の地図（ギターの場合）
| 帯域 | 役目 | 目安の操作 |
|---|---|---|
| 〜80Hz | 要らない低音 | ハイパスで切る（歪みギターは100〜150Hzまで上げてよい） |
| 80〜250Hz | ボディ・厚み | 薄ければ少し足す。ベースと濁るなら緩く削る（250〜350Hz） |
| 250〜500Hz | キャラクターの中核 | 削りすぎると力が出ない |
| 500Hz〜1kHz | 鋭さ・明瞭さ | きついと感じるときがある |
| 1〜3kHz | **前に出る帯域（プレゼンス）** | ギターが埋もれたらここを足す |
| 3〜5kHz | アタック感 | 足すと攻撃的、きついときは狭く削る |
| 5〜10kHz | きらめき・ピックの音 | 刺さるならローパス（歪みなら6〜8kHz、クリーンは8〜10kHz） |
- 5曲の分析（`punk-guide.md` §9）でも、ギターの中心は1〜4kHz（重心 約1400Hz）だった。ギターの高音が足りない曲は、まず1〜3kHzの厚みを見る。

## 3. 重ね方・広げ方
- 同じパートを2回弾いて（ダブルトラック）左右に振ると、厚みと幅が出る。同じ音を2本コピーするのでなく、弾き方を少しずらす。
- 低音（キック・ベース）の中心から、ギターの低域を離す。幅は左右に出す。
- ギターが2本以上のときは、1本は低め・中域の太い音、もう1本は高め・細い音に役割を分ける（にごらない）。
- 残響: ごく短い部屋の響き（約0.5秒）で自然さを足す。前に出したいときは、鳴り出しから少し遅れて響かせる（プリディレイ 5〜15ms）。残響の低域（200〜250Hz以下）は切る。

## 4. 打ち込みで本物らしくするコツ（ここが肝心）
- **ぶつぶつ切れる原因**: 音が短い（スタッカート）、同じ強さの同じ音の連打、音と音のあいだに隙間がある。実際のギターは、弦が鳴り続けて次の音に重なる。
- 音の強弱を1音ずつ変える。目安: ふつう65〜95、アクセント100以上、弱い音35〜50。
- 同じ音の連打を避ける。連打するなら強弱をつける。録音音源（ラウンドロビン）が使えるものを選ぶ。
- 音の終わりをそろえない。長さを少しばらす。
- 位置を少しずらす（5〜15ms）。ぴったりのグリッドにしない。
- 録音の鳴りを活かす: 長い音は短く切らない。

## 5. うちの道具（曲JSON）での書き方
| やりたいこと | 書き方 |
|---|---|
| 鳴りを伸ばす | `sustain` 1.3〜1.8。`'`（スタッカート）は使わない。16分・8分の細かい音も、sustain を上げて重ねる |
| 強弱 | 拍頭を `!`、あいだを `,`（例 `A3:0.5! E4:0.5, C4:0.5,`） |
| 連打の機械っぽさ | 連打をやめて、和音の長い音＋リズムの切れ目に変える。`human` 0.4〜0.5 |
| 低音がにごる | ギターの音域は C3 より上（歪みは E2〜）。キック・ベースと同じ音域に置かない |
| 高音が細い・刺さる | 録音音源（`--guitar gretsch`）を使い、`bright` を -0.2〜+0.2 で調整。amp は clean か auto |
| 前に出ない（埋もれる） | 歪みなら amp `punk`（1〜4kHzを厚くしてある）、音量を上げる、ほかのパートの同じ帯域を空ける |
| 厚みと幅 | 同じリフを2パートに分け、pan を -0.9 / 0.9、片方に `push` 0.02 |
| 空間 | `reverb` 0.15〜0.25、`chorus` は 0（電子的に聞こえやすい） |
| ファンクの刻み | 短い単音の連打にしない。2〜3拍の伸びる音＋休符で、和音の構成音を入れかえる |

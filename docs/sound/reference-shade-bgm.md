# 参考調査: Shade さんのBGM素材（2026-09-30）

人間から「元アリスソフトの作曲家 Shade さんのフリー楽曲を学習素材としてプッシュして」と依頼があり、調べた記録です。
**結論: 曲そのものはリポジトリに入れていない（入れられない）。** ここに残すのは、公開されている商品説明から読み取れる「BGMの揃え方」と、使えなかった理由だけです。曲を聴いてメロディやコード進行を写すことはしていない（CLAUDE.md 1-1）。

## Shade さんについて（公開情報）

- 1994年にチャンピオンソフトに入社し、ブランドのアリスソフトで音楽を担当した。2012年に退社してからはフリーランスで、コンシューマーゲームやブラウザゲームの曲も手がけている（Wikipedia）。
- 公式サイトは「Shade Music Laboratory」（http://shade-music-lab.net/ ）。**この作業環境からは開けなかった**（名前解決できない）。
- 販売・配布は BOOTH の「S.M.L OnlineShop」（https://sml.booth.pm/ ）。

## 使えなかった理由

1. **無料の1曲は規約が不明。** 聴いて楽しむための公開と読める。CLAUDE.md 1-1 の例外の条件1（規約が読めない・不明な素材は使わない）に当たる。
2. **素材集は有料。** 買うかどうかは人間の承認が必要（CLAUDE.md 1-2）。買ったとしても、曲のファイルをリポジトリに置くのは再配布になりうるので、同梱の規約で認められている場合に限る。
3. **アリスソフト時代の曲は既存のゲームの曲**なので、使うことも似せることもできない（CLAUDE.md 1-1）。
4. 「学習素材として使う」ことについては、どの規約にも書かれていない。

## 商品の構成から学べること（曲を聴かずに分かる範囲）

VOL1（RPG向け12曲）の曲目の並べ方は、少ない曲数でRPG1本分をまかなう設計の手本になる。

| 用途 | 曲数 | 中身 |
|---|---|---|
| 汎用マップ曲 | 3 | 本体＋バリエーション2つ |
| 汎用戦闘曲 | 4 | 本体＋バリエーション3つ |
| 汎用イベント曲 | 3 | 本体＋バリエーション2つ |
| 戦闘勝利ジングル | 1 | 短い曲 |
| 戦闘敗北ジングル | 1 | 短い曲 |

ここから、このゲームの曲づくりに使える考え方:

- **1つの曲を元に「バリエーション」を作って数を増やす。** 同じ旋律を、テンポ・楽器・調・伴奏の厚さ・アンプ（`amp-rack.ts` のジャンル別アンプ）を変えて別の場面に使う。曲数を抑えつつ、作品全体の音に統一感が出る。`composition-notes.md` 第5節（モチーフの使い回し）と同じ考え方。
- **いちばん多く聴かれる戦闘曲に、いちばん多くのバリエーションを割く。** 雑魚戦・強敵・章ごとの戦闘など、場面の緊張に合わせて同じ曲を変化させると、聴き飽きにくい。
- **勝利・敗北のジングルは、曲とは別に必ず用意する。** 戦闘の区切りを音で知らせる短い曲は、RPGの必須部品。
- **VOL2 のように「テーマを決めて数曲まとめる」作り方もある。** 章や地域ごとに楽器（例: ピアノ中心）と雰囲気をそろえた曲の組を作ると、場所の個性が出る。

`docs/sound/tracks.md` の曲の一覧を見直すときは、「本体の曲」と「そのバリエーション」を分けて数えると、足りない曲と作り足せる曲が分かりやすい。

## 今後この素材を使いたくなったら

- 人間が VOL1 などを購入し、同梱の利用規約を読む。再配布が禁止なら、曲は人間の手元だけに置き、リポジトリには置かない。
- 学習として残せるのは、曲の長さ・ループのしかた・楽器の使い方・場面ごとの作り分けなど、特徴をまとめたメモだけ。旋律やコード進行は写さない（CLAUDE.md 1-1）。
- 公式サイトに無料配布のページがあると分かったら、そのページの規約を読んで判断し直す。

# ベースでメロディを歌わせる手引き（2026-10-08 調査）

「ベースが旋律を受け持つ曲」を書くときの考え方と、うちの道具での書き方。見本は `assets-src/ai-songs/autumn-dusk-bass-melody.json`（夕焼けのとなりで・ベースがメロディ版。仮）。関連: `layering-guide.md`（重ね方）、`mixing-guide.md`、`music-knowledge.md`。数値は目安で、最後は耳で決める。

## 1. 書き方の原則（調べたことのまとめ）
1. **根音と5度だけにしない**。和音の3度・7度・9度を強拍に置くと、ベースの線が「歌」になる。弱拍では経過音（音階の隣の音）でつなぐ。
2. **ほとんど順次進行**。隣の音へ歩くのが基本。跳躍は大きくても1オクターブまでにして、跳んだら次は逆方向へ戻る。
3. **半音のアプローチ**。次の和音の根音・3度の半音下（または上）から入ると、つなぎが滑らかになる。
4. **休符が歌わせる**。16分の細かい動きばかりにせず、白玉・休符・語尾を伸ばす音を混ぜる。旋律には息つぎが要る。
5. **リズムに型を作る**。同じリズムの型をくり返し、小節ごとに少しだけ変える。
6. **歌の曲に仕えさせる**。主役を取りすぎず、サビで一番高く、一番動く。Aメロは低く控えめ。
7. **音域を分ける**。旋律のベースは中低域、根音を支える低音は別に（1オクターブ以上下）。ギターのアルペジオは1オクターブ上げて場所を空ける。

## 2. うちの道具での事実
- ベースの音源は、A2より上の音も鳴るよう `build-bass.mjs` で鍵域を21〜84に拡張した（以前はA2より上が無音だった）。
- ただし高くなるほど元の録音をずらして使うので音が薄くなる。**旋律は D2〜F3 に収めるのが基本**（見本も、最初に作った高め版 D3〜F4 は「高い音はいらない」と判断して1オクターブ下げた）。
- 旋律の声は2つ。`finger`（既定。輪郭がはっきり）と `patch: "fretlessBass"`（なめらか、歌に近い）。曲の切り替えは JSON の旋律パートの `patch` だけ。
- 旋律パートは `volume` .2・`pan` .12・`reverb` .25・`chorus` .1。根音の低音は `volume` .12・`duck` .3 で、キックとも入れ替わる。
- 技法記号が効く: `~`（ビブラート）、`/`（しゃくり上げ）、`\`（落とす）、`_`（なめらかにつなぐ）。語尾に `~`、音の頭に `/` を少し。

## 3. 見本の数値（夕焼けのとなりで・ベース旋律版）
| 指標 | 値 | 目安 |
|---|---|---|
| 順次進行の割合 | 63% | 6割前後 |
| 強拍が和音の構成音 | 93% | 9割前後 |
| 音域 | D2〜F3 | 高い音は使わない |
| 8半音以上の跳躍 | 3回 | 少なく |
| 低 60〜250Hz | -2.0dB | 参考 -3.3 |
| 中低 250〜1kHz | -8.1dB | 参考 -5.9 |
| 左右の相関 | 0.76 | 0.4〜0.88 |
| 音の重心 | 308Hz | しっとり 220〜400 |

帯域は目安に収まった。旋律を低くすると250Hz〜1kHzが薄くなるので、**ギターのアルペジオを高く逃がさず、旋律のすぐ上（E3〜）に置いて**中低域を埋めた（旋律を高くしていた版では、アルペジオを1オクターブ上げて場所を空けていた。旋律の高さに合わせて決める）。旋律パートには `bright` .3 を足した。

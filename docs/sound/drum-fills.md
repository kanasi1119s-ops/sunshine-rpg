# ドラムのおかず（フィルイン）集（2026-10-08 調査）

「おかず」＝フィルイン。曲の流れの中に差しこむ短い飾りで、**場面の区切りを聴き手に知らせ、次の頭のグルーブに気持ちよく着地させる**ためのもの。ドラムの教則・解説ページ数件（96bit-music「フィルイン基本16パターン」、クラブナージ「フィルインとは」ほか）で言われていたことを、うちの曲の書き方（16分グリッド）に落としてまとめた。型は一般的な基本形を、うちの記法で書き直したもの（特定の曲のフレーズではない）。

## 1. 考え方（調べて分かったこと）
- **音数より「どこに入れて、どこを休むか」**。毎回入れず、効果的な場所に選んで入れる。休むこともフィルの一部。
- **役割**: 抑揚をつける／聴き手の耳を引く／曲の構成を区切る／他パートとの掛け合いと呼吸を作る。
- **入れる場所**: 4・8小節のフレーズの終わり、場面の切れ目（A→B、B→サビ、サビ→次）、盛り上がりの手前。
- **着地**: おかずの最後は「次の小節の1拍目」へ向かう。次の頭に crash＋キックを置くと、はっきり着地する。
- **大きさは場面で決める**: 静かな場面の区切りは「ひとつ・ふたつ」程度、サビ前は「タム回し」で大きく、止める（ブレイク）のも強い手。
- **音の高さ**: タムは **高 → 低** に下りると「落ち着いて着地」、低 → 高に上がると「煽る」。基本は高→低。
- **ゴーストノート（弱いスネア）** を混ぜて加速すると、ノリを崩さずに盛り上がる（バラード向き）。
- **引き出しを増やす**: 1拍／2拍／3連／16分など長さと細かさを変え、スネア・タム・シンバルを曲調で使い分ける。同じ型を連続で使わない。

## 2. うちの記法での書き方
1小節（4拍）は、16分で16マス（`g:` の16文字）。おかずは**小節の最後の2拍（後ろ8マス）**を置き換える。
- スネア・キック・ハイハットは `g:` グリッド（`x` 普通／`X` 強く／`o` 弱く／`.` 休み）。
- **タム（tom）** は音名で高さを選ぶ: `C4`（高い）／`A3`／`G3`／`E3`／`C3`／`A2`（低いフロア）。例 `R:2 C4:0.25! A3:0.25, G3:0.25! E3:0.25, C3:0.25! C3:0.25!`（`R:2` は前半2拍の休み）。
- タムの左右の振り分けは、曲の `drumMix: { "tom": { "spread": 0.7 } }` で（高いタム＝左、低いフロア＝右）。

## 4. 場面ごとの選び方
| 場面の終わり | 大きさ | 例 |
|---|---|---|
| 曲の入り（イントロの最後） | 中 | スネアからタム／タム回し（1拍） |
| フレーズの区切り（4小節ごと） | 小 | ひとつ／ふたつ／うらから（8小節の場面の4小節目） |
| Aメロの終わり → Bメロ | 中 | かけあがり／シンコペ |
| Bメロの終わり → サビ | 大 | タム回し（2拍）／スネアのあとタム |
| サビの終わり → 次の場面 | 中 | タム回し（1拍）／スネアからタム |
| 間奏・ブリッジ → サビ | 止める（drop） | ブレイク（全部止めて低いタム1発）→ サビの頭に crash |
| 曲の最後に向かうサビ | 大 | 広い音域／ロール |
- 続けて同じ型を使わない（場面ごとに変える）。大きなおかずを入れた次の小節は、頭に crash とキックを置いて着地。
- 速い曲は2拍を詰めすぎない（16分が聞き取れない）。遅い曲（60〜90）では、2拍のタム回しはゆったり聞こえる。

## 5. 自動で入れる
`sections` を使った自動伴奏（`autoAccompaniment: true`）では、場面の変わり目と、8小節以上の場面の4小節ごとに、上の型が**自動で入る**（`applySections`、大きさは `fillSizeAt` で決まる）。要らないときは曲の `fills: false`。手書きのドラム（`g:` グリッド）の曲では、上の表の型を、最後の8マスに貼りつける。

## 7. 追加の型（2026-10-08・第2回の調査）
調べた先: [Drumeo「初心者のドラムフィル」](https://www.drumeo.com/beat/beginner-drum-fills/)、[emastered「ドラムフィルのパターン」](https://emastered.com/ja/blog/drum-fill-patterns)、[drumlessons「とびとび16分フィル」](https://drumlessons.com/?p=5435)、[Drummer Cafe「パラディドルをリニアフィルに」](https://drummercafe.com/education/articles-commentary/paradiddles-as-linear-fills-around-the-kit.html)。どれも一般的な基本形で、特定の曲のフレーズは写していない（CLAUDE.md 1-1）。

### 調べて分かったこと
- **長さは3段階**: 1小節・半小節（2拍）・1/4小節（1拍）。「いつ始めていつ終わるか」を決めるのが先。フィルは**次の頭のクラッシュ（とキック）で終わる**のが基本。
- **基本の形**: 8分の積み上げ（スネアとフロアタム、キックは4分）／16分／フラム＋キックの交互（スプラット）／高いタム→スネア→低いタムと下りる流れ／スネア16分の連打のあとキックとフラム（ビルドアップ）。
- **リニア**: 手足が同時に鳴らず、1つずつ順に回る。音がつながって聞こえる。
- **パラディドル**（R L R R L R L L）を、スネアとタムに割りふると、流れるタム回しになる。
- **とびとび**: 16分の連打の一部を休みに替える。ノリを崩さずに変化をつけられる。
- **やり過ぎない**。道具箱（引き出し）を増やして曲調に合わせて選び、強弱（ダイナミクス）を作り込む。
- うちの記法（16分グリッド）では書けないもの: 3連符・6連符・「バケツ・オブ・フィッシュ」（16分3連のあと8分のアクセント）。未対応（今後の課題）。
- フラム（直前に弱い1発をつけた装飾音）は、`o`（弱い）＋`X`（強い）の2マスで近似している。

### 追加した17型
型の長さは、段の文字数で決まる（4マス＝1拍、8マス＝2拍、16マス＝1小節）。
| 型（id） | 長さ | 大きさ | 内容 |
|---|---|---|---|
| しっぽ（tail） | 1拍 | 小 | 弱→強の3連打でそっと次へ |
| 小さな下り（downq） | 1拍 | 小 | 最後の1拍でタムを高→低へ4つ |
| キックで押す（kickq） | 1拍 | 小 | 裏のキック2発。スネアは休む |
| 8分ビルド（build8） | 2拍 | 中 | 8分で弱→強。キックは4分 |
| スプラット（splat） | 2拍 | 中 | フラム風のスネアと裏のキックを交互に |
| 高→スネア→低→キック（downkit） | 2拍 | 中 | 高いタム→スネア→低いタム→キックと下りる定番 |
| とびとび16分（broken） | 2拍 | 中 | 16分の連打を所々休みに |
| 3・3・2（g332） | 2拍 | 中 | 16分8マスを3+3+2に区切り、引っかける |
| リニア（linear） | 2拍 | 大 | スネア・タム・キックが順に回る |
| パラディドル（para） | 2拍 | 大 | 右＝スネア、左＝タムの流れる回し |
| 煽り上げ（rise） | 2拍 | 大 | 低いタムから高いタムへ。期待をふくらませる |
| 8分で1小節（bar8th） | 1小節 | 大 | 前半スネア8分、後半タムで低く着地 |
| 16分で1小節（bar16） | 1小節 | 大 | 前半スネア16分、後半は高→低へタム |
| ロール（1小節）（buildbar） | 1小節 | 大 | スネアを弱→強に連打して育てる |
| リニア（1小節）（linearbar） | 1小節 | 大 | 1マスに1音で、3つの太鼓が順に回る |
| はずむ（bounce） | 1小節 | 中 | 裏拍に引っかけた、弾む1小節 |
| ストップ（1小節）（dropbar） | 1小節 | 止める | ほぼ全部止めて、最後に低いタム1発 |

`placeFill(tracks, fill, fromBeat, …)` は、型の長さぶんだけ入れかえる。自動伴奏（`applySections`）は、小節の終わりから**型の長さ**をさかのぼって入れ、3拍子では3拍を超える型を選ばない（`pickFill` の `maxBeats`）。

## 9. 選び方のまとめ
- **静かな区切り（4小節ごと）**: 1拍の型（しっぽ・小さな下り・キックで押す）か、ひとつ／ふたつ／うらから。
- **次の場面への橋渡し**: 2拍の型（かけあがり・高→スネア→低→キック・スプラット・とびとび・3・3・2）。
- **山場の前**: タム回し（2拍）／パラディドル／リニア。1小節の型（16分で1小節・リニア（1小節）・ロール（1小節））は、**ここぞ**の場面に。
- **止める**: ストップ（2拍）／ストップ（1小節）。サビの頭の全員の出が際立つ。
- 長い型ほど、前のグルーブを置きかえる量が大きい。**1小節の型は曲中に数回まで**。

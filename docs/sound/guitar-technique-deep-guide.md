# ギターのテクニックの使い方・表現の深掘り — ソロ・表情・ピッキング・リズム・ポジション・アンサンブル（2026-10-11 調査）

目的: 「ギターの奏法（何を弾くか）」ではなく、「**奏法をどう使うか（どこに置き、どれだけ付け、他の楽器とどう分けるか）**」を、作曲ソフトで書けるところまで落とし込む。
**先に読む文書（この文書は重複を避け、その先を書く）**:
- `guitar-techniques-rock-guide.md`（ロック系の奏法の辞典と、ジャンル別の使い分け）
- `guitar-techniques-world-guide.md`（ジャズ・ブルース・アコースティックなど、ロック以外）
- `melody-craft-guide.md` §5（ソロの組み立ての共通原則と、楽器別・ジャンル別の8〜16小節の型）／§6（失敗と直し方）
- `arrangement-deep.md`（編曲の表。ギター2本の役割の基本）
- `banned-sounds.md`（**使わない音**。下の §0.3）

**この文書の新しい部分**: ①作曲ソフトの記号が実際にどんな音の動きになるか（コードを読んで確かめた）②ソロを「表現の階段」と「表現の予算」で設計する考え方③ビブラート・ベンド・スライド・レガート・強弱の種類と使い分け④ピッキング技術を「音の違い」で選ぶ表⑤リズムギターの強弱・ミュート・ボイシング・転回形・2本の役割⑥ポジション取り（音域・弦・開放弦・ボイシングの色）⑦ベース・ドラム・鍵盤・歌とのすみわけ⑧打ち込みの失敗と直し方⑨取り入れる提案12件。

### 要点（先に読む人へ）
1. **ベンド＆リリースは `^^\\`（ノート列の中身。JSON では `\\\\`）で書ける**。プリベンドは「曲げたあとの音を書く」、プリベンド＆リリースは「それに `\\`」（§1.1・§3.2。MIDI の実測で確認）。
2. **ビブラートは深さ2段（`~`・`~~`）だけで、速さは音源任せ**。頭は自動で0.4拍まで待つ。ここが「ビブラートが不自然」の根っこで、提案 #1・#2（§10）にした。
3. **`strum` の和音（1拍以上）にも自動しゃくりがかかり、「キュイン」の原因になる**。曲に `autoScoop:false`（この文書の例はすべてそう）。
4. ソロは**表現の階段**（素の音 → 長音のビブラート → つなぐ技法 → ベンド → 頂点でベンド＋ビブラート → フォール）と**表現の予算**（8小節で `~` 4〜5音・`^` 1〜2音）で設計する（§2）。
5. ギターは**歌の休符にだけ**入れ、**歌・ベース・鍵盤とは音域とリズムを分ける**（§7、例 E1）。

1. **使わない音**（`banned-sounds.md`、人間が決めた）【確認】: 短い単音の「ピ、ピ」（`guitar`＋gretsch＋amp `funk`/`clean` の短い刻み）／`hardrock`・旧`punk`の歪み／`punk` でのメロコア（割れ・PLR 2.7〜3.5）／ナイロン弦＋amp `auto`。**共通: 短い音（`'`・0.25拍以下）を同じ高さで連打しない。6kHz以上をギターで出さない。** 歪みギターは volume 0.05〜0.12、`loudrock`／`crunch` から試す。
2. **人間の指示（2026-10-11、`guitar-rock-band-guide.md`）**: エレキギターは、音の終わりに何度もビブラート（`~`）を付けて無理に鳴りを作らない。`sustain` で伸ばすのもやめ、録音そのままの自然な減り方で聴かせる。→ この文書の `~` は「山場の長い音」に限る。`sustain` を 1.0 から大きく外す例は、ストロークの長い響き（P3）など**意図があるものだけ**にした。
3. 既存曲のメロディ・コード進行は写さない（`CLAUDE.md` 1-1）。例は新作。
4. この文書の例は**すべて `autoScoop:false`** で書いてある（理由は §1.3）。

## 1. ソフトの「物差し」— 記号が実際にどう動くか【確認】（コードを読んで）

奏法を「どう使うか」を決めるには、まず**ソフトが何をどこまで表せるか**を数字で知っておく必要がある。`midi-export.ts` などから読み取った値（PPQ=480、1拍=480 tick）。

### 1.1 記号と実際の値

| 記号 | 実際の動き | 使うときの数字 |
|---|---|---|
| `!` | 強さ（velocity）×1.3 | 強拍・山の音・ベンドの頭 |
| 記号なし | ×1.0 | |
| `,` | 強さ ×0.7 | 弱拍・アップ・レガートの2音目・ゴースト |
| `'` | 音の長さ（gate）×0.4 | 短くなるぶん切れて聞こえる。同音連打に使わない（禁止の音） |
| `_` | gate ×1.15（次の音に少し重なる） | レガート・スライドの経過音・ハンマリング |
| `~` | ビブラート（CC1=89）。`~~` は CC1=127 | 深さは**2段だけ**。**速さは音源のモジュレーション任せで、ソフトからは変えられない** |
| `^` | ベンドアップ。半音（`^^`＝全音、最大4、`^.`＝1/4音相当） | 発音と同時に上がり始め、**min(音の長さの35%, 0.5拍)** かけて S字になめらかに目標へ。目標を保って、**音の終わりで一気に0へ戻る** |
| `/` | しゃくり（下から入る） | min(音の長さの40%, 0.3拍) で本来の音程へ |
| `\` | フォール（終わりで落とす） | 音の長さの**70%の地点**から終わりにかけて下がる |
| 組み合わせ | `^^\\`（JSON内では `\\\\`）＝**ベンドアップしてリリース** | 実測: 0→+2半音（0.5拍で到達）→保持→70%から0へ。**音の長さが2拍以上あると形が見える** |

- ビブラートは、**発音から min(音の長さの30%, 0.4拍) 待ってから**（CC1 を0.15拍かけて）揺れ始め、音の終わりで元に戻る。**0.4拍未満の音には付かない**。`leadGuitar` は何も書かなくても CC1=26 の「底」があり、ごく弱い揺れが常に乗る（`tone:"prs"` は40）。→ **「音の頭は真っすぐ、遅れて揺れる」実演の定石【確認】（S1）は、ソフトが自動でやってくれる**。
- ベンドとビブラートの**短い音の限界**: 音の長さが 60 tick（0.125拍）未満だとベンド曲線が付かない。ビブラートは 0.4拍未満で付かない。
- ベンドの上昇の速さは**音の長さで決まる**: 2拍以上の音なら0.5拍で上がる（ゆっくり歌うベンド）、1拍の音なら0.35拍（速いベンド）。0.5拍の音なら0.175拍（ほぼグレースノート）。速さを別に指定する記号はない。

### 1.2 自動で付く表情（知らないと「書いていないのに鳴る」）

| 自動の動き | 条件 | 止め方 |
|---|---|---|
| **自動しゃくり（autoScoop）** | `guitar`／`leadGuitar` の**1拍以上の音**（曲頭を除く）で、`^ / \` を書いていないもの。半音下（-1）から入り、約0.07拍で本来の音程へ | 曲に `autoScoop:false`。**`strum` で展開されたコード音（1拍以上のもの）にもかかる** |
| **autoArticulation** | 曲に `autoArticulation:true` のとき。`guitar`／`leadGuitar`／`strings`／`brass`／`lead` の**1.5拍以上でフレーズの最後（次が休符か終わり）の音**に `~`（CC1=89）。ギターの短い（0.5拍以内）上下2音は50%でハンマリング／プルオフ風（1音目 gate 1.15、2音目 強さ0.7） | パートごとに false |
| **human 音程のずれ** | `human>0` のとき `leadGuitar`／`guitar` などの1音ごとに±8セント（×human）、ベンドの指定がない音だけ | `human` を下げる |
| **長音の音量の山（CC11）** | `human>0` で `leadGuitar`／`lead`／`strings`／`brass`／`pad`／`choir` の1拍以上の音 | 同上 |
| **自動エコー（MIDI経路）** | `leadGuitar`（と `lead`／`bell`／`keys`）の0.4拍以上の音に、付点8分（強さ×0.42）・付点4分（×0.22）のコピー | 【確認】はコード。録音音源の経路で同じ動きかは未確認 |

> **まとめ**: 「ギターを歌わせる」道具は、記号（`~ ^ / \ _ ! ,`）と、パートの `phrase`・`human`・`dynamics`、そして**書かないことで入る自動の動き**の3つ。**ソフトに無いのは、ビブラートの速さの指定、ベンドの戻りの速さ・途中で止める位置、ベンドしながらのビブラート（ベンドビブラート）、音程のない「チッ」**。これらは §10 の提案にした。

### 1.3 なぜ例は `autoScoop:false` か
`strum` の `D.D.D.D.`（1拍ずつ）の和音にも自動しゃくりがかかり、**コードの頭が毎回「キュッ」と下から上がる**【確認（コード）】。「ギターがキュインキュインする」（`song.mjs guide` の autoScoop の項）の原因になる。ソロの音も、`/` を書いたところだけで「下から入る」ほうが、意図が伝わる。

## 2. ソロの組み立て — ギターらしい設計

共通の原則（動機を決める・頂点は後ろ3分の1に1回・休符は句読点・速い音は終盤）は `melody-craft-guide.md` §5-0 に書いてある。ここでは**重複せず、ギターの演奏の事情から来る設計**を足す。

### 2.1 ソロの4段と、ギターで「何が起こるか」

| 段 | 役割 | 音の置き方 | 表情（技法）の段階 | 出典 |
|---|---|---|---|---|
| ①提示 | 覚えやすい動機を置く | 長め・音数少なめ・休符多め。音域は中〜低 | 音の頭は素直に。長音だけ軽いビブラート | 【確認】S7（動機は「パンくず」。聴き手が覚える足がかり）、S8（冒頭は単純で印象に残るフレーズ） |
| ②発展 | 動機を変形して緊張を足す | 音数を増やす／音域を上げる／リズムを変える（**1度に1要素**） | レガート・スライドなどの**つなぐ技法**を足す | 【確認】S8（速さ・複雑さ・新しい技法で緊張を高める）、S7（リズムを速め、フレーズの位置を上下させて勢いを出す） |
| ③頂点 | いちばん強い所を1回 | 最高音／最も速い所／最も感情的なベンド。ここに技法を集める | **ベンド＋ビブラート＋アクセント**（高音ベンド）。**最も技術が要る奏法は頂点のために取っておく**【確認】S12 | 【確認】S8・S12 |
| ④解決 | 落ち着いて次へ渡す | 単純な旋律に戻る／冒頭の動機を再現して締める | 長音のビブラート。フォール `\` | 【確認】S8（再現で結ぶ） |

> **表現の階段**【推測を含む整理】: ①素の音 → 長音の軽いビブラート → ②スライド・ハンマリング（つなぐ）→ ③ベンド → ベンド＋ビブラート（頂点）→ ④フォールで降りる。**階段を一段飛ばして最初からベンド＋深いビブラートを使うと、頂点で出す手がなくなる**。
>
> **表現の予算**【推測】: 8小節のソロなら、`~`（ビブラート）は 4〜5音、`^`（ベンド）は 1〜2音、`/`・`\` は 2〜3か所、`!`（アクセント）は拍頭と頂点だけを目安にする。**毎小節に全部載せない**（§8 の「ベンドが不自然」「ビブラートが不自然」の主因）。

### 2.2 モチーフ展開の操作（ギターで効くもの）
`melody-craft-guide.md` §5 と `node tools/composer/song.mjs motif`（動機の変形）に変形の道具がある。ギターで特に効く操作だけ並べる。

| 操作 | 例（動機 `A4 D5 F5`） | ギターでの意味 | 確度 |
|---|---|---|---|
| 反復進行（隣の高さで同じ形） | `C5 F5 A5` | ポジションを上げるだけで弾ける。「同じことをもう一度」が最も歌になる | 【一般】 |
| リズムを変える | `A4:0.5 D5:0.5 F5:1.5` → `A4:1.5 D5:0.5 F5:0.5` | 音を変えずにリズムだけ変える。答えを作るときの基本 | 【確認】S10（音は同じでリズムを変える） |
| 断片化（最初の2〜3音だけ） | `A4 D5` | 速弾きの前の「溜め」。短い断片を休符で区切る | 【一般】 |
| 装飾を足す | `A4 D5 F5` → `A4 (C5_ D5) F5~` | ハンマリング・スライドの経過音（`_` つき0.25拍）を足す | 【確認】S23（半音の指のスライドで目標の音へ滑らかに入る） |
| オクターブ上げ | `A5 D6 F6` | 頂点の演出。ただし E6 より上は書けず、高域は刺さる（§8）。**頂点でも A5〜C6 まで** | 【確認】音域（leadGuitar は E3〜E6）／【推測】C6まで |
| 反行（上と下へ広がる） | 上へ行く声と下へ行く声 | 速弾きの見せ場（`melody-craft-guide.md` 5-4） | 【一般】 |

### 2.3 問いと答え（コール＆レスポンス）
- 一つのフレーズが「問い」、次が「答え」。会話になり、音階の羅列にならない【確認】S10。
- **12小節ブルースの伝統的な分け方: 小節の前半に歌（問い）、後半にギター（答え）**【確認】S10。ギターは「歌が終わってから入る」。早く入ると歌にかぶり、早く終わるとフレーズが未完に聞こえる【確認】S10。
- 答えの作り方【確認】S10: ①問いを繰り返してから答えを変える ②音を同じにしてリズムを変える ③和音（リズム）に対して短い単音で答える（ブルース・ファンク・ソウルで有効）。
- 練習の縛り【確認】S10: 答えを「2拍」「1小節」「3音」に制限する。**書くときも、答えは問いより短くすると締まる**【推測】。
- 問いは**不安定な音（2度・4度・7度、または5度）で止め**、答えは根音か3度で止める（`song.mjs guide` の「問い／答え」）。
- 「問い」にベンドを使うと**上がりきらない緊張**、「答え」にフォールやスライドダウンを使うと**落ち着く**ので、技法そのものが問答になる【推測】。例 G2。

### 2.4 ピークの作り方（まとめ）
1. 最高音は**1回**、後ろ3分の1（`melody-craft-guide.md`）。
2. ピークの直前に**1拍の休符**か、低い音からの跳躍で「溜め」を作る【一般】。
3. ピークの音は**長く（1.5〜3拍）**、`!`＋`^`（ベンド）＋`~`（ビブラート）。**3つとも付けるのは頂点の1音だけ**。
4. 上げるのは**速さ・音域・表情**の3つのうち、一度に**2つまで**【推測】（全部上げると詰め込みすぎに聞こえる）。
5. ピーク後は**降りる**: フォール `\`、下行、休符。S7 の例: 低く始め、小さな谷を挟みながら階段状に上がり、最後に頂点【確認】。

### 2.5 休符の使い方【確認】S7・S8・S10・S12
- 「静けさは音と同じくらい強い」【確認】S8。間（ま）は直前のフレーズを際立たせ、次への期待を作る【確認】S7。
- 休符は**フレーズの切れ目だけでなく、フレーズの内側にも**置く（ジャズの8分の流れを休符で崩す。S11）。
- 「空間を埋める」のは中級者の典型的な失敗【確認】S10。
- 目安【推測】: 8小節のソロで、**音のない拍が全体の20〜30%**。4小節に1回は2拍以上の休符か長音。
- 歌のあるセクションでは、**歌の休符にだけ**ギターを入れる（§7）。

### 2.6 ジャンル別: ソロの長さと構成

| ジャンル | 長さの目安 | 構成の型 | 音の密度・表情 | 確度 |
|---|---|---|---|---|
| ポップ／J-POP | 間奏 **4〜8小節**。歌メロをなぞる／変奏するのが主。長いソロは入れない | 歌のメロディを下敷きに、装飾（スライド・ハンマリング）だけ足す。最後はサビ頭へ | 密度低め。ビブラートは長音だけ。ベンドは1回まで | 【一般】【推測】 |
| ロック／パワーポップ | **16小節以上**が普通、**8小節は少数派だが有効**。ロック／パワーポップのソロは冒頭から勢いが要る | 冒頭で爆発して曲のエネルギーを上げ、次のセクション（最後のヴァース／サビ）へ飛び込む | ベンド・ビブラートが主。アンプの粘りで長音を歌わせる | 【確認】S13（長さと「冒頭から爆発」）／【一般】 |
| ハードロック | 16小節＋最後に速い締め | 提示（ペンタトニックの歌うフレーズ）→ ブルース的な問答 → 速いラン → 高音ベンドで頂点 | ベンド＋速いビブラート（幅広）。ペンタ主体 | 【一般】 |

## 3. 表情づけ — ビブラート・ベンド・スライド・レガート・強弱

### 3.1 ビブラート

**種類**【確認】S1・S2
| 種類 | 動き | 音の特徴 | ソフトで近い書き方 |
|---|---|---|---|
| 指（クラシック）ビブラート | 指先を弦と平行（ネック方向）に小さく揺らす | 音程の揺れが小さく、音程補正にも使う。控えめ | `~`（深さ0.7）。幅が小さい |
| 手首ビブラート | 弦をフレットと直角（上下）に押し引きする。手首の回転で力を出す（B.B.キング式） | 豊かで歌う。ブルース・ロックの定番 | `~~`（深さ1.0） |
| 前腕ビブラート | 腕全体を上下 | まれ | ー |
| ダブルストップのビブラート | 2弦を同時に揺らす（ヘンドリックス式） | 太い | 2パートに同じ `~` |
| ベンド上のビブラート | ベンドの頂点で、戻しては上げる | **最も声に近いビブラート**【確認】S4 | **×**（ベンドしながらの揺らしは表せない）。`^^~` で近似 |
| アーム（ビブラートバー） | 上げ下げ | ふわっとした揺れ | `~~` で近似（§10 提案） |

**速さ×幅の組み合わせと使いどころ**【確認】S1・S2（数値は出典に無い。ソフトでは速さを変えられない）
| 組み合わせ | 聞こえ方 | 場面 | ソフト |
|---|---|---|---|
| 遅く・狭く | しっとり、控えめ。マイナーブルース | バラード、悲しい場面 | `~` を長音に |
| 中くらい・中くらい | 標準（出典の筆者の既定） | 迷ったらこれ | `~` |
| 中・広め | 大胆。大きいアンプの音 | ロックの山場 | `~~` |
| 速く・広く | エネルギッシュ（アンガス・ヤング型）。目立つ | ハードロック、メタルの頂点 | `~~`（速さは音源任せ。耳で確認） |
| 速く・狭く | 緊張・震え | 不安、ホラー | `~`（速さは音源任せ） |

**使い方の定石**
1. **まず目標の音程を鳴らし、少したってから揺らす**（練習法としても、頭は音程をはっきり）【確認】S1。→ ソフトは自動で0.4拍まで待つ（§1.1）。
2. **揺れは音程の中心をまたぐ**。出典はベンドでは「わずかに（シャープ側へ）行き過ぎて、戻ったところが正しい音程」と説明【確認】S1。
3. **揺れの幅・速さが途中で急に変わるとガタついて聞こえる**【確認】S1。ソフトは1音の中で一定なので、この失敗は起きにくい。逆に**毎回完全に同じ深さ**が機械的に聞こえる原因になる（`~` と `~~` を使い分ける、`~` を付けない長音も混ぜる）。
4. **全部の音に揺らさない**【確認】S1（筆者自身もしない）。人間の指示（§0.3）もある。
5. 幅を広げすぎると音程が外れて聞こえる【確認】S1。

**ジャンル別**【確認】S1（遅く狭い＝マイナーブルース、広く＝大胆）／【一般】

|---|---|
| ブルース | 長音の `~`（ゆっくり）。ベンドの頂点だけ `~~` |
| ロック／ハードロック | 山場の長音に `~~`。その他は無印 |
| メタル | 頂点の長音に `~~`。速いランには付けない |
| バラード | 2拍以上の音の後半に `~`。毎フレーズ末に付けない |
| ジャズ | ほぼ付けない。付けても `~` を1〜2か所（S11: 飾り程度） |
| ナイロン弦（ボサ・クラシック） | 付けない。長音は `sustain` ではなく自然な減衰 |

**ベンドの音程の確かさ**
- よくある失敗は**届かず低い（フラット）**【確認】S3。→ 書くときは**ベンド後の音（目標）が音階の音か**を確かめる。`C5^^`＝D5 になるので、D5 が和音に合うか。
- ブルース・ロックのベンドの目標は、**和音の構成音か、次に動く音**に置く。和音の半音上で長く鳴らすと濁る（`build` の注意が出る）。

**ベンドのタイミング**【確認】S4
- 普通のベンドは**リズムの中で（拍に合わせて）**上げる。グレースノートベンドは**拍の前**に置く。プリベンドは先に曲げるので、音程の予測が要る。
- ゆっくりリリースして深いビブラートを足すと、表情の深い持続フレーズ。速いビブラートは切迫した場面【確認】S4。→ ソフトでは**2拍以上の音＝ゆっくり上がる**、**1拍前後の音＝速く上がる**（§1.1）。

### 3.3 スライド

**種類**【確認】S6
| 種類 | 動き | ソフトでの書き方 |
|---|---|---|
| **レガート・スライド** | 出発の音だけ弾き、目標の音は弾き直さない。滑らかにつながる | 経過音を `0.125_` の半音の連なりで（`B4:0.125_ C5:0.125_ C#5:0.125_ D5:1.625!`） |
| **シフト・スライド** | 目標の音を弾き直す。着地の音が強く明瞭 | 経過音のあとの目標に `!`（同じ書き方で、最後の音を強く） |
| **スライドで入る（装飾）** | 出発の音が不定で、一瞬で目標へ | `E5:3!/`（下から入る） |
| **スライドで出る／落ちる** | 音を伸ばしたまま落とす | `A4:1.25\`（終わりで落とす） |

- **遅いスライドは意図的でなめらか、速いスライドは鋭く到着が即座**【確認】S6。→ 経過音の長さ（0.125 → 0.25）で変える。
- 出発の音を「音階の音」にするか「半音隣」にするかで性格が変わる（S6）。半音の指のスライドで目標へ入る流れの良さは S23 も書く【確認】。
- 長い距離のスライドは音数が多くなるので、**経過音は多くても6〜8個**（`0.125` × 8 ＝ 1拍）【推測】。経過音が多すぎると「音階のラン」に聞こえる。
- 例 X3（G、bpm 80）: 小節1＝上へのレガート・スライド、小節2＝下へのスライド＋最後にフォール、小節3＝しゃくりで入る長音、小節4＝フォールで終わる。

### 3.4 レガート（ハンマリング・プルオフ）の滑らかさ

- ハンマリングは**指の位置が大事**（フレットに近すぎ・遠すぎでは音が死ぬ）。プルオフは**指で弦をはじいて**音を出し、ただ離さない【確認】S23。
- **クリーンな音で練習する**: 歪みは強弱を押しつぶして、弱い音を隠す【確認】S23。→ ソフトでも、**レガートの聞こえ方はクリーンのほうがわかりやすい**。歪み系で `_` を使うなら、2音目の `,` が埋もれないか耳で確認【推測】。
- 実演ではピッキングする音とレガートの音を混ぜ、**弦移動でピッキングを入れる**とつながりが保てる【確認】S23。
- **ソフトの書き方**: 1音目 `_`（次に重なる）、2音目は `,`（弱く）。短い連続は 0.25拍／0.125拍。`autoArticulation` の自動付与は「短い2音を50%でハンマリング風」（§1.2）。
  - `G4:0.25_ A4:0.25,_ B4:0.25,_ D5:0.5!`＝3音のレガートから最後をピッキング（強く）。
- レガート連続は**5〜6音まで**で切り、頭に `!` を入れる（均一だと機械的）【推測】。

### 3.5 ピッキングのアタックの強弱とダイナミクス

| 段 | 記号 | 強さ | 使いどころ |
|---|---|---|---|
| 強 | `!` | ×1.3 | 拍頭、アクセント、頂点 |
| 普通 | 無印 | ×1.0 | |
| 弱 | `,` | ×0.7 | アップピッキング、レガートの2音目、ゴースト |
| 切る | `'` | gate ×0.4 | 禁止の音との境（同音連打には使わない） |
| 重ねる | `_` | gate ×1.15 | レガート |

- **3段しかない**ので、それ以外の強弱は次で作る: ①パートの `volume`（全体）②`phrase`（4拍や8拍ごとに「出だしは弱く、山で強く、終わりは引く」）③`dynamics:"natural"`（曲全体の山と谷・拍の強弱・音ごとのばらつき）④`parts[].sections` で出し入れ。
- **「ある音は強く、次は弱く」という自然な強弱の偏り**が、人間らしさの元【確認】S27（一つの音を強く、次を弱く。ランダムは過剰になる）。
- **サンプル音源は強さで音色も変わる**【確認】S27・S28。書き出しの音源で `!` が明るく太い音になるかは耳で確認。
- 強弱のつけ方のジャンル差【確認】S21・S20／【一般】
  - アコースティックのストロークは**ダウン主体、2拍目と4拍目の終わりにアップ**の型が基本【確認】S21（ダウンを強く、アップを弱く）。
  - ファンクは**右手は常にダウン・アップを刻み続け、左手の押さえ方でミュート（スクラッチ）と鳴らし（スタブ）を切り替える**【確認】S20。→ ソフトでは `x` と短い和音の混ぜ方（§5.4）。
  - メタル／パンクの8分刻みは**拍頭を強く、他を同じ強さで**（弱すぎるアップを作らない）【一般】。

### 4.2 速さと正確さの考え方

**人間の演奏の側（出典）**
- **ゆっくり、メトロノームで**始め、1ストロークずつ正しく【確認】S17。
- **動きを節約**（エコノミーの「最小の動き」）。ムダな動きを消す【確認】S17。
- **ストロークを「きつく・均一に」**【確認】S17。
- **グループの最初の音にアクセント**を置くと拍の位置を見失わない（5連符のまとまりなど）【確認】S17。→ ソフトでも**16分を4つずつのグループにして、頭に `!`**（P1）。
- ハイブリッドは**手首を中立、ピックを握りしめない、指は手のひらに向けて閉じ、外へ弾かない**（外へ弾くと緊張・タイミングの乱れ）【確認】S18。
- スウィープは**左右の手を合わせ、指を上げて1音ずつ切る**。合わないと音が混ざる【確認】S15。

**ソフトに翻訳すると**
1. **16分の連打は、人間の限界を意識して**: 16分音符が1秒に何回になるかは `bpm÷60×4`。例 bpm 100＝6.7回/秒、bpm 140＝9.3回/秒、bpm 180＝12回/秒。**bpm 160 を超える16分の連続（持続的なオルタネイト）は、実演の限界に近い**【推測】。超えるなら、①8分に下げる ②休符を挟む（4音＋休符）③バースト（1〜2拍）にする。
2. **0.125拍（32分）の連続は1フレーズ8音まで**を目安に【推測】。それ以上はレガートの扱い（`_`）にして、ピッキングで弾く音ではないと分かるようにする。
3. **すべてを正確にしない**: 速弾きでもアクセント（`!`）と弱（`,`）を混ぜる。`human` を 0.3 以上にすると、速いフレーズでもずれる【確認】（`song.mjs guide`）。**スウィープやタッピングのように「正確さが売り」のものは `human` 低め**【推測】。
4. **同じ高さの短い連打は禁止の音**。トレモロは `leadGuitar`＋amp `lead`／`loudmetal`、1〜2拍のバーストで（`guitar-techniques-rock-guide.md` §1）。

## 5. リズムギターのテクニック

### 5.1 ストラミングの強弱パターン
`strum` の型の文字: **D** ダウン／**d** 弱いダウン／**U**・**u** アップ（高い弦だけ・弱く）／**x** ミュート／**.** のばす／**-** 休み。1文字＝0.5拍（`step` で変える）。

| 型（8文字＝4拍） | 意味 | 使いどころ |
|---|---|---|
| `D.D.D.D.` | 4分ダウンだけ | バラード、ゆったり、ソロの伴奏（G1〜X4の伴奏） |
| `D.DU.UDU` | 定番のポップ（既存 `guitar-techniques-world-guide.md`） | フォーク、ポップ |
| `D.du.UdU` | **強弱つき**: 1拍目を強く、途中のダウン／アップを弱く | 歌の伴奏を邪魔しない |
| `D.xuxUdx` | **ミュート混ぜ**: 3文字目と8文字目をミュート | 歌ものの弱拍、バンドが入る前の導入 |
| `DxuxDxuxDxuxDxux`（`step:0.25`） | **16分ストローク**＋ミュート | 軽い16ビート、ファンク寄りのポップ |

- 実演で**右手は常にダウン・アップを刻み続け**、音を出さない拍も腕は動いている【確認】S20。→ 「強弱」は鳴らす・鳴らさないではなく**当てる強さ**。ソフトでは `d`・`u` が弱い音、`x` が当てて鳴らさない音。
- アコースティックの基本形: **ダウン主体**で、**2拍目と4拍目の終わりにアップ**【確認】S21。
- ストロークの `spreadMs`（6弦が時間差で鳴る）は 10〜25ms が自然。大きすぎると「ジャラ〜ン」と間延びする【推測】。**strum は最大5〜6パートに展開される**ので、同時に鳴るギターの数（上限6）に注意（`build` が警告する）。

### 5.2 ミュートの混ぜ方
| ミュート | 音 | ソフトで近い書き方 |
|---|---|---|
| **パームミュート（ブリッジミュート）** | 手刀をブリッジに当てる。「ズンズン」【確認】（歌ネット・リットー、`rock-guide` §1） | 低い音域、`sustain` 0.8〜1.1、amp `loudrock`／`loudmetal`／`modernHigh`、拍頭だけ `!`。`'` で短くしすぎない（禁止の音） |
| **左手ミュート／ブラッシング** | 音程のないパーカッシブな音【確認】S20 | `strum` の `x` |
| **ハーフミュート** | パームミュートより軽く触れる | `bright` を -0.3、音を少し短く（`sustain` 0.8）【推測】 |
| **ノンミュートの「開放」** | ミュートの刻みの中で、開放で鳴らして対比 | 刻みの小節末に長音（R2 の小節4 `E2:3!`） |

- 混ぜ方の定石【確認】S20・（`rock-guide`）: 刻み（ミュート）の中の**アクセントだけをミュートせずに鳴らす**。ミュートとノンミュートの**対比**が表情になる。

### 5.3 ゴーストストローク
- 音程のない「チッ」を挟んでリズムを埋める【確認】S20。
- ソフトは**音程のないノイズは出せない**。近似は ①`strum` の `x` ②弱く短い音（`,` ＋ 0.25拍）を休符の位置に混ぜる。**ただし短い同音連打は禁止の音 1 に近い**ので、必ず**和音（複数パート）**にし、低めの音域で（E3〜G4）、volume を小さく（0.04〜0.08）。

### 5.6 オープンボイシングの響かせ方
- **閉じた三和音を開く**: 最低音を1オクターブ上げ、最高音を1オクターブ下げる。D–F#–A（5・4・3弦）が A–F#–D（6・4・2弦）になる【確認】S22。幅が広がり、**隣り合わない弦**になるので、ハイブリッドか指で弾く【確認】S22。
- **1音足すと色が変わる**: add9・6・maj7（開いた三和音に1音）【確認】S22。**弦楽三重奏やホーンのように、他の音を保って一部だけ動かす**ことができる【確認】S22。
- 弾き方のコツ: **"let ring"**（音を押さえたまま伸ばす）で和音の構成音が重なって響く【確認】S22。→ ソフトでは `sustain` 2〜3（P3）か、`strum` の「のばす（`.`）」。
- **開放弦を含むオープンコード**（C G Am Em D Dm E A）は `strum` が形を知っているので、そのまま鳴らすのが最も自然。

### 5.7 コードの転回形の選び方
| 状況 | 選ぶ形 | 理由 | ソフトでの書き方 |
|---|---|---|---|
| ベースが動く進行 | **分数コード**（A/C#、G/B）でベースを順次進行に | ベースがなめらかに下がる／上がる | `chords: "D A/C# Bm7 G"`（R1） |
| 高い音（トップノート）を歌わせたい | トップを順次進行（G→F#→E）にする転回形 | 声部が滑らか、伴奏が旋律として聞こえる | 3声のパートを分ける（R3 の方式） |
| 同じコードが続く | 転回形を交互に（`C` と `C/E`）【確認】S22（I–IV–♭VII–IV で異なる形を使う） | 繰り返しが退屈にならない | `chords` に分数コードを混ぜる |
| ベースと近い低域 | **ギターの最低音を上げる**（ルートを抜く、3度から） | 80〜150Hz を削ってベース・キックとぶつからない（`arrangement-deep.md`） | 5声のうち低い声を省く（`strings: 4`） |
| 暗くしたい／明るくしたい | 低い転回形＝暗く太い／高い転回形＝明るく軽い | 音域で色が変わる（§6） | 音域を指定する |

### 5.8 2本のギターの役割分担

## 6. ポジション取り — 音域・弦・開放弦・ボイシングで色を選ぶ

### 6.1 音域ごとの音色（ソフトの音域と、基音の周波数）
標準チューニングの基音（A4=440Hz）【一般】: E2 82Hz／A2 110／D3 147／G3 196／B3 247／E4 330／A4 440／E5 659／E6 1319。倍音はこの数倍まで続く。

| 音域 | 弦の感じ | 音の性格 | 向く役 | ぶつかる相手 | ソフトの注意 |
|---|---|---|---|---|---|
| E2〜B2 | 太い巻き弦（6・5弦）【確認】S29 | 太く暗い。パワーコードの根音、刻み | リズムの土台、ブリッジミュート | ベース（E1〜G3）と80〜200Hz。キック（60〜145Hz） | `distGuitar`（E2〜E4）。80〜150Hz は削る【確認】`arrangement-deep.md`。ギターの100Hz以下は不要【確認】S24 |
| C3〜B3 | 巻き弦から細い弦へ（4・3弦）【確認】S29 | 太さと明るさの中間。コードの土台 | コード、ストローク、低めのオブリガート | 鍵盤の左手、男声 | `guitar`（E2〜E5）の中心。ストロークの中心はここ |
| C4〜B4 | 細い平弦（2・1弦。3弦は平弦の場合も）【確認】S29 | 明るく歌う。中域の主役 | 旋律、ハモリ、オブリ、アルペジオの高音 | 歌（中域）、鍵盤の右手 | **旋律は迷ったらここ** |
| C5〜E5 | 最も細い弦 | 明るく透明。ベンドしやすい【確認】S29（細い弦はベンド・ビブラートが楽） | ソロの山場、ハーモニクス風 | シンバル、女声、鍵盤の高音 | `guitar` はE5まで |
| F5〜E6 | 高いフレット | 細く鋭い。基音は約0.7〜1.3kHz だが、**倍音が6kHz以上に伸びて刺さる** | 頂点の一音だけ | スネア、シンバル、ボーカルの子音 | `leadGuitar`（〜E6）。頂点でも C6 まで【推測】。amp `crystal`、`bright` を下げる（§8） |

- **同じ音高でも、どの弦で弾くかで音色が違う**: 太い弦＝暗く大きな音、細い弦＝軽く明るい音【確認】S29。例えば E4 は1弦の開放でも、4弦の14フレットでも出せるが、太さが違うので響きが違う【一般】。
- **作曲ソフトでは弦を選べない**（音高から音源が決まる）。音域の選び方が「弦の選び方」の代わり【確認】`song.mjs guide`。ストロークの形（`strum`）は弦の形を知っている。
- 巻き弦（6・5・4弦、時に3弦）と平弦（1・2弦、時に3弦）の境目で音の質が変わる【確認】S29。

### 6.2 開放弦とハイポジションの使い分け
| | 開放弦を含む形 | ハイポジション（高いフレット） |
|---|---|---|
| 響き | 余韻が長く、開放的で明るい【一般】 | 細く集中した音、歌うように持続、ベンド・ビブラートが効く【一般】 |
| ミュート | 手で止めにくい（全体を消すのが難しい） | 押さえた弦は止めやすい【一般】 |
| 使いどころ | オープンコードのストローク、add9／sus、**ペダル（低い開放弦を鳴らしたまま上の旋律を動かす）** | ソロの山場、ハモリの上の声、リードの歌 |
| ソフト | `strum` の開放形（C G Am Em D Dm E A）／長い `sustain` | `leadGuitar` の C5 以上、ベンド・ビブラート |
- ペダルの例: 低い E2 を保ち（`drone:"root"`、パートの `drone` で自動）、上で E4〜B4 を動かす。ギターらしい「開放弦を残した響き」を作れる【確認】（`rock-guide` §1「コード・ボイシング」）。

### 6.3 ボイシングによる色の違い
| ボイシング | 色（聞こえ方） | 使いどころ | 確度 |
|---|---|---|---|
| パワーコード（根音＋5度） | 3度が無く、**長調にも短調にも寄らない**。歪みでも濁らない | ロック・パンク・メタルの刻み | 【確認】`rock-guide` |
| 閉じた三和音（近接） | 密集して太い。低域で濁る | 中〜高音域のストローク | 【一般】 |
| 開いた三和音（開離） | 透明で広がる。弦楽三重奏のような**間** | アルペジオ、バラード、ジャズのコンピング | 【確認】S22 |
| 3度・7度だけの2声（ガイドトーン） | 和音の性格が決まり、ベースが根音を担当 | ジャズ（フレディ・グリーン式、世界ガイド J1） | 【確認】世界ガイド |
| sus2／sus4 | 3度が無く浮遊・解決待ち | イントロ、サビ前 | 【一般】 |
| add9／6／maj7 | 開いた三和音に1音足す。明るく洗練 | J-POP、バラード | 【確認】S22 |
| m7／m9／9th | 少し大人、ブルース、ジャズ | ファンクのカッティング（R3） | 【一般】 |

**高域の色**: ボイシングを高い音域に置くほど「細く光る」、低く置くほど「暗く重い」。同じ Am でも、A2 起点（太い）と A3 起点（中）と A4 起点（細い）で別の曲に聞こえる【一般】。

## 7. アンサンブルの中のギター — ベース・ドラム・鍵盤・歌とのすみわけ

### 7.1 帯域（高さ）のすみわけ
| 相手 | ぶつかる所 | すみわけの書き方 | 確度 |
|---|---|---|---|
| ベース（E1〜G3） | **ベースの倍音がギターの帯域に重なる**【確認】S25。ギターの100Hz以下は切ることが多い【確認】S24 | ギターは **E2 より低い音域を使わない**／パワーコードのルートを抜いて5度から／ギターの低音域を削る（`arrangement-deep.md`: 80〜150Hz） | 【確認】 |
| キック | 60〜145Hz（`song.mjs guide`）。ギターの低域と重なる | キックのある拍はギターの低い根音をぶつけない（`duck` はベースやパッドに） | 【確認】 |
| 鍵盤（エレピ・ピアノ） | **ギターとエレピは低中域がともに厚い**【確認】S25。**ギターとピアノが同じ音域で和音を弾くと混む。片方を1オクターブ上げる**【確認】S26 | 鍵盤が C3〜E4 の和音なら、ギターは**オクターブ上のアルペジオ**か、**刻みだけ**に。交互に出入りさせる | 【確認】 |
| 歌（旋律）・歌の代わりのリード | 歌の帯域とギターは**同じ中域**【確認】S24 | リズムギターは歌より**低く薄く**、歌の休符にだけオブリ（E1）。**歌より先に弾かない・歌にかぶせない**【確認】S10 | 【確認】 |
| シンバル・スネア | ギターは高域で上に出すぎると衝突【確認】S24 | **6kHz以上をギターで出さない**（禁止の音）。高い音域は頂点の一音だけ | 【確認】 |
| 弦・パッド | 広い帯域を埋める | ギターが歪み、弦が長音のときは**ギターを刻みに**（`arrangement-deep.md`） | 【一般】 |

### 7.2 リズムのすみわけ
- **ベース**は**キックと噛み合わせる**（キックのない位置は経過音）。ギターは**キックの位置を避けて裏拍**にアクセント（レゲエのスカンク、ファンクのカッティング）【一般】。
- **複雑なパート同士は同じ場所でぶつかる**。例: 忙しいベースとフロアタムが同じ音域で重なるなら、**片方を単純にする**【確認】S26。
- **歌がある所は、ギターを引く**。歌の休符に合いの手【確認】S10（歌に重なるのは典型的な失敗）。S25 のサイドチェイン例（トランペットが入るとギター群が凹む）と同じ考え方。作曲ソフトでは、**歌・旋律のパートを `parts[].sections` で出し入れ**する（`{"verse":0.6,"chorus":1}` など）。
- **ブレイク**（一度全員を止める）では、ギターの余韻を残す（`keepBreak:true`）か、完全に止めて次の頭に全員で戻る。

## 8. よくある打ち込みの失敗と直し方

| 症状（聞こえ方） | 主な原因 | 直し方 | 悪い書き方 → 良い書き方（ノート列） | 確度 |
|---|---|---|---|---|
| **機械的に聞こえる** | 全部同じ強さ・同じ長さ・グリッドぴったり・同じ音の連打【確認】S28・S27 | ①`!` と `,` で偏りをつける（強い音の次は弱く）②`phrase` 4か8③`dynamics:"natural"`④`human` 0.3〜0.6⑤休符⑥くり返しを手で少し変える | `E4:0.5 G4:0.5 A4:0.5 B4:0.5 D5:0.5 B4:0.5 A4:0.5 G4:0.5` → `E4:0.5! G4:0.5, A4:0.5 B4:0.5! D5:1_ B4:0.5, A4:1 R:0.5` | 【確認】S27・S28 |
| **音が切れる／ぷつぷつ** | 短い音（`'`、0.25拍以下）の往復、`sustain` 不足、音の間の隙間【確認】`banned-sounds.md` | 長めの音と `_`（レガート）、単音の刻みをやめて**アルペジオか和音**に。音の間を詰める | `A4:0.25' C5:0.25' A4:0.25' C5:0.25' A4:0.25' C5:0.25'` → `A4:0.5_ C5:0.5_ E5:1.5_ C5:0.5_ A4:1` | 【確認】 |
| **高域が刺さる** | 音域が高すぎる（F5〜E6）、amp が明るい、`bright` が高い、残響の高域【確認】`amp-sim-guide.md` | 頂点の一音以外は **E5 以下**。amp `crystal`／`lead`、`bright` -0.3、`reverb` で奥に。6kHz以上は出さない | `A5:0.5 C6:0.5 E6:1.5` → `A4:0.5 C5:0.5 E5:1.5` | 【確認】 |
| **ビブラートが不自然** | 全部の音に付けた【確認】S1、幅が広すぎる【確認】S1、毎回同じ深さ、自動付与（autoArticulation）と手書きが重なる【確認】人間の指示 | **1拍以上の長音だけ**、`~` と `~~` を使い分け、付けない長音も混ぜる。`autoArticulation` を使うなら手書きの `~` は控える | `A4:1~~ B4:1~~ C5:1~~ D5:1~~` → `A4:0.5 B4:0.5 C5:1 D5:2~` | 【確認】 |
| **ベンドが不自然** | 短い音に付けた（効かない／一瞬）、目標の音が和音に合わない、毎音ベンド、戻りが無い | **0.5拍以上**（できれば1拍以上）の音、目標を確認、頂点だけ、`^^\\` で戻す | `A4:0.25^^ C5:0.25^^ D5:0.25^^ E5:0.25^^` → `A4:0.5 C5:0.5 D5:2!^^\\ R:1` | 【確認】 |
| **キュインキュインする** | 自動しゃくり（autoScoop）が、ストロークの和音や長音にかかる | 曲に `autoScoop:false`。必要な所だけ `/` を書く | ー | 【確認】`song.mjs guide` |
| **レガートがぎこちない** | 強さが均一、つなぎの `_` が無い、速すぎる | 1音目 `_`、2音目以降 `,`、頭を `!`、5〜6音で切る | `G4:0.25 A4:0.25 B4:0.25 D5:0.25` → `G4:0.25_ A4:0.25,_ B4:0.25,_ D5:0.5!` | 【確認】S23 |
| **ストロークが「ジャラン」と一斉** | `spreadMs` が小さすぎ（機械的）または大きすぎ | 10〜25ms、アップを `u` に | ー | 【推測】 |
| **ギターがうるさい／歌にかぶる** | 同じ帯域、休符が無い、volume が大きい | 歌より小さく、歌の休符に入れる（§7）。歪みは 0.05〜0.12 | ー | 【確認】 |
| **のっぺりして覚えられない** | 動機が無い、リズムが一様 | `melody-craft-guide.md` §6。リズムを先に変える | ー | 【確認】 |
| **速弾きが雑音に聞こえる** | 0.125拍の連続が長すぎる、すべて同じ強さ | 8音まで、4つずつの頭に `!`、バーストにする | ー | 【推測】 |
| **残響で濁る** | `reverb` と `echo` を両方強く／全パートに | 奥に置くパートだけ。`reverb` 0.15〜0.3、echo の decay は 0.3 以下 | ー | 【一般】 |

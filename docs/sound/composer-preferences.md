# 旭さんの曲づくりの好みと決まり（作曲ソフトで曲を作るとき、毎回はじめに読む）

クラウドの Claude が会話の中で教わってきたことを、パソコンの Claude Code でも同じように守れるようにまとめた（2026-10-29）。新しく教わったら、ここに書き足す。

## 進め方
- 話し・報告・説明・コミットは日本語。子どもからお年寄りまで読めるやさしい言葉で。
- 作るときは情報を深く集めてこだわる。学ぶ・調べるよう頼まれたら、早く切り上げず徹底的に。ジャンルの決まりごと（見本）を先に確かめ、無ければ調べてから作る（全部なぞる必要はない）。
- 作る前に「曲を決める表」を書いて見せる。列: 曲／形（物語の言葉での骨組み）／場面と、そこで必要な強さ／旋律の性格（＋始まり方・終わり方・山・伴奏の主役・ただひとつ）。ほかの曲と並べて、始まり方と終わり方・山と静けさの置き方・旋律の動き方とリズムの形・リードとリフの音が似ていないか確かめ、似ていたら作る前に直す。
- 曲にはストーリーを持たせる。その曲の物語でしか出てこない音や展開を1曲に最低1つ入れる（ただひとつ）。
- できた曲は zip にまとめず、mp3 を1曲ずつ、その場で聞ける形で渡す。保存先: C:\Users\fujik\Downloads\<曲集の名前>\ と G:\マイドライブ\<曲集の名前>\。
- 点数は基準として必要だが、最後は耳で判断する。書き出したら点数だけで判断せず、区間ごとに単調なところ・急に小さくなる所・前奏が小さすぎる所がないか確かめてから渡す。
- 音質の点数（Audiobox Aesthetics の PQ）: ふだんの曲は最低 7.5、目標 8。ケルト100曲は 静の曲 7.0・動の曲 7.5 を超えればよい（2026-10-29 に 7.2・7.8 から変更。「似たような感じからはなるべくしないで」）。
- 音量を「5上げて」「10下げよう」と数字で言うときは割合（5上げ＝×1.05、10下げ＝×0.9）。調整は 1〜10 ではなく 1〜1000 くらいの細かさで。パート別に数値で調整してから、最後に全体を調整する。
- ゲームの曲と言われたときだけゲームの曲（曲名や音にゲームの要素を出さない）。曲名はよく使われる言葉でもよい。
- **点数を上げるために、全部の曲に同じ処理を入れない**（2026-10-29「点数あげる為に全部同じにしない。それはただの作業でしかない」「楽するな。１曲を丁寧に作り上げなさい」）。床・きらめき・厚い弦・前奏の持ち上げなどの部品は、その曲の場面に要るときだけ、その曲に合う形で使う。似た所があってもよいが、始まり方・弾き方・流れが全部同じになるのはだめ。全曲に関わる変更は、勝手にせず先に相談する。
- 一度決めたことを全曲に当てはめない。固定概念に頼らず柔軟に。追加した音源は「使える素材」で、毎回使う決まりではない。省きすぎて薄くしない・ごちゃごちゃして聞きにくくもしない。

## 曲づくり全般
- 同じような曲・似た曲・つまらない曲・単調な曲・曲として成り立っていない物は作らない。展開の骨組み・旋律・リズムの形が似た曲はいらない。既存の物にとらわれない旋律に。
- 全曲を同じ展開にしない。始まり方（サビから・前奏・ドラムだけ・ベースだけ等）・流れ・終わり方を曲ごと・物語ごとに変える（ただし「必ず変える」も固定概念。同じリフのままでもよい）。
- 強弱は区間の種類で決めず、場面ごとに必要な強さを決める。人が演奏しているように。全曲に人間っぽさ。
- 曲の途中で不自然に音が小さくならない（特に前奏→Aメロ）。前奏が小さすぎないか作るときに確かめる。
- 音域（スケール）を広く使う。定番のコード進行以外もやる。
- リードなどの音色は曲調に合わせて曲ごとに選ぶ（気に入った音でも全曲に同じ音を入れない）。曲ごとに1つだけ入れる楽器は主役として音量を上げてよい。
- FX はいくつか作って重ねて、空間の透明感と深みを出す。場面のある曲はその場面の空気（環境音）も感じられるように。ただし「空間を支配する」は、作った効果音や環境音で埋めることではなく、**音楽の音そのもので耳を気持ちよくして支配する**こと（2026-10-29）。
- ピアノは単音ばかりにせず、コード弾きも入れて左手と右手で弾くイメージに。主旋律と速弾きで別トラックに分けてもよい。
- 場合によって: ベースを2種類重ねる／ドラムに場所ごとのインパクト音／キックを2種類／わざとノイズ音を入れて深み／シンセでデジタルっぽく空間を支配する。

## ドラム
- 単調にしない。緩急・間・グルーブ。強弱・アクセント・ゴースト。ライド・タム・フロアも使う。シンバルは鳴りを伸ばす（すぐ止めない）。
- その曲に合ったドラム。エイトビートでもライドで刻むなど、ハイハット以外も曲に合わせて。オープンとクローズのハイハットの使い分け。
- 学んだプログレのテクニックをふつうの曲に一律に当てはめない（ぐじゃぐじゃに聞こえる）。シンプルなフレーズを色々、曲に合うものを。フィルはただ回すだけでなく、アクセントになるカッコいいフィル。
- 音色: Naked Drums の素直な版（処理なし）が好評。ジャズも Naked Drums。

## ギター
- 使わない音: 短い単音の刻みで「ピ、ピ」と切れる高いギター／歪みすぎて割れる・高域がピーと鳴る歪み／chorus をかけたクリーン（きゅいんきゅいん）／リードの標準 crunch アンプ（ピロピロ）。詳しくは banned-sounds.md。
- ブリッジミュートの刻みをなんでも入れない（特に曲の最初が刻みだと聞きにくい）。弾いている途中で急にミュートに切りかえない。
- ビブラートは「ゴムが伸びる音」に聞こえるので嫌い。チョーキングはよいが、戻しが速く「上がって落ちる」のはだめ。
- 歪みは明るい歪み。リフは歪ませつつ「ラウドな透明感」。リードの高音は少しだけ低めにし、余韻を残して「鋭いけど優しく心に響く」。ゲームっぽくない現代的な音。
- プロのエフェクター接続・複数のエフェクターの組み合わせを取り入れる。エフェクトはつまみで細かく調整できるように。
- ギターは「Rギター・Lギター・リードギター」の三種で作れるように。アコギは柔らかめ。ギターが大きすぎてほかが聞こえない曲にしない。

## ベース
- ふつうはコード進行の根音に沿わせてよい。メロディラインのあるベースは丁寧に。
- ラウド: 歪ませてよいが、こもった音ではなく明るくゴリッと。指弾き。ベースは少し大きめが好み（×1.2）。
- ジャズ: 全部ウッドベース、指で弾く感じ、一音一音はっきり。

## ジャンル別
- ラウドロック: BMTH 寄りの音（参考の音 wide-dark-wall）が好評。バスドラはトリガー＋重みのあるバスドラ。
- バンドの音: TRiDENT の音（参考の音 glossy-jrock・ドラム crocell-punch）。曲に合わなければ使わなくてよい。
- ジャズ: 電子音は使わず録音の原音、ジャズでふつう使う楽器だけ。硬さを抜いて柔らかく全身を包む音色、居心地のよい空間、頭の中を支配する音、一音一音丁寧に。ギターは繊細に。ライドは伸びて鋭く。一流の奏者の技術・ミキシング・音作りを楽器ごとに学んでから。
- バイオリン（フィドル）: 柔らかく力強く、透き通るように。
- ケルト: 音全体に強弱と余韻、スケールの大きさと幻想的な感じ、「頭の中を全て支配するような感じ」。1曲ごとにその曲のイメージ（場面・物語・ただひとつ）を大事にして、形・拍子・楽器・始まり方・終わり方を選ぶ。
- ケルト・フルート: 主役のフルートを伴奏やシンセより小さくしない。高音は硬くせず柔らかく、滑らかで優しい吹き方。オーボエなど笛以外の旋律楽器は並べない。終わり際のクラッシュシンバル系はいらない。環境音だけが鳴る時間を作らない。詳しくは celtic-flute-100-plan.md・celtic-flute-100-ledger.md・celtic-study/。
- 自然を感じる曲は、その空間が感じられる音に。

## 歌（テト）
- 人間らしく、少し透き通る、少しアニメ声寄り、一字一字聞こえやすく。ノイズ・濁り・ひずみなし。フォルテ・ピアニッシモ・しゃくり・ビブラートを場面で。伴奏に対して大きくしすぎない。人間が歌える速さに。
- リードの歪みが強いと声が聞きにくい → リードの歪みは抑えめ。
- 歌詞は直接的な言葉ばかりにせず、比喩・隠語・造語も。「好きだよ」「ありがとう」などは場面でそのままと言いかえを使い分ける。

## 仕上げ
- 書き出しの標準: 音量を下げて左右の広げなし（-13.5 LUFS・widen 1.0）の「B」でよい（曲集ごとに決めた値があればそれ）。
- 2026-10-29 旭さん「物語考えたら主役笛じゃない？」: 銀の笛と百の夜の主役は、どの曲もエイラの笛。伴奏（ピアノ・竪琴など）が旋律を持つ曲でも、伴奏は奥、笛が前。山と最後は笛が持つ。

# メロディ（旋律）の作り方 ガイド（2026-10-11 調査）

作曲ソフトで旋律（メロディ・リード・ソロ）を書くときの、**手順・型・見本・点検**をまとめた手引き。「どう並べると歌えて、覚えられて、飽きないか」を、うちの `notes` 記法（`音名:拍`）でそのまま書ける形に落とした。

- 調べた先: 末尾の参考URL（35か所。考え方だけを借り、文章は写していない）。数値の目安は一般論で、最終判断は耳。
- 見本の旋律は、この文書のために作った**完全オリジナル**（CLAUDE.md 1-1）。実在曲の旋律・歌詞は一切入れていない。見本はそのまま使い回さず、**調・リズム・音を必ず変えて**使う（同じ見本を続けて使うと、自分の曲どうしが似る）。
- コードは編集していない。ここにある「提案」は §8 にまとめた。

## 1. 要点

1. **旋律は「高さ」と「リズム」の2つでできている。しかも覚えやすさは、リズムの方が効くことが多い。** 音をなくして1音（リズムだけ）で弾いても面白いなら、よい旋律。つまらないときは、音より先にリズムを変える。
2. **音は隣へ動くのが基本。** 世界のいろいろな旋律を数えた研究で、半音〜全音（2半音以下）の動きがいちばん多い。跳躍は「ここぞ」に1回。跳んだら、反対向きに順次で戻る。
3. **輪郭（アーチ・波・階段）は傾向であって決まりではない。** 山形は多いが、民謡では下がっていく型も多い。「1フレーズに最高音は1回、強い拍に」を守れば、形は自由。
4. **作る単位は「動機（3〜7音）→2小節→4小節→8小節」。** 8小節の型は2つ: **ピリオド**（問い4小節＋答え4小節）と**センテンス**（基本形1小節→くり返し1小節→縮めて展開2小節→終止）。
5. **くり返しすぎても、変えすぎても飽きる。** くり返しを軸にして、2〜3回目に**1つだけ**変える（リズム、音域、和音、終わりの音のどれか）。
6. **強拍・長い音は和音の構成音、和音の外の音は弱拍・短く・すぐ解決。** 例外は、解決を狙う倚音と掛留（強拍に置いて、次の音で解決する）。
7. **休符は音と同じくらい大事。** 呼吸のまとまりは約4〜6秒（テンポ120なら2〜3小節）。休符がないと、聴く側が疲れる。
8. **セクションは1〜2要素だけ変えて対比させる。** サビは Aメロより高く（1〜2音でも）、長い音を増やす。全部変えるとばらばらになる。
9. **場面で型を変える。** 町は落ち着いた「問い→答え」（ピリオド）、フィールドは前へ進む型（センテンス）、ダンジョンは和音の動きが少なく同じ形がくり返される、戦闘は同音連打＋短いリズム型（ここは調べた資料でなく、見本づくりでの整理）。
10. **ソロは「小さく始め、後ろ3分の1で頂点、最後に解決」。** 最初に言いたいこと（モチーフ）を1つ決め、1度に1要素ずつ変えながら発展させる。
11. **単調になる主な原因は5つ**: 同じ音の再訪、同じリズム、同じ音域、休符なし、毎回同じ高さの頂点。直し方は §6。

## 2. メロディの設計図（手順）

「全部書いてから直す」より、**小さな決定を順番にする**方が速い。上から順に1行ずつ決める。

| 手順 | 決めること | 目安・やり方 |
|---|---|---|
| 0 | 場面・気持ち・テンポ・拍子 | 町＝落ち着き、戦闘＝緊張、など。`music-knowledge.md` §14 で気持ちと場面を対応づける。テンポは速いほど音数は減らす |
| 1 | 調・音階・**音域** | 歌える幅は9度（ドからオクターブ上のレ）まで。1曲通しで最大でも1オクターブ半（18半音）。Aメロは低く始め、サビの頭を2〜4度高く |
| 2 | **リズム型を2〜3種** | 例: 「短短長」「付点＋短」「長＋休符」。この種類数に絞り、小節ごとに使い回す。手拍子だけで叩いて、面白いか確かめる（1音テスト） |
| 3 | **動機**（3〜7音） | リズム型1つ＋跳躍は1回まで。最初の音は和音の構成音、最後の音は和音の構成音か次へ引っぱる音 |
| 4 | **2小節の単位**にならべる | A A' B A'' や 問い→答え。8小節ならピリオドかセンテンスを選ぶ（§4 の見本4・5） |
| 5 | **頂点**の位置を決める | 1フレーズに最高音1回。置き場所は後ろ3分の1あたり、強拍（4拍子なら1拍目か3拍目）。サビの頂点はセクション全体で最高音 |
| 6 | **拍頭**を和音から選ぶ | 小節の頭と2拍以上の音は、そのときの和音の根音・3度・5度（7th コードなら7度も）。間は音階の音でつなぐ。コード外の音は弱拍・短く |
| 7 | **変化**をつける | 2回目は骨格とリズム型を8割残して、1〜2音を変える。3回目以降は音域・音色・和音のどれか1つだけ変える。3回くり返したら4回目は別の形 |
| 8 | **終わり方**（終止） | 問い＝主音以外（2度・5度など）か和音の3度で止める。答え＝主音か和音の根音。曲全体の最後は主音の長い音 |
| 9 | **息**を入れる | 4小節に1回は休符か2拍以上の長音。サビ前は1拍空ける |
| 10 | **点検** | `score-check.mjs` を通し、耳でも聴く。楽器を別の音色（ピアノなど）に替えて聴いて、旋律だけで成立するか確かめる |

### 2-1. 拍頭の音の選び方（早見）

| 場所 | 置く音 | 例（和音が C のとき） |
|---|---|---|
| 小節の1拍目 | 和音の構成音（根音・3度・5度） | C・E・G |
| 2拍以上の音 | 構成音。7th コードなら7度も可 | C・E・G（Cmaj7 なら B） |
| 弱拍・短い音 | 音階の音（経過音・刺繍音） | D・F・A |
| 和音が変わる直前 | 次の和音の音を半拍早く入れてもよい（先取音） | 次が G なら D・G |
| フレーズの最後 | 主音か和音の根音（答え）／ほかの構成音（問い） | C（答え）／E・G（問い） |

### 2-2. うちの `notes` 記法に落とすときの注意

- 1パートは同時に1音（和音は別パートに分ける）。旋律は**曲全体ぶん**書く（短いと自動でくり返されるが、旋律は変化が命）。
- `phrase` に **フレーズの拍数**（4拍子の2小節なら 8、4小節なら 16）を入れると、フレーズごとに「弱→山→引く」の強弱がつく。8か16が目安。
- 同じ音の連続は、`!`（アクセント）や `,`（弱く）で強弱をつけ、機械的に聞こえるのを避ける。
- 休符は `R:拍`。リズムで勝負するフレーズは、音を減らして休符を使う。

## 3. 技法の表（効果つき）

書き方の例は、4拍子1小節ぶん（合計4拍）で示す。

### 3-1. 動機の変形

| 技法 | やり方 | 効果 | 書き方の例（元 → 変形） |
|---|---|---|---|
| 反復（そのまま） | 同じ形をもう一度 | 覚えさせる。くり返しは安心感 | 元 `E5:1 D5:1 C5:2` を2回 |
| 反復進行（移高・シークエンス） | 同じ形を音階の隣の高さで | 前へ進む勢い。山をつくる | `E5:1 D5:1 C5:2` → `F5:1 E5:1 D5:2` |
| 同リズム・別の音 | リズムは同じで音だけ変える | 「同じ曲の続き」に聞こえつつ新鮮 | `E5:1 D5:1 C5:2` → `G5:1 E5:1 D5:2` |
| 同音・別リズム | 音は同じでリズムを変える | 別の曲のようにも聞こえる。単調直しの第一手 | `E5:1 D5:1 C5:2` → `E5:1.5 D5:0.5 C5:1 R:1` |
| 逆さ（反行・インヴァージョン） | 上がるところを下がるに、下がるを上がるに | 対照的な気持ち。問いに対する答えに | `E5:1 D5:1 C5:2` → `E5:1 F5:1 G5:2` |
| 逆行（レトログラード） | 後ろから読む | 不思議・謎解きの色 | `E5:1 D5:1 C5:2` → `C5:2 D5:1 E5:1` |
| 拡大（音価を延ばす） | 音の長さを2倍などに | 重々しさ、劇的な盛り上がり。終盤の再登場に | `E5:0.5 D5:0.5 C5:1` → `E5:1 D5:1 C5:2` |
| 縮小（音価を縮める） | 長さを半分に | 勢い、急ぎ。ボス戦の終盤 | `E5:1 D5:1 C5:2` → `E5:0.5 D5:0.5 C5:1 R:2` |
| 断片化 | 動機の一部だけ使う | 緊張を高める。センテンスの展開部 | `E5:1 D5:1 C5:2` → `E5:0.5 D5:0.5 E5:0.5 D5:0.5 E5:0.5 D5:0.5 C5:1` |
| 装飾・間引き | 音を足す／減らす | 2回目以降の変化の主役 | `E5:1 D5:1 C5:2` → `E5:1 D5:0.5 E5:0.5 C5:2` |
| オクターブ移動 | 同じ旋律を1オクターブ上へ | サビや最後の山。音量なしで盛り上がる | `C5:2 G5:2` → `C6:2 G6:2`（C6 以上は鐘など高域の音色で） |
| 問いと答え | 前半を開いた形、後半を閉じた形に | 話しているように聞こえる。8小節の骨格 | 問い `E5:1 G5:1 D5:2`（D＝V度）／答え `E5:1 D5:1 C5:2`（主音で終止） |

### 3-2. 和音とのからみ（非和声音と終止）

| 技法 | やり方 | 効果 | 書き方の例（和音 C） |
|---|---|---|---|
| 経過音 | 和音の音から次の和音の音へ、同じ向きの順次で通る | なめらか。弱拍に置く | `G5:1 F5:0.5 E5:0.5 E5:2`（Fが経過） |
| 刺繍音（隣接音） | 和音の音から上か下に寄って戻る | 飾り。短く | `E5:1 F5:0.5 E5:0.5 G5:2` |
| 倚音（アポジャトゥーラ） | 強拍に非和声音を置き、次で順次に解決 | 切なさ・ため息。ひとつの山場に1回 | Cの上で `F5:1 E5:1 C5:2`（Fが倚音） |
| 掛留（サスペンション） | 前の和音の音を持ち越し、ずれてから解決 | じらし。終止の直前に効く | 前小節 C5 → G の上で `C5:1.5 B4:0.5 D5:2`（4→3） |
| 先取音 | 次の和音の音を半拍早く | ノリが前へ。和音の変わり目に | C の小節 `E5:1 D5:1 C5:1.5 G4:0.5`（最後の G4 が、次の G の和音を半拍早く先取り） |
| 逸音（エスケープ） | 順次で入り、反対向きに跳んで出る | 軽いひねり。弱拍に | `E5:1 D5:0.5 G5:0.5 E5:2` |
| テンション（9度・13度など） | 長めに伸ばして色をつける | おしゃれ・ジャズ・バラードの深み | Cmaj7 の上で `D5:2 E5:2`（9度→3度） |
| アヴォイド（避けたい音） | 和音の3度の半音上などを長く伸ばさない | 濁りを避ける（`chord-theory-deep.md` §7） | Cmaj7 の上の F は経過だけ |
| ブルーノート | 3度・5度・7度を半音下げた音を混ぜ、元の音へしゃくる | 土くささ・哀愁 | A7 の上で `C5:0.5 C#5:0.5 E5:3`（C から C# へ） |
| エンクロージャー（囲み） | 目標の音を半音か全音で上下からはさむ | ジャズ的な推進力 | 目標 E へ `F5:0.5 D#5:0.5 E5:3`、または `D5:0.5 B4:0.5 C5:3`（Cを囲む） |
| ドローンの上 | 低い持続音の上で自由に動く | 民族・神秘。和音を変えなくても成り立つ | 低く A を伸ばし、上で民謡音階 |

### 3-3. リズム・間（ま）・盛り上げ

| 技法 | やり方 | 効果 | 書き方の例 |
|---|---|---|---|
| シンコペーション | 弱拍から入って次の強拍へのばす | ノリ・弾み。最初は全体の2〜3割に | `R:0.5 E5:1.5 D5:0.5 C5:1.5` |
| 付点と3＋3＋2 | 0.75＋0.75＋0.5 の並び | 16ビートの推進力（J-POP・ダンス） | `E5:0.75 E5:0.75 E5:0.5 C5:0.75 C5:0.75 A4:0.5` |
| アウフタクト（弱起） | 小節の前から入る | 「はっ」とさせる。サビの入りに | 前の小節 `E5:1 D5:1 C5:1 R:0.5 G4:0.5`（最後の G4 が次の頭へ向かう弱起） |
| 休符のシンコペ | 強拍に休符を置き、直後から出る | 隙間のノリ。ファンク | `R:0.5 E5:0.5 G5:0.5 E5:0.5 R:2` |
| 長い音＋休符 | 2拍以上の音のあとに息 | 歌うような呼吸、サビ前の溜め | `E5:2.5 D5:0.5 R:1` |
| 3連・細かい音の連続 | 高まりで音数を増やす | ソロ・戦闘の山 | `C5:0.333 D5:0.333 E5:0.334`（1拍に3音。合計を保つため最後を 0.334 に） |
| 同音連打から跳躍 | 同じ音で助走して一気に跳ぶ | サビの立ち上がり、言葉の強調 | `F4:0.5 F4:0.5 F4:1 Db5:2` |
| 跳躍→反対向きの順次 | 跳んだ後、逆へ歩く | 「ここぞ」の跳躍が自然に聞こえる | `C5:1 A5:1 G5:1 F5:1` |
| 山の高さの設計 | 各セクションの最高音を段階的に上げる | 曲全体の盛り上がり | Aメロ最高 E5、サビ最高 A5、最後のサビ B5 |
| 半音・全音の転調 | 最後のサビを上げる | 気持ちの持ち上がり（ただし旋律も手で書き直す） | `modulate: { atBar, semitones }`（実装済み。旋律の音名も指定の半音数だけ上がる） |
| 音域の逆転 | サビを低く静かにする（落ちサビ） | 引き算で、直後のサビを立たせる | 落ちサビは音数と音域を落とす |

## 4. ジャンル別の型

### 4-0. ジャンル・場面ごとの特徴（早見）

| ジャンル・場面 | 音域と動き | リズム | フレーズ | 和音との関係 | 見本の型番号 |
|---|---|---|---|---|---|
| 町 | せまい（9度以内）。順次中心 | 落ち着いた付点・8分。休符あり | 4＋4のピリオド、問い→答え | 構成音が拍頭。終止がはっきり | 1・2・3・5 |
| フィールド・旅 | 広め（10度前後）。上向きの跳躍で視野が開く | 4分と8分の混ぜ、行進のリズム | センテンス型（縮めて展開） | 和音の動きが速くなるほど前進感 | 4・28 |
| ダンジョン | 低くせまい。半音・休符・長音 | まばら。拍の頭で動かない | 短いくり返し、終止を避ける | 和音の動き少。ドローンやペダル | 6・7 |
| 戦闘 | 中〜高。同音連打と短い跳躍 | 16分・付点、休符で切る | 短い型を何度も、4小節ごとに変化 | ペンタやリフ。拍頭に根音・5度 | 8・9・10・11 |
| ボス | 高めに突き上げ。短調（和声的短音階） | 付点・シンコペ、変拍子も | 動機の移高・縮小で追い込む | 導音（短調の7番目の半音上げ）で緊張 | 9・10・32 |
| ロック（歌・ギター） | 5音（ペンタ）中心。跳躍はパワーコードの音 | 8分の刻み＋休符、裏拍の入り | 4小節の問い→答え | 拍頭は根音・5度。ブルーノート | 11・12 |
| ポップ | Aメロは低くせまい、サビは高く長い | Aメロは同型反復、サビで変化 | A→B→サビで山を作る | サビ頭は構成音。アウフタクト | 13・14・33 |
| J-POP | 広い音域、跳躍とシンコペ | 16分のシンコペ、付点、8分の言葉乗せ | 8小節＋8小節、サビは覚えやすい型 | テンションと分数コード | 15・16 |
| バラード | 長い音、ゆるやかな上下 | 2拍以上の音と休符。6/8 は3拍ずつ | 4小節の息、サビで大きく | 7度・9度を長音で響かせる | 17・18・20・38 |
| ジャズ | 8分の流れ、コード音への到達 | 8分の連なり、スウィング | ii–V–I 単位で考える | 3度・7度へ向かう。囲み・テンション | 19・20 |
| ブルース | ペンタ＋ブルーノート | 問いと答え、休符が多い | 12小節（4＋4＋4）の型 | ドミナント7が全部の和音 | 21 |
| 民謡・和 | 5音の音階（民謡・都節・琉球・律）。装飾音 | 4拍で素朴、ゆっくり | 短い歌のくり返し | ドローンが基本。和音は少ない | 22〜25 |
| 民族・ケルト | 順次、踊るリズム（6/8の3＋3） | 付点・跳ねる | 4小節の問い→答えのくり返し | 低音のドローンと2〜3和音 | 26 |
| チップチューン | 分散和音、速い | 16分の連続 | 短い型のくり返し | 和音そのものが旋律 | 27 |
| 感動・エンディング | 上がって落ち着く | 長い音が多く、休符で息 | ピリオド型で完全終止 | 掛留・倚音で泣かせる | 29・31・38 |
| 神秘・謎解き | 浮く旋法（リディアン）、半音階 | まばら、または規則的な反復 | 短い動機の移高・逆行 | 浮く音（#4度）を伸ばす | 30・32 |

以下は、**4〜8小節の見本38**。調は意図的にばらつかせた。各見本は、拍の合計が1小節の拍数と一致することを確認済み（4拍子は1小節4拍、3拍子は3拍、7拍子は7拍、6拍は6拍）。コードは1小節に1つで、`chords` の例として使える（そのままでなく、進行も変える）。

### 4-1. ゲーム音楽：町

**型1　町（のどか）**（G長調・4拍子・bpm 92・4小節・音域 F#4〜E5）

コード（1小節ずつ）: `G | Em | C | D`

```
G4:1 B4:0.5 D5:0.5 B4:1 G4:1
E5:1.5 D5:0.5 B4:2
C5:1 E5:1 D5:0.5 C5:0.5 A4:1
A4:1 F#4:0.5 A4:0.5 D5:2
```

- 和音の分散で始め、4小節目は D の上で止まって「続きがある」形（問い）。音域は F#4〜E5 の9度以内。

**型2　町（にぎやか）**（C長調・4拍子・bpm 128・4小節・音域 A4〜G5）

コード（1小節ずつ）: `C | F | G7 | C`

```
E5:0.5 E5:0.5 G5:1 E5:0.5 D5:0.5 C5:1
A4:0.5 C5:0.5 F5:1 E5:0.5 D5:0.5 C5:1
D5:1 G5:1 F5:0.5 E5:0.5 D5:1
E5:1 C5:1 C5:2
```

- 1〜2小節目は同じ『短・短・長』のリズム型で音だけ変え（リズム型1つ＋音の変化）、3小節目でリズムを変えて、4小節目の主音で答える。

**型3　夜の町（ワルツ）**（ニ短調・3拍子・bpm 80・4小節・音域 A4〜A5）

コード（1小節ずつ）: `Dm | Bb | Gm | A`

```
D5:1.5 F5:0.5 A5:1
F5:1 D5:1 Bb4:1
G5:1.5 F5:0.5 D5:1
E5:1 C#5:1 A4:1
```

- 3拍子は1拍目が重い。各小節の頭に和音の根・3度・5度を置き、4小節目の C# が A の和音の3度で、主和音へ強く引っぱる。

### 4-2. ゲーム音楽：フィールド（8小節の型2つ）

**型4　フィールド（センテンス型・8小節）**（ヘ長調・4拍子・bpm 112・8小節・音域 A4〜G5）

コード（1小節ずつ）: `F | Dm | Gm | C7 | Bb | Gm | C7 | F`

```

D5:2 A4:1 D5:1
D5:1 G5:1.5 F5:0.5 D5:1
E5:2 C5:1 E5:1
F5:1 D5:1 F5:2
G5:1 D5:1 G5:2
E5:0.5 F5:0.5 G5:1 E5:2
F5:1 C5:1 A4:2
```

- 1〜2小節が基本の形、3〜4小節で一段上げて反復（提示）。5〜6小節は1小節ずつに縮め（断片化）、7小節は半小節の細かい動き（さらに縮む）、8小節で解決。和音の動きも後半ほど速くする。

**型5　フィールド（ピリオド型・8小節）**（ニ長調・4拍子・bpm 108・8小節・音域 A4〜A5）

コード（1小節ずつ）: `D | Bm | G | A | D | G | A | D`

```
F#5:1 A5:1.5 F#5:0.5 D5:1
D5:1 F#5:1 B4:2
B4:1 D5:1 G5:1.5 F#5:0.5
E5:2 C#5:1 E5:1
F#5:1 A5:1.5 F#5:0.5 D5:1
B4:1 D5:1 G5:2
C#5:1 E5:1 A4:2
D5:4
```

- 前半（問い）は A の上の E で止まる半終止、後半（答え）は出だしを再現してから別の道を行き、D の長い主音で完全に終わる。問いと答えの出だしが同じなので覚えやすい。

### 4-3. ゲーム音楽：ダンジョン

```
Bb4:2 C5:1 Bb4:1

```

- 休符と長音が多く、音は少ない。Bb（主音の半音上）がフリジアンの暗さ。拍の頭で動かないことで『何か潜んでいる』間が出る。

**型7　ダンジョン（不穏・半音）**（ホ短調・4拍子・bpm 84・4小節・音域 Eb4〜Eb5）

```
C5:1 B4:1 G4:1 E4:1
```

- 半音（E–F、E–D#）のゆらぎが主役。4小節目の B7 の上の D#（導音）が次のEmへ戻る力になり、くり返してもよい。

### 4-4. ゲーム音楽：戦闘・ボス

**型9　ボス戦（和声的短音階）**（ニ短調・4拍子・bpm 150・4小節・音域 F4〜G5）

**型10　ボス戦（7拍子）**（イ短調・7拍子・bpm 140・4小節・音域 F4〜G5）

### 4-5. ロック

### 4-6. ポップ・J-POP

### 4-8. ジャズ・ブルース

- 和音の構成音だけの跳躍で、休まず上へ。『4度・3度の跳び上がり＋同音の連打』が号令の形。最後は主音の高い C で終止。

### 4-11. 感情・場面・技法の見本

**型29　悲しい場面（下行）**（イ短調・4拍子・bpm 60・4小節・音域 E4〜E5）

**型30　神秘（リディアン）**（ヘ（リディアン）・4拍子・bpm 76・4小節・音域 A4〜E5）

**型31　エンディング（ピリオド型・8小節）**（ト長調・4拍子・bpm 84・8小節・音域 F#4〜E5）

**型34　コミカル（スタッカート）**（ヘ長調・4拍子・bpm 132・4小節・音域 E4〜A5）

## 5. ソロの組み立て

### 5-0. ソロの考え方（共通）

- **言いたいことを1つ決める**（モチーフ。2小節ほど）。まず提示し、**1度に1要素だけ**変えながら（リズム→音の高さ→音域→音数の順に）育てる。
- **頂点は後ろ3分の1に1回**。最初に一番よいフレーズを使い切らない。前半は低め・遅め・音数少なめ。
- **休符は句読点。** 連続して弾き続けるのは2〜4小節まで。長く弾いたら、次は休む。
- **和音の変わり目では、次の和音の3度か7度へ向かう。** ソロが和音を「説明」して聞こえる。
- **速い音は山場のためにとっておく。** 序盤は歌うような長い音、終盤に細かい音。
- **終わりは構成音の長い音。** 次のセクションの頭の音へつながるように置く。

### 5-1. ギター・ロックバラードの歌うソロ（8小節・イ短調・bpm 72）

和音: `Am | F | C | G | Am | F | G | Am`

| 小節 | 役割 | 音価・音数 | 音域 | 技法 |
|---|---|---|---|---|
| 1〜2 | 提示（モチーフ） | 2拍以上の音が中心。小節に3〜4音 | C5〜F5 | ビブラート `~`、しゃくり `/` |
| 3〜4 | 反復進行（隣の高さで） | モチーフと同じリズム | D5〜G5 | 音を1つ足す（装飾） |
| 5〜6 | 展開（縮小・断片化） | 8分が増える。小節に6〜8音 | E5〜A5（**6小節目に最高音 A5 を1回**） | ベンド `^`、アクセント `!` |
| 7 | 下行・息 | 長音＋休符 | A5→C5 | フォール `\` |
| 8 | 解決 | 全音符（または 3拍＋休符） | A4 か E5 | ビブラート深め `~~` |

動機（1〜2小節）: `E5:1.5 D5:0.5 C5:2` / `C5:1 A4:1 F5:2`

## 6. 失敗と直し方

| 症状（聞こえ方） | 主な原因 | 直し方 |
|---|---|---|
| のっぺりして覚えられない | リズムが全部同じ。同じ音の再訪が多い | 音より先に**リズム**を変える（長音と休符を混ぜる）。同じ高さの音が4小節で3回以上出たら、別の音に替える |
| 音が上下に暴れて歌えない | 跳躍が多い。音域が広い | 跳躍を1フレーズ1回に。跳んだら反対へ順次。音域を9度以内に |
| ふわふわして落ち着かない | 強拍に和音外の音。終止がない | 小節の頭と長音を構成音に。フレーズの最後を主音・根音に |
| 濁る・不協和に聞こえる | 和音の半音上の音（アヴォイド）を長く鳴らす | 半音下の構成音へ替える、または短い経過音に |
| 間延びして盛り上がらない | 頂点が複数、または頂点がない／前半に使い切る | 最高音を1回に。後ろ3分の1に置く。頂点前に1拍の休符 |
| サビがAメロと同じに聞こえる | 音域・リズム・長さが同じ | サビの中心音を2〜4度上げる。長い音を増やす。サビ頭を跳躍で入る |
| 同じ形の連続で退屈 | 完全な反復が3回以上 | 3回目は1要素（リズム／音域／終わりの音）を変える。4回目は別の形 |
| 息が詰まる・疲れる | 休符がない。ずっと音が続く | 4小節に1回は休符か2拍以上の長音。サビ前に1拍空ける |
| 機械的で冷たい | 全部同じ強さ・同じ長さ | `phrase`、`!` `,`、ビブラート、少しのタイ（長音）で強弱を作る |
| 先が読めすぎる | 全部の音が音階を順に上下しているだけ | 3度跳びを混ぜる。2小節に1回、予想外の音（同音に戻る・半音）を入れる |
| 逆に何を言っているか分からない | 毎小節ちがう形。動機がない | 動機を1つ決め、全体の7割をその変形にする |
| ソロが速いだけで印象に残らない | 休符がなく、モチーフがない | 先に歌えるモチーフを置く。速い音は終盤だけ |
| 2番・2回目が同じで飽きる | 変化がない | 旋律は骨格を保ち、装飾・オクターブ・楽器の替えを1つ |
| 旋律が伴奏にうもれる | 音域がかぶる | 旋律を伴奏より高く、または1オクターブ離す（`arrangement-deep.md`） |

## 7. チェックリスト

書き終えたら、上から1つずつ確かめる。1つでも「いいえ」なら §6 の該当行を見る。

**形**
- [ ] 動機（3〜7音）が決まっていて、曲の中に何度か（変形して）出てくる。
- [ ] 8小節（または4小節）の型が、ピリオド／センテンス／A A' B A'' のどれか言える。
- [ ] 問いのフレーズの終わりは「開いた」音、答えは主音（根音）で終わる。
- [ ] 3回くり返したら、4回目は変えてある。

**音の高さ**
- [ ] 旋律の音域が、ふつうの区間で9度以内（最大でも1オクターブ半）。
- [ ] 1フレーズの最高音は1回で、強拍にある。
- [ ] 跳躍（5度以上）のあとは、反対向きに順次で戻っている。
- [ ] 順次進行が6〜7割以上。
- [ ] サビは Aメロより高い（最高音も、中心の音も）。

**和音との関係**
- [ ] 小節の頭と2拍以上の音が、そのときの和音の構成音。
- [ ] 強拍の和音外音は、倚音・掛留として次の音で解決している。
- [ ] 和音の半音上（アヴォイド）を、長く・強拍・最高音で使っていない。
- [ ] 最後の音が主音、またはその時の和音の音。

**リズム・息**
- [ ] リズム型が2〜3種類に絞られ、小節ごとに使い回されている。
- [ ] 休符か2拍以上の長音が、4小節に1回以上ある。
- [ ] リズムだけ（1音で）叩いても面白い。
- [ ] サビの入りが、アウフタクトか休符のあとで立っている。

**セクション・仕上げ**
- [ ] Aメロ→Bメロ→サビで、音域・音価・密度のうち1〜2つが変わっている。
- [ ] 2回目のくり返しで、1つだけ変えてある（楽器・オクターブ・装飾）。
- [ ] 実在曲のメロディ・歌詞を使っていない（CLAUDE.md 1-1）。聞いて「何かに似ている」と感じたら、出だしの音程とリズムを変える。
- [ ] `score-check.mjs` を通し、△が出た箇所を「わざと」か「直す」か決めた。

## 8. 取り入れる提案（実装できる単位）

| P3 | リズム型の点検（1音テスト） | 小節ごとの「音価の並び」を文字列にし、種類数を数える。4小節以上で全部同じ、または種類が6を超えたら△。さらに、すべての小節で「拍頭に音が来る」（シンコペ0%）なら参考として表示 | `score-check.mjs` | 小 |

| P6 | セクション間の音域差の点検 | `plan.json` や `sections` のセクション名（Aメロ／サビ）ごとに旋律の平均音高と最高音を出し、「サビの平均 ≧ Aメロの平均 +2半音」「最高音はサビ」を確認。足りなければ△ | `score-check.mjs`（`--plan` 指定時） | 中 |

補足の提案（余裕があれば）:

- **P11 倚音・掛留の見える化**: 強拍の和音外音で、次の音が順次下行して構成音に着地していれば「倚音／掛留（OK）」と表示し、着地していなければ△。アヴォイド点検の誤警報を減らす。
- **P12 リズム先の直し手順をガイドに**: 「単調と言われたら、音より先にリズムを変える」（§6の第一行）を、コンポーザーの直しの手順（`ai-composition-workflow.md` の直しのループ）に一文で加える。

### 8-1. 実装状況（2026-10-11、ブランチ feat/r2-melody）

P1〜P12 をすべて実装した。テストは `src/audio/melody-craft.test.ts`（提案ごとに `describe` を分けてある）。

| 番号 | 状況 | 置き場所・使い方 |
|---|---|---|
| P1 頂点の点検 | 実装 | `tools/audio-check/melody-lint.mjs` の `checkPeaks`。4小節（8小節未満の曲は2小節）ごとに最高音の回数と位置を数え、2回以上、または前25%なら △。リフ役（role に「リフ」「刻み」「アルペジオ」など）は除外 |
| P2 同音の再訪・連打 | 実装 | `checkRepeatedPitch`。同じ区間で同じ高さが4割超、または同じ音が4回以上つづくと △ |
| P3 リズム型（1音テスト） | 実装 | `checkRhythmTypes`。同じ型が4小節以上つづく、8小節に型が7種以上で △。全部の音が拍頭にあるとき（シンコペ0%）は参考表示（`VERBOSE=1` で表示）。「6種を超えたら」は曲全体ではほぼ必ず超えるので、**8小節ごと**に数える形にした |
| P4 息の点検 | 実装 | `checkBreath`。0.5拍以上の隙間か2拍以上の音を「息」とし、息なしの長さが6秒（バラード・民謡・和風は4秒）を超えたら小節番号つきで △ |
| P5 問いと答えの終わり | 実装 | `checkAnswerEndings`。8小節ブロックごとに、4小節目の終わりの音と8小節目の終わりの音が同じなら △（全ブロックで同じ場合）。「曲の最後が主音か」は既存の点検 7 が見る |
| P6 セクション間の音域差 | 実装 | `checkSectionRange`。`--plan` で設計図（sections の kind が verse／chorus）を渡したときだけ働く。サビの平均音高が Aメロ+2半音未満、または最高音が Aメロ側なら △ |

| P8 `AI_SONG_GUIDE` の設計図 | 実装 | `src/audio/ai-song.ts` の「技術の深掘り」に「旋律の設計図」1項目（手順①〜⑩）を追記 |
| P9 旋律の型ライブラリ | 実装 | `docs/sound/data/melody-patterns.json`（型1〜38。`node tools/composer/melody-patterns.mjs build` で本書 §4 から作り直せる。テストが両者の一致を確かめる）。`node tools/composer/song.mjs pattern --scene 町 --key D [--beats 4] [--record <曲ID>]` で移高した下書きを出す。直前2曲で使った型は選ばない（履歴は `docs/sound/data/pattern-history.json`、`--record` で追記）。出力に「リズムか音を2か所以上変える」ルールを付け、`changeCount` で変更数を数えられる。履歴は `revision-log` ではなく専用ファイルにした（`revisions.md` は音の直しの記録で、型番号の検索に向かないため） |
| P10 音程列の類似 | 実装 | `tools/composer/interval-sim.mjs`。6音の窓（半音数の列）が直近の曲と20%超で一致したら注意、リズム（隣の音との長さの比）も同じ位置で20%超なら【強い警告】。`novelty.mjs` の `checkNovelty` から呼ぶ（`song.mjs novelty`） |
| P11 倚音・掛留の見える化 | 実装 | `classifyStrongNonChord`／`checkAppoggiatura`。強拍の和音外音が次の音で1〜2半音下がって構成音に着くものを「倚音／掛留（OK）」として数え、解決しないものだけ △ |
| P12 リズム先の直し手順 | 実装 | `docs/sound/ai-composition-workflow.md` の直しの手順（6.）に1項目を追記 |

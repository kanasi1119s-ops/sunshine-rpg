# ドラムのビートとグルーブの手引き（2026-10-02）

AIソング形式（`song.mjs guide`）でドラムを書くときの型。1文字＝16分音符、1小節（4拍）＝16文字。`g:` のあとに書く。
記号: `x` 打つ ／ `X` 強く ／ `o` 弱く（ゴーストノート）／ `.` 休み。パートは kick・snare・hihat・crash・tom に分けて書く。
どれもジャンルの一般的な型で、特定の曲のリズムを写したものではない（CLAUDE.md 1-1）。

- 2〜4小節ごとに、最後の1拍をフィル（tom か snare の16分連打。例 `g:xxxx` を tom に）にして、次の小節の頭に crash を置く。
- 8小節のうち1回は、キックを抜く（ブレイク）か、スネアを倍にして（せり上げ）、次で全部を戻す。

## グルーブ（ノリ）をつくる

「型どおり並べる」だけでは機械的に聞こえる。ノリは、次の4つで決まる。

1. **強弱（アクセント）**: 同じ型でも `X`（強）・`x`（ふつう）・`o`（弱）を書き分ける。ハイハットは表拍を強く、裏拍を弱く（`XoxoXoxo` の感じ）。スネアの間に `o`（ゴーストノート）を挟むと、転がるような動きが出る。
2. **スウィング（裏拍のはね）**: 曲の `swing`（0〜1）で、裏の8分を遅らせて三連に寄せる。ジャズ・ブルース・ファンクは 0.5〜0.7、ヒップホップ・ローファイは 0.2〜0.4（「よれた」ノリ）、ロック・ダンス・メタルは 0（ぴったり）。
3. **あと乗り・前のめり（push）**: パートごとの `push`（拍）。スネアを +0.02〜0.04（あと乗り＝どっしり、ゆったり）、ハイハットを -0.01〜-0.02（前のめり＝軽く、せかす）。キックとベースは 0 で土台をそろえる。ダンスは全部 0 にして、機械のようなぴったりを狙う。
4. **休符（間）**: キックを毎拍置かず、「3拍目の手前」を空ける・2拍目の裏を空けるなどで、ためをつくる。ヒップホップ・ファンクは間が主役。

### 例（ヒップホップ・よれたノリ）
`swing: 0.3`、kick `g:X.....o...X..o..`、snare `g:....X.......X...`（`push: 0.03`）、hihat `g:XoxoXoxoXoxoXoxo`（`push: -0.01`）、808ベースは kick と同じ位置から。

## 音の伸び（sustain）との組み合わせ
- ベースやリードを歯切れよくしたいときは `sustain: 0.5`、ハープ・鐘・琴の余韻を重ねたいときは `sustain: 2`。
- ドラムには `sustain` は使わない（長さは楽器ごとに決まっている）。

## 見本: 場面ごとにビートを変える（夏のボカロ風「入道雲のむこうがわ」、bpm 172）
8ビートを続けず、場面でノリを変えると、同じテンポでも単調にならない。
| 場面 | kick | snare | hihat | ベース |
|---|---|---|---|---|
| Aメロ（16ビート） | `g:X.....x...x.....`（4小節で型を変える） | `g:....X..o....X..o` ほか（ゴーストを移動） | `g:X.oxX.oxX.oxX.ox` | キックの隙間に合わせた、はねる音型 |
| Bメロ前半（静かな4つ打ち） | `g:x...x...x...x...`（弱く） | `g:....x.......x...` | `g:..o...o...o...o.`（裏拍だけ） | 8分の根音 |
| Bメロ後半（盛り上げ） | `g:X...X...X...X...` | `g:....X..o....X.o.` | `g:x.x.x.x.x.x.x.x.` | 8分の根音とオクターブ |
| サビ（ダンスの4つ打ち） | `g:X...X...X...X...` | `g:....X.......X...` | `g:xoXoxoXoxoXoxoXo`（裏拍の8分を強く） | 裏拍（ブンチャ）。キックと重ならない |
| 間奏（ボサノバ・サンバ風） | `g:x..o..x..o.....`（弱く） | `g:..o..o...o..o...` | `g:x.o.x.o.x.o.x.o.` | 根音と5度の、ゆったりした2拍フレーズ |
- 場面の最後の小節は、スネアの16分フィル（`g:..o.X.o.xxxxXXXX`）とタム（tom）のフィル。
- ベースは、キックと同じ位置に打つか（ロック）、キックの隙間を埋めるか（ダンスの裏拍）で、曲のノリが決まる。

# 音の重ね方と曲の仕上げ方の技術（Claude Code がどの曲でも使えるように）

2026-10-29 人間「勉強した音の重ね方・音楽の作り方のテクニックを、すべてコードに共有できるようにして」。
クラウドの Claude がケルト100曲（銀の笛と百の夜）・ジャズ・歌の曲で学び、試し、点数と耳で確かめたことをまとめる。
好み（何が好き・嫌い）は docs/sound/composer-preferences.md、学んだ元の資料は下の「くわしい資料」。

## 1. 曲を作る前（設計）
1. その曲のイメージ（場面・物語・この曲だけの要素＝ただひとつ）を1行で書く。形・拍子・調・楽器・始まり方・終わり方は、それを伝えるために選ぶ
2. 「曲を決める表」を書き、ほかの曲と並べて、始まり方・終わり方・山の置き方・旋律の動き・リズムの形・主役の音色が似ていないか確かめる（似ていたら作る前に直す）
3. ジャンルの決まりごと（見本）を先に調べる。ケルト: celtic-study/README.md（装飾音・はずみ・ダンスの型・8小節の文法・旋法・15の編曲の型）

## 2. 音の重ね方（主役を立てたまま、厚く・細やかに）
山下達郎の重ね方の学び（layering-study.md）と、ケルト100曲での実験から:
- **主役は1つ**。主旋律の楽器を並べない（ケルトでは笛だけ。応える役も笛か、低い音域のチェロだけ）
- **主役を2重にする**: 同じ旋律を、少し遅らせて（1音ずつランダムに 0〜0.05拍）、反対寄り・小さめ・明るさを下げて重ねる → 深み（c100_common.finish の double）
- **和声の重ね（主旋律の下）**: 3度下（だめなら4〜5度下）の和音の音を、2本目・3本目に。左右に分けて小さく（c100_common.rich の choir）
- **内声の動き**: 弦の1本が、和音の中のテンション（9th・maj7・6th）から一音ずつ下りる（クリシェ）。止まって聞こえる所が動きだす（rich の inner）
- **床（ゆか）を敷く**: 主役が休む小節・止まる小節・前奏にも、うすい弦3声＋低音（チェロ）を必ず置く。音が落ちる所を作らない（floor_bed）
- **広がりのパッド**: 左右いっぱいに、ごく小さな長い和音（finish の pads）
- **それぞれ別の音域・別の左右に**: 低音（チェロ・コントラバス）／中低（竪琴の左手・ギター）／中（主役）／中高（和声・内声）／高（竪琴の倍音・グロッケン）。同じ音域・同じ左右に2つ重ねない
- **ピアノの音源（Salamander）は小さい**: 弦などと同じ大きさに聞かせるには、volume を 2〜2.5倍に。ピアノだけの場面は特に
- **楽器の数は場面ごとに決める**（区間の名前で決めない）。増やす順・減らす順そのものを物語にする（例: 灯りが1つ増えるごとに楽器が1つ増える）
- **速い曲の推進力**: 枠太鼓（ボーラン）の型＋ギターの開放和音のストローク（DADGAD 風: 3度を抜いた根音・5度・オクターブ・9度）。012（7.88点）の厚さ＝ボーラン＋ギター＋竪琴の3音オスティナート＋チェロ＋弦＋笛の和声（c100_common.drive）
- **重ねすぎに注意（2026-10-29 016 で確かめた）**: 速い曲（ホーンパイプ）に、ピチカート・内声・パッドを足したら 7.48→7.25 に下がった。速い曲は「ボーラン＋ギター＋竪琴＋チェロ＋弦＋笛の和声」までにして、細かい刻みの層を増やしすぎない。静かな曲は逆に、床・内声・パッドで点が上がりやすい
- **作った効果音を外しても点はほぼ変わらない**（008 で比べた: 6.70→6.66）。空間は音楽の音で作ってよい
- **曲ごとの「ただひとつ」を音で作る例**: 5度だけの古い響き→山で初めて3度（041）／欠けた旋律が回るたびに埋まる（042）／同じ旋律が最後に半分の速さ（044）／和音の並べ方が狭い→4オクターブに開く（046）／遠くの笛が同じ音で返事（047）／音のない打音が先にリズムを刻む（050）

## 3. 空間（頭の中を支配する音）
- **空間は音楽の音で支配する**（2026-10-29 人間）。作った効果音（倍音の鳴り・息のような雑音）で埋めない。環境音は景色の気配にとどめる（音楽より −30dB 前後、音楽が大きい所では下げる＝ダッキング）
- 使ってよい空間の層: 楽器そのものの残響（--space dome / hall、wet 0.3〜0.4）、音楽を遅らせて暗くした遠い反射（far）、高域を1オクターブ上げて長い残響へ（shimmer・ひかえめ）
- 左右の広がり: --widen 1.32・--side-hpf 200（1.4 にすると左右の相関がマイナスになり、音がやせる）
- 環境音だけが鳴る時間を作らない（点数が下がる・人間もいやがる）
- 仕組み: assets-src/ai-songs/_gen/c100_air.py（MUSIC_FIRST）

## 4. 強弱と流れ
- 場面ごとに必要な強さを決める（0.6〜0.95 の曲線）。山は1曲に0〜2つ
- 曲の途中で急に小さくしない。特に前奏→最初の場面、笛が休む小節、終わりの場面
- 前奏は「楽器1つだけ」にしない（竪琴だけ・ピアノだけ・太鼓だけは −35〜−50dB になる）。その場面の空気（弦の和音とチェロ）を下に敷く
- 終わりは長く消えていかない（20秒以上沈むと「段差大」）。最後の場面は4〜6小節、最後まで弦が支え、消え方は最後のフェード（7秒）にまかせる
- 「遠い」「小さい」場面も、音量を下げずに、楽器の選び方（やわらかい打ち方・高い音域・残響）で表す

## 5. 書き出したあとの検査（1回目で合格しやすくする）
- 書き出す前: thickness_report（薄い小節の数・前奏の厚さ）→ 薄い小節 0 にしてから書き出す
- 書き出したあと: 音質の点数（Audiobox Aesthetics の PQ。tools/audio-check/aes-score-lowmem.py）と、2秒ごとの大きさ（前奏が小さい・急に小さい所・段差）
  - 目標: ふだんの曲 7.5 以上（目標8）。ケルト100曲は 静 7.2・動 7.8
  - 点数が低い原因の多く: 薄い（弦2声だけ・チェロなし・パッドなし）、前奏や休む小節が空く、終わりが長い、作った効果音・大きい環境音（CE＝楽しさが下がる）
- 点数だけで決めず、区間ごとに単調な所がないかを聞いて確かめる
- 4〜5分の曲は、長さが足りなければテンポを少し下げて合わせる（場面を空白でのばさない）

## 6. 仕組み（コード）
- 曲の生成: assets-src/ai-songs/_gen/c100_common.py（make・finish・rich・floor_bed・drive・thickness_report）、c100_v2.py（はずみ lilt・装飾 ornament・ボーラン bodhran・ストローク strum・ハープのオスティナート）
- 空気と空間: c100_air.py ／ 書き出しの流れ: tools/celtic100/README.md
- ケルト以外の曲でも、make/finish/rich/floor の考え方はそのまま使える（楽器を置きかえる）

# 歌の動画（重音テトが舞台で歌う・歌詞と英訳つき）を作るプロンプト

2026-10-27 作成。人間「完成したら、今回の流れをすべてプロンプト化してください」。
ボカロ曲25曲のアルバム『SCARLET FREQUENCY（スカーレット・フリークエンシー）』の YouTube 用の動画（約1時間49分）を作った流れを、次も同じ質で作れるように書き残す。
下の「プロンプト」を Claude にそのまま渡せば、同じ流れで作れる。【 】の中だけ書きかえる。

---

## プロンプト（ここから下を渡す）

> 【アルバム名】の全【25】曲を、重音テトが舞台で歌う YouTube 用の動画にしてください。25曲をつないだ1本にします。
> 渡すもの: 舞台の絵（【左に歌詞ボード・右に立つ台がある絵】）、テトの動画（白い背景で歌っている【10秒】の動画）。
> 曲は sunshine-rpg の歌の版（vb25 の「（歌：重音テト・仮）vNN.mp3」）の決まった版を使ってください。
> 手順と決まりごとは `docs/sound/teto-stage-video-prompt.md` のとおりです。日本語で説明してください。

---

## 1. 決まりごと（人間が言ったこと。必ず守る）

### テト（人物）
- **口の動きも体の動きも、渡された元の動画だけで完結させる。** 口だけを別のコマから切り貼りしたり、拍に合わせて絵をはずませたり、ゆらしたりしない。元のコマを、1枚まるごと並べ直すだけにする。
- **口は歌詞の言葉に合わせる。** 歌詞の母音（あ・い・う・え・お）と、歌っていない所（閉じる）に合うコマを選ぶ。
- **アホ毛まで、頭のてっぺんが画面から切れないようにする。** どのコマでも、頭の上に少しすき間（今回は約50px）を残す。
- **白い背景は残さない。** 髪のすきま（縦ロールと顔の間、髪と首の間）に残った白も抜く。
- **リボンと白目は残す。** 背景だけを抜く（人間「背景だけね！リボンは残してね！」）。
- 人物や物が欠けていないかを、細かく確かめてから出す（前からの決まり）。

### 歌詞ボード（左）
- 文字は**少しデジタルっぽい字体**（DotGothic16）。英語の題名などは Orbitron。どちらも SIL OFL 1.1（商用可・`docs/assets-credits.md` に記録ずみ）。
- ボードに出すもの:
  - アルバム名（英名を大きく、和名を小さく）
  - 曲番号「♪ NN / 25」
  - 曲名の和名と英名
  - 「歌：重音テト / Vocal: Kasane Teto」
- **音楽ジャンルは出さない。** 「ボカロ曲」「テクノポップ」なども、動画・サムネイル・説明文から全部外す（人間「音楽ジャンルは動画からすべて外してほしい」「紹介文からも外そう」）。
- 歌詞の出し方:
  - 上に前の行、まん中にいま歌っている行、下に次の2行を出す。
  - いま歌っている行は、歌った所から左から順に色が変わる（カラオケのように）。
- **英訳を、いま歌っている行のすぐ下に出す。**
- **ボードの奥に、曲に合わせて動くゲージ（30本の棒）を出す。** 絵にもともと描いてある動かない棒は、暗くして沈める。
- 右上の「PLAYING」に、曲の進み具合と「経過 / 全体」の時間を出す。

### 動画全体・サムネイル・説明文
- 前の動画（カフェジャズなど）と同じ情報を入れる。どの情報にも**和名と英名**を両方つける。
- 置き場所と名前は、パソコンの「ビデオ」フォルダに次のとおり。
  - 「【アルバム名】/【アルバム名】 全25曲.mp4」
  - 「【アルバム名】 サムネイル.jpg」
  - 「【アルバム名】 説明文.txt」
- **サムネイル**: 歌詞ボードに、次のものを載せる。右の台にテトを立たせる。
  - アルバム名（英名を大きく、和名を下に）
  - 「全25曲 / 25 Songs」
  - 「歌：重音テト / Vocal: Kasane Teto」
  - 「歌詞つき（日本語・英語）・約○時間○分 / With Lyrics (Japanese & English) - ○h ○min」
- **説明文**:
  - 題名、紹介文（日本語と英語）
  - 曲目と時間（「時間 和名 - 英名」の形）
  - クレジット（作詞・作曲・編曲・映像: Sunshine Pixel Sound／歌: 重音テト（UTAU）／すべてオリジナル／フォント）
  - ハッシュタグ（#重音テト #KasaneTeto #UTAU）
  - タグ（YouTube のタグ欄に貼る・カンマ区切り・500文字以内）: 重音テト・UTAU・ボカロ曲・オリジナル曲・歌詞付き・英訳付き などの日英。前の動画と同じく説明文の最後に「■ タグ」として書く。ジャンル名は入れない
  - ジャンルは書かない。テトは UTAU なので「#VOCALOID」は付けない。
- アルバム名は、英語のかっこいい名前にする（人間「英語タイトルのがいいな・・・かっこよくしたい」）。候補を出して選んでもらう。

## 2. 流れ（道具はすべて `tools/mv/`）

| # | やること | 道具 | 確かめること |
|---|---|---|---|
| 1 | テトの動画を 1コマずつの PNG にする（24コマ/秒） | `ffmpeg -i 動画 fr/%03d.png` | コマの数 |
| 2 | 口の位置（顔の動き）を測る | `teto_track.py`（※たたき台。下の注意） | 口に四角を描いた絵で、合っているか目で見る |
| 3 | テトを白い背景から切り抜く | `teto_matte.py <コマ> <出力> 0.66` | 暗い背景に置いて、髪のすきまの白・リボン・白目・アホ毛を拡大して見る |
| 4 | 曲ごとに、歌詞の行と、口を合わせたコマの並びを作る | `teto_mv.py`（`MV_DRY=1`。曲の JSON と UST を渡す）＋ `lyric_mouth.py` | 「歌っていない所で閉じている」100%に近いか |
| 5 | 歌詞の行を書き出し、英訳する | `stage_mv.py`（`MV_STILL=1` で行だけ出る）→ 英訳は手分け（下の 3） | 英訳の数が行の数と同じか |
| 6 | 舞台の動画を1曲ずつ書き出す | `yt_render_all.sh`（中で `stage_mv.py` を `MV_EN` つきで呼ぶ） | 映像と曲の長さの差が 0.6 秒未満か（自動で止まる） |
| 7 | 30MB 未満に切り分けて、パソコンへ送る | `yt_render_all.sh` の切り分け＋`yt_mover.sh`＋送る道具（device_commit_files） | 送ったら雲の分は消す（容量） |
| 8 | パソコンで1曲ずつ足して1本にする | `fmp4_join.py`（パソコンの `~/fm/addsong.sh NN [start]`） | 全体の長さ、曲の頭の画面、途中に飛んでも映るか |
| 9 | サムネイルと説明文 | `yt_thumbnail.py`、`yt_description.py`（`PAD` で時間をそろえる） | テトが欠けていないか、時間が動画とずれていないか |

### 見本を先に見せる
- 25曲を書き出す前に、**1曲目だけを書き出して見せる**。直しは早いほど安い（今回はアホ毛・白い背景・英訳・ジャンルを見本の段階で直した）。
- 静止画（`MV_STILL=10,30,62`）なら数秒で作れる。字の大きさや並びはこれで確かめる。

## 3. 歌詞の英訳（手分けして訳す）

- 5人の助手（サブエージェント）に、5曲ずつ同時に訳してもらう。1人あたり約1〜2分で終わる。
- 渡すもの:
  - その曲の画面の行（`lines/NN.txt`。1行＝画面の1行・ひらがな）
  - 台本（`vb25_NN_*.py`）の頭にある物語と、歌詞の文字列
- 決まり:
  - 出力は行と同じ数・同じ順の JSON。
  - 文字は ASCII だけにする（曲がった引用符やダッシュは使わない）。
  - 1行は40字くらいまで、長くても52字まで。
  - 同じサビは毎回同じ訳にする。
  - たとえ・作った言葉は、たとえのまま訳す（例:「ゆでだこ」→ I'm a boiled octopus）。
  - 慣用句は意味で訳す（例:「ひざわらう」→ my knees are shaking）。
  - 行の途中で言葉が切れている所は、2行続けて読むと自然になるように訳す。
  - 既存の作品の名前は出さない。
- 画面の歌詞は、実際に歌っている UST から出す（台本の古い歌詞と違うことがある）。

## 4. 歌詞の行の分け方（`stage_mv.py`）
- 休み（0.32秒以上）で切る。ただし、言葉の途中なら切らない。言葉の切れ目は janome で調べ、知っている短い言葉の途中では切らない。
- 続けて歌う所は、6〜16文字の間で「切りやすさ」がいちばん高い所で切る。切りやすさは次の合計で決める。
  - すきまの長さ
  - のばした音
  - 小節の切れ目
  - 助詞のあと（を・は・が・に・で・て・ね・よ など）
- 同じ母音が3つ以上続く「のばし」（しまう・う・う・う）は「〜」1つにまとめる。2つまで（にい・いち）はそのまま出す。

## 5. つなぎ方（パソコンでの仕上げ）
- パソコンの連結フォルダは書きこみが遅い（約3〜6MB/秒）。しかも1回の命令は180秒まで、裏で動かした処理は終わると止められる。だから 1.9GB を ffmpeg で一度に作ることはできない。
- そこで、1曲ずつ足していく。
  1. 曲ごとに、パソコンの中の速い場所（`~/fm`）で、切り分けを断片化 MP4（`-movflags +frag_keyframe+empty_moov+default_base_moof`）にまとめる。
  2. `fmp4_join.py` で本体に書き足す。時刻（tfdt）をずらし、番号を通しにする。1曲あたり約20秒で終わる。
- 1曲目は `start`、2曲目からは `add`。
- 時刻は1曲ごとに「映像と音の長いほう」で進むので、曲の長さの合計より1曲あたり約0.11秒長くなる。説明文の時間は `PAD=0.10925` でそろえる。

## 6. 気をつけること（今回つまずいた所）
- **テトの240コマを float でメモリに持つと 1.8GB になる。** 長い曲の途中で止まるので、uint8 のまま持ち、重ねるときだけ float にする。
- **書き出しを2本同時に動かさない。** 同じファイルに2つが書きこんで壊れる。自動で始まる仕込みと、手で始めた分が重ならないようにする。始める前に `ps` で確かめる。
- **`pkill -f` や `pgrep -f` で自分のコマンドの文字を含めると、自分のシェルが止まる（exit 144）。** `ps -eo pid,args | awk` で、引数をきっちり比べて止める。
- **実行中のシェルスクリプトを書きかえない。** 実行中の部分は読みこみずみでも、そのあとの行が狂うことがある。
- 雲の空き容量は少ない（約2GB）。送った切り分けはすぐ消す。
- 作曲ソフトの書き出し（node）と動画の書き出しを同時に動かすと、CPU（2つ）が足りない。そのせいで作曲ソフトが1時間の時間切れで落ちることがある（「Target page … has been closed」）。落ちたら待ち行列に戻す。
- 効果音サイトの素材は、自動で取ってこない（ボットよけを回る形になるので止められる）。使うなら人間に落としてもらう。効果音ラボの効果音を使った曲は、YouTube の Content ID に登録してはいけない（規約）。

## 7. 道具の一覧（`tools/mv/`）
| 道具 | 中身 |
|---|---|
| `teto_track.py` | 口の位置と開き具合を測る（たたき台。今回の動画は `track_teto_a.json` を使った） |

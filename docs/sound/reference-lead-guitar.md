# 単音のギター（リード・タッピング）の弾き方 — 調べたこと（2026-11-16）

人間「調べてないことを調べよう。」→ これまで学んでいなかった「単音のギター」を、データと記事で調べた。和音の弾き方は `reference-guitar-chords.md`。

- **音程の動き（ロック）**: となりの音（1〜2半音）43%／3〜4半音 22%／同じ音のくり返し 21%／5〜7半音 10%／8半音以上 3%。
- **拍のどこで弾くか（ロック）**: 8分のウラ 40%／拍の頭 37%／16分のウラ 22%。ファンクは3つがほぼ同じ（16分のウラが 32%）。
- **句をどこから始めるか（ロック）**: 8分のウラ 54%／拍の頭 33%／16分のウラ 11%。つまり、半分は「食って」入る。
- 上がる動きと下がる動きは半々。句の最後は、下がって終わるのが少し多い（55%）。

### ここから決めた弾き方

1. **手数は少なくてよい**。ロックで1拍に 1.3〜1.7音（8分が中心で、ところどころ16分）。16分でうめつくさない。
2. **句で切る**。5〜10音・3〜9拍でひと息。2割は休む。句の頭は、半分を8分のウラから。
3. **歌とちがって、句の最後を長くのばさなくてよい**（最後の音 0.48拍・途中 0.46拍）。のばすのは山場の1〜2音だけ（1拍以上の音は全体の1割弱）。
4. **和音の音は半分でよい**。残りは、となりの音でつなぐ音。ただし、のばす音と句の最後は、3つに2つを和音の音にする。
5. **同じ音をくり返す**（2割）。跳ぶのは少し（5度以上は1割ほど）。
6. **つなげ方**: 音の半分は次の音につなげる。そのうち4割は同じ弦のハンマリング・プリング・スライド（`_`）。長めの音の5つに1つはチョーキング（`^`）、ビブラート（`~`）は、のばした音の6〜7つに1つだけ（人間「ビブラートはゴムが伸びる音に聞こえて嫌い。チョーキングはよい」とも合う）。

## 2. タッピング（記事で調べたこと）

- タッピングは、指板を指でたたいて音を出し、ハンマリングとプリングでつなぐ弾き方（Wikipedia）。右手でたたいた指をはなすとき、弦を少し横に引っかけて、左手で押さえている音を鳴らす（Guitar World）。
- 基本の形は3つ組。「12フレットをたたく → はなして5フレット → はなして開放弦」や、「12をたたく → 左手で8をたたく → はなして5」（Riffhard ほか）。
- 両手の間かくを変えるだけで、広い音程の型が作れる（Guitar Player）。
- クリーンの音で、開いた形の和音を分けて弾く使い方がある。毎音ちがう弦で弾くと、打楽器のような効果になる（Guitar World「Tapper's Delight」）。
- マスロック寄りの使い方: 9度入り（add9）の和音を分けて弾く（Premier Guitar「Future Rock」）。両手を別々に使って「3＋3＋2」のリズムを作る（Premier Guitar「Expanded Two-Hand Tapping」）。
- 弾くときの注意: どの音も同じ大きさにそろえる。ほかの弦をミュートして雑音を出さない。クリーンの音で練習すると、音量を腕で出すことになる（Riffhard ほか）。

### ここから決めた弾き方（部品 `tap3()`）

1. 「たたく（高い音）→ はなす（左手の低い音）→ 左手でたたく（近い音）」の3つ組をくり返す。3つ組なので、16分で弾くと4拍子の上をずれていく（3＋3＋3＋3＋…）。
2. 左手の2音は近く（2〜5半音）、右手の音は遠く（7半音以上）。
3. 9度入りの和音を使う。組が変わるたびに、1段ずつ上（下）へ移る。
4. どの音も同じ大きさで、つなげる（パートに `legato=True`）。クリーンの音。
5. 歌が細かい小節では休み、歌が伸ばしている小節で答える。

17 のスケッチ G を、この形で作り直した（G v2）。

## 3. いっしょに調べて分かったこと（2026-11-16）

- **雑音の点検の「パチパチ」「プチッ」は、ドラムの打った音だった**。16 の D・E・F と、17 のスケッチ G・H・I で、点検が言った所を1つずつ、どの楽器の音かを調べた（`tools/vt3/noise_who.py`）。どれも 6kHz より上の音の 9割以上がドラム（キックのビーターの「カチッ」とクラッシュの頭）。同じ形が毎回くり返されているので、録音されたドラムの音そのもの。ほんとうの雑音ではない。例外は H の1か所（歌 52%・ドラム 47%。歌の子音と重なった所）。
- **息の音**: 16 E（目安の内）・F（目安より大きめが4か所。−6dB をこえる所は無し）、17 のスケッチ G・H・I（目安の内）。調べたのは、いちばん多く使っている声（クリア）だけ。
- **16 E のベース**: ベースだけを書き出して測ると、1小節に5音で動いている（サブベースと合わせても4音）。曲ぜんたいを分析ソフトにかけると「2音・根音 85%」と出るのは、明るいシンセのベース（音の重心 354Hz）が、分ける道具で「ベース」として取り出されず、のびるサブベース（72Hz）だけがベースに入るため。**楽譜どおり動いている。分析ソフトの弱点**。耳で動いて聞こえるかは、まだ人間に聞いてもらっていない。
- **伴奏の休み**: 16 D は、伴奏を止める所を足したあとも、音で測ると 0.1%。音で測る「伴奏」にはドラムが入っていて、止めた所でもフィルが鳴っているため。お手本51曲も、この測り方では 0〜0.8%。目安の「4〜10%」は、楽譜でピアノ伴奏だけを数えた別の測り方（POP909）なので、くらべてはいけなかった。
- **お手本の測り直し**: 51曲すべて測り直せていた（前の報告の「50曲」は数えまちがい）。

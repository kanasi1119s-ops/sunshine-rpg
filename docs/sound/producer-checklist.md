# 仕上げの確認表（機械の検査と、人の耳で聴く項目）

目的: 「作曲ソフトで作った曲が、プロの耳に耐える」ために、**機械で測れること**と**人の耳でしか決められないこと**を分ける。
私（Claude Code）は音を聴けない。機械の検査は、はっきりした欠点を落とすためのもので、「良い曲」の保証ではない。

## 1. 機械の検査（`tools/audio-check/producer-check.py`）
書き出した WAV に対して実行する。1つでも「×」なら直す。

| 項目 | 基準 | 落とす欠点 |
|---|---|---|
| peak | -1.0dBTP 以下 | 圧縮配信での割れ |
| clip | 頭打ち 0 個 | 音割れ |
| dc | 直流成分 0.005 未満 | 余裕（ヘッドルーム）の浪費・プチッという音（2026-10-02 に実際にラウドメタル曲で 0.04 を検出し、出口の直流カットで解決） |
| lowmono | 120Hz 未満の左右相関 0.95 以上 | 低音の位相の打ち消し・左右に振れた低音 |
| start | 頭の無音 0.3秒未満、最初の音が小さい | ループ時のプチッ・間延び |
| seam | 終わりと頭の音量差 9dB 以内 | ループのつなぎ目の段差 |
| harsh | 4〜8kHz が -13dB 以下 | 耳が痛い |
| lufs / crest / corr / tail / lra（△） | ジャンルごと | 音量・詰めすぎ・真ん中寄り・残響の尾・起伏のなさ |

## 2. 人の耳で聴く項目（機械では決められない）
聴く順番: ①小さい音量で ②スマホのスピーカーで ③ヘッドホンで ④モノラルで（左右を足しても濁らないか）。

1. **最初の10秒**: 引き込まれるか。導入が長すぎないか。
2. **メロディ**: 口ずさめるか。同じ動機が繰り返されすぎていないか。サビで盛り上がるか。
3. **ベースとキック**: 低音がもたつかないか。キックとベースが喧嘩していないか（重さが出ているか）。
4. **ドラムのノリ**: 機械的でないか。スネアの位置（あと乗り）・ハイハットの強弱が気持ちいいか。フィルの入りが自然か。
5. **ギター**: 歪みが濁らず、刻みの粒が聞こえるか。サビで壁になるか。高域がジャリつかないか。
6. **広がり**: 左右の配置が不自然でないか。奥行き（残響）が曲の場面に合っているか。
7. **起伏**: 静と動があるか。間奏・ブレイクからサビへの戻りが効いているか。
8. **疲れ**: 3分間聴いて耳が疲れないか（ラウド系は特に）。
9. **ループ**: 終わりから頭へ戻るところで違和感がないか（3周聴く）。
10. **場面への合い**: ゲームの場面（町・戦闘・ボス・悲しみ）に合っているか。ほかの曲と音量の差が大きすぎないか。

感想は `docs/sound/tracks.md` に書き、直したい点を依頼してください。

## 3. 今の限界（正直なところ）
- 音色の質感（ギターのアンプの「それらしさ」、ピアノ・弦の生っぽさ）は、サウンドフォントとアンプの仕組みの上限に左右される。実際の機材・生録音には届かない。
- 作曲（旋律・和声・展開）の良さは、数値では測れない。必ず人が聴いて選ぶ。
- 仕上げのマスタリング（曲間の音量そろえ、最終EQ）は、曲ごとの耳での調整が要る。

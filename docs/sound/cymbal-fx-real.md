# 本物のシンバルの効果音（patch `cymbalFx`）

2026-10-22 追加。逆再生シンバル・スウェル（盛り上げ）を、**合成音ではなく本物のシンバルの録音**で鳴らす（人間の決まり「電子音（シンセのライザーなど）は使わない」）。
これまでの `fxRiser` の F4（合成の逆再生シンバル）の代わりに使う。作曲ソフト専用（ゲーム本体 `dist/` には入れていない）。

- 音源: `assets-src/soundfont/extra/fx-cymbal-real.sf3`（2.2MB。GM 127）。使う曲だけ自動で読み込まれる。
- 元の録音（どちらも **CC BY 4.0・クレジット必要**）:
  - CrocellKit（DrumGizmo）: クラッシュ2枚・チャイナ2枚の強い一打を最後まで（OH＋部屋のマイクをまぜたステレオ）
  - Cymbal percussion（オスロ大学 fourMs Lab、2011。https://zenodo.org/records/21710617）: サスペンデッドシンバルのマレットのロール（クレッシェンド・ディミヌエンド）とふちの強打
- 作り方: `tools/soundfont/cymbal-fx-prep.py`（取り出し・逆再生・切り出し）→ `tools/soundfont/build-cymbal-fx.mjs`（SF3 に）

## 書き方
パートを1つ作り、`"instrument":"pad","patch":"cymbalFx"` にする（オクターブはどれでもよい）。

| 音名 | 中身 | 長さ |
|---|---|---|
| C | 逆再生クラッシュ | **音符の長さぶん盛り上がり、音符の終わり（次の拍の頭）で山（打った瞬間）になって止まる** |
| D | 逆再生チャイナ | 同上 |
| E | スウェル（マレットのロールのクレッシェンド） | 同上（いちばん大きい所で終わる） |
| F | クラッシュ1の一打（長い余韻） | 書いた所から鳴る。余韻は約8秒（長めの音符で書く） |
| F# | クラッシュ2の一打 | 同上 |
| G | チャイナ1の一打 | 同上 |
| G# | チャイナ2の一打 | 同上 |
| A | サスペンデッドシンバルのふちの強打 | 約7秒 |
| B | ロールのディミヌエンド（だんだん消える） | 約21秒（曲の終わりに） |

- 逆再生・スウェルの長さは、書き出しのとき音符の長さ（秒）にいちばん近い録音（逆再生 0.25・0.35・0.5・0.7・1・1.4・2・2.8・4 秒、スウェルはさらに 5.6・8 秒）が選ばれ、**その長さぶん手前から鳴らして、終わりが音符の終わりにそろう**（`src/audio/midi-export.ts` の CYMBAL_FX）。テンポに関係なく、山は拍の頭に来る。
- 例（サビの頭に向けて1拍・2拍）: `"notes":"R:30 C4:2 R:30 C4:1 ..."` と書き、山の所（サビの頭）に crash パートの一打を重ねる。
- 逆再生は山のあと 30ms で止まる（すぐあとの本物の一打につなぐため）。一打の音は鍵盤を離しても 4 秒かけて消える（すぐ止めない）。

## 確かめたこと（2026-10-22。数値だけ。耳での確認はまだ）
- 120bpm の試験曲で、2拍（1秒）の逆再生クラッシュ・逆再生チャイナの音が切れる所は、拍の頭から +36ms・+34ms（離したあとの 30ms と、打った瞬間のあとの 8ms）。山（10ms 平均）は拍の頭の 100〜125ms 前（シンバルの洗うような鳴りが打った直後にいちばん大きくなるため）。
- クリップなし。書き出した WAV は頭の無音が切られるので、時刻は「最初の音」からの位置になる点に注意。

# ラウドロックのドラムの音の目標（数値）

2026-10-22 記録。人間「TRiDENT みたいなドラムの音」「ニューエラ」。
参考の曲（TRiDENT「NEW ERA」2025年。編曲 堀江晶太）を人間が録音して渡したものを、音源分離（Demucs htdemucs）でドラムだけにして測った。
**録音そのもの・取り出したドラムは保存しない・使わない**。ここに残すのは、帯域の量などの数値だけ（旋律・フレーズ・音そのものは写さない。CLAUDE.md 1-1）。

測り方: `analyze.py`（作業用。10帯域のエネルギー、キック・スネアの1打ごとの帯域の形と立ち上がり）。

## これまでの失敗（同じことをしない）

- **作曲ソフトのドラムは1本の通り道（MIDI のドラムチャンネル）を共有する**。パートの fx は太鼓ごとに分かれず、キット全体に掛かる。キック用の EQ がスネアやシンバルにも掛かり「不自然」「スネアだけ大きい」になった。太鼓ごとの音作りは、ドラム音源（sf3）を作る段階で焼き込む（`tools/soundfont/build-drums.mjs` の `crocell-punch`）か、太鼓ごとに別々に書き出してから処理する。
- **kick の `trigger`（作曲ソフトのトリガー）は合成音**で、150Hz→55Hz に音程が滑り落ちる。「きゅいんきゅいん」と聞こえる（人間が嫌った）。使わない。トリガーは録音のキックの「カチッ」で作る。
- CrocellKit のスネアは**強さ 118 以上でリムショットの録音**になる。volume 0.18 前後の `X` はリムショットになり、大きすぎる。ふつうの打ちにしたいときは volume 0.13 前後。
- 部屋マイク（amb 0.4）を混ぜた音源は「空間を感じすぎる」。
- うねる系（フランジャー・フェイザー）は「きゅいんきゅいん」で不要。
- EQ だけで帯域の形を合わせても、元の録音の性格は変わらない（人間「全然違う」）。

## 結果（2026-10-22。8ビート `beat8.json` 188bpm・8小節・ドラムだけ。測り方は上と同じ）

キックの中のマイク（ビーター側）を 2 倍（`micMul`）、録音に無い「カチッ」を合成のクリック（3〜12kHz に絞った 15ms のノイズ。打音の山に比例。種でそろえた乱数。音程なし）で足す、
10帯域の補正（`bandEq`）、アタックの強調（キック +4・スネア +3・タム +3dB まで）、軽いクリップ（キック 2.5・スネア 2・タム 2dB）、スネアの音量 +16dB（補正で下がった分を戻す）。

### ハイハット（2026-10-22 人間「オープンなのかクローズなのかわからない」「半開きでももう少し音伸びていい」）

- CrocellKit のクローズ（42）は、どの強さの録音も −20dB まで 45〜90ms で、層の切りかわりで開いた音にはならない（直す必要なし）。
- 開き（46）・半開き（95）の release を 0.6 → 6 秒・0.4 → 4 秒にした（SoundFont の release は −96dB までの秒数）。止まるのは同じ exclusive 1 の次のクローズ・ペダルのときだけ（spessasynth の止め方は約 260ms で −96dB）。
- グリッドの `h` で半開きを書けるようにした（`drum-keys-crocell.md`）。
- ハイハットだけの8小節（`hat8.json`）で、−20dB までの余韻: crocell の X 36〜59ms・x 47〜68ms、crocell-punch の X 39〜57ms・x 39〜52ms（すべて 150ms 以下）。
  半開き h は 270〜330ms（次の X で閉じるまで鳴る）、開き O は 420ms（次の O まで）。

### Naked Drums（途中で止めた）

`naked`・`naked-punch` 系（`drum-keys-naked.md`）は、人間「これはシンバルの音じゃないな」「一個前の音源に戻そうか」で調整を止めた。
Naked のクラッシュは 1打ずつ測ると −20dB まで 0.6〜1.0 秒・−40dB まで 1.7〜2.9 秒で、CrocellKit（1.0〜1.6 秒・3.0〜3.7 秒）より短く切れる。

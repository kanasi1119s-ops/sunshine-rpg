# HUMMING RELAY（vt3・25曲）を作り直す — 決まりと進み具合（仮）

2026-11-11 人間「25曲作成止まってたよね。あれ全部完成度高めて。同じ感じにならないようにするのと、音の深み、スケール、空間、しゃくり、ビブラート。
とにかく細部まで細かく作っていって。特にギターはだいたい良くないから音の作り方もプロ仕様にするように。演奏の仕方もプロ仕様にして。」
同日「電子系音源なんだけど、既存のよく使ってたやつじゃなくて、Kawaii future bass 系に変えていこう。」

曲の物語・歌詞・旋律（`docs/sound/vt3-plan.md`）は変えない。伴奏と歌い方を、1曲ずつ作り直す（全曲に同じ処理をかけない）。

## 1曲ごとに見直すこと
1. **歌**（`vt3x_lib.vocal_polish`・`harmony`）
   - しゃくり: 句の頭を 50〜100 セント下から。どの句に入れるかは曲ごとに決める（自動の決まりまかせにしない）。
   - ビブラート: 1拍以上の長い音の後ろ 1/3〜1/2 だけ。Aメロは浅く、サビは深く（場面ごとの深さを曲ごとに決める）。
   - 人の歌い方の細かい揺れ（auto）・息つぎ（breaths）・ノイズ対策（hiClean・breathy 0・declick・headFade）。
   - サビの3度下のハモリ、最後のサビの重ね。入れる場面は曲ごとに変える。
2. **ギター**（`vt3x_lib.GuitarRig`）
   - 弾き方: 弾く場所は曲の句に合わせた型で決め、揺れ方は本物のギタリスト（GuitarSet。Funk／Bossa／Jazz／Rock／Singer-songwriter をジャンルで選ぶ）から借りる。
     弦ごとに鳴らす（弾かなかった弦は鳴り続ける）。`powerChord: false`・`double: false`。
   - 音作り: 直接録音のギター（DI）→ ペダル（コンプ・ブースト・オーバードライブ）→ アンプ（歪みは NAM、48kHz で書き出す）→ キャビネット → 空間（プレート・スプリング・やまびこ）。
     コーラスの「きゅいん」・crunch の「ピロピロ」・すぐ止めるミュートは使わない（`banned-sounds.md`）。左・右・リードの3本。
3. **深み・スケール・空間**: 場面ごとの強さ、低い音から高い音までの広さ、残響の長さ・手前の間、うすい層（聞こえるか聞こえないかのパッド）、効果音は音楽と重ねる。
4. **電子の音**: これまでよく使っていた音（picoLead・surgePad…・modernBass など）ではなく、カワイイ・フューチャーベース系（fbChord＝キックで凹むうねる和音・vocalChop・kawaiiArp・popBell・surgePopcorn・surgeBassPop）に替える。ゲームの音（チップ音）は使わない。
   2026-11-11 に足した音（`docs/assets-credits.md`）: kfbSupersaw・kfbSupersawSwell・kfbSawStab・kfbSquarePluck・kfbGlocken・kfbMusicBox・kfbBrightBells・kfbSquareLead・kfbSineLead・kfbFormantLead・kfbSub、
   kawaiiFx（効果音: C4 泡・C#4 水滴・D4/D#4 きらきら・E4 きゅっ・F4 ぴょん・F#4 上がる音・G4 下がる音・G#4 逆再生シンバル風／電子ドラム: A4 キック・A#4 スネア・B4 クラップ・C5 指パッチン・C#5/D5 ハイハット・D#5 リム・E5/F5 タム。`modulate: false`）。
   2回目（同日「ブルーアーカイブで使われてそうなの追加して」）: kfbGrowlBass・kfbNeuroBass・kfbFmBass・kfbHoover・kfbHardcoreLead・kfbRaveStab・kfbChipLead（ゲームの曲だけ）・kfbTranceLead・kfbGlassEp・kfbBoops・kfbCharmOrgan・kfbFlute・kfbSparklePad、
   kawaiiFx に F#5 ハードなキック・G5 インパクト・G#5 サブドロップ・A5 レーザー・A#5 レコードのパチパチ・B5 タンバリン・C6 シェイカー・C#6/D6 ウッドブロック・D#6 グリッチ。
   試聴の点数: かわいい日常（エレピ・フルート・ぽこぽこ・オルガン・鉄琴）8.2／激しい電子（ハードなキック・うなるベース・ハードコアのリード）6.7。
   気づいたこと: kfbSub は bass のパートだと とても大きい（音量 0.03〜0.05 で足りる）。kfbFormantLead・kfbBrightBells は 6kHz より上が強いので、ローパス（5〜9kHz）をかけて使う。
   3回目（同日「他にも可愛い日常系の音源ない？あったら追加して」）: 録音の楽器（VCSL・CC0）。ocarina（オカリナ）・harmonica（ハーモニカ）・tubeGlock（筒の鉄琴。A6 より上がきれい）・wineGlass（グラスハープ。伸ばす音・パッド向き）・balafon（木琴の仲間。ぽこぽこ）・strumstick（小さな3弦の弦楽器。ウクレレのように軽い。D3〜A5）・toysFx（おもちゃと小物。鍵盤ごとに別の音・`modulate: false`。C4〜D4 おもちゃの汽笛・D#4/E4 玉の笛・F4/F#4 サイレン笛・G4/G#4 フレクサトーン・A4/A#4 ラチェット・B4 スラップスティック・C5 ビブラスラップ・C#5/D5 ウインドチャイム・D#5 フィンガーシンバル・E5/F5/F#5 トライアングル）。試聴 8.27。作り方は `tools/soundfont/build-vcsl-daily.py`
   **使わない音（2026-11-11 人間）: kfbFlute（シンセのフルート）と ocarina（オカリナ）は、指定されないかぎり使わない**（「普通のフルートの音にしか聞こえない」「オカリナもフルートと同じ感じで使う時にいいます。そこら辺の音、電子って感じの音にして」）。やわらかいメロディは電子のリードで: kfbDreamLead（サイン波＋透き通った高い音＋オルゴールの立ち上がり）・kfbWobbleLead（ゆれる中空の音）・kfbFutureSax（電子のサックス）・kfbSineLead・kfbSquareLead。試聴 8.28
   **kfbHardcoreLead は作り直した（2026-11-11 人間「こもる感じでキレがない。もう少し繊細で透き通るような感じも入れた方がいい」）**: 前の音（Rozzer「He Never Lost His Hardcore」）は 5〜10kHz が −29dB でこもっていた。芯＝Giana Brotherz「Cut Through」（するどいノコギリ波）に、Inigo Kennedy「Glitter 2」「Delicate」（細くて透き通った音・1オクターブ上）を小さく重ねた（5〜10kHz −14dB）。さらに同日「鋭さがもう少し欲しい。音の粒もはっきりすると」→ プリセットのリバーブ・ディレイを切り（--strip-space）、余韻を 0.12 秒に短くし、鳴り始めを 4dB 持ち上げ（--punch）、Giana Brotherz「Crisp Cross」（とても明るい）を重ねた。鳴り始めの粒は、はじめオルゴールの音（Music Box Lead）を重ねたが「オルゴールのリードは違うかな。ギター和音のがいいかも」→ 歪んだギター（John Valentine「Distorted Electric Guitar」）を根音と5度上（パワーコード）で重ねた（続けて弾いた音の間の谷 −28dB）。作り方は `tools/surge/layer.py`（プリセットを重ねて1つの音源にする）
   **ブルーアーカイブの曲でよく使われる要素（2026-11-11 人間が調べて教えてくれた。電子の曲の編曲はこれを軸にする）**:
   - 和音・リード: 厚いスーパーソー（デチューン）＋ キックに合わせて大きくうねるサイドチェイン（kfbSupersaw・fbChord・`duck`）
   - プラック・ベル: ぽこぽこした木琴・マリンバの質感、クリスタルのようなベル・オルゴール。アクセントと、裏で細かく刻むアルペジオ（kfbSquarePluck・kfbGlocken・kfbMusicBox・kfbBrightBells・balafon・tubeGlock）
   - チップ風の矩形波: かくし味・対旋律として少しだけ（kfbChipLead・kfbSquareLead）。主役にはしない（ゲームの音を主役にするのは「ゲームの曲」と言われたときだけ）
   - ドラムとベース: 4つ打ち → サビ（ドロップ）でハーフテンポ（トラップ風）に切りかえる。太くて丸いサブベース（kfbSub）をキックとサイドチェインでなじませる
   - アクセント: コインや UI のようなゲーム風の効果音（kawaiiFx）、ボーカルチョップ（声を切って音程をつけて鳴らす。**まだ音源がない → テトの声から作る**）
   **音がズレて聞こえた原因（2026-11-11 人間「音ズレて聞こえる」・ヒップホップ風の試聴）**: (1) パートごとに swing の量を変えた（キック 0・スネア 0.35・ハット 0.45・メロディ 0.35）ので、同じ拍の音がばらばらに鳴った → swing は全パート同じ量にする（または 0）。(2) 立ち上がりのおそいシンセ（kfbWobbleLead）が拍より約 50ms おくれて聞こえた → `tools/surge/layer.py --trim 0.12` で鳴り始めを詰めた。新しい音を足したら、パートを1つずつ書き出して、鳴り始めが格子からどれだけずれるかを測る。(3) ギターのストロークは、弦のずらしの真ん中が拍の頭に来るようにする
   **テトの声の種類（2026-11-11 人間「滑らか音源も使える用にしようか」「テトボイス5種類ぐらい用意して欲しい」）**: `vt3x_lib.TETO_VOICES` と `teto_voice(path, 名前)`。
   clear（クリア＝これまでの標準）・smooth（なめらか＝滑らか音源 `teto-smooth`。ない音は通常の音源で歌う）・whisper（ウィスパー＝弱音源 75%＋息）・cute（キュート＝幼く明るい）・cool（クール＝少し大人っぽい）。
   **主体にするのは クリア・ウィスパー・キュート（2026-11-11 人間「1.3.4 を主体に曲に反映しましょう」）**。なめらか・クールは、曲に合うときだけ。場面ごとに変えるのは `voice_by_scene(path, S, {"verse": "whisper", "chorus": "cute"})`。
   曲と場面で選ぶ（全曲同じにしない）。なめらかは高い所のかすれが通常より少し多い（測った値: 倍音とすきまの差 5.0dB、クリアは 9.7dB）ので、使う曲では雑音を念入りに調べる
   **ベースの連打の引っかかり（2026-11-11 人間・01）**: 同じ音を休みなしで続けて弾くと、前の音が切れてから次の音が立ち上がるまでに 6〜12ms の穴（−24dB）があく → ベースのパートに `sustain: 1.15`（音を 15% 長くして重ねる）。連打のあるベースの曲では、ベースだけ書き出して穴を測る
   **気に入った音（2026-11-11 人間「この音気に入りました」）**: 01 のサビ2 の「ピロピロピロピーン」＝ kfbSquarePluck（Surge XT「Pure Square」）で和音の音を16分で8つ駆け上がり、ピンポンディレイ（0.75拍・mix 0.16・feedback 0.25）で最後の音を残す。4小節ごとの最後の小節の後半に置いた。合う曲で使う（全曲には入れない。音の並べ方・置く場所は曲ごとに変える）
   **kfbSquareLead は旋律に使わない（2026-11-11 人間・01「ヒヨコがピヨピヨ鳴いているみたいな音はいらない」）**: 音の高さが ±70 セント揺れる（矩形波＋深いビブラート）。歌をなぞるシンセや BGM の旋律に使うと、高い音でヒヨコの声に聞こえる。新しい音を旋律に使う前に、長い音を鳴らして高さの揺れを測る（kfbSineLead ±10・kfbDreamLead ±20・kfbFutureSax ±35・kfbTranceLead −130〜+65）。原因を探すときは、まず「その場面で鳴っているパートの一覧」を出し、聞こえた時刻を聞く
5. **似た曲にしない**: 始まり方・山の作り方・伴奏の型を25曲で並べて、重なりを直す。
6. **確かめ**: 点数（最低 7.5・目標 8）、場面ごとの大きさ（サビがいちばん大きい）、雑音（noise_scan.py で声・楽器・仕上がりを最初から最後まで）。最後は人間の耳。

## 絶対条件: 似た曲を作らない（2026-11-12 人間「絶対条件でここで作った曲で似た曲を作らない。過去の物も含めて。1曲1曲こだわって作る」）

- これまでに作った全部の曲（この第3弾だけでなく、過去のアルバムも）と、旋律・ベース・展開・音の選び方が似た曲を作らない。
- 2026-11-12 に数えたら、vt3 の 02（v3）は、旋律のリズムが 03 と 88%・過去の vb25-01 と 86% 同じ、ベースの型が過去の曲と 79% 同じだった。
  原因は、旋律を「半拍休み → 8分で上がる → 長い音 → 休み」の型で書き、ベースを共通の部品（`bass_line` の root8・oct8・walk・long）で書いていたこと。
- 決まり:
  1. 旋律とベースは、共通の部品や前の曲の型を使わず、その曲の物語と曲調のために書く（`bass_line` は使わない）。
  2. 書いたら、書き出す前に `python3 tools/vt3/similar_check.py <歌入りの JSON>` で、これまでの全部の曲とくらべる。
     目安: 旋律の動き 25% 未満・旋律のリズム 60% 未満・ベースの型 50% 未満。こえたら書き直す。
  3. 音の種類・音域・奥行き・場面ごとの強弱・その曲だけの仕掛けも、曲ごとに決める。同じ手順を何曲にも当てはめない（「2曲目から手抜き感しかない」と言われた）。
  4. 同じサビを同じ編成で3回くり返さない。場面ごとに足す音・引く音を変えて、単調にしない。
  5. 数字は入口。最後は耳で確かめてもらう。

### 作る順番（2026-11-12 人間「必ず次の曲作る時、1回曲調が以前のものと似てないか確認してから作るようにして。あとプロみたいにこだわって作って」）

1. **書く前**に、決めた曲調（テンポ・和音の進み方・使う音色）を、今までの全部の曲とくらべる:
   `python3 tools/vt3/similar_check.py --plan bpm=122 chords="Ebmaj9 Dbmaj9 Cm9 Abm6 ..." patches=kfbGlassEp,kfbSub,...`
   目安（近さ 50% 未満・音色の重なり 60% 未満・和音の進み方 60% 未満）をこえたら、曲調を決め直してから書く。
2. 書いたら、歌入りの JSON で `python3 tools/vt3/similar_check.py <JSON>`（旋律・ベース・曲調の全部をくらべる）。こえたら書き直す。
3. 直前の曲と、テンポ・ノリ（4つ打ち／2ステップ／ハーフ／シャッフル…）・主役の音・始まり方・終わり方のどれも同じにしない。
4. 既にある曲に音を足して直すのではなく、つまらないと言われたら曲そのもの（テンポ・和音・節・音の世界・展開）から決め直す（02 は v4 まで足すだけで「クソつまらない」「プロが作る曲ではない」と言われ、v5 でゼロから作り直した）。

## アルバムの考え（2026-11-12 人間）: 「幸せで美しい物語に書き換えて行く」

（はじめ「物語は幸せで楽しいものに書き換えられる」→ 同じ日に「幸せで美しい物語に書き換えて行く」に変更。「楽しい」ではなく「美しい」。書き換えて「行く」＝曲の中で、また曲から曲へ、少しずつ書きかえていく）

- HUMMING RELAY の25曲ぜんぶの考えにする。どの曲も、はじめは小さな悩み・さびしさ・うまくいかない事から始まってよいが、曲の中でそれを幸せで美しい物語に書きかえていく（にぎやかに楽しくするのではなく、美しく。音も言葉も、きれいさを大事にする）。
- 書きかえるきっかけは、合いことばの節（5つの音の鼻歌）や、だれかのひとこと・音。暗いまま・悲しいまま終わる曲は作らない。
- **この考えはニュアンス（曲の向き）で、歌詞にそのまま書く言葉ではない**（2026-11-12 人間「歌詞を全てそれに変えたらおかしくなるよね。だからニュアンス、コンセプトなの。直接的な言葉ではないの」）。
  「書きかえる」「幸せ」「美しい」「物語」と歌わせない。景色・音・しぐさの変わり方で感じさせる。もとの歌詞を全部この考えに合わせて書き直すこともしない。
- 02 では、涙でにじんだ文字を DJ の声がなぞると、夜空に星がふえて部屋が透きとおる（Aメロ2 の後半「にじんだもじのあと こえがなぞると／よぞらにほしがふえ へやがすきとおる」）。
- 作り直すとき、曲ごとに「どこで・何が・どう書きかわるか」を曲を決める表に1行で書く。

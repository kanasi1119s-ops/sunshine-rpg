# HUMMING RELAY（vt3・25曲）を作り直す — 決まりと進み具合（仮）

2026-11-11 人間「25曲作成止まってたよね。あれ全部完成度高めて。同じ感じにならないようにするのと、音の深み、スケール、空間、しゃくり、ビブラート。
とにかく細部まで細かく作っていって。特にギターはだいたい良くないから音の作り方もプロ仕様にするように。演奏の仕方もプロ仕様にして。」
同日「電子系音源なんだけど、既存のよく使ってたやつじゃなくて、Kawaii future bass 系に変えていこう。」

曲の物語・歌詞・旋律（`docs/sound/vt3-plan.md`）は変えない。伴奏と歌い方を、1曲ずつ作り直す（全曲に同じ処理をかけない）。

## 1曲ごとに見直すこと
1. **歌**（`vt3x_lib.vocal_polish`・`harmony`）
   - しゃくり: 句の頭を 50〜100 セント下から。どの句に入れるかは曲ごとに決める（自動の決まりまかせにしない）。
   - ビブラート: 1拍以上の長い音の後ろ 1/3〜1/2 だけ。Aメロは浅く、サビは深く（場面ごとの深さを曲ごとに決める）。
   - 人の歌い方の細かい揺れ（auto）・息つぎ（breaths）・ノイズ対策（hiClean・breathy 0・declick・headFade）。
   - サビの3度下のハモリ、最後のサビの重ね。入れる場面は曲ごとに変える。
2. **ギター**（`vt3x_lib.GuitarRig`）
   - 弾き方: 弾く場所は曲の句に合わせた型で決め、揺れ方は本物のギタリスト（GuitarSet。Funk／Bossa／Jazz／Rock／Singer-songwriter をジャンルで選ぶ）から借りる。
     弦ごとに鳴らす（弾かなかった弦は鳴り続ける）。`powerChord: false`・`double: false`。
   - 音作り: 直接録音のギター（DI）→ ペダル（コンプ・ブースト・オーバードライブ）→ アンプ（歪みは NAM、48kHz で書き出す）→ キャビネット → 空間（プレート・スプリング・やまびこ）。
     コーラスの「きゅいん」・crunch の「ピロピロ」・すぐ止めるミュートは使わない（`banned-sounds.md`）。左・右・リードの3本。
3. **深み・スケール・空間**: 場面ごとの強さ、低い音から高い音までの広さ、残響の長さ・手前の間、うすい層（聞こえるか聞こえないかのパッド）、効果音は音楽と重ねる。
4. **電子の音**: これまでよく使っていた音（picoLead・surgePad…・modernBass など）ではなく、カワイイ・フューチャーベース系（fbChord＝キックで凹むうねる和音・vocalChop・kawaiiArp・popBell・surgePopcorn・surgeBassPop）に替える。ゲームの音（チップ音）は使わない。
5. **似た曲にしない**: 始まり方・山の作り方・伴奏の型を25曲で並べて、重なりを直す。
6. **確かめ**: 点数（最低 7.5・目標 8）、場面ごとの大きさ（サビがいちばん大きい）、雑音（noise_scan.py で声・楽器・仕上がりを最初から最後まで）。最後は人間の耳。

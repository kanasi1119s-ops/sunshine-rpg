# 作曲の技法メモ（学習ノート）

ネット上で公開されているゲーム音楽・チップチューンの作り方の解説を読んで、**一般的な技法だけ**を自分の言葉でまとめたノートです。
`docs/design/pixel-art-notes.md` の音楽版で、曲を作る役（`roles.md` 3-7）が曲を作る前に読みます。新しくわかったことは、曲を作るたびにここへ書き足します。

- 既存の曲のメロディ・コード進行・リズムの型は写さない。特定の作曲家の作風を狙って似せることもしない（`CLAUDE.md` 1-1）。このノートに書くのは「仕組みと考え方」だけで、実在の曲の旋律は1音も載せていない
- 学んだ日: 2026-09-30（人間の依頼「ネット上のゲーム音楽を学習してClaude Codeにも共有」）
- 数値（BPMなど）は、出典の記事が挙げていた目安。そのまま使うのではなく、曲の場面に合わせて決める

## 1. うちの音源でできること・できないこと（先に確認）

`src/audio/score.ts` と `audio-engine.ts` の現状（2026-09-30時点）。

| できる | まだできない |
|---|---|
| 波形4種（`square` / `triangle` / `sawtooth` / `sine`）のパートを何本でも重ねる | ノイズ（ドラム用）。**キック・スネア・ハイハットは鳴らせない** |
| パートごとの音量、音符ごとの長さ、休符 | 矩形波のデューティ比（12.5%・25%・50%）の切り替え |
| ループ再生（全パートの合計拍数をそろえる） | ビブラート、ポルタメント（音程のすべり）、スイープ |
| 立ち上がり5ms・終わり最大50msの固定の音量変化 | 音符ごとの音量エンベロープ、クレッシェンド |
| | 曲の途中のテンポ変更、イントロ部分だけを最初の1回だけ鳴らす（イントロ＋ループ分割） |

**曲を作る側の心得:** できないことは、下の「工夫」で代用できるものが多い。代用しても足りないときは、曲のために音源を広げる提案を `docs/ideas.md` に書く（第6節に候補をまとめた）。音源の変更は既存の曲の聞こえ方を変えうるので、`CLAUDE.md` 1-7 に従って `docs/decisions.md` に理由と影響を書いてから行う。

## 2. ファミコン風の音づくりの基本（仕組み）

出典の解説が共通して挙げていた、チップ音源の考え方。

- **チャンネルには役割がある。** 本物のファミコンは「矩形波2＋三角波1＋ノイズ1」の4つだけ。矩形波はメロディ（リード）、三角波は低音（ベース）、ノイズはドラム。この「少ない音で全部を表す」窮屈さが、あの音の魅力になっている
- **三角波は音量を変えられない**（鳴るか鳴らないか）。だからベースは「長さ」と「休符」で強弱をつける
- **同時に鳴らせる音が少ない分、和音は「アルペジオ」で匂わせる。** 和音の構成音（たとえば根音・3度・5度）を、1つのパートで高速に順番に鳴らすと、耳が「和音が鳴っている」と感じる。うちでは、8分音符や16分音符で上下させる形がすでに硝子湖の町で使われている
- **音色（波形）の選び方**
  - 矩形波: 中央がぽっかりした「ぽこぽこ」した音（50%）〜細くて鼻にかかった音（デューティ比が極端なとき）
  - ノコギリ波: 鋭く、輪郭がはっきりする。アルペジオや、切迫した旋律に向く
  - 三角波: こもった丸い音。ベースに向く。旋律に使うと、音程が曖昧に聞こえやすい
  - サイン波: いちばん柔らかい。鐘・しずく・霧のような「空気」の表現に向く
- **空間の広がりは、実際のリバーブではなく「工夫」で出す。** 同じ旋律を、小さい音量で少し遅らせて別パートで鳴らす（ディレイ／エコー）。同じ旋律を、ごくわずかに音程をずらして重ねる（デチューン）。音を切らずに小さい音で残す（残響の代わり）

## 3. 場面別の作り分け（考え方）

複数の出典に共通していた考え方。うちの既存曲の作り方とも相性がよいものを選んだ。

| 場面 | 狙い | 使える手 |
|---|---|---|
| 町・村 | 安心。ゆったり。土地の味 | 民謡風の素朴な音階（ペンタトニックなど）、明るい跳ね方、テンポは中庸〜遅め。フォーク風の伴奏（低音が休符を挟んで歯切れよく打つ、など） |
| フィールド・冒険 | 「先へ行きたくなる」広がり | 旋律の音域を広く取る、跳躍を使う、低音を規則正しく歩かせる |
| ダンジョン・洞窟 | 緊張、閉塞、反響 | 遅い低い持続音（ドローン）、まばらな高音（しずく）、不協和な音（半音・トライトーン）を静かに重ねる。音数を減らす |
| 通常戦闘 | 短い時間で「やる気」を出す | 速いテンポ、短調、8分と16分の刻み、口ずさめる短いフレーズ。音数は少なくてよい |
| ボス戦 | 通常戦闘より重く、前のめり | 通常戦闘より低い調、ストレートな低音の刻み、フレーズを1つに絞って繰り返す |
| 悲しい・切ない場面 | 痛み | 長い音、間、ゆっくりした半音の動き。不協和音を強めに（`tracks.md` の方針） |

- **音数は少ないほどよいことが多い。** 「少ないトラックで最大の表現」が、出典が口をそろえて言う要点。プレイヤーは長時間聞くので、詰め込むより、間を残して疲れさせないほうがよい
- **プレイの邪魔をしない。** 町の会話中に高音が耳に刺さる曲、何十回も聞く通常戦闘のフレーズが長すぎる曲は避ける

## 4. 戦闘曲・ボス曲を「かっこよく」する技法

（人間の好み: 戦闘曲は疾走感を強めに、`tracks.md`）

- **テンポ:** ターン制RPGの戦闘曲は、BPM 160台前後を目安にする解説があった。うちの通常戦闘はすでに速めなので、ボス戦は「速さ」より「重さ」で差をつける手もある
- **調:** 短調（自然短音階）を基本にすると、暗さと緊張感が出る。旋律はまず自然短音階だけで組み、変化がほしい所にだけ臨時記号（半音）を入れる
- **リズムの層:** 8分音符の刻みを土台に、低音だけ16分にして「走り」を出す。逆に低音を8分でどっしり刻み、旋律を16分にする手もある
- **低音のパターン:** 1度と5度だけ（パワーコード風）にすると、明るい・暗いが決まらず力強くなる。同じ音をオクターブで跳ねさせると、ロックのような推進力が出る
- **緊張を上げる定番の動き:** 同じ音（たとえば軸になる1音）を保ったまま、上に乗る音だけを上げていく。フレーズ4つごとに低音の根音を半音上げる（うちの第5章ボスがこれに近い）
- **低音を「一瞬抜く」:** ずっと鳴っていた低音を1〜2拍だけ止めると、戻った瞬間が強く聞こえる
- **メリハリ:** メロディが前に出る場所（Aとサビ）と、抑える場所（B、間奏）を交互に置く。全部を盛り上げると、どこも盛り上がらない
- **サビは新しい旋律を作るより、Aの旋律を広げる。** 音域を上げる、オクターブで重ねる、同じ形を別の調で言う、で「発展した」感じが出る
- **人間らしさ（うちではリズムの置き方で表す）:** 全部の音を拍にぴったり置かず、強い拍の頭だけ少し早く／遅くする、という「ヒューマナイズ」の考え方がある。うちの音源には音の開始を微調整する仕組みがないので、当面は「休符の入れ方」「音符の長さの差」でノリを変える

## 5. モチーフ（ライトモチーフ）の使い回し

`roles.md` 3-7 の「灯りのテーマを変奏して使う」方針の、具体的な手の一覧。

- **調を変える:** 通常の場面の調と違う調でボス戦に出す。下げると重く、上げると切迫する
- **一部だけ引用する:** 旋律の全体ではなく、最初の1フレーズだけを一瞬入れる（「あ、あの曲だ」と無意識に気づく程度が理想と、複数の解説が述べていた）
- **和音（低音）を替える:** 同じ旋律を、明るい響きの上で言うか、暗い響きの上で言うかで、印象が反転する
- **リズムを替える:** 町では休符で軽く、ボスでは同じ音高の並びをまっすぐ刻む
- **音色を替える:** 同じ旋律を、サイン波（やわらかい）から、ノコギリ波（鋭い）に持ち替える
- **章ごとに軸をずらす:** すでに実践している手（章ごとにトライトーンの軸を半音ずらす）。これが「章をまたぐ統一感」と「章ごとの差」の両方を出している。続けてよい
- **伏線と結びつける:** 謎の真相に関わる場面では、同じモチーフの「欠けた形」や「ずれた形」を使うと、プレイヤーが気づいたときの手応えになる（伏線台帳の項目と対応させて `tracks.md` に書く）

## 6. ループの作り方

- うちの決まり: 全パートの合計拍数をそろえる（`chapter*-tracks.test.ts` で確認済み）
- **つなぎ目:** 曲の終わりの余韻が、頭に戻る瞬間に切れて不自然になることがある。対策の基本は、終わりの小節を「頭へつながる和音・音」で終える（終止させず、頭の音へ自然に進む形にする）
- **構成の目安:** 4小節を1つのかたまりとして、4つ（合計16小節）で1周にする作り方が解説にあった。4小節ごとに、リズムや音の並びを少し変えて単調さを避ける
- **間を残す:** 何十時間も聞くので、休みの小節や、音数を減らす区間を混ぜると疲れない

### 音源を広げる提案（`docs/ideas.md` に書き足す候補。まだ実装しない）

| 提案 | 効果 | 大きさ |
|---|---|---|
| ノイズパート（`waveform: "noise"`。ホワイトノイズを短く鳴らす。音の長さと高さ（フィルター）で、ハイハット・スネア・キックを分ける） | 戦闘曲・ボス曲にドラムが入り、疾走感が大きく上がる | 中（`score.ts`・`audio-engine.ts`・テスト） |
| 矩形波のデューティ比の指定（`duty: 0.125 \| 0.25 \| 0.5`） | 音色のバリエーション。旋律とアルペジオを聞き分けやすくする | 中 |
| 音符ごとの音量の指定（`volume?`）とビブラート | 強弱、しずくの余韻、泣きの旋律 | 小〜中 |
| イントロ＋ループ分割（`introBeats`） | 最初の1回だけ導入を鳴らして、その後は本編だけループする | 小 |
| 曲の途中のテンポ変更 | 既存の課題（`tracks.md` のメモ）。当面は音符の細かさで代用 | 大 |

## 7. 曲を作るときのチェックリスト

曲を1つ作るたびに、上から確認する。

1. 場面（第3節）と、使うモチーフ（第5節）を1行で決めたか
2. 既存のゲーム音楽の旋律・コード進行になっていないか（口ずさんで、他の曲が浮かんだら作り直す）
3. パートの数は、今の音源で必要な分だけか（多すぎないか）。低音・旋律・アルペジオ・「空気」の4役のうち、要る役だけにしたか
4. 全パートの合計拍数がそろっているか（`npm test`）
5. 頭と終わりがつながるか（第6節）。実際にループさせて耳で確認したか
6. `docs/sound/tracks.md` に、方針をどう反映したかの一言メモを書いたか
7. 音源の限界にぶつかったら、`docs/ideas.md` に提案を書いたか

# ギターソロの勉強（2026-10-11）

人間（旭さん）の依頼: 「高音域の速弾きギターソロをロック風に」「単調じゃなくて、ギターの見せ場の速弾きのソロを聞きたい。速度も早めに」「ギターソロも勉強してきて」。
最初に私が作った2本（16分音符を並べただけ／起伏が弱い）は、どちらも「ソロになっていない」と言われた。その原因を、調べて直すための文書。

記号: **（出）**＝取得した出典で確認した内容。**（補）**＝私の整理・一般的な目安で、今回は出典を取得して確かめていない。**（実）**＝うちの書き出しで確かめたこと。
曲の丸写しはしない（CLAUDE.md 1-1）。型と数字だけを書く。耳での確認はまだ。

## 0. 要点

1. **ソロは「物語」**: 始まり → 盛り上がり → 頂点 → 終わり。16分音符を最初から最後まで並べると「練習フレーズ」になる。**最初は控えめに、疎に始める**。「思っているより単純に始める」（出）[1][4]。
2. **勢いを少しずつ上げる**: 音の細かさ（8分 → 16分 → 32分／六連）と、音の高さ（ネックの上のほうへ）を、ゆっくり上げる（出）[1][4]。速弾きは**メロディの下地ができてから、頂点にとっておく**（出）[1]。
3. **速弾きは「バースト」**: 4・6・8音の短いパターンを速く弾き、**休む**。休みの小節（または拍）を挟む。次のパターンは弦や位置をずらして運ぶ（出）[3]。ずっと走り続けない。
4. **短いモチーフを繰り返し、少し変える**: 冒頭の短い旋律を、音の順番やリズムを変えて戻す（出）[1][4]。
5. **休符が前の音を引き立て、次への期待を作る**（出）[4]。
6. **同じ音でも、ベンド・スライド・ハンマリング・プリング・ビブラートで表情が変わる**（出）[4]。ただし全部を毎小節に載せない（うちの「表現の予算」、guitar-technique-deep-guide.md §2）。
7. **曲の形がソロの形を決める**: 和音が変わる曲では、その形に沿う。変わらないループなら構造を自分で作る（出）[4]。

## 2. 速さの目安

- **16分音符4つ/拍**を 140bpm 以上でぴったり弾くのが「速弾き」の入り口（出）[3]。
- **六連（1拍に6音）を 100bpm** で「速弾きの領域」（出）[3]。
- 1秒あたりの音数（補）: 16分×BPM÷15。160bpm で約10.7音/秒、32分は2倍の約21音/秒。
- うちの書き方で確かめたこと（実）: 0.125拍（32分）より短い音はベンド曲線が付かず、ビブラートは0.4拍未満で付かない（deep-guide §1.1）。**速いバーストには付けず、バーストの最後の長い音に付ける**。
- `leadGuitar` の音域は E2〜E6（instrument-range.ts）。それより上の音は鳴らない（警告が出る）。頂点は E6 で、ベンドで一段上げる。

## 3. 速弾きの音の素材

- **スケール**: A マイナー・ペンタトニック（A C D E G）が土台。そこに 2度（B）と 6度（F）を足した A エオリアン（ナチュラルマイナー）、E7 の上では和声的短音階の導音（G#）を使う（出）[2][3]。
- **パターン**: 3音を1組にして、1音ずつ上げていく並び（A B C → B C D → C D E…）。**位置と弦をずらしながら運ぶ**（出）[3][5]。
- **アルペジオ**: 和音の構成音を上下に並べる（スウィープの素材）（出）[2]。
- 速い所の音は、**その瞬間の和音の構成音か、すぐ解決する経過音**に（補）。和音の変わり目の頭の音は構成音にする。

## 4. 「見せ場の速弾きソロ」の設計図（うちの曲に使う）

16小節・4拍子・テンポ 160 以上（補）。和音は 1小節1コード。

| 小節 | 役割 | 音の細かさ | 高さ | 表現 |
|---|---|---|---|---|
| 1〜4 | 控えめに歌う（問いかけ） | 4分〜8分、休符を多めに | 中音域（E5〜D6） | 長い音にビブラート、ベンド1回 |
| 5〜8 | バースト（速いパターン→休み） | 16分の8音パターン＋8分の休み | 中〜高（G5〜E6） | 速い所は記号なし、終わりの音だけ表現 |
| 9〜12 | 走り続ける（位置を運ぶ） | 16分の連続（3音1組の上昇・アルペジオ） | 高音域 | 小節の頭だけ強く（`!`） |
| 13〜16 | 頂点 | 32分のバースト＋16分 | 最高（E6） | 頂点の長い音にベンド＋ビブラート、最後の音は伸ばして終わる |

- 冒頭のモチーフ（小節1〜2）を、後半で形を変えて戻す（出）[1][4]。
- 和音が E（属和音）のところで、G#（導音）を使うと、ソロが A に「帰る」感じが出る（補）。
- **ソロを前に出す**: ギターの音量を伴奏より上げる。音量バランスの最終調整はミックスする人の仕事（人間の指示）なので、うちは「聞こえる」ところまで。

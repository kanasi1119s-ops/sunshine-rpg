# メロコアパンクの学習ノート（2026-10-12、人間の指示「展開と音作りをひたすら勉強して」）

調べた結果と、作曲ソフトの機能を照らし合わせたもの。【出典】はページで確認できたこと、【定石】は複数の解説からの目安（数値は未確認）。歌詞・旋律の引用はしない。

## 曲の展開
- 基本形: Aメロ→サビ→Aメロ→サビ→ブリッジ→サビ【出典】。曲間はドラムのフィル・ギターのリード・一瞬の無音でつなぐ【出典】。
- 3分半以上にする型【定石】: ブリッジを2部（静→ビルド）にする／サビを倍長にして落ちサビを入れる／間奏にソロやツインリード 8〜16小節／ハーフタイムのブレイク 8小節／アウトロを新しいリフにする。
- ラスサビの盛り上げ手段【出典】: 転調（半音／全音）・ハモリ追加・楽器追加・リフ追加・サビの倍長・伸ばし音。→ **転調は型を1つにしない**（半音・全音・短3度・4度・同主調・平行調・途中で上げたまま・下げてから上げる・2段上げ）。
- 起伏【出典】: 静（ブリッジ）→ビルド（スネアロール）→全員ストップ（1〜2拍）→ラスサビ頭で爆発。層を足していく。

## ドラム・ベース・コード
- テンポ: 速い8ビートは 180 前後、200超もある【出典 ragnet】。メロコアは 160〜200 中心、ミッドは 130〜150【定石】。
- ノリの型: 8ビート（キック1・3、スネア2・4）／スケートビート（キックとスネアが8分で交互）／Dビート／サビでハットをクラッシュ・ライドへ／ブレイクはハーフタイム（スネアが3拍目）。
- フィル: 終わりは次の小節の1拍目のクラッシュ（キックと同時）が定石【出典】。**4小節・8小節の切れ目だけ**に入れ、毎回同じにしない【定石】。フロアタムは単発より、フィルの終わりとブレイクダウンの4分・8分刻みに【定石】。
- ベース: ルートの8分が基本。ギターが休む所・小節末・ブリッジで動く【出典 TalkBass】。サビは安定、サビ前の1拍だけ駆け上がる【定石】。
- コード: I–V–vi–IV、I–IV–V が基本【出典】。短調→平行長調【出典】。ivの借用はサビ終わりやブリッジの切なさに【定石】。
- 旋律: 8小節を「問い4＋答え4」。ツインリードは3度ハモリで、歌のない小節に【定石】。

## 機械的に聞こえる原因【出典 producelikeapro ほか】
- 8小節を同じループのコピペ／全部同じ強さ／フィルが毎回同じ位置／ベースが全編ルート固定／ギターが常に同音量・同音色／ベロシティ全部同じ・人間に叩けない配置。
- 対策: 4小節ごとにキック位置・クラッシュ・フィルを変える。セクションごとに層を足す。ラスト1小節は全員ストップ→クラッシュ1発。

## ギターの音作り
- ギターは 80〜100Hz 以下をハイパス。ベースは 250〜350Hz を下げ、800Hz 付近を少し上げる。歪みの高域（4〜6kHz 以上）は落とす【出典】。
- リズムギターは**別テイク2本**を左右へ（同じデータのコピーを振るとモノラルになる）。音色・タイミング・強さを変える【出典】。
- クリーンの広がりは、コーラスでなく、左右で違う長さのディレイ（1/4と1/8）か、片側を数セント下げた遅延コピー【出典】。リバーブは 5〜10% wet から。
- 打ち込みの自然さ: ストラムは低音弦が先（弦ごと 3〜12ms、全体 10〜40ms は目安）／ダウンは強め・アップは弱め／ゴースト音／音の強弱は3段／同じ音の連打をしない【出典＋目安】。
- 物理モデル（弦）: ノイズ励起→ピック位置のコム→ループフィルタ（高音ほど速く減衰）→分散オールパス→ボディ共鳴。立ち上がりは音程がわずかに高く、減衰で下がる【出典 CCRMA】。

## 作曲ソフト側で分かったこと
- 主旋律のエコー（leadGuitar などで同じ音を 0.75・1.5拍後に小さく鳴らし直す）が、ギターの伸びを削っていた → パートの `noRestrike: true`（2026-10-12 追加）。
- 「きゅいんきゅいん」の正体は、autoScoop（音の頭のしゃくり）と音ごとの音程ずれ → 曲の `autoScoop: false`、パートの `humanPitch: 0`、`chorus: 0`（banned-sounds.md の 7）。
- 自然さに効く設定: `dynamics: "natural"`、`human` 0.3〜0.6 と `humanProfile: "role"`、`lockToKick: true`、旋律の `phrase`、ドラムの `pushMs`（スネア +5〜12ms、ハット −3〜0）。まだ試していない: `strum`（弦ごとの時間差）、`grooveFeel`、`swing16`、`hihatBySection`、`doubleDetune`、`echo` の左右違い。

- **NAM（学習式アンプ）は、これまで書き出しで一度も鳴っていなかった**（2026-10-12 発見・修正）。ワークレットの中に `URL` が無く、NAMの初期化が失敗 → 素通しになっていた。`src/audio/nam/nam-processor.ts` で `URL` の代わりを置き、WASMを同期で組み立てるようにして直した。AIソング形式では `amp: "namA" | "namB"` と `ampDrive`（入力の大きさ）・`ampTone`（高音dB）・`ampCab`（closed/open/dark/bright）で使う。
- NAMの音色（gretsch 録音ギターを通した測定。耳での確認は未）: namA は低域に偏り暗い／namB は広帯域で 1.6〜3.2kHz が山。`pluck-deepair` を通すと 2〜5kHz に偏って鼻にかかる → リズムは `--guitar gretsch` ＋ `namB`（`ampTone: -6`）を既定にした。**仮**。

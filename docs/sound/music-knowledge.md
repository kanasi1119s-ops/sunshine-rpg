# 音楽制作の一般知識メモ（2026-10-02 調査）

世間一般の作曲・編曲・ミックス・ラウドネスの知識を、Web検索で調べてまとめたもの。
**注意:** 本文を読めたページは少なく（多くのサイトがネットワーク制限で読めなかった）、数値は検索結果の要約に書かれていた「出発点の目安」。最後は耳で決める。出典のない推測は「（推測）」と書いた。既存曲のメロディ・コード列は使わない（CLAUDE.md 1-1）。理論の一般論だけを使う。

## 1. 作曲（メロディ・和音・構成）
- **動機は2小節**。反復→音高だけ変える→始まりや終わりを変える、で展開する。主な動きは順次進行、跳躍は強調したい所だけ（目安は順次7：跳躍3）。跳躍のあとは逆向きに順次で戻す。
- **サビ**は A・B より高い音域で、最高音は1フレーズに1回だけ。サビは最初の4小節に重点を置く。
- **フレーズは問いと答え**。前半は未解決の音で止め、後半で主音に着地。左右対称にして、末尾だけ変える。
- **和音の機能**: T（安定）→SD（展開）→D（緊張）→T（解決）。借用和音は同主調（マイナー）から借りる。bVI→bVII→I は V を使わずに高揚感が出る。セカンダリードミナントは進行に推進力を足す。ペダルポイント（ベース固定）はサビ前4〜8小節の溜めに使う。
- **シンコペーション**は先に表拍を確立してから崩す。崩し続けない。
- **骨組みの目安**: イントロ4小節、A 16小節、B 4〜8小節、サビ8〜16小節、間奏4〜8小節、Cメロ8小節、サビ8小節。Bは属音（D）に着地させるとサビが解決に聞こえる。
- **起伏**は、楽器数・音域・リズム密度・和音の変化速度のうち2つ以上を同時に上げる。終盤は半音上げ転調か同主調への転調で再び盛り上げる。
- **手順**: 役割・キー・テンポ → リズム型 → 2小節動機（2回目は音高だけ変える）→ 8小節 → 和音（T-SD-D-T＋借用か V/x を1か所）→ 音域とリズム密度を段階的に上げる → 終盤の転調 → 最高音の回数・同音連続を確認。

## 2. ダンス×ロックの編曲
- **ビート**: ロックはキック1・3、スネア2・4、ハイハット8分（90〜140BPM）。4つ打ちはキック全4拍（110〜140BPM）。融合は、Aメロはロック形、サビは4つ打ち／4つ打ちの上にスネア2・4／オフビートのハイハットを足す。疾走・ボス戦は140〜180BPM。
- **キックとベース**: キックは超低域20〜60Hz・胴80〜150Hz・アタック3〜5kHz。ベースは80〜250Hz、キックより9〜12dB下。サイドチェインは比4:1以上、アタック1〜10ms、リリース50〜150ms（テンポで変わる）。ダンス系のベースは裏拍の8分、ロック系は根音の8分連打＋オクターブ。
- **ギター**: ダブルトラックを左右100%。4本重ねるなら内側の1組を3〜6dB下げ、歪みは浅めにする。シンセは低域を切り、ギターと帯域がぶつかる1〜2kHzを狭く削る。ギターがリフの間、シンセはアルペジオか広いパッドにする。
- **シンセ**: リード・パッド・アルペジオに200〜300Hzのハイパス（24dB/oct）。スーパーソーはモノの本体＋左右に広げた層＋アタック層＋8kHz以上の空気の層。
- **ビルド・ブレイク・ドロップ**: 短い移行は4小節、ドロップ前は8〜16小節。ハイパスのスイープは100Hzから8〜16小節。スネアロールは4分→8分→16分→32分と密にする。**ドロップの直前に1拍だけ無音**を作ると衝撃が増す。
- **ボス戦**: 導入1〜2小節→長いループ→段階ごとの変化（楽器追加・転調・テンポ変更）。低・中・高の強度ループを切り替える方法もある。

## 3. ミックス（出発点の目安）
- **帯域**: 25〜45Hz以下はハイパス。60〜250Hzが土台（キック60〜100Hz、ベース80〜120Hzで分ける）。250〜500Hzは濁り（1〜3dBの小さなカットが効く）。2〜5kHzは前に出る帯域。まず足すより引く。
- **コンプ**: バスコンプは比1.5〜2:1、アタック10〜30ms、1〜3dB（これ以上でつぶれる）。ボーカル2〜3:1、ベース4:1以上、ギター3〜4:1。
- **サイドチェイン**: 比4〜6:1、アタック0〜5ms、リリース60〜200ms。整理が目的なら3〜6dB、EDMのポンピングなら10dB以上。
- **ステレオ幅**: 低域と主役は中央。ハース効果（5〜30ms遅らせて左右）、ダブリング、M/Sでサイドだけ高域を1〜2dB上げる。ハース効果はモノラルで薄くなりやすい。
- **リバーブ**: リターンは100%ウェット、センドで送る。プリディレイ10〜40ms。リターンのEQは、低域（200〜600Hz以下）と高域（8〜10kHz以上）を削る。ディレイはリバーブの前。
- **マスキング**: 重なる帯域の片方に1〜3dBのカット。強い被りはサイドチェイン。
- **ゲイン配分**: 各トラックは平均約-18dBFS、マスターに6dB以上の余白。

## 4. ラウドネス・マスタリング
- **指標**: LUFS（聴感の平均音量）、True Peak（サンプルの間のピークまで含む最大値）、クレスト（ピークと平均の差。圧縮が強いほど小さい）、DR、LRA（音量の振れ幅）。
- **目標**: 配信の再生基準は -14 LUFS（Apple Musicは-16）、True Peak -1dBTP。実際の市販曲は約-8.4 LUFS、現代の実用目標は-12〜-10 LUFS。クラブ・EDMは-6〜-8 LUFS。DRは、ポップ・ロックで8〜10dB、クラシック・ジャズで12〜15dB。
- **ゲーム**: Sonyの据え置き機は -23 LUFS（許容-25〜-20）、携帯機は -18 LUFS、True Peak -2dBTP。会話はBGM・SEより約4dB大きく、ピークは-3dB以下が目安。携帯・モバイルは屋外騒音のため大きめ（AESは携帯機で-16 LUFS以下）。BGMと会話は約-23 LUFS、効果音・環境音は-30 LUFS以下という別の資料もある。Webゲームの目標は、BGM単体で -16〜-18 LUFS、SEはBGMと同程度から+3dB（推測）。
- **つぶれの原因**: リミッターの下げすぎ（目安3〜6dB）、リミッター・クリッパー・サチュレーターの重ね、低域の密度（キックとベースがエネルギーを取り合う）、位相のずれ。
- **つぶれを減らす手順**: 各トラックを-18dBFSで作る → キックとベースの帯域を分けるかサイドチェインでベースを2〜4dBへこませる、100Hz以下はモノ → ダイナミクスはトラック・バス単位で先に整え、マスターのリミッターは最後の1〜3dB → 目標は-14 LUFS付近・DR 8〜10dB → True Peak -1dBTP以下、ループの継ぎ目、BGMとSEの差を聴いて確認。

## 5. ゲームBGMの作法
- **場面別の目安**: 町 80〜110BPM・長調・アコースティック系／ダンジョン 60〜100BPM・短調・音数少なめ・残響多め／戦闘 140〜170BPM・短調・ブラスとギター。フィールド・ボスは資料なし（推測: フィールドは町より少し速く、ボスは戦闘より厚く主題入り）。ループ前提で1〜2分（推測）。
- **ループ**: 「イントロ＋ループ本体」。残響の尾は、(1)終わりで消えるまで鳴らす（4小節以内）、(2)尾を録って曲頭に重ねる（テールラップ。リミッターの前で）、(3)尾がなければリバーブで作って(2)。切るのは小節の頭（ゼロクロス）。クロスフェードはリズム曲5〜15ms、パッド25〜50ms。
- **適応型音楽**: 縦割り（レイヤーを音量で足し引き）と横割り（断片を小節頭で切り替え）。ブラウザなら縦割りは全レイヤー同時再生＋GainNodeで作りやすい（推測）。
- **ライトモチーフ**: 人物・場所・考えに結びついた短い旋律。主題を4〜8小節で作り、場面ごとに調・テンポ・楽器・和声を変えて変奏する。伏線台帳に「どの主題がどの謎に結びつくか」も書く。
- **邪魔をしない**: 60Hz以下と16kHz以上をゆるく削る。BGMの1〜4kHzを2〜3dB下げて、会話・効果音の帯域を空ける。ダッキング（効果音の間だけBGMを下げる）。最後にゲーム内で聴いて確認。

# 第2弾（2026-10-02）: 実装・楽器・技法の深掘り
出典は検索要約が中心（本文を読めたページはほぼない）。「（一般）」は出典なしの一般知識。

## 7. ドラム・グルーブ・人間味
- **型**: ロック＝キック1・3／スネア2・4／ハット8分。ファンク＝キック1・2・8分裏＋ハットを少し遅らせて跳ねさせる。ヒップホップ＝重いキック＋裏拍のスネア、バックビート前にキック2発。ハウス＝四つ打ち＋スネア2・4＋16分ハット＋裏拍のオープンハット。ボサノバ＝8分基準、クラーベ2:3か3:2。
- **ベロシティ**: スネア通常90〜100、ゴースト30〜50（別資料40〜60）、アクセント100〜110。同種の音は±5〜10ずつ（±4%）ばらす。ハットは表拍を強く裏拍を弱く。ゴーストは「聞こえるか聞こえないか」。
- **スウィング（MPC式）**: 50%＝ストレート（トラップ・EDM）、54%＝現代ヒップホップ・R&B、58%＝定番ブーンバップ、62%＝ネオソウル・ジャズ寄り、66%＝完全3連（機械的になりやすい）。
- **ヒューマナイズ**: 全体で5〜20ms、50ms超は「意図したシンコペ」。出典Aはスネア5〜15ms早め・キック5〜20ms遅め・ハット2〜4ms前のめり、出典Bはハット固定・キック+10ms・スネア-8ms。**出典どうしが食い違う**（あと乗りの流儀もある）ので、耳で決める。
- **フィル**: 8〜16小節ごと、1小節が基本（1〜2拍の短いものも）。直後の1拍目にクラッシュ。
- **音作り**: キックは50〜80Hzがサブ、80〜200Hzが胴、2〜5kHzがクリック、200〜500Hzはこもるので削る。スネアは胴120〜250Hz、アタック900Hz、5kHzさわやか、10kHzぱりっ。レイヤーはサブ用を150Hzでローパス＋クリック用を150Hzでハイパス。
- **機械っぽさを消す順**: 型→ベロシティの強弱→ゴースト→スウィング54〜58%→5〜20msずらし→フィル＋クラッシュ→小節ごとに少し変える。

## 8. ベースライン・ギターリフ
- **ベース**: 骨格は根音・5度・オクターブ（R-5-8-5）。強拍に構成音、弱拍に経過音、小節末に次の根音へのアプローチノート（半音か全音）。ウォーキングは4分で、1拍=構成音／2拍=経過音／3拍=構成音／4拍=アプローチ。根音弾きが基本で、Aメロ・間奏・ギターが休む所でメロディックに動かす。**キックと音の頭をそろえ、短め（スタッカート）に**。ギターがベースのリフを1オクターブ上で重ねるとパンチが出る。
- **リフ**: パワーコード（根音+5度）で骨格→リズム型（8分一辺倒にせず、シンコペ・休符・3連を混ぜる）→パームミュートで溜めて開放で放つ→コードの間に単音フィル（コール&レスポンス）→ペンタトニック（Aマイナーペンタ=A C D E G）。Aエオリアン=暗く壮大、Aドリアン=少し明るく軽快。
- **ハモり**: メロディの3度上（か下）をキーの音だけで。例（Aマイナー）メロディ E-D-C-A → 3度上 G-F-E-C。2本のハモりは左右に分け、さらにダブルにする手もある。
- **カッティング**: 16分の連続ストロークで、鳴らす音とミュート（ゴースト）を混ぜ、裏拍にアクセント。
- **ソロ**: モチーフ（2〜4音）→展開（反行・断片化・延長、音域と音数を上げる）→最高音→着地（冒頭の形に戻すと物語が一周する）。
- **ジャンル**: RPG戦闘曲＝短調・速いテンポ・推進力のあるベース・パワーコード。ダンスロック＝4つ打ち＋8分根音ベース＋16分カッティング。

## 9. オーケストレーション
- **音域**: ヴァイオリンG3〜E7、ヴィオラC3〜A6、チェロC2〜A5、コントラバスE1〜G4（実用）、フルートC4〜C7、オーボエBb3〜A6、クラリネットD3〜Bb6、ファゴットBb1〜D5、トランペットの旋律はC3〜G4が安全。
- **弦のボイシング**: 低音はコントラバス＋チェロのオクターブ。先に旋律と低音を置き、内声（チェロ・ヴィオラ・第2ヴァイオリン）で3度・5度を割り振る。**低音域は開離配置、C3〜C4より上は密集配置**。旋律が高いときは旋律と低音の間に大きな空白を作らない。
- **刻み**: スピカートは推進力（オスティナートに効く）、ピチカートは軽さ、トレモロは低弦で不気味・高弦で緊張。
- **ブラス**: スタブ（短く強い）、ファンファーレは4度・5度・オクターブ、持続はホルン。強奏のバランスは トランペット1＝トロンボーン1＝ホルン2。
- **木管**: ユニゾンの相性は フルート＋オーボエ、フルート＋クラリネット、オーボエ＋クラリネット。フルート＋ファゴットは不可。
- **盛り上げ**: 弦→木管→金管→打楽器の順に足す。短いクレッシェンドは数拍〜1小節、長いものは数小節。8小節なら4小節かけて積み、最後の1〜2小節で頂点（一般）。
- **シンセと混ぜる**: 弦にシンセパッドを重ねる。ハイパス・ローパスで帯域を分ける。コントラバスは60Hz付近でハイパス。

## 10. シンセ音作り・サウンドデザイン（WebAudioで組む前提）
- **波形**: サイン＝サブ・やわらかい／のこぎり＝倍音豊富（リード・パッド・ブラス・ベースの主力）／矩形＝中空感・レトロ／三角＝まろやか。
- **ADSR（秒）**: リード攻め A0.001 D0.1〜0.15 S0.5〜0.7 R0.15〜0.25／パッド A0.5〜2 D0.3〜0.8 S0.6〜0.8 R1〜3／プラック A0 D0.2〜0.5 S0〜0.28 R0.09〜0.2／ベース A0.001〜0.01 D0.1〜0.2 S0.6〜0.8 R0.1〜0.3／ブラス（一般）A0.05〜0.12（フィルターも遅れて開く）。
- **フィルター（一般）**: ローパスはベース200〜800Hz、リード2〜6kHz、パッド800Hz〜3kHz。プラックは1.5〜4kHz→300Hzへ0.2秒で閉じる。ベースは30〜40Hz以下を切る。
- **スーパーソー**: のこぎり7〜16基を±10〜30cent（35cent超は音程が崩れる）、中央の細い「芯」の層を足す。WebAudio向けは、のこぎり3〜7本を detune ±7〜20cent にして StereoPanner で左右に振る。
- **LFO**: ビブラート4〜8Hz（心地よいのは4〜6Hz）・深さ10〜35cent。パッドのフィルターは0.1〜0.5Hz。ダンスのウォブルはBPM同期の1/8〜1/4。
- **アルペジエーター**: 定番はUp/Up-Down・1/16・2オクターブ。ゲート45〜60%でプラック、85%以上で流れる。
- **ライザー**: ノイズをハイパス150Hz→10kHzへ4〜8小節で開き、ゲインも上げる。のこぎりを1〜2オクターブ上げる層も重ねる。インパクト（一般）はサイン60→35Hzを0.5秒で下げ、直前に0.1〜0.3秒の無音。
- **効果音（一般）**: 斬撃＝バンドパスのノイズ（3kHz→1kHz、0.15秒）＋のこぎり急降下／魔法＝2本のこぎり（+7cent）の上昇スイープ0.4〜0.8秒＋高音アルペジオ／回復＝長三和音の上昇（約0.08秒間隔・4音）／決定音＝短い2音（E5→B5、各0.06秒）／キャンセル＝決定音を下降に／ダメージ＝ノイズ＋100Hz付近のサイン下降0.2秒。
- **WebAudio実装メモ**: **DynamicsCompressorNode はサイドチェイン非対応**。サイドチェインを作るなら、楽譜（キックの位置）が分かっているので、ベース用の GainNode に「キックの瞬間に下げて戻す」ゲインの予約を入れる方法が使える（推測＝要検証）。指数変化は0にできないので0.001を使う。エンベロープは setValueAtTime→linearRampToValueAtTime→setTargetAtTime。タイミングは「25msごとのタイマーで、100ms先までを AudioContext.currentTime に予約する」先読みスケジューラが定石。

## 11. 日本のRPG音楽の一般的な技法（特定曲は写さない）
- **旋法**: 明るい町は長調、幻想・謎はドリアン（長6度が特性音。主和音とIVを往復して色を固定）、悲しい場面は短調。
- **和音**: 同主短調から♭VI・♭VII・IVmを借りる。セカンダリードミナントで推進力。4度進行（ii-V-I）はサビ前や終止に。ペダルはボス戦・不穏な場面に（一般）。悲しい場面は根音が下降する進行や短調のクリシェ、ドミナントに♭9。
- **場面別**: 町・村 90〜130BPM、アコースティック中心・楽器は10種類以内・長調・ベースは根音と5度／戦闘 140〜180BPM（一般）・テンションコード／ボスは低音を厚く（一般）／悲しい場面 60〜80BPM（一般）・ピアノと弦。
- **音源の制約が生んだ手法**: 同時3音しか出ないので、分散和音を速く弾いて和音に聞かせる、根音と5度を残して3度を省く、ノイズでスネアを代用。
- **ループで飽きさせない**: 曲を長く、16〜32小節以上の構成（AABA・ABAC）、ループ点で主和音に戻りきらない、2周目に対旋律を足すかオクターブをずらす、町を出入りしても曲を最初に戻さない。
- **ライトモチーフ（作り方）**: 3〜5音の動機を作る→場面ごとにリズム・旋法・テンポだけ変えて同じ動機を使う→真相に近づくほど和音を変える（長調→短調、借用和音）。

## 12. 自作曲の評価
- **リファレンス比較**: 参考曲を2〜3曲（音の測定専用。曲の流用は禁止）。**先に音量をそろえる**（そろえないと大きい方が良く聞こえるだけ）。スペクトル・ステレオ幅・ダイナミクスを比べる。ステレオ幅は「120Hz以下はほぼモノ、中域から広げ、高域が最も広い」が目安。
- **メーター**: 位相相関は +1＝モノ、0＝無相関、-1＝逆相。マイナス側に居座るとモノ互換が悪い。
- **モノチェック**: 主旋律・ベース・キックが消えないか。
- **失敗の直し方**: 低域の濁り（200〜300Hz）は各パートの200〜400Hzを2〜4dB削り、キックとベースの役割を分ける。こもり（300〜500Hz）は小さな削りと音数の整理。暖かさ目的で低中域を持ち上げない。
- **歌がない曲のメロディ**: 主旋律の音域を伴奏と分ける、リズムを単純にして休符で息継ぎ、対旋律と音色で主役をはっきりさせる、同じ旋律を別の楽器で重ねる。
- **A/Bテスト**: 音量を±0.1dB以内にそろえ、ブラインド・順番ランダム。ABXは10回が標準。質問は具体的に。
- **耳を休ませる**: 45〜50分作業したら10〜15分休む。翌日にもう一度聞く。複数の環境（ヘッドホン・スピーカー・スマホ小音量）で確認。
- **数値の限界**: スペクトル重心やクレストは「参考曲との差」を示すだけで、メロディの魅力や感情は測れない。最後は耳とA/B。

## 13. 和音の響かせ方（ボイシング・転調）
- **ボイスリーディング**: 共通音は同じ声部に残し、残りは跳ばず最短で動かす。例（Cメジャー）C→F は、Cを保ち E→F、G→A で、Fは第2転回形（C-F-A）になる。例（Aマイナー）Am→F は A・C が共通で、E だけ F へ半音下。G→C は、Gの転回形（D-G-B）からCの転回形（E-G-C）へ進めば、Gが共通音。
- **テンション**: ドミナント7（G7）は9th（A）・13th（E）が自然、11th（C）は3度（B）とぶつかるので避ける（使うなら3度を抜いて sus4）。maj7 の11thは #11 にする。Am7 は9th（B）・11th（D）が使え、Am9 はやわらかい。**add9**（Cadd9 = C-E-G-D）はゲーム音楽の明るい場面に合う。sus2/sus4 は3度を抜いた浮遊感。
- **低域の3度を避ける**: 短3度の下限はおよそC3〜Eb3。それより低い所は単音・5度・オクターブにする。低域は開離配置（例: 左手 C2-G2、または根音+5度+10度）、高域は密集配置。ピアノ例（Am9）: 左手 A1-E2、右手 C3-G3-B3。
- **弦**: 上の2声の間に完全4度があると鋭いので、第2声を1オクターブ下げる。弦のCメジャー例は、チェロとバス＝C、ビオラ＝E、第2ヴァイオリン＝G、第1ヴァイオリン＝C5。
- **パッド**: 低い声部は動かさず、上の声部だけ最短で動かす。
- **分数コード**: 下降ベース C → C/B → Am → Am/G → F（ベースが C-B-A-G-F と順次進行）。ペダル C/G → F/G → G は緊張が高まる。転回形を使うとベースが跳ばない。
- **ドミナントの装飾**: Gsus4 → G7 → C（Cを長3度のBへ下げて解決）。V7alt（b9・#9・b5・#5）は緊張が強いので、穏やかな場面では手前に sus だけを置く。
- **モーダルインターチェンジ**: Cメジャー中の借用は Fm・Ab・Bb・Cm。Fm・Ab は切なさ、Bb は広がり。F → Fm → C は、Aが Ab に半音下がって明るさが急に曇る。Aマイナーの場合は同主調Aメジャーから借りる。
- **次の一手の選び方（整理）**: 今の機能を確認 → 候補3つ（安定・緊張・意外）→ ベースが順次進行になる転回形を優先 → 共通音が多い候補 → 場面が変わる所で借用和音か sus を1つだけ。
- **転調**: ピボット（両方の調に属する和音を橋にする。C→Gなら Em）、半音上げ（フレーズ区切りで突然上げる。終盤の盛り上げ）、同主調転調（C→Cm。同じドミナントGが橋）。

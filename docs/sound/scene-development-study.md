# 場面展開の学習（2026-11-23）

人間（旭さん）の指摘:「どの曲も始まりが同じすぎて、オリジナリティがまったくない」「場面展開も今までと全部同じ感じに聞こえる。場面展開を学習してくると良いかな」「メロディ全てよくある感じ」。

## 1. まず自分の曲を数えた（歌入り 109 曲の、いちばん新しい版の場面の並び）

| 調べたこと | 結果 |
|---|---|
| 「前奏」から始まる | 109 曲中 95 曲 |
| 「Aメロ → Bメロ → サビ」の並びがある | 86 曲 |
| サビがちょうど 3 回 | 77 曲 |
| 「おわり（後奏）」で終わる | 109 曲すべて |
| サビの次に来る場面 | 歌なしの場面（ドロップ・間奏・ソロ）か、おわり。Aメロに直接もどるのは 12 回、別のサビへ進むのは 17 回だけ |
| 最初のサビが来る位置 | 曲の長さの 26%（どの曲もほぼ同じ） |
| 途中でテンポが変わる曲 | ボカロの曲では 0 曲 |

つまり「前奏 → A → B → サビ → 歌なし → A → B → サビ → ソロか静かな場面 → 最後のサビ → おわり」という1つの型を、音色と歌詞だけ変えてくり返していた。指摘のとおり。

## 2. 調べて分かったこと（出どころつき）

### 2-1. アニメソングの転調（Music Theory Online 32.1「Modulation and Chromatic Mediants in Japanese Anime Songs」）
- テレビサイズ 100 曲のうち、転調が 1 回以上ある曲は 41%、2 回以上は 21%。
- 転調の半分以上（72 回中 38 回）は **短3度の上下**。半音・全音上げ（いわゆる最後に上げる形）は 19% だけ。
- 転調の場所は、Bメロ → サビが 46%、Aメロ → Bメロが 18%、前奏 → Aメロが 17%。
- Bメロは「次の調への橋」として書かれる（♭VI や ♭VII を、次の調の IV・V として使い、次の調の V で止める）。
- サビのあとの短い場面（ポストコーラス）は、もとの調へ戻す役。3つの型: サビの調のまま終わって急に戻る／サビの調で始まり、Aメロの調の V で終わる／いきなり Aメロの調で始まる（2つめの前奏の役）。
- 自分の曲: 転調は「最後のサビで半音上げ」ばかりだった。**場面ごとに調の色が変わる**形（A と サビで調がちがう）はほとんど使っていない。

### 2-2. 「転転結転」の構成（Real Sound 2014-11 のバンド曲の構成分析）
- サビのあと、サビの雰囲気を引きつがない。Aメロにも戻らない。2回め・3回めのサビのあとは、それまで出ていない新しい場面。
- 1つの場面は 2〜4 小節のくり返しでできていて、場面の中の動きは少ない。場面と場面の差が大きい。
- ばらばらにならない理由は、ベースとドラムのノリが一貫しているから。
- サビをくり返しすぎないので、覚えやすいサビでも古く聞こえない。

### 2-3. 電子音楽のエネルギーの設計（Beat Kitchen「Arrangement and Energy Management」ほか）
- 並べるのは「Aメロ・サビ」ではなく、**エネルギーの曲線**。作る前に紙に曲線を書く。
- ビルド（立ち上げ）の長さを毎回変える（4小節・8小節・16小節）。
- **にせのビルド**: 盛り上げておいて、ドロップではなく静かな場面に落とす。
- 2回めのドロップは 1回めと変える（ベースの音・旋律・リズムのどれか）。同じだと「くり返し」に聞こえ、「たどり着いた」感じがしない。
- 静かな場面は「半分の速さ」に感じさせる方法もある（テンポは同じ）。
- 場面の変わり目: 最後の小節で 1つ楽器を抜く／フィル／逆回しのシンバル／上がる音・下がる音。

### 2-4. そのほか（展開の実例集のメモ）
- サビで速さが半分に感じる曲、最後のサビだけテンポが上がる曲、2番から同じ旋律のままテンポが上がる曲、Bメロの途中でテンポが変わる曲がある。
- J-POP でよくある並びは「サビ → A → B → サビ → A → B → C → サビ → 大サビ」。これは自分の型とほぼ同じ＝「よくある感じ」の元。

### 2-5. 旋律が「よくある感じ」になる理由（Native Instruments・Ableton「Making Music」ほか）
- よい旋律は「予想どおり」が多く、ときどき「予想外」が来る。全部が予想どおりだと陳腐に聞こえる。
- 対比を使う: 音の高さ（跳ぶ・となりへ進む）、リズム（細かい・のばす）、くり返しと変化。
- 跳んだら、反対向きにとなりの音へ戻るのが基本。ここをわざと破る所を 1 句に 1 か所作ると、耳に引っかかる。
- 高さより**リズムで覚えさせる旋律**もある（音の高さは少なく、リズムの形が主役）。
- 自分の旋律: 1・2・3・5・6 の音を、となりへ順に進むだけ。句の長さが全部 2 小節。始まる位置が全部「小節の頭」か「1拍休んでから」。＝ 予想外が 1 つもない。

## 3. これから使う「場面展開の道具」（1曲に 2〜3 個えらぶ。毎回同じ組み合わせにしない）

| 番号 | 道具 | 内容 |
|---|---|---|
| 1 | 調の色を場面で変える | A と サビで調を変える（短3度上・下）。B を橋にする。サビのあと、戻し方を 3 型から選ぶ |
| 2 | サビのあとに新しい場面 | ドロップや間奏ではなく、それまで出ていない歌の場面へ進む |
| 3 | にせのビルド | 盛り上げて、静かな場面に落とす。本当のサビ・ドロップは後ろへ |
| 4 | 2回めを変える | 2回めのサビ・ドロップは、和音・リズム・ベースのどれかを変える（同じ旋律に別の和音をつける など） |
| 5 | 速さの感じを変える | 半分の速さのサビ／倍の速さの A／最後だけテンポを上げる（作曲ソフトは `tempo: [{bar, bpm, ramp}]` が使える） |
| 6 | 句の長さを変える | 2小節の句ばかりにしない。3小節・5小節・6小節の句、1小節早く入る句 |
| 7 | B を無くす・A を無くす | A → サビ、サビ → 別のサビ、A が 1 回だけ、など |
| 8 | 終わり方 | 後奏なしで歌の最後の音で終わる／始まりの音にもどる／途中で切る |
| 9 | 始まり方 | 過去の曲の出だしを並べて、使っていないものを選ぶ（静かに始まって増える形は使いすぎ） |
| 10 | 場面の長さ | 8・16 小節だけにしない（6・10・12 小節、ビルドは 2〜4 小節も） |

## 4. 作る前の確かめ（新しい決まり）

1. 場面の並びを書いたら、上の表 1 の数字と見くらべる。「前奏 → A → B → サビ」「サビ 3 回」「後奏で終わる」の 3 つが全部そろっていたら、作り直す。
2. エネルギーの曲線を先に書く（場面ごとの大きさを数字で）。となり合う場面の差を決めてから音を入れる。
3. 旋律は、句ごとに「予想外」を 1 か所（跳ぶ・入る位置・のばす長さ・句の長さ）入れたかを確かめる。

## 5. 正直なところ

- 上の内容は、文章の資料と自分の曲の集計から学んだもの。お手本の曲を耳で聞いて確かめたわけではない（音は聞けない）。
- 人間から渡された Kawaii future bass の動画 3 本の形（`kfb-study-user-refs.md` の 1〜2 章）は、どれも「前奏（和音だけ）→ 歌 → 歌のサビ → 歌なしのドロップ」で、ここに書いた道具の多くは入っていない。場面展開のお手本としては、別の曲のデータ（使ってよい曲）があると、もっと確かに学べる。

## 形のくじの直し（2026-11-25）: 合わない所だけ引き直す／リズムの取り方も引く

人間「ランダムだけど合わない部分は合うように引き直すようにしようか。あとリズムの取り方も変えれるようにしよう。なんか、グルーブがのっぺりしていて感じられないんだよね」

### 1. 合わない所だけ引き直す（`tools/vt3/form_dice.py`）
- くじを引いたあと、場面を1つずつ調べ、**合わない所だけ**を別のさいころで引き直す（全体は引き直さない）。何を・なぜ引き直したかを、最後に「■ 合わないので引き直した所」として書く。
- 前と同じ結果がほしい時は `--no-fit`。
- 合わないと見なすもの:
  - 場面: 「止まる」が最初か最後／「止まる」が続く・3回め／「立ち上げ」の次が静かな場面や A・B（上げたのに山へ行かない）／「にせの立ち上げ」の次がサビ・ドロップ・フック（落とす先がない）／テンポ150以上の「A（倍の速さ）」・110以下の「サビ（半分の速さ）」／歌のない場面が3つ続く／同じ場面が2回続く／サビが3つ続く・6回め
  - 長さ: 立ち上げが8小節より長い／歌の場面が4小節より短い／歌のないソロ・ドロップ・フックが12小節より長い
  - 旋律の句: 場面の長さに入らない句（5小節の句・3小節の句・4小節のばす句）／12小節以上ずっと1小節の短い句／前の歌の場面と同じ句の形
  - 始まり方・終わり方: 最初（最後）の場面と合わないもの（歌のない場面なのに歌で始まる・終わる、など）
- 引き直しでサビを増やしすぎない（サビがもう4回あれば、引き直しではサビを引かない）。引き直しが次の引き直しを呼ぶのをふせぐため。
- 決まりを増やしすぎると、また同じ形になる。ここに入れるのは「音楽として成り立たない組み合わせ」だけ。好みの問題は入れない。

### 2. リズムの取り方（グルーブ）もくじで引く
- 型は `tools/vt3/grooves.json`（8種: まっすぐ4つ打ち・はねる16分・3・3・2・あと乗りのハーフ・前のめりの8ビート・2ステップ・ファンクの16分・ブレイクビート）。型ごとに、キック・スネア・ハイハット・ベース・和音の打ち方（4小節で1まわり）、はねの量、ノリ（ぴったり／あと乗り／前のめり）、合うテンポの幅を持つ。
- くじは、テンポに合う型の中から「主」と「静かな場面用」を1つずつ引く（1曲の中で、はねる型とはねない型は混ぜない）。`--not-groove 型の名前` で、前の曲と同じ型をさける。
- 曲では `assets-src/ai-songs/_gen/groove_lib.py` を使う: `G = Groove("bounce")` → `G.drums(D, b, i)`・`G.B[i % 4]`（ベース）・`G.C[i % 4]`（和音）・書き出しの前に `G.apply(js)`。
- 型を足す時: 16分のマス×4小節。**ベースは、キックを打つ所では必ず音を出す**（そろえる）。ハイハットは強さを3段（X・x・o）＋開く音（O）で書き、4小節めは少し変える。

### 3. v1 がのっぺりだった元（HUM01 で確かめたこと。耳では未確認）
- サビ・フックがずっと「4つ打ち＋2・4拍のスネア＋強さ2段のハイハット」で、キック・ベース・和音の打つ所が毎小節同じだった。
- ずれ（はね・あと乗り・前のめり）を、曲に1つも書いていなかった（エンジンには `swing16`・`grooveFeel`・`lockToKick` があるのに使っていなかった）。
- 手引き（`rhythm-groove-guide.md` §3.0）の順番どおり、**打つ所と強さの山を先に、ずれは最後に**直す。

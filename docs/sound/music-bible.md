# 音楽バイブル（案・人間の確認待ち）

**状態: 案です（2026-10-02）。** 旭さんの確認が済むまで、曲づくりの正式な基準にはしません。プロデューサー役が曲の企画書を書くときの土台になる文書です（学習メモ: `docs/sound/roles/producer.md`）。既存作品の曲名・旋律は書きません。性質だけを言葉で書きます。

## 柱（感情で書く。3〜5個）
1. **あたたかい灯り** — どの場面にも、人のぬくもりがある。町は穏やかで、戦闘や不穏な場面でも、帰る場所の気配を失わない。
2. **少しずつ近づく謎** — 音が、謎の手がかりを小さく先に出す。真相に近づくほど、同じ旋律が少しずつ形を変える。
3. **旅の広がり** — 章が進むほど、土地の色（楽器・音階・リズム）が変わり、世界が広がる実感がある。
4. **静かな不穏** — 「歪み」の気配は、大きな音でなく、静けさ・不協和・間（ま）で出す。
5. **まっすぐな勇気** — 主人公たちの決意は、飾らず、素直な旋律で出す（物語の「分かり合えなくても手を取れる」に合わせる）。

## スタイルガイド（出発点。聴いて変えてよい）
- **ジャンルは場面から選ぶ**（レトロ風にこだわらない。`CLAUDE.md` の音の方針）。町＝フォーク・ジャズ・クラシックなどの生楽器寄り／フィールド＝ロック調やオーケストラ風で開放感／ダンジョン・謎＝空間系・不思議・ミステリー／戦闘＝ロック・メタル・ダンス／ボス＝多段構成／悲しい場面・終盤＝弦とピアノ／電子音楽（ダンス・エレクトロ）は「歪み」の人工的な気配（第6章の発生装置の施設、灯芯都の裏通りなど）に。
- **テンポ・調・編成の傾向**（`music-knowledge.md` の 14・15・27 参照）: 町 80〜110BPM・長調かドリア・楽器は10種類以内／戦闘 140〜170BPM・短調／悲しい場面 60〜80BPM・短調／ミステリー 遅いか拍なし・半音やクラスター。
- **音量の方針**: ゲーム内で曲どうしの音量差を縮める（`src/audio/bgm-trim.ts`、目標 約 -15 LUFS）。BGMは効果音・会話の下に入る前提で、リードの帯域（1〜4kHz）を効果音と争わせない。PLR 9以上を目安に、つぶさない。
- **耳に痛い・疲れる音を避ける**: 歪みギターは小さめ、高域の持ち上げすぎをしない。同じ曲が何度回っても疲れないよう、2周目に変化を足す。
- **避けたいこと**: 能天気に明るすぎる（序盤の不穏の伏線を消さない）／ホラーに寄せすぎる／戦闘曲が毎回同じ型／効果音を覆う大音量／既存作品を思わせる旋律・進行。

## 主題の方針（`docs/sound/motif-ledger.md` に台帳）
主題は**3系統**に絞る: ①**灯りの主題**（ユーリと仲間・灯りの相談所）／②**土地の主題**（各地方。共通の骨格に、土地ごとの色を付ける）／③**歪みの主題**（「歪み」・静まりの年・黒幕の気配。早い章では断片だけ）。変奏は物語の意味と対応させる（短調化＝悲劇、断片化＝記憶の欠落、反行＝裏の顔、拡大＝決意など。`docs/sound/roles/composition-writer.md`）。

## 音量・仕上げの基準（ミキサー役・聴取係役の基準）
- 数値の合格目安: True Peak -1dBTP以下／PLR 9以上／左右の相関 0.4〜0.88／LRA 2.3〜9／曲の頭は最大より小さい。ラウド系は理由を書いて例外にしてよい。
- ゲーム内の音量差は、`render-catalog.mjs --raw` と `make-bgm-trim.py` で補正表を更新。
- 最後は人間の耳。確認が済むまで「仮」。

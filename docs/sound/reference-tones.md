## 気をつけること

- EQ は「聞き比べ G の音」との差。ドラム音源（naked）・ベース音源（bnb-loud）・ギターのアンプ（ラウド25曲の作り）が違う曲では、同じ音にならない。その場合は、その曲を測り直して計算する。
- 参考のベースは、歪んだ上の帯域がギター側に入りやすく小さく測られる。ベースを下げる量（−14〜−18dB）が大きいので、細く聞こえたら戻す。
- 歌の代わりのリードは、参考の歌の帯域と大きさに合わせた（今の曲には歌が無いため）。歌を入れたら、歌のほうに当てる。

## リードギター（6つ共通。2026-10-23）
人間が聞き比べで選んだ③: リードギター（歌の代わり）には、歌の EQ ではなく `LEAD_GUITAR`（`src/audio/ref-tones.ts`）を当てる。PRS Archon リード1（TONE3000、T3K 規約のため手元だけ。無い環境ではマーシャル系）を浅い歪み 0.45・ゲート 3 で。濁り 350Hz −2.5dB／歌う帯域 1.6kHz +2dB／刺さる 4.2kHz −2dB／ローパス 11.5kHz／付点8分のやまびこ 0.16＋残響の送り 0.25。大きさは参考の音で測った比（vocal）のまま。人間「これで音源6個を合わせて」。

# 使わない音（人間が「ダメ」と決めた音）

新しい曲を作るときは、ここに書いた音の作り方を**使わない**。理由は「聴いて気持ちよくなかった」（人間の判断）。決めた日付と、何がダメだったかを残す。

## ギター
### 2026-10-11 決定
1. **「スラップの曲」（intro-bass-first）のバックのギター**
   - 作り方: `guitar`（GM27 クリーン）＋ 生ギター音源 `--guitar gretsch` ＋ amp `funk`/`clean`、音域 D3〜A4 の単音・2音の刻み／短い伸び（0.25〜1.5拍）。
   - ダメだった所: 短い単音のくり返しが「ピ、ピ」と切れる。音が伸びない。高い。
   - 代わりに: ナイロン弦（`patch: nylonGuitar`、amp auto）でアルペジオ。短い単音の刻みはやめる。
2. **「いきなり全員の曲」（intro-cold-strike）の歪みギター（旧アンプ設定）**
   - 作り方: `distGuitar` ＋ amp `hardrock`／旧 `punk`（5kHz以上が+15〜+30dB多く、ピーという高域が出た）／`crunch` 同音連打。
   - ダメだった所: 歪みすぎて割れて聞こえる。
   - 代わりに: 現在の `punk`（参考録音5曲のギターの形に合わせた。`docs/sound/data/guitar-curve-5tracks.json`、5kHzから急に落とす）。音量は 0.2 以下、キック・ベースを小さく。
   - 追記（同日・4件目）: `punk` も、メロコアの曲では高域の割れとつぶれ（PLR 2.7〜3.5）が出た。この「代わりに」は絶対ではない。まず `loudrock`／`crunch` を試し、書き出しの合否表の PLR が 6 未満なら、アンプを疑う。

### 2026-10-11 決定（2件目）
3. **「いきなりフックの曲」（intro-hook-first）のギター**
   - 作り方: `guitar` に `patch: nylonGuitar`（ナイロン弦）＋ amp `auto`（フィルターを通さない生の音）。
   - ダメだった所: 6〜10kHz が目標より +8〜+15dB 多く、耳に少し強い。透き通っていない。
   - 代わりに: `guitar`（GM27）＋ `--guitar gretsch` ＋ amp `crystal`（透明。2〜4kHz の刺さりと低中域のこもりを抑え、上にほんのり空気感を残す）。
   - ナイロン弦を使うときは、必ず amp に `crystal` か `delicate` を付けて高域を丸める（amp auto の生の音で使わない）。

### 2026-10-11 決定（4件目）
4. **「メロコアの曲」（疾走のその先 v1）の歪みギター**: `distGuitar` ＋ amp `punk`
   - ダメだった所: 音割れ。測ると、100Hz〜1.3kHz が目標より 20〜40dB 足りず、2.5〜3.2kHz に偏り、8kHz 以上が +28dB の「ピー」。山と平均の差（PLR）が 2.7〜3.5 とつぶれる。`punk` は画面収録の録音に形を合わせたため、実物のギターには薄すぎる。
   - 代わりに: amp `loudrock`（PLR 8.4、8kHz 以上が −39dB）か `crunch`。仕上げは `--master-preset rock-clean`（`punk` プリセットはクリップ付きでさらにつぶれやすい）。volume は 0.07 前後。
   - 見分け方: 書き出しの合否表で PLR が 6 未満なら、アンプを疑う。

### 2026-10-11 決定（5件目）
5. **J-POPのアルペジオ**（jpop-clean-test）: `guitar` ＋ amp `jpopClean`（レシピ `jpop-arpeggio`）
   - ダメだった所: 人間が聴いて「この音は嫌い」（理由の言葉はまだ聞けていない）。聴いて確かめずに作った初期値のまま。
   - 代わりに: 前に気に入ってもらった `sparkleClean`／`crystal` 系のクリーン（`sparkle-delay`、`crystal-wide`）。`jpopClean` は人間が聴いて良いと言うまで、曲では使わない。

### 2026-10-11 決定（6件目）
6. **クリーンギターへの chorus（コーラス）**（J-POP見本曲「ひかりの手前」の分散和音。chorus 0.3）
   - ダメだった所: 人間が聴いて「きゅいんきゅいんする音」が嫌い。コーラスの音程のゆらぎがギターでは耳につく。
   - 代わりに: ギターに chorus は掛けない（0）。広がりは pan の左右振り分けと reverb、`doubleDetune` の控えめな値で出す。鍵盤・弦・パッドの chorus は別（今回の指摘はギターだけ）。
   - レシピ `jpop-*` と `widen:"dimension"` の chorus も 0 にした。

7. **ギターの「しゃくり」と、音ごとの音程ずれ**（メロコア曲 butterfly-2〜4、2026-10-12）
   - ダメだった所: 人間が聴いて「きゅいんきゅいんするギターの音が気に食わない。曲に入れるな」。調べると、リード・リフのギターに (a) 1拍以上の音の頭に自動で付く「半音下からのしゃくり」（autoScoop）と、(b) human を上げたとき音ごとに±8セントずれる音程のゆらぎが、勝手に乗っていた（リフのトラックにピッチベンドが約1100個）。
   - 代わりに: 曲に `"autoScoop": false`、ギターのパートに `"humanPitch": 0`（音程のずれだけ止める。タイミングと強さのゆらぎは残る）と `"chorus": 0`。しゃくり記号 `/` は手で書いた所だけ。
   - 確認: 書き出した MIDI のピッチベンドが 0 になっているか（リフ）／ベンド記号を書いた所だけか（リード）。

## 共通の注意
- 短い音（スタッカート `'`、0.25拍以下）を同じ高さで連打しない。
- 高域（6kHz以上）をギターで出さない。
- 迷ったら `tools/audio-check/third-octave.py` で、ギターだけを書き出して目標の形との差を測る（100Hz〜5kHzは±3dB以内）。

## 再調整のルーティン（2026-10-11、人間の指示）
書き出しの合否表に「つぶれ気味」（PLR・PSR が小さい）が出たら、`build --wav --master-preset ...` が自動で仕上げをやさしくして最大2回やり直す（1回目: クリップ 0・圧縮を一段やさしく・目標を 1.5LU 下げる／2回目: さらに 3LU 下げる）。やり直しは警告欄に「再調整しました」と出る。止めるときは `--no-retune`。それでも残るときは元の音がつぶれているので、歪みギターのアンプ・パートの音量の合計（0.7 前後）・同じ音の重ねすぎを見直す。

### 2026-10-13 決定（7件目）
7. **普通に弾いている途中で、すぐにミュートへ切りかえる奏法**（ギターの刻み）
   - ダメだった所: 人間が聴いて「ギターを普通に弾いてすぐにミュートを入れると違和感がある」。ミュートの刻み自体は使ってよい。
   - 代わりに: ミュート（`'`・パームミュート）は、Aメロなどのブロックの頭から終わりまで通して使う。直前がギターなし（休み）やクリーンの伴奏のところから入る。ミュートから開放へ（Aメロ→サビ）の変化はよい。開放で弾いた直後の1〜2小節で急にミュートへ変えない。
   - 見本: `assets-src/ai-songs/summer-rock.json`（Aメロ8小節を通してミュート、その前の間奏はリズムギターを休む）。

### 2026-10-14 決定（8件目）
8. **リードギターの `crunch` アンプ**（標準のギター音源、夏のロックのリードの音色違い c）
   - ダメだった所: 人間が聴いて「ピロピロ鳴るギターの音色が嫌い」。
   - 代わりに: 他の候補（a=crystal クリーン、b=loudrock、d=gretsch録音のジャズ+sparkleClean、e=gretsch録音+lead、f=hofner録音+crunch）の感想を聞いてから決める。それまで、リードの音色に標準音源の `crunch` を使わない。
9. （2026-10-14、人間の指摘）**音をすぐミュートする書き方は全体的に禁止。** ギターの刻みだけでなく、シンバル（たたいたら鳴りを伸ばす）、タム、ベース、ブラスなど、どの楽器も、次に鳴らすまで・自然に消えるまで鳴らす。短く切るのは、その奏法がジャンルの本質のとき（レゲエの裏打ち `skank`、スラップのゴースト、スタッカートの指定）だけ。
10. （同）**ドラムを毎回同じ型で単調にしない。** 緩急（`barGain` で小節ごとの強弱の曲線）、間（抜く小節、最後の拍の空白、ハーフタイム）、グルーブ（スネア `push` +0.02、ハットは前）を必ず設計する。見本: `_gen/summer-rock4.py`。
11. （2026-10-14、人間の指摘）**ギターの `~`（ビブラート）。** 聴くと「ゴムが伸びているときの音」に聞こえる（ビブラートのかかり方が深く、モジュレーションホイール127まで上がっていた）。チョーキング（`^`）はよい。リードギターには `~` を付けない。ビブラートが必要なら、浅く（`~.` か `~`）して、聞いてもらってから決める。
12. （2026-10-14、人間の指摘）**メロコアのタム（`--drums rock` の録音ドラムのタム）。** 「メロコアのタムの音は二度と使わないで。実録音の音にして」。
   - 分かったこと: 前の書き出しもすでに録音ドラム（rock）だった。つまり、標準音源ではなく rock のタムが嫌われた（耳では確かめられない。数字では録音の音源）。
   - 代わりに: メロコア・パンク系は `--drums muldjord`（加工の少ない生録音）で書き出す。rock のタムは、人間が聞いて良いと言うまで使わない。
   - 見本: `assets-src/ai-songs/melocore-sunrise.json` は `--drums muldjord --bass pick --orchestra vsco --piano salamander --guitar gretsch` で書き出す。
13. （2026-10-14、人間の指摘）**「ポンポン」と鳴る音**（メロコアの高めのタムを音程を変えながら1発ずつ叩く短いフィルが疑わしい。どの音かは未確認）。
   - 代わりに: フィルはスネアのロール主体にし、タムは低め（E3・C3・A2）の2〜3本だけ、音量も控えめ（0.14）。高いタム（C4・A3）を1発ずつ音程を変えて並べない。まだ違うと言われたら、タムを使わない版も作る。
   - 追記（同日）: タムを直した v3 でも「ポンポン」はまだ鳴っていた（人間の感想）。タム以外の音が原因。どのパートかは、何秒あたりかを聞いて特定する（未確定）。
   - 追記（同日）: 人間の感想「タムなのにエコーが効きすぎた感じがした」。タムの残響は 0（`drumMix.tom.reverb:0` とタムのパートの `reverb:0`）にする。録音ドラムの部屋の響きがもともと入っているので、さらに足さない。
14. （2026-10-14、人間の指摘）**トランペット（`brass`）のメロディを、音と音の間をあけて1音ずつ切って書く。** Aメロで「ポンポン」と聞こえた（パートごとに分けて聞いて、トランペットだと確認）。
   - 代わりに: 休みに挟まれていない音は `_`（レガート）でつなぐ。見本: `_gen/melocore-sunrise.py` の `add()`（brass のとき自動で `_` を付ける）。
15. （2026-10-14、人間の指摘「ぽーんって音が残ってる」）**オーケストラ音源 `orchestra.sf3` の楽器データの共有バグ（修正済み）。**
   - 起きたこと: GM 19・20（オルガン）・41（ヴィオラ）・43（コントラバス）・48・49（弦アンサンブル）・57（トロンボーン）・58（チューバ）・70（ファゴット）・72（ピッコロ）・117・118・121 が、同じ1つの楽器データ（「Strings」）を指していた。作り方（`build-orchestra.mjs` の `emptyInstrument`）が、元の音源の楽器を名前で共有する `clonePreset` のあとで中身を空にして作り直していたため、あとから作った楽器が先の楽器を上書きし、最後の「インパクト・ヒット」の効果音がこの13個すべての音になっていた（出だしで音程が落ちる「ぽーん」。2026-10-13 のタム・インパクト追加の作業で混入）。
   - 直したこと: 楽器ごとに新しい楽器データを作って割りあてた（`emptyInstrument`）。VSCO の元ファイルは GitHub（sgossner/VSCO-2-CE）から必要なフォルダだけ取って作り直した（`VSCO=<フォルダ> node --experimental-strip-types tools/soundfont/build-orchestra.mjs`）。作り直したあと、全プログラムの出だしの音程を測り直して、落ち込みが消えたことを確認した（鍵の範囲外の低い鍵は測定の誤差）。
   - 注意: 作曲ソフトの HTML は音源を埋め込むので、`orchestra.sf3` を作り直したら `tools/composer/entry.ts` を触って（`touch`）HTML を作り直させる。**2026-10-13〜14 に VSCO の弦アンサンブル・ヴィオラ・トロンボーン・オルガンなどを使って書き出した曲は、すべてインパクト音になっていた。必要なら書き出し直す。**
16. （2026-10-14、人間の指摘）**パンクで「リードギター」の音色（`leadGuitar` ＋ `amp: lead`）を使う。** 「ギターの音がパンクの音じゃない」「リードギターの音はパンクでは使わないで」。
   - 代わりに: パンクのギターは `distGuitar` ＋ `amp: loudrock`（中域を活かした歪み。リフを左右に振って2本重ねる）。リードの旋律を入れるときも、まず歪みの刻みの音色で。
   - 見本: `_gen/punk-bolt.py`（リフギター左右）。
17. （2026-10-15、人間の指摘）**リードギターの旋律で「ビヨーン」と音程が動く音。** 『ネオンハートビート』のリードギターで気になった。原因: ①作曲ソフトの標準で、ギターの1拍以上の音に「半音下から持ち上げて入る」しゃくり（`autoScoop`）が自動でかかる ②ソロのチョーキング（`^^`）。
   - 代わりに: 曲に `"autoScoop": false`、旋律のギターはチョーキングなし・`humanPitch: 0`。「響かせる」方向にする（`reverb` 0.3 前後＋`delay`（0.75拍・mix 0.18・feedback 0.35）＋`plate`（mix 0.16））。
   - 見本: `_gen/neon-heartbeat.py`（リードギター）。
   - 追記（2026-10-15、2回目の指摘「ギターにしゃくり、ゴムが伸びたような音」）: さらに3つ見つけて止めた。③ `leadGuitar` には曲の最初にモジュレーション（CC1＝26）が入り、**全部の音に自動のビブラートがかかっていた** ④長い音で音量がふくらむ（CC11 のスウェル）⑤ 0.75拍・1.5拍後の自動の弾き直し（こだま）。③④は `src/audio/midi-export.ts` でリードギターから外した（全曲に効く）。⑤は音色プリセット（`guitarTone`）で `noRestrike: true`。⑥クリーンギター（`guitar`）にも、音ごとにわずかに音程をずらす揺らぎ（`humanPitch` の自動のずれ）がかかっていた（『あの夏のとなり』で457回）→ ギター類（guitar・leadGuitar・echoGuitar）から外した（全曲に効く）。

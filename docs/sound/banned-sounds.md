# 使わない音（人間が「ダメ」と決めた音）

新しい曲を作るときは、ここに書いた音の作り方を**使わない**。理由は「聴いて気持ちよくなかった」（人間の判断）。決めた日付と、何がダメだったかを残す。

## ギター
### 2026-10-11 決定
1. **「スラップの曲」（intro-bass-first）のバックのギター**
   - 作り方: `guitar`（GM27 クリーン）＋ 生ギター音源 `--guitar gretsch` ＋ amp `funk`/`clean`、音域 D3〜A4 の単音・2音の刻み／短い伸び（0.25〜1.5拍）。
   - ダメだった所: 短い単音のくり返しが「ピ、ピ」と切れる。音が伸びない。高い。
   - 代わりに: ナイロン弦（`patch: nylonGuitar`、amp auto）でアルペジオ。短い単音の刻みはやめる。
2. **「いきなり全員の曲」（intro-cold-strike）の歪みギター（旧アンプ設定）**
   - 作り方: `distGuitar` ＋ amp `hardrock`／旧 `punk`（5kHz以上が+15〜+30dB多く、ピーという高域が出た）／`crunch` 同音連打。
   - ダメだった所: 歪みすぎて割れて聞こえる。
   - 代わりに: 現在の `punk`（参考録音5曲のギターの形に合わせた。`docs/sound/data/guitar-curve-5tracks.json`、5kHzから急に落とす）。音量は 0.2 以下、キック・ベースを小さく。
   - 追記（同日・4件目）: `punk` も、メロコアの曲では高域の割れとつぶれ（PLR 2.7〜3.5）が出た。この「代わりに」は絶対ではない。まず `loudrock`／`crunch` を試し、書き出しの合否表の PLR が 6 未満なら、アンプを疑う。

### 2026-10-11 決定（2件目）
3. **「いきなりフックの曲」（intro-hook-first）のギター**
   - 作り方: `guitar` に `patch: nylonGuitar`（ナイロン弦）＋ amp `auto`（フィルターを通さない生の音）。
   - ダメだった所: 6〜10kHz が目標より +8〜+15dB 多く、耳に少し強い。透き通っていない。
   - 代わりに: `guitar`（GM27）＋ `--guitar gretsch` ＋ amp `crystal`（透明。2〜4kHz の刺さりと低中域のこもりを抑え、上にほんのり空気感を残す）。
   - ナイロン弦を使うときは、必ず amp に `crystal` か `delicate` を付けて高域を丸める（amp auto の生の音で使わない）。

### 2026-10-11 決定（4件目）
4. **「メロコアの曲」（疾走のその先 v1）の歪みギター**: `distGuitar` ＋ amp `punk`
   - ダメだった所: 音割れ。測ると、100Hz〜1.3kHz が目標より 20〜40dB 足りず、2.5〜3.2kHz に偏り、8kHz 以上が +28dB の「ピー」。山と平均の差（PLR）が 2.7〜3.5 とつぶれる。`punk` は画面収録の録音に形を合わせたため、実物のギターには薄すぎる。
   - 代わりに: amp `loudrock`（PLR 8.4、8kHz 以上が −39dB）か `crunch`。仕上げは `--master-preset rock-clean`（`punk` プリセットはクリップ付きでさらにつぶれやすい）。volume は 0.07 前後。
   - 見分け方: 書き出しの合否表で PLR が 6 未満なら、アンプを疑う。

### 2026-10-11 決定（5件目）
5. **J-POPのアルペジオ**（jpop-clean-test）: `guitar` ＋ amp `jpopClean`（レシピ `jpop-arpeggio`）
   - ダメだった所: 人間が聴いて「この音は嫌い」（理由の言葉はまだ聞けていない）。聴いて確かめずに作った初期値のまま。
   - 代わりに: 前に気に入ってもらった `sparkleClean`／`crystal` 系のクリーン（`sparkle-delay`、`crystal-wide`）。`jpopClean` は人間が聴いて良いと言うまで、曲では使わない。

### 2026-10-11 決定（6件目）
6. **クリーンギターへの chorus（コーラス）**（J-POP見本曲「ひかりの手前」の分散和音。chorus 0.3）
   - ダメだった所: 人間が聴いて「きゅいんきゅいんする音」が嫌い。コーラスの音程のゆらぎがギターでは耳につく。
   - 代わりに: ギターに chorus は掛けない（0）。広がりは pan の左右振り分けと reverb、`doubleDetune` の控えめな値で出す。鍵盤・弦・パッドの chorus は別（今回の指摘はギターだけ）。
   - レシピ `jpop-*` と `widen:"dimension"` の chorus も 0 にした。

7. **ギターの「しゃくり」と、音ごとの音程ずれ**（メロコア曲 butterfly-2〜4、2026-10-12）
   - ダメだった所: 人間が聴いて「きゅいんきゅいんするギターの音が気に食わない。曲に入れるな」。調べると、リード・リフのギターに (a) 1拍以上の音の頭に自動で付く「半音下からのしゃくり」（autoScoop）と、(b) human を上げたとき音ごとに±8セントずれる音程のゆらぎが、勝手に乗っていた（リフのトラックにピッチベンドが約1100個）。
   - 代わりに: 曲に `"autoScoop": false`、ギターのパートに `"humanPitch": 0`（音程のずれだけ止める。タイミングと強さのゆらぎは残る）と `"chorus": 0`。しゃくり記号 `/` は手で書いた所だけ。
   - 確認: 書き出した MIDI のピッチベンドが 0 になっているか（リフ）／ベンド記号を書いた所だけか（リード）。

## 共通の注意
- 短い音（スタッカート `'`、0.25拍以下）を同じ高さで連打しない。
- 高域（6kHz以上）をギターで出さない。
- 迷ったら `tools/audio-check/third-octave.py` で、ギターだけを書き出して目標の形との差を測る（100Hz〜5kHzは±3dB以内）。

## 再調整のルーティン（2026-10-11、人間の指示）
書き出しの合否表に「つぶれ気味」（PLR・PSR が小さい）が出たら、`build --wav --master-preset ...` が自動で仕上げをやさしくして最大2回やり直す（1回目: クリップ 0・圧縮を一段やさしく・目標を 1.5LU 下げる／2回目: さらに 3LU 下げる）。やり直しは警告欄に「再調整しました」と出る。止めるときは `--no-retune`。それでも残るときは元の音がつぶれているので、歪みギターのアンプ・パートの音量の合計（0.7 前後）・同じ音の重ねすぎを見直す。

### 2026-10-17 決定（人間の指示）
18. **ベースは、ふつうはコードの根音に沿わせる。** 「ベースは普通のコード進行でいいかも」。5度・オクターブ・次のコードへの経過音で動き回るベースを、どの曲にも入れない。拍のまとまりごとに根音（分数コードは指定の低音）を弾くのが基本。見本: `_gen/celtic_suite.py` のベース。
19. **ベースが旋律を弾く曲（ベースの見せ場・ベースソロ・ベースが主役のリフ）は、手で1音ずつ丁寧に書く。** 「ベースのメロディラインある曲は大事に丁寧に作って欲しい」。自動の型（音階を上下するだけ・同じ型のくり返し）で作らない。動機・問いと答え・コードとの関係を設計し、ほかのパートを引いて聞こえるようにする。
20. **アコギ（ストローク・分散和音）は、もう少しやわらかい音に。** 「アコギもう少し音が柔らかいといいかも」。強い弾き（`!`）を使わず、`bright: -0.4` と `fx: [{"type":"eq","high":-2.5}]` で高音をおさえる。楽器ごとの点検（`song.mjs inspect`）で、アコギの重心は 2kHz 前後・6kHz より上は -18dB 以下を目安にする（元の音は重心 3.1kHz・6kHz より上 -14.7dB）。
21. （2026-10-17、人間の指示）**フィドル（バイオリン）は「柔らかく力強く、音を透き通るように響かせる」。** フィドルだけを書き出して9通りを数値で比べて決めた出発点: `doubleDetune:{"cents":5,"spread":0.3}`（2本重ね。フィドル単体の点数 7.23→7.65）、`fx` に `eq`（low +2・mid -2.5 @2800Hz・high 0）→ `delay`（1拍・mix 0.08）→ `reverb`（mix 0.22）→ `plate`（mix 0.12）、`bright -0.15`・`attack 0.35`・`release 0.7`・`reverb 0.5`・`gainDb +3`。高音（6kHz以上）は落とさない（落とすとこもる）。見本: `_gen/celtic_suite.py` の LEAD_META["fiddle"]。2本重ねで MIDI のチャンネルが1つ増えるので、弦の上下などは pan をそろえて共有させる。
22. （2026-10-17、人間の指示）**全体的に音域（スケール）を広く使う。** 旋律は約2オクターブ半（A3〜G6あたり）を使い、順次進行に1割ほど4〜5度の跳躍（跳んだ直後は反対向きに1歩もどる）を混ぜる。ハープの分散和音は A2〜E6 の3オクターブ。
23. （2026-10-17、人間の指示）**自然を感じる曲は「その空間が感じられる」ように。** 曲全体をホールの残響に通す（書き出しに `--space hall --space-wet 0.15〜0.22`）、霧のパッド・鉄琴のしずく・遠い笛など「遠くにあるもの」ほど reverb を深く（0.55〜0.7）、左右に広く置く。自然音の楽器（wind・stream・bird・crickets）は AIソング形式ではまだ使えない。

# 参考調査: 日本一フリーBGMの「音の作り方」（2026-09-30）

人間から「日本一フリーBGM（https://nihonichi-bgm.com/ ）の音楽をいろいろ聴いて、特に音の作り方を学んでほしい。こういうきれいな音も出したい」と依頼があり、調べた記録です。

**曲そのもの（mp3）はリポジトリに入れていない。** 二次配布が禁止されているためです。残したのは次の2つだけです。
- 数値で測った結果: `docs/sound/data/nihonichi-bgm-metrics.json`。音声は入っていない。
- 測るための道具: `tools/audio-check/analyze.py`。

**旋律・和音・リズムの型は測っていないし、写してもいない**（CLAUDE.md 1-1）。学んだのは、音量・音の帯域・左右の広がり・残響・曲の起伏といった「仕上げ方」だけです。

## 1. 規約（2026-09-30 に利用規約 https://nihonichi-bgm.com/terms/ を全文確認）

このゲームでの扱い:
- **学習（音の作りを数値で測って、うちの音づくりの目安にする）だけに使う。**
- **ゲームに曲を入れることはしない。** このゲームの曲はすべてオリジナルで作る方針です（`roles.md` 3-7）。さらに、AIで作られた曲は権利関係が保証されておらず、既存曲に似ている可能性もサイト自身が認めています（1-1 を厳しめに解釈）。
- 聴いた曲の旋律に寄せた曲は作らない。

## 2. 調べ方

1. **参考の37曲**: ゲーム用BGM 13曲（戦闘・追跡・ワルツ・西部劇風・ジャズ・魔王城・スタッフロール）、オーケストラ・映画風 11曲、ヒーリング・朗読用のピアノ 4曲、ローファイ 2曲、和風 4曲、ホラー 3曲。
   - 曲名・URL・サイトの説明タグは、数値と一緒に `data/nihonichi-bgm-metrics.json` に入れた。
   - サイトの説明タグには、AIに渡した「音づくりの指示」がそのまま書かれている。次の2つがそれにあたる。
     - 「very soft close-miked felt piano over a warm analog pad」（フェルトをかませたピアノを近くで録った音＋暖かいパッド）
     - 「wide ambient pad」「long hall reverb」「subtle tape saturation」
   - この言葉と数値を突き合わせた。
2. **うちの15曲**: 作曲ソフトと同じ音（real版＝録音音源・アンプ・仕上げ）で WAV に書き出し、同じ道具で測った。
   - 対象: タイトル、灯里の朝、町外れの風、戦闘、灯里の歪み戦、麦香野、涸れゆく水源、霧断崖、試作機の歪み戦、オープニング、別れの雨、追憶、推理、虚灯宮・深部、スタッフロール。
3. 測ったもの: 音量（LUFS）、ピークと平均の差、音量の幅、左右の相関と帯域ごとの広がり、帯域ごとの量、音の重心、2〜8kHzのざらつき、5秒ごとの音量の流れ、最後の余韻。
   - 道具のくわしい説明は `analyze.py` の冒頭に書いた。

## 4. 学んだこと（「きれいな音」の正体）

### 4-1. 音量を上げすぎず、つぶさない（いちばん大きな差）

- **参考**: どの分類もほぼ **-13〜-15 LUFS**、ピークは -1dBTP 前後、ピークと平均の差は **13〜17dB**。速い戦闘曲でも -13.8 LUFS・14dB で、静かな曲とほとんど同じ音量にそろえてある。
- **うち**: 全体で -10.5 LUFS、戦闘・ボスは **-4〜-7 LUFS**（参考より約8〜10dB大きい）、差は **7〜9dB**。音の頭（アタック）がつぶれて、ずっと同じ大きさで押し寄せる音になっている。
- **原因**: BGMの出口（`src/audio/voices.ts` の `createBgmBus`）で、3つの処理が重なっている。
  - コンプレッサー（-20dB・3.2:1）
  - 音量の底上げ（×1.75＝約+4.9dB）
  - 強いリミッター（-1.5dB・20:1、アタック2ms）
- **直し方**:
  - 底上げを下げ、リミッターは「割れないための歯止め」だけにする。目安は、ほとんどの時間でリミッターが働かない程度。
  - 曲ごとの音量は -14 LUFS 前後にそろえる。ピークと平均の差は 12.5dB 以上を目安にする。
  - 戦闘曲の迫力は、音量ではなく、ドラムのアタック・低音・テンポで出す。参考の戦闘曲は、低（60〜250Hz）が全体の中でいちばん多い。

### 4-2. 左右に広げる（楽器ごとに置き場所を決める）

- **参考**: 左右の相関は 0.5〜0.75。中音域（1〜4kHz）の「横−中央」は **-2〜-5dB** で、弦・パッド・ピアノ・残響が左右いっぱいに広がっている。
  - 超低音（60Hz未満）だけは -15dB 前後で、真ん中に集めている（低音は真ん中、上は広く）。
- **うち**: 相関 0.91、中音域の「横−中央」は -10dB。とくに戦闘・ボス・町の曲がほぼ真ん中だけ。
  - オープニング・別れの雨・霧断崖・スタッフロール（オーケストラ系）は 0.54〜0.67 で、参考に近い。
- **直し方**:
  - キック・ベース・主旋律は真ん中。
  - 和音楽器（ギターの刻み、ピアノ、パッド）は左右に振り分ける。弦は左右に大きく広げる。
  - ギターの刻みを2本にして左右に分ける（重ね録り）のが、戦闘曲の定番の広げ方。
  - 残響は左右で別の響きにする（今の残響の元になる音は左右別に作ってあるので、その量を増やす）。
  - どこで真ん中に集まっているのか（作曲エンジンの `pan` の値か、アンプの段か）を最初に調べる。

### 4-3. 低音をしっかり、1〜8kHz は控えめに（暖かく、耳に刺さらない）

- **参考**: 帯域の量は「低 > 中低 > 超低 > 中 ≫ 張り ≫ 空気」の順。音の重心は **約390Hz**。
  - 1〜4kHz は -11.5dB、4〜8kHz は -23dB と、高いほうはかなり控えめ。
  - ピアノ・ヒーリング系は 4kHz より上がほとんど無い（-60dB）。サイトの説明にある「フェルトピアノ」「暖かいアナログのパッド」「くすんだ音」の正体がこれ。
- **うち**: 音の重心は **約870Hz**（参考の2倍以上）。1〜4kHz は -6.8dB（参考より約5dB多い）、4〜8kHz は -16dB（約7dB多い）。
  - 町・イベントの曲は超低音（60Hz未満）が -22〜-27dB で、ほとんど無い。
  - 明るく硬い、すこし耳に刺さる音で、底が浅い。
- **直し方**:
  - 仕上げの「3.2kHzを持ち上げる」「8kHzから上を持ち上げる」はやめるか、逆に少し下げる。
  - 町・イベントの曲に、ベースかパッドの低い音を足す（ルート音を1オクターブ下で長く鳴らすなど）。
  - しっとりした曲のピアノ・エレピは、高いほうを丸めてフェルトピアノのような音にする。目安は 3〜5kHz より上を下げること。
  - 場面ごとの目安は第5節の表。

### 4-4. 残響と空気感（「きれい」「広い」の手ざわり）

- **参考**: 2〜8kHz のざらつきは、全体で 0.10、戦闘・オーケストラでは 0.2〜0.3。音と音の間を、残響・シンバル・弦のこすれなど、ノイズに近い細かい成分が埋めている。
  - 説明タグにも「wide ambient pad」「long hall reverb」「gentle room ambience」が何度も出てくる。
  - 最後の音が消えるまでは 1〜4秒。
- **うち**: 0.04。一つひとつの音が澄んではいるが、音と音の間がすき間になっていて、「電子的」「硬い」に聞こえる原因の一つ。
- **直し方**:
  - 残響は「全部に同じだけ」ではなく、楽器ごとに送る量を変える。
    - 多め: 弦・パッド・ピアノ
    - 少なめ: ドラムとベース
  - 残響の最初に 20〜40ms の間（プリディレイ）を置いて、音の輪郭を残したまま広げる。
  - 戦闘曲は、シンバル（ライド・クラッシュ）と弦の刻みを足して、上の空気を作る。電子的な高音で作らない。

### 4-5. 曲に起伏をつける（小さく始めて、途中で一度引く）

- **参考**:
  - 曲の頭は、いちばん大きい所より **約6.6dB 小さい**。オーケストラ系は約10dB。
  - 途中に「一度引く」場所が平均2か所ある。5秒ごとの音量が最大より 4dB 以上下がる所。
  - 例: スタッフロールの曲の流れは -15 → -8 → -3 … -7.7（中ほどで一度引く）… 0 → -11 → -13。
- **うち**: 曲の頭は **-0.8dB**（最初から全開）、途中で引く所はほぼ0か所。音量の幅（LRA）も 2.0 で、参考（4.6）の半分以下。
- **直し方**: 作曲エンジン（`songwriter.ts`）の曲の組み立てに、次の2つを入れる。
  - 最初の数小節は楽器を減らす（例: ピアノとパッドだけ、ドラムはハイハットだけ）。
  - 間奏で一度音を減らしてから、サビで全部を戻す。
  - ループする曲は、ループの頭が「小さい所」に戻るので、つなぎ目でも急に大きくならない。

### 4-6. 曲の長さ

- **参考**: 中央値 **約2分40秒**（戦闘系は40秒〜2分半）。
- **うち**: 約1分15秒。
- 同じ曲を何度も聴くRPGでは、長いほうが飽きにくい。工程表の 4-29c（全曲を1分半〜2分に）とあわせて進める。

### 4-7. 同じ注文から「版違い」を作る

- サイトの曲の多くは「〜に」「〜に Ⅱ」のように、**同じ指示から作った2曲**が並んでいる。
- Shade さんの素材集の「本体＋バリエーション」（`reference-shade-bgm.md`）と同じ考え方で、場面に合わせて音色・編成だけを変えた版を作るとよい。

## 6. 次にやること（`docs/roadmap.md` の S-1〜S-6）

1. **S-1 仕上げ（出口）の見直し**: 4-1 と 4-3 の出口側。
   - 底上げ・リミッター・持ち上げの設定を変え、15曲を書き出して測り直す。
   - 全曲の音が変わるので、先に `docs/decisions.md` に書く（CLAUDE.md 1-7）。
2. **S-2 左右の配置**: 4-2。
3. **S-3 低音と高音のバランス（楽器側）**: 4-3 の楽器側。
4. **S-4 残響の送り方**: 4-4。
5. **S-5 曲の起伏**: 4-5（作曲エンジン）。
6. **S-6 仕上がりの確認**: 全曲を書き出し、目安と比べ、人間の耳で確かめる。

**自分では音を聴けないので、最後は人間（旭さん）の耳で判断してもらう。** 数値は「参考と同じ方向に近づいたか」を確かめるためのもの。数値を合わせること自体を目的にしない。

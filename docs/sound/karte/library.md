# 学んだ型の引き出し（お手本のカルテから）

お手本 51曲（ポップ 7・ロック 9・メタル 8・ファンク 7・ダンス 8・エレクトロニクス 8・ボカロ 3・そのほか 1）。ネットレーベルの、自由なライセンス（CC BY・CC BY-SA・CC0）の曲だけ。
数字は「まん中の値（25%〜75%の幅）」。機械の聞き取りなので、目安。1曲ぶんの進行や旋律は入っていない。

**信用しにくい所**: ①根音が半音で動く進行（C → B、C → D♭ など）は、聞き取りのゆれで多めに出る（自分の曲でも、書いていないのに 1〜29% と出た）。②ドラムの絵は、テンポや小節の頭の当てまちがいでぼやける。③歌の数字は、歌の少ない曲（ダンス・エレクトロニクス）では声の切れはしを測っている。

## 使い方

- 曲を作る前に、そのジャンルの行を見て、幅から外れすぎていないかを確かめる（外すなら、わざと外す）。
- ドラムの絵は「その場所を打つ小節の割合」。X の場所を骨組みにして、x の場所を小節ごとに入れたり抜いたりする。
- 短いコード進行は、度数（I＝その調の1番目）。そのまま並べるのではなく、つなぎ方の材料にする。

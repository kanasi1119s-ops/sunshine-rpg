# パンク（メロディックパンク）の音の作り方（2026-10-11 調査）

人間の指示：「ジャンルの雰囲気ではなく、実際のバンド（ELLEGARDEN）の音を分析して学ぶこと」「ドラムは2ビートも使う」「ギターの音がぶつぶつ切れるのは直す」。
**決まり**：既存曲のメロディ・コード進行・歌詞は写さない（CLAUDE.md 1-1）。ここに書くのは、公開されている解説から分かった**演奏の型・音作りの考え方**だけ。録音そのものをこの環境では聴けないので、「曲を聴いて採譜する」ことはしていない。

## 1. ドラム（いちばん大事）
- **2ビート**（メロコアの基本。4ビートを倍速にした形）：1拍の**表にキック、裏にスネア**を置いて繰り返す（ドッタン・ドッタン）。ハイハットは8分で、**スネアと重なる裏を強く**（表は弱く）。テンポは150〜200以上。
- 変化のつけ方：キックの型を1小節おきに変える（例「ドッタドットタン」＝拍の終わりにキックを足す）／200を超えるとハイハットの表拍を省く／クラッシュの直後のスネアでハットを省く。
- 8ビート（キック1・3、スネア2・4）はAメロや落とす場面に。**ハーフタイム**（スネアを3拍目だけ）はブリッジに。
- セクションの頭にクラッシュ。4・8小節ごとの最後にタムかスネアのフィル。
- 音作り（ポップパンク）：キックはアタックの高域（ビーターの「カチッ」）を持ち上げ、少し強めに圧縮。スネアは高中域で明るく。ルームの音を混ぜてシンバルに大きさを出す。ゲートでスネアの余韻を揃える。
## 2. ギター
- **2本を左右に振る**（ダブルトラック）。同じ音を2本重ねるより、**1つ変えて**（ピックアップ・アンプ・弾き方）重ねるほうが広がる。3本目以降は、低音のない転回形や高い音を足す。
- 歪みは深すぎず、**中域（500Hz〜2kHz）を活かし、低音は控える**（ベースと重ならないように）。ゲインは中程度。空間系（リバーブ・コーラス）はほとんど使わず、ドライでタイトに。
- Aメロはパームミュート、サビは全開のストローク（歪みは同じで、弾き方で大きく聴かせる）。クリーンのアルペジオを間に挟む。
- 一方がメインの歪み、もう一方が歯切れのよいクリーン寄り（中域を削った音）という役割分担。リードは歪みを浅く、単独で抜ける音に。
- 参考：細美武士の機材は Diezel Herbert（アンプ）、Les Paul と Telecaster の2本、オーバードライブはアンプの手前、空間系はほぼ使わない。EQの目安は Bass 4〜5・Middle 6〜7・Treble 5〜6・Gain 4〜6（出典の目安）。
## 3. ベース・ミックス・曲の形
- ベースは8分の根音をピックで刻む。キックに合わせ、サイドチェーンで噛み合わせる。低域のゴロつきは削る。
- 曲の長さは2〜3分が普通（うちは依頼で3分30秒）。構成は 前奏→Aメロ→Bメロ→サビ→間奏/ソロ→サビ。進行は I-V-vi-IV や I-IV-V が土台（そこに一つ変化を足す）。
- ヴォーカルのサビ：3度・オクターブのハモリ、掛け合いを左右に振る。ギターのリードも同様に歌えるメロディにする。
## 4. うちの道具での書き方
| 学んだこと | 書き方 |
|---|---|
| 2ビート | kick `x...x...x...x...`／snare `..x...x...x...x.`／hihat `x.X.x.X.x.X.x.X.`（16分グリッド。`g:` を付ける）。1小節おきに kick を `x...x...x..xx...` に |
| ハーフタイム | kick `x.......x.......`／snare `........x.......` |
| フィル | 小節の最後の1拍に `tom`（`R:3 C4:0.25! A3:0.25 E3:0.25 A2:0.25`） |
| ギターが切れる | 8分の刻みにスタッカート `'` を付けない。`sustain` を 1.25 前後にして音を重ねる（0.8 以下は音と音のあいだに隙間ができる。実測：10ms単位の音量の谷が 6秒で31回→0回） |
| 中域を活かす | `amp: punk`（1.5kHz を押し出し、低音を締める）。歪みギターは `volume` 0.1 くらいから |
| ギター2本の広がり | 左右（±0.85）に同じリフ。片方は5度を足さない／オクターブ違いにするとさらに広がる |

## 6. まだ分かっていないこと
- ELLEGARDEN の個別の曲のテンポ・構成・ドラムの型は、聴いて確かめられていない（この環境は音源を聴けず、解説記事も一部は読めなかった）。聴き取れる人が「この曲のドラムはこう」と教えてくれれば、型として足す。

## 7. 参考録音との比べ（2026-10-11、人間が渡した録音。画面収録・モノラル・小音量）
`tools/audio-check/analyze.py`（帯域）と `analyze-rhythm.py`（リズム）で、渡された録音と、うちの見本曲を同じ指標で測った。録音はスマホ収録のように質が低いので、数値は**目安**（低音は小さいスピーカーで減る）。
| 指標 | 参考録音 | うちの見本曲（直す前） | 直したあと |
|---|---|---|---|
| mid（1〜4kHz） | -5.7dB | -18.1 | -13.0 |
| presence（4〜8kHz） | -14.5 | -23.7 | -22.8 |
| air（8kHz〜） | -19.7 | -30.5 | -29.6 |
| 音の重心 | 979Hz | 228Hz | 382Hz |
- 分かったこと：うちの曲は**低音に偏り、ギターとシンバルが引っ込んでいた**。ギター（歪み）の音量を 0.1→0.3、ベースを 0.21→0.14、キックを 0.21→0.16 にして改善したが、参考録音の明るさ（presence・air）にはまだ届かない。
- 原因の見当：パンク用のアンプ（`punk`）は 6.5kHz から上を落とす。ドラムの `level` は 1.05 が上限。ハイハット・クラッシュの高域が足りない。`hardrock`・`loudrock` のアンプに替えても大きくは変わらなかった。
- 参考録音のテンポは約208BPM（自動推定。倍・半分の可能性あり）。打点の型は録音が悪く断定できない。
- 音量の起伏：参考録音は、セクションの頭で約 -7dB に落とし、サビで 0dB に戻す。うちの曲はほぼ平ら。

## 8. 音割れの原因と直し方（2026-10-11）
- 症状：ギターの音量を上げた版（全パートの `volume` の合計 2.5）で「音が割れて聞こえる」。
- 原因：書き出しは全体の大きさを自動でそろえるが、その前に内部のリミッターとソフトクリップがかかる。合計が大きいと、ここで山がつぶされる（波形のピークは -10dBFS でも、ピークと平均の差＝crest が 8.4dB と小さく、つぶれていた）。
- 直し方：**音量の比率を保ったまま、合計を 0.7〜0.8 に下げる**（全部に同じ係数をかける）。直したあとの crest は 12.6dB。書き出しの音の大きさは自動でそろうので、小さく書いても最終の大きさは変わらない。
- 確かめ方：パートの `volume` を 0.4 倍・0.6 倍にして書き出し、最大音量（max_volume）が上がっていくなら、リミッターがかかっている。crest が 10dB 以上あれば、つぶれ過ぎではない。

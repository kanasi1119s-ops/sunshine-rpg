# ラウドロック・ラウドメタルの曲の型（記録）

ラウドロック25曲（`assets-src/ai-songs/_gen/loud25*.py`）を作る中で、人間の感想から決まった「型」と「やってはいけないこと」の記録です。
次の曲を作る前に読み、同じ失敗をくり返さないようにします。既存の曲の旋律・進行は写さない（`CLAUDE.md` 1-1）。

## 型A「逆光プリズム型」（2026-10-22 記録。人間「このパターンも一回記録に残して」）

元の曲: `assets-src/ai-songs/_gen/loud25_01_gyakkou.py`（「逆光プリズム」D・150・ドロップD・約4分）。
作ったきっかけ: 自動で作った1曲目が「曲として成り立ってない」「魅力を感じない」「旋律とか既存でよく聞くもの過ぎてつまらない」で没になり、旋律から手で作り直した。

### 1. 定番から外すしかけ

| しかけ | この曲でのやり方 | ねらい |
|---|---|---|
| 同じ主音のまま旋法を切りかえる | Aメロ = D フリジアン（暗い・♭2 のミ♭）→ サビ = D リディアン（明るい・♯4 のソ#） | 転調しないのに景色が変わる。サビで「光が差す」 |
| サビの和音を機能和声から外す | D → E → C#m7 → B♭maj7 → D → E → F#m → A♭（3全音はなれた和音）… | 「よく聞く進行」に聞こえない。B♭maj7 で一瞬陰る |
| 短3度ずつ上がる和音 | D → F → A♭ → B（Bメロ・ブリッジ） | 1周すると元にもどる対称な並び。上り続ける感じ |
| 拍子からずれるリフ | 7つの8分音符のかたまり（開放のD・D・1オクターブ上・♭2・D・5度・♯4）を 4/4 の上でくり返す。区間の最後の8分で根音にもどす | 小節の頭とずれていき、区切りでぴたりと合う。刻みではない |
| 旋律を手で書く | 7度・3全音の跳躍、裏拍から入る、休みも旋律の一部、サビの最後は解決しない ♯4（ソ#）で止める | 自動の旋律は「既存でよく聞くもの」になりやすい |
| 予告 | Aメロの終わりに、サビの色の音（ソ#）をちらっと見せる | サビの切りかえに説得力が出る |

### 2. 単調にしないしかけ（人間「単調になりやすい傾向あるから注意して」）

- **区間ごとに編成を変える**
  - 前奏: リフとベースだけで始め、5小節目からドラムがゆったりしたノリで入る
  - Aメロ前半: ギターを抜き、ベース・ドラム・旋律だけにする
  - ブリッジ: 分散和音のギターと低いタムだけにし、旋律を4小節休ませる
- **同じ区間でも1回目と2回目を変える**
  - Aメロ: 2回目は旋律を1オクターブ近く上げて、リズムを詰める。ハイハットをライドに変える
  - サビ: 2回目はツーバスを1小節入れる。3回目は頭の4小節をゆったりしたノリにしてから全開にする
- **Bメロで積み上げる**: キックを2分音符 → 4分音符 → 8分音符 → 16分音符と細かくし、最後は止めてサビへ入る
- **音域を区間で分ける**: Aメロは低め（レ4〜）、Bメロで上り、サビで一番高く（ミ6）
- **終わり方**: 後奏はリフにもどり、最後は明るいDの和音を1回鳴らしてぱっと終わる（フェードアウトしない）

### 3. 音（この型で決まったこと）

| 楽器 | 中身 |
|---|---|
| リード | 学習したアンプのマーシャル系（namJVM 0.7・Greenback・1kHz +2.5・7.5kHz から上を切る・付点8分のディレイ・プレート）。人間が4通りから「2」を選んだ。標準の lead アンプ（warm-lead-a）は「好きじゃない」 |
| リード（Aメロ・ブリッジ） | 同じ音色で小さめの別パート（サビより前に出ない） |
| 分散和音のギター | キーボードの代わり。同じアンプで歪みを浅く（0.35）、8分で上がって下がる形を和音ごとに変える |
| 刻みのギター | loud-mid（B3）。刻みではなく、付点のアクセントで伸ばして弾く |
| ベース | 指弾き＋bassSplit（0.6）。中域 2.2kHz +3・高域 +2 |
| バスドラ | トリガー（punch）＋重みの層（録音のキックを 180Hz から下だけにして低音 +6dB）。人間「トリガーは必要」「トリガーとは別に重みのあるバスドラ」 |
| 入れないもの | キーボード・シンセ・ライザー（人間「全体的に電子音感が強すぎる」） |

## やってはいけないこと（この1曲目で言われたこと）

- 曲の頭を「伸ばした和音＋旋律」だけにする（「曲の始まりがものすごくつまらない」）
- 何にでもブリッジミュートの刻みを入れる。特に曲の頭（banned-sounds 25〜27）
- キーボードの右手を、同じ8つの音の16分音符で機械的にくり返す（「最初のキーボードの演奏なんか変えられないかな」）
- 伸ばしたキーボードの和音・シンセのライザーで、電子音っぽくする
- 自動で作った旋律・よくある進行のままにする（「既存でよく聞くもの過ぎてつまらない」）

## 点数の目安（音質採点 Audiobox PQ）

- 自動で作った旧1曲目: 7.08〜7.19
- サビの抜粋の比較で効いたもの: 刻みをやめて伸ばす（+0.13〜0.25）、外れたコード進行、旋律の種を変える、リードを +1.5dB、ベースを少し明るく
- 旧1曲目にそれらを当てはめた全体: 7.50〜7.58（ただし人間の耳では「魅力を感じない」。点数より曲の中身が先）

## 型B「現代ラウドロックの設計図」（2026-10-22 記録。人間「もっと現代のラウドロックの勉強してきて」）

詳しい調査: `docs/sound/modern-loud-rock/structure.md`（構成と展開・出典43）、`vocabulary.md`（旋律・和音・リフ・ドラムの語彙・出典約30）、`production.md`（音作り・ミックス・出典38）。
型A（逆光プリズム第1版）は「定番から外す」を優先しすぎて、曲としてまとまらなかった（人間「曲としてレベルが低い」「聴きたいかと言われたら聞きたくはない」）。型Bでは **定番の骨組みを守り、意外性は3〜5か所に絞る**。

| 決まり | 中身 |
|---|---|
| 長さ | 3:15〜4:00、約100〜125小節。最初のサビは曲頭から60秒以内 |
| 形 | イントロ → Aメロ → Bメロ → サビ → 看板リフ → Aメロ2（短く・2つ以上変える）→ Bメロ2 → サビ2（ハモり・ツーバス）→ ブリッジ（静）→ ブレイクダウン → ラストサビ（頭4小節は抜く）→ アウトロ |
| イントロ | 静かな顔見せ（クリーンの分散和音・サビの先出し）→ 1拍全員休み → 全員の一撃（クラッシュとチャイナを鳴らし切る）→ 看板リフ。刻みで始めない |
| サビの旋律 | Aメロより中心を4〜7半音高く。2小節のフックを A・A'・B・終止。長い音（2拍以上）を8小節に3つ以上、3度か9度で伸ばす。上への跳躍（5〜8半音）を1回、跳んだら順次で下りる。最高音は1回だけ |
| サビの和音 | 短調なら VI か III の長三和音で開ける。主和音は最後まで取っておく。和音の変わる速さは Aメロの半分（2小節ごと）。借用の長三和音（例: IV）を1回だけ＝光が差す |
| Bメロ | 低音は主音のペダル、旋律は1小節ごとに上がる、最後の1拍は全員休み |
| リフ | 刻みばかりにしない。開放弦のペダル・伸ばす和音・オクターブ・高い弦の旋律・スライド・無音のうち3種類以上 |
| ブレイクダウン | ハーフタイム（スネア3拍目）、キックとギターを完全にそろえる、休みを必ず入れる、最後は2拍休んで一番低い一撃を伸ばす |
| 2回目 | 同じ区間の2回目は最低2つ変える（ドラムのノリ・パートの数・ハモり・オクターブなど） |
| 歌の代わり | リードは「歌」として書く。曲の50〜70%の小節だけ鳴らし、フレーズのあとに息つぎ |
| 日本のラウドらしさ | 区間の境目に必ず前ぶれ（フィル・止め・ため）。前ぶれなしの急な切りかえは1曲1回まで |
| 音 | リズムギターは4本重ね（外側 ±1・内側 ±0.75 で −5dB、内側はサビとブレイクダウンだけ）。リードのディレイは左右で拍を変える。ベースはキックで少し下げる（duck） |

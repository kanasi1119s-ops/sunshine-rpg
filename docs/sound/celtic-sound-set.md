## パターン「霧の湖」型（音と空間の使い方の記録。2026-10-25 人間「この感じいい」）
**記録するのは音と空間の使い方だけ。旋律・和音の流れ・場面の並びは写さない（似た曲は作らない）。** 見本の曲: `assets-src/ai-songs/_gen/celt_kiri.py`。
- 空間: `--space dome --space-wet 0.3`（4.4秒の余韻・最初の反射 65ms・高い音は早く消える）。耳を包み、頭の中を満たす広さ。仕上げは −15 LUFS・widen 1.0。
- 強弱: 曲全体の強さの曲線を、全パートの barGain にかける（いちばん小さい所 0.35 → いちばん大きい所 1.0。約 20dB の幅）。
  大きい山は1曲に1〜2か所。山のあとに1拍の完全な無音を置き、そこから小さく始め直す。最後は長い余韻（シンバルのロールのディミヌエンド）で消える。
  ただし前奏は小さくしすぎない（霧の場面は −36dB で、いちばん大きい所より 20dB 小さかった。次からは 0.5 くらいから始める）。
- 音域: 低い支え（コントラバス・チェロの C2 前後）から、笛の F#6・ベルの C7 まで、5オクターブを同時に使う場面を作る。
- 音の重ね方: 芯＝ハープの8分の分散和音（真ん中）／空の高さ＝2本目のハープの高い響きとベル（右・残響を深く）／広がり＝弦の持続を左右いっぱい（±0.7）＋空気のパッド2本／
  大きい場面だけ＝ホルン・ティンパニ（ロールで入る）・コントラバス・シンバルのスウェル。旋律は笛とフィドルの掛け合い、山では同じ旋律を2つで重ねる。
- 環境音: そよ風を前奏と終わりに小さく（seasonFx の A#4）。
- 音質の点数: 7.92（前奏を少し持ち上げると上がる見込み）。

# Kawaii future bass の使い方 100（2026-11-15）

人間（2026-11-15）:「kawaiiFutureベースの使い方を100通りぐらい学んできて」

Kawaii future bass の「作り方・鳴らし方・重ね方」を 100 個、10 の分野に分けてまとめた。曲を作る前にここから「この曲で使うもの」を選ぶ（**全部を1曲に入れない。1曲に 5〜8 個、曲ごとにちがう組み合わせ**）。

- 「今」の列: ◎＝今の作曲ソフトですぐ使える（かっこは部品の名前。`vocalo_lib.py`・`vt3x_lib.py`・パートの設定）／△＝工夫すればできる／×＝まだできない（これから作るもの）
- もとにしたもの: 末尾の出典（解説記事・ジャンルの説明）と、これまでこの作曲ソフトで試して分かったこと。数字は解説記事の目安で、最後は耳で確かめる。
- ジャンルの土台（出典 1・2・3）: テンポ 140〜160・半分の速さ（スネアかクラップが3拍目）。明るい調。7th・9th・add9・sus の和音を重ねたスーパーソウを、キックで凹ませて「ポンプ」させる。ベル・おもちゃのピアノ・木琴・やわらかい矩形波・チップ音のアルペジオ。高い声のチョップ。場面の変わり目に上がる音・きらきら。

## KFB04「透過率100%」（2026-11-27）

- 依頼: 空が透き通るような Kawaii future bass。ギターは見本の39番（crystal・コーラスなし）、ベースは見本の22番（fretlessBass）、FX は4種類（しずく・きらめき・逆回しのシンバル・ウインドチャイム）、テンポ130、物語仕立て。
- 台本: `assets-src/ai-songs/_gen/kfb_04_sky.py`（イ長調・130小節・約4分3秒。形はサイコロ 2403 の骨組み。リズムは break と tresillo）。
- 点数: v1 歌 7.45 / BGM 7.62 → v2 歌 7.55 / BGM 7.73。
- v1→v2 で直したこと: ベースが目印の音にくらべて +20dB と、ギター（+18）やドラム（+12）より大きかった。区間ごとに採点すると「走る」7.17・「風」7.26 が低く、切り出しで試すと、ベースを 4dB 下げ、ピアノとパッドを上げると上がった。そこで gainDb 5→2、ベルのピアノ 0.04→0.055、パッド 0.05→0.065。
- 分かったこと: fretlessBass は volume を変えても大きさがほとんど変わらない。gainDb で動かす。
- 残っていること: 「パチパチ 30か所」の表示（場所は未特定）。耳では未確認。

## KFB05「夕方の背伸び」（曲名は「釣瓶落としのベーカリー」→「閉店五分前」→「夕方の背伸び」。人間が選んだ）（2026-11-27）

- 依頼: 秋の夕暮れの寂しさを感じながら恋する物語。ベースは見本の18番（--bass finger＋bassSplit 歪み 0.3）、ギターは見本の11番（electro-rock）、FX を何種類か、テンポ120、ギターソロとアルペジオ。
- 台本: `assets-src/ai-songs/_gen/kfb_05_dusk.py`（ト長調・122小節・約4分6秒。形はサイコロ 2514。始まり＝上がっていく音から落とす、終わり＝フックをくり返しながら消える）。
- 点数: v1 歌 7.75 / BGM 7.87。
- はんぶんこサイダー v4（和音を fbChord に）: 歌 7.60 / BGM 7.66（v3 は 7.55 / 7.53）。
- 作る前の確かめで直したこと:
  - grooves.json の型（bounce・twostep）のキックとベースをそのまま使うと、同じ型を使った「はんぶんこサイダー」とベースが 90.7%・キックが 100% 同じになった。→ キックとベースは曲ごとに書く（ドラムのスネアとハイハット、はね・ノリだけ型から借りる）。
  - 歌のリズムが 61%（4分音符と長い音だけの小節が多い）→ 付点と8分の食いこみに書きかえて 34%。
- 音づくりで分かったこと（切り出しで採点）:
  - 歪んだギター（11番）のアルペジオが、パッドだけの静かな場面でむき出しになると 6.82。ギターを消すと 7.74。→ 静かな場面だけ別のトラックにして、歪みを浅く（ampDrive 0.2）・volume 0.015・release 0.3・自動の持ち上げ（barGain）なしで 7.67。
  - 歌のサビで、歪んだ左右のギターを 0.6 倍にすると 7.38 → 7.89（BGM 版は下げない）。
  - distGuitar＋guitarTone は、gainDb を下げても大きさがまっすぐには下がらない（-7 で約 -4.5dB、-13 で約 -9dB）。balance_check.py で測りながら決める。
- 残っていること: 最初の2小節（上がっていく音だけ）が -28dB と小さい。「パチパチ 30か所」の表示（場所は未特定）。耳では未確認。

# 曲を決める表（曲の設計の型）

2026-10-24 人間「曲をこんな感じで決めれるといいね」。ラウド26曲（lm25）を作り直すときに使った表を、
**どのジャンルでも、曲（またはシリーズ）を作る前に最初に書く型**にする。書いたら人間に見せてから作る。

## 書き方

| 列 | 書くこと | よくない例 | よい例 |
|---|---|---|---|
| 曲 | 番号と曲名 | | |
| 形 | 曲全体の骨組みを、物語の言葉で1行。何がくり返し、何が変わっていくか | 「前奏→Aメロ→Bメロ→サビ」 | 「同じ8小節が半音ずつ4周上がる」「最期から始まり、人生を巻き戻す」 |
| 場面と、そこで必要な強さ | 場面ごとに、その場面の中身から決めた強さ。どこを最大にし、どこを無音・小さくするか | 「Aメロは弱く、サビは強く」 | 「嵐の目＝完全な静けさ（長い）」「爆発は決闘の一度だけ、短く」 |
| 旋律の性格 | 旋律のリズムの形・音の動き・歌い方。主役の楽器との関係 | 「明るいメロディ」 | 「裏拍から入る崩したジャズの言い回し、3連符」「法廷の早口（16分の同じ音の連打）と、判決の長い音」 |

必要なら列を足す: 主役の楽器（その曲だけの楽器）／物語（1行）／始まり方・終わり方／ベースの旋律の有無。

## 確かめること（書いたあと）

1. **どの2曲を取っても、3つの列（形・強さ・旋律の性格）のうち、少なくとも2つが違う**こと。似ている行があれば、作る前に直す（同じような曲は作らない。`.claude/skills/compose-song/SKILL.md` の 2.55）。
2. 「形」に、Aメロ・サビなどの区間の名前だけが並んでいないこと（区間の名前は、物語の場面のあとに付ける）。
3. 「強さ」に、最大の場面と、静か・無音の場面の両方があること。ずっと同じ強さの曲は、その理由を書く。
4. 作ったあとは、表のとおりになっているかを、比べる道具（`assets-src/ai-songs/_gen/lm25_novelty.py`）と耳で確かめる。表と変えた所は、表を直してから進める。

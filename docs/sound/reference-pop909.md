## 使ったデータと、使わなかったデータ

- **使った**: POP909（https://github.com/music-x-lab/POP909-Dataset ・MIT ライセンス）。プロの音楽家がポップス909曲をピアノ編曲した MIDI（旋律・副旋律・伴奏）と、和音・拍・調の注釈。**音楽の作り方を研究するために公開されたデータ**。
  - 出したのは、全曲を合わせた統計だけ（`docs/sound/data/pop909-stats.json`）。曲ごとの旋律・コードの並びは出していない・保存していない（CLAUDE.md 1-1）。データそのものもリポジトリに入れていない（測ったあと消した）。
  - 道具: `tools/audio-check/pop909-stats.py`
- **使わなかった（規約で禁止されていたため）**:
  - 日本一フリーBGM（規約の「できないこと」に「楽曲（音源ファイル）を、AI音楽モデルやデータセットの学習データとして利用すること」がある。2026-11-15 確認）。**2026-09-30 に測った1000曲の数値（`reference-nihonichi-bgm-1000.md`）を今後どう扱うかは、人間の判断が必要。**
  - 魔王魂（規約に「生成AIに魔王魂の音楽を学習させる行為はいかなる場合でも違反」「AIによる自動作曲システムなどに組み込んでフレーズや音色を再利用することを禁止」とある。2026-11-15 確認）。
- **注意**: POP909 は中国語圏のポップスのピアノ編曲で、ボカロ曲ではない。伴奏はピアノ1台なので、バンドやシンセの曲とそのまま比べられない所がある。

### 和音（今後は和音も測って使う。2026-11-15 人間の指示）

- 種類（時間の割合）: 長3和音 51%・短3和音 34%・sus2 4%・m7 4%・maj7 2%・sus4 2%・属7 1%。**3和音が 85%。sus2・sus4 が合わせて 6% ある**（自分の曲ではほとんど使っていなかった。最近の曲は逆に 7th ばかり）。
- 長調の度数: I 25%・V 21%・IV 14%・VIm 13%・IIIm 8%・IIm 8%。借りてきた和音（♭VII・♭VI・IVm）は各1%。
- 短調の度数: Im 26%・♭VII 15%・♭VI 12%・♭III 11%・IVm 9%・Vm 8%・V 6%・I 6%（同主調の長い和音で明るくする）。
- 和音の移り方は、いちばん多い「V → I」でも全体の 10%。決まった型に片寄っていない（＝同じ進行のくり返しだけで作っていない）。
- 1小節に 1.5回変わる。**2小節に1回は、小節の途中で和音が変わる。**

## 曲づくりに入れること

1. 作る前に「どこで伴奏を休ませるか」を決める。伴奏が休む時間の目安は 4〜10%。完全な無音（全員休み）を1〜4%。
2. 書いたあと、`pop909-stats.json` の幅と比べる（伴奏の休み・歌の休み・小節ごとの音の数のばらつき）。幅の外でもよいが、「わざと外した」と言えること。
3. 和音は 7th だけにしない。3和音・sus2・sus4 をまぜ、小節の途中で変える所を作る。
4. これは目安で、全曲を同じ数字にそろえるためのものではない（曲ごとに決める）。

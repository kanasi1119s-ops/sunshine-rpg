## 使ったデータと、使わなかったデータ

- **使った**: POP909（https://github.com/music-x-lab/POP909-Dataset ・MIT ライセンス）。プロの音楽家がポップス909曲をピアノ編曲した MIDI（旋律・副旋律・伴奏）と、和音・拍・調の注釈。**音楽の作り方を研究するために公開されたデータ**。
  - 出したのは、全曲を合わせた統計だけ（`docs/sound/data/pop909-stats.json`）。曲ごとの旋律・コードの並びは出していない・保存していない（CLAUDE.md 1-1）。データそのものもリポジトリに入れていない（測ったあと消した）。
  - 道具: `tools/audio-check/pop909-stats.py`
- **使わなかった（規約で禁止されていたため）**:
  - 日本一フリーBGM（規約の「できないこと」に「楽曲（音源ファイル）を、AI音楽モデルやデータセットの学習データとして利用すること」がある。2026-11-15 確認）。2026-09-30 に測った1000曲の数値（`reference-nihonichi-bgm-1000.md`）は、**人間が「9月30日までのは大丈夫です」「使って大丈夫です」と判断（2026-11-15）。そのまま使う。** これから新しく測ることはしない。
  - 魔王魂（規約に「生成AIに魔王魂の音楽を学習させる行為はいかなる場合でも違反」「AIによる自動作曲システムなどに組み込んでフレーズや音色を再利用することを禁止」とある。2026-11-15 確認）。
- **注意**: POP909 は中国語圏のポップスのピアノ編曲で、ボカロ曲ではない。伴奏はピアノ1台なので、バンドやシンセの曲とそのまま比べられない所がある。

### 和音（今後は和音も測って使う。2026-11-15 人間の指示）

- 種類（時間の割合）: 長3和音 51%・短3和音 34%・sus2 4%・m7 4%・maj7 2%・sus4 2%・属7 1%。**3和音が 85%。sus2・sus4 が合わせて 6% ある**（自分の曲ではほとんど使っていなかった。最近の曲は逆に 7th ばかり）。
- 長調の度数: I 25%・V 21%・IV 14%・VIm 13%・IIIm 8%・IIm 8%。借りてきた和音（♭VII・♭VI・IVm）は各1%。
- 短調の度数: Im 26%・♭VII 15%・♭VI 12%・♭III 11%・IVm 9%・Vm 8%・V 6%・I 6%（同主調の長い和音で明るくする）。
- 和音の移り方は、いちばん多い「V → I」でも全体の 10%。決まった型に片寄っていない（＝同じ進行のくり返しだけで作っていない）。
- 1小節に 1.5回変わる。**2小節に1回は、小節の途中で和音が変わる。**

## 曲づくりに入れること

1. 作る前に「どこで伴奏を休ませるか」を決める。伴奏が休む時間の目安は 4〜10%。完全な無音（全員休み）を1〜4%。
2. 書いたあと、`pop909-stats.json` の幅と比べる（伴奏の休み・歌の休み・小節ごとの音の数のばらつき）。幅の外でもよいが、「わざと外した」と言えること。
3. 和音は 7th だけにしない。3和音・sus2・sus4 をまぜ、小節の途中で変える所を作る。
4. これは目安で、全曲を同じ数字にそろえるためのものではない（曲ごとに決める）。

## 音の伸ばし方（2026-11-15 追加）

人間（2026-11-15）:「音の伸ばし方とかを勉強するといいかも。」

同じ POP909（909曲）で、旋律の「音の長さ・切り方・伸ばす場所」を測った（`tools/audio-check/pop909-sustain.py` → `data/pop909-sustain.json`、拍の位置は `data/pop909-onset-position.json`）。
自分の曲は `tools/vt3/sustain_check.py <曲.json>` でくらべられる。

### 分かったこと

1. **伸ばすのは句の最後。** 句の途中は短く（0.36拍）、最後だけ約5倍（1.7拍）。「短い・短い・短い・長ーい」の形。全部を同じ長さで歌わない。
2. **長い音は、拍の上から入らない方が多い。** 半分ほどは 8分か16分のウラから食って入り、小節線や拍をまたいで伸びる。自分の曲は 12・14・15 で 0% だった（いつも拍の上で伸ばしはじめる）。これが「曲調が同じ」に聞こえる原因の1つ。
3. **伸ばしすぎない。** 4拍以上の音はほとんどない。いちばん長い音でも 3.75拍。
4. **音を次の音までいっぱいに伸ばさない。** プロは次の音の前に4分の1ほどすき間を空ける（ピアノの演奏なので、歌はもう少しつながる）。自分の歌は全部 100% で、切れ目がなかった。
5. **歌が伸ばしている間、伴奏は動く。** 伴奏は平均 0.6拍の音で動き、歌の長い音の下で止まらない。
6. 伴奏は、16分より短い音ばかり（15 は 47%）にも、小節まるごとの長い音ばかりにもしない。0.5〜0.75拍の音が中心。

### 注意

- POP909 の旋律は歌ではなくピアノで弾いたもの。「切り方」（4）は、歌ではもっとつながるのがふつう。楽器の旋律（リード・プラック）に当てはめる方が合う。
- 歌の長い音の「中身」（ビブラートをいつからかけるか・音量をどう変えるか・終わりの抜き方）は MIDI では分からないので、今回は測れていない。今の歌声は、2拍以上の音の後ろ半分にビブラート、句の終わりで力を抜く、という設定のまま。

### 15 に入れたこと（v10）

- 句の最後を、8分のウラから食って入って2拍のばす形にした（サビの2小節目・4小節目、Aメロの答えの小節）。句の最後が2拍以上: 14% → 52%。長い音の割合: 8% → 28%。
- 長い音がウラから入る割合は 0% → 78%（プロの幅より多い。この曲の特徴として、わざと多くした）。
- Aメロの早口に、16分の切れ目を1つ入れた。

# ギターを自然に鳴らす決まり（2026-10-14、人間の指摘で調べてまとめた・仮）

人間の指摘: 単音ギターが電子音に聞こえる／刻みが「ダッダッダッ」と不自然に切れる／弾いた直後の短いミュートはだめ。

## 直したこと
- **音の伸ばし方**: 実際のギターは、はじいた弦が次にはじくまで鳴り続ける。`strum.ring`（既定 入）で、弦ごとに「次にその弦を打つ直前まで」（最長 `ringMax` 2拍）鳴らす。`ring:false` で従来。
- **音源のリリース**: 上書き用ギターSF3は、プリセット側の「リリース×0.3」が残って実効 0.1秒だった。`tools/soundfont/fix-guitar-release.mjs` で実効 0.55秒にそろえた（build-guitar*.mjs も 0.55 に）。
- **パームミュート `m`**: 0.25拍に固定。ふつうに伸ばした直後には混ぜず、ミュートはブロックごと（1小節以上）にまとめる。
- **強さ**: 1拍目を強く、アップは弱く、アップは高い弦だけで速く（ずれを65%に）。
- **コーラス**: ギターの標準コーラス（20）をやめた。コーラスは曲ごとに `chorus` で指定する。

## 使い分け
- エコー（delay）はリード・ソロ・アルペジオだけ。ストロークにはかけない。
- 歌うメロディやソロは、単音ギターに弾かせず、録音音源のトランペット・ピアノなどに任せる（単音ギターは電子音に聞こえやすい）。
- 聞いた感想は人間の耳が決める。この文書の効果は未確認（仮）。

## ドラムを単調にしない決まり（人間の指摘、2026-10-14）
- セクション種類ごとに1つの型を使い回さない。キック・スネア・ハイハットは数種類の型から小節ごとに選び、4小節・8小節の終わりにフィル（タム）を入れる。
- 一つ前の小節と同じ型を続けない。サビは回を重ねるごとに強く（オープンハイハット、キックの手数）。プリ（Bメロ）は小節ごとにスネアを細かくして盛り上げる。ブリッジは半拍子ふう。
- 見本: `assets-src/ai-songs/_gen/summer-rock3.py` の `varied_drums()`（80小節でキック19種・スネア22種）。
- ロックらしさ: 歪みギターを主役に左右へ振って重ね、ドラム・ベースを前に出す。歪みは録音ギター＋アンプ（loudrock）。

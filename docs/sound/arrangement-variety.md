# 展開を曲ごとに変える（学んだことの記録）（2026-10-23）

ラウド26曲（lm25）を作る途中で、人間（旭さん）から受けた指摘と、それに答えるために作った道具・決まりごとをまとめる。
**次に曲を作るときは、この記録を読んでから設計する**（`.claude/skills/compose-song/SKILL.md` の 2.6）。

## 1. 人間の指摘（そのままの言葉の要点・時刻順）

| 指摘 | 何がだめだったか |

| 「サビから始まる曲」「前奏から」「同じギターリフで、展開がリードだけで変わる」「ドラムから・ベースから始まる」「最後イントロがゆっくりフェードアウト」 | 始まり方・終わり方が毎回同じだった |
| 「オリジナル性をだして」 | |

## 2. 決まりごと（これからの曲すべて）

1. **曲ごとに「展開の型」を先に決める**。同じシリーズ（アルバム）の中で、同じ型は2曲まで。型の例:
   ロンド（同じ看板に何度も戻る）／転調の階段（上る・下る）／積み上げ（1つの楽器から嵐へ）／沈黙が主役（全休止・1小節の無音）／
   ブレイクダウン中心／二部構成（賛美歌→重い曲、テンポも変える）／逆さ構成（最後のサビから始まり、だんだん消える）／
   加速（区間ごとにテンポが上がる）・沈む（下がる）／一本道（同じ区間をそのままくり返さない）／三部構成（突撃・休戦・再突撃）／
   かけ合い（2つの楽器が交代。交代をだんだん短くするストレッタ）／クラブのドロップ型（ループ→助走→空白→ドロップ）／
   アーチ形式（真ん中を山に鏡のように戻る）／回想形式（終わりの場面から始まり、過去へ行って戻る）／ボレロ型（同じテーマを、楽器を足しながらくり返す）／
   人生を巻き戻す／演目のメドレー（場面ごとにドラムの感じが変わる）／離陸・巡航・着陸（テンポの山）／場面転換の物語／壊れていく変奏／
   溜めて最後に一度だけ解放／時刻の組曲。
2. **始まり方と終わり方を曲ごとに変える**。始まり: サビから・ドラムだけ・ベースだけ・追加の楽器だけ・心臓の音・スネアの行進・前奏のリフ。
   終わり: フェードアウト・ピタッと止める・1つの楽器だけ残る・途中で途切れる・だんだん遅くなる・笑い声で切れる。
3. **ドラムは学んだフレーズ集から区間ごとに選ぶ**（`lm25_lib.lib_section` ← `loud25_drums.Library.fit`）。4・8小節目のフィル、小節ごとに変わるキック・スネア・ハット、
   ゴースト、ライド・タム。ハーフタイム・倍の速さの感じ・シャッフル・ライド・タム入り・静かな型を区間で選ぶ。
   手で作る型も混ぜる: タムの太鼓（tribal）・4つ打ち（kick4）・スネアがだんだん細かくなる助走（build）・心臓の音（heart）・ドラムソロ（solo）・全員の決め（kime）・最後の半小節で止める（stop）。
   4拍子以外の曲は、フレーズ集の小節を「4拍＋次の小節の頭」で拍子に合わせる（小節の頭はそろえる）。
4. **ギターとベースの弾き方を変えるかどうかは、曲の物語で決める（決まりにしない）**。人間「必ず弾き方が変わる必要性があるわけじゃない。柔軟に」。曲ごとに keep（看板のリフを最後まで守り、変化は旋律・ドラム・強弱で。螺旋・クラブのループ・ボレロ・アーチ・沈黙）／rare（ここぞの1〜2か所だけ）／often（場面ごとにどんどん。演目・時刻・場面転換・人生）を選ぶ（`lm25_plans.PHR_POLICY`）。変えるときは、同じ区間の2回目以降を **フレーズ集の別の型**（`lm25_lib.lib_guitar_bass` ← `loud25_phrases.pick_pair`）。
   実演（GuitarSet）の伴奏は経過音が多くパワーコードで濁るので、リズムギターには自作の型だけを使う。和楽器の都節（E と F）のように、わざとの半音は残してよいが、長く重なる所は元のリフに戻す。
5. **追加の楽器は雰囲気の主役**。和楽器は +8dB、ほかの追加の楽器は +6dB、空気の層などの重ねは +4.6dB。追加の楽器が旋律を弾く小節は、リフ・リズムのギターを弱く弾く（場所をゆずる）。
   旋律を追加の楽器に渡す区間（give）も作る（馬頭琴・サックス・バグパイプ・フィドル・三味線がサビやAメロを歌う）。
6. **場面ごとの強弱**（`lm25_lib.section_dynamics`）: Aメロ・前奏・ブリッジ・終わりは弱く、サビ・ソロ・ブレイクダウンは強く、Bメロはだんだん強く、区間の最後の小節は次へ向けて少し強く。拍の頭を立て、裏は少し抜く。
7. **長さは 4〜5分**（テンポの変化を入れて計算する。`song_seconds`）。
9. **曲名はゲームの曲名にしない**（人間「曲名もなんかゲームの曲名だよね。そのイメージも取っ払って」）。「〇〇の〇〇」（名詞＋の＋名詞）の形を続けない。英語の短い言い切り・長い一文・漢字の熟語・日本語の命令や言い切りなど、その曲の物語の一瞬を切り取る。有名な曲名・アルバム名と同じにしない。
8. **決まりごとを崩す**: 1曲に1つ以上、ジャンルの決まりごとをわざと外す所を作り、設計に「どれを崩したか」を書く（下の表の「崩したこと」）。決まりごとは床であって天井ではない。

## 3. 道具（`assets-src/ai-songs/_gen/`）

| 道具 | 使い方 |
|---|---|
| `lm25_lib.rearrange`（`song.plan`） | 曲のファイルで作った小節を材料に、区間を並べかえる。`(新しい区間の名前, もとの区間 or (区間, 始め, 終わり), {しかけ})`。しかけ: kind・keep・drop・semi（転調）・drums・bpm（テンポ。(数, 何小節かけて)）・give（旋律を別の楽器へ）・soft・hold・oct・from（stopBeat など）・kime（全員の決め）・stop・bed（同じリフを敷き続ける）・phr（フレーズ集のギター・ベース）・dyn・energy・fills |
| `lm25_plans.py` | 26曲の展開の型（`PLANS`）・説明（`DESC`）・フェード（`FADE`）・調（`KEYS`） |
| `song.fade_in` / `song.fade_out` | 秒。`<json>.fade` に書き、`lm25_render.sh` が書き出しのあとに WAV へかける |
| `feature_extras` / `section_dynamics` | 追加の楽器を前に・場面ごとの強弱（`to_json` の中で自動） |

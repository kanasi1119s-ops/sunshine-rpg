# モンスタードット絵224体（DLsite 販売の準備）

2026-10-07、人間の指示「モンスタードット絵をまとめて販売できるように。ボスとモンスター両方」「DLサイトで売ろうか」で準備を始めた。
決めたこと: DLsite で売る／雑魚200体とボス24体を **1パック** にまとめる／等倍・2倍・4倍を入れる。

> **ここまでは「売るファイルと文章の下書き」だけ。** サークル登録・作品登録・価格設定・公開は、CLAUDE.md 1-2 のとおり人間（旭さん）が行う（または承認のあとで行う）。

## 作り方

```
python3 tools/sales/build_monster_pack.py 出力フォルダ
```

- 絵は各敵の `final.txt / final.json`（ドット絵エディタで描いた最終版）から、背景が透明な PNG を作る。拡大は最近傍（にじみ無し）。
- ボスの名前は、物語の謎とつながらないよう、販売用の名前（`tools/sales/boss_names.json`）にする。雑魚の名前はゲームと同じ（ゲームの場所の名前を含むものもある）。
- 中に入れる説明書・利用規約: `tools/sales/monster-pack-README.txt`（下書き）。

パックの中身:

| フォルダ | 中身 |
|---|---|
| `雑魚_96px/1倍・2倍・4倍/` | 雑魚200体 `mob_001〜mob_200.png`（96×96・26色以内） |
| `ボス_256px/1倍・2倍・4倍/` | ボス24体 `boss_01〜boss_24.png`（256×256・62色以内） |
| `一覧/` | 一覧画像（雑魚50体ずつ4枚、ボス1枚）。販売ページの見本にも使える |
| `一覧.csv` | 番号・種類・参考名・大きさ・色数 |
| `はじめにお読みください.txt` | 中身・制作方法（AIの使用）・利用規約 |

容量は約9MB（PNG 672枚＋一覧画像5枚）。

## DLsite で確かめること・設定すること（調べた内容。公式の最新の案内で必ず確認する）

- **AIの申告**: DLsite は「AI生成作品」「AI一部利用」の区分を設けていて、AIを使った作品はどちらかを選び、作品の説明に **AIをどこにどれだけ使ったか** を書くことが求められる（2022-11-30 の告知）。このパックは下絵がAIなので **「AI生成作品」**。
- **AI生成フロア**: 2024年2月から、AI生成作品は「AI生成フロア」で扱われ、**1サークルあたり月2作品まで**（2024-02-19 の報道。その後「月3作品」とする解説もあり、要確認）。このパックは1作品として出す。
- **AI生成作品の取り扱いの再確認**: 2023年5月に「マンガ・CG・動画・素材集」のAI生成作品の販売が一時停止された経緯がある。2024年2月の再開で「すべてのAI生成作品」が対象になったと報じられているが、**素材（画像素材）として出せるかは、サークル登録の前に DLsite の公式ヘルプで確認する**。
- **枚数の上限**: 「差分込み500枚まで」という上限を挙げる解説がある（CG集の話の可能性）。このパックは PNG が672枚あるので、素材でも当てはまるなら、2倍・4倍をまとめる（ZIPの中のZIPにする等）か、倍率を減らす必要がある。**要確認**。
- 作品の形式: 素材（画像素材）。全年齢。
- 見本画像: `一覧/` の画像を使う（DLsite の見本画像の大きさの決まりに合わせて切り出す）。

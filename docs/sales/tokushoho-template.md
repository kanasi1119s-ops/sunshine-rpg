# 特定商取引法に基づく表記（ひな形）

> 日本で、インターネットでソフトを売るときに、販売ページに出す必要がある表記のひな形です。【 】を埋めてください。
> BOOTH などの販売サイトでは、サイトの決まり（住所・電話番号を請求があれば開示する形にできる、など）に合わせてください。専門家への確認をおすすめします。

| 項目 | 内容 |
|---|---|
| 販売業者 | 【サンシャインソフトウェア（屋号）】 |
| 運営責任者 | 【氏名】 |
| 所在地 | 【住所】（請求があれば遅滞なく開示します、とする方法もあります） |
| 電話番号 | 【電話番号】（同上） |
| メールアドレス | 【メールアドレス】 |
| 販売価格 | 各商品ページに表示（消費税込み） |
| 商品代金以外の必要料金 | インターネットの通信料。AI作曲の機能を使う場合、Anthropic 社のAPI利用料（利用者のAPIキーに請求） |
| 支払方法 | 【販売サイトの支払方法】 |
| 支払時期 | 【購入時】 |
| 商品の引渡時期 | 決済が終わったあと、すぐにダウンロードできます |
| 返品・返金 | デジタル商品のため、原則として購入後の返品・返金はできません。【動作しない場合の扱い・販売サイトの決まり】 |
| 動作環境 | Windows 10 以降（64ビット）／macOS 【12】以降／Linux（AppImage）。MIDIキーボード・オーディオインターフェースは任意 |

# インストールの案内（購入者向け・案）

## Windows
1. ダウンロードした「Sunshine Composer Setup ○.○.○.exe」を開きます。
2. 【署名なしの場合】青い画面「WindowsによってPCが保護されました」が出たら、「詳細情報」を押し、「実行」を押します。
3. 利用規約を読み、「同意する」を押して、画面の案内どおりに進めます。
4. インストールが終わると、スタートメニューに「サンシャイン作曲ソフト」が入ります。

## Mac
1. ダウンロードした「Sunshine Composer-○.○.○.dmg」を開き、アプリを「アプリケーション」フォルダへ入れます。
2. 【署名・公証なしの場合】「開発元を確認できないため開けません」と出たら、「システム設定」→「プライバシーとセキュリティ」の下のほうにある「このまま開く」を押します。

## はじめて使うとき
- 録音やMIDIキーボードを使うときは、「使う」「つなぐ」を押したときに、マイク（音の入力）の許可を求められます。許可してください。
- AI作曲を使うときは、「AIに作曲してもらう」に、Anthropic のAPIキーを入れて「キーを保存」を押します（https://console.anthropic.com で作れます。使った分だけ料金がかかります）。

## 困ったとき
- 音が出ないとき: パソコンの音量と、画面右上の「マスター音量」を確かめてください。
- 保存した曲は、「プロジェクト」の形（.sunshine-song.json）で保存すると、あとで続きを編集できます。

# 遊び方（現時点の仮の説明書）

まだ制作の初期段階です。ここでは、いま動かせる範囲の操作方法だけを説明します。
物語・町・戦闘などが増えるたびに、この説明書も更新していきます。

## 起動方法

```bash
npm install
npm run dev
```

表示されたURL（例: `http://localhost:5173`）をブラウザで開いてください。

## 操作方法

### PC（キーボード）

| 操作 | キー |
|---|---|
| 歩く | 矢印キー または `W` `A` `S` `D` |
| 決定・話しかける・会話を進める | `Enter` または `Space` または `Z` |
| 会話の選択肢を選ぶ | 上下キーで選び、決定キーで確定 |

### スマホ・タブレット

- 画面左下の十字ボタンで歩く
- 画面右下の「決定」ボタンで、話しかける・会話を進める・選択肢を確定する

## いま遊べる内容

- 動作確認用の仮のマップ（原っぱと、木の扉から入れる小さな部屋）を歩き回れます
- 部屋の中の人物に話しかけると、簡単な会話と選択肢を試せます
- マップ・人物の見た目はまだ単色の四角です（ドット絵は後日、制作方針に沿って作成します）
- 町・ダンジョン・戦闘・セーブなどの本編要素はまだありません

## よくある質問

**Q. 音が鳴らないのはなぜ？**
BGM・効果音の仕組みはまだ実装していません（今後の工程で追加します）。

**Q. スマホの十字ボタンが反応しない**
ボタンを指で押している間だけ移動します。離すと止まります。

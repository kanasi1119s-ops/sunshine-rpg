# 遊び方（現時点の仮の説明書）

まだ制作の初期段階です。ここでは、いま動かせる範囲の操作方法だけを説明します。
物語・町・戦闘などが増えるたびに、この説明書も更新していきます。

## 起動方法

```bash
npm install
npm run dev
```

表示されたURL（例: `http://localhost:5173`）をブラウザで開いてください。

## 操作方法

### PC（キーボード）

| 操作 | キー |
|---|---|
| 歩く | 矢印キー または `W` `A` `S` `D` |
| 決定・話しかける・会話を進める | `Enter` または `Space` または `Z` |
| 会話の選択肢を選ぶ | 上下キーで選び、決定キーで確定 |

### スマホ・タブレット

- 画面左下の十字ボタンで歩く
- 画面右下の「決定」ボタンで、話しかける・会話を進める・選択肢を確定する

### 開発確認用のキー（PCのみ。正式なメニュー画面ができるまでの仮の操作）

マップを切り替えたときと、戦闘に勝ったときには自動で「オートセーブ」枠に保存されます（これは本番でも動きます）。下のキーは、正式なタイトル画面・メニュー画面ができるまでの動作確認用です。

| 操作 | キー |
|---|---|
| 仮の戦闘を試す | `B` |
| スロット1にセーブ | `K` |
| スロット1から読み込み | `L` |
| セーブデータをファイルに書き出す | `J` |
| ファイルからセーブデータを読み込む | `U` |
| デバッグメニューを開く・閉じる | `` ` ``（バッククォート） |

デバッグメニューでは、マップへのワープ・レベル変更・無敵・エンカウントなし・フラグ全クリアを試せます（上下キーで選び、決定キーで実行）。本番用にビルドすると自動的に取り除かれ、遊ぶ人には見えません。

### 音について

- 何か操作すると（矢印キーを押す、画面をタップするなど）BGMが鳴りはじめます。ブラウザの決まりで、操作するまでは音を出せません
- `M` キーで音のオン・オフを切り替えられます
- 序章の町・町外れ・ボス戦には、それぞれ専用のBGMがつきました（`docs/sound/tracks.md`）。第1章（麦香野）はまだ専用曲がなく、序章の曲を仮に流用しています
- 決定・カーソル移動・扉の出入り・勝利・全滅の効果音がついています。攻撃・ダメージの効果音は作成済みですが未接続です

## いま遊べる内容

- 序章の舞台、港町・灯里を歩き回れます。灯りの相談所灯里支部の中に入って、支部長カセンや先輩調査員レトと話せます
- カセンから依頼を受けると、町外れ（歪みの発生地点）へ行けるようになります。歪みに話しかけると戦闘になります
- 歪みを倒すと、現場の調査・カセンへの報告・レトの仲間加入まで進みます。現場の調査で手がかりを見つけた後にレトへ話しかけると、簡単な推理クイズが出ます（正解しなくても物語は先に進みます）
- レトが仲間になると、以後の戦闘に実際に参加します（複数人パーティ対応）。専用のとくぎ「見切りの一撃」を使います
- 灯里の東の街道から、第1章の舞台・麦香野の村へ進めます。村長に水路の水が涸れた相談をされ、依頼を受けると水源（北の道の先）を調査できます
- 水源の歪みを倒し、採掘跡（伏線）を見つけたうえで村長に報告すると、村の水路が元に戻ります。その後、村の子ミナが仲間に加わり、水紋系のとくぎ「水紋ノ波」で戦闘に参加します
- ミナが仲間になった直後、もう一度話しかけると、「歪み」の話題にミナが表情を曇らせる場面があります（今後の章につながる伏線）
- 町の人の会話は、依頼を受ける前・受けた後・歪みを倒した後で内容が変わります
- 主要キャラクター（ユーリ・レト・ミナ・カセンなど）が話すとき、会話欄に顔グラフィック（ドット絵、陰影つき）が表示されます。マップ上でも、ユーリと顔グラフィックが登録済みのNPC（カセン・レト・ミナ）は同じドット絵で表示されます。名前の無い町の人や、まだ物語に登場していないキャラクターは、引き続き単色の四角のままです
- ユーリが歩いている間、簡単な足踏みアニメーションがつきます
- 地面・壁などのタイルには、隅の陰影と斑点模様で簡単な質感をつけています。まだ単色べた塗りの延長ですが、平坦な印象を減らしています
- 戦闘の敵（序章「灯里の歪み」・第1章「水涸れの歪み」）は、いびつな塊のようなドット絵で表示されます。動作確認用の仮の敵はまだ単色の四角です
- 草・水・道・木のタイルには、手続き的なドット絵の模様（草の茂み、水の波、道の踏み跡、木の樹冠と幹）がついています。壁・岩・橋など、それ以外のタイルはまだ単色＋質感付けのままです
- 開発確認用のキーで、仮の戦闘・セーブ・ロードを試せます（上の表を参照）。デバッグメニューから麦香野の村・水源にも直接ワープできます
- 第5章（霧断崖）までを遊べます。砂音の東の街道から霧断崖へ進めます。第6章より先はまだありません

## よくある質問

**Q. 音が鳴らないのはなぜ？**
何か操作する（矢印キーを押す、画面をタップする）までは鳴りません。ブラウザの決まりです。

**Q. スマホの十字ボタンが反応しない**
ボタンを指で押している間だけ移動します。離すと止まります。

## 開発者向け: BGMプレイヤー

`node tools/bgm-player/build.mjs` で、ゲームの全BGM・効果音を聴ける1ファイルのHTML（`dist-bgm-player/index.html`）を作れる。再生エンジンと曲データはゲーム本体と同じものを使う。音が出る環境がない場所（クラウドの作業環境など）で作った曲を、人間が聴き比べるために使う。

## BGMの音の版（開発者向け）

既定は現代的な音です。ゲームのURLの最後に `?edition=ps2` をつけて開くと、PS2世代のサウンド版（弦の重ね・ホール残響）でBGMが鳴ります。合成音だけで聴き比べたいときは `?synth` です。

## サンシャイン作曲ソフト（開発者向け）

`node tools/composer/build.mjs` で、1ファイルのHTML（`dist-composer/index.html`）を作れる。パソコンのブラウザで開くだけで使える（インストール不要）。

- **自動作曲**: 曲調（20種類）・調・長調/短調・テンポ・乱数の種・長さ・拍子を選んで作曲。ボス戦向けの疾走感も選べる。3〜4分の「特別曲」の型（ラスボス・裏ボス・八神・運命の扉・難関ボスなど）も作れる。
- **実楽器の音で試聴**: ゲームと同じ再生エンジン（録音音源・ギターアンプ・ドラムの仕上げ）。サウンドは「現代的／PS2世代／実楽器」を切り替え。再生・一時停止・位置の移動。
- **手直し**: トラックごとの楽器・音量・左右の位置・ミュート・ソロ、トラックの追加と削除。ピアノロールで、クリックして音を足す、音の上をクリックして消す（足すと、その音が鳴る）。
- **書き出し**: MIDI（いま選んでいるサウンドの編成）、プロジェクト（`.sunshine-song.json`。あとで読み込んで続きを編集できる）。このブラウザにも自動保存する。
- **音の長さを変える**: 音の右はしをドラッグ（クリックの間隔にそろう）。
- **WAVで書き出す**: 曲の頭から1周ぶん（＋余韻2.5秒）を、実時間より速く（オフラインで）描き出してWAV（16ビット・ステレオ・44.1kHz）にする。37秒の曲なら5秒ほど。音の山は -1dB ほどにそろえる。
- **和音で足す**: 「和音で足す」でメジャー・マイナー・パワーコードなどを選んでクリックすると、根音をいまのトラックに、ほかの音をすぐ下の同じ楽器のトラック（足りなければ自動で作る）に入れる。相手のトラックの音はピアノロールにうすく出る。和音の上をクリックすると、和音ごと消える。
- **複数の音を選ぶ**: 道具を「選択」にして、ドラッグで囲む（Shiftで追加）か、音をクリック。選んだ音はドラッグで移動。キー操作: Delete（消す）、←→（クリックの間隔ぶん移動）、↑↓（半音。Shiftで1オクターブ）、Ctrl+C／Ctrl+V（コピー／貼り付け）、Ctrl+D（すぐ後ろに複製）、Ctrl+A（すべて）、Esc（選ぶのをやめる）。ボタンでも同じことができ、「長さをそろえる」もある。
- **ゲームの曲として登録**: 曲ID（英小文字・数字・`-`）と使う場面を入れて「登録用ファイルを書き出す」→ できた `〇〇.sunshine-song.json` を `src/audio/songs/` に置くと、ゲームの曲一覧（`allEntries()`。BGMプレイヤーにも出る）に入る。鳴らす場面は、ゲーム側の `bgmId` にそのIDを書いて決める。NAMモデルはゲームには入らない。
- **新しい曲**: コード進行（例 `Am F C G`）・テンポ・拍子・雰囲気（ロック／ポップ／バラード）から、ドラム・ベース・ギター・ピアノ・弦の伴奏を作り、空のメロディのトラックを足す（`src/audio/newsong.ts`）。あとはピアノロールでメロディを書く。
- **音づくり（アンプ）**: トラックごとに、アンプの種類（クリーン／オーバードライブ／ディストーション／メタルゾーン／PRS風）・歪みの深さ・高音の明るさ・出力を変えられる。無料のアンプシミュレーター NAM（Neural Amp Modeler）も入っていて、同梱のモデル3つ（ハイゲインアンプA・B、ベース用プリアンプ。NAM作者がMITライセンスで公開している見本）から選ぶか、`.nam` モデルを読み込むと、そのアンプの音になる（読み込むモデルの利用規約は利用者が確認する）。
- **Claude Code から曲を作る（APIキー不要）**: Claude Code に「〇〇な曲を作って」と頼む（`/compose-song`）。Claude Code が「AIソング形式」のJSON（`assets-src/ai-songs/`）を書き、`node tools/composer/song.mjs build <曲.json> --wav` で、作曲ソフトのプロジェクト・MIDI・WAV（`dist-songs/`）を作る。`--register <曲ID> --scene "<場面>"` でゲームの曲として登録。形式の説明は `node tools/composer/song.mjs guide`、組み立ては `src/audio/ai-song.ts`。
- **曲を開く・1から作る**: ゲームの全曲（57曲＋登録した曲）を開いて手直しできる（ゲームの元の曲は変わらない）。1から作るときは、拍子（上 1〜32 ／下 1・2・4・8・16・32。例 7/8・5/4・13/16）・テンポ・小節の数・はじめの編成（1トラック・ピアノ・バンド・オーケストラ・電子音楽）を選ぶ。今の曲の拍子とテンポも変えられる。ピアノロールには、拍子どおりの小節線と小節番号が出る。
- **ファイルを開く**: 作曲ソフトのプロジェクト・ゲームの曲・AIソング形式・MIDI（`.mid`。和音は同じ楽器の複数トラックに分ける。テンポと拍子も読む）・アンプ定義。
- **MIDIキーボード**: 「つなぐ」で USB の MIDIキーボードを使う（Chrome・Edge・デスクトップ版）。ステップ入力（止めたまま1音ずつ。「足す音の長さ」ずつ進む）とリアルタイム録音（再生しながら弾く。「クリックの間隔」にそろえる）。和音で弾くと、すぐ下の同じ楽器のトラックに分けて入る。
- **書き出し（保存の形式）**: 音声は WAV（16・24ビット、32ビット小数）・FLAC（音質そのまま）・Ogg Opus（とても小さい）。データは MIDI・MusicXML（楽譜ソフト向け。小節線をまたぐ音はタイ）・CSV（音の一覧）・プロジェクト。デスクトップ版は「名前を付けて保存」、Chrome・Edge は保存先を選ぶ画面で保存する。
- **アンプの追加**: 「音づくり」の「追加したアンプ」で、アンプ定義ファイル（`.sunshine-amp.json`）やキャビネットIR（`.wav`）を読み込める。ほかのアンプシミュレーターを自由に組み込むための形。書き方は `docs/design/amp-plugins.md`。ジャンル別アンプ（14種: クリーン〜ラジオ）も選べる。
- **デスクトップ版（ダウンロードして使う）**: `desktop/`。`cd desktop && npm install && npm start` で起動、`npm run dist:win`（Windows）・`dist:mac`・`dist:linux` でインストーラーを作る（Windows のインストーラーは Windows か GitHub Actions の「desktop」で作る）。AI作曲は、利用者の Anthropic APIキーを、本体の側でOSの機能を使って暗号化して保存し、画面には渡さない。
- **コネクタ（MCPサーバー）**: `tools/mcp/server.mjs`。このリポジトリを Claude Code で開くと自動で使える（`.mcp.json`）。道具: 曲の書き方（song_guide）・曲を作る（compose_song）・ゲームへの登録・ゲームの曲の一覧・作曲ソフトの場所。Claude デスクトップで使うときは、設定の MCP サーバーに `node <このリポジトリ>/tools/mcp/server.mjs` を足す。
- 1つのトラックは1度に1音だけ鳴る（和音はトラックを重ねる）。編集の道具は `src/audio/edit.ts`（自動テストあり）。

# ドット絵のトレース練習ログ（6時間）

2026-10-03、人間の指示（「参考画像・参考ドット絵をトレースして、ドット絵エディタで学習する。6時間たつまで終わらない」）で行ったトレース練習の記録。開始 12:21（日本時間）。
- 道具: `tools/pixel-practice/prep-trace.py`（参考画像→文字グリッド）、`trace-batch.sh`（エディタで下絵つきにトレース。食い違い0マスを確認）、`analyze.py`（色づかいを数字にする）、`sheet.py`（一覧画像）
- トレースは、参考の絵を**エディタの下絵（薄く表示）に読み込み、1ドットずつマウスで写す**。トレース結果は `assets-src/pixel-practice/trace/`（参考素材は `assets-src/pixel-reference/` の無料素材。**練習の写しはゲームに入れない**）
- 各回で、(1)一覧画像を見て、(2)色づかいを数字で測り、(3)分かった技法を書き、(4)次の自作に生かす

## 第1批（12点: アイコン・食べ物・武器・防具・宝石）
トレース: 靴・指輪・ニンジン・ブドウ・宝箱・クローバー・ダイヤ・試験管・矢・火の玉・斧・剣。すべてエディタで食い違い0マス。
測って分かったこと:
- **外周は100%、ほぼ黒（明度L 0〜0.15）の1ドット輪郭**（12点中11点）。例外はダイヤで、外が白・内が黒の二重線（光る物を白縁で目立たせる）
- **色数は5〜11色**。食べ物・クローバーは5〜8色、金属・光る物は10〜11色
- **金属（剣・斧・靴・指輪・矢）は、影も光も青みの灰色（色相255〜260°、彩度0.1〜0.2）**。彩度を抑えた青灰色を明度だけで5段に分けている。剣は純粋な灰（彩度0）で、白→灰→暗灰の5段
- **食べ物は、光が黄寄り・影が赤寄り**。ニンジンは影H24°（赤橙）→光H33°（黄橙）、宝箱も影H21〜23→光H32。葉は緑H77で、明暗は彩度（S0.54→0.87）で付ける
- **ブドウ（紫）は、光が青寄り**（影H257°→光H248°）。寒色は光が青側へ、暖色は光が黄側へずれる（色相が、明るい色ほど「明るい色の側」へ動く）
- **火は、暗い所が赤（H14°）、明るい所が黄（H39°）**で、彩度は常に高い（0.9以上）。炎の中の岩（黒い塊）は、明度0.39〜0.54の彩度の低い灰
- **宝箱・斧の柄・ブドウの粒など、丸い物は「左上が明るい点（ハイライト）＋右下が暗い帯」**。ハイライトは1〜3ドットの塊で置く
- 次の自作に生かす: 金属は青灰色5段（彩度を抑える）、食べ物は影を赤寄り・光を黄寄り、外周は1ドットの黒に近い暗色

## 第2批（24点: 防具・装身具・金属・食べ物・大砲）
測って分かったこと:
- **金属の色は、どのアイコンでも同じ5段を使い回している**。色相260°・彩度0.07〜0.20、明度は 1.00 / 0.82 / 0.64 / 0.50 / 0.36 の約0.15〜0.18刻み（金属の素材3点・大砲・兜・盾に共通）。**素材ごとにランプ（色の並び）を1つ決めて、使い回す**と、持ち物が並んだときに質感がそろう。金属に影の色相ずらしは無く、一定の青灰色
- **金は、色相39〜54°・彩度ほぼ1.0**の黄〜橙。明度0.50 / 0.53 / 0.72 / 0.93 の4段。ハイライトは白に近い黄（L0.93〜0.97）。金は彩度が高いまま明度だけ動く
- **赤い防具・靴は、色相11°（赤橙）で彩度0.7〜0.9、明度0.23〜0.56の暗めの段、ハイライトだけ色相39°（黄橙）**。光だけ黄にずらす
- **果物**: レモンは「ほぼ1色（彩度1.0・色相46〜53°）＋小さな明るい粒」で、**ランプではなく粒（ドットの散らし）で質感**を出す。洋梨は色相77〜95°を彩度で段にする。スイカは果肉H352°（ピンク）・皮H120°（彩度0.25〜0.37のくすんだ緑）で、皮だけ彩度を落とす
- **大きな面（盾・兜・鎧・砂・肉）には、市松の細かい模様（ディザ）で2段の間をなじませる**。盾の丸みは、面を4等分して明度を変え、リベットは1ドットの明点と暗点
- **縁取りの色**: ほとんど黒（L<0.02）だが、靴は少し明るい青灰（L0.15）。2素材が接する所は、縁取りを引かずに明度差だけで分ける例もある（ネックレスの鎖は白い縁取り）
- **二重の素材（金＋金属、革＋金属）は、素材ごとに別のランプ**で塗り、境目に暗い線を引く
- 次の自作に生かす: 盾（金属5段を使い回し、紋は金4段）、果物（粒で質感）、食材の色相は影を赤・光を黄へ

## 第3批（24点: 特技・状態のアイコン、矢、薬びん、道具）
測って分かったこと:
- **状態・強化のアイコン（人型の影）は、色が4〜5色だけ**（buff06は4色）。人の形のシルエットを暗く（L0.10）塗り、**縁に1〜3ドットの色つきの光の輪**（オレンジ・紫・水色）を付けて、効果の種類を伝える。輪郭が黒ではなく暗い灰紫（L0.10）なのが、「光っている」感じを出す
- **爆発・炎・雷は、とがった星形（スパイク）で、橙H20°→黄H46°の彩度1.0のランプ**（明度0.42 / 0.60 / 0.72 / 0.90の4段）。中心を最も明るく、外へ向かって暗く。矢や剣の「勢い」は、物の背後にこの星形を置くだけで出る
- **薬びんは、びんの形を使い回し、中身の色だけ変えている**（紫H284・緑H108・黄H46・ピンクなど）。ガラスは共通の色相215°・彩度0.44〜0.64・明度0.84〜0.92＋白のハイライト。13×31の細長い形で、中身には市松（ディザ）で濃淡
- **宝石（サファイア）は二重の縁**（外が白、内が黒）。面は2〜3段で、面の間にディザ。光る物の縁を白にすると、暗い背景から浮く
- **氷の呪文は色相197〜231°・彩度0.4〜0.7**を5〜6色。白いハイライトを2〜3か所の斜めの短い線で置く
- **薪（たいまつ）・毛皮・巻物は、くすんだ暖色（彩度0.2〜0.8）を5色**で、素材感はドットの散らしと縁のぎざぎざで出す（毛皮は縁が毛束のぎざぎざ、巻物は端がめくれる）
- **岩は、青灰（色相259〜262°・彩度0.1）に、青い結晶の小さな差し色（H229°）**を2か所だけ置く。差し色が少量だと目を引く
- 次に生かす: 薬びんの型（ガラス色は共通、中身だけ差し替え）をゲームのアイテム用アイコンとして作る、状態アイコン（人型の影＋色つきの縁）を状態異常の表示に使える

## 第4批（22点: 1ビット（2色）の魔物・人物、アリ、フード、カエル、ランプ、ヘビ）
測って分かったこと:
- **1ビット絵（白と黒の2色だけ）の12点は、全部「黒い大きな塊の上に、白い線で細部を描く」**。顔は白い面に黒で目・口を抜き、武器と盾は**白い輪郭線**（中は黒）、足は白い小さな塊。2色でも、**白は「見せたい所」にだけ使い、体は黒でつぶす**と、種類（骸骨・オーク・カボチャ・吸血鬼）が読める。形で見分けさせる練習になる
- 同じ体型（肩幅の広い黒い塊＋顔＋武器＋足）を使い回し、**頭と持ち物だけを変える**ことで12種を作っている。素材づくりの効率の手本
- **縁取りなしのカエルは、10色の平塗り**（縁の主な色L0.34が30%だけ＝輪郭は一部だけ）。明るい黄緑・暗い青緑の2系統で、体と脚を塗り分け、目だけ白＋黒の点。縁取りを省くと軽くなるが、背景が暗くないと形が溶ける
- **アリは6色**（色相15〜16°・彩度0.47〜0.79、明度0.26〜0.64）の1系統のランプだけ。16×14の小さな絵は、色を絞ると読める
- **フードの人物（暗灰）は、縁だけ赤（H0°前後）の細い光**。暗い体＋色つきの縁は、第3批の「状態アイコン」と同じ技法
- ランプは**色相315°（ピンク紫）の5段**を、笠の縦に細かく帯にして、折り目を出す。台・脚は茶（H48°）
- ヘビ（再トレース）: 12色。胴は黄（H49〜50°）を彩度1.0→0.69の段で、横縞（体の向きに垂直）に交互に塗る。第3回の自作で足りなかった**縞の方向**と**とぐろの内側の輪郭線**を、数字と見た目で確認できた

### 自作: 1ビットの鎧の騎士（第4批をふまえて）
- 1回目は、体が黒い塊のままで、兜・剣・盾だけが読めた。2回目で、**肩当ての点線の縁・胸の紋（縁取りの盾形に十字）・ベルトの点線・足の2段**を白い線で足すと、2色だけで「鎧」と分かった。→ 黒い塊は、**点線（1ドットおきの白）を縁やベルトに使うと、布や金属の継ぎ目が出る**

## 第5批（24点: 16×16の小キャラ、宝箱、家のタイル、ゴーレム、兜、植物の魔物など）
測って分かったこと:
- **16×16の小さなキャラ（surtシリーズ、ミノタウロス・老人・人・ぬいぐるみなど）は、全員が同じ約10色のパレット**を共有している（肌H45°・彩度0.24〜0.69、茶H19〜28°、暗い赤H0°…）。**1つのパレットを使い回す**ことで、登場人物がまとまって見える。うちでも「雑魚の絵」は地方の色相でパレットを作る方式（`mob-palette.ts`）にして、同じ考え方
- **16×16は「顔の1〜2ドット」で表情を出す**: 目は2ドット、口は1〜2ドット。服は色の塊で、2〜3色
- **家のタイル（48×64、15〜16色）は、石の壁を色相214°・彩度0.04〜0.12の青みの灰5段、屋根を赤H3〜33°・彩度0.67**で塗り分ける。屋根の色だけ変えた色違いを3×4で並べて、町の変化を出す（うちの家の色違いと同じ手）
- **ゴーレム（30×32）は、色相200°前後・彩度0.66〜1.0の青を主役に、岩の灰（彩度0.25）が体、青い結晶が差し色**。暗い体色（L0.15）の中の青い光だけが目立つ
- **兜（55×48、16色）は、金属の滑らかなグラデーション**（明度0.43〜0.76）を、なめらかな帯で塗る。16色まで使うと、素材のつやが出る
- **植物の魔物（46×41）は、葉を同じ形の繰り返し（8枚）で左右対称に並べ、中央に1つ目玉**。同じ形の繰り返しは、少ない色でも「密度」が出る

## 完成度を上げる練習（人間の指摘「自作は完成度がまだ低い」への対応）
同じ題材を、参考と同じ大きさで並べて見比べ、直して描き直した（剣: 4回）。直す順番:
1. **形**: 45度の斜めは「1行ごとに1ドット動く」（行の左右の端 x=y+a〜y+a+W-1）で作ると、輪郭が整う。幅を数えて決める
2. **面**: 幅方向に5〜8段の明暗（左上の縁＝白、溝＝暗い線、右下＝暗い面）。素材ごとに別のランプ（刃は青灰、鍔・柄頭は金の4段、柄は茶の4段）
3. **細部**: 切っ先の白い光、刃の縁のきらめき（1ドットおきに白）、溝の内側の細い明線、鍔の先を反らせる、中央の宝石、柄の巻き革の縞（斜めに）、柄頭の丸い塊
4. **欠点つぶし**: 刃が鍔を突き抜ける、孤立した点、影の点の浮き。→ 重なりの順を決めてクリップ、1ドットだけ離れた点は消す
5. 描いたら必ずエディタで描き直して、食い違い0マスと見た目を確認する
- 結果: 1回目は「青いグラデーションの棒に金色の十字」だったが、4回目は刃・鍔・宝石・柄・柄頭がそれぞれ読める剣になった。**完成度は「細部の数」と「素材ごとのランプ」と「欠点つぶし」で決まる**

### 完成度を上げる練習（2頭身の主人公・4回）
- 参考（コックの2頭身）と同じ大きさで並べて、4回描き直した。1回目: 大きな顔・髪・チュニック・ベルト・ブーツの形。2回目: 目の白い反射と上まぶた、マフラーの垂れ、服のしわ、ブーツのつま先、髪のしま。3回目: 髪のツヤ、もみあげ、瞳の反射。4回目: **顔の影を「斜め半分」から「頬と顎のふち（三日月）」に変更**（斜めの半分は顔が汚れて見える）

### 完成度を上げる練習（林檎・5回）
- 形は、左右の円＋中央の円を合成し、中央にヘタのくぼみ。光は左上手前、右下に照り返し。7段のランプ、左上に白い照り（鏡面）、ヘタ・葉（3段＋葉脈）、地面の影（市松）
- **失敗: 全体に市松（ディザ）をかけると「ざらざらのノイズ」になった**（2・3回目）。参考の果物は、大きな面は**なめらかな段（帯）**で、ディザは「2段の境目の1列だけ」か「小さな粒の質感」に限っている。→ ディザは境目だけ。面全体にはかけない
- 1回目（帯だけ）が最もきれいで、2〜4回目は悪化した。**「足せば良くなる」ではない**。5回目は、1回目の帯を残し、**色（ランプ）を赤寄りに直す**だけにした（桃に見えたため）
- 検査ツール（`tools/pixel-practice/lint.py`）: 孤立点・浮いた塊・縁取りの欠け・色数・光の向きを数字で確認できる。軸のずれ（剣）は、検査ではなく**描く前に軸の式を決める**ことで防ぐ

### 大きな屋敷と「奥行き」（人間の指示: 家はもっと大きく、奥行きのある感じに）
- 1回目（正面だけ、幅5マス・2階建て）は、大きくなったが**平らな立面図**だった。→ **奥行き**は、(1)正面の壁と、右へ向かって**1ドット進むごとに0.45ドット上がる**側面の壁（遠ざかる面）を並べる、(2)屋根を前面と側面の2面にし、側面を暗く、境の隅棟を明るい線に、(3)側面の窓を傾いた平行四辺形に、(4)ポーチの庇と柱を手前に出し、壁に庇の影を落とす、(5)地面の影を右奥へ伸ばす、で出した
- ゲームの飾りに「屋敷」3色（赤・青・緑の屋根）を追加。幅5マス×足元2マスを通れなくし、絵の上3マスにNPC・出入り口を置かないことをテストで確認。灯里・麦香野・硝子湖に置いた
- **エディタの制限（要注意）**: 80×80の大きさは、エディタ上でマウスの塗りがずれて食い違いが出た（178マス）。64×64までは0マス。大きな絵は、書き出した文字グリッドと同じ画像で確認し、エディタでは分割するか倍率を下げて描く

### 家のリアリティ（人間の指示）と家の生成器（`house3d.py`）
- 家を、**斜め上から見た絵**（正面の壁＋奥へ引く側面の壁＋2面の屋根）の生成器にまとめ、小屋（1階）・石の家・屋敷（2階）を、同じ部品から作れるようにした
- **リアリティの足し方**: (1)瓦1枚ごとの明暗のむら（同じ段でも少し違う）、(2)屋根のコケ、(3)漆喰のしみ（窓の下の縦の汚れ）・ひび、(4)梁の木目、(5)窓のカーテン・花箱、(6)つた（左の角を這う）、(7)土台の足元の草と飛び石、(8)ポーチの庇と柱（影が壁に落ちる）、(9)側面の窓は傾いた平行四辺形、(10)地面の影を右奥へ
- 屋根の色違い（赤・青・緑）は、屋根の6色だけ差し替え。ゲームの家は、この生成器の「小屋」（`cottage`）と「屋敷」（`manor4`）に差し替えた

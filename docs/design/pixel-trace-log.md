# ドット絵のトレース練習ログ（6時間）

2026-10-03、人間の指示（「参考画像・参考ドット絵をトレースして、ドット絵エディタで学習する。6時間たつまで終わらない」）で行ったトレース練習の記録。開始 12:21（日本時間）。
- 道具: `tools/pixel-practice/prep-trace.py`（参考画像→文字グリッド）、`trace-batch.sh`（エディタで下絵つきにトレース。食い違い0マスを確認）、`analyze.py`（色づかいを数字にする）、`sheet.py`（一覧画像）
- トレースは、参考の絵を**エディタの下絵（薄く表示）に読み込み、1ドットずつマウスで写す**。トレース結果は `assets-src/pixel-practice/trace/`（参考素材は `assets-src/pixel-reference/` の無料素材。**練習の写しはゲームに入れない**）
- 各回で、(1)一覧画像を見て、(2)色づかいを数字で測り、(3)分かった技法を書き、(4)次の自作に生かす

## 第1批（12点: アイコン・食べ物・武器・防具・宝石）
トレース: 靴・指輪・ニンジン・ブドウ・宝箱・クローバー・ダイヤ・試験管・矢・火の玉・斧・剣。すべてエディタで食い違い0マス。
測って分かったこと:
- **外周は100%、ほぼ黒（明度L 0〜0.15）の1ドット輪郭**（12点中11点）。例外はダイヤで、外が白・内が黒の二重線（光る物を白縁で目立たせる）
- **色数は5〜11色**。食べ物・クローバーは5〜8色、金属・光る物は10〜11色
- **金属（剣・斧・靴・指輪・矢）は、影も光も青みの灰色（色相255〜260°、彩度0.1〜0.2）**。彩度を抑えた青灰色を明度だけで5段に分けている。剣は純粋な灰（彩度0）で、白→灰→暗灰の5段
- **食べ物は、光が黄寄り・影が赤寄り**。ニンジンは影H24°（赤橙）→光H33°（黄橙）、宝箱も影H21〜23→光H32。葉は緑H77で、明暗は彩度（S0.54→0.87）で付ける
- **ブドウ（紫）は、光が青寄り**（影H257°→光H248°）。寒色は光が青側へ、暖色は光が黄側へずれる（色相が、明るい色ほど「明るい色の側」へ動く）
- **火は、暗い所が赤（H14°）、明るい所が黄（H39°）**で、彩度は常に高い（0.9以上）。炎の中の岩（黒い塊）は、明度0.39〜0.54の彩度の低い灰
- **宝箱・斧の柄・ブドウの粒など、丸い物は「左上が明るい点（ハイライト）＋右下が暗い帯」**。ハイライトは1〜3ドットの塊で置く
- 次の自作に生かす: 金属は青灰色5段（彩度を抑える）、食べ物は影を赤寄り・光を黄寄り、外周は1ドットの黒に近い暗色

## 第2批（24点: 防具・装身具・金属・食べ物・大砲）
測って分かったこと:
- **金属の色は、どのアイコンでも同じ5段を使い回している**。色相260°・彩度0.07〜0.20、明度は 1.00 / 0.82 / 0.64 / 0.50 / 0.36 の約0.15〜0.18刻み（金属の素材3点・大砲・兜・盾に共通）。**素材ごとにランプ（色の並び）を1つ決めて、使い回す**と、持ち物が並んだときに質感がそろう。金属に影の色相ずらしは無く、一定の青灰色
- **金は、色相39〜54°・彩度ほぼ1.0**の黄〜橙。明度0.50 / 0.53 / 0.72 / 0.93 の4段。ハイライトは白に近い黄（L0.93〜0.97）。金は彩度が高いまま明度だけ動く
- **赤い防具・靴は、色相11°（赤橙）で彩度0.7〜0.9、明度0.23〜0.56の暗めの段、ハイライトだけ色相39°（黄橙）**。光だけ黄にずらす
- **果物**: レモンは「ほぼ1色（彩度1.0・色相46〜53°）＋小さな明るい粒」で、**ランプではなく粒（ドットの散らし）で質感**を出す。洋梨は色相77〜95°を彩度で段にする。スイカは果肉H352°（ピンク）・皮H120°（彩度0.25〜0.37のくすんだ緑）で、皮だけ彩度を落とす
- **大きな面（盾・兜・鎧・砂・肉）には、市松の細かい模様（ディザ）で2段の間をなじませる**。盾の丸みは、面を4等分して明度を変え、リベットは1ドットの明点と暗点
- **縁取りの色**: ほとんど黒（L<0.02）だが、靴は少し明るい青灰（L0.15）。2素材が接する所は、縁取りを引かずに明度差だけで分ける例もある（ネックレスの鎖は白い縁取り）
- **二重の素材（金＋金属、革＋金属）は、素材ごとに別のランプ**で塗り、境目に暗い線を引く
- 次の自作に生かす: 盾（金属5段を使い回し、紋は金4段）、果物（粒で質感）、食材の色相は影を赤・光を黄へ

## 第3批（24点: 特技・状態のアイコン、矢、薬びん、道具）
測って分かったこと:
- **状態・強化のアイコン（人型の影）は、色が4〜5色だけ**（buff06は4色）。人の形のシルエットを暗く（L0.10）塗り、**縁に1〜3ドットの色つきの光の輪**（オレンジ・紫・水色）を付けて、効果の種類を伝える。輪郭が黒ではなく暗い灰紫（L0.10）なのが、「光っている」感じを出す
- **爆発・炎・雷は、とがった星形（スパイク）で、橙H20°→黄H46°の彩度1.0のランプ**（明度0.42 / 0.60 / 0.72 / 0.90の4段）。中心を最も明るく、外へ向かって暗く。矢や剣の「勢い」は、物の背後にこの星形を置くだけで出る
- **薬びんは、びんの形を使い回し、中身の色だけ変えている**（紫H284・緑H108・黄H46・ピンクなど）。ガラスは共通の色相215°・彩度0.44〜0.64・明度0.84〜0.92＋白のハイライト。13×31の細長い形で、中身には市松（ディザ）で濃淡
- **宝石（サファイア）は二重の縁**（外が白、内が黒）。面は2〜3段で、面の間にディザ。光る物の縁を白にすると、暗い背景から浮く
- **氷の呪文は色相197〜231°・彩度0.4〜0.7**を5〜6色。白いハイライトを2〜3か所の斜めの短い線で置く
- **薪（たいまつ）・毛皮・巻物は、くすんだ暖色（彩度0.2〜0.8）を5色**で、素材感はドットの散らしと縁のぎざぎざで出す（毛皮は縁が毛束のぎざぎざ、巻物は端がめくれる）
- **岩は、青灰（色相259〜262°・彩度0.1）に、青い結晶の小さな差し色（H229°）**を2か所だけ置く。差し色が少量だと目を引く
- 次に生かす: 薬びんの型（ガラス色は共通、中身だけ差し替え）をゲームのアイテム用アイコンとして作る、状態アイコン（人型の影＋色つきの縁）を状態異常の表示に使える

# アンプの追加のしくみ（アンプ定義ファイル）

サンシャイン作曲ソフトには、あとからほかのアンプシミュレーターを自由に組み込めるよう、
**アンプ定義ファイル（`〇〇.sunshine-amp.json`）** という形を用意しています。
組み立ては `src/audio/amp-plugins.ts`（形のチェック `validateAmpPlugin`、音の部品づくり `buildAmpPlugin`）。

## 使い方

- **作曲ソフト**: 「音づくり（アンプ）」で「追加したアンプ」を選び、「アンプ定義を読み込む」。
  キャビネットのIR（`.wav`）だけを持っているときは、「キャビネットIRからアンプを作る」で自動で定義を作れます。
  「ファイルを開く」からアンプ定義を開いても追加できます。
- **デスクトップ版**: 「ヘルプ」→「アンプの追加フォルダを開く」で開くフォルダに置くと、起動時に読み込みます。
- 選んだアンプの定義は、曲（プロジェクト）の中にも入るので、ほかのパソコンで開いても同じ音で鳴ります。
- 見本: `assets-src/amp-plugins/`（キャビネットIRつき・プログラムつき）。作曲ソフトにはじめから入っています。
- ジャンル別アンプ14種（`src/audio/amp.ts`）も、同じ形で書けます（`presetToPlugin`）。

## 形

```json
{
  "format": "sunshine-amp",
  "version": 1,
  "id": "my-amp",
  "label": "表示名",
  "description": "説明（なくてもよい）",
  "author": "作った人",
  "license": "利用条件（MIT・CC0・作者の許可あり など）",
  "stages": [
    { "type": "eq", "kind": "highpass", "freq": 90 },
    { "type": "gain", "value": 5 },
    { "type": "drive", "shape": "asym", "hardness": 3.5, "asymmetry": 0.3 },
    { "type": "eq", "kind": "peaking", "freq": 900, "gain": 3, "q": 0.9 },
    { "type": "ir", "wav": "（WAVをbase64にしたもの）", "mix": 1 },
    { "type": "gain", "value": 0.7 }
  ]
}
```

音は、`stages` の上から順に通ります。作曲ソフトの「歪みの深さ」は入口の大きさ、「高音の明るさ」「出力の大きさ」は出口で調整されます。

| 段（type） | 中身 | 決まり |
|---|---|---|
| `gain` | 音量を `value` 倍にする | 0〜100 |
| `drive` | 歪み。`shape` = soft（真空管風）・hard（角が立つ）・asym（上下で非対称）・steps（階段状）、`hardness` = 硬さ（steps は段数）、`asymmetry` = 0〜1、`amount` = 前に入れる増幅（なくてもよい） | hardness は 0より大きく64まで |
| `eq` | フィルター・イコライザー。`kind` = lowpass・highpass・bandpass・lowshelf・highshelf・peaking・notch・allpass、`freq`（Hz）、`gain`（dB）、`q` | freq は 10〜22000 |
| `compressor` | 音の大小をそろえる。`threshold`（dB）・`ratio`・`attack`・`release`（秒） | |
| `ir` | キャビネットや部屋の響き（インパルス応答）。`wav` = WAVファイルをbase64にした文字、`mix` = 0〜1（1で響きだけ） | |
| `worklet` | 自分で書いた音の処理（AudioWorklet）。`name` = 処理の名前（`registerProcessor` の名前と同じ）、`code` = プログラム、`params` = 初めの値 | **プログラムを含むので、読み込む前に確認が出ます。信頼できる配布元のものだけ使う** |
| `nam` | NAM（実機を学習したアンプ）のモデル。`model` = .nam ファイルの中身 | 作曲ソフトだけで鳴る（ゲームではとばす） |

- 段は64個まで。まちがいがあると、`stages[2]: freq は 10〜22000` のように場所つきで知らせます。
- ほかのアンプシミュレーターを組み込むときは、①そのソフトの音づくりを段の並びに置きかえる、②そのソフトのIR（キャビネットの響き）を `ir` で使う、③NAMのモデルなら `nam`、④独自の処理はプログラム（`worklet`）で書く、のどれかで行います。
- VST・AU などのプラグイン（パソコンに入れて使う形式）は、ブラウザの中では動かせないため、今は直接は読み込めません（今後の候補: デスクトップ版にプラグインを動かす部品を足す）。

## 規約の確認（販売するときは必ず）

- 他の人が作ったアンプ定義・IR・NAMモデルを作曲ソフトに**同梱して配る**ときは、その利用条件（商用利用・再配布）を確かめ、`docs/assets-credits.md` に記録する（CLAUDE.md 1-1 の例外の手順）。
- 利用者が自分で読み込むものは、利用者が規約を確かめる（画面にもそう書いてある）。
- 実在の機材の名前（メーカー名・製品名）を、表示名に使わない。

# 他社の歌声ソフトを作曲ソフトの中で動かす計画（Cubase と同じ形）

人間の指示（2026-11-15）:「cubaseみたいに、他社のボカロソフトを入れれる用にしましょう。その際にはパソコンで使える用にします」
選んだ方法:「Cubase のように中で動かす」。使いたいソフト: VOCALOID（6 など）・Synthesizer V・UTAU / OpenUtau。
パソコン: Windows（AMD Ryzen 5 8640U・メモリ約 15GB）。

## 今の作曲ソフトと、足りないもの

- 今の作曲ソフトは、ブラウザで動くページ（`dist-composer/index.html`）。ブラウザは、パソコンに入っているプラグイン（VST3）を読みこめない。
- Cubase のように中で動かすには、**パソコン用のアプリ**にして、その中に**プラグインを動かす部分（ホスト）**を持つ必要がある。
- VST3 の開発キットは 2025 年 10 月から MIT ライセンス（無料・商用も可）になった。費用のかかる契約はいらない（CLAUDE.md 1-2 に当たらない）。

## 歌声ソフトごとのつなぎ方

| ソフト | プラグイン（VST3）として動くか | つなぎ方 |
|---|---|---|
| VOCALOID6 Editor | 動く（DAW の中で使える。VX-β もプラグイン） | 作曲ソフトの中でプラグインの画面を開き、再生位置とテンポを合わせて音を受け取る |
| Synthesizer V Studio（Pro） | 動く（Pro 版のプラグイン） | 同じ |
| UTAU | プラグインではない（単体のソフト） | ファイルでつなぐ（UST を書き出し → 歌の WAV を読みこむ）。今の内蔵の歌声（重音テトの UTAU 音源）もそのまま使える |
| OpenUtau | 単体のソフト | ファイルでつなぐ（USTX/UST を書き出し → WAV を読みこむ） |

- プラグインの歌声ソフトは、**歌詞と音符をプラグインの画面の中で打つ**作りになっている（ホストから歌詞つきの音符を送って歌わせる作りではない）。
  そのため、作曲ソフトの歌のパートを**そのソフトの形式（VSQX/VPR・SVP）で書き出して、プラグインの画面で読みこむ**ボタンを用意する。打ち直しをなくす。

## 作る順番（段階ごとに、パソコンで動かして確かめる）

1. **第1段階: パソコン用アプリの入れ物**（Windows）。今の作曲ソフトをそのまま中に入れ、プロジェクトの保存・読みこみ・WAV の書き出しがパソコンのフォルダでできるようにする。
2. **第2段階: プラグインを動かす部分（ホスト）**。VST3 の楽器プラグインを読みこむ → プラグインの画面を開く → 再生・停止・テンポ・位置を合わせる → 音を受け取って作曲ソフトのミキサーに入れる → プラグインの設定をプロジェクトに保存する。
3. **第3段階: 歌のパートの受けわたし**。VSQX/VPR（VOCALOID）・SVP（Synthesizer V）・UST/USTX（UTAU・OpenUtau）・MusicXML・MIDI の書き出しと、歌の WAV の読みこみ（伴奏と頭をそろえる）。
4. **第4段階: 書き出し**。プラグインの歌声をふくめて、曲全体を WAV にまとめて書き出す（実時間の録音 → のちに速い書き出し）。
5. **第5段階: 使いやすさ**。プラグインの一覧、読みこめなかったときの案内、歌のトラックのつまみ（音量・左右・響き）。

## 正直に書いておくこと

- この作業場（クラウドの Linux）には Windows も歌声プラグインも無いので、**プラグインが実際に動くかは、旭さんのパソコンでしか確かめられない**。段階ごとにアプリを作って、パソコンで開いてもらう（またはパソコンとつないで確かめる）。
- VOCALOID6・Synthesizer V のプラグインは、**持っている版がプラグインで動く版か**（VOCALOID6 Editor の製品版か、Synthesizer V Studio の Pro 版か）で、できることが変わる。先に確かめる。
- 第2段階は大きな開発（Windows のアプリと音の出入り口を作る）。1回では終わらない。途中の状態は「仮」と書く（CLAUDE.md 1-4）。
- アプリの配布・公開（ストア・サイト）は、人間の承認が出てから（CLAUDE.md 1-2）。作るのと、手元のパソコンで使うのは、その前にできる。

# ドット絵の技法メモ（学習ノート）

ドット絵を作るたびに、うまくいった点・失敗した点を書き足していくノートです。**既存作品の絵そのものは写さず**、一般的な技法だけを自分の言葉で残します（CLAUDE.md 1-1）。
制作の手順は `.claude/skills/rpg-cycle/roles.md` 3-8、道具は `tools/pixel-art/`（ドット絵エディタをヘッドレスブラウザで動かして描く）です。

## 基本の型（64×64の部品でうまくいったやり方）
1. **形→塗り分け→縁取りの順**。先に「輪郭になる形」を決め、5階調（暗→明）で塗り、最後に外周を1ドットの暗い色で縁取る。落ち影は縁取りの対象にしない。
2. **光は左上から**。丸いものは、中心から見た向きで明暗を決める（`toneOf`）。右下の縁は一段暗くして立体感を出す。
3. **かたまりを重ねる**。木・茂みは、半径の違う円を後ろ（上）から順に重ね、塊ごとに明暗をつける。1つの大きな円より、ぎざぎざした葉の感じが出る。
4. **面を切り替える**。岩は、斜めの面（3つ程度）ごとに1段ずつ明るさをずらすと、削り出したような硬さが出る。
5. **質感はディザと点で**。ランダムな点を少しだけ（1割前後）混ぜる。混ぜすぎるとノイズになる。
6. **小さな金属・光る物は明暗を大きく**。灯りの光は中心を白に近く、外へ向けて段階的に暗くし、まわりにディザの点で「にじみ」を置く。
7. **構造物は部品ごとに描く**。井戸なら胴・縁・水面・支柱・屋根・滑車を別々に描いて重ねる。

## 失敗と直したこと
- 橋（09）の最初の案は、板が3色の大きな帯になって不自然だった → 板1枚（5ドット高）ごとに色を変え、継ぎ目を暗くしたら板らしくなった。
- 洞窟（10）の最初の案は、岩が黄土色で「砂山」に見えた → 岩の色を青みのある灰褐色に寄せ、洞口を暗くしたら岩山らしくなった。
- 家（64×64）の窓が小さく単純、壁の漆喰の面が広くて単調だった → 次に作るとき、漆喰に細かい汚れ・ひびを足し、窓を大きくする。

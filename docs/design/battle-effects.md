# 戦闘のエフェクト（ボスの魔法）

2026-10-04、人間の指示「ボスが使う魔法エフェクトを作ろうか。まずは雷系」「魔法を発動するとき、ボス周りに発動のエフェクトもかけよう」。

## 大きさと置き場所

- 戦闘画面（論理 400×225、戦闘の場は上の169）と同じ1ドットの大きさで描く。ボスは左（x=16, y=2, 132×132）、味方は右の地面（4人の足元: (368,165)・(354,147)・(338,165)・(324,147)）。
- 作る道具: `tools/pixel-art/fx/lightning.py`（コマの JSON）→ `tools/pixel-practice/fx-editor.mjs`（ドット絵エディタのフレームに入れ、作品・GIF・シートを書き出す）→ `tools/pixel-art/fx/verify_sheet.py`（エディタのシートとコマが1マスもちがわないか）→ `tools/pixel-art/fx/fx_preview.py`（本物の戦闘画面に重ねた見本の動画）。
- 置き場所: `assets-src/effects/lightning/`（`*.json` がコマ、`editor/` がエディタで書き出したもの）。見本の背景は `assets-src/effects/preview/`（ゲームの描画 `battle-renderer.ts` で作った画面）。

## コマのデータ

`{"name", "w", "h", "anchor": [x, y], "palette", "frames": [{"ms", "x", "y", "rows", "dim", "flash", "shake", ("bx", "by", "back")}]}`

- `anchor`: 画面のどこに合わせるか（ため＝手の上の点、落雷＝当たる人の足元、嵐＝味方の一団のまん中、発動＝ボスの絵の左上）。
- `dim`: 画面を暗くする強さ（0〜1）。`flash`: 白く光る強さ。`shake`: 画面の揺れ（ドット）。
- `back`: ボスのうしろに描く部分（発動の光の輪の奥の半分）。

## 描き方の決まり

- 光るものは、芯を白、そのまわりを薄い黄、外を水色、いちばん外を青の点々（1ドットおき）。
- 本物の雷のように、光る・消える・また光る、をくり返す。コマごとに稲妻の形を少し変えて、ちらつかせる。
- 白い光（画面の点滅）は、1つの術でいちばん強いのを1回だけ。ほかは弱く。何度も強く白くなると、目にきつい。
- 術のあいだは画面を暗くし（暗い紫）、光を目立たせる。最後は暗さをもどしていく。
- 印（光の輪の上の小さな棒と点）は、この術だけのもの。既存作の魔法陣・文字には似せない。

## 炎系（4つ、2026-10-04、人間の指示「では火の魔法のバージョンも作って」）

作る道具: `tools/pixel-art/fx/fire.py`（置き場所 `assets-src/effects/fire/`）。見本は `fx_preview.py --set fire`、音は `se_mix.py fx --fxdir assets-src/effects/fire`。

| エフェクト | コマ | 長さ | 中身 |
|---|---|---|---|
| 発動（ボスのまわり） | 20 | 約1.4秒 | 足もとに赤い炎の陣（回る炎の印）。輪から炎が立ちのぼり（奥はボスのうしろ）、体のふちが赤く脈打ち、上のふちから小さな炎がゆらぐ。火の粉がのぼる |
| ため | 16 | 約1.2秒 | 振り上げた両手の上で火の玉がふくらみ、上へ炎の舌。火の粉がうずを巻いて吸いこまれ、最後にぎゅっと光る |
| 火球（1人） | 17 | 約1.0秒 | 火の玉が弧をえがいて飛び（尾と火の粉・煙）、当たってはじける: とがった光 → ふくらむ火の玉 → まん中から燃えつきて輪 → 地面から炎・煙・焦げ |
| 火柱（全体） | 28 | 約1.9秒 | 味方の足もとに赤い輪（予告）→ 地面から火柱が少しずつずれて立つ（味方4人と地面2か所）→ 煙 |

- 炎は「熱さ」の格子を下から上へ流す（すぐ下の熱さを左右にランダムにずらして持ち上げ、少しずつ冷ます）。1コマのあいだに何回か流すと、炎が速く高くのびる。色を分ける前に少しぼかすと、1ドットのざらつきが消えて、色の帯がきれいになる（ぼかさない版は砂のようにざらついた）。
- 色は 白に近い黄 → 黄 → 濃い黄 → 橙 → 赤 → 暗い赤（いちばん外は1ドットおき）。煙は灰色の点々。
- 光は弱め（はじけた瞬間・最初の火柱だけ、あたたかい色で）。
- ドット絵エディタは幅256までなので、火球はコマごとに「火の玉（当たった所）のまわり 120×104」を切り出し、画面の置き場所を `at` に書く。
- コマに `party`（当たった味方の絵）と `se`（鳴らす効果音）を書く。見本の動画と効果音の道具は、これを読む。
- 味方のダメージの絵に `burn_left`（燃える: ひるむ姿を、ふちは暗い赤、中は赤・橙・黄）を足した（`hurt_pose.py`）。当たると 白 → 燃える ⇄ ひるむ。すすけた絵（点を打つ）は水玉もようにしか見えなかったので、やめた。

## 味方・敵の術（属性ごと、2026-10-05）

人間の指示「モーションドットをもっと派手にできないかな？この動画の炎の術みたいに」「モーション作るときドット絵エディタ使って細かく作って」「細かく派手に作っていいからね」。
ボスの雷・炎と同じ作り方（熱さの格子を流す・芯が白く外へ暗く・いちばん外は1ドットおき・けむりは網目）で、どの戦いでも使える術のコマを作り、**ゲームに組み込んだ**（それまでのゲームの術は、コードで描いた簡易なもの）。

- 作る道具: `tools/pixel-art/fx/spells.py`（コマのJSON）→ `tools/pixel-practice/fx-editor.mjs`（ドット絵エディタのフレームに1コマずつ入れ、シートを書き出す）→ `tools/pixel-art/fx/verify_sheet.py`（0マス）→ `tools/pixel-art/fx/export-spell-sheets.py`（エディタのシートを `src/assets/spell-fx/` へ。もう一度0マスを確かめ、色番号つきPNGにして小さくする。長さ・光・揺れは `src/game/art/spell-fx.generated.ts`）。
- 置き場所: `assets-src/effects/spells/<属性>/<種類>.json`、`editor/` がエディタで書き出したもの（作品・GIF・シート・画面）。
- 種類: `hit`（1人に当たる。120×128、足もと＝(60,116)）・`area`（全体の術で1人ずつ）・`charge`（ため。96×104、足もと＝(48,92)）・`bolt`（飛んでいく弾。72×40、左向き。右へ飛ぶときは左右反転）。
- ゲームでは、コマの足もとを当たる人・となえる人の足もとに合わせる。大きな敵（背が100以上）には2倍で描く。術の長さに合わせて、コマを長さの比で進める。コマの「光」は画面にその色で重ね、ゆれは今までどおり。

| 属性 | 当たる（1人） | 全体（1人ずつ） | 飛ぶ弾 |
|---|---|---|---|
| 炎 | とがった光 → ふくらむ火の玉（つづけて小さな爆発2つ）→ まん中から燃えつきて輪 → 体の上に炎がのぼる・地面から炎 → けむり・焦げ | 予告の輪 → 太い火柱 → 大きく燃えあがる → けむり | 火の玉（尾がゆらぐ） |
| 水 | しぶきがはじける → 足もとから水柱（上ほど細く、うねる。白い泡のすじ）→ てっぺんで王冠のしぶき → くずれて落ちる → 波紋・霧 | 同じ | 水の玉 |
| 氷 | 霜の輪が広がる → 氷の柱が次々に突き出す（左が光る面・右が影の面）→ きらめき → 白く光ってくだけ、破片が飛ぶ → 霜の霧 | 柱の数を多く・高く | つらら |
| 風 | 砂けむり → ろうと形の竜巻（しま模様の帯が回る）・葉と砂が巻きあがる・白い風の切りつけ → ほどけて消える | 大きな竜巻 | — |
| 光 | 天から細い光 → 太い光の柱 → 十字の光（2重）・光の輪 → 光の羽がまう | 太い柱 | 光の玉 |
| 雷 | 細い先がけ → 太い稲妻（枝わかれ）→ 消える → もう一度光る → 火花・焦げ・煙 | 3本の雷が少しずつずれて落ちる | — |
| 岩 | 大岩が落ちてくる → 当たってくだける（とがった光・岩のかけら）→ 地面が割れて、太い岩のとげが王冠のように突き出す → 土けむり | とげを多く | 回る岩 |
| 回復 | 体のまわりの輪から、緑の光が炎のようにのぼる・十字の光が舞う → 8方向の光 | （1人ずつ同じ） | — |
| 強化 | 金の光がのぼる・上向きの矢じるし → 8方向の光 | — | — |
| 弱体 | 頭の上から紫の闇がのしかかる・3本の輪がしめつける・闇のかけら | — | — |
| 爆発（体の技） | とがった星形の光 → 輪 → 火花 | — | — |

- ため（全属性）: 足もとに属性の色の陣（二重の輪・回る6つの印。陣のふちから属性の色の光が立つ）→ まわりから属性のもの（火の粉・しずく・雪・風・光・稲妻・小石・葉・闇）がうずを巻いて吸いこまれ、頭の上に玉がふくらむ → 陣から光の柱・玉がはじける。印はこの術だけのもの。
- 白い光（画面の点滅）は、1つの術で強いのを1回だけ（0.3〜0.42）。
- 毒・眠り・混乱（毎ターン出る小さなしるし）は、これまでどおりコードで描く。

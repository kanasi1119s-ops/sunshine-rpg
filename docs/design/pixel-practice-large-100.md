# 大型モンスターの模写練習100点（2026-09-30）

人間の指示「大型モンスターを100体ほど参考ドット絵をつかってエディタの練習をしよう」への対応の記録。

## やったこと
- `assets-src/pixel-library/` の「モンスター」「ボス」から、幅か高さが48ドット以上の絵（48〜127ドット）を、重複を除いて**100点**選んだ（`tools/pixel-art/v7/slice.mjs` に種類・大きさの指定を追加）。すべて **CC0**（OpenGameArt の作品 58、ほか 42）。
- 100点すべてを、**ドット絵エディタでマウス操作により描き込み**、エディタの書き出しが元の絵と**1マスも違わない**ことを自動で確認した。**100/100 一致**（`tools/pixel-art/v7/batch-practice.mjs`）。
- 練習用のデータと描いた結果は、素材の複製にあたるため、**リポジトリには入れていない**。この文書には集計だけを書く。

## 集計
- 種類: モンスター 57, ボス 43
- 大きさ: 1点あたりの不透明なドットの数は、平均 1226、最大 5645（先の1000点の平均は約530）。64ドット以上の辺を持つ絵 47 点
- 色数: 平均 11.4、最大 26
- かかった時間: 1点あたり平均 48.2 秒、最大 274 秒（3並列）

## わかったこと
- 先に直した「細長い絵で下の行がずれる」問題は、大型でも起きなかった（100/100 一致）。
- 練習は「元の絵をそのまま写す」ものなので、上達の確認にはならない。大型の敵を自分でデザインする力をつけるには、（1）元の絵を見ずに説明だけで描いて比べる、（2）色・形を変えて別の敵にする、（3）学んだ技法でオリジナルを描く、の順に進める。

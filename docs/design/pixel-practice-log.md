# ドット絵の練習ログ

2026-10-03、人間の指示（「ドット絵をひたすら参考画像をもとに、コピーしたり、トレースしたり、一から作ったりを繰り返す」「作るときはエディタを使う」）で行った練習の記録。
絵そのもの（練習の成果）は `assets-src/pixel-practice/`、道具は `tools/pixel-practice/`。**ゲームには、練習の絵そのものは入れない**（参考にした素材は `assets-src/pixel-reference/` の無料素材で、規約は `docs/assets-credits.md`。写しの練習は学ぶためだけで、配布しない）。ゲームに入れたのは、練習で学んだことを使って**一から描いた**雑魚の敵4体（`tools/pixel-art/mobs.mjs`）だけ。

## 練習の型（1題材あたり）
1. **模写（コピー）**: 参考画像を拡大して見ながら、文字グリッドに写す。`grid.py compare` で「参考｜自作｜差」を並べ、`grid.py score` で一致率を出す（差がどこかを目で見る）
2. **なぞり（トレース）**: `grid.py trace` で輪郭だけを写した下書きを作り、中の陰影（光・影・面）は自分で描き込む。形は100%合うので、陰影の判断だけを練習できる
3. **一から**: 同じ種類のものを、参考なしで別の形で描く。描いたら見て、悪いところを直して描き直す
4. 描くときは**必ずドット絵エディタ（Artifact）**を使う。`tools/pixel-practice/editor-draw.mjs` が、エディタをヘッドレスブラウザで開き、実際にマウスで1ドットずつ塗る（エディタの書き出しと文字グリッドの食い違いが0マスなのを毎回確かめる）。下絵読み込み（トレース用）も使える

## 道具
| ファイル | 役目 |
|---|---|
| `tools/pixel-practice/zoom.py` | 参考画像を拡大して見る |
| `tools/pixel-practice/grid.py` | `ascii`（画像→文字）・`trace`（輪郭だけ）・`render`・`score`（一致率）・`compare`（差分画像） |
| `tools/pixel-practice/shapes.py` | 多角形・楕円・線で文字グリッドの下書きを作る（面のある物は、手で1文字ずつより速く正確） |
| `tools/pixel-practice/editor-draw.mjs` | エディタを実際に操作して描く（`EDITOR=エディタのindex.html`。エディタは `Artifact` の「ドット絵エディタ」から `read path=index.html` で保存する） |

## 学んだこと（回ごと）
### 第1回: キノコ（34×34、7色）
- 模写の1回目は、シルエット一致66%。傘だけ描いて**柄を忘れた**（全体の形を先に取らず、見えている所から描いたため）。→ 先に全体の輪郭（外形）を取ってから中を描く
- なぞり（輪郭は100%）の陰影は、色まで一致60%。**面ごとのブロック分けでは足りない**。参考は、傘の明るい筋が縁に**平行に流れ**、傘と傘裏の境に1段暗い帯があり、柄の中央に明るい筋が通る。陰影の帯は形（縁）に沿わせる
- 一から（赤い傘に白い斑点）: 傘が平たくなりすぎ、ハイライトが四角い塊。→ 傘は半球を意識して縁を丸く、ハイライトは縁に沿う細い弧にする

### 第2回: ポーション（34×34、16色）
- なぞり: 一致38%だが、見た目の印象は近い。差は**ガラスの上半分が白に近い**（自作は青灰色で濁った）、**液面から下は水平の帯**で、帯の境に市松（ディザ）が入る、底は暗い帯が重なる
- 一から（丸底のフラスコ）: 形は読める。ただし輪郭の右側（影側）に暗い線を足さず、立体感が弱い

### 第3回: ヘビ（30×30、16色）
- なぞり: 輪郭は99.6%一致。**とぐろの重なり目は、内側にも暗い輪郭線を引く**ことで前後が分かる（自作は塗り分けだけで、重なりが読めなかった）。腹の縞は体の向きに垂直（自作は水平一律）。舌は1ドットの細い二股（自作は赤い塊になった）
- 一から1回目（緑のヘビ）: **カモのように見えた**。頭が丸く太く、首が太い。→ 頭は首より少し太い程度の楔形に、とぐろの重なりに輪郭線を入れて描き直した2回目で、ヘビに見えるようになった

### 第4回: 結晶（34×34、6色）
- なぞり: 面を「縁からの距離」の規則で塗ると、**水玉と斜めの線が散るだけ**になる。結晶は面の向き（左は明、右は暗）と稜線が要る
- 一から1・2回目（手で1文字ずつ）: **波やひれのように見えた**。幅の広い土台の上に山を並べると、結晶ではなく岩や波になる
- 一から3回目（`shapes.py` で六角柱を4本）: 柱ごとに「左の面（明）／右の面（暗）／とがった頭の2面／稜線」を作ると、結晶に見えた。→ **面のある硬い物は、図形（多角形）で面を作ってから輪郭を付ける**。曲面は楕円体の陰影、硬い物は多角形、と使い分ける

### 実戦: 雑魚の敵4体（64×64）への応用
- 練習で学んだ「面の向きで塗り分ける（結晶）」「重なりに輪郭線（虫のとぐろ→背の割れ目と脚）」「目は白＋瞳＋1ドットの照り（顔が読める）」「影は青紫・光は黄へ色相をずらす（ランプ）」を使い、`mobs.mjs` で4体（こうもり・虫・結晶・しずく）を描いた
- **途中で直したこと（法務）**: 4体目のしずくを最初は「涙形の体に笑顔」にしたが、有名作品のスライムに似るので、**球の体＋単眼＋水たまり**に描き直した（CLAUDE.md 1-1）。涙形・笑顔・口は避ける
- ゲームでは、絵は色番号だけを持ち、地方の色相から色を作る（`src/game/art/mob-palette.ts`）。形はこの4種で、色の違いで地方ごとの見た目を変える

### 第5回: 剣（28×32の切り出し、9色）
- 模写: 1回目はシルエット83%。**刃の傾きと幅を目分量で決めた**ため、実際より太く急だった。2回目は参考の縁を測り（左縁は1行で約0.88ドット、右縁は約0.98ドット、幅6〜7ドット）、一致85%・見た目はよく似た。→ 斜めの物は、傾き（1行あたり何ドット動くか）と幅を数えてから描く。鍔は「刃に直角の細い棒」で、塊にすると読めない

### 第6回: ゴースト（20×20、2色）
- 模写: 一致85%。大きな白い塊は、**位置と大きさが1〜2ドットずれる**だけで印象が変わる。上が丸すぎ（参考は平たく幅広）で、目の位置が右にずれた。2色でも「輪郭の曲線の段の長さ」で個性が出る
- 一から: 雑魚「かげ」（ぼろ布のフード）。顔を闇にして細い光る目だけを置くと、ゴーストの定番（白い丸い体＋点の目）を避けつつ、顔が読める

### 第7回: 木（32×39、5色）
- 模写: 一致86%。参考の樹冠は、ドーム型ではなく**ふくらみ（塊）がいくつも重なった輪郭**で、内側に暗い小さな切れ込み（葉の塊の影）と、左上に短い横線の明るい筋、下の縁は暗いぎざぎざ（スカラップ）。幹の上端は樹冠の影で暗い
- 一から（40×46、8色）: 楕円を5〜6個重ね、塊ごとに「左上が明るい・右下が暗い」と塗ると、木らしくなった。根元は広がり、幹に明るい縦筋を入れる。**塊を重ねるほど自然、1つの大きな形にすると平たい**

### 第8回: 家（48×46、17色）
- 一から: 屋根（瓦を1段ごとに半分ずらして並べ、上端に光・下端に影・継ぎ目を暗く、左が明るく右が暗い）、漆喰の壁に×の筋交い、アーチ形の扉、窓と窓台と鉢植え、石積みの土台、右下への落ち影、煙突。1回目は梁が縦に並ぶだけで単調だったので、2回目で筋交い・アーチ・鉢植えを足して、人の暮らしが見える絵になった

### 第9回: オオカミ（30×30、18色）
- 模写: 一致85%（色は19%）。形の骨格は取れたが、**毛の質感が出ない**。参考は、輪郭が毛束でぎざぎざ、胸と脚に明暗の斑、筋肉の境に黒い内側の線がある。自作は塗り分けが滑らかで、猫のようになった
- 一から: 頬の毛束・縦の毛筋・耳の内側・光る目を足したが、**まだ猫に見える**。原因は、(1)鼻先（マズル）が前に出ていない（顔が平面）、(2)耳が頭の上に立ちすぎ、(3)体のバランス（頭が大きく、胴が短い）。→ 正面向きの犬科は、鼻づらを別の塊（明るく、鼻が先端）として顔の下半分に置く。次に描くときの課題

### 練習をふまえた雑魚の敵（`mobs.mjs`）の追加4体
- かげ（ぼろ布）・ねずみ（横向き）・サソリ・め（目玉）の4体を追加（計8形）。**横向きの生き物（ねずみ・サソリ）は、正面向きより形が読みやすい**ことを確かめた（オオカミの正面向きの失敗との対比）
- サソリの尾は、点を打つより**ベジェ曲線（4点）で弧を描き、太さを少しずつ細く**すると反りが出る。1回目は尾が真上に伸びて画面から切れたので、始点・終点・2つの制御点を決めて描き直した

### 第9回の続き: オオカミ（一から・2回目）
- 鼻づら（マズル）を明るい塊として顔の下半分に置き、牙・耳の内側・斜めの目を足した。**1回目より犬科らしくなった**が、まだ首がなく、頭が胸に直接のっている。→ 頭と胸の間に首の毛（ふさ）を1段入れる、頭を胴より小さくする

### 第10回: 2頭身のキャラクター（32×32、12色）
- 模写（コック）: 一致95.6%（全体が右に1ドットずれただけ）。**輪郭線なし・頭が全身の半分・目は2×3の暗い塊＋下に1段明るい色・髪は顔の横と前髪だけ**というつくり。ぴぽやの現代キャラの作り方を、手で確かめられた
- 一から: 鍛冶屋（バンダナ）・薬草つみ（フード）・絵描き。同じ体型で、髪・上着・帽子の形と色だけを変えて3人。→ 体の左右を半分ずつ塗り分けると「マント」に見えるので、陰は**下の右端だけ**にする。足は背景に近い暗さだと消えるので、少し明るくする

### 第11回: 地形タイル（32×32、継ぎ目なし）
- 一から1回目（草・水・土）: 3×3に並べると、**花・小石・波が格子状に繰り返して見える**（草の花は同じ位置に周期的、水は横縞が規則的、土の小石は斜めの列）
- 一から2回目: 2〜3倍の周期のノイズ（色の斑）を下地にして、房・波頭・小石は**数を絞り、位置と長さを散らす**。タイル2枚をランダムに並べても、継ぎ目は見えない。ただし、ノイズの補間で**三角形のようなかたまり**ができて不自然になった（土）。→ 斑は補間の格子を大きくしすぎない。花・小石は、タイルに入れず、別の飾り（オブジェクト）として散らすほうが繰り返しが出ない
- 道具の注意: ノイズのように1ドットごとに色が変わる絵は、エディタを1ドットずつマウスで塗ると時間がかかりすぎる（1タイルで数分）。テクスチャは、生成した文字グリッドをエディタの「読み込む」（配列の貼り付け）で入れるのが現実的

### 第12回: 鍵アイコン（32×32、4色）と参考の観察
- 模写: シルエット一致92%。**輪の穴を小さく、輪を太く**描いてしまった（参考は、穴が輪の幅の約半分）。軸の先の歯の切り欠きも欠けた。金属の艶は、明るい色と中間色の**市松（ディザ）**で出している
- 観察: 王ネズミ（ボス絵）は、細かい陰影ではなく**ひとつの暗い塊＋小物（王冠・首飾り・金貨の山）**でボスらしさを出している。オオカミの霊は、**輪郭を何重にもずらして描く（同心の縁取り）**ことで光のもやを表している。スライムの参考は、どれも平たい半円（ドーム）＋照りの点で、うちの「しずく」（球＋単眼＋水たまり）とは形が違うことを確かめた
- 失敗: 文字グリッドの手書きで、行の長さがそろわないまま複数のアイコンを1枚に並べたら、エディタ上でずれた（食い違い554マス）。**複数の絵を並べるときは、行の長さを機械的にそろえてから描く**（`editor-draw.mjs` は、食い違いを数えて知らせる）

### 第9回の続き: オオカミ（一から・3回目、横向き）
- 正面向きで2回失敗した（猫に見えた）ので、**横向き（左向き）**に変えて描いた。長く伸びる鼻づら、首のふさ、背中のぎざぎざ、尾の房、細い脚を足したところ、**初めてオオカミに見えた**。→ 犬科は、鼻づらの長さが見分けの決め手で、それが見える横向きが描きやすい。正面向きは、鼻づらが短く見えて猫になる（練習の型: 難しい向きは、まず読みやすい向きで描いて形を身につける）

## 練習から言えること（まとめ）
1. 模写は「全体の外形 → 傾き・幅を数える → 中の陰影」の順。見えた所から描くと欠ける
2. なぞり（輪郭だけ写す）で形を固定すると、陰影の練習に集中できる。一致率は色より**シルエットとランプの順序**を見る
3. 面のある硬い物（結晶・家）は多角形で面を作る。柔らかい物（木・毛皮・水）は楕円体の塊と、縁のぎざぎざ
4. 重なりには必ず**内側にも輪郭線**（ヘビのとぐろ、虫の背の割れ目）
5. 自作は「描く→エディタで見る→直して描き直す」を最低2回。1回目はたいてい別の物に見える（ヘビ→カモ、結晶→波、オオカミ→猫）

6. 難しい向き・題材は、読みやすい向きで先に成功させる（オオカミは横向きで成功、正面向きは2回失敗）

# 戦闘のルール（初版・調整前提）

実装は `src/game/battle/` にある。数値は今後のバランス担当の検証で調整する（`CLAUDE.md` 2-3、roles.md 3-6）。

## 能力値

| 能力値 | 意味 |
|---|---|
| HP | 体力。0になると戦闘不能 |
| MP | 特技を使うためのポイント |
| こうげき | たたかう・特技の威力のもとになる |
| ぼうぎょ | 受けるダメージを減らす |
| すばやさ | 行動順・命中・逃走の判定に使う |

## ダメージ計算

```
基本ダメージ = max(1, こうげき × 威力倍率 − ぼうぎょ ÷ 2)
実際のダメージ = round(基本ダメージ × ばらつき（90%〜110%））
会心のとき: 実際のダメージ × 2、会心率は6.25%（16回に1回程度）
```

「たたかう」の威力倍率は1.0。特技はデータごとに威力倍率とMP消費を持つ。

## 行動順

すばやさが高い順に行動する。同じすばやさの場合は乱数で決める。

## コマンド

- **たたかう**: 通常攻撃
- **とくぎ**: MPを消費して特技を使う（威力・効果はデータで定義）
- **どうぐ**: 道具を使う（回復など）
- **ぼうぎょ**: 次に受けるダメージを半分にする
- **にげる**: 成功率 = 0.5 + (自パーティ平均すばやさ − 敵平均すばやさ) ÷ 100（10%〜90%の範囲）。成功すると戦闘終了、失敗すると1ターム消費する

## 勝敗判定

- 敵が全員戦闘不能 → 勝利
- 味方が全員戦闘不能 → 全滅（`CLAUDE.md` 2-1のとおり、所持金半分で最後の記録地点から再開する想定。セーブ実装後に対応）

## 乱数

`src/game/random.ts` のシード指定できる乱数（mulberry32）を使う。自動テスト・自動シミュレーションで同じ結果を再現できるようにするため（roles.md 3-6・3-9）。

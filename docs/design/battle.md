# 戦闘のルール（初版・調整前提）

実装は `src/game/battle/` にある。数値は今後のバランス担当の検証で調整する（`CLAUDE.md` 2-3、roles.md 3-6）。

## 能力値

| 能力値 | 意味 |
|---|---|
| HP | 体力。0になると戦闘不能 |
| MP | 特技を使うためのポイント |
| こうげき | たたかう・特技の威力のもとになる |
| ぼうぎょ | 受けるダメージを減らす |
| すばやさ | 行動順・命中・逃走の判定に使う |

## ダメージ計算

```
基本ダメージ = max(1, こうげき × 威力倍率 − ぼうぎょ ÷ 2)
実際のダメージ = round(基本ダメージ × ばらつき（90%〜110%））
会心のとき: 実際のダメージ × 2、会心率は6.25%（16回に1回程度）
```

「たたかう」の威力倍率は1.0。特技はデータごとに威力倍率とMP消費を持つ。

## 行動順

すばやさが高い順に行動する。同じすばやさの場合は乱数で決める。

## コマンド

- **たたかう**: 通常攻撃
- **とくぎ**: MPを消費して特技を使う（威力・効果はデータで定義）
- **どうぐ**: 道具を使う（回復など）
- **ぼうぎょ**: 次に受けるダメージを半分にする
- **にげる**: 成功率 = 0.5 + (自パーティ平均すばやさ − 敵平均すばやさ) ÷ 100（10%〜90%の範囲）。成功すると戦闘終了、失敗すると1ターム消費する

## 勝敗判定

- 敵が全員戦闘不能 → 勝利
- 味方が全員戦闘不能 → 全滅（`CLAUDE.md` 2-1のとおり、所持金半分で最後の記録地点から再開する想定。セーブ実装後に対応）

## 乱数

`src/game/random.ts` のシード指定できる乱数（mulberry32）を使う。自動テスト・自動シミュレーションで同じ結果を再現できるようにするため（roles.md 3-6・3-9）。

## 呪文名の付け方（オリジナル）

ドラゴンクエストやファイナルファンタジーのような、いわゆる王道RPGの「弱い呪文→強い呪文」という段階分けの様式（ジャンルのお約束、`CLAUDE.md` 1-1で自由に使ってよいとされている部分）は参考にしつつ、名前そのものは`docs/story/bible.md` 4「共鳴術」の命名規則（**系統名＋効果を表す和語**）でオリジナルに作る。既存作の呪文名（メラ系、ファイア系など）はそのままはもちろん、音の響きが似た名前も避ける。

例（序章で実装済みの「火照ノ一」以外の、今後の参考イメージ）:

| 系統 | 弱い呪文の例 | 強い呪文の例 |
|---|---|---|
| 火照系（攻撃・熱） | 火照ノ一 | 火照ノ皆 |
| 水紋系（回復・防御） | 凪ぎ癒し | 満ち凪ぎ |
| 風唱系（速度・状態異常） | 疾風唱 | 迅雷唱 |
| 地固系（防御・拘束） | 縛土ノ壁 | 縛土ノ牢 |
| 光断系（特殊・終盤） | （終盤解禁のため未定。secret-boss.md・第6章の設計時に確定） | |

実際に採用する呪文名・効果は、ゲームデザイナーが`docs/design/`に呪文一覧を作るとき（1-10以降の工程）に確定させる。上表はあくまで名付けの方向性の例。

## 成長とバランスの想定（2026-09-30、roadmap 7-2）

- **ランダムエンカウント**: 町・ボスの間・禁域を除く19か所で、12〜26歩ごとに1〜3体の敵が出る（`src/game/encounter/`）。敵の強さ・経験値は、その場所の**想定レベル**で決まる。
- **想定レベル**（ボスに挑むときのユーリ＋仲間のレベル）: 第1章 Lv5 → 第2章 Lv7 → 第3章 Lv9 → 第4章 Lv11 → 第5章 Lv13 → 第6章 Lv15 → 第7章 Lv17 → 第8章 Lv19 → 終章 Lv21 → 深部 Lv23〜25 → 8神 Lv28 → 塔 Lv30〜32 → 環奥 Lv34 → 全環 Lv36。序章のボスだけは、Lv1のユーリ1人。
- **経験値**: 雑魚1体の経験値は「想定レベルから次のレベルまでの必要量の10分の1」（1〜3体の一団なので、約5〜7戦で1レベル）。ボスは「次のレベルまでの必要量の1.5倍」。
- **ボスの勝率の目安**: 本編のボス 約72〜83%、深部の中ボス 約89%、裏ボス「初源の歪み」約48%、8神 約64〜74%、塔・環奥の強敵 約60〜84%、ラスト裏ボス「全環」約36%（想定レベルのパーティ、300回のシミュレーション。`boss-balance.test.ts`）。想定より低いレベルで挑むと、勝率はかなり下がる。
- **仲間の途中加入**: ユーリのレベルより1つ下まで追いついた状態で加わる（`statsAtLevel`）。
- **雑魚戦の強さ**: 想定レベルのパーティが、最悪の3体の一団にも90%以上で勝ち、戦闘後の残りHPが9割以下になる強さ（`encounter.test.ts`）。HPは戦闘ごとに全回復する（宿屋・回復の仕組みは未実装）ため、雑魚戦は「ボス戦に向けたレベル上げ」の位置づけ。
- **未調整**: ジョブ・装備・所持品（灯貨・お店）は、まだ戦闘力に含めていない。実装したときに、想定レベルを見直す。


## 効果つきの特技（2026-09-30）

`Skill.effect` で、特技の効果の種類を決める（省略は「敵1体にダメージ」）。

| effect | 効果 | 対象の選び方 | 使っているジョブの特技 |
|---|---|---|---|
| `multi` | 敵1体に `hits` 回ダメージ（MPは1回だけ） | 敵1体を選ぶ | 拳闘士「二連打」「乱れ打ち」 |
| `damageAll` | 生きている敵全員にダメージ | 選ばない | 火照術士「火照の波」、風唱術士「風唱の刃」 |
| `heal` | 味方1人を「使った人のこうげき × `healRatio`」回復 | 味方1人を選ぶ | 水紋術士「水紋の癒し」 |
| `healAll` | 生きている味方全員を回復 | 選ばない | 水紋術士「水紋の慈雨」 |

- 強化・弱体・状態異常（受け流し・足さばき・眠り唄・はやし立てなど）は、まだ戦闘に対応していない。
- 自動シミュレーション（`balance-helpers.ts`）は、これらの効果つき特技を使わない（基本のとくぎのみ）ため、ジョブの特技を使うと、ボスの勝率の目安よりやや易しくなる。

### HPを支払う・一撃で倒すチャンス（悪神ジョブの特技）

- `hpCost`（0〜1）: 使うたびに、使った人の最大HPのこの割合を支払う（HPは1より下がらない）。鬼神の破戒者の特技。
- `koChance`（0〜1）: 敵1体を、このチャンスで一撃で倒す。最大HPが500を超える強敵には効かない（外れたときや強敵には、ふつうのダメージ）。蟲神の呪術師の特技。

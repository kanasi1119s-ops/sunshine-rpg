# フィールド（世界地図）のドット絵の学習メモ（2026-10-03）

人間の指示「フィールドドット絵はちょっと学習してこようか」。ネットの解説記事は、実行環境の通信制限で開けなかった（検索結果の一覧だけ）。そのため、ジャンルで広く知られている作り方と、今のゲーム画面の観察から学んだ。既存作品の絵・配置は、なぞっていない（CLAUDE.md 1-1）。

## 観察した弱点（改善前）
1. 森の塊が、四角いブロックのまま並んでいる（角が直角で、辺がまっすぐ）。
2. 山の大きな塊が、同じ三角形のタイルのくり返しで、外ふちも直線。
3. 山や森のふもとに影が無く、地面と「貼りついて」見えない。
4. 広い平地は、草の濃淡だけで、タイルの繰り返しは目立たないが、起伏がない（これは地形の生成側で林・丘・池をちらして対応済み）。

## 学んだ作り方
- **地形の境目は「優先順位つきの重ね描き」**: 塊（山・森）は、地面（草・道）の上に重なる。重なりの縁は、直線ではなく、角を丸め、辺を1〜3ドットの波にして、下の地面の色を食い込ませる。
- **ふもとの影**: 光は左上。塊の「下」と「右」の地面に、細い影を落とす（山は少し長く、森は短く）。
- **同じ模様のくり返しを隠す**: 同じタイルが並ぶ塊は、タイルごとに明暗を少しゆらす。
- **ハイライトは使わない**（人間の方針）。明るくするのは、ごく薄い白の重ねだけ。

## 実装（今回）
- `src/render/ground-decor.ts` の `erodeMass`（辺の波・角の丸め・内側の明暗のゆらぎ・森の縁の暗い線）と `massShadow`（ふもとの影・山すその小石）。マップのデータは変えない。タイル座標だけで決まる（毎フレーム同じ）。

## 次にやりたいこと（未実施）
- 山・森の専用の「縁・角のタイル」を描く（今は重ね描きで近似）。
- 山の塊のタイル絵を、稜線がつながる形に描き直す（今は三角形の繰り返し）。
- 丘（hills）・砂漠・雪原の縁も、同じ考え方で処理する。

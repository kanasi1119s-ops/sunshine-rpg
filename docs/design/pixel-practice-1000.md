# 参考ドット絵の模写練習1000点（2026-09-30）

人間の指示「学習するためにエディタを使って、参考に入っているドット絵を、慣れるために1000枚作ろう」への対応の記録。

## やったこと
- `assets-src/pixel-library/` の500ファイル（OpenGameArt の CC0、Kenney の CC0、ぴぽや倉庫。規約は `docs/assets-credits.md` に記録済み）から、スプライトを1つずつ切り出し、**1000点**を選んだ（`tools/pixel-art/v7/slice.mjs`）。1ファイルから取るのは3点まで。同じ絵（左右反転を含む）は除いた。色が多すぎる（90色を超える）絵は、練習に向かないので除いた。26色を超える絵は26色にまとめた。
- 1000点すべてを、**ドット絵エディタでマウス操作により描き込み**、エディタの書き出しが元の絵と**1マスも違わない**ことを自動で確認した（`tools/pixel-art/v7/batch-practice.mjs`）。**1000/1000 一致**。
- 練習用のデータと描いた結果は、素材の複製にあたるため、**リポジトリには入れていない**（作業用の場所のみ）。この文書には集計だけを書く。

## 集計
- 種類: キャラクター 361, モンスター 208, フィールド 132, 小物・アイテム・乗り物 77, ダンジョン 64, 町・屋内 63, ボス 60, マップ（完成図・見本） 35
- 素材の規約: CC0 1.0 509, ぴぽや 無料素材利用規約 491
- 大きさ: 平均の面積 738 ドット、最大 7110、64ドット以上の辺を持つ絵 59 点
- 色数: 平均 14.3、最大 26
- かかった時間: 1点あたり平均 28.6 秒、最大 276 秒（4並列）

## 見つかった問題と直したこと
- 縦に長く細い絵（幅が10〜30ドットで高さが60ドット以上）で、最下段の行が描けず、18点が最初は一致しなかった。原因は、エディタのキャンバスの外枠（左右上下1ドット）を含めて1マスの大きさを求めていたため、細い絵では下へいくほど位置がずれたこと。枠を除いて縦横それぞれで計算するよう直し、18点とも一致した（`batch-practice.mjs`）。大型の敵・ボスの描き込み（`v5/batch5.mjs`）や人物の道具（`v6/batch6.mjs`）にも、同じ計算が残っているので、細長い絵を描くときは直すこと。

## 次にやること（人間の判断待ち）
- この1000点は「エディタの操作に慣れる」練習で、元の絵をそのまま写した。上達の確認には、「見ないで描く」テストが要る。次の案: (1)一部を、元の絵を見せずに、説明だけで描いて、元の絵と比べる。(2)模写した絵の色・形を変えて、別の絵にする。(3)学んだ技法（陰影・輪郭・光の縁）を使ったオリジナルにする。
- ゲームに入れる絵は、素材の規約で許されたものだけ。ぴぽや素材の模写は、規約の範囲を守る（`docs/assets-credits.md`）。

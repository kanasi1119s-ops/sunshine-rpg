# ドット絵の練習記録（2026-09-30、人間の指示「エディタで練習・学習」）

`tools/pixel-art/v3/` に、32×32の手描きの絵31点と、描く様子の「6倍速の縦動画」を作る道具を置いた。**ゲームには入れていない**（人間の判断待ち）。絵は、素材ライブラリ（`assets-src/pixel-library/`）や `assets-src/pipoya/charachip/` の作りを見て学んだうえで、すべて自分で描いたオリジナル。

## 作った絵
- 仲間6人: ユーリ・レト・ミナ・ガイド・オルカ・アヤメ（`*-front.mjs`）
- 町・物語の人: カセン・エドレア・ドルン・村長・宿屋の主人・町の子ども・行商人
- 敵6体: 火照ノ一・灯り草・歪みの子・石の番人・灯り蛾・錆の蟲（`*-mon.mjs`）
- アイテム6点: 回復薬・灯り石・宝箱・旅の剣・薬草・古い鍵（`*-item.mjs`）
- ボス縮小絵6体: 灯里の歪み・積荷の歪み・実験の歪み・砂嵐の歪み・予言の歪み・試作機の歪み（`boss-*.mjs`）

## 学んだこと（次に生かす）
1. **左半分（16列）だけ描いて鏡写しにし、非対称の部分を上書きする**（`sprite.mjs` の `mirror`・`overrides`）と、左右のゆがみが出ず、速く描ける。人物は、共通の骨組み（ユーリ）から、髪・服・小物を上書きして描き分けた
2. 32×32の人物は、頭が全体の6割ほど（2頭身）。頭の輪郭の段の増やし方を規則的にすると、なめらかに見える
3. 縁取りは黒ではなく、部位ごとの暗い色。光は左上
4. **キャラクターの目には、必ず白いハイライトを入れる**（2026-09-30 人間の指示）。閉じた目・細い目でも、開けて白い点を1つ。`check-eyes.mjs` で確かめる
5. 色は1枚26色まで（エディタの記号の上限）。絵ごとに色を割り当てる（`pal`）
6. 直したいこと: 髪や服の陰影が、なめらかな塊になりやすい。手のポーズが硬い。向き（横・後ろ）と歩きのコマは未作成

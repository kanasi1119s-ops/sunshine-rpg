# フィールドの町・塔・洞窟・祠のドット絵の勉強（2026-10-05）

人間の指示「フィールド上の町、塔、洞窟、祠のドット絵をちょっと学んできて」で調べたことと、練習の結果のまとめ。
練習の絵は `assets-src/pixel-practice/r23-field-icons/`（`study.py` で作り、ドット絵エディタで描いて食い違い0マスを確認）。**ゲームにはまだ入れていない。**

## 調べたもの

- **ぴぽや「フィールドマップセット１」**（`assets-src/pipoya/pipo-map001/`。フィールドの草・森・水などの地面の絵は、もうこの素材集から使っている）。同じ素材集の城・町・塔・洞窟の絵を、**見え方・光・色の段数を学ぶため**に拡大して観察した（絵そのものは使わず、写してもいない）。
- 解説の記事（SLYNYRD の Pixelblog「Graphical Projection」「Top Down Objects」、Lospec のチュートリアル一覧、日本語の「ドット絵でマップを描こう」など）。この作業環境からはページの本文が読めなかった（ネットワークの制限）ので、検索結果の要約だけを参考にした。要点は「斜め45度くらい上から見下ろすと、屋根と正面の両方が見える」「光は上の角のどちらか（ふつうは左上）から」「地面にふちの影を落とすと立体に見える」。

## 今のアイコンが「シールを貼ったよう」に見える理由（ゲームの画面で確かめた）

1. **黒い縁取り**。地面（ぴぽやの絵）は黒い線を使っていないので、アイコンだけ浮く。
2. **真横から見た形**。地面は「斜め上から見下ろす」見え方なのに、アイコンは正面図（三角の洞窟、横から見た家）。
3. **色の段が2〜3段で、べた塗り**。地面は1つの素材に5〜7段の色がある。
4. **足もとが地面に乗っていない**。影がなく、草の小島の台座だけで立っている。
5. **小さい・細い**。村は48×48の下半分だけ、祠は線だけの枠で、まわりの森の模様に負ける。

## 学んだこと（これからの描き方のきまり）

1. **縁は黒ではなく、その素材のいちばん暗い色**。光の当たる左・上のふちは1段だけ暗く、影の右・下のふちはいちばん暗く（`study.py` の `outline_dark`）。
2. **斜め上から見下ろす見え方**。塔は上のだ円の面と胸壁が、町は石垣の輪の上の面と、手前だけ見える側面が、祠は張り出した屋根の上の面が見える。だ円のつぶれ（縦÷横）はおよそ 0.35〜0.4。
3. **光は左上から**。丸い物（塔・岩山・木）は、左が明るく右が暗い。面で考える物（屋根・石段）は、上の面が明るく、手前の面が暗い。
4. **1つの素材に5〜6段の色**（石・岩・屋根）。真ん中の3段で形を作り、いちばん暗い段はすき間と縁、いちばん明るい段は左上の角だけに使う。
5. **模様は「かたまり」で**。岩は大きめの岩のかたまり（1つずつに左上の光）、石垣は段ごとにずらした目地、屋根は2ドットごとの瓦の列。1ドットの点をばらまくと、ゲームの画面ではざらつくだけになる。
6. **48×48の枠をしっかり使う**。下の数ドットまで建物を置き、まわりの森や山に負けない大きさにする。
7. **足もとの影**。今のゲームのドット絵の色は不透明だけなので、絵に影を描きこむと雪や砂の上で色が合わない。**ゲームでは、アイコンの下にコードで半透明のだ円の影を敷く**のがよい（練習のプレビュー `study-preview.png` は、この方法で影を試している）。
8. **ジャンルのお約束は使ってよいが、形はこの世界のものに**。祠には、この世界の「環信仰」のしるし（三つの環、いちばん小さな環が欠ける）を屋根にのせた。

## 2回目の勉強（町・塔・洞窟・祠・特別な塔・お城）

人間の指示「町、塔、洞窟、祠、さらに特別な塔とお城ももっと勉強してきて」（2026-10-05）で、1回目よりくわしく観察し、6点を練習した。
練習の絵は `assets-src/pixel-practice/r23-field-icons/`（`study2.py` で作り、ドット絵エディタで「食い違い 0 マス」を確認）。**今回もゲームにはまだ入れていない。**

### 何を見たか

拡大して観察したもの（絵は写さず、**見え方・光・色の段数・形の組み立て方だけ**を学んだ）。

- ぴぽや「フィールドマップセット１」の城（灰色の城・青い屋根の城・暗い城）、丸い塔、角ばった塔、町のかたまり、洞窟の口（`assets-src/pipoya/pipo-map001/`）
- OpenGameArt の無料素材（CC0）: `oga-overworld-grass.png` の柵で囲んだ村・大きな聖堂・小さな塔、`oga-puny-world.png` の家と城の部品、`oga-pastoral-overworld.png` の家と山、`oga-adventure-awaits-*` の家、`oga-rpg-tile-set-stonelands-*`（8ビットの岩）
- 検索の要約（ページ本文はネットワークの制限で読めない）: 「小さくても分かるシルエットを先に決める」「色は少なく、段をはっきり」

数で確かめたこと（ぴぽやの城・塔・洞窟を調べた結果）

- 1つの絵に使う**不透明な色はとても多い**（城で100色以上）が、**面積の大きい色は20〜40色**。つまり「段は5〜6段、残りは境目のなじませ」。わたしたちは不透明なドット絵なので、**面積の大きい色だけを5〜6段つくる**のが正解だった。
- 絵の下と右には、**半透明の影が必ず敷いてある**（絵の外に3〜5ドットはみ出す）。ゲームではコードで半透明のだ円を敷く方針（1回目と同じ）で合っている。
- 64×64の城は、**絵のほぼ全部（左右5ドットほどを残して）を使い切る**。32×32の洞窟も同じ。

### 2回目に決めたきまり（数で言えるもの）

1. **形は「上の面＋手前の面」の2つだけで組む。** 横の面は描かない（真正面から少し見下ろす見え方）。明るさは **上の面 0.85〜1.0 / 左の面 0.75 / 手前の面 0.5 / 右の面 0.3**（0〜1の段の位置）。
2. **だ円のつぶれ（縦÷横）は 0.30〜0.40。** 塔の上の面は 0.36、足もとの台座は 0.30、とんがり屋根のすそは 0.35。石の段の線も**同じだ円の弧で下へふくらませる**と、まわりこんで見える。
3. **寄棟の屋根は「いちばん近い軒からの距離」で面を分ける。** 瓦の線は面ごとに軒と平行。**暗い面（右）では瓦の線を半分の濃さ**にする（強いと縦じまに見える）。面のさかい（棟）は1ドットだけ明るく。
4. **屋根と壁の高さの比**: 48×48の家は 屋根7：壁4（屋根のほうが太い）。64×64の城の天守は 屋根16：壁14。**屋根を壁より大きく**すると、小さくしても「建物」に見える。
5. **窓は幅1〜2ドット・高さ3〜4ドット**の縦長。**下に1ドットの明るい棚（石）**を置くと窓に見える。**明かり（黄色）は窓の2〜3個に1つだけ**。窓を2つ横に並べて穴を2つ作ると**顔に見える**ので、段ごとに互いちがいに置く。
6. **シルエットは高さを3段にする。** 城＝角の塔（いちばん高い）／天守／壁、町＝鐘の塔／家／石垣、特別な塔＝浮かぶ石／塔／台座。同じ高さの物だけだと、小さくしたとき四角いかたまりに見える。
7. **岩は「大きな面の集まり」で描く。** 1つの面は**ほぼ1色**、面の上・左のふちを1段明るく、下・右のふちを2段暗くする（`cave2`）。1ドットの点をまくより、12〜20個の面に割るほうが岩に見える。面の大きさはそろえない（そろえるとレンガに見える）。
8. **「特別・魔法」は、色をばらまかずに形で見せる。** 光は **芯（白に近い1色）→まわり1段** の2色だけ。光る物のまわりに置く点も、**決まった2〜4か所**だけ（ばらまかない）。`spire2` では「浮かぶ光の石＋金色の3つの環（いちばん小さな環は欠ける＝この世界の環信仰）」で特別さを出した。
9. **地面の色との相性**: 石は**少し暖かい灰色**（緑の草の上で浮かない）、屋根は**青緑か赤茶**（草の緑とけんかしない色）。雪の町は**青白＋濃い青と赤**。砂の上では暖かい灰色が沈むので、**いちばん明るい段を1段上げる**とよい（今回は同じ絵のまま、影の色だけ変えて確かめた）。
10. **絵の中に草のふさを描かない。** 1回目は足もとに草を描いたが、雪や砂の上に置くと浮く。地面の違いは**コードの影と地面にまかせる**。

- **`castle` は「斜め上から」より「正面から少しだけ見下ろす」に寄っている。** 中庭を描いたが、手前の壁と門でほとんど隠れてしまった。本当に斜め上から見せるなら、壁の輪をだ円にして中庭を見せる形にやりなおす必要がある。
- **`town2` の家6軒は、同じ形の色違い。** 本物の町なら、大きさ・向き・屋根の形を変えるべき。また雪のかたまりが角ばっていて、やわらかく見えない。

## 3回目の勉強

人間の指示「いいね、教会以外はもっと勉強してきて」（2026-10-05）で、2回目の弱いところを直し、ゲームにあるほかのアイコンの種類もすべて練習した。
練習の絵は `assets-src/pixel-practice/r23-field-icons/`（`study3.py` で作り、プレビューの道具は `study3_view.py`）。23点とも、ドット絵エディタで「食い違い 0 マス」を確かめた。**今回もゲームにはまだ入れていない。**

### 何をしたか

- ゲームの本物の地形の絵（`assets-src/field/terrain/w-*.png`。1マス16ドット、絵は世界の座標でつながる）と、本物の地図（`src/game/map/world/world-map.generated.ts`）を使って、**地図の上に置いたときの見え方**を確かめた（`study3-world.png`）。
- 地面の色の明るさを数で測り、アイコンの色と比べた（下の表）。

| 地面 | 平均の色 | 明るさ（0〜100） |
|---|---|---|
| 草 | #5aa93b | 62 |
| 森 | #378131 | 48 |
| 雪 | #e8f0f8 | 94 |
| 砂 | #e6d29c | 85 |

### 3回目に決めたきまり（家族のきまり）

1. **1枚16色まで。** どの素材も「共通の縁の色 `o`（#2b2631）」と「共通の穴の色 `k`（#120e16）」を使い、**素材ごとの色は3〜4段だけ**にする。1回目・2回目は素材ごとに6段（いちばん暗い段も別々）だったので、24〜26色になっていた。いちばん暗い段を共通にするだけで、5〜8色減る。
2. **色は家族のパレット（`study3.py` の `MASTER`、48色）から選ぶ。** 石はどの絵でも同じ4色、青緑の屋根も同じ4色。だから城・港町・浮き島を並べても、同じ世界の物に見える。1枚で使う素材は3〜4種類にしぼる（例: 港町＝石・赤い屋根・しっくい・木・水）。
3. **色が足りないときは、段を減らす前に素材を減らす。** 港町は青緑の屋根をやめて赤い屋根だけに、湖の町は葦の暗い緑をやめて木の色で代用した。段を減らすと形が平たくなるが、素材を減らしても形はくずれない。
4. **光は左上、だ円のつぶれは 0.36。** 屋根・円柱・とんがり屋根・寄棟・石積みは、全部同じ道具（`study2.py` と `study3.py` の関数）で描く。手で1枚ずつ明るさを決めないことが、家族に見えるいちばんの近道だった。
5. **奥の物は細く暗く、手前の物は太く明るく。** 特別な塔の環は、奥の半分を1ドットの暗い色にして先に描き（塔に隠れる）、手前の半分を2〜3ドットの明るい金にした。これで環が塔をぐるりと回っているのが分かる。
6. **見下ろす角度を急にすると、中庭が見える。** お城は、壁の手前の面を5ドット（2回目は9ドット）、奥の壁の面を3ドットにし、手前の角の塔をとんがり屋根でなく平らな屋上にした。これで中庭（石だたみ・4本の木・天守への道）が見える。
7. **建物の集まりは、1つの地面に乗せる。** 家を草の上にばらばらに置くと「家が4つ」に見える。港町は石だたみ、村はこげ茶の土、雪の町は踏まれた雪の広場に乗せると「町」に見える。広場の色は**屋根より1段暗く**する（雪の町で、屋根の雪と広場の雪が同じ白だと家が消えた）。
8. **家は形を変える。** 寄棟・棟が横の家・妻（三角の壁）がこちらを向く家の3種類と、えんとつ。**扉は右より、窓は左より**に置く（まん中の扉と左右の窓は顔に見える。2回目までに何度も顔に見えた）。
9. **雪は丸いこぶで。** 5ドットはばの半円のこぶを並べ、こぶの右下の1ドットだけ影の色にする。しずくやとがった歯は、つららに見えてかたい。
10. **岩は、向き・伸び・大きさがばらばらの面＋ななめの割れ目。** 面ごとに伸びる向きを変え（異方性のボロノイ）、大きい面の一部に右下へのびる3〜5ドットの割れ目（左どなりは1段明るく）を入れる。面の形がそろうとレンガ、そろわないと岩に見える。

### 地面ごとの明るさの直し方（草・雪・砂で確かめた結果。`study3-grounds.png`）

- **草（62）**: 石のまん中の段（#a49a88、64）とほぼ同じ明るさ。色の違いで分かるので問題ないが、形は縁 `o` と上の面の明るい段（80）が支えている。直しは不要。
- **雪（94）**: 雪・雲・しっくいの白（85〜97）がとけこむ。雪の町は、家の壁と屋根の色、足もとの半透明の影があれば読める。**雪の上に置く絵は、白い所をふちに出さず、ふちは1段暗い青白（#93a6c8、68）にする**。影の色は青みにする（今回のプレビューは青みの影）。
- **砂（85）**: 石の明るい段（80）・しっくい（90）・わら（74〜88）が近い。縁 `o` があるので形は残るが、天幕や遺跡の明るい面が地面と同じに見える。**砂の上の絵は、上の面の明るさを1段下げる（いちばん明るい石を使わない）か、影を少し濃くする**とよい。
- **海（37）・荒れ地（35）**: 暗い段（32〜38）がとけこむ。小島は波の白い線が島を海から分けている。宮殿は荒れ地の上で壁が沈むので、**金の屋根と灯の窓で形を見せる**か、壁を1段明るくする。

### 4回目のきまり（なじませるきまり）

1. **色は、置く地面の地形の絵から取る。** 草・森・山の岩・道・砂・雪・海の色は、地形の絵の色そのもの。足す色（屋根の赤茶・青い石板・しっくい・灯）は少しだけにする。あざやかさは地形と同じ0.6前後、明るさは30〜80の中に収める。
2. **黒い縁どりはしない。** 縁は「影の側（右と下）だけ、その素材のいちばん暗い色」にする。森の房や山の岩のすき間と同じやり方。
3. **模様のきめを地形にそろえる。** 石は山の岩の色と同じ段、木は森の房と同じ色と同じ大きさ（はば7〜8ドット。1回目の見直しで、房が小さいと「しげみ」に見えたので1.2倍にした）、雪の木は雪の森と同じ小さな針葉樹。
4. **足もとは、地面の色をドットで描きこむ。** 建物の下に地面の色を暗くした影（草なら #2f6e24 と #3a7a2a の2段。市松でまぜてやわらかく）をつける。建物の下のふちには、草の葉・雪の吹きだまり・砂を手前からかぶせる。地面ごとに絵を分ける（`-grass` / `-snow`）。コードの半透明の影は使わない。
5. **見えない地面はけずる。** 地形と同じ色だけの「すそ」は、地図の上ではどうせ見えない。そのため、建物から1ドットより遠い所は消す。
6. **色が16をこえたら、まず地面の粒の色どうしをまとめる。** 建物や森の色をまとめるとこわれる（祠の森が草の色になってしまった）。地面の粒は2色でも見え方が変わらない。
7. **大きさは小さめ。** 家は横8〜12ドット（木の房の1.5倍くらい）、お城は横30ドットくらい。48ドットの枠をうめない。
8. **1つだけ「見つける目じるし」を残す。** なじませすぎると、地図の上で見つからない（2回目の見直しで、村・鉱山・祠が見えなくなった）。屋根の色、暗い入口、灯の黄色のどれか1つは、まわりと明るさの差を25〜35残す。祠は屋根を青い石板にし、洞窟は入口を大きくした。
9. 光は地形と同じ左上から。

### わかったこと

- **1ドットの線を消す「点の掃除」は、ななめの線（櫂・綱・寄棟の稜線・雪の峰）までこわしていた。** ななめにつながる同じ色があるドットは「線」として残すようにした。そのため、霧間の集落・浮嶼・宮殿でも、寄棟の稜線などが 10〜32 ドット元にもどった。
- 雪の上では、白い部品（屋根の雪）は形が消える。形は色のついた面で作り、雪は細い線だけにする。
- 明るい壁や水の前に置くと、木の細い部品（水車の腕・柵）が読める。草の上だけだと消える。

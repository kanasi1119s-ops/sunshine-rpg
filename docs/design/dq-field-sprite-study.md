# 王道RPGのフィールドキャラ（小さな歩行ドット絵）の作り方：技法の学習メモ

2026-10-03、人間（旭さん）の指示「ドラクエのフィールドのドット絵キャラの作り方を参考にして」「隅々まで細かく学んで」に基づく。
**学ぶのは「作り方（技法）」だけ。** 特定のキャラの絵・配色・デザインは真似しない（CLAUDE.md 1-1）。
情報源は、解説サイトの検索結果の要約（ページ本体は通信制限で読めなかった）と、手元の素材集（`assets-src/`）の観察。

## 学んだ技法（要点）
| 項目 | 学んだこと | 当ゲームでの取り入れ方 |
|---|---|---|
| 大きさ | 王道のSFC作の歩行キャラは 16×24 前後が基本。 | 当ゲームは 16×32（ゲームの縦横比に合わせて背を少し高く）。 |
| 頭身 | 頭がとても大きい 2頭身。頭:体:足 ＝ おおよそ 14:5:5 の比（頭が全体の半分以上）。 | 頭を大きく保つ。今後の描き直しでさらに頭を大きくする候補。 |
| 色数 | 16×16 では 3〜5色。量産の町人は4色、主役級や装備差を見せたい人は8色まで。SFC は1キャラ15色以内。 | 1キャラ15〜23色（輪郭・肌・髪・服2色・靴・目）。町人は役割色の塗り替えで量産。 |
| 塗り方 | 「下書き → 線画 → 影なしでベタ塗り → 影」の順。影を先に塗ると直しにくい。影は1段だけ。 | **ハイライト（照り）をやめ、影と地の2段だけの「つや消し」にした**（2026-10-03）。 |
| 輪郭 | 全体を濃い色で囲う。内側の線は最小限（部品の境だけ）。 | 縁取りは素材ごとの暗色。 |
| 顔 | 目は点（1〜2ドット）。白目を付ける作風も付けない作風もある。口・鼻は省くか1ドット。 | 目は点＋まぶたの線。白い反射は付けない。 |
| 向き | 正面・後ろ・横。後ろは顔なしで髪のかたまり。横は目が1つ、腕は片方だけ見える。 | 4方向を手描き（実装済み）。 |
| 歩き | 立ち→片足前→立ち→反対の足前（0→1→0→2）の型。体を1〜2ドット上下させると重みが出る。腕は足と逆に振る。足元の線は同じ行にそろえる。 | 実装済み（テストで足元をそろえている）。 |
| 量産 | 町人は髪型・服・帽子の形と色を変えて作る。 | 素体3種（短髪・長髪・ツインテ）＋役割色の塗り替え（実装済み）。 |

## 次にやること
- 頭をさらに大きく（頭:体:足 ≒ 14:5:5 に近づける）素体の描き直し。
- 町人の職業別のシルエット（帽子・エプロン・ローブ・よろい）の追加。
- 歩きのコマで体を1ドット上下させているか確認し、足りなければ足す。

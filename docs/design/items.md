# 装備・アイテムのルール（初版・調整前提）

実装は `src/game/items/` にある。

## アイテムの種類

- **消費アイテム**（どうぐ）: 使うとHPなどを回復し、1つ消費する。戦闘中・フィールドどちらでも使える想定
- **装備品**（ぶき・よろい・アクセサリ）: キャラクターに装備すると能力値にボーナスがつく。装備を外しても消えない（何度でも着せ替えできる）

## 所持品（インベントリ）

パーティ全体で共有する所持品リストを持つ（`docs/design/battle.md` のパーティと同じ考え方）。同じアイテムは個数で管理する。

## 装備の効果

装備はキャラクターの**基本能力値（レベルで決まる値）**を変えない。効果は「今の装備で戦うとどうなるか」を都度計算する（効果的な能力値 = 基本能力値 + 装備ボーナスの合計）。こうすることで、装備の着せ替えが自由にでき、外したときに数値がおかしくならない。

装備スロットは「ぶき・よろい・アクセサリ」の3つ。1種類につき1つまで装備できる。

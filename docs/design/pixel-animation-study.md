# ドット絵アニメーションの勉強メモ（2026-10-04）

人間の指示「ドット絵アニメーションの勉強をしてきてほしい」。予言の歪み（256×256のボス）の歩く動き・攻撃の動きを作ったときに、
「歩きは左右の動きが大きく、上下の動きが少ない」「攻撃で体が謎に動いて違和感」「腕を動かして前に出す動きを」「足の一部も攻撃に巻き込まれている」
と指摘を受けた。調べたことと、このゲームでの決まりをまとめる。

## 1. 歩く動き

- 基本の4つの形: **接地**（前の足が地面につく）→ **沈みこみ**（体重がかかって、体がいちばん低い）→ **通過**（足どうしがすれ違う。片足が上がる）→ **伸び上がり**（体がいちばん高い）。これを左右で1回ずつ、合わせて8コマ（小さな絵なら4コマ）。
- **体の動きの中心は上下**。2ドットの上下だけでも生きて見える。左右のゆれは、支える足の側へ1ドットほどにとどめる（大きいと酔ったように見える）。
- 腕は足と**反対**に振る（左足が前なら右腕が前）。
- 重い大きな敵は、ゆっくり・沈みこみを長めに止める（接地・沈みこみ 170〜230ミリ秒、通過・伸び上がり 150ミリ秒ほど）。沈みこみで胴を1〜2ドット縮めると重さが出る。

## 2. 攻撃の動き

- 流れ: **構え → ため（予備動作）→ 振り（速い。1コマ）→ 当たり → 振り抜け → 戻り（少し戻りすぎて、はね返る）→ 構え**。
- **ため**は、攻撃と反対へ引く（腕を後ろ・横へ引く、肩を上げる、体を少し沈める）。長めに止めて、何が来るか分からせる。
- **振り**は1コマで速く。形と形のあいだに**残像（スミア）**を1コマ入れると、少ないコマでもなめらかに見える。残像は、腕の通り道（円弧）に沿って描く。
- **当たり**は長めに止める（150〜200ミリ秒）。火花・光・画面の揺れ（1〜3ドット）を足すと重さが伝わる。
- 動くのは**主に腕**。胴は少し傾ける・沈む程度。体全体をゆがめたり大きくしたりすると、何をしているのか分からなくなる（最初に作った版の失敗）。
- 正面向きの絵で「前に出す」は、手前に来るので**腕を大きく描く**（遠近）。

## 3. 大きな絵（256×256のボス）の動かし方

- 腕・足を**部品として切り分け**、関節（肩・足の付け根）を中心に回す・ずらす（切り絵のアニメーション）。回すときは最近傍で、ぼかさない。あとで1ドットずつ整える。
- 部品の切り分けは、**手の高さでは外側の手・爪だけ**にする。腰・太ももの横に手があると、腕の範囲に太ももが入り、攻撃で足の一部まで動いてしまう（指摘された失敗）。`boss_anim.py` の `lower_from`。
- 腕を切り取ったあとに胴の重なっていた所が穴になるので、近くの胴の色で埋める。
- 正面向きで絵いっぱいに大きなボスは、腕を外へ大きく振ると絵の外に出る。頭の上へ回すと形が崩れ、胸の前を横切ると胸と同じ色で見えなくなる。**横へ引く（ため）→ 爪を手前・下へ突き出す（大きく）**が読みやすい。

## 3b. 部品を描き分ける（2回目の勉強、人間の指示「もっと勉強して」「腕を別の部品として描き分けて」）

- **隠れている所まで描く**: 部品を回すと、ほかの部品に隠れていた所が見える。腕の付け根・肩当ての下・腕に隠れていた胴の横も、先に描いておく（すき間ができない）。
- **関節は丸く**: 肩・ひじなど回す所は、円に近い形にする。付け根が円なら、どの角度に回してもすき間が出ない。重なる所の端も丸める。
- **まっすぐな形から**: 部品は、曲げていないまっすぐな形で描く（どちらへも曲げられる）。
- **前と後ろでレイヤーを分ける**: 体の前に出る部品と後ろに回る部品は、別のレイヤーにする。上にかぶせる部品（肩当て）で付け根をかくす。
- **ドット絵の回し方（RotSprite）**: そのまま回すと線がぎざぎざになり、1ドットの穴があく。2倍拡大（Scale2x・EPX）を2〜3回 → 回す → 元の大きさにもどす（かたまりごとに多い色を選ぶ）と、形がくずれにくい。回したあとは1ドットずつ整える。
- **サブピクセル**: 呼吸・待機などの小さくゆっくりした動きは、体を1ドット動かす代わりに、色の境目を1ドットずつ広げたり狭めたりして見せる（大きな絵向き）。
- **キーフレームが先**: まず「ため」「当たり」など読める決めの形を作り、あいだのコマは少なく。なめらかさより勢い。コマの長さで勢いが決まる（少ないコマなら速く再生）。
- 実装: `tools/pixel-art/ai-gen/boss_rig.py`（胴・左腕・右腕・左肩当て・右肩当てのレイヤー。部品の範囲・関節はボスごとの `rig.json`）。予言の歪みでは、腕を頭の上まで振り上げ、体の前へ振り下ろせるようになった。
- **腕が切れて見えた**（人間の指摘）: 腕の部品の上の端がまっすぐな切り口のままだと、回したときに切り口とすき間が見える。付け根に大きな玉（半径18ドット、腕の模様で塗る）を付けて、どの角度でも丸くつながるようにし、玉の上半分を肩当てでかくす（`joint_r`）。
- **コマを増やす**（人間の指示「もっと滑らかに」）: 決めのポーズのあいだに中割りを入れる。歩き8→16コマ（1周の時間は同じ）、攻撃7→14コマ。ためと戻りは「ゆっくり始まり・ゆっくり終わる」中割りを多めに、振り下ろしは残像2コマだけ（速さを残す）。中割りを入れすぎると勢いが消える。
- **攻撃の種類**: 腕だけ／体ごと（ためで上半身を反らして伸び上がり、片足を上げて踏みこむ。当たりで打つ向きへ体を倒して沈む）／両手（両腕を頭の上へ振り上げ、体の前へたたきつける。残像はX字、火花は両手、揺れを大きく）。
- **指先が切れて見えた**（人間の指摘「指先が切れたりしてるよ」）: 原因は2つ。①手の高さでは「外側のいちばん端のかたまりだけ」を腕に入れていたので、内側へ曲がった指や、少しはなれた爪が腕から外れ、攻撃のとき胴の側に置き去りになっていた。→ `rig.json` の `"extra"`（指先を囲む多角形）で腕にもどす。腕の範囲の下の端も、いちばん下の爪の先まで広げた（174→180行）。②回すときの「4×4の16票のうち7票以上で点を置く」が、1〜2ドットの細い爪の先を消していた。→ 5票以上に下げた（`ROT_MIN`、ふだんは5）。
- **はなれた指先は腕と一緒に動かす**（人間の指示「指先が取れてるから一緒に動かして」）: 腕から外れて胴に残った小さなかけら（40ドット未満）は、胴から消す。指先は `extra` で腕の部品に入れる。
- **攻撃のとき腕は体より前**（人間の指摘）: 前へ突き出すコマ（大きさ1.06倍より上）と、頭の上へ振り上げるコマ（90度より上）では、腕が胴の上にかかる所に1ドットの暗い縁（絵でいちばん暗い色）を付ける。胴と同じ色の腕でも、手前にあると分かる。当たりの腕は、もっと内側（体のまん中）へ・大きく（1.34倍ほど）。
- **両手の攻撃は内側へ**（人間の指示「両手の動きは内側に入る感じ」）: 当たりで両手が体のまん中（おなかの前）に集まる（±40度）。振り抜けでさらに内側へ（±46度）。
- **すべての版を残す**（人間の指示）: 予言の歪みの動きは、`assets-src/monsters/kiri-yugami/anim-versions/` に「1 腕が切れる版」「2 丸い関節版」「3 指先なおし版」「4 腕が前・両手が内側版」を残す（gzで圧縮。いま使うのは4と同じ `anim.json`）。
- **エディタの中の再生**は、コマ数が多いと描き直しが追いつかず遅くなる。正しい速さは `anim_clip.py`（コマの長さどおりの動画）で確かめる。

## 4. このゲームでの決まり

- 道具: `tools/pixel-art/ai-gen/boss_anim.py`（部品の範囲・関節は、ボスごとの `parts.json`）。
- 作ったコマは、ドット絵エディタのフレームに入れて、タイムラインとオニオンスキンで確かめる（`tools/pixel-practice/editor-record.mjs` で製作の様子を動画にできる）。
- ゲームの戦闘画面でボスを動かすのは、まだ入れていない（コマのデータだけ）。入れるときは `docs/decisions.md` に書く。

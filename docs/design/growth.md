# 成長のルール（初版・調整前提）

実装は `src/game/growth/` にある。数値は今後のバランス担当の検証で調整する。

## 経験値カーブ

レベル N に到達するために必要な**累計**経験値:

```
必要経験値(N) = floor(20 × N^2.5)
```

序盤は少ない経験値でレベルが上がり、レベルが上がるほど必要量が急激に増える、よくあるRPGの形。

## レベルアップ時の能力値の伸び

キャラクターごとに「成長率」（レベル1回あたりの伸び幅）を持たせる。レベルが上がるたびに、最大HP・最大MP・こうげき・ぼうぎょ・すばやさに成長率の分だけ加算する（現在のHP・MPも同じ分だけ増える＝そのぶん実質回復する）。

```
新しい最大HP = 元の最大HP + HP成長率
新しい最大MP = 元の最大MP + MP成長率
（こうげき・ぼうぎょ・すばやさも同様）
```

成長率は仲間ごとに変える（例: 力型は こうげき成長率を高く、すばやさ型は すばやさ成長率を高く）。実際の値はキャラクターデザイン確定後（フェーズ2）に調整する。

## 経験値の入手

戦闘に勝利すると、倒した敵の経験値の合計をパーティ全員（生存者）が入手する（`Combatant.expReward` で敵ごとに設定）。

## ジョブチェンジ・システムとの関係

- 2026-09-28、人間からの提案でジョブチェンジ・システムを採用した（詳細は `docs/design/jobs.md`）。ここで扱う「キャラクターレベル（1〜99）」は、ジョブとは別に、HP・MP・基礎能力値の伸びだけを管理する軸のまま変わらない
- 特技（じゅもん・とくぎ）の習得は、キャラクターレベルではなく、装備しているジョブの熟練度（1〜15☆）に応じて増えていく方式に変更する。1人1つの固定特技という現状の実装（1-10時点）は、ジョブシステム解禁（アヤメ加入、第6章想定）にあわせて置き換える

## 今後の調整予定

- ジョブ熟練度・ジョブごとの特技解放の実装は `docs/design/jobs.md` 7章・`docs/roadmap.md` フェーズ4（第6章）を参照
- 実際のカーブ・成長率は、章ごとの想定レベル（`docs/playtime-budget.md` 系）と合わせてバランス担当が検証する

# 木のしくみと描き方（ドット絵のための勉強ノート）

2026-10-06 作成。前に作った木の絵が「没。作り直し、もっと木の勉強してきて」と言われたので、
本物の木のつくり・光の当たり方・ドット絵の木の描き方を調べてまとめたノートです。
（調べた内容を自分の言葉でまとめたもの。文章の丸写しはしていません。出典は最後にあります）

---

## 1. 本物の木のつくり

### 1-1. 幹（みき）は「下が太く、上へ行くほど細い」

- 幹はまっすぐな筒ではない。**根元がいちばん太く、地面に近いところで横に広がる**（「根張り」）。
  木は何トンもの重さと風を支えるので、根元は裾（すそ）を広げたような形になる。
- 根元では、縦にのびる幹の皮が、横にはう根っこへと曲がっていく「つなぎ目」が見える。
  根っこは2〜4本くらいが地面に少し顔を出し、すぐに土や草に潜る。
- 幹は上に行くほど細くなり、枝が分かれるたびにさらに細くなる。
- 幹は少し曲がっていてよい。まっすぐすぎる棒は作り物っぽく見える。

### 1-2. 枝の分かれ方

- **レオナルド・ダ・ヴィンチの法則**: 枝分かれした先の枝を全部合わせた太さ（断面積）は、
  分かれる前の幹や枝の太さとだいたい同じ。
  → 「太い幹から急に細い枝が何本も生える」のはおかしい。
  → 2本に分かれたら、それぞれは元の太さの7割くらい。どんどん細くなっていく。
  （最近の研究では、すべての木にぴったり当てはまるわけではないとされるが、絵の目安としては十分）
- わき枝の太さは、くっついている幹の**半分〜4分の3まで**が目安。
- 枝は「Y字」に分かれる。分かれた枝は**上と外へ**向かう（光を取りに行く）。
  下の方の枝は、重みで水平〜少し下向きになる。
- 枝はまっすぐではなく、少しジグザグに折れ曲がりながらのびる（カシ・カエデ・シナノキなどは特に）。

### 1-3. 木の形の2つのタイプ

| タイプ | どんな木 | 形 |
|---|---|---|
| **まるい木（広葉樹に多い）** | カシ・ナラ、ブナ、カエデ、シナノキ、トチノキなど | 主役の幹がはっきりせず、太い枝が何本かに分かれて広がる。**丸・たまご形・横に広い傘形**になる |
| **とがった木（針葉樹に多い）** | マツ、モミ、トウヒなど | まん中に1本まっすぐの幹があり、横枝は短く細い。**三角・円すい形**になる |

広葉樹の例（絵にするときの特徴）:

- **カシ・ナラ（オーク）**: 横に広く、どっしりした丸い形。太い枝がうねる。樹皮はごつごつ。
- **ブナ**: なめらかな灰色の幹。たまご形のまとまった形。
- **カエデ**: 幹は短め。丸〜たまご形。枝先が細かく、軽やかに見える。
- **シナノキ（リンデン）**: 街路樹によくある。たまご形〜丸。
- **トチノキ（マロニエ）**: 大きくて重たい丸。葉のかたまりが大きく、下側がこんもり垂れる。

ゲームの町の木として使いやすいのは、**「カシ・ブナ・シナノキ風の、たまご形〜丸い木」**。

針葉樹:

- 枝は幹の同じ高さからぐるりと放射状に出る（輪生）。それが**段（だん）**になって積み重なる。
- 枝は重みで**S字に垂れる**。葉先は少し下を向く。
- 段ごとに、下側にくっきり影ができる。下の段ほど横に広い。

### 1-4. 葉のかたまり（「房（ふさ）」）

- 葉は1枚ずつ見えるのではなく、**枝の先ごとに「かたまり」**になる。
  かたまりの形は、**カリフラワーやブロッコリーのような、もこもこした丸**。
- 大きな丸い樹冠（じゅかん＝葉の茂った部分全体）は、
  **大きな房 → 中くらいの房 → 小さな房** の入れ子でできている。
- 房と房のあいだには、**すき間**がある。そこから
  - 奥の暗い葉
  - 枝や幹（ちらっと見える）
  - 空（「空の穴」）
  が見える。すき間があると、木が平たい板ではなく、立体に見える。
- 輪郭（シルエット）は、まん丸ではなく、**房ごとの小さなでこぼこ（波形・スカラップ形）**になる。
  ただし、でこぼこは「大・中・小」がまざっていて、同じ大きさの山が並ばないこと。

### 1-5. 空の穴（スカイホール）

- 葉のすき間から見える空。**本物の空より少し暗く・くすんで・青っぽく**塗ると、奥に引っこんで見える。
- 穴は、樹冠の**ふち近く**に多い（まん中は葉が厚くて空が見えない）。
- 穴の数は少なめ（大きな木で2〜4個）。形は不ぞろいにする。
- ドット絵の小さな木（64×80くらい）では、空の穴は **0〜2個、1〜3ドットくらい** で十分。
  町の草の上に立つ木なら、穴からは空ではなく「奥の暗い葉」か「草」が見えることになるので、
  無理に穴を作らず、**暗い葉のすき間**で代わりにしてもよい。

### 1-6. 樹皮の模様

- **カシ・ナラ**: 深いみぞが縦に走り、それが横にちぎれて、ごつごつの板のようになる。
- **ブナ**: なめらかで灰色。ほとんど模様がない。
- **マツ**: 赤茶色で、うろこ状にはがれる。
- 大事なのは**模様より「丸み」**。光が左上から来るなら、**幹の右側はまるごと影**。
  模様は幹の丸みに沿って縦に入れ、影側では模様をほとんど描かない。

## 2. 木への光の当たり方

### 2-1. 樹冠は「大きな球（または雲）」として考える

まず樹冠全体を1つの球だと思って、光と影を決める。そのあとで房ごとに細かく分ける。
**順番が逆（房を一つずつ丸く塗る）だと、もこもこが全部同じ明るさになり、立体に見えない。**

光が左上から来るとき、樹冠全体では:

1. **明るい面（左上）**: 日が当たる。黄色っぽい明るい緑。
2. **中間の面**: 本来の葉の色。
3. **明暗の境目（ターミネーター）**: 明るい面から影へ変わる所。ここが**いちばん色が鮮やか（彩度が高い）**になりやすい。
4. **本影（コアシャドウ、右下寄り）**: いちばん暗い所。青っぽい暗い緑。
5. **照り返し（反射光）**: 影の側のふち（右下のふち）が、地面や空の光を受けて**ほんの少しだけ**明るくなる。
   本影より明るく、でも中間の面よりは暗く。やりすぎると「まくら影（後述）」になるので控えめに。
6. **下側（底）**: 樹冠の下は、空の光も日光も届きにくく、**いちばん暗い**。

### 2-2. 上の房が下の房に影を落とす

- 上の房は、すぐ下の房に**影を落とす**。だから下の房は、上の部分が暗く、
  **少し出っぱった先（左上の頭）だけが明るい**。
- 房を積み重ねるとき、「上の房の下には暗い帯」が入る。これが立体感のいちばんの元。
- 樹冠の中では、**上の方の房ほど明るく、下の方の房ほど暗い**（全体の球の光と合わせる）。

### 2-3. ふちの透け（透過光）

- 葉はうすいので、**光が透ける**。樹冠のふち、特に光の当たる側のふちの葉は、
  **黄緑に光って見える**ことがある。
- ドット絵では、左上のふちの数ドットだけをいちばん明るい黄緑にする、くらいの表現でよい。

### 2-4. 幹への影

- 樹冠の真下の幹は、葉の影に入るので**暗い**。樹冠から出たすぐ下はとくに暗い。
- 幹の明るい所は、**樹冠から離れた根元近くの左側**。
- 枝がすき間から見えるとき、その枝も影の中なので暗い色にする。

### 2-5. 色のずれ（色相シフト）

- **日の当たる所 → 暖かい色（黄色寄りの緑）**。太陽の光は黄色っぽいから。
- **影の所 → 冷たい色（青寄りの緑、青緑）**。影には空の青い光が回りこむから。
- 明るさだけを変えた緑（同じ色相のまま白・黒をまぜた緑）を並べると、**ぼやけて、にごって見える**。
  明るくするときは黄色へ、暗くするときは青へ、色相も少しずつ回す。

### 2-6. 地面の影

- 木の下の地面には、**横長のだ円の影**を置く。木が地面に立っているように見える。
- 影の色は、**草の色を暗く・少し青くした色**（黒をそのまま置かない）。
- 光は左上からなので、影はほんの少し**右下にずらす**。ただし長くのばさない
  （となりのマスとぶつかるから）。
- 影の形は、まん丸より、樹冠の形をつぶしたような**でこぼこのだ円**のほうが自然。

## 3. ドット絵の木の描き方（チュートリアルからわかったこと）

### 3-1. まずシルエット

- 「形が正しくなければ、どれだけ影をつけても救えない」。最初に**1色で塗りつぶした形**で判断する。
- 1色の形だけで「木だ」「どんな木か」が分かるのが目標。
  - 広葉樹: でこぼこのある、たまご形〜丸。幹が下に少し見える。左右対称にしすぎない。
  - 針葉樹: 段のある三角。段のふちはギザギザで、下向き。
- シルエットのでこぼこは「大きな山2〜3個 + 小さな山いくつか」。同じ大きさの山を並べない。

### 3-2. 房（クラスター）で描く

- ドット絵の「クラスター」= 同じ色のドットのまとまり。
  **形のはっきりしたまとまりで塗る**。1ドットだけぽつんと浮いた色（ノイズ）は作らない。
- 方法の例（Slynyrd さんの見下ろしの木の方法）:
  1. まず**葉の房を1つ**ていねいに描く（この形が木全体の質感を決める）。
     葉の形は、ひし形・台形などの簡単な形をもとに、少しずつ形を変える。
     **形・大きさ・並び方がそろっていると、全体がきれいな質感になる。**
  2. その房の**暗い版と明るい版**を作る。
  3. 光の向きに合わせて、**奥（下・右）に暗い房、手前（上・左）に明るい房**を重ねていく。
  4. 最後に幹と地面の影を足す。
- 葉っぱを1枚1枚描こうとしない。**64×80の木なら、房は大きい物で直径12〜20ドット、
  小さい物で5〜8ドットくらい**。

### 3-3. 色の数をしぼる

- 葉の緑は**4〜6色**で十分。それぞれの色の役目を決める
  （最暗・影・中影・基本・明るい・ハイライト）。
- 色は2-5の「色相シフト」で作る（暗い方は青へ、明るい方は黄へ）。
- 幹は**3〜4色**（最暗・影・基本・明るい）。
- 色を増やすほど、ふちがにじんでぼやける。少ない色でくっきり。

### 3-4. やってはいけないこと

- **まくら影（ピロー・シェーディング）**: 形のふちに沿って、ぐるっと同じように暗くし、
  まん中を明るくする塗り方。光の向きを無視しているので、ふくらんだクッションのように見える。
  → 木でやりがちなのは「房一つ一つをまん中明るく・ふち暗く」塗ること。必ず**左上明るく・右下暗く**。
- **バンディング**: 色の境目の線が、ふちの線と平行に、階段状にきれいに並んでしまうこと。
  → 色の境目は、房の形に沿ったでこぼこにして、ふちと平行に並べない。
- **ノイズ**: 1ドットずつばらばらの色。遠目に砂あらしのように見える。
- **ディザ（市松もよう）のやりすぎ**: 小さな木ではほぼ使わない。使うなら
  「明るい房と中間の房の境目に数ドット」くらい。**深い影の中は、何も描かずにすっきり**させる
  （幹と葉のあいだの暗い所などは、ディザで埋めない）。
- 光の向きがほかの絵（建物・キャラ）とちがう。**ゲーム全体で左上からにそろえる**。

### 3-5. 輪郭（アウトライン）

- 真っ黒な輪郭で全部囲むと、古くさく固い感じになり、草の上で浮く。
- **色つき輪郭**: 輪郭を黒ではなく、となりの色のいちばん暗い色（暗い青緑など）にする。
- **選択的アウトライン（セルアウト）**: 暗い側（右下・下）は暗い輪郭、明るい側（左上）は
  輪郭をうすくする・中間の色にする・なくす。
- 草の上に立つ木は、草と色が近いとまざってしまうので、**上側のふちにうすい輪郭**を入れると読みやすい、
  という意見もある。下側は暗い影色で自然に区切れる。

### 3-6. 幹をすき間から見せる

- 樹冠の下のほうのすき間から、**太い枝が1〜2か所**のぞくと、「中に枝がある」ことが分かって立体になる。
- のぞく枝は影の中なので暗い色。2〜4ドットの短い線でよい。

### 3-7. RPGの地図に置くときの注意

- 見下ろし・ななめ見下ろし（3/4視点）の地図の木は、**48〜80ドットくらいの高さ**が多い。
  樹冠が絵の大部分（6〜7割）で、幹は下に少しだけ見える。
- タイル（例: 16×16や32×32のマス）に合わせて、**根元がマスの中心に来る**ように置く。
- 地面の影は控えめに。だ円で、少しだけ右下にずらす。長くのばさない（となりのマスとぶつかる）。
- **草の色と木の色を分ける**:
  - 木の「いちばん広い面積の色」は、**草より少し暗く、少し青い**緑にする。
  - 木の明るい所は、**草より明るく、黄色寄り**にする。
  - こうすると、木の形が草の中にとけこまずに読める。
- 根元に**草の葉先を数本**かぶせると、木が地面から生えているように見える。
- 木を何本も並べたとき、全部同じ絵だと不自然。**左右反転・房の位置の少しの違い・大きさ2種類**などを用意すると森に見える。

### 4-2. 広葉樹（64×80）を描く手順

- [ ] 2. シルエットのふちは、**大きな山2〜3個＋小さな山**のでこぼこ。同じ大きさの山を並べない

- [ ] 4. 幹から樹冠の中へ、Y字に分かれる太い枝の流れを（下書きとして）決める。分かれるたびに細くする
- [ ] 5. 樹冠全体を「1つの球」として、左上明るい・右下暗い・底いちばん暗い、の大きな明暗を先に塗る
- [ ] 6. その上に房を置く。**大きな房3〜5個、小さな房をいくつか**。上の房ほど明るく、下の房ほど暗い

- [ ] 9. 影側（右下）のふちに、ごく控えめな照り返し（中影の色を数ドット）
- [ ] 10. 左上のふちだけに、ハイライトの黄緑を数ドット（ふちの透け）

### 4-3. 針葉樹（48〜64×80）を描く手順

- [ ] 1. シルエットは**段のある細長い三角**。段は4〜6段。下の段ほど横に広い。てっぺんは細くとがる
- [ ] 2. 段のふちはギザギザで、**葉先が下向き**（枝がS字に垂れるイメージ）
- [ ] 3. まん中に1本まっすぐな幹。葉の段のすき間から少しだけ見える。根元は短く少し広がる
- [ ] 4. 各段: **上の面と左側が明るく、段の下側に次の段へ落ちる暗い影の帯**
- [ ] 5. 木全体でも、左側が明るく右側が暗い（円すいの立体）
- [ ] 6. 広葉樹より暗く・青い緑を使う（並べたときに種類の違いが分かる）
- [ ] 7. 地面の影は、広葉樹より細めのだ円

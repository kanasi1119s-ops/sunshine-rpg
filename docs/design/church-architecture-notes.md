# 教会・大聖堂の建物のしくみ（ドット絵のための勉強ノート）

町の教会（大聖堂）の外観を、112×96 ドットの絵（正面＋右へ奥行きのある横の壁、光は左上から）で描き直すために、実在の教会建築の「しくみ」を調べてまとめたノートです。

> **大事な約束**
> - 実在の建物は**しくみを学ぶための参考**です。特定の実在の教会・大聖堂の形をそのまま写した絵は描きません（塔の数・窓の並び・彫刻の配置などを1つの建物に寄せない）。
> - **現実の宗教の印（十字架など）は描きません。** このゲームの教会は、独自の「三つの輪」の紋章を使います。十字架が立つ場所（塔のてっぺん・破風の頂き・扉の上）には、三つの輪の飾りを置きます。
> - ステンドグラスや彫像も、現実の聖人・聖書の場面ではなく、ゲームの世界の灯り・輪・自然の文様にします。
> - 文章は調べた資料の要約で、引き写しではありません。

## 1. 建物の形と高さの重なり（平面と量感）

### 1-1 基本の平面
- **身廊（しんろう）**: 入口から奥へまっすぐのびる、いちばん大きく高い部屋。人が集まる場所。
- **側廊（そくろう）**: 身廊の左右に沿う、細くて低い通路。外から見ると、高い身廊の両わきに「一段低い屋根」がつく。
- **翼廊（よくろう）**: 身廊と直角に交わる腕。上から見ると建物全体が「十字形」になる（ゲームでは十字を意識させない形にしてよい。T字や、短い張り出しでもよい）。
- **交差部**: 身廊と翼廊が交わるところ。上に小さな塔や尖塔（とがった屋根）が立つことが多い。
- **後陣（こうじん）・シュヴェ**: いちばん奥の丸い（半円・多角形の）端。小さな礼拝室が花びらのように並ぶこともある。
- **西正面（ファサード）**: 入口のある正面。いちばん飾りが多く、左右に2本の塔が立つ形が王道。

### 1-2 高さの重なり（いちばん大事）
外から見た高さは、だいたい次の順に積み重なる。

1. **塔・尖塔**（いちばん高い）
2. **身廊の屋根**（急な三角屋根。勾配はおよそ 55〜60 度）
3. **高窓（クリアストーリー）**: 身廊の壁のうち、側廊の屋根より上に出ている部分に並ぶ窓。外から「低い屋根の上に、もう一段窓の列が見える」形になる。
4. **側廊の屋根**（片流れの低い屋根。身廊の半分くらいの高さ）
5. **側廊の壁と窓**（いちばん下の段）

- 目安として、**側廊は身廊の約半分の高さ**。
- 横から見ると「低い段（側廊）→ 高い段（身廊）」の**2段の階段**になる。これが教会らしさの決め手。

### 1-3 控え壁と飛び梁（フライング・バットレス）
- 高い身廊の壁は、天井（石の丸天井）に外へ押されている。そこで**外側に石の柱（控え壁）**を立て、そこから**斜めのアーチ（飛び梁）**を身廊の壁へ渡して支える。
- 外から見ると、側廊の屋根の上を**斜めの石の橋が等間隔にまたいでいる**。その足もとの控え壁の頭には**小尖塔（ピナクル）**がのる（重しの役目と飾り）。
- このおかげで壁を薄くでき、大きな窓（ステンドグラス）を入れられた。
- 横の壁は「控え壁（縦の柱）と窓」が交互に並ぶリズムになる。

## 2. ゴシック風の正面の部品

上から下へ、正面によく見られる部品。

| 部品 | どんなものか | ドット絵での見え方 |
|---|---|---|
| **3つの入口（ポータル）** | 中央が大きく、左右が小さい。身廊と側廊の位置にそろう | 中央の扉を高く広く、左右は一回り小さく |
| **段々のアーチ（アーキボルト）** | 扉のまわりのアーチが、外から内へ何重にも小さくなって奥へ下がる | 明るい線と暗い線を交互に重ねた、同心のとがったアーチ |
| **タンパン** | 扉の上、アーチの内側の半月形の板。彫刻が入る | 扉の上の、少し明るい半円の面（中に紋章や小さな模様） |
| **わき柱の像** | 扉の両わきの斜めの壁に並ぶ縦長の像 | 1〜2ドット幅の縦の明暗の列で「並んでいる」感じを出す |
| **像の回廊（ギャラリー）** | 扉の段の上を横切る、像の並んだ水平の帯 | 細い横帯に、小さな縦のくぼみを等間隔に |
| **バラ窓** | 正面中央の大きな丸窓。放射状の石の格子 | 円＋中心から放射する線、色ガラスを数色の点で |
| **装飾破風（ヴィンペルク）** | 扉や窓の上にのせる、とがった三角の飾り屋根。高さを強調する | 扉のアーチの上に、さらに細い三角を重ねる |
| **クロケット** | 破風や尖塔のふちに並ぶ、小さな巻いた葉の飾り | ふちに1ドットのでっぱりを等間隔に |
| **フィニアル（頂華）** | 尖塔や破風のてっぺんの、つぼみのような飾り | 先端の小さな玉・十字形以外の飾り（このゲームでは三つの輪） |
| **小尖塔（ピナクル）** | 控え壁や角の上に立つ、細いとがった小塔 | 2〜3ドット幅の細い三角＋影 |
| **尖頭窓（ランセット）とトレーサリー** | 縦長でとがった窓。石の縦棒（マリオン）で分け、上部に丸・三つ葉・四つ葉の格子 | 縦長の窓を縦線で2つに分け、上に小さな丸 |
| **控え壁と段差（セットオフ）** | 控え壁は上へ行くほど段々に細くなる。段の頭は水が流れるよう斜め | 各段の上面に明るい1ドット、下に影 |
| **ガーゴイル（樋口）** | 屋根の雨水を壁から遠くへ吐き出す、怪物の形の石の樋 | 屋根の下から横へつき出た小さな突起 |
| **蛇腹（ストリングコース）** | 壁を横に一周する細い出っぱりの帯。階の区切り | 1ドットの明るい線＋その下に1ドットの影 |
| **基壇（プリンス）・水切り** | 壁のいちばん下の、少し張り出した台。上面は斜め | 足もとに一段太い帯、上面を明るく |

**正面の見た目の基本**: 縦の線（控え壁4本と塔2本）と、横の線（入口の段・像の回廊・窓の段）が格子のように組み合わさると、落ち着いて見える。正面は「入口の段 → 像の帯 → バラ窓の段 → 塔」の3〜4段構成が王道。

## 3. 有機的な近代の大聖堂（モデルニスモ風）の考え方

19世紀末〜20世紀はじめの、自然の形を取り入れた建築の一般的な特徴。特定の建物を写すのではなく、「発想」として使う。

- **放物線・懸垂線（かけいせん）の形**: 鎖をつり下げたときの曲線を上下ひっくり返した形。塔の輪郭が、まっすぐな三角ではなく**砲弾・とうもろこしのような、すそが太く上で細くなるふくらんだ形**になる。
- **双曲面などの曲面**: まっすぐな線を回して作る曲面。塔の窓や天井が、なめらかにねじれた形になる。
- **穴のあいた塔**: 塔の胴に、縦のすき間や斜めの石の羽板（鐘の音を外へ出すため）が並ぶ。遠目には**縦の縞・らせん状の点の列**に見える。
- **色のついた頂き**: 塔のてっぺんに、割ったタイルや色ガラスを貼ったモザイク（トランカディス）の飾り。**石の灰茶色の上に、急に鮮やかな色**が来る。
- **自然の彫刻**: 果物・麦の穂・葉・つる・動物などが、壁から生えるように彫られる。柱は木の枝のように枝分かれし、傾いて立つ。
- **ドット絵での使い方**: ゴシックの骨組み（2段の屋根・控え壁・3つの入口）はそのままに、**塔の形をふくらんだ砲弾形にする／頂きに色の玉を置く／入口のまわりを葉やつるの曲線で縁取る**、くらいの「味つけ」にとどめると、このゲームらしいオリジナルになる。

## 4. 素材と古び方

### 4-1 石の色
- **石灰岩**: 白〜クリーム〜はちみつ色。明るく、やさしい黄みの灰色。
- **砂岩**: 薄い赤茶・ピンクがかった茶・黄土色。地方によって赤い石の教会もある。
- **切石積み（アシュラー）**: 四角く整えた石を、同じ高さの段で積む。目地（すき間）は細くまっすぐ。
- ドット絵では、目地をすべて描くと線だらけになる。**数段おきに横の目地、ところどころ縦の目地**を、壁の色より1段暗い色で薄く入れる程度がよい。

### 4-2 古び方（よごれ・こけ）
- **下のほうが暗い**: 地面からのはね返りの雨・湿気・こけで、壁の足もとほど暗く、緑がかる。
- **出っぱりの下に筋**: 蛇腹や窓台・ガーゴイルの下に、雨水が流れた**縦の黒い筋**ができる。
- **雨の当たらないくぼみが黒い**: 空気のよごれは、雨で洗われない場所（入口の奥・彫刻のくぼみ・ひさしの下）に黒いかさぶた状にたまる。逆に**雨がよく当たる面は白っぽく洗われる**。
- **日の当たらない面（北側）にこけ・藻**: 緑〜黄緑のしみ、目地がえぐれる。
- **地衣類（ちいるい）**: 石の上に、黄・橙・灰緑の丸いしみが点々とつく。

### 4-3 屋根の色
- **鉛の屋根**: 新しいうちは銀色、古くなると**白っぽい明るい灰色**。まだらに色むらが出る。
- **スレート（粘板岩）の屋根**: **濃い青灰色〜黒っぽい灰色**。うろこ状の小さな板の段々が見える。
- **銅の屋根・尖塔**: 新しいと赤みのある橙 → こげ茶 → 緑 → 最後は**くすんだ青緑（緑青）**。尖塔の緑青色は遠くからでもよく目立つ。緑青の雨水が下の石に流れて、**石に青緑の筋**がつくこともある。

## 5. ドット絵への落とし込み（実践メモ）

### 5-1 小さくてもよく伝わるもの
- **2段の屋根（高い身廊＋低い側廊）と高窓の列**。これがあるだけで「大きな教会」に見える。
- **とがったアーチの扉と、段々の縁取り**（明暗を2〜3重）。
- **丸いバラ窓**（正面中央に1つ。小さくても円＋放射線で読める）。
- **控え壁の縦のリズム**と、その頭の**小尖塔**。
- **塔のとがった屋根**と、てっぺんの飾り（三つの輪）。
- 逆に、彫像の顔・細かい葉飾り・トレーサリーの曲線などは、**描きこむほどつぶれる**。点の並び・明暗のリズムで「ありそう」に見せる。

### 5-2 目安の比率（実在の大聖堂を参考にした、だいたいの値）
- **正面の幅：塔を含めた高さ ≒ 2：3〜1：2**（例: 幅40m前後に対して塔の頂きまで約70m）。塔のない正面本体の高さは幅とほぼ同じ（正方形に近い）。
- **側廊の高さ ≒ 身廊の高さの1/2**。
- **中央の入口の高さ ≒ 正面本体の高さの1/3前後**（上にさらに破風がのる）。左右の入口は中央の約2/3〜3/4。
- **バラ窓の直径 ≒ 正面中央部分の幅の2/3〜3/4**。入口の段のすぐ上、正面の中ほどに置く。
- **身廊の屋根**は急勾配（約55〜60度）。ゲームではやや大げさに急にしてよい。
- 112×96 の絵なら、たとえば「正面の幅 約56〜64ドット、塔の先まで 約90ドット、側面の奥行き 約40〜48ドット」が出発点になる。

### 5-3 光（左上から）と陰の付け方
- **正面（こちら向きの面）**: 明るい〜中くらい。**右へのびる横の壁は一段暗く**（面ごとに色を分けると立体に見える）。
- **四角い塔**: 左の面が明るく、右の面が暗い。**2面の色の差をはっきり**つけ、角の線で区切る。
- **丸い（円筒の）塔**: 左寄り（左から1/3あたり）に**いちばん明るい縦の帯**、右端に向けて**3〜4段階で暗く**。右端のふちに**反射光の1ドット明るい線**を入れると丸みが出る。屋根の円錐も同じ考え方。
- **とがった屋根**: 左の斜面を明るく、右の斜面を暗く。スレートなら横の段の線を数本。
- **出っぱり（蛇腹・窓台・控え壁の段）**: 上面に明るい1ドット、その下に**右下へ落ちる影**を1ドット。
- **影の向きをそろえる**: 絵の中のすべての影を、右下（光の反対）へ落とす。1か所でも逆だと違和感が出る。

### 5-4 くぼんだ入口の奥行きの出し方
- アーチの縁取りを**外側ほど明るく、内側ほど暗く**して、何重にも重ねる（段々のアーチ）。
- 光は左上なので、**くぼみの左の内壁と上の内側は影、右の内壁は光が当たってやや明るい**（左の縁が光をさえぎるため）。
- 扉そのものはいちばん奥なので、**いちばん暗い色**（木の扉なら暗い茶）。
- 扉の上のタンパンは、扉より少し明るく（紋章を置く場所）。
- 入口のすそに、1段の石段（明るい上面＋暗い前面）を入れると、地面との境がはっきりする。

### 5-5 古びの入れ方
- 壁の下1/4〜1/5に、**少し暗く緑がかった色**をまぜる（ディザか点々で）。
- 蛇腹・窓の下に、**1ドット幅の暗い縦の筋**を2〜3本だけ。入れすぎない。
- 入口の奥・ひさしの下は**ほかより一段黒く**。
- 屋根を緑青色にするなら、屋根の下の石にうすい**青緑の筋**を1〜2本。
- こけ・地衣類は、**右（日陰）側の壁と足もと**に、黄・緑の点をまばらに。

### 5-6 色の数のめやす
- 石: 明・中・暗・最暗（＋反射光）の4〜5色。
- 屋根: 3〜4色（スレートなら青灰系、緑青なら青緑系）。
- ステンドグラス: 青・赤・金の3〜4色を、点で少しずつ。暗い窓の中にちらばらせると「光る窓」に見える。
- アクセント: 三つの輪の紋章・塔の頂きの金色（または色モザイク風の点）。

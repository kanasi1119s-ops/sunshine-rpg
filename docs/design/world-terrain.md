# 全体フィールドの地形

## 地形の整理とフィールドのタイル（2026-10-05）

人間の指示「地形、結構山とか岩山がぐちゃぐちゃに置かれてるから整えて。フィールドの1マスのドット絵もこだわりを持って、違和感がなくなるように作って。」「ドット絵はすべてこだわって」で行ったこと。

### A. 山の置き方の整理（`tools/world-map/tidy_mountains.py`）

#### 見つかった「ぐちゃぐちゃ」

本物の地形の絵で地図全体を描いて調べた（`assets-src/field/tidy-preview/world-before.png`）。

- **ぽつんと1マスだけの山**（となりに山がない山）: 144か所
- **山にかこまれた1マスのくぼみ**（4方向のうち3方向以上が山）: 139か所
- 1マスはばの細い山の筋、ななめにだけつながる山
- **茶色のとがった山（N）**: 山脈のまわりや草原の中に、灰色の山（M）と関係なく、まだらに散らばっていた
- 谷（X）の小さなかけら（6マス以下）: 44か所。地図の上で、黒い四角い点に見えた

#### 整え方（毎回同じ結果になる。乱数は使わない）

1. 6マス以下の谷のかけらは、山にする（谷も山も通れないので、歩ける所は変わらない）。
2. 山のふちをならす: まわり8マスのうち山が3マス以下の山は消し、6マス以上の陸は山にする。
3. ぽつんと1マスの山は消す。1マスのくぼみは山でうめる。消すと近道ができてしまう「ななめの山の壁」は、すき間を1マスうめて、ふつうの山の帯にする。
4. 5マス以下の小さな山のかたまりは消す。
5. 2〜4を、変わらなくなるまでくり返す。
6. **とがった山（N）は、大きな山脈のまん中だけ**にする。条件は、山のふちから3マス以上内がわで、山のかたまりが60マス以上あること。N のかたまりもまるくならし、12マス未満なら M にする。雪の地方（雪原・雪の森から5マス以内）には N を置かない。
7. **丘（H）**: 山にふれる草原（まわり8マスのうち2マス以上が山）を丘にして、山と草原のあいだをやわらげる。

整える前の地形は `tools/world-map/rows-before-tidy.txt` にとっておく。2回目からはそこから整えなおすので、何度実行しても同じ結果になる（確かめ済み）。`gen_world.py` → `apply_field_trace.py` を実行しなおしたあとは、もう一度このスクリプトを実行する。

#### まもったこと（スクリプトの最後で確かめ、守れていなければ書きかえずに止まる）

- 変えたのは M・N・H・小さな X と、それにとなる陸（P・F・D・S・T・W・A）だけ。海・湖・道・雲・溶岩・渦の輪（O L R C Z V Q）は1マスも変えていない。
- 町・村・名所・環灯台・小島・船着き場・船・飛空艇・塔・渦の通り道のまわり2マスは変えない。
- 町のまわり12マスも変えない。章のダンジョンの入口は、町から歩いて3〜9マスの所に、通れるマスを数えて決まるため。
- 塔の陥没（塔から22マス以内）、渦の輪から3マス以内、溶岩から8マス以内（火山の本体）、地図のふち8マスは変えない。
- 道のとなりを山にしない。
- **歩いて行けるつながりを変えない**: 前もあとも通れるマスについて、「どこからどこへ行けるか」の組み分けがまったく同じであること。ただし、もとから行けなかった5マス以下の小さな陸が、まわりにくっつくのはよい（行ける所がふえるだけで、近道にはならない）。

### B. フィールドのタイルの描きなおし（`tools/pixel-art/ai-gen/world_tiles_v2.py`）

`world_tiles.py` の中から、次の8つを `world_tiles_v2.py` の描き方に置きかえた。草・海・砂・雪・森・湖・雲・溶岩は前のままで、粒の大きさの基準にした。

`w-mountain` `w-pyramids` `w-hills` `w-snowforest` `w-road` `w-waste` `w-ash` `w-chasm`

#### 前の絵の問題（1倍・拡大・3×3にならべて確かめた）

| タイル | 問題 |
|---|---|
| 山 | 丸い小石がならぶ絵で、山ではなく砂利に見えた |
| とがった山 | 小さな茶色の三角がびっしりならび、まわりの灰色の山と色も形もつながらなかった |
| 丘 | 暗い線でかこんだ平たい小山が、はんこのようにならんでいた |
| 雪の森 | 1ドットの点がちらつき、雪あらしのように見えた |
| 道・荒れ地・谷 | 1ドットの点をまいただけで、ざらざらの雑音に見えた |
| 灰の大地 | 同じ渦の形が4×4でならび、くり返しがすぐ分かった |

#### 描き方のきまり

- 光は左上から。上・左を向いた面が明るく、右・下を向いた面が暗い。
- 粒の大きさは、草・海と同じ2〜6ドットのかたまり。1ドットの点はまかない。
- 縁どりは、影の側（右・下）だけ、その素材のいちばん暗い色にする。
- 同じ形のはんこはならべない。山はひとつずつ、頂の位置・左右の斜面の急さ・肩（低いもう1つの頂）のあるなし・斜面の折れを変える。
- 128×128 の上下左右がつながるようにする。座標は128で割ったあまりにし、距離もつながった輪の上で測る。つなぎ目をこえる山や木は、手前・奥がくずれないよう3回に分けて描く。つなぎ目をまたぐ所を拡大して、つなぎ目が見えないことを確かめた。

`world_tiles.py` を実行すると、ほかの9枚は前とまったく同じ絵になることを確かめた。8枚とも、ドット絵エディタ（`--wide`）で「食い違い 0 マス」。エディタの絵は `assets-src/field/terrain-editor/`。

ゲーム用のデータは `tools/pixel-art/world-terrain.json` を書きかえた。**`export-game-data.mjs` はまだ実行していない**ので、ゲームに出すには、メインの作業で書き出しを実行する。

#### 地面の飾り（ground-decor）

`src/render/ground-decor.ts` は、地形の絵のある地図（全体フィールド）では、山の上に絵を重ねない。山・森のかたまりのふち（`erodeMass`）を、となりの地面の1色でけずって丸める。ふもとには影を落とす。今回は変えていない。

### まだ弱いところ（正直に）

- **地形はマスの四角で切りかわる。** M と N、山と草原の境目は、階段のような四角いふちになる。ゲームでは `erodeMass` がふちを丸めるが、M と N のあいだはどちらも「かたまり」なので丸まらない。
- **雪の地方の山（M）は、灰色で暗く重い。** 地形の種類は M が1つだけなので、雪の地方用の「雪をかぶった山」がない。作るには、新しい地形の種類（コードの変更）が要る。
- 火山のまわり（溶岩から8マス以内）と、町のまわり12マスは変えていない。そのため、そこには前の細い N の点や小さな山が残っている。
- 丘（H）は山のまわりに帯になったが、遠くから見ると「明るい草の輪」に見える所がある。
- 山のタイルは、広い所ではやや同じ調子の模様に見える（はんこのくり返しではないが、ならびが互いちがいの格子なので）。
- 谷（X）の大きなかたまり（7マス以上）は、意味があるかもしれないので残した。森の中の黒い四角い穴に見える所がある。

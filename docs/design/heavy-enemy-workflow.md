# 重厚な敵グラフィックの作り方（2026-10-03、練習から学んだこと）

人間の依頼（「RPG風に」「もっと頑張ってクオリティを上げて」「ドット絵エディタを使って作って」「この作り方を、うちのドット絵エディタで作れるようにどんどん学習して」）で、スーファミ後期の戦闘画面に出てくるような、**大きくて陰影の重い敵の絵**を練習した記録です。練習で作った絵はリポジトリに入れていません。

## 0. 守ること

- 目指すのは、あの時代の敵グラフィックに共通する**質の要素**だけ（第1節）。特定の作品のモンスターの形・色・名前は使わない（CLAUDE.md 1-1）。
- 画像生成AIへの指示に、ゲームの題名・作品名・作者名を書かない。生き物の種類と、色・体の特徴を自分で決めて書く（名前だけで指示すると、有名な作品のデザインに寄ることがある。例: 火のサラマンダー）。
- できた絵は、既存作品に似ていないかを必ず目で確かめる。AIで作った絵をゲームに入れるときは、人間の確認を受ける（`docs/decisions.md` 2026-10-03）。

## 1. 「重厚な敵」に見える質の要素

1. **大きい**: 64×64では細部がつぶれる。**96×96**くらいから、筋肉・布のしわ・鱗が描ける（ボスは128以上）。
2. **黒一色の輪郭を使わない**: 外周は「その部分の色を暗くした色」（少し青みを足す）。黒で囲むと、絵本や今風のアイコンに見える。
3. **絵画のような重い陰影**: 同じ素材の中で4〜6段の明暗。光は左上から当て、上と左の縁の1つ内側を明るくする（照り）。
4. **実在の生き物のような体のつくり**: 頭身を下げない。斜め横向き（3/4）で、体の厚みを見せる。
5. **落ち着いた地の色＋ひとつだけ光る差し色**: 苔の緑の体に青く光る目、紫の衣に金の飾り、など。差し色は2〜4ドットでも効く。
6. **色数**: 1体で16〜20色。スーファミの敵はふつう16色（透明を含む）の組み合わせなので、ゲームに入れるときは16色に寄せる（エディタの「色を減らす」）。

## 2. 作り方の流れ

| 段階 | やること | 道具 |
|---|---|---|
| 1. 下絵 | 絵画向けの基本モデルで描かせる。ドット絵用のモデルは、線が太く素朴になり、重厚さが出なかった | `tools/pixel-art/ai-gen/generate.py`（`STYLE=painterly`、例: `example-jobs-painterly.json`） |
| 2. 切り抜き | 景色の入った下絵は、AIで背景を切り抜く | `pixelize.py` の `--rembg`（rembg＋isnet-general-use） |
| 3. ドット絵にする | 少しシャープ→縮小→Lab色空間で減色→孤立点を消す→色つきの縁取り→左上の照り→最終の減色。足のあいだなど大きなすき間は透明のまま（12マス以下の穴だけ埋める） | `sfcize.py`、またはエディタの「画像から作る」 |
| 4. 手直し | 目・顔・牙を読めるようにする、背景の取り残しを消す、強すぎる色を落ち着かせる | `edits.py`、またはエディタのペン・「似た色を消す」 |
| 5. エディタで描く | エディタで1ドットずつ描いて、書き出しと文字グリッドの食い違い0マスを確かめる | `tools/pixel-practice/editor-draw.mjs`（96×96は `--zoom 6` で0マス、1体3分半ほど） |
| 6. 並べて見る | 戦闘画面のような暗い背景に、ほかの敵と並べて見る。1体だけで見ると、暗すぎ・明るすぎに気づかない | 見本の画像を作る |

### 下絵の指示（うまくいった形）

- 中身: 「生き物の種類＋色＋体の特徴＋持ち物」を自分で決める（例: 苔におおわれた石の巨人で、青く光る紋様）。
- 共通部分: `fantasy creature concept painting, entire body visible, wide shot, small in frame, three-quarter view, realistic anatomy, rich colors, dramatic lighting, detailed painterly shading, single monster centered, isolated on plain white background`
- `entire body visible, wide shot, small in frame` を入れると、体が画面からはみ出しにくい（入れないと、半分ほどが切れた）。
- `rich colors` を入れないと、茶色一色の古い挿絵のようになった。
- 1つの指示につき乱数の種を2つ以上試す。使える形になるのは半分ほど。

### 手直しで効いたこと（手で直す価値が大きい順）

1. **目**: 2ドットの光る目（中心に明るい1ドット）と、その上の暗い眉の線。これだけで「顔」に見える。
2. **口・牙**: 暗い横線に、明るい牙を2本。
3. **背景の取り残し**: 足のあいだ・脇の下に残った背景の色を消す。
4. **強すぎる色**: 鮮やかな赤紫などは、彩度を3割ほど落として少し暗くすると、ほかの敵となじむ。
5. **差し色の追加**: 苔の巨人の胸に、光る紋様を5ドット。

## 3. ドット絵エディタに入れた機能（2026-10-03）

エディタ（Artifact: https://claude.ai/artifact/Xo7VKZU9cHJk15BnvVmxdp ）に、この作り方の3〜4段目を入れました。

- **画像から作る（重厚な敵）**: 元の絵を選び、大きさ（既定96）と色の数（既定20）を決めて「変換してキャンバスに入れる」。背景は「自動」（透明な所があればそれを使う）・「四すみの色を消す」・「消さない」から選ぶ。シャープ・色を強める・孤立点・色つきの縁取り・左上の照りは、それぞれ入り切りできる。変換すると、対称描きと陰影プレビューは自動で切る（変換した色をそのまま見るため）。
- **仕上げ**: いま描いてある絵に「孤立点を消す」「色つき縁取り」「左上の照り」「色を減らす（○色まで）」をかけられる。手で描いた絵にも使える。
- **似た色を消す（ツール）**: 押した所から、となりどうしの色が近い所をまとめて消す。変換のあとに残ったグラデーションの背景を、数回押すだけで消せる。
- 色（記号）は、大文字・小文字・数字で最大62色まで使えるようにした（これまでは26色）。「元に戻す」は、パレットの変化も戻す。
- ブラウザの中では、AIの切り抜き（rembg）は動かない。景色の入った下絵は、先に `pixelize.py --rembg` などで背景を透明にしたPNGにするか、変換のあとに「似た色を消す」で消す。

## 4. 失敗と注意

- **メモリ不足**: メモリ7GBほどの環境で、絵の生成と同時に rembg やブラウザ（エディタ）を動かすと、生成が止まった（2回）。生成が終わってから、切り抜き・エディタの作業をする。
- **背景の消し方**: 四すみの色からのつながりを広く取ると、暗い縁取りを伝って体の中まで消えた。エディタの自動の背景消しは控えめにしてあり、残りは「似た色を消す」で消す。
- **ドット絵用モデル（All-In-One-Pixel-Model）**: 48〜64pxの素朴な敵には向くが、96pxの重厚な絵では、線が太く塊が大きくなった。用途で使い分ける。
- **大きな絵のエディタ描画**: 以前の記録では80×80で食い違いが出たが、96×96でも `--zoom 6`（キャンバスが画面に収まる倍率）なら0マスだった。食い違いは、キャンバスが画面からはみ出す倍率で起きる。

## 5. 次に試すこと

- 同じ群れの敵（3〜4体）で、パレットを共通にする（「色を減らす」を、共通のパレットに合わせる形にする）。
- 色違いの敵（上位種）を、パレットの差し替えだけで作る。
- ボス用に128×128・256×256（`roles.md` の大きさの基準）で、同じ流れを試す。

# 作曲ソフトで作った、ゲーム用の曲

作曲ソフトの「ゲームの曲として登録」で書き出した `〇〇.sunshine-song.json` を、このフォルダに置くと、
ゲームのBGM一覧（`ALL_CATALOG`）に自動で入ります（`src/audio/user-songs.ts` が読み込みます）。

- ファイル名の `〇〇` が曲のID（英数字と `-` だけ）。既存の曲のIDと重ならないようにしてください。
- どの場面で鳴らすかは、ゲーム側の `bgmId` にこのIDを書いて決めます。
- NAMモデル（.nam）はゲームには入れません（曲に含まれていても無視し、ふつうのアンプの音にします）。

## 選び方

1. **ライセンス**: 規約で再配布まで認められているものだけを使った（このリポジトリは公開されているため）。
   - ぴぽやの規約
   - OpenGameArt の CC0・CC-BY・OGA-BY（継承型の CC-BY-SA・GPL は使わない）
   - 美術館がパブリックドメインの作品として CC0 で公開している画像
   - **再配布禁止のフリー素材サイトは使っていない**（素材屋『氏』、itch.io の30体パックなど。`docs/assets-credits.md`）
2. **外したもの**: AIで作ったと書かれたもの、既存のゲーム由来のもの、3D、ドット絵。
3. **作るのが簡単な絵を外した**: 細かさを数値で測って判定した。次のどれかに当てはまる絵を外した。
   - 質感のばらつきが少ない
   - 平らな塗りが多く、陰影が少ない
   - 色も階調も少ない線画
4. **小さい絵を外した**（長い辺が200px未満）。
5. **重複を外した**: ほぼ同じ絵、同じキャラクターのコマ違い、同じ版画の連作（6枚まで）。
6. **目視で外した**（約2万枚を確認）:
   - 主題が関係ないもの（ふつうの人物画・風景・器・装飾・文字のページ・人物のカードなど）
   - 裸体・性的なもの
   - 残虐なもの
   - 薄すぎる・小さすぎるもの
   - 重複

   最初の依頼のときは、実在の宗教の信仰対象（キリスト・聖人・仏など）を外していた。追加の依頼で「聖書」が入ったので、聖書・宗教の主題は残すことにした。

## 使うときの注意

- **CC-BY・OGA-BY の絵**: ゲームに使うなら、`CREDITS.md` のとおり作者・作品名・ライセンスを表記する。
- **ぴぽやの絵**: 加工したものでも、素材として売ることはできない（ゲームに組み込んで売るのはよい）。
- **美術館の作品**（9,664枚）: 昔の版画・素描・絵画です。
  - 著作権は切れていますが、作品そのものをゲームに出すと目立ちます。
  - **聖書・宗教の作品は、信仰の対象を描いたもの**です。ゲームでどう扱うか（そのまま出すか、描き方の参考にとどめるか）は、人間が判断する。
- **クトゥルフ神話**: 美術館の作品にはほとんど無く、OpenGameArt の数点（eldritch・lovecraft で検索したもの）だけです。
- このゲームの敵や登場人物は、オリジナルのデザインにする（CLAUDE.md 1-1）。ここの絵は、描き方・構図・雰囲気の参考に使う。

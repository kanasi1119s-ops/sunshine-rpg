## 選び方

1. **ライセンス**
   - ぴぽや: 同梱の説明と規約で確認した。
   - OpenGameArt: CC0・CC-BY・OGA-BY だけを使った。継承型（CC-BY-SA・GPL）は、ゲーム全体に条件が及ぶおそれがあるので使わない。
   - 美術館: パブリックドメインで、画像が CC0 で公開されているものだけを使った。
   - OpenGameArt の採用ページは、すべて 2026-10-01 に読み直して確認した。
2. **外したもの**
   - AIで作ったと書かれたもの
   - 既存のゲームの絵や、既存のゲームに似せた・着想を得たと書かれたもの
   - 3Dの説明があるもの
   - ドット絵（色数256以下で半透明がほとんど無いもの）
   - 再配布が禁止されている素材（素材屋『氏』、itch.io の「Free 30 Enemy characters pack」など。`docs/assets-credits.md`）
3. **作るのが簡単な絵を外した**（6,426枚）
   - 細かさを数値で測って判定した。
     - 4×4のかたまりの中の濃淡のばらつき（筆致・質感）が少ない
     - 平らな塗りが30%以上で、なめらかな陰影が少ない（エディタで簡単にトレースできるベタ塗りのベクター画）
     - 色も階調も少ない単純な線画
   - どれかに当てはまる絵を外した。
4. **小さい絵（長い辺が200px未満）を外した**（17,017枚。スプライトシートを切り分けた小さなコマが多い）
5. **重複を外した**
   - ほぼ同じ絵
   - 同じキャラクターのアニメーションのコマ違い（同じページの中で色の分布が近いものは2枚まで）
   - 1ページ15枚まで
6. **目視で外した**（約4,800枚）
   - モンスター以外（武器・アイテム・エフェクト・UI・風景・ふつうの人物・装飾）
   - 裸体・性的なもの・残虐なもの
   - 実在の宗教で信仰の対象になっている存在が主題のもの（キリスト、聖母、仏・菩薩、ヒンドゥーの神々など）
     - 天使・悪魔と、ギリシャ・ローマ・北欧などの神話の神は残した。
   - 文字・透かし入りのもの

## 使うときの注意

- **CC-BY・OGA-BY の絵**: ゲームに使うなら、`CREDITS.md` のとおり作者・作品名・ライセンスを表記する。
- **ぴぽやの絵**: 加工したものでも、素材として売ることはできない（ゲームに組み込んで売るのはよい）。
- **美術館の作品**: 昔の版画・絵画・屏風などです。著作権は切れていますが、作品そのものをゲームに出すと目立つので、使うかどうか・どう加工するかは人間が判断する。描き方の参考に向いています。
- このゲームの敵は、オリジナルのデザインにする（CLAUDE.md 1-1）。ここの絵は、そのまま使う候補か、描き方の参考として使う。

## 数について（1万点に届かなかった理由）

- 規約を確かめられた入手元から、約4万枚（切り分けたコマを含む）を候補にした。
- 規則での絞り込みと目視で、ほとんどが外れた。外れた主な理由は「作るのが簡単」「小さい」「モンスターではない」「同じキャラのコマ違い」。
- 次の入手元は使えなかった。
  - Wikimedia Commons: この環境からは利用制限で取得できなかった。
  - シカゴ美術館・itch.io: 自動取得を止める確認画面が出たので、回避しなかった。
- 数を増やすなら、次のどれかが要る。
  - 基準をゆるめる（小さいコマを入れる、同じキャラのコマ違いを増やす）
  - 人間がブラウザで入手元を開いて取得する

# ライセンスの写し・要点

- `pipoya-rpg-monster-pack-readme.html`: ぴぽや「ポップモンスターイラスト素材（Pipoya RPG Monster Pack）」に同梱の説明（利用条件の表を含む）。最新の規約は https://pipoya.net/sozai/terms-of-use/ 。商用利用可・加工可・利用報告と著作権表記は不要。**素材データの販売（加工したものを含む）は不可**。無償の再配布は条件つきで可（規約とともに）。
- OpenGameArt: 各ページのライセンス欄で確認（2026-10-01 にすべてのページを読み直し）。CC0 は権利放棄（表記不要）。CC-BY 3.0／4.0（https://creativecommons.org/licenses/by/4.0/ ）と OGA-BY 3.0（https://static.opengameart.org/OGA-BY-3.0.txt ）は、作者名・作品名・ライセンスの表記が必要（`../CREDITS.md`）。
- 美術館の作品: いずれもパブリックドメインの作品で、画像は各美術館が CC0 で公開しているもの。
  - メトロポリタン美術館 Open Access: https://www.metmuseum.org/about-the-met/policies-and-documents/open-access
  - ナショナル・ギャラリー・オブ・アート（米国）Open Access: https://www.nga.gov/open-access-images.html
  - クリーブランド美術館 Open Access: https://www.clevelandart.org/open-access

# 仲間6人のドット絵（顔アイコン・全身・歩くキャラ）

2026-10-04 に作った、仲間6人（ユーリ・レト・ミナ・ガイド・オルカ・アヤメ）のドット絵一式。人間の確認「キャラのアイコンってプッシュした？」（2026-10-05）で、作業用の置き場にしか無かったのでリポジトリに入れた。

人物ごとのフォルダの中身:
- `アイコン_512x512.png`・`アイコン_128x128.png`（と2倍）: 顔アイコン（顔に寄せた構図、全員で顔の大きさをそろえた。作り方は `.claude/skills/make-art/prompt-icon.md`）
- `全身_256x256.png`（と2倍）: 全身の絵
- `歩き_4方向x3コマ.png`（と8倍）・`歩き_動き.gif`・`歩き_ゲーム用データ.json`: 2頭身の歩くキャラ（16×32）。ダメージの絵を足した版は `../walk-2head/`
- `エディタ用_*.txt`・`エディタ用_*_色.json`: ドット絵エディタで読みこむ文字の絵と色

まだゲームには入れていない（ゲームの顔グラフィック・歩く絵は前の版のまま）。入れかえるときは `docs/decisions.md` に書く。

# r22-vehicles 世界地図の乗り物・海の塔・小島のドット絵

世界地図（1マス16×16、画面400×225）に置く、船・飛空艇・芯環塔・隠しダンジョンの小島のアイコンです。
すべて一から描いた自作で、外部素材・既存作品の絵は使っていません（1-1 を守っています）。
`r17-polish/worldicons.py` と同じ道具立て（1文字=1色の文字グリッド＋`pal-*.json`、光は左上、ハイライトなし、縁取りは素材ごとの暗い色、1枚16色まで、足元に影や波）です。

- 全部作り直す: `python3 build.py`（`.txt`・`pal-*.json`・`preview.png` を出力。大きさ・色数（16色以内）・パレットにない文字・足元の位置を自動確認し、NG があれば終了コード1）
- 確認用の拡大画像: `preview.png`（4倍、海の青の背景）
- 部品: `lib.py`（キャンバス・図形・縁取り・パレット）、`ships.py`、`airships.py`、`spire.py`、`islets.py`

## 一覧

「足元」は、泡・水を除いた最下行（縁取りを含む）のy座標（枠の上から数える）。

| 名前 | 大きさ | 足元 | 中身 |
|---|---|---|---|
| ship-right / ship-left / ship-down / ship-up | 32×32 | 26（下から6ドット上） | 帆走船。帆に灯の環の輪（青）。うしろに白い航跡。down は船首の波、up は船尾の窓と V字の航跡 |
| airship-right-0/-1, airship-left-0/-1, airship-down-0/-1, airship-up-0/-1 | 40×40 | （飛行中のため決めない） | 飛空艇「環翔船」。2コマ（プロペラ・赤いひれ・輪の中心の灯が変わる） |

飛空艇のデザイン: 胴体（クリーム色に赤いライン）の上に、真鍮の縁に青緑の膜を張った「輪の円盤」が立つ（灯の環の意匠）。横から見ると細い楕円、前後から見ると放射状の骨のある真円。尾に赤いひれ、プロペラ。既存作品の飛空艇には似せていません。

## 本体に組み込むための変更点（この作業では本体を触っていません）

1. `tools/pixel-art/props.mjs`
   - `PIECES` に、`piece("V1-船右", "r22-vehicles", "ship-right.txt", "pal-ship-right.json", {}, 32)` のように追加。第6引数が枠の大きさ。
   - 32×32: ship-right/left/down/up。40×40: airship-*-0/-1。24×10 はそのまま `frame=24`（縦は下そろえ。`piece()` は縦横とも枠の正方形なので、影だけ別枠にするか、32の枠に入れて下そろえにする）。
   - 48×48: ship-docked, airship-landed, islet-*, whirlpool-ring。64: spire は縦112なので `piece()` の枠を「正方形」から「幅×高さ」に拡張する必要がある（今は正方形の枠だけ。`frame` を `[w,h]` も受けるようにして、`oy = h - rows`、`ox = (w - rowW)/2`）。
   - r20 のように `readdirSync` で自動登録する方法も使える（`R22_NAMES`）。ただし枠はファイルごとに違うので `SPEC`（名前→枠）を持たせる。
2. `tools/pixel-art/export-game-data.mjs`
   - `SETS.props` の名前対応表に `"V1-船右": "prop:ship-right"` … を足す（数字を上げる版管理 `props: [1, …]` も上げる）。
   - 飛空艇の2コマは別名（`airship-right-0` / `airship-right-1`）で別々の prop にする。
3. `src/game/map/types.ts`
   - `MapPropKind` に `"ship-right" | "ship-left" | "ship-down" | "ship-up" | "ship-docked" | "airship-<向き>-<コマ>" | "airship-shadow" | "airship-landed" | "spire" | "islet-ruin" | "islet-cave" | "islet-shrine" | "islet-fort"` を足す。
   - 乗り物は固定の飾りではなく「動くもの」なので、`MapProp` ではなく別の型（例: `WorldVehicle { kind: "ship"|"airship"; x; y; dir; }`）を作るほうがよい。
4. `src/game/map/map-props.ts`
   - `PROP_HEIGHT` に高さ（ship 32、airship 40、docked/landed/islet 48、spire 112、影 10）、`PROP_*` の当たり判定表（`"icon-port": { left: 0, right: 0, up: 0 }` の行）に、島・塔は通れない（陸の歩行者が触れない）印を足す。
5. 描画側（世界地図の描画）
   - 海の上に乗せるので、足元の y をタイルの下端に合わせる（ship は `y_px - (26 - 16)` あたり。足元26に対し、マスの中心が船底になるよう調整）。
   - 飛空艇は、機体を描く前に `airship-shadow` を地面側に、機体の足元から 20〜28ドット下にずらして描く。高度が上がるほど影を小さく・遠くにする。飛行中は 0.2〜0.25秒ごとに `-0` と `-1` を切り替える。
   - 帆走船は航跡（絵に入っている）を揺らすだけでよい。波の動きは本体の水タイルのアニメに合わせる。
   - 芯環塔（spire）は海の「大渦」の中央に、足元を渦の中心に合わせて置く。雲の部分だけ、ごくゆっくり左右に動かす（雲は別パーツに切り分けてもよい。今は一枚絵）。
   - `whirlpool-ring` は使わない。渦はコードで回し、配色は `l`（深い青 #2a4a78）・`L`（青 #3a6a9a）・`B`（#7ab0d8）・`C`（白 #f0f6fc）に合わせる。
6. 色について: パレット（`lib.py` の `PAL`）は既存の `worldicons.py` の色に、飛空艇用の青緑 `S s z`・帆の `P p`・石の `U u V` を足したもの。`pal-*.json` は使った色だけを書き出している。

## 弱い所（正直に）

- **芯環塔**は、3段の雲が積み重なって「きのこ」や「五重塔」のように見える瞬間がある。塔の細さ・高さの迫力は、112ドットの高さではまだ足りない（画面の高さの半分ほど）。雲の渦巻きのすじはかなり控えめで、渦巻いている感じは弱い。雲を別パーツにして動かすと良くなる。
- **帆走船**は小さい（32×32）ため、輪の意匠は「青い丸」にしか見えない。左向きは右向きの鏡像（輪は左右対称なので不自然ではない）。down/up は船体が丸く、船としての細かさは少ない。
- **飛空艇**は、前後向き（down/up）の翼（赤いひれ）が大きく、少しコウモリのように見える。up のプロペラは船尾の窓に重なって少しごちゃつく。2コマの違いは小さい（遠目では分かりにくい）。真上から見た図ではなく、斜めの見かけを混ぜている。
- **ship-docked** は、桟橋と船体が重なっていて、桟橋の板の奥行きが浅い。縁の波の泡が少ない。
- **着陸中の飛空艇**の影は市松（半透明の代わり）で、地面の色によっては網目に見える。そり・はしごは小さく粗い。
- **小島4種**は、島の形が似ている（共通の島＋載せ物）。洞窟は「穴のある岩山」の域で、小島ごとの個性は載せ物に頼っている。遺跡の柱の欠けは単純。
- **足元の影・水かげ**は海の色（#2e6296 前後）で見て決めた。海タイルの色が大きく違うと水かげの青が浮く可能性がある。
- ゲームへの組み込み（上の 1〜5）はまだしていない。実機の画面（400×225）での見え方は未確認で、`preview.png` の4倍拡大でしか見ていない。

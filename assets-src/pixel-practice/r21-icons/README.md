# r21-icons: アイテム・装備・ジョブ・特技の小さなアイコン（16×16）

ゲームのメニュー・お店・戦闘の窓に添える、文字だけだった所のアイコン案です。全部オリジナルで、既存作品の絵・記号は使っていません。このフォルダの中だけに置いてあり、`src/` と `tools/pixel-art/` は変更していません。

全部で **70個**（武器10・防具9・消耗品11・ジョブ22・特技15・灯貨3）。確認用の画像は `preview.png`（6倍・ラベルつき）と `preview-actual.png`（実寸の2倍、暗い背景と明るい背景）です。

## 作り方・きまり

- 1個ずつ `<種類>-<名前>.txt`（16行×16文字、`.`=透明）と `pal-<種類>-<名前>.json`（文字→色）。色は縁取りを含めて最大10色（`build.py` が確認）。
- 光は左上、照りの点は使わず明・中・暗の3段。縁取りは素材ごとの暗い色（鋼=青灰、木=茶、金=褐色、赤=暗赤…）で、黒一色にしていない。
- `python3 build.py` で全部作り直せる（`common.py`=部品、`icons_equip.py` `icons_items.py` `icons_jobs.py` `icons_skills.py`=絵）。縁取りは自動で足す。色数・文字の抜け・16×16・端の余白を自動確認し、問題があれば終了コード1。
- ジョブのしるしは枠の色でランクが分かる: 初期=鋼 / 上級=金 / 天神=白金 / 悪神=紫 / レジェンド=炎色。中の8×8の絵でジョブの特徴を表す。

## ゲームに組み込むには（案。この作業では実施していない）

1. **書き出し**: `tools/pixel-art/` の書き出し（`run.mjs` / `export-game-data.mjs`）に、このフォルダの `*.txt` と `pal-*.json` を読む一覧を足す。ほかの絵（例: `assets-src/pixel-practice/r14-icons2/`）と同じ「文字グリッド+パレット」形式なので、同じ読み込み関数が使える。出力は `public/` 以下にまとめた1枚のスプライトシート（16×16を横に並べたPNG）と、名前→番号の `icons.json`（本フォルダの `icons.json` が元になる）がよい。容量は全体で数KB。
2. **データに名前を足す**: `src/game/items/equipment.ts` の各段（武器・防具・飾り）と `shop.ts` の品、`src/game/job/jobs.ts` の `JobData` に、省略可能な `icon?: string`（例: `"weapon-sword"`, `"job-flame-mage"`）を足す。武器の割り当て案: 剣=灯り鉄・水鏡・霧割り・雲裂き、曲刀=砂風、鉄鎖断ち=`weapon-sword`で代用、霜刃=`weapon-dagger`、灯芯の聖剣=`weapon-sword-holy`。防具は `armor-light` → `armor-heavy`（坑夫・雲糸）、霧絹=`armor-robe`、飾りは首飾り/指輪/腕輪を段で割り当てる。
3. **描画**: `src/render/` のメニュー・お店・ジョブ画面で、名前の左に `drawIcon(ctx, id, x, y, scale)` を呼ぶ（16×16を `imageSmoothingEnabled=false` で2倍=32px）。戦闘の特技欄は系統の印（`skill-fire` など）を行頭に置く。`battle` の `effect`（heal / buff / debuff / sleep / damageAll / multi）から印を選ぶ対応表を1つ持たせる。ジョブの☆は `job-star` を熟練度の数だけ並べる。灯貨は所持金の左に `coin-one`、お店の価格には額に応じて `coin-one` / `coin-few` / `coin-bag` を使い分ける。
4. 外部素材ではなく自作なので `docs/assets-credits.md` への追記は不要（組み込む時に「自作アイコン」と1行だけ書くとよい）。

## 弱いところ（正直に）

- 16×16で試作しただけで、ゲームに入れて実寸で見ていない。実寸ではジョブの紋の中の絵（8×8）はつぶれやすく、主に枠の色と大まかな色で見分けることになる。
- 同じ系統のジョブ（初期と上級）は絵が近い。上級は金の枠で区別するが、ひと目では差が小さい。
- 「風」「突く」「闇」は形がやや分かりにくい（風は渦巻き、突くは斜めのとげ+線、闇は黒い玉）。文字ラベルと一緒に使うのが安全。
- 武器は全10種で、ゲーム内の全段（9段×3種）には足りない。段ごとの絵の使い回しが必要。
- 円の枠は角ばった八角形に見える（ドット絵の都合）。キャラ絵の線の太さとの統一は未確認。
- 完成品ではなく、採用するなら見直し前提の試作（CLAUDE.md 1-4）。

- 種類: モンスター（龍）／性別: なし／設定: 苔むした岩場にすむ、小さな竜の子ども。頭と背中に石のとげが育つ
- イメージ画像: `ref.png`（Stable Diffusion 1.5、CreativeML OpenRAIL-M。地面の下絵 ground から img2img・強さ0.9、QUALITY=real、乱数の種 7300）

  - 描けた絵には額の宝石は出なかったので、ドット絵にも入れていない（イメージ画像どおり- 2頭身で残した特ちょう: 苔の緑の体と模様／頭の上の灰色の石のとげ（冠のように並ぶ）／黒いアーモンド形の大きな目と石のまゆ／灰色の羽（とげつき）／長いしっぽと灰色の爪
- 人間の指示の流れ（2026-10-07）: 32×32 の待機絵 →「却下、32×16よ」→「無理なら16×16でも検討して。もしくは16×32か」→
  「16×32と32×16をうまく使うのもありだね」「とりあえずこのパターン全部やってみて」→「立たせないで」。
  そのため、立たせず4本足で歩く竜にして、3つの大きさで作った（どれも 4方向×3コマの歩き、右向きは左向きの反転）。
  - `v16x16/` … 16×16 だけ。小さな4本足の竜
  - `mix/` … 下・上は 16×32（見下ろしなので、体が奥へ長くのびる形）、横は 32×16（イメージ画像どおり、低く長い形）
  - `v16x32/` … 16×32 だけ。下・上は mix と同じ、横は 16×16 の竜を下にそろえて置く
  - 足は前足と後ろ足を交互に出し、しっぽの先が1ドットゆれる
- 最初の 32×32 の待機絵（採用しない）は `old-32x32/`
- 作り方: `make.py`（下・上は左半分を描いて左右反転、足は部品を重ねる）。色は 12〜14色
- どのシートもドット絵エディタで描き、食い違い 0 マスを確かめた（`*-editor.png`）。各フォルダの `walk.gif` が動き

- **2026-10-07、人間が ① 16×16（`v16x16/`）を選んだ。** ほかの型は見比べ用に残している。
- 2026-10-07、人間の指示「後ろから見たとき足が前しか見えない」で、16×16 の後ろ向きに後ろ足を足した（前足は体の左右に小さく、後ろ足はしっぽの左右。前と後ろは逆に出す）。

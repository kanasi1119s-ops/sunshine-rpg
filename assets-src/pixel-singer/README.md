# ドット絵の歌い手（歌の動画用。RPGでは使わない）

旭さんの絵（`参考_もらった絵.jpg`）のキャラクターを、ドット絵エディタ（`tools/pixel-editor`）で打って作った歌い手です。

## 採用した版（2026-11-23、旭さん「これでいこう」）

- 作品: `縦ロールの歌い手_v24.sunshine-pixel.json`（エディタの「作品を開く」で読みこめる）
- 絵の設計: `art_24x40_v24.py`（どのマスに何色を置くかの表）
- 大きさ: 横26×縦40（絵は横24。左右に1マスずつ、ゆれる分の余白）。33色
- コマ: 動き16 × 口と目7（とじる・あ・い・う・え・お・まばたき）＝ 112コマ。並びは「動き1の7コマ → 動き2の7コマ → …」
- 動き: 体は16コマのうち左右3コマずつだけ1マス寄る／つま先を下ろす拍（動き5・6・13・14）で1マスしずむ／縦ロール・あほ毛・スカートのすそがおくれてゆれる／左足のつま先だけでリズムを取り、右足は動かさない

## 作り直し方

```
python3 editor_drive.py art_24x40_v24.py <出力フォルダ> <名前>     # エディタをブラウザで開き、クリックで1マスずつ打って、エディタの「作品を保存」を受け取る
python3 render.py <出力フォルダ>/<名前>.sunshine-pixel.json <出力フォルダ> <名前> 7   # 確認用の絵・等倍シート・見本GIF
```

- ドット絵は、ファイルを直接書かずにエディタで作る（旭さんの決まり）。`editor_drive.py` は、エディタが返した作品を設計とくらべて、ちがうマスの数を出す（0 になること）。
- エディタは、はじめ「左右対称に描く」が入っている。左右でちがう絵なので切ってから打つ。

## 決めたこと（やり直さないために）

- お手本にした広告のドット絵からは、頭身・目の作り・色の段の付け方などの考え方だけを取り入れた（絵はなぞっていない）。
- 足: 3マス幅 → ひざから下2マス。スカートはひざがかくれる長さ。縦ロールは13段（ひじのあたりまで）。
- 胸から上だけを横にずらすと胴が折れて見えるので、体を動かすときは頭から腰までひとかたまりで動かす。
- 古い版（v5〜v23 と 24×32・32×48・64 の試作）は、経過の記録として残している。

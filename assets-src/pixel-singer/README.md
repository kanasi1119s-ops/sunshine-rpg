# ドット絵の歌い手（歌の動画用。RPGでは使わない）

旭さんの絵（`参考_もらった絵.jpg`）のキャラクターを、ドット絵エディタ（`tools/pixel-editor`）で打って作った歌い手です。

## 採用した版（2026-11-23、旭さん「これでいこう」）

- 作品: `縦ロールの歌い手_v24.sunshine-pixel.json`（エディタの「作品を開く」で読みこめる）
- 絵の設計: `art_24x40_v24.py`（どのマスに何色を置くかの表）
- 大きさ: 横26×縦40（絵は横24。左右に1マスずつ、ゆれる分の余白）。33色
- コマ: 動き16 × 口と目7（とじる・あ・い・う・え・お・まばたき）＝ 112コマ。並びは「動き1の7コマ → 動き2の7コマ → …」
- 動き: 体は16コマのうち左右3コマずつだけ1マス寄る／つま先を下ろす拍（動き5・6・13・14）で1マスしずむ／縦ロール・あほ毛・スカートのすそがおくれてゆれる／左足のつま先だけでリズムを取り、右足は動かさない

## 作り直し方

```
python3 editor_drive.py art_24x40_v24.py <出力フォルダ> <名前>     # エディタをブラウザで開き、クリックで1マスずつ打って、エディタの「作品を保存」を受け取る
python3 render.py <出力フォルダ>/<名前>.sunshine-pixel.json <出力フォルダ> <名前> 7   # 確認用の絵・等倍シート・見本GIF
```

- ドット絵は、ファイルを直接書かずにエディタで作る（旭さんの決まり）。`editor_drive.py` は、エディタが返した作品を設計とくらべて、ちがうマスの数を出す（0 になること）。
- エディタは、はじめ「左右対称に描く」が入っている。左右でちがう絵なので切ってから打つ。

## 決めたこと（やり直さないために）

- お手本にした広告のドット絵からは、頭身・目の作り・色の段の付け方などの考え方だけを取り入れた（絵はなぞっていない）。
- 足: 3マス幅 → ひざから下2マス。スカートはひざがかくれる長さ。縦ロールは13段（ひじのあたりまで）。
- 胸から上だけを横にずらすと胴が折れて見えるので、体を動かすときは頭から腰までひとかたまりで動かす。
- 古い版（v5〜v23 と 24×32・32×48・64 の試作）は、経過の記録として残している。

## 金髪の子（4方向の読み取りと、ダンス1000コマ）（2026-11-28）

旭さんの用意した4方向の絵（`dance/参考_もらった4方向の絵.jpg`。1マスが約2.77ピクセルのドット絵ふうの画像）から作った。

- 読み取り: `dance/grab.py`（マスの大きさとずれを、マスの中の色のばらつきが最小になる所で決める）→ `dance/build.py`（4枚を同じキャンバス 64×168 に、足もとをそろえて並べ、56色にまとめる）→ `dance/clean.py`（まわりの灰色のにじみを消す）。結果は `dance/4方向の読み取り.json`。
  もらった絵の2枚めと4枚めはどちらも右向きなので、左向きは右向きの左右反転で作る。エディタで打った3方向（正面・右向き・後ろ）は `dance/金髪の子2_3方向.sunshine-pixel.json`。
- ダンス: `dance/rig.py`（正面を部位に分ける。足はひざから下を上げてふとももをちぢめる。手拍子の前うでと手は、肌の色の段で描く。回るときは4方向を切りかえて横を少し縮める）と `dance/dance.py`（振り付け。1000コマ・24コマ/秒・テンポ120）。
  1000コマのうち形のちがうコマは192。`dance/ダンスの形192.sunshine-pixel.json` がエディタで打った192コマ、`dance/1000コマの並び.json` が1000コマそれぞれに使う形の番号。
- エディタでの打ち方: `editor_drive_fast.py`（エディタのキャンバスに、マウスを押す・横に動かす・はなす操作をまとめて送り、エディタのえんぴつで同じ色の横の並びをひと筆で引く。localStorage の自動保存は止める）。
  エディタの「元に戻す」の記録は、1筆ごとに全部のコマを写すので、コマが多い作品は16コマずつ打ってから `dance/assemble.py` で1000コマにまとめ、エディタで開いて保存しなおした。
- エディタを直した所（tools/pixel-editor/index.html）: 1筆ごとにキャンバス・プレビュー・書き出しの文字・フレームの一覧を作り直していたのを、次に画面を描くときにまとめて1回にした（10コマで 272秒 → 48秒）。
- 1000コマの作品（約14MB）はリポジトリに入れず、出力フォルダに置いた。見本の動画は `dance/video.py`。

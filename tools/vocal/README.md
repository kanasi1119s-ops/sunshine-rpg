# 歌声の道具（ボカロ曲づくり用。ゲームには入れない）

| 道具 | すること |
|---|---|
| `vocal-export.py` | 歌の旋律と歌詞（`_gen/*-vocal.py`）を OpenUtau のプロジェクト（.ustx）・MusicXML・歌詞カードに書き出す |
| `utau-render.py` | UTAU 音源（oto.ini つき）で実際に歌わせて WAV にする（連続音でつなぎ、歌い出しは単独音、フレーズ終わりは「a R」。WORLD で高さと長さを変える） |
| `vocal-mix.py` | 歌と伴奏を混ぜて仕上げる（ボーカルの EQ・コンプ・リバーブ・ディレイ → -13.5 LUFS） |

## 例（重音テト『なつぞら、かけだせ』）

```
VB=<音源フォルダ>/重音テト音声ライブラリー
python3 tools/vocal/utau-render.py assets-src/ai-songs/_gen/teto-natsu-vocal.py --vb "$VB/重音テト連続音" --head-vb "$VB/重音テト単独音" \
  --breath "$VB/重音テトエクストラ" --bpm 150 --out 歌.wav --cache <分析の置き場> --gain "8-24:0.94,24-32:0.97,56-64:0.94,64-72:0.97,88-96:0.9" --breath-db -20
python3 tools/vocal/vocal-mix.py 伴奏.wav 歌.wav --out 完成.wav --bpm 150 --vocal-lu 1.5 --stems 完成
```
必要なもの: `pip install --break-system-packages pyworld pedalboard pyloudnorm`（確かめ用: `faster-whisper praat-parselmouth`）

## 2026-10-15 の改良（人間の指示「強弱がありすぎて聞きにくい」「自然な歌声に」）
- 原因: 短い音（8分音符＝0.2秒）の次の音の子音（先行発声 約0.3秒）が、前の音の母音の時間に食いこみ、な・だ・さ などの前の音が 10dB 以上小さくなっていた。
- 直し方: UTAU の自動調整と同じく、はみ出す子音を縮める（子音速度。最小 0.4 倍）／音ごとに母音の大きさをそろえる／同じ力のクロスフェード／ボーカルライド（±4dB）／
  長い音は母音の安定部分を半分の速さで行き来／元の声の細かな音程の揺れを残す／フレーズの前に息。
- 結果: となりの音との大きさの差（90%）11.2dB → 1.6dB。文字起こしは全部の区間で歌詞どおり。完成版 PQ 8.10（歌は伴奏 +1.5LU）。
- 「滑らか音源」（2021）も試したが、子音がぼやけて言葉がほとんど聞き取れなかったので使わない（通常の連続音を使う）。

## 2026-10-15 の改良その2（人間の指示「ノイズを少なく、透き通る声に」）
- 測った: 元の録音の雑音は声より 56dB 小さく問題なし。合成後の声は、母音のきれいさ（HNR）が元より約 6dB 悪かった。
- 原因1: WORLD の「かすれ（非周期成分）」の見積もりが大きめ → 声のある所だけ下げる（--ap-power 2、標準）。
- 原因2: 音のつなぎ目で、別々に合成した2つの声の波を足していた（波の山の位置がずれて、ざらつく）
  → フレーズごとに、スペクトル（対数）・かすれ・音の高さを混ぜてから1回で合成（Phrase）。合成も 3分→20秒に速くなった。
- ミックス: 高域の持ち上げを控えめ（12kHz +1dB）、ディエッサー（5.5kHz より上）、息を -20dB に。
- 結果: 母音の HNR 中央 26.5 → 32.8dB（元の録音 31.6〜32.9dB と同じくらい）。文字起こしは全区間で歌詞どおり。完成版 PQ 8.11。

## 確かめ方（耳の代わり）
- 音の高さ: 歌の WAV を WORLD で分析し、楽譜とのずれ（セント）を見る（初回: 中央値 2.3 セント、95% が 11 セント以内）。
- 言葉の聞き取りやすさ: faster-whisper（small）で文字起こしして歌詞と比べる。
- かすれ・ノイズ: praat-parselmouth の HNR（母音のきれいさ。大きいほど透き通る）と、6〜12kHz の量。
- 音質: Audiobox Aesthetics（完成版 PQ 8.11）。

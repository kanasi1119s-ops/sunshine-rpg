# ドット絵エディタ（使い方）

sunshine-rpg の絵（キャラ・敵・タイル・顔アイコン）を描くための、ブラウザで動くドット絵エディタです。
Aseprite のような作業画面（メニュー・レイヤー・フレーム・タイムライン）と、このゲーム用の機能（文字の記号で書き出す・画像から重厚な敵を作る・陰影プレビュー）を、1つのページにまとめています。

- ファイル: `tools/pixel-editor/index.html`（これ1つで動きます。ネットにつながっていなくても使えます。字体だけはネットから読み込みます）
- 公開版: Artifact「ドット絵エディタ」 https://claude.ai/artifact/Xo7VKZU9cHJk15BnvVmxdp （中身はこのファイルと同じ。直したら両方を更新する）
- 開き方: `index.html` をブラウザ（Chrome・Edge・Safari・Firefox）で開くだけ。スマホでも使えます。

## 画面のつくり

| 場所 | 中身 |
|---|---|
| 上 | メニュー（ファイル・編集・画像・レイヤー・フレーム・表示・ヘルプ） |
| 左 | グリッド（大きさ・拡大率・対称・陰影・マスの線・区切り線）、ツール、下絵、画像から作る、仕上げ、テンプレート、操作 |
| 中 | キャンバス、情報バー（マウスの位置・大きさ・拡大率・フレーム・レイヤー）、タイムライン |
| 右 | パレット、プレビュー（3倍・6倍・タイル表示）、書き出し |

スマホでは、キャンバスがいちばん上に来て、その上にツールと色のボタンが並びます。

## はじめの一歩

1. メニュー「ファイル → 新しい作品…」で大きさ（例: 16×16、96×96）を決める。キャラの土台から始めるときは、左の「テンプレート」を使う。
2. 右の「パレット」で色を選ぶ。**左クリック＝主色、右クリック＝副色**（副色は、はじめは「消」＝消しゴム）。色の四角の横の色ボタンで色を変え、名前（肌・髪など）も付けられる。
3. キャンバスをクリック・ドラッグして描く。右クリックで副色（はじめは消しゴム）。
4. できたら右の「書き出し」から、PNG・GIF・シート、または文字の配列で持ち出す。

描いた作品は、このブラウザの中に自動で残ります（ブラウザのデータを消すと消えるので、大事な作品は「作品を保存」でJSONにして残す）。

## ツール

| キー | ツール | メモ |
|---|---|---|
| B | ペン | 太さ 1〜8（`[` `]` で変える）、形は四角か丸 |
| E | 消しゴム | |
| G | 塗りつぶし | 「つながった所だけ」を外すと、同じ色をぜんぶ塗りかえる |
| I | スポイト | Alt を押しながらクリックでも使える。右クリックなら副色に |
| L | 直線 | Shift で 0°・45°・90° にそろう |
| U / Shift+U | 四角（枠）/（塗り） | Shift で正方形 |
| O / Shift+O | だ円（枠）/（塗り） | Shift で円 |
| M | 範囲選択 | 選んだ範囲の中にだけ描ける。クリックだけで解除 |
| V | 動かす | 選んだ所（選んでいなければレイヤー全体）を動かす。Alt で複製。矢印キーで1マスずつ。Enter で確定 |
| H | 画面移動 | スペースを押しながらドラッグ・中ボタンのドラッグでも同じ |
| W | 似た色を消す | 画像から作ったあとに残った、グラデーションの背景を消す |

ペンの設定:
- **ピクセルパーフェクト**: 斜めの線のかどにできる余分な1ドットを自動で消す（細い線をきれいに）
- **市松（ディザ）で塗る**: 1マスおきにだけ塗る（2色の間の中間色の表現に）
- **描いてある所にだけ塗る**: 透明な所には塗らない（形をはみ出さずに陰を付けるときに便利）
- **左右対称・上下対称**（左の「グリッド」）: 反対側にも同時に描く

## 色（パレット）

- 主色・副色: ツールの下の2つの四角。X キーで入れかえ。
- 「明暗の段」: 主色をもとに、暗い色2段（青紫寄り）と明るい色2段（黄色寄り）を足す。陰影の色を作るときの出発点に。
- 「明るさ順」: 暗い順に並べかえる。
- 「未使用を消す」: どのレイヤー・フレームにも使っていない色を消す。
- 色は62色まで（1色＝1文字の記号で書き出すため）。

## レイヤーとフレーム（タイムライン）

キャンバスの下のタイムラインは、**縦がレイヤー、横がフレーム**の表です。マス（●＝描いてある、○＝空）を押すと、そのレイヤー・フレームに切りかわります。

- レイヤー: ＋レイヤー・複製・削除・↑↓（並べかえ）・下と結合、◉ で表示／非表示、名前と不透明度。
- フレーム: ＋フレーム・複製・削除・←→（並べかえ）、「長さ」（ミリ秒）、▶ 再生（Enter）。
- オニオンスキン（F3）: 前のフレームが赤み、次のフレームが青みで透けて見える。歩くアニメを描くときに使う。
- 歩くアニメの作り方の例: 1コマ目を描く → 「複製」で2コマ目を作る → オニオンスキンを付けて足と腕だけ描き直す → 長さを 150〜250 ミリ秒にして再生で確かめる。

## 編集・画像のメニュー

- 編集: 元に戻す（Ctrl+Z）・やり直す（Ctrl+Y）、切り取り・コピー・貼り付け（Ctrl+X/C/V）、消去（Delete）、すべて選択（Ctrl+A）・選択を解除（Ctrl+D）、左右反転（Shift+H）・上下反転（Shift+V）、主色を副色に置きかえる（Shift+R）、ずらす（ループ）。
  - 貼り付けた絵は「動かす」でドラッグして置き場所を決め、Enter で確定する。
  - **ずらす（ループ）**は地形タイルのつなぎ目直しに使う: 半分ずらす → まん中に来たつなぎ目を描き直す → もう一度半分ずらして元に戻す。右のプレビューの「タイル表示」で3×3に並べて確かめる。
- 画像（すべてのレイヤー・フレームが変わる）: キャンバスの大きさ（絵を寄せる場所を9か所から選ぶ。キャラは「下のまん中」がおすすめ）、ぜんぶ反転、90°回転、2倍に拡大、半分に縮小。

## 表示

- ホイール・`+` `-`: 拡大・縮小（マウスの下を中心に）。`0`: 画面に合わせる。
- マスの線、区切り線（例: 16 で 1マス16ドットのタイルの境目）、陰影プレビュー（portraits.ts と同じ式の陰を付けて見る。書き出しには入らない）、タイル表示。

## 下絵・画像から作る・仕上げ（このゲーム用）

- **下絵**: 画像を薄く重ねて、なぞって描く（保存はされない）。
- **画像から作る（重厚な敵）**: 絵画風の絵（AIの下絵など）を、縮小→減色→孤立点を消す→色つきの縁取り→左上の照り、の順で陰影の重いドット絵にする。いま選んでいるレイヤーに入る。くわしい手順は `.claude/skills/make-art/monster.md`。
- **仕上げ**: 孤立点を消す・色つき縁取り・左上の照り・色を減らす、をいまのレイヤー・フレームに1つずつかける。
- **テンプレート**: portraits.ts と同じ顔の土台（短髪・長髪・ツインテール・撫でつけ）。新しい作品として始まる。

## 書き出し・読み込み

| 方法 | 中身 |
|---|---|
| PNG | いまのフレーム（またはすべてのフレームを1枚ずつ）を、倍率を選んで画像に |
| GIF | すべてのフレームを、くり返し再生のアニメGIFに（透明つき。レイヤーの不透明度は使われない） |
| シート | すべてのフレームを1枚に並べたスプライトシートと、位置と長さのJSON |
| 作品を保存／開く | レイヤー・フレーム・色をまるごとJSONで（Ctrl+S / Ctrl+O）。開くときはファイルを選ぶか、テキストを貼り付ける |
| PNGを読み込む | 1ドット＝1マスでそのままの色で読み込む（256×256まで。新しいレイヤーに、または新しい作品として） |
| 文字の配列 | 「書き出し」欄の配列は、表示中のレイヤーを重ねた、いまのフレーム。TypeScript にそのまま貼れる。「貼り付けて読み込む」で、配列をいまのレイヤーに入れられる |

公開版（Artifact）の中では、ファイルを直接パソコンに保存できません。できた画像は**右クリック（スマホは長押し）→「名前を付けて画像を保存」**、JSONは「コピー」してファイルに貼ってください。手元で `index.html` を開いたときも同じ操作で保存できます。

## Claude Code から使う（自動で描く）

`tools/pixel-practice/editor-draw.mjs` が、このエディタをヘッドレスブラウザで開き、文字グリッドの絵を実際のマウス操作で描いて、「食い違い 0 マス」を確かめます（make-art の決まり）。エディタはこのフォルダの `index.html` を使います（環境変数 `EDITOR` で別のファイルも指定できる）。

準備: ヘッドレスブラウザを動かす `playwright-core` が要ります（リポジトリの依存には入れていない）。はじめに一度 `npm install --no-save playwright-core` を実行してください。ブラウザ本体は `/opt/pw-browsers/chromium` を使います（`playwright install` は不要）。

```bash
node tools/pixel-practice/editor-draw.mjs 絵.txt パレット.json 出力.png --zoom 6            # マウスで1ドットずつ
node tools/pixel-practice/editor-draw.mjs 絵.txt パレット.json 出力.png --zoom 6 --import   # 大きな絵（読み込み＋直し描き）
node tools/pixel-practice/editor-draw.mjs 絵.txt パレット.json 出力.png --zoom 6 --wide --import   # 256×256 など
```

エディタを直すときは、`editor-draw.mjs` が使う部品の名前（`#gridW` `#gridH` `#resizeBtn` `#zoom` `#symmetry` `#showShading` `#templateSelect` `#loadTemplateBtn` `#addSymbolBtn` `#symbolList` の各行・`#gridCanvas` `#importRows` `#importBtn` `#exportRows` `#refFile` `#refOpacity` `#refClearBtn`）を変えないこと。直したら、上の3つの使い方で「食い違い 0 マス」になるか確かめる。

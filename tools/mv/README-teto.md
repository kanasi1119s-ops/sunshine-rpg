# 歌う重音テトの動画（切り抜き・なめらかな動き）

2026-10-29 人間「このトリミングしたテトさん今後も使うからね」。何度でも同じ品質で使えるように、作り方と置き場所をまとめる。

## 素材

- 切り抜いたコマ（RGBA・240コマ・720×1280、透明な背景）: **G:\マイドライブ\テト切り抜き\000.png〜239.png**（Google ドライブ）。クラウドでは /mnt/user-data/outputs/teto_matte
- 口の位置の追跡: tools/mv/track_teto_a.json（コマごとの口の位置と、口の開き）

## 切り抜き（teto_matte2.py）
`python3 tools/mv/teto_matte2.py <元のコマのフォルダ> <出力フォルダ> <縮める倍率>`
- 背景が真っ白とわかっているので、縁のあいまいな数ピクセルは「体の色と白が α の割合で混ざった色」として α を計算する → 縁がなめらか・輪郭の黒い線が残る・白いにじみが残らない
- 体の色の推定は、3ピクセル以内のいちばん暗い色（輪郭線）。α が小さい所は推定した色に寄せる（色がぶれない）
- 白は、リボン本体・白目・歯のほかは、どこにあっても背景にする（腕と体のすきま・指のあいだ・髪の巻きのすきま・髪とリボンのすきま）
- リボン: 細い輪郭線にすきまがあると背景がリボンの中まで流れこむので、リボンの枠の中だけ線を太らせて壁にする。リボンの影の青むらさきの所は穴をあけない。髪の縁にそって細く残る白は取りのぞく
- 縮めるときは α をかけた色で縮めてから戻す
- 確かめ方: 全コマで「α が 0.25 より大きく、白に近い色」の所を数える（2026-10-29 時点で 240コマ合計 200ピクセルほど＝肌のふちの光など、絵そのもの）。濃い色・明るい色・まだらの背景の上に重ねて、髪のまわり・手・リボンを拡大して見る

## なめらかな動き（smooth_motion.py、stage_mv.py の MV_SMOOTH=1 MV_FPS=48）
- 並び（24コマ/秒のコマ番号）を、飛ぶ所で区切り、区切りの中をガウスでならした「なめらかな位置」にする（向きの変わり目は振り子のように減速して戻る）
- 48コマ/秒で書き出し、小数の位置の絵は、となりの2コマのあいだをオプティカルフロー（DIS）で補間する（ただ重ねると二重に見えるので）
- 飛ぶ所は4コマかけて溶かして切りかえる
- 口の形は、歌詞の母音から並びを選ぶ（teto_mv.py。元の動画のコマだけで口と体を動かす。2026-10-26 人間）

## 動画の書き出し
`MV_SMOOTH=1 MV_FPS=48 python3 tools/mv/stage_mv.py <曲番号> <songs.tsv> <歌の mp3> <曲の JSON> <UST> <並び json> <切り抜きのフォルダ（縮めたもの）> <舞台の絵> <出力 mp4>`
- 舞台の上に置くときは 0.66 倍（844 ピクセルの高さ）に縮めた切り抜きを使う（teto_matte2.py の倍率 0.66）

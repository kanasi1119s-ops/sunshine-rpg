# オープニング映像（リングライト・クロニクル）

`make_op.py` … 曲『ひのわのそらへ』（`assets-src/ai-songs/_gen/hinowa-op.py`＝伴奏、`hinowa-op-vocal.py`＝重音テトの歌）の拍に合わせて、
1280×720・30fps・84秒の映像を作り、ffmpeg で MP4 にする（2026-10-16、人間の指示「リングライトクロニクルのオープニングアニメーション作ろっか」）。

- 素材: ゲームの戦闘の背景（`src/assets/battle-bg`）、ドット絵帳（Artifact）から取り出した仲間の全身・ボス・神の絵（`art/`）、歩く絵（`header/walk-c*.png`）、
  町の画面（note 記事用に撮った写真）。字体は Cinzel・しっぽり明朝 B1（どちらも SIL OFL。npm の @fontsource から）。
- 流れ（1小節＝1.5秒）: 前奏 8（夜空に光の環 → 夜明けの草原）→ リフ 8（土地のモンタージュ）→ Aメロ 8（仲間6人の紹介）→
  Bメロ 8（歪みの影・謎）→ サビ 16（草原を駆ける・戦い・8つの神・船出・朝日の環）→ 後奏 8（タイトル・全員で一発）。
- 使い方: `python3 make_op.py <出力.mp4> --audio <曲.wav>`。`--still 秒 --png 絵.png` で1コマだけ確かめられる。
- 素材の場所はファイルの先頭（GAME・ART・PHOTO・WALK・字体）で決めている。作業フォルダに合わせて書きかえる。

## 2026-10-16 作り直し（人間の指摘を受けて）

- 曲をジグ（6/8・BPM120で1拍を3連に分ける）に書き直した（「ケルト感ないかな。ケルトちょっと勉強してきて」）。1小節＝2秒・44小節・88秒。
- 仲間はドット絵をやめ、元のイラスト（人間のPCの立ち絵シート。顔・全身を切り出して使う）にした（「キャラクターは大元の画像使おうか」）。
- ボス・神は、手直し済みの版（ブランチ monster-fullbody の `assets-src/monsters/<ID>/final.txt`）から書き出したものにした（「ゲームのボスの直した版」）。
- タイトルはゲームのロゴ（`src/render/logo-pixel.ts`）。`render-logo.mjs` で開発用サーバーから PNG に書き出して使う（「ロゴちゃんとあるから使って」）。
- 流れ: 前奏4（夜空の環 → 草原）→ 笛とフィドルの曲8（土地）→ Aメロ8（仲間の紹介・6人並び）→ Bメロ4（ボス8体）→ サビ16（駆ける・戦い・8つの神・船・環）→ 後奏4（ロゴ）。

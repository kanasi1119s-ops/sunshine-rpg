# 戦闘背景の確認ツール（追加の6つ）

`src/render/battle-backdrop-extra.ts` に、戦闘の背景を6つ足しました（まだ本体には組み込んでいません）。
`render.mjs` は、その絵をヘッドレスブラウザで描いて PNG にします。

```
node tools/backdrop-preview/render.mjs            # 6つ全部
node tools/backdrop-preview/render.mjs forest lava # 指定だけ
```

出力は `tools/backdrop-preview/out/<kind>.png`（400×225 を2倍）。塗り残しは桃色で出て、数がコンソールに出ます。
playwright-core は `/opt/node-tools/node_modules` などから探し、ブラウザは `/opt/pw-browsers/chromium` を使います。

## 6つの特徴

| kind | 場所 | 特徴 |
|---|---|---|
| forest | 深い森 | 天井の濃い葉、左上から斜めに差す木漏れ日の筋、霞む奥の幹、苔むした太い幹、地面の光だまり、倒木、しだ、舞う光の粒 |
| swamp | 沼 | 夕暮れの空と低い太陽、枯れ木（枝分かれ）、濁った水面と夕日の映り込み、水面の霧、浮かぶ水草、手前の葦とがま |
| coast | 海辺 | 水平線と遠い島・帆かげ、波の筋ときらめき、浅瀬と泡の波打ちぎわ、砂浜、岩、かもめ、青空と雲 |
| sky | 空の上 | 青から薄紅へのグラデーション、霞んだ遠い浮島、3列の雲海、滝のある浮島、遠近の石畳の浮かぶ足場、折れた石柱 |
| lava | 火山の洞窟 | うねって手前に広がる溶岩の川（黄→橙→赤→黒い殻）、黒い岩の床と赤く光るひび、天井の黒い岩、奥の赤い光、立ちのぼる火の粉 |
| shrine | 神殿・禁域 | 青白い光の柱、大きな環の紋様（目盛りの輪・星形・中心の光）、左右の石柱、石畳の床に映る環と光、漂う光の粒 |

どれも画像ファイルは使わず、Canvas 2D で一度だけ描きます（既存の5つと同じ作り方）。色は帯ごとに5〜8段、境目は市松、光は左上、奥ほど淡く手前ほど濃くしています。

## 本体への組み込み手順

`src/render/battle-backdrop.ts` を次のように変えます（今回は既存ファイルを触っていないので、組み込みは別の作業で）。

1. 先頭で `import { paintExtraBackdrop, type ExtraBiome } from "./battle-backdrop-extra";`
2. `export type Biome = "grass" | "cave" | "desert" | "snow" | "ruins" | ExtraBiome;`
3. `BIOME_BY_PREFIX` に、どの地図でどの背景を使うか足す（地図の名前の先頭で決まる）。例: 森の地図 → `"forest"`、沼の地図 → `"swamp"`、港・海岸の地図 → `"coast"`、空の島の地図 → `"sky"`、火山の洞窟 → `"lava"`、禁域・神殿の地図 → `"shrine"`。どの地図IDがどれに当たるかは、`docs/story/` と地図データを見て決める。`biomeForMap` は今のまま（先頭一致で `Biome` を返す）でよい。
4. `getBackdropCanvas` の `switch` に `case "forest": case "swamp": case "coast": case "sky": case "lava": case "shrine": paintExtraBackdrop(biome, ctx, w, h); break;` を足す。
5. 戦闘の背景が640×360などの別サイズで呼ばれる場合は、座標が400×225前提の固定値なので、いったん400×225で描いて拡大するか、`w`/`h` に合わせて直す。

## 弱いところ（正直に）

- 座標は 400×225 の固定値。ほかのサイズでは崩れます。
- 画面の下側は戦闘のウィンドウに隠れる前提で作ったので、下の方（森の地面、海辺の砂浜、沼の岸）はやや単調です。
- forest: 奥の幹が似た形で、縞のように見えます。倒木はあまり良い出来ではありません。
- swamp: 枯れ木は同じ作り方なので、並ぶと似て見えます。手前の水面は単調です。
- coast: 砂浜が広くて単調。岩は形が少なく、かもめは記号的な形です。
- sky: 雲海は同じ作りの重ね。浮島の岩は単純な形です。
- lava: 空や壁の帯の段差が目立ちます。手前の黒い岩は、暗すぎて形が読み取りにくいです。川のふちの市松が少し粗いです。
- shrine: 環の星形は単純な図形（六芒星）です。床の石畳は遠近が簡易で、本当の透視にはなっていません。
- ブラウザの実機（本体の戦闘画面にキャラクターやウィンドウが重なった状態）での見え方は、まだ確かめていません。確認画像は背景だけです。
- 半透明の色（光の筋・霧・光）を使っています。厳密な「パレット固定」ではありません。
- テストは「例外なく描ける・塗り残しがない」だけです。見た目の良し悪しは `out/*.png` を目で見て判断してください。

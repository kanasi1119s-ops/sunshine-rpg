# 大きな敵・ボスのドット絵を1体描く（担当者向けの共通指示）

## 目的
`tools/pixel-art/v5/pieces/<ID>.mjs` に、指定された敵（またはボス）の絵を1つ作る。完全オリジナルのデザインで、「遊べる品質」まで仕上げる。仕上がりの目安は、スーパーファミコン後期の大型の敵の絵（大きなシルエット、3〜5段階の陰影、光の縁、暗い輪郭、細かい描き込み）。
参考にするのは**技法だけ**（形の作り方・陰影・輪郭・質感）。既存作品の敵の姿・配色・構図・名前は使わない（CLAUDE.md 1-1）。

## 道具（必ず先に読む）
- `tools/pixel-art/v5/lib5.mjs` … 描画道具。`Cv` クラスで「形（マスク）を作る → paint で立体の陰影つきで塗る → edge/rim/speckle/outline で仕上げる」。光は左上。`ramp()` で色の並び（暗→明）を作る。**このファイルは変更しない**（足りない道具は自分の絵のファイルの中で定義する）。
- 見本: `tools/pixel-art/v5/pieces/s1-lantern-slime.mjs`（64×64の小型）。
- 確認: `node tools/pixel-art/v5/render5.mjs <絵.mjs> <出力PNG> [倍率]` で画像にし、**Read ツールで画像を必ず目で見て**直す（1回描いて終わりにしない。最低でも5回は「描く→見る→直す」を繰り返す）。出力PNGは `/tmp/claude-0/-home-user-sunshine-rpg/51da3179-7489-57f0-b669-53f06cb3ad87/scratchpad/` の下に置く。倍率は 64→10、128→6、192→4、256→3 くらい。全体と、顔や手など細部の両方を見ること（細部は倍率を上げて見る。必要なら rows を部分的に切り出して別の絵にして見る）。
- 参考のドット絵（技法の勉強用）: `assets-src/pixel-library/{02-monsters,03-bosses,...}/`。`NODE_PATH=/opt/node22/lib/node_modules/playwright/node_modules node tools/pixel-art/v5/zoom-ref.mjs <出力PNG> <倍率> <参考PNG...>` で拡大して見られる。大きな絵の参考になる例: 03-bosses/oga-fat-zombie.png(192×256)、oga-dragon-a/b/c.png、oga-flash-mage.png、oga-plague-king.png、oga-eastern-dragon.png、mw-black-dragon.png。見て学ぶのは、輪郭の色の使い方、陰影の段数、ハイライトの置き方、質感の描き方。
- 既存の32×32の絵（`tools/pixel-art/v4/pieces/`）や、`src/game/art/` の古い絵は、参考にしない（出来が良くない）。

## 決まり（守れない絵は不合格）
1. ファイルの形: `export const name`（日本語の名前）, `category`（"monster" か "boss"）, `size`（正方形の一辺）, `pal`（文字→"#rrggbb"）, `rows`（size 行 × size 文字。"." は透明）。ファイル名は半角の英小文字・数字・ハイフンだけ（UTF-8）。
2. **色は26色以内**（使っている文字の種類が26以下）。`pal` の文字が**重ならない**ように注意（ramp("abcde")のあとに同じ文字を別の色で上書きしないこと。過去にこれで絵が壊れた）。render5 が色数を表示する。
3. 大きさは**指定のキャンバスいっぱいに近く**使う（体が小さすぎる・余白が多すぎるのは不可）。足元の落ち影（`shadow`）は、地面に立つ敵には入れる。空中の敵は影を離して薄く。
4. 見た目: 輪郭は「真っ黒」ではなく、隣の色に合わせた暗い色（`outline` の map を使う）。形は丸い塊の寄せ集めに見えないように、部位ごとの形の違い・重なり（手前と奥）・大小の対比・鋭い角と丸みの対比をつける。陰影は光が左上。目は、光る目なら明るい芯を入れる。1ドットだけの孤立した点（ざらつき）は、狙った所（ハイライト・きらめき）以外は作らない（`despeckle` を使う）。
5. 勝手に既存作品の姿を写さない。似ていると感じたら描き直す。名前も既存作品で使われていそうな名前は避ける。
6. 他のファイルは変更しない（自分の `pieces/<ID>.mjs` だけを作る・直す。lib5.mjs、他の絵、CLAUDE.md、docs は触らない。gitのコミット・プッシュもしない）。
7. 仕上げに `node tools/pixel-art/v5/render5.mjs` で最終確認して、色数・大きさ・見た目を確かめる。

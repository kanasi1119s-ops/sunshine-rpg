# 進み具合をまとめる手順

**このスキルでは、ファイルの変更・コミット・プッシュはしない。** 読んでまとめるだけにする。

1. 最新の `main` を取得する。
2. 次を読む。
   - `docs/progress.md`（「作業中」欄、完成したこと、次回やること）
   - `docs/roadmap.md`（工程表のチェック状況）
   - `docs/playtime-budget.md`（プレイ時間の予算）
   - `docs/story/clue-ledger.md`（伏線台帳）と `docs/story/side-stories.md`（サブストーリー）
   - `docs/sound/tracks.md`（曲の一覧）
   - `reports/` の直近の実行レポート（最新5件程度）と、直近の日ごとのまとめ
3. 次の形で、旭さん向けにやさしい日本語でまとめる。

```
■ いま遊べる範囲: 序章〜第○章（仮の部分: …）
■ 工程表: 全○項目中 ○項目完了（○%）。いまの段階: …
■ 物語: 章の状態（完成／仮／未着手）、サブストーリー ○/○本、裏ボス …
■ プレイ時間の見積もり: メイン約○時間（上限48時間）
■ BGM: 完成○曲／仮○曲／未着手○曲
■ 最近の実行: 1日あたり○回・平均○分・1回あたり平均○項目
■ 完成までの見込み: このペースで約○週間（根拠: 残り項目数 ÷ 1日あたりの完了数）
■ 旭さんに確認してほしいこと: …（実行レポートの「人間に相談したいこと」から）
■ 遊んでみてほしい所: …（人間のテストプレイを勧める区切りがあれば）
```

4. まだ工程表や記録がない場合は、「まだ作業が始まっていません。`/rpg-cycle` で最初の作業（工程表づくりと基盤）を始められます」と伝える。

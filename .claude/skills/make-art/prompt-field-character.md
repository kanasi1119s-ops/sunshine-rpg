# 2頭身の歩くキャラ（16×32）を、1から完成まで作るためのプロンプト

うちの仲間6人（ユーリ・レト・ミナ・コハク・オルカ・アヤメ）の歩くキャラと同じ作りのキャラを、
**設定を決めるところから、エディタで描いてゲーム用データにするところまで**作るときの頼み方。
`〈 〉` のところを書きかえて使う。作り方の中身は `field-character.md`（型の使い方）と `pixel-character-guide.md`（決まり）。

## A. Claude（定期作業・Claude Code）に頼むとき — 1から完成まで

```
/make-art フィールド用の歩くキャラ（2頭身・16×32）を、1から完成まで作ってください。

■ 人物
- 名前: 〈名前〉／役割: 〈例: 港町の見張りの青年〉／性別: 〈男性・女性〉
- 見た目（分かる所だけでよい。空いている所は役割に合わせて決めてよい）:
  髪〈色と形〉、目〈色〉、肌〈色〉、上着〈色と形〉、下〈ズボン・スカート・ワンピース・ローブと色〉、靴〈色〉、
  目印の1色〈例: 襟とマフラーの赤〉、持ち物・飾り〈例: 背中の剣、ランタン、腕輪〉
- イメージ画像: 〈置き場所。なければ「なし」〉

■ 手順（この順に進め、各段階で見本の画像を作って確かめる）
1. 設定: docs/story/characters.md と並べて、ほかの人物と髪の色・目印の1色が重ならないかを確かめる。
   有名なRPGの主人公・キャラを思わせる組み合わせ（色・髪型・飾り）になっていないかも確かめ、似ていたら色を変える。
2. 色: イメージ画像があればそこから6色（髪・肌・上着・下・靴・目印）と目の色を拾う。なければ自分で決める。
   真っ黒に近い髪は、少し明るい茶・紺にする。field_sprite.py の --set で指定し、.compare.png で取り違いがないか確かめる。
3. 形: 型（field_templates.py）の髪型・服・飾りから組み合わせを選ぶ。合う型がなければ型を足す
   （左半分を書いて左右反転、横向きは右向きを書いて反転。足したら全部の組み合わせで12コマが16×32になるか確かめる）。
4. 作る: field_sprite.py で 4方向（下・上・左・右）×3コマ（立ち・左足・右足）を作る。男性は --still-hair（髪を揺らさない）。
5. 見て直す（4倍以上に拡大した一覧で）:
   - 2頭身（頭が体の半分ほど）。1ドットの暗い外周（真っ黒ではなく、その部分を暗くした色）。部位ごとに3段の陰影、光は左上から。
   - 目は縦2ドットの点。ほおに薄い赤み、口は1〜2ドット。髪に暗いすじは入れない（つやは明るい点）。
   - 飾りは細かく: 金具の光、宝石・灯りの白い1ドット、布のしわ、ボタン、腰の袋、靴の折り返し。
   - 4方向とも同じ人物に見えるか。持ち物がどの向きでも手の位置にあるか。全体で20色以内か。
6. 動き: 歩幅は小さめ（前後に1〜2ドット）。出した足と反対の腕を前後に1ドット振る。剣・ランタン・盾を持った手は振らないが、杖は持った手といっしょに上下させる。
   大きな道具（つるはし・弓など）は背中に背負わせる（backpick・bow）。
   女性・長い髪の人物は、髪の先を1ドット揺らす。男性は髪を揺らさない。はちまき・マフラーの端、マントのすそは1ドット揺らす。
   歩く動きのGIF（0→1→0→2、1コマ0.2秒ほど）を作って、がたつきがないか確かめる。
7. エディタで描く: うちのドット絵エディタで 48×128（12コマ）を描き、「食い違い 0 マス」を確かめる
   （editor-draw.mjs --zoom 7、速くするときは --import）。
8. 仕上げ: ゲーム用データ（WalkerData の JSON。palette と frames の down0〜right2）・拡大した一覧（8倍）・歩く動きのGIF・
   エディタ用のファイル（文字グリッドと色）を、assets-src/ の人物名のフォルダにまとめる。

■ 報告
できたら、拡大した一覧・歩く動きのGIF・ほかの仲間と並べた見本を見せてください。
ゲームへの組み込み（walker-data.generated.ts への追加）は、見せてから決めます。
```

## B. 画像生成AI（ChatGPT・Gemini など）で下絵を作るとき

画像生成AIは、ドットの数や外周を正確には守れない。**下絵（色と形の見本）として使い**、仕上げは A の手順で行う。

```
16×32ピクセルの、2頭身のドット絵キャラクターのスプライトシートを描いてください。
横に3コマ（立ち・左足を出す・右足を出す）、縦に4方向（正面・後ろ・左向き・右向き）、全部で12コマ。背景は透明か単色。

キャラクター: 〈例: 港町の見張りの青年。黒に近い紺の、少しはねた短髪。灰色の目。紺の上着に赤いマフラー、茶色のズボンとブーツ。背中に剣〉

絵の決まり:
- 大きな頭と小さな体の2頭身。目は縦長の小さな点、ほおに薄い赤み。
- 1ピクセルの暗い輪郭線（真っ黒ではなく、色ごとに暗くした色）。
- 部位ごとに3段の陰影、光は左上から。グラデーション・ぼかし・アンチエイリアスは使わない。
- 歩幅は小さめ。歩くコマでは、腕を前後に小さく振り、マフラーの端が少し揺れる。〈女性なら: 髪の先も少し揺れる〉
- 色は20色以内。90年代後半の家庭用ゲーム機のRPGのフィールドキャラのような、くっきりした作り。
- 既存のゲームや漫画のキャラクターには似せない。
```

英語で頼むとき（AIによっては英語のほうが守りやすい）:

```
A pixel art sprite sheet of a chibi (2-heads-tall) RPG field character, each frame 16x32 pixels.
3 columns (standing, left foot forward, right foot forward) x 4 rows (facing down, up, left, right), 12 frames total, transparent background.
Character: 〈a young harbor lookout, short slightly messy navy-black hair, gray eyes, navy jacket, red scarf, brown trousers and boots, a sword on his back〉.
Style: big head and small body, small vertical-dot eyes, light blush on cheeks, 1-pixel dark colored outline (not pure black),
3-tone cel shading per part with light from the top-left, no gradients, no anti-aliasing, no blur, under 20 colors,
short steps, arms swing slightly and scarf ends sway one pixel while walking〈, hair tips sway too (for female characters)〉.
Original design, not based on any existing game or manga character.
```

## 書くときの注意

- 作品名・ゲーム名・作者名・既存のキャラの名前は書かない（CLAUDE.md 1-1）。「〜のような」と書くのは「年代・機種の雰囲気」までにする。
- 髪の色と目印の1色は、仲間どうしで重ならないようにする（並んだときに見分けられるように）。
- 全身の絵（256×256）・顔のアイコン（`prompt-icon.md`）と同じ色にする（同じ人物だと分かるように）。

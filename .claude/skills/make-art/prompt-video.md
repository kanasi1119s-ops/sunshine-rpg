# 見本の動画（製作・動き・エフェクト）とインスタ用の動画を作るためのプロンプト

予言の歪みの4本（エディタで作る様子・歩く/攻撃・雷の術・炎の術）と同じ作りで、
**ほかのボス・ほかの術の見本の動画**を作るときの頼み方。`〈 〉` のところを書きかえて使う。

## A. Claude（Claude Code）に頼むとき

```
〈ボスの名前〉（assets-src/monsters/〈id〉/）の見本の動画を作ってください。予言の歪みの4本と同じ作り方で。
作る動画: 〈例: エディタで作る様子／歩く・攻撃／〈系統〉の術〉
背景: 〈例: assets-src/backgrounds/star-shrine/（星の神殿）〉　曲: 〈例: そのボスの戦闘曲 boss-〈id〉〉
インスタ用も: 〈作る／作らない〉

■ 1. エディタで作る様子（ドット絵ができるまで）
- node tools/pixel-practice/editor-record.mjs 〈仕上げ前.txt〉 〈色.json〉 〈touchup.json〉 〈出力.mp4〉 --ref 〈下絵.png〉 --title "〈名前〉" --anim 〈anim.json〉
  （色を暗い順に置く → 手直しのレイヤーに直線ツールで描く → 部品をレイヤーに分けて、歩く・攻撃のコマをフレームに入れて再生）
- 録画は長い（10分ほど）ので、nohup で裏で動かす。ほかの重い作業（画像生成・曲の書き出し）と同時に動かさない。
- 画面の文字（何をしているか）は上に出す。絵の上（おなかなど）に文字を描かない。

■ 2. 歩く・攻撃（コマの長さどおり）
- python3 tools/pixel-art/ai-gen/anim_clip.py 〈anim.json〉 〈出力.mp4〉 --title "〈名前〉" --bg 〈背景 400×250〉
- 効果音と曲: python3 tools/sound/se_mix.py attack 〈出力.mp4〉 〈完成.mp4〉 --bgm 〈曲.wav〉 --bgm-gain 0.2

■ 3. 術のエフェクト（本物の戦闘画面に重ねる）
- 文字と窓（ゲームと同じ細かさの透明な絵）: 開発用サーバー（npx vite --port 5174）を動かして
  node tools/pixel-practice/battle-ui-layer.mjs assets-src/effects/preview/ui-〈系統〉.png "〈ボスの名前〉は 〈術の名前〉を となえた！"
  **下の窓の文は術ごとに作る**（炎の動画が「雷の術」のままだった失敗）。
- 動画: python3 tools/pixel-art/fx/fx_preview.py （背景2つ） assets-src/effects/〈系統〉 〈anim.json〉 〈出力.mp4〉
  --slow 3 --party assets-src/characters/walk-2head --set 〈系統〉 --bg 〈背景 400×169〉 --ui 〈ui-〈系統〉.png〉
  （発動・ため → 1人用、発動・ため → 全体用、最後に3倍おそく。味方は新しい2頭身の絵、当たるとダメージの絵）
- 効果音と曲: python3 tools/sound/se_mix.py fx 〈出力.mp4〉 〈完成.mp4〉 --fxdir assets-src/effects/〈系統〉 --bgm 〈曲.wav〉 --bgm-gain 0.2
- ボスの戦闘曲は、ゲームと同じ音で書き出す: node tools/composer/build.mjs のあと
  node tools/audio-check/render-catalog.mjs 〈フォルダ〉 boss-〈id〉

■ 4. 背景
- 人間がくれた絵は assets-src/backgrounds/〈名前〉/original.jpg に置き、戦闘の場（400×169）と動きの見本（400×250）に切って64色にする。
- 絵の出どころを README に書く。

■ 5. インスタ用（リール、縦 9:16）
- python3 tools/video/insta_reel.py 〈完成.mp4〉 〈出力.mp4〉 --title "〈見出し〉" --sub "〈小見出し〉"
  （1080×1920・H.264・30コマ・AAC 48kHz・-14 LUFS。文字は上下のふち（250ドット）を避ける。見出しは横からはみ出さない大きさに）
- 3分を超えるもの（エディタの様子）は、描く場面を4倍速にして3分以内に収める。
- **ファイル名は英数字にし、1本ずつ送る**（日本語の名前・まとめて送ると、ダウンロードできないことがあった）。30MBを超えないように。
- 投稿は人間がする（CLAUDE.md 1-2: SNSでの一般公開は人間の承認）。

■ 確かめる
- 決めのコマを並べた画像で見る（文字が読めるか、背景で絵が見えにくくないか、光が強すぎないか）。
- 音の大きさ（ebur128）: 見本は -14〜-17 LUFS、ピーク -1dB 以下。

■ 報告
完成した動画を送ってください。動画ごとに、何が映っているかを1行で。
```

## 気をつけること（これまでの指摘から）

| 指摘 | 直し方 |
|---|---|
| なんで動画に文字を入れたの？／おなかの文字はいらない | 説明の文字は画面の上の帯だけ。絵の上には描かない |
| ドット絵の全身が入っていない | 最後に全身が入る大きさで見せる |
| ゲーム画面の文字が読みにくい | 文字はゲームと同じ細かさ（1200×675）で重ねる（--ui）。論理の大きさの文字を拡大しない |
| 炎の動画なのに「雷の術を となえた」 | 窓の文は術ごとに作る |
| ダウンロードできない | 英数字のファイル名・1本ずつ・30MB以下 |

# ボスの魔法エフェクトを作るためのプロンプト

雷の術（`tools/pixel-art/fx/lightning.py`）・炎の術（`tools/pixel-art/fx/fire.py`）と同じ作りで、
**新しい系統（氷・闇・風・土など）や、ほかのボスの術**を作るときの頼み方。`〈 〉` のところを書きかえて使う。
決まりの中身は `docs/design/battle-effects.md`。

## A. Claude（Claude Code）に頼むとき

```
ボスが使う〈系統: 例 氷〉の術のエフェクトを作ってください。雷の術・炎の術と同じ作り方で。
使うボス: 〈例 予言の歪み（assets-src/monsters/kiri-yugami/anim.json）〉
イメージ: 〈例: 足もとから氷の柱が突き出し、砕けて破片が飛ぶ。青白く、冷たい霧〉

■ 4つ1組で作る（tools/pixel-art/fx/〈系統〉.py、置き場所 assets-src/effects/〈系統〉/）
1. 発動（ボスのまわり、aura）: 足もとに〈系統〉の色の陣（輪と、回る印）。陣の奥の半分はボスのうしろ（"back"）に描く。
   体のふちに〈系統〉の光が脈打ち、ふちから小さな〈系統〉のもの（稲妻・炎の舌など）がはう。粒がのぼり、最後に柱が立って消える。
   ボスが両手を振り上げた姿（anim.json の flat_attack3 の5コマ目）の形から作る。
2. ため（charge）: 振り上げた両手の上で〈系統〉の玉がふくらみ、まわりから粒が吸いこまれ、最後にはじける。
3. 1人用（例: 落雷・火球）: 当たる人の足もとに合わせる。当たった瞬間に いちばん強い光・揺れ。
   飛んでいくものは、コマごとに画面の置き場所 "at" を書く（エディタは幅256までなので、まわりだけ切り出す）。
4. 全体用（例: 雷の嵐・火柱）: 味方4人と地面2か所に、少しずつずらして当てる。予告（足もとが光る）→ 当たる → 残り（煙・破片）。

■ 描き方の決まり
- 戦闘画面（論理 400×225、戦闘の場は上の169）と同じ1ドットの大きさで描く。ボスは左（x=16, y=2, 132×132）、味方は右の地面。
- 光るものは、芯がいちばん明るく、外へ向かって暗く。いちばん外は1ドットおきの点々。
- 〈系統〉の色の段: 〈例 氷: 白 → 薄い水色 → 水色 → 青 → 紺（点々）〉。煙・霧は灰色の点々。
- 炎・煙・霧のような「流れるもの」は熱さの格子（FireField）を流し、色を分ける前に少しぼかす（1ドットのざらつきを消す）。
- 稲妻・ひびのような「折れ線」は、ぎざぎざの点のならび＋芯・縁・光の重ね描き。コマごとに形を少し変えてちらつかせる。
- **白い光（画面の点滅）は1つの術で強いのを1回だけ**（0.3〜0.45）。ほかは弱く（0.1）。何度も強く光ると目にきつい。
- 術のあいだは画面を少し暗くする（dim）。光の色は "flash_color" で系統の色に。
- 豪快さは、大きさ（玉・爆発・柱）、続けて起こる小さな爆発、揺れ（shake 4〜6）で出す。
- 既存作品の魔法陣・文字・呪文の見た目に似せない。陣の印はこの術だけのもの。

■ 当たった味方の絵
- 2頭身キャラ（assets-src/characters/walk-2head/）に、〈系統〉に当たった絵を足す（tools/pixel-art/fx/hurt_pose.py）:
  ひるむ姿（hurt_left）を〈系統〉の色で塗りかえる（例: しびれ＝ふち白・中青、燃える＝ふち暗い赤・中 赤橙黄）。
- エフェクトのコマに "party": [[味方の番号, 絵, 後ろへのずれ]] を書く（当たると 白 → 〈系統〉の絵 ⇄ ひるむ、2ドット後ろへ）。
  光っている絵は、エフェクトより手前に描く（かくれて見えなくならないように）。

■ 効果音
- エフェクトのコマに "se": [[効果音の名前, 音量]] を書く（音の作り方は prompt-sound-effect.md）。

■ エディタで描く・確かめる
- 4つともドット絵エディタに1コマずつ入れて書き出す:
  node tools/pixel-practice/fx-editor.mjs assets-src/effects/〈系統〉/〈名前〉.json assets-src/effects/〈系統〉/editor
- 食い違いを確かめる: python3 tools/pixel-art/fx/verify_sheet.py 〈名前〉.json editor/〈名前〉.sheet.png（0マスになること）
- 決めのコマを並べた画像で見る（光が強すぎないか、味方にかくれていないか、画面の外に出すぎていないか）。

■ 見本の動画・記録
- 見本の動画は prompt-video.md の手順で（効果音と、そのボスの戦闘曲を入れる）。
- docs/design/battle-effects.md に〈系統〉の表を足し、docs/roadmap.md の FX の項目を更新する。ゲームへの組み込みはまだ「仮」と書く。

■ 報告
決めのコマの画像と、見本の動画を見せてください。呪文の名前は、既存作品に似ない名前の案を3つ出してください（battle.md の名付けの決まり）。
```

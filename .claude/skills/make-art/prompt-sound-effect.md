# 効果音を作るためのプロンプト

雷の術・炎の術・ボスの攻撃の効果音（`tools/sound/se_synth.py`、置き場所 `assets-src/se/`）と同じ作りで、
**新しい効果音**を作るときの頼み方。`〈 〉` のところを書きかえて使う。録音素材・既存作品の音は使わない（一から合成する）。

## A. Claude（Claude Code）に頼むとき

```
〈何の音か: 例 氷の術〉の効果音を作ってください。雷・炎の効果音と同じ作り方で（tools/sound/se_synth.py に足す）。
鳴らす場面: 〈例: 発動とため／氷の柱が突き出す／砕ける／冷たい風〉
イメージ: 〈例: キーンと高く張りつめた音から、ガシャンと割れる音へ。最後にさらさらと氷の粒が落ちる〉

■ 作り方
1. 音を部品に分けて考える（立ち上がり → 本体 → 余韻）。例:
   - 雷: 裂ける音（とても短い白い音＋高いざらつき）→ どん（下がる低い正弦波＋低いノイズ）→ ゴロゴロ（低いノイズを波打たせる）
   - 炎: ごうごう（帯を区切ったノイズを、炎のゆらぎで波打たせる）＋ぱちっとはぜる音 →「ボッ」（低いノイズの塊＋低音）
   - 攻撃: ため（岩がきしむ粒）→ 風切り（帯の中心が低→高→低へ動くノイズ、左から右へ）→ 当たり（打撃＋つぶれる音＋かけら）
2. se_synth.py に関数を足す（48kHz・ステレオ）。左右は別のノイズにして広がりを出す。残響（reverb）は短め・少なめ。
3. **音の終わりは必ず短く小さくする（tail）**。途中でぷつっと切れると「プチ」と鳴る。
4. 書き出す: python3 tools/sound/se_synth.py assets-src/se 〈名前の一部〉

■ 確かめる（耳で聞けないので、数値と絵で）
- スペクトログラム（周波数の絵）を作り、思った帯域に音があるか、途中で急に切れていないかを見る。
- 高い音だけを取り出して、まわりより飛びぬけて大きい所（プチ）を探す（わざと入れたぱちぱち以外に無いこと）。
- ピーク -1〜-6dB、音の大きさをそろえる。

■ 使う
- エフェクトのコマに "se": [["〈系統〉/〈名前〉", 音量]] を書くと、見本の動画に入る（tools/sound/se_mix.py fx）。
- docs/sound/tracks.md の効果音の節に、名前と中身を足す。ゲームの効果音（se-library.ts）へのつなぎ込みは、まだ「仮」。

■ 報告
スペクトログラムの画像と、効果音を入れた見本の動画を見せてください（私は聞いて確かめます）。
```

## 気をつけること

- 既存作品の効果音（有名なRPGの決定音・呪文の音など）に似せない。
- 雷の「ぱちぱち」は高く鋭く（2.5k〜12kHz）、炎の「はぜる音」は低く丸く（0.7k〜2.6kHz）にすると、聞き分けられる。
- 曲と重ねる見本では、曲を小さく（0.2倍ほど）して、最後にリミッターをかける（se_mix.py がやる）。

# ボスの動き（歩く・攻撃）を作るためのプロンプト

予言の歪み（256×256のボス）で作った「歩く16コマ・攻撃3種類（腕だけ・体ごと・両手）各14コマ」と同じ作りで、
**ほかのボスに動きをつける**ときの頼み方。`〈 〉` のところを書きかえて使う。
考え方は `docs/design/pixel-animation-study.md`、道具は `tools/pixel-art/ai-gen/boss_rig.py`（見本は `assets-src/monsters/kiri-yugami/rig.json`）。

## A. Claude（Claude Code）に頼むとき

```
〈ボスの名前〉（assets-src/monsters/〈id〉/）に、歩く動きと攻撃の動きをつけてください。
予言の歪み（assets-src/monsters/kiri-yugami/）と同じ作り方で。

■ 部品に分ける（rig.json）
1. 仕上がった絵（〈id〉.txt と色）を4倍以上に拡大し、行・列の目盛りを入れた画像で、腕・肩当て・手・指先の位置を確かめる。
2. rig.json を書く（予言の歪みの rig.json を見本に）:
   - "arm"（右腕）・"arm_l"（左腕）: 腕を囲む多角形 poly、肩の関節 pivot、手の高さから下は外側のかたまりだけを腕にする lower_from、
     付け根の丸い玉の半径 joint_r（18ほど）。
   - "extra": 内側へ曲がった指・はなれた爪を囲む多角形。**外側のかたまりだけの決まりでは指先が腕から外れ、攻撃のとき胴に置き去りになる**ので、必ず足す。
     腕の範囲の下の端は、いちばん下の爪の先まで。
   - "shoulder"・"shoulder_l": 肩当て（腕の付け根の上にかぶせて、関節をかくす）。
   - "hip"（足の付け根の行）、"split"（左右の境の列）、"glow"（光る色の記号。当たりで明るくする）。
3. 腕の範囲を赤・青で重ねた画像を作り、腕の部品に太ももが入っていないか・指先が全部入っているかを見る。
   胴に残った小さなかけら（40ドット未満）は boss_rig.py が消す。

■ 動きを作る
4. python3 tools/pixel-art/ai-gen/boss_rig.py 〈絵.txt〉 〈色.json〉 〈rig.json〉 〈anim.json〉
   - 歩く16コマ: 上下の動きが中心（沈みこみ・伸び上がり）、左右は1ドットまで、腕は足と反対に振る。
   - 攻撃（各14コマ）: 構え → ため（ゆっくり、長めに止める）→ 振り下ろし（速く、残像2コマ）→ 当たり（止める・火花・揺れ）→ 振り抜け → 戻りすぎ → 構え。
     腕だけ／体ごと（ためで反って片足を上げ、当たりで倒れこむ）／両手（両腕を頭の上へ → **両手が体のまん中（内側）へ**たたきつける）。
   - 腕が前へ出るコマ・頭の上へ振り上げるコマは、**腕のまわりに暗い縁**をつけて、胴より前にあると分かるようにする。
5. 確かめる（決めのコマを拡大して並べた画像で）:
   - 腕が切れて見えないか（付け根の玉が肩当てにかくれているか）
   - 指先・爪が腕といっしょに動いているか、胴に残っていないか
   - 足の一部が攻撃に巻きこまれていないか
   - 体全体がゆがんでいないか（動くのは主に腕。胴は少し傾く・沈むだけ）
6. 版を残す: 前の版と比べるため、assets-src/monsters/〈id〉/anim-versions/ に「番号-何を直した版.json.gz」で残す。

■ 見本の動画
7. python3 tools/pixel-art/ai-gen/anim_clip.py 〈anim.json〉 〈出力.mp4〉 --title "〈ボスの名前〉" --bg assets-src/backgrounds/star-shrine/clip-400x250.png
   （コマの長さどおり。効果音と曲を入れるのは prompt-video.md）

■ 報告
決めのコマを並べた画像と、見本の動画を見せてください。ゲームの戦闘画面で動かすのは、見せてから決めます。
```

## 気をつけること（これまでの指摘から）

| 指摘 | 直し方 |
|---|---|
| 歩きが左右に大きく、上下が少ない | 上下（2〜7ドット）を中心に、左右は1ドットまで |
| 攻撃で体が謎に動く | 体ごとゆがめない。腕を部品にして関節で回す |
| 足の一部が攻撃に巻きこまれる | 手の高さから下は外側のかたまりだけ（lower_from） |
| 腕が切れて見える | 付け根に丸い玉（joint_r）、上半分は肩当てでかくす |
| 指先が切れる・取れる | extra で指先を腕に入れる。回すときの票数を下げる（ROT_MIN=5） |
| 腕は体より前に行くはず | 前へ出る・振り上げるコマに暗い縁 |
| 両手は内側に入る感じ | 当たりで ±40度、振り抜けで ±46度 |
| もっと滑らかに | 決めのポーズの間に中割り（歩き8→16、攻撃7→14）。振り下ろしは速さを残す |

# 外部の画像生成AIのイメージ画像から、2頭身のドット絵を作るプロンプト

2026-10-07、人間の指示「外部のAI画像生成をつかってファンタジーになるキャラクター、モンスター、ボス、天使、悪魔、魔王、神の
イメージ画像を作って、それを参考にしてエディタを使って2頭身のドット絵を作るプロンプトにして」。

流れは2段階:
1. **イメージ画像**: 人間が外部の画像生成AI（ChatGPT・Gemini など）で、1体ずつ「全身・正面・背景なし」の**ふつうの頭身のキャラ**を作る（A）。
   画像生成AIには2頭身（ちびキャラ）を描かせない（2026-10-07、人間の指示「画像生成AIでは普通のキャラを生成してそれを参考にしてエディタで2頭身キャラを作るの」）。
2. **ドット絵**: その画像を Claude に渡し、Claude が2頭身にデフォルメして、うちのドット絵エディタで描き起こす（B）。

画像生成AIの絵は、ドットの数・縁取り・左右の形を守れないので、**ドット絵そのものは作らせない**。
色・形・持ち物の「見本」として使い、ドットは Claude がエディタで1マスずつ置く。

## 大きさの決まり（2頭身）

| 種類 | 1コマの大きさ | 色数 | コマ |
|---|---|---|---|
| キャラクター（人・天使・悪魔の人型） | 16×32 | 20色以内 | 4方向×3コマ（歩き） |
| 雑魚モンスター | 32×32 | 16色以内 | 正面1枚＋待機2コマ |
| ボス・魔王 | 48×48 | 24色以内 | 正面1枚＋待機2コマ |
| 神（いちばん大きいボス） | 64×64 | 32色以内 | 正面1枚＋待機2コマ |

- 2頭身 = 頭（または顔のある上半分）が全体の半分近く。手足は短く、目は大きめの点。
- 羽・光輪・角などの大きな飾りは、枠の中に収める（はみ出すなら1段大きな枠にする）。

## A. 外部の画像生成AIで、イメージ画像を作るプロンプト

どの種類も、最後に共通の決まり（A-0）を付けて頼む。

### A-0. 共通の決まり（毎回、末尾に付ける）

```
【絵の決まり】
・1体だけ、全身、正面（少しだけ斜めでもよい）。頭のてっぺんから足先まで（羽・角・しっぽの先も）切れずに入れ、上下左右に余白を残す。
  縦長の画像で、体を画面の中央に、全体の8割ほどの大きさで描く。顔だけ・上半身だけの絵にしない
・キャラだけを描く。背景は描かない（白一色か透明。景色・床・影・飾りの枠も入れない）
・ふつうの頭身（ちびキャラ・デフォルメにしない）。体つき・服・持ち物の形がはっきり分かるように
・色ははっきり、数を少なめに。光は左上から。細かい模様より、大きな形と色の分け方を大事に
・ファンタジーRPGの、オリジナルのデザイン。既存のゲーム・漫画・アニメのキャラクターや、実在の宗教の特定の神・人物には似せない
・文字・ロゴ・サインは入れない
```

英語で頼むときの共通の決まり:

```
Single character only, full body from head to toe in a tall portrait image, front view, the whole figure (including wings, horns and tail tips) visible and centered with empty space around it, never cropped, not a close-up or half body, character only, no background (plain white or transparent), no scenery, no floor, no shadow, no frame.
Normal (non-chibi, non-deformed) proportions, with the body shape, clothes and items clearly readable.
Clear flat-ish colors with a small palette, light from the top-left, bold shapes over fine detail.
Original fantasy RPG design, not based on any existing game, manga, anime character or any specific real-world deity or person. No text, no logo, no signature.
```

## B. Claude に、イメージ画像から2頭身のドット絵を作ってもらうプロンプト

イメージ画像をチャットに貼るか、リポジトリの `assets-src/chibi-ref/〈名前〉.png` に置いてから頼む。

```
/make-art 貼ったイメージ画像（ふつうの頭身）を参考に、2頭身にデフォルメして、うちのドット絵エディタでドット絵を作ってください。

■ 絵
- 名前: 〈名前〉／種類: 〈キャラクター・雑魚モンスター・ボス・天使・悪魔・魔王・神〉
- イメージ画像: 〈貼った画像／assets-src/chibi-ref/〈名前〉.png〉
- 大きさとコマ: prompt-chibi-from-reference.md の「大きさの決まり」のとおり（〈変えるときだけ書く: 例 48×48〉）

■ 手順（各段階で、拡大した見本の画像を見せる）
1. 読み取り: イメージ画像（ふつうの頭身）から、その人物・モンスターだと分かる特ちょう（髪型・顔つき・服の形・羽・角・持ち物・目印の色）と、
   色（部位ごとに 暗・地・明 の3段）を拾い、一覧にして見せる。既存の作品のキャラに似ている所があれば、ここで色か形を変える。
2. デフォルメ: 2頭身に描き直す。頭を全体の半分近くまで大きくし、体と手足を短くする。
   特ちょうは、小さくなっても分かるよう大きめにして残し（髪型・角・羽・持ち物・目印の色）、細かい模様やしわは省く。
   人型は、うちの2頭身の歩くキャラ（assets-src/characters/walk-2head/）と同じ頭と体の大きさにそろえる。
   大きな形だけを1色ずつのかたまりで置き、羽や角は左右対称から始める。
3. ドット: 1ドットの暗い縁取り（真っ黒ではなく、その部分を暗くした色）、部位ごとに3段の陰影（光は左上）、
   目ははっきりした点、金具・宝石・光輪に明るい1ドット。孤立した点（意図しない1ドット）は消す。色数の上限を守る。
   イメージ画像を縮めて減色しただけの絵にしない（頭身がちがうので、なぞらずに描き起こす。輪郭・陰影は1マスずつ置く）。
4. コマ: キャラクター・人型は 4方向×3コマ（立ち・左足・右足。右向きは左向きの反転）。
   モンスター・ボス・神は、正面1枚＋待機2コマ（体が1ドット上下、羽・炎・光輪が1ドット揺れる）。
5. エディタで描く: ドット絵エディタで全コマを描き、「食い違い 0 マス」を確かめる（tools/pixel-practice/editor-draw.mjs）。
6. 見せる: 8倍に拡大した全コマの一覧、動きのGIF、イメージ画像と並べた見比べ画像。

■ 仕上げ
assets-src/chibi/〈名前〉/ に、エディタ用のファイル（文字グリッドと色）・PNG（等倍と8倍）・GIF・README（イメージ画像の出どころ、使ったAIの名前）をまとめる。
ゲームへの組み込みは、見せてから決める。
```

## 注意

- 作品名・ゲーム名・作者名・既存のキャラの名前は、どちらのプロンプトにも書かない（CLAUDE.md 1-1）。
- 外部の画像生成AIの画像を参考にして作った絵を売ったりゲームに入れたりする前に、そのAIの利用規約（商用利用・出力の扱い）を確かめ、
  README に、使ったAIの名前と、AIを使ったことを書く（販売するときは「AI生成作品」の表示が要る。`docs/sales/monster-pack.md`）。
- 有料の画像生成AIを新しく契約するのは、人間の承認が要る（CLAUDE.md 1-2）。

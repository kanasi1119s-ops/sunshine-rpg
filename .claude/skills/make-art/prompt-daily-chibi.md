# 今日の1体: キャラ決め担当（エージェント）→ イメージ画像 → 2頭身ドット絵 のプロンプト

2026-10-07、人間の指示「今日作るキャラを決める人をエージェントで入れて、それをさきほどの2頭身ドット絵までの生成の流れでプロンプトを作ろうか」。
流れの中身（大きさの決まり・イメージ画像の決まり・ドット絵の手順）は `prompt-chibi-from-reference.md`。
このプロンプトは、それを **1日1体、キャラ決めから仕上げまで** 通しで行うためのもの。
手で頼むときも、定期タスクに入れるときも、下の枠の中をそのまま使う。

```
今日の2頭身ドット絵を1体、キャラを決めるところから仕上げまで作ってください。
手順は .claude/skills/make-art/prompt-daily-chibi.md と prompt-chibi-from-reference.md に従う。

■ 1. キャラ決め担当（サブエージェントに任せる）
次の内容を、キャラ決め担当のエージェントに頼み、結果（設定表）を受け取る。

  あなたは「今日作るキャラ」を1体だけ決める担当です。ファイルは読むだけで、書きかえないでください。
  読むもの:
  - assets-src/chibi/log.md（これまでに作ったキャラの一覧。無ければまだ0体）
  - docs/story/characters.md と docs/story/ の世界観（世界や町の雰囲気に合わせるため）
  - .claude/skills/make-art/prompt-chibi-from-reference.md（大きさの決まりと、種類の一覧）
  決め方:
  - 種類は次の6つから選ぶ（2026-10-07、人間の指示）。log.md の最後の種類の次を選び、この順に回す:
    1. ファンタジーの人間・人型の種族（例: エルフ・ドワーフ・獣人・戦士・剣士・騎士・魔法使い・僧侶・賢者・盗賊・弓使い・
       踊り子・吟遊詩人・召喚士・錬金術師・勇者・王族・商人・村人 など。種族と職業を組み合わせてよい）
    2. モンスター（例: スライム状の生き物・獣・虫・植物・アンデッド・ゴーレム・精霊・龍・ドラゴン など。龍もここに入る）
    3. 天使
    4. 悪魔
    5. 神
    6. 魔王
  - モンスター以外（人間・天使・悪魔・神・魔王）は、性別（男性・女性）を必ず決める。同じ種類が続けて同じ性別にならないよう、
    log.md の前回の同じ種類と反対の性別を基本にする。
  - 大きさ: 人間・天使・悪魔（人の形）は 16×32。モンスターは小さいもの 32×32、龍・大型は 48×48。魔王は 48×48。神は 64×64。
  - これまでのキャラと、髪の色・目印の1色・形が重ならないようにする。
  - 既存のゲーム・漫画・アニメのキャラクターや、実在の宗教の特定の神・人物を思わせる組み合わせ（名前・色・髪型・飾り）にしない。
    龍・天使・悪魔・神・魔王も、有名な作品のデザイン（決まった色・形の組み合わせ）に寄せない。
  - 名前はこの物語の世界に合う、オリジナルの日本語の名前（既存作品の名前・呪文名・モンスター名を使わない）。
  返すもの（この形の表で）:
  - 名前／種類／性別（モンスターは「なし」）／種族・職業（人間のとき）／大きさ（例 16×32）／ひとことの設定（どこにいて何をしている者か）
  - 見た目: 髪（色と形）・目（色）・肌（色）・服や体（形と色）・目印の1色・持ち物や羽・角・光輪
  - 2頭身にしたとき残す特ちょう（3つ）
  - イメージ画像の指示文（英語、77トークン以内）と、避ける言葉（英語）
  - 選んだ理由（これまでの一覧と重ならない点）

■ 2. イメージ画像（ふつうの頭身・背景なし）
- 設定表の英語の指示文で、この作業環境の画像生成（Stable Diffusion 1.5、tools/pixel-art/ai-gen/generate.py、QUALITY=real）を使い、
  ふつうの頭身・全身・正面・白い背景の絵を1枚描く（1枚 約9分。ほかの画像生成・エディタ・rembg と同時に動かさない）。
  指示文の決まり: "full body standing fantasy rpg character, 〈設定表の見た目〉, front view, realistic proportions,
  painterly concept art, isolated on plain white background"。避ける言葉: "photo, 3d render, chibi, text, watermark, frame,
  border, multiple people, cropped, cut off head, close-up, blurry, nsfw, background scenery, floor, shadow"。
- 頭や足が切れた・2人いる・背景がある絵なら、種を変えてもう1枚（2枚まで）。
- 絵を assets-src/chibi/〈名前〉/ref.png に置き、ここで一度、人間に絵を見せる。

■ 3. 2頭身のドット絵（ドット絵エディタで描く）
prompt-chibi-from-reference.md の B の手順どおり:
読み取り（特ちょうと 暗・地・明 の色）→ デフォルメ（頭を全体の半分近くまで大きく、特ちょうは大きめに残し、細かい模様は省く）
→ ドット（1ドットの暗い縁取り、3段の陰影、光は左上、色数の上限）→ コマ（人間・天使・悪魔の人型は4方向×3コマ、モンスター・神・魔王は正面＋待機2コマ）
→ ドット絵エディタで描いて「食い違い 0 マス」を確かめる。
イメージ画像を縮めて減色しただけの絵にしない（頭身がちがうので、なぞらずに描き起こす）。

■ 4. 確かめ担当（別のサブエージェントに任せる。作った本人が採点しない）
8倍の一覧・動きのGIF・イメージ画像を渡して、次を見てもらい、だめな所があれば直す（2回まで）:
- 2頭身になっているか／イメージ画像の人物だと分かるか（特ちょう3つが残っているか）
- 縁取り・陰影・色数・孤立した点／4方向で同じ人物に見えるか（人型）
- 既存の作品のキャラに似ていないか

■ 5. 仕上げと記録
- assets-src/chibi/〈名前〉/ に、ref.png・エディタ用のファイル（文字グリッドと色）・PNG（等倍と8倍）・GIF・
  README.md（設定表・指示文・乱数の種・使ったAI: Stable Diffusion 1.5 / CreativeML OpenRAIL-M）をまとめる。
- assets-src/chibi/log.md に1行足す（日付・名前・種類・性別・大きさ・髪の色・目印の1色）。
- コミットしてプッシュし、作業ブランチの名前を伝える。ゲームへの組み込みはしない（見せてから人間が決める）。

■ 報告（日本語で短く）
今日のキャラの名前と設定（2〜3行）、イメージ画像、8倍の一覧、動きのGIF、確かめ担当の指摘と直したこと。
```

## メモ

- キャラ決め担当と確かめ担当をサブエージェントにするのは、決める人・作る人・確かめる人を分けて、同じ考えのくせで偏らないようにするため。
- 種類を順番に回すので、6日で 人間・モンスター・天使・悪魔・神・魔王 が1体ずつそろう。性別は同じ種類の前回と反対にするので、2周で男女がそろう。
- 1回の時間の目安: キャラ決め 5分、イメージ画像 10〜20分、ドット絵 30〜60分、確かめ 10分。
